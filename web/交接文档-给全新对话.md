## 4. 硬规矩（犯过就会白干）

1. **不许硬编码两份战报的配队结果**；改动必须实测，验收下降就回滚（除非是"数据纠错"，那种要留下证据链）。
2. **改大文件不用 Python 的 `'w'` 模式**：`io.open(p,'w')` 先截断再编码，遇编码错会把文件清成 0 字节
   （本项目已把 583KB 的 simulator.html 清空过一次；恢复办法见 fix_log 第62轮）。
   一律用 Edit 工具 / Node 写。
3. **HTML 字符串拼接的行级容器必须闭合**。本项目刚踩过：战报每行 `<div>` 没闭合 → 行行嵌套 →
   点第 N 行时事件冒泡到最外层 → 永远显示第一条船。静态检查靠 `_static_audit.js`。
4. **弹窗必须 `classList.add('active')`**（`openModal/closeModal`），只写 `style.display='flex'` 会得到
   "全屏透明但仍拦截点击"的遮罩 —— 用户报"点不动"十有八九是它。
5. **页面控件必须真 dispatch 事件**：内联 `onclick` 的 bug 直接调函数测不出来（要用 `page.mouse.click`）。
6. `let/const` 声明的变量**不挂 window**：探针要读裸变量名，写 `window.X` 会得到假警报。
7. 联网/知识库的口径**先查再做**；不确定的机制宁可记录"不实现+原因"，也不猜。

## 6. 你那两个方案，能不能在这台机器上实现？（实测数字）

**这台机器**（刚量的）：`Intel i5-2450M @2.5GHz × 4 线程`、**内存 1.9GB（可用仅 0.1GB）**、C 盘剩 2.0GB。

引擎实测：加载 202 舰船+加点树 **86ms / 35MB**；单场 **839ms**（大舰队，平均时长 596s）；**单线程 1.2 场/秒**；
一次"护航对弈"（参数级）一代（6 个体 × 3 对手 = 18 场）≈ **15.1 秒**。

| 方案 | 本机能不能跑 | 说明 |
|---|---|---|
| **方案二A（神经进化自对弈 NEAT）· 参数级演示** | ✅ 能 | `demo/evolve_duel.js` 的**参数包**交替进化已经能跑（实测 A 742→1235、B 841→1577）——⚠️它还**不是** NEAT（无网络、无拓扑进化）；20 代 × 6 个体 ≈ 5 分钟 |
| **方案二A · 无人值守持续进化（24h+）** | ❌ 不能 | 可用内存只剩 89MB，开一个 headless Edge 就要 300~700MB；C 盘剩 2GB 也存不下多代存档 |
| **方案二B（混沌生长引擎无枷锁版）** | ❌ 不能 | 同上，且它要"每代存全基因组 + 多岛并行"，内存与磁盘都不够 |

**真正的瓶颈不是 CPU**：每个进化代都要调 LLM 做变异/评估，一次 API 往返 3~30 秒且要花钱 —— 与设备无关。

**换到 16核/46G 的收益（按本机实测线性外推）**：
- 线程 4→16（×4）、内存 1.9G→46G（×24）
- 纯引擎：1.2 场/秒 → **≈19 场/秒 ≈ 69,000 场/小时**（并行 16 份）
- 护航对弈一代：15.1 秒 → **<1 秒**
- 能同时开：8 个进化岛 + 常驻向量库 + 每代存档 + 自动跑验收，**不会再 OOM**
- ⚠️ 建议：把"变异算子"做成**纯引擎侧（随机/遗传算子，不调 LLM）**，那样 16 核才真正吃得满；
  LLM 只用于"每 N 代总结/提出新策略"，否则瓶颈永远是 API 配额。
