# 神经元实验室 · 使用说明（2026-10-06）

> 这一轮把另一台设备训练了 1000+ 代的「方案二A · 神经元对打」**完整做进了 `拉格朗日智能体3`**：
> 不再需要 Node / 命令行 —— 浏览器里点几下就能训练，训练过程每 5 代自动存档，断了能接着跑。
> 本文件 = 怎么用 + 做了什么 + 诚实的状态说明。

---

## 一、30 秒上手

1. 打开 `neuron.html`（任何页面导航里的 **🧬 神经元** 都能进）；
2. 点 **📦 载入内置默认战报配队**（内置了另一台设备的训练起点：我方/敌方各两支队的配队 + 加点）；
3. 设备预设点 **⚖️ 均衡**（或按机器选 1~16 个岛）；
4. 点 **▶ 开始训练**。看板会逐岛显示：代数 / 分数 / 胜率 / 网络规模 / 精英冻结代数 + 曲线。
5. 想停就 **⏸ 暂停**（暂停前会先存档）；想看网络长什么样，点导航 **🧠 网络 3D**。

**两种玩法（第①节单选）**
- 两边都选「进化」→ **自对弈**（A 群 vs B 群互打，= 另一台设备在跑的原版形态。**分工：A 控我方 2 支——我方护航 + 我方被护航；B 控敌方 2 支——敌方护航 + 敌方被护航**；每场 = 这 4 支舰队打一场护航战）；
- 敌方选「固定」+ 在四个下拉里选好敌方两支舰队 → **打指定对手**（我方进化到能击败它；稳定击败后自动暂停）；
- 我方选「固定」→ **强化对手**（练一个专门克制我这套的 AI，用来找自己配队的漏洞）。

**配队/加点从哪来（不导入文件）**：四个下拉直接读**网站里已保存的方案** ——
「模拟器舰队」（战斗模拟页保存的我方护航/我方被护航/敌方护航/敌方被护航）＋「配队页 · 我的配队」（每个方案里每支舰队各算一条）；
加点下拉读加点页「💾 保存方案」存的整套方案。先在那些页面保存好，回实验室点「🔄 刷新列表」。
还有一个「⚡ 一键用模拟器舰队填满四个槽位」。

**按设备调**：岛数 = 并行 Worker 数（一个岛一代约 8 场对局）。省电 1 岛 / 均衡 2~4 岛 / 火力全开 = 逻辑核数（≤16）。

## 二、你要的功能对照

| 你的要求 | 落在哪 |
|---|---|
| 调用接口 = 加点（只能重分配、不可追加）/ 旗舰 / 主舰队 / 增援 / 载机（按机库，不能直接加）/ 模块 / 超主力多模块 | 全部由项目自己的 `FleetCheck` 卡口径（和战舰配队页同一套）；加点"只能重分配"= 变异只挪等级、绝不超出原有总点数 |
| 选择 CPU 占用 / 启动数量 | 第②节：岛数滑条 + 设备预设（1~16） |
| 用户给敌方（护航/被护航/两个）→ 目标击败对方 | 第①节：敌方「固定」+ 四个下拉里选**网站里保存的**配队（模拟器舰队 / 配队页我的配队）自动带入 |
| 不给定 → 自对弈 | 两边都「进化」= 方案二A 原版（**A 控我方 2 支、B 控敌方 2 支，两个网络互打**，不是单网络打自己）|
| 直到几乎收敛停止 | 收敛判定沿用另一台设备的判据（平台 + 多岛离散 + 是否仍在爬），可勾「自动暂停」；也可手动暂停 |
| 每 5 代在浏览器里存档 / 断了继续 | IndexedDB（`lagrange_neuron`），每 5 代一份**完整快照**；重开页面勾「有本机存档就续跑」即可接上 |

| 3D 网络实时状态页 | `neuron3d.html`：节点=球（输入蓝/隐藏金/输出绿）、连接=线（青正红负、粗细=|权重|）、拖拽旋转、实时激活高亮 |
| 战报存网页 + 发给 AI 分析 | 模拟器战报弹窗新增「💾 存入战报库 / 📤 发给AI分析」；神经元页同样有；AI 有工具可读 |

| 打开第一个对话 AI 主动打招呼自我介绍 | 已做（本机第一次打开对话时，AI 自动发一条自我介绍；只发一次） |
| 对话 / 单个 skill 导出 JSON | 对话列表每条 + 手机抽屉都有「📤」；技能卡片有「导出JSON」（都是**单个**，不是全部） |
| RSI 递归自我改进落地方案 | `docs/RSI-递归自我改进-落地方案.md`（只出方案，没实现 —— 按你说的"先不动"） |

## 三、从另一台设备继续训练（把它的 1000 代接过来）

**不需要导入任何文件**——另一台设备停机时的 12 个岛已经**打包在网站里**（`data/neuron/state/`，共 2.3MB）：

1. 在实验室页第③节点 **📥 装入训练存档（网站内置）** 的下拉（列出每个岛的代数/分数/网络规模）；
2. 选「装入这个岛」或「装入全部（12 岛）」——会把该岛的【完整快照 + 行为档案 + 最近 120 代日志】写进浏览器存档；
3. 点「开始训练」（保持勾着"有本机存档就续跑"）→ 日志会出现「断点续跑：从快照第 N 代恢复」，看板的历史曲线也会接上；
4. 内置存档 = 岛 00 第 1100 代 / 岛 02、03 第 1000 代 / 岛 05 第 1050 代 …（详见下拉里的清单）；
5. 说明：E8 行为空间图（原包 9.7MB）**没有**打进内置存档，会自行重建；训练状态里"最近一次最好配队"随快照一起恢复。

## 四、诚实的状态说明（不要忽略）

1. **移植的是算法，不是训练成果**：另一台设备的 12 个岛跑了 94~1141 代，那些"成绩"没有被自动搬过来 —— 要接着跑它的成果，必须按上面第三节导入它的状态文件（内置的只有：预训练网络热启动 + 一个冠军示例）。
2. **本机（2GB 内存）跑不大**：本机已经实测跑通（1 岛、小参数），但 12 岛全开请在你那台 16 核/46G 的设备上跑。浏览器关掉就停（存档在，接着跑）。
3. **分数不是绝对强度**：网络互打的分数是"打对方"打出来的，对手变弱自己就涨 —— 跨代比较一律看 **fscore（冻结标尺）**；要判断"真的强不强"，把配队复制到战斗模拟器里和真实战报对照。
4. **收敛判定要 100 代以后才作数**（判据本身要求），之前只会显示"观察中"。
5. 「舰船库模式」用的是你在**舰船图鉴页**维护的舰船库（船 + 超主力模块 + 每艘的蓝点数）：打开后只用库里有的船/模块，加点只能重分配且不超过你填的蓝点。库里没填蓝点的船不设上限（会按原有点数重分配）。
6. 每次开始训练建议先用 **省电/均衡** 试 5~10 代看看速度，再往上加岛数。
