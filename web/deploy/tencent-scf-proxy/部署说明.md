# 腾讯云函数代理部署说明（智谱 GLM 免费 API · 国内可用）

> 背景：`*.workers.dev` 在国内网络不可达（已实测）。腾讯云函数部署在国内节点，访问快，免费额度够个人使用。
> **本目录已备好 `lagrange-glm-proxy.zip`**，控制台「上传 zip」创建，**无需在代码编辑器里粘贴**（避免剪贴板权限问题）。
> 耗时：约 8 分钟，一次性。

## 部署步骤

1. **登录腾讯云**：https://console.cloud.tencent.com/scf （个人实名即可，未实名无法创建）

2. **新建函数**：
   - 左侧 **函数服务** → **新建**
   - 创建方式：**从头开始**
   - 函数名称：`lagrange-glm-proxy`
   - 地域：`广州`（或离你近的国内地域）
   - 运行环境：**Node.js 16.13**（或更新，代码零依赖两种都支持）
   - **函数代码 → 提交方法：选「本地上传 zip 包」** → 上传本目录的 `lagrange-glm-proxy.zip`
   - 触发方式：勾选 **「HTTP 访问（Web 函数）」**（自动创建 API 网关触发器）
   - 点 **完成/部署**

3. **设置环境变量**：
   - 函数 → **函数配置**（「配置」标签）→ 环境变量 → 添加：
     - 变量名 `GLM_API_KEY`，值 = 你的智谱免费 Key
   - 保存 → 再次 **部署**（右上角"部署"按钮）

4. **拿到访问 URL**：
   - 函数 → **触发管理**（「触发方式」标签）→ 复制 **访问路径**
   - 形如 `https://service-xxxx-1250000000.gz.apigw.tencentcs.com` 或 `https://xxxx.ap-shanghai.app.tcloudbase.com`

5. **填进静态页设置**：
   - 打开 `http://192.168.1.49:3002/settings.html`
   - 「智谱 GLM 默认模型」→ 连接方式选 **Cloudflare Worker 代理**（该字段通用，填云函数地址即可）
   - 代理地址填第 4 步的 URL → **🔍 测试连接** → 成功 → **保存**

## 验证

浏览器请求 → 云函数 → 智谱。对话全功能（工具调用/质检）与直连一致，Key 藏在云函数环境变量中不暴露。

## 常见问题

- **测试连接 500 / GLM_API_KEY 未配置**：环境变量没保存成功，或改完没点部署。
- **测试连接 404 / 502**：URL 是否带了多余路径？只填云函数根地址；若 API 网关提示 CORS 问题，在 API 网关触发器配置里开启「CORS 支持」（我的代码已自带 CORS 头，一般无需）。
- **费用**：云函数免费额度每月约 40 万次调用，个人使用绰绰有余；超出后几分钱/万次。
- **智谱模型过载 429**：glm-4.7-flash 偶发过载，设置页模型可先选 `glm-4-flash`。

- `package.json`：函数包配置
- `lagrange-glm-proxy.zip`：**上传用打包文件**（index.js + package.json）
