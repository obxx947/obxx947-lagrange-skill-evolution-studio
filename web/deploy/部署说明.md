# Cloudflare Worker 部署说明（智谱 GLM 免费 API 代理）

> 目的：把智谱免费 Key 藏在服务端，静态网页（GitHub Pages / 安卓 APP）公开部署也不暴露 Key。
> 耗时：约 15 分钟，一次性。免费档每天约 10 万次请求。

## 前置准备

- 智谱免费 Key：open.bigmodel.cn 注册 → 实名认证 → 创建 API Key（`glm-4.7-flash` 等免费模型，无 `sk-` 前缀）
- Cloudflare 免费账号：https://dash.cloudflare.com

## 部署步骤

1. **登录 Cloudflare** → 左侧菜单 **Workers & Pages** → **Create**（创建）
2. 选 **Create Worker** → 名称随意（如 `lagrange-glm-proxy`）→ **Deploy**（部署）
3. 部署后点击 **Edit code**（编辑代码），**全部删除**默认代码，粘贴 `glm-proxy-worker.js` 的完整内容 → **Deploy**
4. **设置 → 变量与环境变量** → 添加变量：
   - 变量名：`GLM_API_KEY`
   - 值：你的智谱免费 Key
   - 保存
5. 顶部会显示你的 Worker 地址：`https://lagrange-glm-proxy.<你的子域>.workers.dev`

## 接入静态页

1. 打开网页版 **设置页**
2. 「智谱 GLM 默认模型」卡片 → 连接方式选 **Cloudflare Worker 代理**
3. 代理地址填：`https://lagrange-glm-proxy.<你的子域>.workers.dev`
4. 点 **🔍 测试连接** → 显示"连接成功"即完成
5. 保存配置

## 常见问题

- **测试连接报 500 / GLM_API_KEY 未配置**：第 4 步环境变量没保存成功，或未点 Deploy。
- **测试连接报 401**：智谱 Key 错误 / 未实名。去 open.bigmodel.cn 检查。
- **国内访问 workers.dev 慢或不稳定**：Workers 免费版可绑定自己的域名（需域名已在 Cloudflare），或用直连模式（Key 存本地，仅限个人/局域网）。
- **想切换回直连**：设置页连接方式改回「直连」，填智谱 Key 即可，两者随时可切。

## 验证

代理模式下，浏览器请求会转发到 `open.bigmodel.cn/api/paas/v4/chat/completions`，AI 对话全功能（工具调用/质检/流式）与直连一致。
