# 战斗机制与计算公式（按 `simulator.html` 现版本逐行整理）

> 生成于 2026-09-19，取代旧的《战斗模拟器机制与计算公式.md》。
> **本文只写代码实际在算的东西**。凡是"代码里有、但数据里没有输入"或"游戏有、代码没做"的，都在第 12 节如实标注。

---

## 1. 时间与循环

| 项 | 代码 | 说明 |
|---|---|---|
| 逻辑步长 | `dt = 0.1 × battleSpeed` | 一步 0.1 秒，倍速只改变一步跨多大 |
| 帧间隔 | `setTimeout(loop, 100 / battleSpeed)` | 1x=100ms、10x=10ms |
| 时间戳 | `bs.time += dt` | 战报里的"战斗时长" |

每帧做 4 件事：①所有存活舰开火 ②维修 ③子系统维修计时 ④判胜负。

> ⚠️ **`speed`（巡航/曲速）完全不参与战斗**，只用于图鉴显示。没有先后手、没有接敌距离。

## 2. 编队与部署

1. 四个舰队面板各自收人：我方护航/我方被护航 → `ally`；敌方护航/敌方被护航 → `enemy`。主舰队与增援**都参战**（增援不占人口）。
2. 每条舰队条目按 `count` 复制出 N 个**实例**。
3. 实例是**浅拷贝** `{...shipEntry}`。
4. 载机部署（`deployAircraft`）：按**舰队条目 uid** 分组，把该条目的载机**按数量平均分摊**到它的 N 个单位上（余数给前面的）。部署总数 = 配队页填的数量。载机标记 `position='aircraft'`、`carrierId/carrierName/carrierInstId`，并继承母舰的护航标记。
5. **母舰的「机库加成」→ 它搭载的每架载机**（`dmgBonus` 与 `hitBonus` 各加一次）。
6. 出场状态：`alive=true`、`hp = maxHp = hp × (1 + hpBonus/100)`（四舍五入）。

---

## 3. 站位与目标选择（`findTarget`）

站位只有 `前排/中排/后排`；舰载机是 `aircraft`，不参与排。

选目标按优先级：

1. **【优先打击超主力】**（仅当该船勾选）：只在战列/航母/战巡/支援里挑
2. **【直射武器】** 必须先打**敌人最靠前的那一排**（`getDirectFireTargets` 从前排→中排→后排找第一个有活人的排）
3. 在候选里按武器自带的 `targets` **攻击序列**逐条匹配，第一条匹配到就用
4. 都没匹配上 → 全体活人里随机

**候选收缩**（防全员集火同一艘）：`splitCount = max(1, round(候选数 / 2.5))`，再在 `min(候选数, splitCount)` 里随机取一个。

**类型匹配 `matchesType`**：依次比对 ①英文 type ②中文舰种名 ③舰名包含 ④反向包含 ⑤特例：`超主力舰`=superCapital、`大型舰船`=size large、`小型舰船`=size small 且非超主力、`舰载机`=size aircraft。

## 4. 武器开火周期（`processShipWeapons`）

一门武器的循环是 **首射 → （冷却 ∥ 锁定）→ 攻击批次 → 冷却…**

| 阶段 | 代码 |
|---|---|
| **首射** | `firstShot=true` → 冷却/锁定直接清零，第一轮立刻打 |
| **冷却与锁定并行** | 两者每帧都 `-= dt`；**都 ≤ 0 才能开火** |
| **锁定** | `lockRemaining = lockTime × (1 - 锁定减免/100)` |
| **同目标不重复锁定** | 续射时 `lockRemaining` 已是 0，直接打 |
| **目标中途死亡** | **带着剩余发数/批数**重新锁敌，**保留冷却进度**（不重置冷却） |
| **攻击批次** | `ammo × attacks`：如 `3×2` = 2 个批次、每批 3 发；批间隔 = `atkDuration / 总批数`；每批实发 `ceil(剩余发数/剩余批数)` |
| **atkDuration=0** | 一次把全部发数瞬发 |
| **一轮打完** | `cooldownRemaining = cooldown × (1 - 冷却减免/100)`；**刻意不清 currentTarget**（下轮续射） |
| **子系统被毁** | 该模块的所有武器**停火**（`modSys.destroyed → return`） |

## 5. 命中判定（`executeShot` 第一段）

```
基础命中区间 = 该武器 targets 里匹配到目标类型的那一条的 [hitMin, hitMax]   // 默认 50~70
命中率 = (hitMin + rand × (hitMax − hitMin)) / 100
命中率 ×= (1 + (命中加成 + 武器.lockEfficiency − 目标.evasion) / 100)      // ← 命中加成为加点/强化
命中率 = clamp(命中率, 0.01, 0.99)
若 轰炸模式 且 (攻击方或目标 是舰载机)：
    命中率 = clamp(命中率 + (轰炸距离 − 15) × 0.02, 0.01, 0.99)          // 每偏离 15 吉米 ±2%
若 rand > 命中率 → 未命中（5% 概率记日志）
```

> 除轰炸模式的距离滑块外，**没有距离/速度影响**。

## 6. 拦截判定

**拦截率的来源**：写在**模块**上，开战实例化时由 `applyIntercept()` 合成到舰船级：

```
舰船级拦截率 = 1 − (1 − 舰船基础值) × Π(1 − 各所装模块拦截率)
舰船级拦截类型 = 覆盖范围最宽的那个（global > sameRow > self）
```
`createShipInstance()` 与 `switchModuleVariant()` 都会调它 → **换模块会立刻改变拦截率**。

**判定**：
```
noIntercept = (1 − 目标.interceptRate/100)
              × Π( 1 − r/100 )   对每个存活敌舰 r=interceptRate：
                    interceptType==='global'   → 一律累乘
                    interceptType==='sameRow'  → 仅同排时累乘
                    interceptType==='self'     → 不进这个循环（只由上面那一项代表"自身拦截"）
拦截概率 = 1 − noIntercept
若 rand < 拦截概率 → 攻击被拦下（10% 概率记日志）
```
**只有投射武器会被拦截**；`weaponType==='direct'` 的直射武器与 `cannotBeIntercepted` 的武器跳过这段。

## 7. 伤害计算（核心）

```js
tuningCoeff = 1.3                                  // 基础调校系数，固定 +30%

dmg = 武器.singleDmg × (1 + 逐武器强化.单发加成/100)

── 能量伤害 (dmgType==='energy') ──
若 (目标.energyArmor + 能量抗性加成) ≥ 100  → 伤害 0，直接跳过
dmg = dmg × (1 − (energyArmor + 能量抗性加成)/100) × 1.3

── 物理伤害 (其它) ──
破防后 = dmg − (目标.physicalArmor + 物理抵抗加成)      // 护甲是"减法"
若 破防后 > 0 → dmg = 破防后 × 1.3
否则          → dmg = dmg × 0.1 × 1.3                  // 不破防：10% 保底伤害

── 暴击 ──
暴击率 = (武器有 crit 标记 ? 0.15 : 0) + 逐武器强化.暴击率/100
暴击伤害 = 1.5 + 逐武器强化.暴击伤害/100
rand < 暴击率 → dmg ×= 暴击伤害（10% 概率记日志）

── 乘区 ──
dmg ×= (1 + 攻击方.dmgBonus/100)                       // 舰船级伤害加成
若 受伤方旗舰是「普鲁图斯之盾(大盾)」且其指挥系统未毁 → dmg ×= 0.7   // 减伤 30%
dmg = max(0, round(dmg))

── 护航保护 ──
若 目标是被护航舰 且 本方护航舰还有存活 → dmg = 0      // 被护航舰在护航存活时"免疫"
```

**六条要点**：
1. **物理护甲是减法**，**能量护甲是乘法**，两者规则不同
2. **不破防只吃 10% 伤害**，所以小口径打大船基本无效
3. **调校系数 1.3 是全局乘数**
4. **大盾旗舰全场减伤 30%**（只要它在且指挥系统完好）
5. **被护航舰在护航存活时打不动** —— 所以必须先清护航
6. **加点/强化从三个入口进来**：武器单发（逐武器）、舰船伤害加成（乘区）、暴击（概率与倍率）

## 8. 系统破坏（System Damage）

```
① 定向破坏：武器有 subSystemTargets 时
   效率 high=60% / medium=40% / low=20% 概率命中指定系统
   成功 → 该系统 destroyed，且 系统伤害 = 武器.singleDmg × 1.5 × 1.3
         然后 sysHpPenalty()：
           · 若被毁的是【动力系统(engine)】→ 目标额外扣 5% 最大结构值，并记日志
           · 其它系统被毁 → 只记日志（不扣血）
② 随机破坏：任何一次命中都有 10% 概率随机毁掉一个未毁、非永久毁坏的系统，同样走 sysHpPenalty() 扣血规则
```
被毁模块的**所有武器停火**，并可维修。

**子系统维修**：摧毁后 **25 秒**自动修复一次；可修复次数 = 指挥系统 3 次 / 声明 `selfRepair` 的 2 次 / 其它 0 次（0 次=永久毁坏）。

---

## 9. 维修（`processRepairs`）

```
每秒维修量 = (武器.dpm.repair / 60)
             × (1 + min(目标物理护甲 × 0.25, 150) / 100)     // 一点物理护甲=0.25%受维修加成，上限 +150%
             × (1 + 维修方.repairBonus / 100)                // ← 加点/强化的「维修量加成」
```
- 目标按武器 `targets` 的**维修优先级**挑，同优先级里**选血量百分比最低的**
- 找不到符合条件的目标 → 回落为自己/最近友军（自修）
- 只有带 `dpm.repair` 的"武器"才维修（维修模块被当作武器建模）

## 10. 加点（蓝图）如何进入战斗

**数据流**：加点页 `addpoint.html` → `localStorage['lagrange_addpoint']`
→ 模拟器「⬆ 从加点导入」→ 写进舰队条目 → `createShipInstance()` 读条目生成实例。

存档结构：`{ [官方编号]: { lv:{节点id:等级}, manual:{…} } }`

**A 组 10 项（引擎已支持）**：结构值 / 物理抵抗 / 能量抗性 / 伤害加成 / 暴击 / 锁定减免 / 冷却减免 / 单发伤害 / 闪避 / 拦截率
- 自动汇总：**取 `perLevel[当前等级]`**（如冷却 5 级＝15%），**不是各级累加**
- 面板上还可**手动追加**，最终值 = 自动 + 手填

**B 组 4 项（引擎原本没有，靠手填）**：攻城伤害 / 维修量加成 / 命中加成 / 机库加成

**各自落到引擎的哪里**：

| 加成 | 落点 |
|---|---|
| 结构值 | `maxHp = hp × (1 + hpBonus/100)` |
| 物理抵抗 | 加到物理护甲（减法里） |
| 能量抗性 | 能量伤害的减伤百分比 |
| 伤害加成 | 伤害乘区 `× (1 + dmgBonus/100)` |
| 单发伤害 | 逐武器 `dmg = singleDmg × (1 + …)` |
| 暴击 | 逐武器暴击率与暴击倍率 |
| 锁定减免 | `lockRemaining = lockTime × (1 − …)` |
| 冷却减免 | `cooldownRemaining = cooldown × (1 − …)` |
| 闪避 | 命中率里的 `− 目标.evasion` |
| 拦截率 | `applyIntercept()` 合成到舰船级，参与第 6 节 |
| 命中加成 | 命中率里的 `+ 攻击方.hitBonus` |
| 维修量加成 | 维修公式第三项 |
| 机库加成 | 母舰 → 其载机的 `dmgBonus` 与 `hitBonus` |
| 攻城伤害 | **仅记录**（本模拟器没有建筑目标） |

**多参数节点**（说明里有 ≥2 个数值位）**不硬算**，页面与 AI 输出都如实报"未计入"。

## 11. 胜负与战报

- 一方 `存活数 == 0` → 结束，记"我方/敌方胜利"
- 战报统计：每方"总伤害" = 对方 `Σ(maxHp − 当前hp)`、存活数、战斗时长；逐舰给出存活%/损失 HP

## 12. ⚠️ 已知缺口 / 与游戏不一致的地方（如实列出）

### 12.1 加点归类目前有三个错误（**会高估**）
| 问题 | 影响面 |
|---|---|
| **作用域错误**：2364 个"系统内"节点（只该影响该系统武器）被**全舰船汇总**后套到所有武器 | 严重高估，尤其多系统舰船 |
| **武器类型丢失**：1646 个节点写明武器类型（火炮/导弹/鱼雷/离子炮/脉冲炮/轨道炮/防空武器），全部并成一个"单发伤害" | 火炮的加成会加到导弹上 |
| **主动技能被当永久加成**：138 个战术技能有"持续/冷却/触发条件"（如"战斗开始后 45 秒内闪避+35%"），被算成永久属性 | 高估 |

**另**：51 个 type=2 **指挥策略**（战略打击III/切入作战/防空网络/机动撤退…）是**带条件的战场行为**，没有对应字段，目前只从里面抽了个数字——**本质上是错的**。

### 12.2 引擎未实现的机制
| 缺口 | 说明 |
|---|---|
| **闪避** | 字段已就绪，但**全库只有 0 条舰船自带闪避数据**（只能靠加点/手填） |
| **防空三态** | 反击/区域/主动防空区分未实现；数据里有 `antiAirType`(136 门) 但代码不读 |
| **系统独立血量** | 现在是"概率直接摧毁"，不是累积伤害到系统血量归零 |
| **打系统的武器打结构 ×0.8 系数** | 系数不在数据里 |
| **两大战机模式 + 飞行时间** | 数据有 `flightMode` 但不读；无去程/返程时间 |
| **速度/距离** | 完全不参与交战（无先后手、无接敌距离） |
| **反拦截** | 无数据 |
| **策略系数** | 数据有 `strategies`（6 门）但不读 |

### 12.3 数据本身的缺口
- **196 艘里只有 5 艘有拦截率**；**19 艘没有任何加点数据**
- **旗舰技能只实现了大盾**一种
- `leihuo-hui`/`FSV830`/`tianqiang-*` 连 `hp` 都没有（引擎用兜底值，别放进校准用编队）

### 12.4 结论：真正决定胜负的是
`singleDmg × ammo×attacks ÷ 周期`（火力密度）、`hitMin/hitMax`（命中）、`physicalArmor`（物理减法）、`energyArmor`（能量乘法）、`hp`、`targets` 类型序列，加上：
**直射先清前排**、**大盾旗舰减伤 30%**、**护航存活则被护航舰免疫**、**载机数量**。

（本文末尾的缺口清单**不影响第 1~11 节的正确性**——那几节描述的就是代码当前的真实行为。）
