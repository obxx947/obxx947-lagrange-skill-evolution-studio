## 一、本次做完的两件事

### 1. 拦截机制从「空转」变为「真的会拦」

之前：`interceptRate` 全库 0 条 → `executeShot` 里拦截概率恒为 0 → **永远不会拦截**。
现在：把资料里**明确写出数值**的拦截率落库，并让引擎按「所装模块」合成到舰船级。

| 舰船 | 来源模块 | 单舰拦截率 | 类型 | 出处 |
|---|---|---|---|---|
| 雷火之星-综合武库舰 | B2 范围拦截系统 | **27%** | 同排 | `数据/战斗机制.md` §五.3 + `舰船资料129.md`（**双源吻合**） |
| 光锥级-区域防空巡洋舰 | M1 苔原拦截无人机系统 | **23%** | 同排 | `数据/战斗机制.md` §五.2 / §五.3 |
| 普鲁图斯之盾级-防护战列巡洋舰 | B3 反导拦截系统 | **12.8%**（反推） | 同排 | `舰船资料127.md` |
| 太阳鲸-武装战略航空母舰 | C3 防空导弹平台 | **5%** | 同排 | `舰船资料123.md` |
| CV3000级-快速航空母舰 | A2 防空导弹平台 | **12%** | ⚠️ 资料未写范围 | `舰船资料120.md` |

**三个数值都能自验，不是拍脑袋**：
- 雷火之星 B2：资料写「同排拦截 27%，编队 3 艘 61%」→ `1-(1-0.27)^3 = 61.1%` ✓
- 太阳鲸 C3：资料写「同排拦截 5%，编队 5 艘约 23%」→ `1-(1-0.05)^5 = 22.6%` ✓
- 大盾 B3：资料只给编队数列（2 艘 24% / 3 艘 34% / 4 艘 42% / 5 艘 50% / 6 艘 56%）——
  用文档给的累乘公式 `1-(1-x)^n` 反解，n=2..6 五个解落在 **12.73%~12.94%**，取 **12.8%** ✓

**光追级 = 光锥级**：机制文档写「光追级区域防空巡洋舰」，库里没有「光追级」，
但有「光锥级-区域防空巡洋舰」——同音异写，已按它落库。

### 2. 狩猎者级-战术载机巡洋舰（`hunter-B`）补上武器

它此前是「有资料、库里却 0 武器」的**唯一一艘真缺口**（其余所谓缺武器的船，
要么资料根本不存在，要么其实早已有武器）。

`舰船资料65.md` 给的是「防御火炮系统 = 4× CG-1105B型通用火炮 / 单发 20 / 实弹 / 直射 /
锁定 3 秒 / 冷却 4 秒 / 优先目标舰载机 / 火力总览 对舰 600、防空 900、攻城 60」。
新增为 `modules.M3`（与同型 `hunter-A`/`hunter-C` 的 M3 槽位对齐）。

> ⚠️ **一处需要你拍板的取舍**：资料同时写了「冷却 4 秒」和「对舰 600/分」，
> 但按引擎模型 `4 发 × 20 单发 ÷ 4 秒 = 1200/分`，正好是面板值的 **2 倍**——两个数互相矛盾。
> 我选择**让引擎输出等于面板 DPM**（`cooldown = 20×4×60÷600 = 8` 秒），理由是本库所有武器
> 都是按「引擎输出 ≈ 面板 DPM」校准的（上轮实测误差 1~3%），不能让 hunter-B 变成 2 倍特例。
> 资料原写的 4 秒/3 秒没丢，存在 `_statedCooldown` / `_statedLockTime` 字段里；
> **若你认为资料明写的 4 秒为准，把 `cooldown` 改回 4 即可**（该舰输出会翻倍）。

## 二、引擎改动（`simulator.html`）

新增 `applyIntercept(shipInstance)`，在**开战实例化**（`createShipInstance`）
和**切换模块**（`switchModuleVariant`）两处调用：

```
舰船级拦截率 = 1 - (1-舰船基础值) × Π(1-各模块拦截率)      // 同舰多个来源累乘
拦截类型 = 覆盖范围最宽的那个（global > sameRow > self）
```

- 依据就是机制文档 §五的 `1-(1-x)^n×(1-y)^m`，`executeShot` 里原有的跨舰累乘逻辑**一行没动**。
- 之所以做成「模块 → 舰船」合成：资料里的拦截值**挂在模块上**（大盾 B3、雷火之星 B2、太阳鲸 C3、CV3000 A2），
  直接写舰船级会导致「没装该模块的船也能拦」。
- 因此**换模块会真的改变拦截率**（雷火之星 B1↔B2 已实测：0% ↔ 27%）。

### 我**没有**采纳的数据，及原因
`A资料`（玩家攻略/视频转写）里还有几个拦截率说法，但与权威《舰船资料》**互相冲突**，故未入库：

| A资料说法 | 冲突点 |
|---|---|
| 「普鲁图斯之盾 B3 **单艘 24%**，5 艘 50%，6 艘 56%」 | 与《舰船资料127》的编队数列矛盾（资料 127 是「**2 艘** 24%」）→ 以资料 127 为准（12.8%） |
| 「拦截盾（战巡）拦截率 12%」/「拦截矛 11%」/「A2CV 12%」 | 只是玩家讨论里的约数，未指明是哪艘船的哪个模块，无法归属 |
| 「光锥防空（光防）拦截率 24%」 | 与机制文档明写的 **23%** 冲突 → 以机制文档为准 |

**如果你要补全，请按这个格式给**（有一艘补一艘，我不会替没数据的船编数值）：
```
舰名 | 拦截率(%) | 拦截范围(自身/同排/全域) | 来源模块(可留空)
```
闪避同理：`舰名 | 闪避率(%)`。
