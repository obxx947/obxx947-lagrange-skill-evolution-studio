## 4. 战斗引擎现状（`simulator.html`）

### 4.1 已实现且与用户《战斗机制》文档**一致**
- 调校系数 **1.3**；物理=**减法**、能量=**乘法**；**不破防只吃 10%**
- 能量抗性 ≥100% → 0 伤害
- 命中 = `(hitMin + rand×(hitMax−hitMin))/100 × (1+(lockEfficiency−evasion)/100)`，clamp 0.01~0.99
- **锁定与冷却并行**；**同目标不重复锁定**；目标死亡带剩余发数重新锁敌（不重置冷却）
- **直射武器不会被拦截**（投射才拦）；拦截按 `Π(1−r/100)` 累乘（= 文档的 `1−(1−x)^n(1−y)^m`）
- 系统破坏效率 **高60%/中40%/低20%**、系统伤害 `单发×1.5×1.3`、25 秒修复、各系统维修次数（指挥3/自修2/其它0）
- **只有动力系统**被破坏才扣 5% 最大结构
- **母舰被摧毁 → 其舰载机一起被摧毁**（靠实例级 `carrierInstId`）
- 大盾旗舰全场 ×0.7；**被护航舰在护航存活时伤害=0**；分伤候选收缩 `max(1, round(n/2.5))`
- 轰炸模式距离：每偏离 15 吉米 ±2% 命中
- 结构值可按强化 +%（`maxHp = hp×(1+hpBonus/100)`）

## 5. 本次已完成的"模块武器补齐"（**可复用的方法，务必先看**）

**问题**：超主力武器存在**模块变体**里，而 233 个变体**全部没有 `weapons`** → 17 艘超主力在战斗里**零输出**，表现为"打上万秒、巨大劣势"。

**数据来源**：`data/knowledge/舰船资料N.md`（187 份），每份含每个模块变体的：
`#### M1 舰首轨道炮系统（原装）` → `- 2×BG-1850重型火炮` → `- 每分钟伤害：9400，伤害类型：实弹，优先目标：大型舰船，单发伤害：950，特性：反击防空`

**提取规则（已实现并验证）**：
1. **周期推导**：`cooldown = 单发伤害 × 数量 × 60 ÷ 每分钟伤害`（由用户文档的"面板分钟伤害"公式反推）→ **实测每条武器输出与面板 DPM 误差仅 1~3%** ✅
2. `优先目标` → `types`（大型舰船/小型舰船/舰载机）
3. 命中率：资料有 `##### 攻击序列+命中率` 表就用表；无表按优先目标推断（**大 70~100 / 小 50~70 / 舰载机 10~20**，依据文档"舰载防空15%、机载60%"）
4. `伤害类型` 实弹→`physical`、能量→`energy`；**直射/投射按武器名推断**（导弹/鱼雷/无人机→`projectile`，其余→`direct`）
5. `特性`：反击防空→`antiAirType:'counter'`、区域防空→`'area'`、暴击→`crit:true`
6. 每门武器写 `_src` 标明来源资料文件，便于复核

**结果**：填充 **92 个变体 / 126 门武器**；有武器的舰船 ~90 → **183 艘**。
**两种必须兼容的行格式**（我踩过坑）：
- `- 2×BG-1850重型火炮`（带数量×）
- `- 12联装反舰导弹系统`（**无 × 前缀**，数量在名字里）
- 只给「每分钟伤害」不给「单发伤害」的 → 按 DPM 折算（1发/秒）兜底
- 解析必须"武器名行 → 紧邻字段行"配对，**不能只匹配 `N×`**

**未覆盖（仍缺武器的船）**：`leihuo-hui`(雷火之辉)、`FSV830`、`tianqiang-tactical`、`tianqiang-heavy`、`yueshenxing-A`(阅神星Ⅰ)、`yuhai-B`、`ruby-B`、`wildfire`、`ship-ato21c`、`peidao`、`niuwa`、`haishi`、`linxiao`、`shalong`、`andersen`、`sc002`、`lizhi-te`

### P0 —— ~~让拦截/闪避机制活过来~~ → **拦截已做（2026-09-18），闪避仍缺**
拦截部分**已完成**，见《拦截机制落地报告.md》。落库位置已改为**模块级**：
```jsonc
// 模块（含 moduleGroup 的所选变体）上写：
"interceptRate": 27,            // 单舰拦截率 %（资料例：雷火之星-B2=27%、光锥级防空型=23%）
"interceptType": "sameRow",     // global=全域 / sameRow=同排 / self=自身

```
引擎在 `createShipInstance()` / `switchModuleVariant()` 调 `applyIntercept()`，

### P3 —— 防空三态
