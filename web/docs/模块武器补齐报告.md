# 模块武器补齐报告（知识库《舰船资料》→ 舰船库）

> 起因：用户报"游戏里 3-4 分钟碾压结束的配队，在模拟器里打了上万秒还呈现巨大劣势"

---

## 一、根因（两层，都已修）

### 1. 超主力在模拟器里【完全零输出】← 这是主因
- 超主力的武器存在**模块变体**（`moduleGroup.variants`）里
- 而 `ship_database.json` 的 **233 个模块变体，全部没有 `weapons` 字段**
- 结果：大盾/大矛/大帝/太阳鲸/天枢/天权/永恒风暴/CV3000/安东塔斯/雷火之星… 共 **17 艘超主力在战斗里一门炮都没有**
- 所以你以超主力为主的队伍 **0 伤害**，而对面那几艘小船（游骑兵/康纳马拉等是"固定模块"、本来就有武器）能打你
  → 表现为「**巨大劣势**」且永远打不完（实测：**20000 秒、双方 0 伤害**）

### 2. 9 艘舰的结构值是占位值 50000（比真实值高 4.5~10 倍）
会让这 9 艘在战斗里异常耐打（尤其 6 架战机）。

---

## 二、数据来源与提取方法

**来源**：知识库 `data/knowledge/舰船资料1~187.md`（每艘一份，共 187 份）
每份含每个模块变体的：武器名 / 数量 / **每分钟伤害** / 伤害类型(实弹·能量) / 优先目标 / **单发伤害** / 特性（暴击、反击防空、区域防空…）

**提取结果：填充 92 个模块变体、共 126 门武器**

| 处理项 | 做法 |
|---|---|
| 开火周期 | 按你《战斗机制》文档的「面板分钟伤害」公式反推：**冷却 = 单发 × 数量 × 60 ÷ 每分钟伤害** |
| 目标类型 | 优先目标 → `大型舰船 / 小型舰船 / 舰载机`（代码的 matchesType 直接支持中文） |
| 命中率 | 资料有表用表；无表按优先目标推断（大 70~100 / 小 50~70 / 舰载机 10~20，依据文档「舰载防空 15%、机载 60%」+ 库内既有惯例） |
| 直射/投射 | 按武器名推断（导弹/鱼雷/无人机 → 投射，其余 → 直射） |
| 特性 | 反击防空 → `antiAirType:'counter'`、区域防空 → `'area'`、暴击 → `crit:true` |
| 溯源 | 每门武器带 `_src` 字段标明来自哪份资料，便于复核 |

**未填充的 128 个变体**经逐一核对，都是 `x0 无模块` 或 **装甲/能源/侦察/损毁管理** 等本来就没有武器的槽（例如大帝 C1附加能源 / C2舰载机 / C3侦察无人机 / D2重点防护 / D3损管）。
唯一例外：`永恒风暴 D1/D2` 资料里写的是「能量反大直射离子炮（**无细分数值**）」——资料自己没给数值。

## 三、效果对比（镜像战：双方各 4 大盾 + 4 大矛 + 4 大帝，各 2,104,196 结构）

| | 修复前 | 修复后 |
|---|---|---|
| 有武器的舰船 | 约 90 艘 | **183 艘** |
| 12v12 结果 | **20000 秒打不完，双方 0 伤害** | **756~967 秒结束，一方全灭** |
| 大矛武器数 | 0 | **5 门** |
| 逐武器输出 vs 资料面板 DPM | — | **误差 1~3%** ✅ |
| 单边偏袒 | — | 镜像战 6 次：**我方胜 3 / 敌方胜 3**，无偏袒 ✅ |

> 镜像战 12~16 分钟属于正常（两支完全相同的队伍互相消耗）；你说的"碾压配队 3-4 分钟"是强弱悬殊的场景，那种会快得多。
