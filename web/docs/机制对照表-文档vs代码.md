## 二、攻击循环（本次最大的一处修正）

| 文档条目 | 代码 | 结论 |
|---|---|---|
| **锁定与冷却并行**（锁定完成冷却未完→继续冷却；反之继续锁定） | 原：**串行**（先冷却完→再锁定→才开火） | 🔧**已修**（同帧并行递减） |
| **目标已锁定过 → 无需再次锁定** | 原：每轮打完清空目标 → 每轮都重新锁定 | 🔧**已修**（保留目标续射） |
| 开战第一轮攻击不需要冷却 | `firstShot` 清零 | ✅ |
| 攻击持续时间内**均匀分批次**（如小米 3×4：16 秒内 4 次、每次 3 发） | `batchInterval = atkDuration/总批数`；每批 `ceil(剩余发数/剩余批数)` | ✅ |
| 攻击持续=0 → 一次打完 | 瞬发分支 | ✅ |
| **目标被击毁→不进入冷却，带剩余攻击重新锁敌，打光后清空弹夹再进入冷却** | 保留冷却进度、目标死亡才重锁、剩余发数/批数带走 | ✅ |
| 一轮攻击时间 = 锁定 + 冷却（用于秒均伤模型） | 并行后稳态周期 = **max(锁定, 冷却)** | ✅（与"并行"一致） |

**实测（冷却10s + 锁定6s 的炮）**：开火时刻 `6.1 / 16.2 / 26.3 / 36.4…`，**间隔 10.1s**（= 冷却）。
修正前是串行 16s —— 这也是为什么之前 DPS 偏低、雷火这类长锁定舰吃亏。

## 四、伤害计算（与文档例题逐项验算）

| 文档公式/例题 | 代码 | 结论 |
|---|---|---|
| 调校系数 **1.3**（阋神星重炮 (300+60)×1.3−140=328） | `tuningCoeff = 1.3` | ✅ |
| 实弹结构伤害 =(基础+科技+策略)×(1+调校) − 对方护甲 | `(dmg − physArmor) × 1.3` | ✅ |
| 能量结构伤害 =(基础+科技+策略−基础×护甲%)×(1+调校) | `dmg × (1−energyArmor%) × 1.3`（数学等价） | ✅ |
| 能量抗性 ≥100% → 无法造成伤害 | 直接 return | ✅ |
| 不破防：**(基础+科技+策略)/10 ×(1+调校)** | `dmg × 0.1 × 1.3` | ✅ |
| 命中 = 基础命中 ×(1+命中加成−敌方闪避) | 同式 | ✅ |
| 最终冷却 = 基础冷却 ×(1−冷却加成) | 同式 | ✅ |
| 锁定时间 = 基础锁定 ×(1−锁定减少+敌方锁定延长) | 同式（敌方延长无数据） | ✅ |
| 暴击作用于**最终单发伤害**（不是初始伤害） | `dmg *= critMult` 在护甲之后 | ✅ |
| 舰船武器系统伤害 ×**1.5** ×(1+调校) | `singleDmg × 1.5 × 1.3` | ✅ |
| 系统效率：低 20% / 中 40% / 高 60% | `{high:0.6, medium:0.4, low:0.2}` | ✅ |
| 暴击伤害 = 系统伤害 ×(1+暴击系数×系统系数) | 未单独建模（走通用暴击） | ⚠️ |
| 策略系数（乘算/加算） | 数据有 `strategies`（6 门武器）但代码不读 | ⚠️📉 |
| 科技点增加伤害 / 载具加成 | 无对应数据（可由"强化"部分替代） | ⚠️📉 |
| **面板分钟伤害** =（单发−抵抗+强化）×安装数×轮次×每次×60÷(持续+冷却) | 页面 DPM 直接用数据里的预计算 `dpm` 字段，未按此式重算 | ⚠️ |
