# A资料327

## 场景 / 对手
第二阶段护航副队从1.0到2.0版本更新，针对玩家对战（PVP）环境，讨论舰队配置优化

## 舰队例子
- 航母5台+战巡3台（1.0版本）（旧配置）【航母生存优势好，但战巡数量少，盾位不足】
- 航母3台+战巡5台（2.0版本），其中战巡含4台矛+1台盾（胜）【增加挡刀位，盾输出高，不亏人口】
- 增援位：2台CV3000换成2台矛（胜）【有效挡刀位不减，CV3000的B2模块有70所，M1无70所】
- 列兵从5台减至3台，海狮追随者放在CV3000上，增加古神星和雷里亚特C（胜）【奶量更精准，古神星受保护，但后期优化掉】
- 列兵从3台增至5台，减少古神星，增加列维九号（胜）【增加物理伤害和挡刀艇位，列维九号有往复特性】
- 加入050和赤瑶（反大船），替换002等反小船（胜）【与队伍反大伤害契合，避免脱节】
- 挡刀艇全面换装盘古舰船（如天枪），替换011、星云弹炮、002（胜）【天枪有往复特性，能脱锁，扛伤好，结算伤害高】

## 实战结果
副队从1.0到2.0版本，多场实战测试，整体胜率提升，关键改进包括增加挡刀位、优化奶船、提升物理伤害和反大能力，损失减少

## 结论思路
- 航母生存优于战巡，但战巡数量增加可提升盾位和输出
- 盾（如M3、C3）在副队中输出高，适合带多，但耗点数需权衡
- 增援位换矛不减少有效挡刀位，因CV3000的B2模块有70所
- 奶船（如古神星）在无天书时亏人口，应减少，优先保证战斗力
- 列兵数量增加可提供更多挡刀艇位，列维九号增加物理伤害
- 队伍应统一反大伤害，避免反小船船型脱节
- 天枪等往复护航艇适合副队，能脱锁扛伤，结算伤害更高
- 主队和副队应都能输出，向同一方向优化

## 适用限制
- 适用于有2台以上超主力的玩家
- 需要特定模块（如CV3000的B2模块）和舰船（如矛、盾、天枪）
- 无天书时避免带过多奶船
- 不适合打野怪，专为PVP设计
- 需要主队配合，如C2太阳镜腾出对舰飞机人口
