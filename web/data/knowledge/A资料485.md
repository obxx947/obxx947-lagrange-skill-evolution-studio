# A资料485 · 大剑模块拆析与配队

> 场景：主队/护航战斗，配合大帝

## 结论
- 大剑自带模块，平民给点就能用
- 大剑建议放主队，不要放副队
- M1实际主要给护航艇主武器增伤
- M2给同排巡洋舰主武器增伤，需把泡泡龙等调到同排
- M3是大剑核心，让大帝能彻底发挥
- A1战斗开始给安东尼奥公司舰船主武器增伤，配合大帝
- A1策略按战斗序列优先打敌方防空能力最高的舰船，通常先打光锥
- 想玩大帝就选M3配A1
- A2按战斗序列打结构值较低的舰船，可配合大帝暴击
- A3按战斗序列打物理抵挡最高的舰船，可针对前排矛或盾
- B模块适合大后期放副队，前期不推荐
- B3脉冲炮命中后削弱敌方护甲和能量抗性，最多叠加20层，共减100点
- 13鱼打正面比11鱼强，11鱼打正面不如13鱼
- D1防空输出太低，放副队不现实
- D2矿车投射系统伤害一般，不推荐
- 白板大剑优先把点给A1
- B3是核心，大剑一定要带主队
- 有M3时优先用M3配A1，先打掉敌方防空
- 一个带M3的大剑能管三个大帝，两个大剑管六个大帝
- 大剑是氪佬和平民的又一个分水岭

## 配队与模块
- 大剑自带M1和A1模块
- M2配合巡洋舰，需把泡泡龙调到同排
- M3配A1，优先打敌方防空
- A2可配合大帝，大帝AE模块对结构值低于50%的目标造成100%暴击
- A3配合大帝M3站位，可带M2
- B2导弹发射系统：实弹伤害，单发650，锁定时间低，全拉输出
- B3脉冲炮：命中后持续30秒，降低抵抗伤害5%，最多叠加20层，共减100点护甲和能量抗性
- 13鱼打正面推荐玩C2，11鱼玩CC模块，可带可不带
- D2矿车投射系统：能量武器伤害，单发加20%后约360，破不了大矛的甲

## 数值与数据
- B2导弹单发伤害650
- B3脉冲炮持续时间30秒，每层降低抵抗伤害5%，最多20层，共减100点
- D1防空导弹平台单发伤害30
- D2矿车投射系统单发伤害约300，加点后约360
- 敌方防空能力较高的舰船指挥值约420或400
