# A资料466

## 场景 / 对手
针对开阳和瑶光，推荐反小神器rb7突防护航艇，实弹反小，无视能量护盾，环境为当前版本瑶光强势

## 舰队例子
- rb7突防护航艇（sp型号，实弹伤害，优先攻击小型舰船，白板单发300，加点后375）（胜）【实战中4分44秒打出36.7万伤害，对瑶光和开阳造成24万伤害，无视能量护盾】
- 星脉（能量反小）（胜）【对比中打出40万伤害，但受瑶光影响伤害减半】
- 八百（能量反小）（胜）【对比中打出30万伤害，但受瑶光影响伤害减半】

## 实战结果
在对面有开阳和瑶光的情况下，rb7突防型号打出36.7万伤害，对瑶光和开阳造成24万伤害，星脉40万，八百30万，rb7反小效率高

## 结论思路
- 瑶光能量护盾导致能量直射武器伤害减半，需要实弹反小
- rb7突防护航艇是实弹伤害，优先攻击小型舰船，可克制瑶光和开阳
- rb7单发伤害高（加点后375），效率优于011火炮和虚灵126
- 投射武器虽可被拦截，但打小船时站位靠前/后，防空锥子中排拦截不到
- 获取方式：节点混合星域挖碎片或网络交易，8碎片合成

## 适用限制
- 适用于敌方有开阳和瑶光等小型舰船的场景
- 不适用于敌方有强力拦截防空锥子的情况
- 获取难度高，碎片6-8难买
