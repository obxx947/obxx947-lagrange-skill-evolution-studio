# A资料455

## 场景 / 对手
大环境不同，使用开阳、瑶光等小船队，人口紧张，讨论光防是否必要

## 舰队例子
- 光防（光锥）巡洋舰，含拦截无人机系统和矿车投石矩阵（胜）【能拦截鱼雷导弹，打中排，克制重卡、开阳、大地等】
- 战巡模块（如大盾C2、矛C2/C3、雷火B2）（胜）【拦截效果高，但模块难抽，点数要求高】
- 小船拦截（如西神星AC型号）（负）【拦截效率低，实际拦截率感人，不推荐】

## 实战结果
无具体战报，讨论光防在实战中的必要性，强调无模块时用光防

## 结论思路
- 光防是萌新梦寐以求的巡洋舰，能拦截鱼雷导弹，打中排
- 大环境用开阳、瑶光等小船队，人口紧张，但光防仍建议带
- 战巡模块（如大盾C2、矛C2/C3、雷火B2）拦截效果好，但难抽，点数要求高
- 账号水平不高时，光防是拦截的重要选择
- 光防克制重卡、开阳、大地等导弹鱼雷船，拦截后基本无输出
- 光防坦度不高，但性价比够用，没有战巡模块就老老实实用光防
- 小船拦截（如西神星AC）效率低，不推荐

## 适用限制
- 适用于账号水平不高、缺乏战巡模块和点数的玩家
- 光防坦度不高，不适合高战局或需要高坦度的场景
- 小船拦截效率低，不建议依赖
- 有战巡模块（如大盾、矛、雷火）时，可替代光防
