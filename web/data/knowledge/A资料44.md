# A资料44

## 场景 / 对手
当前版本战巡选择，拦截盛行、奶盾当道，前排小船克制直射、大盾减伤，输出环境恶劣

## 舰队例子
- 风暴（M2模块）（胜）【免疫拦截，投射打击后方大型目标，目标选择涵盖航母战巡巡洋，分散奶量，满改后具备拦截和防空能力】
- 大地（白板M1A1，点满A1策略）（胜（低端局）/负（高端局））【白板输出爆炸，一分钟十万伤害，但被拦截克制输出下降一半多，人口性价比低】
- 雷火（M1/M2/M3模块，满改）（负（当前环境））【输出模块多但被拦截和小船限制，服役限制3个，造价高，适合氪佬补充位】
- 大剑（M1/M2/M3/A1/A2/A3模块）（未知（缺乏实战数据））【buff船，提升特定飞机或舰船输出，自身输出一般，依赖舰队质量，服役限制3个】

## 实战结果
风暴排名第一，大地第二，雷火第三，大剑第四；风暴免疫拦截能扛能打，大地低端局战神高端局吉祥物，雷火氪佬补充位，大剑纸面强但缺数据

## 结论思路
- 风暴M2免疫拦截，能打击后方大型目标，分散奶量，培养难度低，满改后能扛能打，排名第一
- 大地白板输出爆炸，但被拦截克制，输出下降一半多，人口性价比低，适合低端局或打NPC
- 雷火输出模块多但当前环境不契合，造价高服役限制3个，只能作为氪佬输出补充位
- 大剑是buff船，提升舰队整体输出，不被特定舰船克制，但缺乏实战数据，强度依赖舰队质量
- 点数不高的玩家不建议培养输出战巡，优先培养巡洋舰或小船，除非其他舰船白板
- 巡洋舰输出与战巡不相上下，但战巡总伤害高且输出分散，能应对奶盾队

## 适用限制
- 风暴适合所有玩家，特别是需要免疫拦截和多功能战巡的
- 大地适合低端局或打NPC，高端局不建议使用
- 雷火适合氪佬且拥有两个满改战巡后作为补充位，平民勿碰
- 大剑适合舰队质量高的账号，缺乏实战数据需谨慎
- 点数不足的玩家不要培养输出战巡，优先其他舰船
- 战巡输出分散但造价高，巡洋舰成型快，需根据账号情况选择
