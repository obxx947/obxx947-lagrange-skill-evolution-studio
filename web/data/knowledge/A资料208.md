# A资料208

## 场景 / 对手
防空艇对舰/防空/轰炸，主队或列兵，前期资源紧缺环境

## 舰队例子
- T800防空艇（脉冲炮+策略优先，动力系统锁定点满，武器系统锁定点满；有气势锁则换命中）（胜）【防空后优先打小船，可放航母或列兵】

## 实战结果
T800作为防空艇，对舰能力优秀，防空强，对飞机较弱；未提及具体对战记录

## 结论思路
- T800是全场主动防空，打破网警防控能力强
- 对舰评级C是假象，脉冲炮输出优秀且不受拦截影响
- 能量伤害和舰载机无视站位特性使其有效输出
- 主队两条路：放航母打小船和防空，或放列兵打超斩
- 也可上轰炸，选择取决于舰队配合
- 加点优先策略，无策略少一半伤害
- 无气势锁优先点动力和武器锁定，有气势锁换命中
- 造价七八百便宜，前期资源紧缺时优先造
- 基础血量护航艇最高，又肉又能打又能防控

## 适用限制
- 对飞机能力较弱
- 适合前期资源紧缺时使用
- 需点满策略和锁定才能发挥最大效果
- 抽到必玩，容易出货，来自未央电子币箱子
