# A资料208 · T800防空艇评测

> 场景：主队/航母/列兵，防空与对舰

## 结论
- 对舰评级C是误导，实际对舰能力不错
- 脉冲炮输出不受拦截影响
- 能量伤害且舰载机无视站位，能打出有效伤害
- 是护航艇（原文为"网警"，疑似语音识别错误）中唯一全场主动防空，反护航艇能力强
- 对飞机防空能力稍弱
- 放航母里防空后优先打小船
- 放列兵里可打超斩
- 也可以上轰炸，按舰队配合选择
- 策略必须优先点，没有策略至少少一半伤害
- 造价便宜，前期资源紧缺时5本舰载机可优先造
- 既能打对方护航艇又能打伤害
- 生存强，基础血量为护航艇最高
- 又肉又能打又能防空，抽到必玩
- 容易出货，未央舰船，电子币箱子有概率出

## 配队与模块
- 加点：策略优先点
- 无气势锁：动力系统两个锁定点满，武器系统一个锁定点满
- 有气势锁：把锁定换成命中

## 数值与数据
- 造价约七八百
