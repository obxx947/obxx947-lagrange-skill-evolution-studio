# A资料292

## 场景 / 对手
天书副队对抗三个输出队，正面防御，环境为常规PVP

## 舰队例子
- 大毛（前排中甲毛，31万血量，未点退到中排策略）x4（损失2个）【前排抗伤】
- 天辰（前排）x6（未提及损失）【前排抗伤】
- 天枢（满改毕业，重甲附加维修61万血量，带海尔波普双型号、天权、挡刀飞机）x5（血量健康）【核心奶量，三分钟奶200万】
- 南十字（A2模块，带6护航艇4飞机，优先攻击前排策略，载天枪、天机、AT021）x2（未提及损失）【提供机库，吸引对空火力】
- 大盾（重甲盾，A2模块，提供30%减伤策略）x1（未提及损失）【中排抗伤，转移伤害】
- 风暴（雷暴无人机模块）x3（未提及损失）【套盾，限制直射反大能量伤害】
- 天权（满改第一页，41万血量，585护甲，M1系统）x1（未提及损失）【掩护幻影艇，提高装甲】

## 实战结果
天书副队被三个输出队围攻，时间3分多钟，承受约900万伤害，击毁对方一个完整副队，自身仅损失2个大毛和一些护航艇，5个天枢血量健康

## 结论思路
- 依靠高血量和多超主力配置分伤，前排10个战巡分散伤害
- 天枢高额奶量提高坦度降低战损
- 中排9个大船分摊伤害，航母提供机库吸引对空火力
- 海尔波普提高奶量
- 南十字可替换为CV3000，提供机库和通牌拦截

## 适用限制
- 适用于抗伤型副队，需多超主力配置
- 依赖天枢奶量，需满改毕业
- 适合面对多输出队围攻场景
- 不适用于快速输出或单挑场景
