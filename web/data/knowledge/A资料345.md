# A资料345 · 乌拉诺斯之矛（原文为"大毛"，疑似简称）全模块解析

> 场景：副队扛伤战巡

## 结论
- M1轨道炮基础单发2600，满点满调校可达3500，面对重甲舰伤害优秀
- M2离子炮因失射惩罚机制，在当前高闪避小船前排版本不推荐使用
- M系统两个模块都有将大矛调到中排的策略，并让M系统获得暴击效果
- 中排策略在主武器系统内，M系统被击毁后策略失效，大矛会从中排回到前排
- A2模块实测输出最高，A1次之
- 火力倾泻策略只在A2模块中，大矛结构值降到50%以下时A系统火炮冷却缩短40%
- 有A2直接用A2，没有A2用原装
- B1防空导弹附带自身拦截和自身防空词条，可反小但伤害较低
- B2模块可装3个护航艇
- B3维修无人机舱维修量约等于半个CAS066级-支援巡洋舰（原文为"066"，疑似简称）
- C1火控雷达模块磁条加加点可为全舰武器提高8%命中率
- C2附加装甲提供额外结构值和护甲
- C3反导拦截系统拦截词条高概率且全域拦截，还有全舰队防空词条，但防空伤害低，主要作用是拦截
- 大矛当前版本只推荐带进副队作为扛伤战巡
- 大矛武器全部是反大火炮，作为输出位容易被前排高闪避的开阳级-机动驱逐舰（原文为"开阳"，疑似简称）克制
- 大矛带进副队时前排矛非常容易死，必须在主武器系统里把大矛调到中排
- 前排用开阳级-机动驱逐舰和瑶光级-通用护卫舰（原文为"瑶光"，疑似简称）克制对方能量直射
- 作为扛伤战巡，C系统必须带C2附加装甲
- 不推荐大矛带C3模块做拦截，副队中大矛必须优先保证生存
- 拦截可以交给光锥级-区域防空巡洋舰（原文为"光仿"，疑似语音识别错误）和CV3000级-快速航空母舰（原文为"CV3000"，疑似简称）

## 配队与模块
- 副队有航母需要补充机位时带B2模块
- 不需要补充机位时可在B3模块补充维修量
- M系统任意使用用原装M1模块
- A系统优先A2模块，没有A2用原装
- C系统带C2附加装甲

## 数值与数据
- M1轨道炮基础单发2600，满点满调校3500
- A1反小火炮单发100，反大火炮单发950
- A2四个反大火炮基础单发1200
- A3六个反小火炮基础单发200
- 火力倾泻触发条件：结构值降至50%以下，A系统火炮冷却缩短40%
- C1火控雷达为全舰武器提高8%命中率
- B3维修量约等于半个CAS066级-支援巡洋舰
