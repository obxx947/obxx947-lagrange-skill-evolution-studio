# A资料156

## 场景 / 对手
护航艇体系，正面/轰炸，环境为当前版本（轰炸被削）

## 舰队例子
- 索姆河之影（护航艇，实弹伤害，单发高，策略：三架一组攻击同一目标并均摊成伤）（胜）【T0级，但轰炸削弱后，地推不如大电风暴之力】
- CB1103（轰炸护航艇，挡刀艇）（胜）【新手免费获得，仅轰炸需要挡刀艇，地推不需要】
- CBM011 A/B型号（护航艇，B型号反大能力不错，飞行号可防空）（胜）【MB型号用得多，其他型号少用】
- CVT800（护航艇，对空对舰强，血量高，唯一防空艇）（胜）【福利上线15艘，量大管饱，全面】
- RBC13型（护航艇，B型号获取难度大）（负）【没怎么用过，不推荐】
- SD为9号（护航艇，实弹伤害反大，往返式机制）（胜）【伤害高，但输出时间短，轰炸不带，地推可带】
- 蜂巢（护航艇，时代伤害，优先反大）（胜）【前期神，后期难打穿战裙，若有反小策略更强】
- 海尔波普 A/B型号（护航艇，奶船，B型号有维修机器人）（胜）【B型号强，放盘古队很强，扛伤队易暴毙】
- 谭普尔 A/B型号（护航艇，A干扰锁定，B提供防空锁敌效率）（负）【一般不用，大佬偶尔用】
- 先拥有两个型号（A输出不高有闪避加成，B轰炸主力）（胜）【A可当挡刀艇，B是T0但轰炸被削，上场机会不多】
- 有两个型号（定位扛伤，B是A的加强版）（胜）【B获取难度大，作用类似003帮轰炸挡刀】

## 实战结果
玩家分析护航艇体系，轰炸被削后地推不如大电风暴之力；护航艇优势是持续输出，但易被防空锁定，需挡刀艇；地推不需挡刀艇。

## 结论思路
- 索姆河之影是T0，但轰炸削弱后地推不如大电风暴之力
- CB1103仅轰炸需要挡刀艇，地推不需要
- 护航艇优势是持续输出，但易被防空锁定，需挡刀艇
- 地推挂护航，护航艇基本不受伤害，不需挡刀艇
- 敌方目标死亡后护航艇返回母舰，类似战机
- CVT800是唯一防空艇，对空对舰强
- SD为9号是往返式，生存高但输出时间短
- 蜂巢前期强，后期难打穿战裙
- 海尔波普B型号维修能力强，放盘古队强
- 谭普尔A/B型号一般不用，大佬偶尔用
- 轰炸主力B型号是T0，但轰炸被削，上场机会少

## 适用限制
- 轰炸被削，地推需用大电风暴之力替代
- 新手不建议用挡刀艇
- 护航艇易被防空锁定，需挡刀艇保护
- 往返式护航艇不适合轰炸，适合地推
- 后期护甲高，蜂巢等实弹伤害难打穿
