# A资料156 · 护航艇全型号简评

> 场景：护航艇/轰炸队/地推队

## 结论
- 索姆河之影单发实弹伤害高且不怕拦截，策略点出三架一组集火并均摊承伤后很强
- 轰炸被削后，索姆河之影放猎兵级地推不如永恒风暴级伤害高
- 只有轰炸队需要挡刀艇，普通地推队不需要
- 护航艇围绕敌方持续攻击不返航，战机打完一轮回母舰补弹
- 护航艇全程在战场易被防空锁定击杀，因此轰炸队需要挡刀艇
- 地推队必挂护航，护航艇基本不受伤害，新手一般用不到挡刀艇
- 敌方目标舰船死亡后，护航艇会返回母舰再重新出击，机制类似战机
- CV-T800型-脉冲炮艇（原文为"CVT800"，疑似简称）对空对舰都强、血量高，是护航艇中唯一防空艇，上限15艘
- S-列维9号-重型鱼雷艇（原文为"SD为9号"，疑似语音识别错误）是唯一往返式护航艇，机制类似战机，生存高但输出时间短
- S-列维9号-重型鱼雷艇一般轰炸队不带，地推队可以带
- 蜂巢守卫者-重型鱼雷艇（原文为"蜂巢"，疑似简称）前期很强，实弹伤害且优先反大，后期难打穿战巡
- 蜂巢守卫者-重型鱼雷艇若有反小策略会非常强
- 海尔波普两个型号都是奶艇，可当挡刀艇，维修量不错但在扛伤队容易暴毙
- 海尔波普-B-维修支援护航艇比A型强，可在受损船上放维修机器人持续回血到战斗结束
- 海尔波普-B-维修支援护航艇放在盘古队里很强
- 坦普尔1号-信息护航艇（原文为"谭普尔A型号"，疑似语音识别错误）干扰舰载机锁定顺序，一般没什么用
- 坦普尔1号-预警护航艇（原文为"一型号"，疑似语音识别错误）提供防空武器锁敌效率，基本不用但部分大佬会用
- 鳐-A-装甲护航艇（原文为"先拥有两个型号，A型号"，疑似语音识别错误）输出不高但有闪避加成，可当挡刀艇，特殊情况有上场空间
- 鳐-B-特种护航艇是轰炸主力，T0级，但轰炸被削后受影响
- 鳐-B-特种护航艇有不错闪避机制能当扛伤艇，但扛伤艇需求有限，上场机会不多
- 鳐两个型号定位都是扛伤，B型号是A型号加强版但获取难度大
- 鳐两个型号主要作用和CV-II003型-轻型护航艇（原文为"CB1103"，疑似语音识别错误）差不多，帮轰炸挡刀

## 配队与模块
- 索姆河之影策略：三架一组攻击同一目标并均摊承伤
- 索姆河之影可放CV3000级-快速航空母舰（原文为"Ctrl C2"，疑似语音识别错误）C2上
- 索姆河之影可放猎兵级-重型载机巡洋舰（原文为"猎兵车"，疑似语音识别错误）上用于地推
- CV-M011型-A-重型导弹艇（原文为"C B M零幺幺 A型号"，疑似语音识别错误）和CV-M011型-B-重炮艇（原文为"B型号"，疑似简称）一般打航母
- CV-M011型-B-重炮艇防空能力还不错
- 野火级护航艇（原文为"飞行号"，疑似语音识别错误）可以防空，MB型号用得多
- 海尔波普-B-维修支援护航艇放盘古队很强
