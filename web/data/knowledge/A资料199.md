# A资料199

## 场景 / 对手
星际猎人战机培养，面向平民玩家，讨论反舰、防空等战机优先级

## 舰队例子
- VB（维B）搭载刀等离子轰炸系统，大型战机，需航母或2.0搭载（胜）【战机中输出最高，无法被拦截，点数需求不高】
- 海市，能量伤害，可防空（仅炮艇），独立作战（胜）【伤害高，战略打击有用，培养优先级最高之一】
- 凌霄，能量伤害，搭配苍穹（胜）【优先级低于VB和海市，能绝育指挥系统，具备防空能力】
- B-2050、次遥（次瑶？），实弹伤害，可更改攻击序列（胜）【单发不高，打重甲费力，但有系统殉爆填补伤害】
- VA，功能型，绝育动力系统（负）【输出不高，战斗能力不强，但能恶心对手】
- 小米，防空战机（胜）【曾经人权卡，防空火力强】
- 雷火（B型号），防空战机，优先打击炮艇（胜）【后起之秀，培养成本略高，适配轰炸版本】
- 沙龙、孢子（防空补充）（胜）【提高防空伤害】
- 干扰机（搭配天枢航母）（胜）【提高空战线坦度】
- 新代弟、天选（胜）【前者绝育武器系统，后者降低武器命中率】

## 实战结果
平民玩家培养战机，反舰优先，防空次之；VB和海市最强，凌霄次之，B-2050/次遥/VA有培养价值；防空小米和雷火优先；其他未提及战机不建议培养

## 结论思路
- 优先培养反舰战机，打结构值伤害直接有效
- 战机点数至少给到60，满足条件后培养下一个
- VB和海市是培养优先级最高的战机
- 若无VB和海市，选择凌霄，搭配苍穹伤害可媲美VB
- B-2050和次遥有系统殉爆填补伤害，可优先打击小船
- VA功能性强，但输出低，主要用于恶心对手
- 至少拥有三个输出战机后，再考虑培养防空
- 防空优先小米和雷火，雷火需B型号
- 后续可根据配置选择沙龙、孢子、干扰机、新代弟、天选等

## 适用限制
- 适用于平民玩家，资源有限
- VB需航母或2.0搭载，不适合早期
- 雷火培养成本高，需B型号
- 未提及的战机伤害低，不建议培养
- 防空培养需在拥有三个输出战机之后
