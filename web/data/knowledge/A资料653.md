# A资料653

## 场景 / 对手
奇美拉级巡洋舰基础型，输出定位，清理小船，测试环境含中甲大毛、六六支援、开阳靶船

## 舰队例子
- 奇美拉基础型（堡垒火炮+雷雨反舰导弹阵列），满编，144人口（负）【打中甲大毛破不了防，打巡洋舰单人口伤害勉强破千，与混沌轨道炮同梯队】
- 奇美拉基础型（策略调效后），满编，144人口（负）【输出提升约10%，性价比低，对中甲无提升】

## 实战结果
奇美拉基础型测试三分钟，对中甲大毛无效，对巡洋舰伤害一般，对闪避小船输出可看但受遥光干扰；策略调效提升有限

## 结论思路
- 奇美拉基础型定位清理小船，双武器系统点满，单发未破五百，对重甲乏力
- 堡垒火炮基础命中率50%-70%，导弹70%-100%，需优先命中加点
- 推荐加点：堡垒火炮两命中三冷却一策略一伤害，导弹放弃反大、命中、一伤害
- 策略启动60秒持续10秒，收益高，但调效后提升仅10%，性价比低
- 输出表现不优秀，不如混沌轨道炮，后者能打中甲战巡

## 适用限制
- 适用于清理高闪避小船，不适合中甲或重甲目标
- 受遥光干扰影响，能量直射武器效果受限
- 人口需求18，性价比不高，需谨慎使用
