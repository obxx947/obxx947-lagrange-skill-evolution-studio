# A资料653 · 奇美拉基础型加点与输出实测

> 场景：靶船测试：中甲乌拉诺斯之矛（原文为"大毛"，疑似语音识别错误）、CAS066级-支援巡洋舰（原文为"六六支援"，疑似简称）、高闪避开阳级

## 结论
- 基础型定位输出，主要职责是清理小船
- 双武器系统点满，单发伤害未破500，对重甲目标破不了防
- 现版本对手多为高闪避小船，对该船命中要求很高
- 打巡洋舰与康纳马拉混沌级-轨道炮巡洋舰同梯队，总伤害更高但人口也更高
- 打高闪避小船数据不算优秀，但能量直射武器会被瑶光干扰，尚可接受
- 策略可调校缩短启动时间，但输出提升小、性价比低
- 任务就不是打中甲目标，对中甲基本没有提升
- 需18人口，表现不优秀，不如用康纳马拉混沌级-轨道炮巡洋舰（至少打得动中甲战巡）

## 配队与模块
- 奇美拉级-重型巡洋舰（原文为"奇美拉"，疑似简称）（基础型）：堡垒火炮 + 反舰导弹阵列双武器系统
- 堡垒火炮7个加点位：优先2命中、冷却点满3个，策略与双伤害三选二（选1策略+1伤害）；基础命中率低，冷却伤害提升大，策略收益高
- 导弹系统4个加点位：放弃反大、命中与1个伤害加点；导弹优先打小船，反大命中意义不大，伤害加点收益低

## 数值与数据
- 单发伤害未破500
- 堡垒火炮反小基础命中率50%~70%，导弹70%~100%
- 策略启动60秒、持续10秒
- 靶船护甲：中甲乌拉诺斯之矛540，CAS066级-支援巡洋舰80
- 开阳级闪避率70%以上
- 测试时长3分钟，满编144人口，单船18人口
- 打巡洋舰单人口伤害勉强破1000
- 策略调校后3分钟输出提升约10%，对中甲目标基本无提升
