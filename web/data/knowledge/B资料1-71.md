# B资料1-71 · 主队副航母选择与苍穹配置

> 场景：主队副队/团战轰炸/地推

## 结论
- 主队副航母仅永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）与南十字星元帅级-武装航空母舰（原文为"乃十字/男识字/男师资"，疑似语音识别错误/简称）两条。
- 天枢级-支援航空母舰（原文为"天书"，疑似语音识别错误）、CV3000级-快速航空母舰（原文为"CV"，疑似简称）、雷火之辉（原文为"雷火之挥"，疑似错字）不建议放主队当副航母。
- 团战轰炸核心为永恒苍穹级-无人机航空母舰+C2。
- 永恒苍穹级-无人机航空母舰是个人主队地推中林鸮A100型-联合攻击机对舰的专属载具，M1大幅增强林鸮A100型-联合攻击机伤害。
- 当前版本多数配队缺艇位，C2永恒苍穹是主队补艇位首选。
- 地推场景多数推荐C2模块，不推荐C1。
- 不推荐C1原因：战机真正有输出的少，不需要太多战机位；艇位空缺，C2补艇位更优。
- C1仅在机库只有B192新大地-重型攻击机（原文为"心脏地/新大帝/新大地/性拉低"，疑似语音识别错误/简称）时值得上，其他可放太阳鲸-武装战略航空母舰（原文为"鱼"，疑似简称）机库平替，如050、014、041等。
- 天枢级普及后，永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）、雷火之星-综合武库舰（原文为"雷火"，疑似简称）等输出战巡可进副队，副队伤害大幅提高。
- B192新大地-重型攻击机可绝育对方主武器系统的大型攻击机，并对超主力目标有高殉爆伤害。
- 永恒苍穹级-无人机航空母舰的分散攻击对全舰生效。
- B192新大地-重型攻击机需分散打击加点，才能绝育更多主武器并提高殉爆。
- 不推荐永恒苍穹级-无人机航空母舰C1携带维塔斯-B010-轰炸机（原文为"维B/尾币/VP/VB"，疑似简称/语音识别错误）。
- C1对维塔斯-B010-轰炸机加成全游戏数一数二，与十三余M2持平；更高者仅十三余、满条南十字星元帅级-武装航空母舰，另有副队天枢级-支援航空母舰。
- C1带维塔斯-B010-轰炸机不能点M1全舰分散；失去后M1林鸮A100型-联合攻击机约等于报废。
- 林鸮A100型-联合攻击机靠分散才大概率绝育对方盾旗剑并打出更多殉爆。
- C1仅4个机位，带满维塔斯-B010-轰炸机需3艘永恒苍穹级-无人机航空母舰；M1被阉割还占3艘，亏人口。
- 除非没有十三余，否则不推荐维塔斯-B010-轰炸机上永恒苍穹级-无人机航空母舰C1输出。
- 永恒苍穹级-无人机航空母舰自身武器推荐A2离子炮与B1反舰投射系统；B1数值低，A2即可满足自身输出。
- 地推点数充裕可开两个方案，一个C1、一个C2。
- 点数不足仅带3艘永恒苍穹级-无人机航空母舰，带满9林鸮A100型-联合攻击机，艇位补CV-T800型-脉冲炮艇（原文为"T800/八百"，疑似简称）即可。
- 南十字星元帅级-武装航空母舰留待下期讲。

## 配队与模块
- 主队副航母可用：永恒苍穹级-无人机航空母舰、南十字星元帅级-武装航空母舰。
- 永恒苍穹级-无人机航空母舰推荐模块：C2艇库、C1机库、M1机库；自身武器A2离子炮+B1反舰投射系统。
- 团战轰炸搭载：星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）、坦克。
- 点数充裕方案：4艘永恒苍穹级-无人机航空母舰C2带15个CV-T800型-脉冲炮艇；1艘永恒苍穹级-无人机航空母舰C1带4个B192新大地-重型攻击机；M1机库带10林鸮A100型-联合攻击机+5新大地。
- 点数不足方案：3艘永恒苍穹级-无人机航空母舰，M1带9林鸮A100型-联合攻击机，艇位补CV-T800型-脉冲炮艇。
- 不推荐主队副航母：天枢级-支援航空母舰、CV3000级-快速航空母舰、雷火之辉。
- 不推荐：永恒苍穹级-无人机航空母舰C1带维塔斯-B010-轰炸机。
- 永恒苍穹级-无人机航空母舰C1若带维塔斯-B010-轰炸机需3艘，且M1不能点全舰分散。

## 数值与数据
- 永恒苍穹级-无人机航空母舰旗舰加点额外弹药，搭载星云追逐者-脉冲炮艇和坦克在轰炸状态可打出地推三倍输出。
- C2永恒苍穹有4个艇位，拥有与猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误）相同加成。
- C1只有4个机位。
- 苍穹C1对维塔斯-B010-轰炸机加成与十三余M2持平；更高者仅十三余、满条南十字星元帅级-武装航空母舰，另有副队天枢级-支援航空母舰。
- 带满维塔斯-B010-轰炸机需3艘永恒苍穹级-无人机航空母舰。
- 当前版本大部分配队缺艇位。
- C1仅在机库只有B192新大地-重型攻击机时值得上。
- 天枢级普及使副队伤害比以前高很多。
