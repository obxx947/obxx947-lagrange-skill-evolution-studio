# A资料439

## 场景 / 对手
测试三个输出巡洋（重卡、泡泡龙、游离子）编入奶队，分别打狩猎订单第十二关（瑶光碰瓷队）和多种大船配置，测试反小和反大能力

## 舰队例子
- 重卡（输出巡洋，未点策略）编入奶队（胜）【反小输出意外高，不受瑶光护盾影响，可驱射越过闪避前排；反大平均输出与游离子、泡泡龙持平，点策略后集火战巡输出遥遥领先】
- 泡泡龙（输出巡洋）编入奶队（胜）【反小力大砖飞，武器机制优秀，顶着瑶光打近百万伤害（含20万打特卡）；反大平均输出与游离子、重卡持平，但纯曲射怕阳光】
- 游离子（输出巡洋）编入奶队（负）【反小输出只有泡泡龙一半，被瑶光护盾减免且离子炮机器被闪避前排玩弄；反大平均输出与重卡、泡泡龙持平，但需叠策略实战略差，且直射曲射都怕】

## 实战结果
重卡、泡泡龙、游离子各编入奶队打狩猎订单第十二关（瑶光碰瓷队）和多种大船配置；反小：重卡和泡泡龙一个梯队，游离子拉胯；反大：三者平均输出持平，重卡点策略后领先；综合反大反小，重卡夺回巡洋输出之王称号

## 结论思路
- 重卡反小和泡泡龙反小是一个梯队，游离子反小拉胯
- 反大时游离子、重卡、泡泡龙平均输出基本持平，游离子因叠策略实战略差但少两个人口抵消
- 重卡点策略后集火战巡输出遥遥领先
- 重卡曲射炮拦截，泡泡龙纯曲射怕阳光，游离子直射曲射都怕
- 玩家用阳光防直射意愿大于补光防防曲射，所以重卡反大第一，泡泡龙游离子并列第二
- 综合反大反小，重卡是巡洋输出之王

## 适用限制
- 测试基于狩猎订单特定配置（瑶光碰瓷队和多种大船），结果可能因对手体系不同而变化
- 重卡未点策略，点策略后表现更优
- 游离子需叠策略，实战可能略差
- 泡泡龙怕阳光，游离子怕阳光和曲射，需考虑环境
- 以上观点代表主播个人理解，可能有争议
