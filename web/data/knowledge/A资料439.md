# A资料439 · 巡洋输出之王赛博斗蛐蛐

> 场景：狩猎订单测试，反小与反大

## 结论
- 重卡反小与泡泡龙反小同梯队，游离子反小拉完
- 反大平均输出三者基本持平，游离子因叠策略实战略差
- 游离子少2人口可抵消策略劣势
- 重卡点集火策略后反大战巡输出遥遥领先
- 重卡怕曲射炮拦截，泡泡龙纯曲射怕防空，游离子直射曲射都怕
- 玩家补防空防直射意愿大于补光防防曲射
- 综合反大反小，重卡为巡洋输出之王
- 泡泡龙与游离子反大并列第二

## 配队与模块
- 测试各取一个输出巡洋编入奶队
- 反小目标：狩猎订单第十二关瑶光碰瓷队，闪避前排+瑶光+碰瓷驱护
- 重卡未点策略

## 数值与数据
- 重卡反小输出意外高
- 泡泡龙顶着瑶光打近百万伤害，其中约二十万打特卡
- 游离子反小输出只有泡泡龙一半
