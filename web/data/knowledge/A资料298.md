# A资料298

## 场景 / 对手
游戏《无尽的拉格朗日》中控制矿区获取资源，涉及登陆舰使用和矿区控制流程

## 舰队例子
- 诺玛A登陆舰（加点：控制作业点满，剩余点频率）（胜）【推荐优先使用，用于登陆控制矿区】
- 于海A登陆舰（胜）【另一种登陆舰，可用于登陆作业】

## 实战结果
玩家在控制矿区过程中损失大量船只，资源不足，但通过控制矿区可获取资源；具体胜负未提及

## 结论思路
- 控制矿区需要登陆舰，推荐使用诺玛A，加点优先控制作业，剩余点频率
- 控制矿区需达到一定标准（如二级难度），等级越高收益越高，但矿种类不同收益不同
- 控制流程：组建控制队，点击矿点停靠，到达后点击工作，再点击控制
- 协助控制需签署对话者协议

## 适用限制
- 适用于有登陆舰的玩家，优先诺玛A
- 控制矿区需达到对应难度标准
- 矿区收益受等级和矿种影响
- 需注意资源消耗，避免过度损失
