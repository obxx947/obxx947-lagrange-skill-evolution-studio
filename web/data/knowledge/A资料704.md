# A资料704

## 场景 / 对手
针对加九打加九的阵容讨论，涉及顶科玩家、护航队与地面战斗的对比，以及战报分析

## 舰队例子
- 零六六（数量较多）+ 满改天数 + 海尔波普（护航艇）+ 副队 + T800（胜）【单队十五分钟，两队六分半解决战斗；零损，海尔波普百分百生存】
- 第二阶段护航（零六六+奶船，未分商）（负）【被第三阶段护航撵着过，策略盾一分零七秒掉，系统持续时间不超四分钟】

## 实战结果
宋老板队伍打加九对手，两队上六分半解决，单队十五分钟；对方一分钟百万战报但己方零损，对方策略盾快速崩溃

## 结论思路
- 加九对顶科玩家无意义，顶科应追求更高配置
- 海尔波普生存依赖护航艇数量，否则不如零六六
- 保空战优先于保地面，零六六人口多但价值低
- 第二阶段护航无法对抗第三阶段，奶量需时间但战斗时间短
- 策略盾是关键，需保护，零六六非唯一手段
- 种族值低的船（如零六六）不需氪金，但仅适合第二阶段
- 阵容需不断研究，不承认最强，但反对无战报的批评
- 进阶需高配置，低配置（灵力）无法达到更高提升

## 适用限制
- 适用于有大量护航艇和满改天数的玩家
- 不适用于无护航艇或低配置玩家
- 仅限第三阶段护航对抗，第二阶段护航不适用
- 需快速解决战斗，避免长时间消耗
