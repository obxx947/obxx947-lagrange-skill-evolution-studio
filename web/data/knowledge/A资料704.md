# A资料704 · 回应加九阵容与护航队质疑

> 场景：护航队体系对抗（第二/第三阶段护航）；对手为066加海尔波普的加九队伍

## 结论
- 宋老板已做出队伍并发视频，号召做加九打加九。
- 顶科玩家不该用加五阵容；顶科连加九都做不了应换门，或去宋老板的门。
- 与普通队伍没本质区别，只是066数量多少的差别。
- 队伍有副队、有CV-T800型-脉冲炮艇时，海尔波普（原文为“海尔伯普”，疑似错字）活不下来。
- 非天权玩家、护航艇少，海尔波普不可能100%生存；其100%生存收益可能高于CAS066级-通用巡洋舰十一台。
- 海尔波普人口低、066人口高，保谁显而易见。
- 对手护航队百万战报打不掉作者队伍，作者零损；最多让乌拉诺斯之矛（原文为“毛”，疑似简称）狂暴、输出略增。
- “减速带”阵容没问题。
- 第二阶段护航不要碰瓷第三阶段护航，第三阶段是撵着过的。
- 作者这一队接完对手一队还能接无数同类队伍，哪怕对手是天枢级-支援航空母舰（原文为“天枢级-支援航空母舰”，疑似语音识别错误）。
- 用066且不分摊/分散策略，本质仍是第二阶段护航，只是奶更多。
- 奶需要时间，但没人陪你打那么久；关键是队伍能否撑过5-6分钟。
- 看策略盾何时掉；作者未开分散打击，因对手超主力数量不值得开。
- 连策略盾都掉了就没法玩，保盾手段不止上066。
- 这些船种族值太低；种族值高的船需多氪金，这是负面效果。
- 066种族值低、不需氪金；其强度仅限于第二阶段护航。
- 有更高护航队时，打第一阶段护航可轻松过。
- 作者从没说阵容最强，仍在研究改进。
- 有人称作者给科老推荐的阵容不能打、没战报，故出视频反驳；老板感兴趣就顺着老板意思。
- 规矩自己定：能做加九就做出来看；想更高提升还用“灵力”不可能，如同羽毛球世界冠军不用苍蝇拍。
- 作者被指圈钱骗粉丝；直播一场收68元，纯爱好为爱发电，老板觉得值才来。
- 作者没拉联盟反对别人，也没看不起新手，耐心教学；莫名攻击才有问题。
