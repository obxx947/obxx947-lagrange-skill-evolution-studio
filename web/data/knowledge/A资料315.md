# A资料315

## 场景 / 对手
CV航母扛伤队，对抗超斩或反小火力环境，正面作战

## 舰队例子
- CV航母（5艘，含30个炮艇，后排铜牌拦截）（胜）【提供物理抗性和拦截，保护古神】
- 古神驱逐舰（9艘，同人口维修量相当于4个六六）（胜）【替代六六奶，但身板脆，需抗性支持】
- 瑶光（提供能量抗性）（胜）【减少能量伤害对古神的威胁】
- 御寒（2艘，兜底维修）（胜）【维修总量有限，带多会断奶】
- 开阳（前排，抵挡直射伤害）（胜）【为古神分摊反向火力】
- 战巡（5艘，4艘大毛挺毛+1艘大盾旗舰，52分摊）（胜）【炮灰提高海尔兄弟生存率，防集火】

## 实战结果
CV航母扛伤队对抗超斩或反小火力，配置优化后生存率高，无具体胜负记录，关键得失是奶妈体系稳定性和战巡分摊

## 结论思路
- 用古神替代六六奶，同人口维修量相同，但需抗性提升容错
- 瑶光加能量抗性，CV拦截物理伤害，御寒兜底，但御寒带多会断奶
- 战巡带5艘，14分商，52分摊，防单点杀，选大毛挺毛提高生存
- 不推荐蓝睫毛，护甲低，维修增益不高
- 舰载机选择看个人理解

## 适用限制
- 适用于反小火力较少的环境，否则古神维修量无法保证
- 御寒最多带2个，带多断奶风险高
- 战巡选择可灵活（奶毛或大盾），但需考虑人口限制
- 不适用于需要高奶量或极端集火场景
