# A资料318

## 场景 / 对手
护航版本，主队轰炸机体系

## 舰队例子
- 维塔斯B轰炸机，武器系统（等离子体发射器，满调教），动力系统（往返频率加点），装甲系统（自带导弹鱼雷闪避，5个加点槽）（胜）【高伤害能量武器不可拦截，生存能力强，适合高加成机库如siri的M机库、鱼的M2机库】

## 实战结果
维塔斯B轰炸机在护航版本中作为主队必带舰船，长期霸榜禁赛季第一，输出和生存能力均优

## 结论思路
- 维塔斯B轰炸机搭载等离子体发射器，基础单发650，满调教后提升至800多，优先反大攻击序列第一个是战巡，能量武器不可拦截
- 装甲自带导弹和鱼雷闪避，5个加点槽，可提升结构值和闪避策略，并增加对方武器锁敌时间，武器系统自带10点护甲，生存能力强
- 作为开服老牌舰船，伤害一骑绝尘，稳坐飞机一哥T0位置，护航版本中主队必带
- 新手未抽到VB时，建议在保底箱定向获取，能带来主队输出质的飞跃，且不特别吃点数，武器和动力系统点满仅需79蓝点
- 加点重点：武器系统和动力系统的三个锁敌必点，动力系统往返频率加点对伤害加成高，是武器系统加点的两倍，点数不足时优先点它
- VB应放在高加成机库，如siri的M机库、鱼的M2机库，这些机库无七十锁，武器系统调教暴击也能提升伤害

## 适用限制
- 适用于护航版本及主队轰炸机体系
- 需高加成机库支持，否则输出受限
- 点数不足时需优先动力系统往返频率加点
- 不适合无护航或低加成机库环境
