# A资料387

## 场景 / 对手
PVP舰队对抗，涉及防空、轰炸、碰瓷队等环境

## 舰队例子
- 干扰型信息护航艇（基础型），加点优先生存（闪避、血量）（胜/负评价：视情况，不稳定）【目标优先战机、无人机、护航艇；对面无舰载机时不出机库，无法扛伤】
- 子型号信息护航艇，加点优先生存，并点锁定效率、命中率增益（胜/负评价：有用，非刚需）【目标优先巡洋舰、驱逐、护卫；提高舰载防空效率，适合碰瓷队】

## 实战结果
测试干扰型对零六六维修无人机的干扰失败，因对面无舰载机时护航艇不出机库；子型号在防空场景中提升锁定效率，如围蔽对光防，缩短驱程时间

## 结论思路
- 干扰型底BUFF可能对对面是正向收益，如蜂巢打大船变打小船，新麦打小船变打大船，效果不稳定
- 干扰型定位是扛伤，加点优先生存（闪避、血量），但对面无飞机时无法出机库，扛伤有条件
- 面对轰炸时干扰型有用，可提高对面转火频率，但不如加强自身防空
- 子型号提供正向锁定效率增益，可理解为提高防空伤害，对舰载防空重要
- 子型号加点优先生存，并点锁定效率和命中率增益，适合碰瓷队
- 总体思路：信息护航艇作用是辅助我方舰船输出，而非直接击杀，有用但非刚需

## 适用限制
- 干扰型需对面有舰载机才出机库，否则无法扛伤
- 干扰型底BUFF可能对对面有利，需谨慎使用
- 子型号适合防空和碰瓷队，但非刚需
- 信息护航艇不直接输出，依赖我方舰船配合
