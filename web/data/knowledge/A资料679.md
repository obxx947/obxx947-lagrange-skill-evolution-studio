# A资料679 · 前期300人口驱护（原文为"区护/区库"，疑似语音识别错误）碰瓷

> 场景：前期300-320人口落地小型战斗、防空碰瓷

## 结论
- 落地小型战斗多，有轰炸出轰炸，之后转碰瓷队。
- 开阳驱逐线落地基本都造，闪避率高；基础型号前排扛伤，子型号打输出。
- 现版本以开阳为基础；以前防御牛配古斯塔/重炮也可用。
- 针对开阳+瑶光组合，雨海基础型号拉满，尤其闪避点。
- 雨海实弹轨道炮针对开阳小船闪避好用，前中期小型战斗也适用；自身能存活。
- 雨海策略先退中排、再退后排仍能输出。
- 雨海改版后主力舰可带巡洋，中期补猎兵/狩猎，主力舰升至巡洋并可吃旗舰。
- 脉冲输出强，加点后有短暂爆发，针对驱护命中好；打架强度高可调整，后期也可用。
- 逆风局经济差被围殴，走新版驱护配置作抗伤副队。
- 逆风副队狼蜥做驱护时造基础型号即可。
- FG300多用途可上，但富贵造价高；狼蜥基础型号造价只高一点，更好用。
- 防空碰瓷队防守时，不载红矿用白垩级吃白垩旗舰拉萤石，做干扰投射单队大队抗伤亡。
- 枪骑兵级-区域防空驱逐舰拉满时增援安东尼奥斯（原文为"安东尼奥"，疑似语音识别错误）巡洋形成默认巡洋buff，不需给旗舰；默认buff加15%命中，吃轰炸做洗澡好用。
- 各公司都有默认巡洋buff，可自行查看。
- 驱逐现在一般只出开阳，其余用护卫配置。
- 七八本两种节奏：八本憋出后造鱼；氪佬落地憋鱼。

## 配队与模块
- 开阳级-机动驱逐舰（原文为“开阳”，疑似简称）基础型号：前排扛伤；落地驱逐线基本都造。
- 开阳级-鱼雷驱逐舰子型号：输出，配合护卫舰。
- 输出推荐：锆石级-特种护卫舰（B型）（原文为"锆石的b型号"，疑似简称）、雨海级-突击护卫舰/雨海级-脉冲炮护卫舰（原文为"鱼海"，疑似语音识别错误）（双型号）、瑶光级-通用护卫舰（原文为"摇光"，疑似错字）。
- 无锆石子型号时，用狼蜥级-突击护卫舰（B型）（原文为"狼西"，疑似语音识别错误）替代。
- 扛伤：开阳级-机动驱逐舰 + 瑶光级-通用护卫舰，少量瑶光配几个塔。
- 碰瓷队：雷里亚特级-快速鱼雷护卫舰（原文为"雷利亚特"，疑似错字）基础型号（小720），加满点；单队投射约200人口带3-5个，澄海级-防空护卫舰补位。
- 以前可用斗牛级-防御驱逐舰（原文为"防御牛"，疑似简称）配古斯塔/重炮；现版本以开阳为基础。
- 针对开阳+瑶光：雨海级-突击护卫舰基础型号拉满，尤其闪避点；实弹轨道炮。
- 中期雨海主力舰队补猎兵级、狩猎者级巡洋，吃旗舰。
- 脉冲路线可考虑，加完点有短暂爆发，针对驱护命中好。
- 逆风驱护副队：开阳级-机动驱逐舰 + 瑶光级-通用护卫舰，有子型号各5个；雨海级-突击护卫舰基础型号；卡利莱恩级-特种护卫舰（卡特）；雷里亚特级-隐身护卫舰中排挡刀；狼蜥级-防御护卫舰（原文为"狼袭"，疑似语音识别错误）也可。
- 逆风狼蜥做副队造基础型号。
- 可上45个FG300型-多用途护卫舰（富贵）。
- 防空碰瓷队200人口：不载红矿，白垩级吃白垩旗舰，拉塔拉萨萤石级-信息/电子驱逐舰，做干扰投射单队大队抗伤亡。
- 枪骑兵级-区域防空驱逐舰拉满，增援安东尼奥斯巡洋（狩猎者级-防空载机巡洋舰、猎兵级等或支援型号），不给旗舰，形成默认巡洋buff。
- 搭载推荐CV-M011型-高速导弹艇（C型）（原文为"011高速"，疑似简称）。
- 驱逐一般只出开阳，其余护卫配置。
- 七八本：八本憋出后造鱼；氪佬落地憋鱼。

## 数值与数据
- 前期人口300-320；通常压到300恢复策略值。
- 碰瓷队单队投射约200人口，带3-5个雷里亚特。
- 雨海实弹轨道炮命中400多，比重炮稍高。
- 安东尼奥斯默认巡洋buff增加15%命中。
- FG300多用途造价600多；狼蜥基础型号造价高一点点。
- 逆风副队开阳+瑶光有子型号各造5个。
- 可上45个FG300多用途护卫舰。
- 防空碰瓷队200人口。
- 升级到七八本为节点，八本后造鱼。
