# A资料679

## 场景 / 对手
前期300-320人口过渡阶段，小型战斗，落地打架，防空碰瓷队

## 舰队例子
- 开阳基础型号（前排扛伤）+ 摇光（少量）+ 锆石子型号或狼西B型号（输出）+ 鱼海基础型号（闪避输出）（胜）【开阳闪避高，基础型号扛伤，子型号输出；锆石B型号推荐，无子型号用狼西B型号】
- 雷利亚特基础型号（3-5个）+ 澄海防空（补位）+ 投射单队（胜）【雷利亚特被称为小720，加满点后200人口单队投射】
- 开阳配摇光（子型号各5个）+ 鱼海基础型号 + 雷隐（中排挡刀）+ 狼西基础型号（胜）【逆风局区护副队配置，雷隐中排挡刀，狼西基础型号造价低】
- 白垩旗舰（吃旗舰）+ 萤石（干扰投射）+ 枪骑兵拉满 + 安东尼奥巡洋（增援，提供默认巡洋buff）+ 011高速（搭载）（胜）【防空碰瓷队，安东尼奥增加15%命中率，吃轰炸时好用】

## 实战结果
前期小型战斗，开阳配护卫舰体系，针对开阳加摇光组合，鱼海基础型号拉满闪避，实弹轨道炮有效；逆风局用区护副队抗伤；防空碰瓷队配合白垩旗舰和安东尼奥巡洋，几胜几负未明确，关键得失是开阳闪避高、鱼海改版后能配巡洋、安东尼奥巡洋buff提升命中

## 结论思路
- 前期300-320人口，开阳配护卫舰打架，轰炸后出碰瓷队
- 开阳基础型号扛伤，子型号打输出，配合护卫舰伤害优秀
- 输出推荐锆石B型号、鱼海双型号、摇光，无锆石子型号用狼西B型号
- 鱼海基础型号拉满，闪避高，针对开阳小船有效，实弹轨道炮命中率高
- 鱼海改版后主力舰可上巡洋，中期补猎兵等巡洋吃旗舰
- 脉冲输出强，加点点后有爆发，针对驱护命中好
- 逆风局用区护配置抗伤，开阳配摇光、鱼海、雷隐、狼西基础型号
- 防空碰瓷队不载红矿时，吃白垩旗舰拉萤石，配合枪骑兵和安东尼奥巡洋增援，利用默认巡洋buff增加命中
- 搭载推荐011高速，其他公司也有默认巡洋buff
- 前期驱逐线出开阳，七八本后憋鱼，氪佬直接落地憋鱼

## 适用限制
- 适用于前期300-320人口小型战斗
- 开阳配摇光组合需针对时，鱼海基础型号和实弹轨道炮有效
- 逆风局经济不好时，区护副队配置适用
- 防空碰瓷队需配合白垩旗舰和安东尼奥巡洋，否则效果差
- 鱼海改版后能配巡洋，但需注意主力舰限制
- 氪佬可无视资源限制直接憋鱼，普通玩家需憋到七八本
