# A资料273

## 场景 / 对手
当前战场环境，前排开阳瑶光普遍存在

## 舰队例子
- 永恒风暴 + M2等离子体投射器（胜）【核心输出模块，无视站位，伤害可观】
- 永恒风暴 + A2工程鱼雷（胜）【实测输出最高，优先选择】
- 永恒风暴 + A3防空加反大导弹（胜）【能量伤害，优于A1实弹】
- 永恒风暴 + B1实弹火炮（胜）【需要输出时选择】
- 永恒风暴 + B2防空火炮（胜）【需要扛伤防空时选择】
- 永恒风暴 + C1防空无人机（胜）【主队使用，增加防空】
- 永恒风暴 + C2无人机护盾（胜）【天枢高达部队使用，为前排战巡套盾】
- 永恒风暴 + C3能量装甲（胜）【普通副队使用，提高承伤能力】
- 永恒风暴 + D1反大离子炮（胜）【需要输出时选择】
- 永恒风暴 + D2防空脉冲炮（胜）【需要承伤和防空时选择】

## 实战结果
永恒风暴各模块在不同场景下的适用性分析，无具体对战记录

## 结论思路
- M1离子炮面板虽高但实际伤害不如M2，M2是核心输出模块
- A模块中A2输出最高，A3能量伤害优于A1实弹
- B模块根据需求选择，B1输出，B2防空
- C模块根据舰队定位选择，主队用C1，天枢部队用C2，副队用C3
- D模块简单，D1输出，D2防空

## 适用限制
- M1在当前前排环境下效果差，不推荐
- A1实弹伤害不如A3能量伤害，优先A2或A3
- C模块选择需根据舰队配置，不可随意更换
- B和D模块选择需明确舰队角色
