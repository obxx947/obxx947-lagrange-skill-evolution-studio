# A资料173 · 南十字A2模块用法解析

> 场景：对手为开阳级-机动驱逐舰（原文为"开阳"，疑似简称）加瑶光级-通用护卫舰（原文为"瑶光"，疑似简称）前排体系

## 结论
- 新版本南十字星元帅级-武装航空母舰（原文为"南十字"，疑似简称）加强核心是A系统新增优先针对前排策略
- 开阳级-机动驱逐舰加瑶光级-通用护卫舰组合难处理点在于高能耗
- A系统建议使用AR模块，放弃AE模块
- AE仓位搭载维塔斯-B010-轰炸机（原文为"VB"，疑似简称）虽为优秀能量伤害，但不契合当前前排环境
- 前排几乎没有拦截时，蜂巢守卫者-重型鱼雷艇（原文为"蜂巢"，疑似简称）能快速清理高血量开阳级-机动驱逐舰
- 现版本南十字星元帅级-武装航空母舰上A2模块是最优选择
- C1模块正常上

## 配队与模块
- 南十字星元帅级-武装航空母舰A系统使用AR模块
- 南十字星元帅级-武装航空母舰C1模块正常上
- 蜂巢守卫者-重型鱼雷艇作为清理前排主力
