# A资料173

## 场景 / 对手
针对开阳前排的南十字配置，现版本环境

## 舰队例子
- 南十字（A2模块，AR模块，C1模块）（胜）【A2模块提供优先针对前台策略，AR模块增强对高血量目标的伤害，C1模块正常配置】

## 实战结果
南十字使用A2模块能有效清理开阳前排，而使用AE模块效果不佳

## 结论思路
- 南十字新版本加强A系统优先针对前台策略
- AE模块的VB虽为能量伤害，但难以处理开阳加瑶光的高能耗组合
- A系统建议使用AR模块，搭配A2模块
- 在前排无拦截环境下，高血量开阳也容易被快速清理
- 现版本南十字上A2模块是最佳选择

## 适用限制
- 适用于前排无拦截的环境
- 针对开阳加瑶光组合时有效
- 不适用于需要AE模块能量伤害的场景
