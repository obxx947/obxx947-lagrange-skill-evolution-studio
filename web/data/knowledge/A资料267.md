# A资料267

## 场景 / 对手
单航母输出队，2.0到1+1阶段，进化星系环境

## 舰队例子
- 单航母（星云弹炮）+ 猎兵 + 狩猎 + 飞机（胜）【分箱输出可达140万】
- 单航母（星云弹炮）+ 风暴L泡泡龙 + 猎兵（胜）【其他星系替代方案】

## 实战结果
单航母输出队分箱输出140万，在进化星系表现优秀

## 结论思路
- 星云弹炮在进化星系很好用，应优先携带
- 其他星系可减少猎兵数量，补充风暴L泡泡龙
- 在线版本输出环境不佳，需增加猎兵和狩猎，用飞机替代
- 此配置为2.0到1+1阶段最强输出队

## 适用限制
- 适用于进化星系环境
- 其他星系需调整配置
- 依赖飞机和猎兵数量，可能受资源限制
