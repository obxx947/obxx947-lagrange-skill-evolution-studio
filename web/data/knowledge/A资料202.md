# A资料202 · 巡洋舰强度排行

## 结论
- CAS066级-支援巡洋舰（原文为"06牛奶"，疑似语音识别错误）排第一，护航队必带，除非天枢或顶氪不需要
- 猎兵级-重型载机巡洋舰（原文为"猎兵a"，疑似简称）与狩猎者级-载机巡洋舰（原文为"狩猎者ABC"，疑似简称）排第二，都能走超斩
- 狩猎者级-载机巡洋舰可走超斩也可不走，但用到时都需要它
- 玉衡级-支援巡洋舰（原文为"玉衡C"，疑似简称）排第三，36000奶只能奶小船
- 开阳级、瑶光级加玉衡级-支援巡洋舰强度超标，以下打上或同等级对冲都强
- 康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡楼/卡玛币"，疑似语音识别错误）排第四，是少数能用的输出
- 瑶光级针对康纳马拉混沌级-高速等离子体巡洋舰，能大幅降低其伤害
- 光锥级-区域防空巡洋舰（原文为"光房"，疑似语音识别错误）排第五，主要作用是在肉队拦截
- 光锥级-区域防空巡洋舰拦截对维塔斯A021-重型攻击机（原文为"维A"，疑似简称）、BR050-标准轰炸机（原文为"050"，疑似简称）、刺鳐-鱼雷轰炸机（原文为"次爻/思瑶"，疑似语音识别错误）伤害降低不大
- 光锥级-区域防空巡洋舰影响最大的只有新君士坦丁大帝级-综合战列巡洋舰（原文为"大地"，疑似语音识别错误）和卡利斯托-重型鱼雷袭击舰（原文为"重卡/钟凯/卡利斯托币"，疑似语音识别错误），但这两艘使用率很低
- 第二阶段、第三阶段花60人口做拦截不值
- 卡利斯托-重型鱼雷袭击舰排第六，被拦截后伤害降很多，但打大船伤害仍高
- 卡利斯托-重型鱼雷袭击舰克制驱逐、战巡、护卫、航母
- 游骑兵级-重型离子炮巡洋舰（原文为"尤其冰壁"，疑似语音识别错误）排第七，不要只看打海盗或低赛玩家的测试
- 游骑兵级-重型离子炮巡洋舰策略需要长时间打击才能生效，且是直射武器，被瑶光级克制
