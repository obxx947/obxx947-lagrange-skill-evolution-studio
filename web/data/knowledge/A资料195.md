# A资料195

## 场景 / 对手
当前版本舰队配置解析，涉及对大、反小、绝育体系，多超主力舰船推荐，主副队配合

## 舰队例子
- 风暴（战巡，主输出）+ 反小火力船 + 小船（干扰直射/能量船）+ VA（结构值威胁）（负（主力全损））【依赖风暴主输出，但缺乏有效反小或干扰导致失败】
- 双行（对方）+ 小船（干扰）（胜）【对方配置有效干扰我方直射/能量船】
- 轰炸机（数量最大化）+ 苏姆河之影（必带）+ 星脉（可选，机位紧张时替代）（未提及）【飞机海配置，强调轰炸机数量】
- 主队（有效输出）+ 副队（大盾、大矛、奶船拉满、太阳瑶光成仓）（胜（一加一大于二效果））【主副队配合，增强生存和输出】

## 实战结果
我方主力全损，对方双行配置获胜；关键得失：缺乏有效反小和干扰，导致主力被消耗

## 结论思路
- 推荐多超主力舰船（如战巡）上场，因模块更新后应用性增强
- 主流对大由战巡承担，如大地、风暴、雷火，风暴是主流对大选择
- 需要反小火力减少干扰项
- VA对结构值威胁高，必不可少
- 飞机海配置中，轰炸机数量优先，苏姆河之影必带，星脉非必然
- 主副队同时上场，主队输出，副队带奶船和成仓，可产生协同效果
- 舰队配置需多样化，有效克制是未来趋势

## 适用限制
- 适用于当前版本模块完善后的配置
- 反小和对空模块需有效应用
- 机位紧张时可用替代船
- 不适用于单一舰队打天下的旧思路
