# A资料401 · 攻击序列分类与优先级

## 结论
- 攻击序列有分类，分类内又有优先级
- 索姆河之影-装甲飞行坦克（原文为"索姆河"，疑似简称）攻击序列分类含对舰、攻城，对舰火力分一二两个优先级
- 索姆河之影-装甲飞行坦克面对战巡、航母、支援舰混编时，优先打战巡和航母
- 索姆河之影-装甲飞行坦克无法锁敌战巡、航母时才打支援舰
- 同优先级内战略航母、战巡、巡洋目标随机，可能先打巡洋也可能先打航母
- 维塔斯-B010-轰炸机（原文为"围蔽"，疑似语音识别错误）每种舰船类型都有优先级，先打战巡、再打航母、再打支援舰
- 海氏追随者型-脉冲攻击机（原文为"海事"，疑似语音识别错误）优先防空会先打护航艇
- 海氏追随者型-脉冲攻击机攻击序列没有战机，序列内目标都没有时才会打战机
