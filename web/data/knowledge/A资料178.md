# A资料178

## 场景 / 对手
太阳鲸C2模块搭配，无C1模块时的替代玩法

## 舰队例子
- 太阳鲸（C2模块）+ 6工程舰 + 4其他舰船（胜）【利用C2高伤害和反大能力，替代载机玩法】
- 太阳鲸（C2模块）+ 8工程舰 + 4其他舰船（胜）【增强指挥系统绝育效率，提高战场控制】

## 实战结果
无具体实战记录，仅介绍6+4和8+4工程玩法

## 结论思路
- C2模块虽不能载机，但伤害高且优先反大，可当战巡使用
- C2指挥系统绝育效率高，适合工程搭配
- 无C1模块时，可通过C2模块实现太阳鲸的战场价值

## 适用限制
- 适用于无C1模块的玩家
- 不适用于依赖载机输出的场景
- 需搭配工程舰以发挥指挥系统优势
