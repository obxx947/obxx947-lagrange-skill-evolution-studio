# A资料471

## 场景 / 对手
特殊舰船获取方式与功能推荐（旧帝国阵营）

## 舰队例子
- 止战级攻坚战舰（战略舰船，8碎片合成1模块）（胜）【拉格朗日唯一战略舰船，能扛能打能输出，但获取极难，碎片出货率极低，需艾格勒姆星域挖掘或交易平台购买】
- 先登级两栖突击舰（A型号）（胜）【登陆舰，用于控制作业（资源点/城池），装甲不错，获取需艾格勒姆星域或交易平台，B型号不考虑】
- XT-11导弹驱逐舰、XT-6火炮护卫舰（胜）【实弹打小船效率不错，日常打野怪可获得箱子，碎片8个合成，缺碎片可交易购买】
- 理智A101战斗攻击机（负）【冷门飞机，实弹输出优先攻击小型舰船，主动攻击主武器系统，实战效果一般，基本不用，仅收集用】

## 实战结果
无具体实战记录，仅介绍舰船功能与获取方式

## 结论思路
- 止战级是拉格朗日最强舰船，但获取难度极高，仅适合顶级玩家或工作室
- 先登级A型号是控制玩法的必备舰船，适合喜欢控制资源点或城池的玩家
- XT系列舰船获取难度低，适合日常打野怪凑碎片，性价比高
- 理智A101实战价值低，不建议投入资源，仅收藏用

## 适用限制
- 止战级：仅限艾格勒姆星域挖掘或交易平台购买，碎片出货率极低，成本极高
- 先登级：仅需A型号，B型号无用，获取需艾格勒姆星域或交易平台
- XT系列：需日常打野怪积累碎片，缺碎片可交易购买，适合平民玩家
- 理智A101：实战效果差，不推荐用于战斗，仅适合收集蓝图
