# A资料703 · 盘古副队与第二家园红黑榜

> 场景：顶氪护航副队；第二家园红黑榜

## 结论
- 盘古体系核心：盘古战巡自带群体减伤与能量抗性，多超主力分摊承伤，天枢级-支援航空母舰（原文为"天书级"，疑似语音识别错误）持续维修，克制直射爆发队。
- 副队硬性标准：只堆战巡与航母，巡洋、驱逐、护卫全舍弃；小船血量低、分摊收益低、分散火力，易使后排被集火。
- 战巡优先级：盘古为核心，其次乌拉诺斯之矛（原文为"矛"，疑似简称），普鲁图斯之盾级-防护战列巡洋舰（原文为"盾"，疑似简称）仅作过渡；矛满即替换盾。
- 盘古策略技能给全队超主力叠高额能量减伤，搭配天枢级维修，面对能量直射承伤压力减半。
- 乌拉诺斯之矛自带狂暴增伤与双直射武器，兼顾分摊与补输出；普鲁图斯之盾级缺载机位、防空弱，上限低。
- 天枢级精准维修前排血量最低舰船，持续抬血，保证盘古与乌拉诺斯之矛不快速战损。
- CV3000级-快速航空母舰（原文为"cv3000"，疑似简称）、永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）、太阳鲸-武装战略航空母舰（原文为"太阳晶"，疑似语音识别错误）不适合副队，缺维修加成，放副队成突破口，只放主队输出。
- 分摊配比不用卡死；超主力数量足够时分摊收益溢出，不强凑五二分伤、六三分伤。
- 副队载机只做功能性，不追求高额输出；输出艇全部放主队太阳鲸、苍穹。
- 误区：副队塞开阳级、瑶光级、CAS066级-支援巡洋舰（原文为"零六六"，疑似简称）等巡洋奶船只适合中低氪；小船吃不到盘古抗性，会瞬间融化并浪费人口。
- 对坦克雷火物理直射队：盘古能量减伤无效，靠多超主力高血量与天枢海量奶硬扛，分摊稀释单点伤害。
- 对风暴、星脉能量队：盘古群体能量抗性大幅降低敌方输出，战损差距拉开。
- 对常规输出航母主队：副队超主力血量充足，难被快速清理，持续拖住敌方给己方主队争取输出时间。
- 加点：盘古全点结构、护甲、闪避防御，放弃输出；天枢级维修无人机效果与冷却拉满；矛兼顾防御与直射伤害。
- 第二家园奖励不诚心：头像框和太阳鲸皮肤获取门槛高，绝大多数玩家难获得。
- 矛和盾皮肤工作室定价高；太阳鲸皮肤更热门，所需工时更少。
- 免费奖励仅局内道具，无法带出局外。
- 类比三角洲行动：哈弗币可不在局内花，每赛季限定挂件有带出局外感觉；第二家园奖励是死局。
- 预测：散客留不住，一眼看到头，奖励丰富，被工作室霸占是迟早。
- S级断档领先：天枢级；纯战机天枢与游戏内拾取天枢机位差别不大，A3奶量更高；游戏内天枢也可S级。
- 该模式比谁天枢多，可自造并拾取天枢，人口可带满，单挑无敌；要输出需平衡。
- 纯战机天枢评价高：护航人口足够可同时造满护航艇与战机；400人口队伍只能专做战机或护航艇。
- 保战机不保护航艇：纯带艇船少；空优机对艇/机命中率高，主流空优艇对艇命中一般、对机命中很低。
- 保护航艇线不纯粹，带艇必带战机；11鱼会带战机，13鱼可直接上；11鱼位置可能靠后。
- 苍穹、蓝狮子可做纯战机，但有太阳鲸或苍穹的玩家难造满两者；造5台苍穹后太阳鲸不可能满，只需极个别太阳鲸带强战机。
- 黑马：B192新大地-重型攻击机（原文为"大地"，疑似简称）；在航母核心、战巡辅助队伍中输出亮眼，打野怪与玩家都好。
- 雷火之星-综合武库舰（原文为"雷火"，疑似简称）地位高于新大地：可开拦截，适合全大船模式，输出与功能性完胜新大地；有剑玩家必有新大地，雷火不一定有。
- 剑排不上A：安东塔斯持剑者级-指挥舰（原文为"剑"，疑似简称）养成成本高，使用强度不如新大地；需稳定空战环境，带坦克、维B并保证不死，带坦克基本第一个死。
- 风暴是保底输出，但该模式多两队爆完；爆完局新大地是大爹，因有残血；400人口上述船已够，防御船多此一举。
- 天权级最大作用保护皇城；不带艇时靠边站，带艇阵容有一定保护作用，可排一排。
- 盾作扛伤船却缩中排与雷火、新大地抢生存，不认可；副队开旗舰意义不大，被夹还想一穿三不现实。
- 矛能扛能打，但该队更需战机保护，它做不到；主要是人口不够，人口够都可带。
- ST59级排名靠前：可前突电磁配置克制主流能量输出阵容；空优机在59快死时作用有限。
- 飞机天然压护航艇一头：护航艇不可能排A，排B有胜算。
- 蜂巢守卫者-重型鱼雷艇（原文为"蜂巢"，疑似简称）成黑马：无拦截；坦克、星脉先死为后来者创造输出机会，后来者是蜂巢；玩艇优不带蜂巢，坦克与星脉白死。
- CV-T800型-脉冲炮艇（原文为"t800"，疑似简称）需跟上，空战靠它打。
- 海尔波普活不久，不能带足护航艇保生存，排不上该位置；能活久则是海尔波普或护航艇天下。
- 模式有雷火V022-A、雷火V022-B、米斯特拉-战斗攻击机（原文为"小米"，疑似简称）三张牌基本赢；空战胜利后靠维塔斯-B010磨死。
- 雷火V022与米斯特拉为首的空优机是第一梯队，加维塔斯-B010创造生存赢战斗。
- 海氏追随者型-脉冲攻击机（原文为"海狮追随者"，疑似语音识别错误）基本出来就死，只能空优；没人口带男士或超展，空优打对舰伤害低，空军赖久后对舰伤害低，不排高。

## 配队与模块
- 盘古体系副队顶配：6盘古、6乌拉诺斯之矛、5天枢级-支援航空母舰。
- 天枢级最少3台起步，顶配5台；C2维修模块拉满，维修无人机效果点满。
- 盘古全部标配A模块，拉满群体抗性与减伤，舍弃输出模块，定位纯承伤。
- 天枢级统一M2+B1艇模块搭配C2维修模块，A3维修效果模块必选，最大化维修无人机数量与奶量。
- 天枢级红黑榜纯战机配置：M、A3、B1、C2、D2，机位选8G，A3奶量更高。
- 乌拉诺斯之矛携带双直射输出模块，兼顾分摊与补伤，不用换防御模块。
- 副队载机：海尔波普-维修支援护航艇（原文为"海尔波普"，疑似简称）必带；天玑-重型护航艇（原文为"天机"，疑似语音识别错误）作前排挡刀；少量CV-T800型-脉冲炮艇限制敌方海尔波普回血；不带星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）、坦克等输出艇。
- 输出航母与输出艇放主队：太阳鲸-武装战略航空母舰、永恒苍穹级-无人机航空母舰。
- 盘古加点：结构、护甲、闪避防御；放弃输出。天枢级维修无人机效果与冷却拉满；乌拉诺斯之矛兼顾防御与直射伤害。
- 红黑榜推荐：天枢级S级，可自造5台并拾取5台；雷火V022-A、雷火V022-B、米斯特拉为空优第一梯队；维塔斯-B010输出；B192新大地、雷火之星为输出战巡；蜂巢守卫者艇优必备；CV-T800打空战。
- 红黑榜不推荐或排位低：安东塔斯持剑者级-指挥舰排不上A；普鲁图斯之盾级中排不认可；海尔波普活不久；海氏追随者型-脉冲攻击机不排高。
- 带艇阵容可考虑天权级前排保护；ST59级可前突电磁针对能量阵容；乌拉诺斯之矛能扛能打但人口不够。
