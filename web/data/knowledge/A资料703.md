# A资料703

## 场景 / 对手
盘古体系顶配氪佬护航副队，针对直射爆发队、能量队、常规输出航母主队

## 舰队例子
- 盘古战巡（a模块，满6条）+ 矛战巡（双直射输出模块，满6条）+ 天书级航母（m2+b1+c2维修模块，a3效果模块，5台）+ 海尔波普护航艇 + 天机护航艇 + 少量t800护航艇（胜）【顶配模板，全超主力，无小船，分摊承伤，持续维修】
- 盘古战巡（a模块）+ 盾战巡（过渡分摊）+ 天书级航母（维修模块）（负）【盾作为过渡，矛满后替换，上限低】

## 实战结果
对阵坦克雷火物理直射队：硬扛，战损可控；对阵风暴、星脉能量队：大幅降低敌方输出，战损差距拉开；对阵常规输出航母主队：拖住敌方，争取时间

## 结论思路
- 全超主力为核心，舍弃巡洋、驱逐、护卫，避免小船被集火
- 盘古战巡必满6条，提供群体减伤和能量抗性
- 矛战巡补充输出，盾仅过渡
- 天书级航母至少3台，顶配5台，维修模块拉满
- 载机只做功能性搭配，如海尔波普、天机、t800，输出艇放主队
- 盘古全点防御，天书点维修，矛平衡防御和输出
- 避开巡洋奶船混搭误区

## 适用限制
- 适用于顶氪玩家，高人口配置
- 不适用于中低氪，小船混搭无效
- 副队定位纯承伤，输出依赖主队
- 需大量超主力，人口要求高
