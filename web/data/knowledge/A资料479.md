# A资料479

## 场景 / 对手
大盾输出能力对比，正面作战

## 舰队例子
- 大盾（未加点，使用防空拦截模块，综合武器未加点）（负）【生存时间5分钟，伤害4.9万】
- 大盾（综合武器加点，重心投射加点，使用C3模块）（胜）【生存时间4-5分钟，伤害9万-15万】

## 实战结果
双方各6条大盾，加点方总伤害82万，未加点方总伤害20万，差距60多万

## 结论思路
- 大盾输出依赖M1和C3模块，是核心输出构成
- 大盾输出能力与加点密切相关，综合武器和重心投射加点可显著提升伤害
- 生存时间相近时，加点与否导致伤害差距巨大，未加点大盾伤害低
- 大盾伤害可观，单条可达十几万，不应忽视其输出能力

## 适用限制
- 适用于当前版本大盾的输出配置
- 需要投入技能点进行加点，否则输出能力有限
- 适合正面作战场景，需保证生存时间以发挥输出
