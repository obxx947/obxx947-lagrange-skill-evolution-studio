# A资料52

## 场景 / 对手
控制高级城获取登陆水母，对手为防空五级、七级城守军，正面控制，环境为误区无喷流

## 舰队例子
- 航母带满八百小米沙龙，加防御牛台原奶古神奶水母防空，再带一两个登陆舰（胜）【防空主力队】
- 拉满登陆舰，带股神和区护前排（胜）【控制队】

## 实战结果
防空五级城出两个怪，防空七级城出三个怪，控制队接战撤回前哨再出发，防空队控到结束，控制进度转移给防空队，成功控城

## 结论思路
- 快速获取登陆水母需控制高级城，五级、七级城可直接出货且控完必拿箱子
- 控城需两队：防空主力队和控制队，防空队负责清怪，控制队负责进度
- 在城旁造前哨，舰队调动到前哨，撤退可回前哨，便于反复接战
- 防空队全程控到结束，控制队被打就撤回前哨重新出发
- 防空城可能出大量轰炸机，带小米800防空拉满可应对
- 推荐控五级、七级防空城，怪少易控，怪多则需小队协作

## 适用限制
- 适用于有工会缝合台原小米或防空舰船充足的玩家
- 防空城可能出大量怪，若对剑要求高则难控，需评估实力
- 仅适用于误区无喷流的地图环境
- 需在SP开放到特定阶段后开始抢控
