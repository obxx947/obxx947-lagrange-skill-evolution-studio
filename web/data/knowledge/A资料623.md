# A资料623

## 场景 / 对手
艾格勒姆星域，指战级攻坚战列舰测评，正面测试

## 舰队例子
- 3艘指战级（白板，M1重型离子炮+M2重型等离子体投射器+A1鱼雷+B攻程+C试验型离子炮塔/轨道炮塔+D中型/大型反舰导弹+E离子强化+F1近防脉冲炮）（胜）【秒伤510，每分钟约3万伤害】
- 3艘指战级（金标，同上模块）（胜）【秒伤1220，每分钟约7.32万伤害】
- 3艘指战级（白板） vs 6艘大矛（带维修模块）（负）【抗伤能力约等于4-5艘大矛】
- 3艘指战级（金标） vs 3艘大矛（平）【抗伤效果相当】
- 3艘指战级（附加装甲系统）（胜）【预计抗伤可媲美6艘大矛】

## 实战结果
测试指战级对线输出和抗伤能力，白板伤害较低，金标伤害翻倍；抗伤方面，3艘指战约等于4-5艘大矛，金标与3艘大矛相当，附加装甲后可达6艘大矛水平。关键得失：指战人口优势（3艘150人口 vs 6艘大矛210人口），但中排站位影响前排吸收伤害，资源消耗高（白板40万金属、9万晶体、4万重氢，金标13万晶体、5万重氢，建造25小时）。

## 结论思路
- 指战级拥有近9万火力和40万血量，是旧帝国核心科技，当前仍具优势
- M1和M2武器伤害相近，但功能不同，可装备多目标同步打击策略
- A1反小单位鱼雷可暴击，A2反小且防空；B模块攻程但瘫痪功能未复原
- C模块根据舰船大小切换武器，D模块兼顾反小和反大
- E模块离子强化提升输出命中，附加装甲提升护甲血量
- F1防空弱但对舰效果佳，F2防空性能更好
- 白板指战秒伤510，金标秒伤1220，伤害提升一倍多
- 抗伤能力：3艘指战约等于4-5艘大矛，金标与3艘大矛相当，附加装甲后可达6艘大矛
- 人口优势明显，但中排站位影响前排生存
- 资源消耗高，晶体需求尤其昂贵，建造时间长

## 适用限制
- 适用于对线输出和抗伤测试，需考虑敌方闪避率
- 指战为中排舰船，无法在前排吸收伤害，影响中排战巡和航母存活率
- 资源消耗高，晶体需求大，不适合资源紧张时建造
- B模块瘫痪功能未复原，限制攻城能力
- F1防空较弱，需搭配F2或其它防空舰船
