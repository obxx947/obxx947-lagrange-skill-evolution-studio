# A资料349

## 场景 / 对手
重甲模块与拦截模块的选择，当前作战环境，投射武器与直射/能量武器对比

## 舰队例子
- 重甲模块（大毛）（胜）【血量接近30万，护甲540，能量抗性5%，维修增益135%，适配奶队，兜底能力强】
- 拦截模块（大毛）（负）【血量24万，护甲390，能量抗性25%，维修量97.5%，针对投射武器但当前收益低】

## 实战结果
大毛分析重甲模块优于拦截模块，当前环境投射武器威胁有限，拦截收益低，重甲提供稳定下限

## 结论思路
- 拦截模块是针对投射武器的针对卡，但当前好用的投射武器不多，威胁有限
- 重卡单发高但数量限制，可分摊瓦解威胁，不刚需拦截
- 大地等能量导弹可被拦截，但也可用风暴C2能量闪避限制
- 主流输出如风暴M2、回避、心脉、海事等无法拦截，拦截收益低
- 重甲模块数值提升明显，维修增益适配奶队，随时间收益递增
- 拦截收益高于重甲的条件是对面投射输出极高且持久战，但当前环境不满足

## 适用限制
- 适用于当前以直射和能量武器为主的环境
- 若未来主流输出变为投射武器，拦截模块收益会提高
- 重甲模块适合搭配奶队，提供生存兜底
- 拦截模块在对面投射输出高时更优，否则收益低
