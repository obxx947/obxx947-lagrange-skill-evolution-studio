# A资料602

## 场景 / 对手
高达抗伤队，对抗敌方直射火力（混沌、艾奥）及舰载机（800、海氏），正面作战

## 舰队例子
- 前排：8艾奥高速+3光防；中排：1大盾+10个066奶；支援：5前排电磁59+10安德森+10个002（胜）【实战验证，前排至少扛4分钟】
- 前排：8艾奥高速+3光防；中排：1大盾+10个066奶；支援：5前排重甲大矛+15海尔波普（胜）【大矛输出高，换战损能力强】
- 前排：6电磁59+5拦截矛+12个066奶（负）【废弃方案，战损换不过，59仅扛3分钟】

## 实战结果
测试中，卡特、阋神20个船最多扛2分30秒；6电磁59面对大量伤害仅扛3分钟；8艾奥+3光防+5战巡前排至少扛4分钟；副队带舰载机最高减免800、600总伤害；59和大矛扛伤队战损时间约5分钟

## 结论思路
- 小船前排易被舰载机克制，高达抗伤队用大船分摊伤害
- 高速艾奥造价低、闪避高，抗伤能力接近电磁59
- 前排16个大船分摊伤害，延长生存
- 副队带舰载机（如002、安德森、海尔波普）削弱主队伤害，海尔波普无攻击能力避免被苔原攻击
- 支援战巡必须前排（如大矛、59），中排战巡无法分担前排伤害
- 大矛输出高、换战损强；59造价低、舰载机限制敌方800
- 维修量分散到艾奥上利用率高，优于浪费在066上

## 适用限制
- 适用于对抗直射火力（混沌、艾奥）和舰载机（800、海氏）
- 不适用于资源有限或需要快速成型的场景
- 舰载机需高生存，避免带攻击性炮艇
- 支援战巡必须前排，中排无效
- 依赖维修量，需确保奶量分配合理
