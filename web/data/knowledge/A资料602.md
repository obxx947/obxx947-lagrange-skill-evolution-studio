# A资料602 · 高达抗伤队配置与思路

> 场景：大船前排抗伤队；环境为舰载机普遍反小，对手含混沌与艾奥的直射输出、断奶队

## 结论
- 组队思路是全大船前排抗伤，不用小船换战损，因为小船容易被舰载机克制。
- 050、刺鳐、800、星脉当前普遍反小，小船前排面对这些火力扛不了多久。
- 改用后排小船奶可延长前排生存，但奶量下降严重，属另一套配队思路。
- 旧方案（电磁59+拦截矛）实战战损根本换不过，造价高、成型慢，只能停留在纸面，已废弃。
- 旧方案对面断奶时还有被炸乌拉诺斯之矛（原文为"大矛"，疑似简称）的风险。
- 大船里能限制混沌和艾奥直射伤害的就是高速艾奥。
- 高速艾奥造价明显低于ST59，且反大武器命中普遍不高、策略启动期闪避很高，抗伤接近电磁59。
- 前排集中16艘大船分摊伤害，能大大延长战巡与整体的生存时间。
- 副队带舰载机能大幅削弱主队受到的伤害，主要削800和海氏，航母抗伤队效果更强，很有必要。
- 副队舰载机必须选高生存的，002和安德森合适，炮艇选海尔波普。
- 海尔波普没有攻击能力，对面带苔原载机时吃不到伤害，只会拖住主队800和海氏；带别的炮艇会死得很快。
- 战巡必须放前排：大盾、大剑是中排，无法给前排艾奥分摊伤害，前排被打穿后中排死得更快。
- ST59和乌拉诺斯之矛扛伤能力没有本质区别，选哪个看个人偏好。
- 乌拉诺斯之矛输出更高，能帮主队更快处理对面副队；残血触发狂暴，高血量高护甲带来维修量加成，换战损更强。
- ST59造价更低，但受护甲限制吃不到高维修量，换战损略劣势；携带的舰载机能更好限制敌方主力800。
- 前排16艘大船必然奶量分散，但艾奥对维修利用率高，生存提升很大。
- 不带艾奥时奶量会分散到066上纯属浪费；风暴队也存在同样的奶量分散。

## 配队与模块
- 前排：艾奥级-高速离子炮巡洋舰（原文为"艾奥高速"，疑似简称）×8 + 光锥级-区域防空巡洋舰（原文为"光防"，疑似简称）×3
- 中排：普鲁图斯之盾级-防护战列巡洋舰（原文为"大盾"，疑似简称）×1 + CAS066级-支援巡洋舰（原文为"066奶"，疑似简称）×10
- 支援方案一：ST59级-防御战列巡洋舰（原文为"电磁59"，疑似简称）（电磁配置）×5放前排 + 平衡安德森SC020-侦察机（原文为"安德森"，疑似简称）×10 + SC002型-量子侦察机（原文为"002"，疑似简称）×10
- 支援方案二：乌拉诺斯之矛（重甲配置）×5放前排 + 海尔波普护航艇×15
- 已废弃旧方案：前排ST59级-防御战列巡洋舰（电磁配置）×6 + 支援乌拉诺斯之矛（拦截配置）×5 + CAS066级-支援巡洋舰×12

## 数值与数据
- 体验服测试：卡利莱恩级-特种护卫舰（原文为"卡特"，疑似简称）、阋神星I级（原文为"阋神"，疑似简称）共20艘船最多扛2分30秒。
- 改用后排小船奶后，前排可扛4到5分钟，因为多出20艘小船分摊火力。
- 旧方案6艘电磁59面对大量伤害只能扛3分钟就全部死亡，5艘ST59的造价实战承受不起。
- 该配置前排共16艘大船（8艘艾奥+3艘光防+5艘支援战巡）。
- 实战战报验证：该配置前排至少能扛4分钟。
- 副队舰载机最高能减免800、600的总伤害。
- ST59与乌拉诺斯之矛的抗伤战损时间都在5分钟左右。
