# A资料711 · 第二家园护航队单挑测试

> 场景：第二家园活动400人口单挑队实战；粉丝测试队 vs 我的护航队

## 结论
- 第二家园活动最终需要400人口单挑队，目前少有玩家或博主做单挑。
- 粉丝测试核心问题：队伍是否真的需要CAS066级-支援巡洋舰。
- 把CAS066级-支援巡洋舰优化为猎兵级-重型载机巡洋舰+谷神星级-支援驱逐舰组合。
- 谷神星级-支援驱逐舰100%奶大船（原文为"耐大船"，疑似语音识别错误），自身是小船，不会奶歪（原文为"乃歪"，疑似语音识别错误）；奶集中到航母+战巡，省掉巡洋一层，奶量加强。
- 谷神星级-支援驱逐舰需要保护：开阳级提供保护，队伍不能只有一条小船，多带小船；再加鸟王（本战未带）可砍能量伤害。
- 副队开阳级和谷神星级-支援驱逐舰死得快，原因在主队有2个星云追逐者-重型护航艇和1个星云追逐者-脉冲炮艇，反小（原文为"反响"，疑似语音识别错误）火力过多。
- 正常队伍不会塞这么多反小，仍以反大为主；这样带开阳级招架不住。
- 星云追逐者系列没有持续时间，放在太阳鲸-武装战略航空母舰上有加成才打出伤害。
- BR050双型号也做反小，正常队伍不会这么带。
- 康纳马拉混沌级-轨道炮巡洋舰大量出现，疑似针对右侧未带瑶光级-通用护卫舰；双航母队伍未带永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称），存疑。
- 卡利斯托-重型鱼雷袭击舰平时少带，疑似提前知道右侧不带拦截，想对盾进行毁灭打击。
- 普鲁图斯之盾级-防护战列巡洋舰可单防卡利斯托-重型鱼雷袭击舰，乌拉诺斯之矛（原文为"毛"，疑似错字）不行。
- 普鲁图斯之盾级-防护战列巡洋舰可点满维修同时点鱼雷闪避；重卡对战巡基础命中不高，再降鱼雷闪避后伤害低；拦截不指望拦伤害，主要点鱼雷闪避。
- 左侧有意针对右侧，但即便针对，实战效果仍不理想。
- 实战结果：右侧全军覆灭，左侧获胜，左侧可算较弱的第三阶段护航队。
- 超主力（原文为"操控力"，疑似语音识别错误）做分摊意义不大：装甲矛自身无输出；损管矛奶量低。
- 海尔波普-维修支援护航艇能精准奶超主力，牺牲艇位做损管矛奶量不划算。
- 海尔波普-维修支援护航艇高生存时可做奶矛；低生存则不如不做。
- 防御机基本没用，不如多上输出战机。
- 猎兵级-重型载机巡洋舰会被坦克打；CAS066级-支援巡洋舰可复活，宁愿两条命。
- 上CAS066级-支援巡洋舰时用盾A2吸引空军、A3吸引导弹鱼雷；若真需保猎兵，应自己跟上；坦克和盾的数值使盾巴不得全吸引。
- 期待下期第二家园400人口输出单挑队。
