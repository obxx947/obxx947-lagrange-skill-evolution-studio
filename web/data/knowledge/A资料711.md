# A资料711

## 场景 / 对手
第二家园活动，第二阶段护航队测试，单挑队（400人口）

## 舰队例子
- 5个CB座真元位 + 盾列兵 + 10个开阳 + 补神星（无遥光）（胜）【测试方阵容，优化掉零六六，用猎兵和谷神星组合】
- 猎兵（带海尔双兄弟）+ 谷神星（100%耐大船）+ 开阳 + 鸟王（未带）（胜）【优化后阵容，奶量精准指向大船，避免奶歪】
- 2个星云弹炮 + 1个星云脉冲 + 零五零双兄弟 + 康纳马拉 + 重卡（负）【对方阵容，反小和反大配置，但效果不理想】
- 3台CD三千 + 装甲毛（点损款毛）（负）【第三阶段晃队，输出不足，奶量有限】

## 实战结果
右边（测试方）全军覆灭，左边（优化阵容）留下120人口（3台CD三千），右边打100万对剑，左边打50万对剑，右边胜

## 结论思路
- 优化掉零六六，用猎兵和谷神星组合，谷神星100%耐大船，避免奶歪，奶量精准指向大船
- 谷神星生存靠开阳和鸟王保护，但鸟王未带，能量伤害被砍
- 对方阵容刻意针对（如康纳马拉、重卡），但效果不理想，盾可单防重卡（25%鱼雷闪避）
- 战机以对舰船为主，但效果有限，不如多上输出战机
- 猎兵生存问题可通过盾的A2和A3吸引空军和导弹鱼雷解决

## 适用限制
- 适用于单挑队（400人口）场景
- 需要谷神星和猎兵组合，且谷神星需点策略
- 对方阵容若带大量反小（如星云弹炮、脉冲），开阳和谷神星生存会受影响
- 不适用于需要大量反小的场景，战机配置需优化
