# A资料571

## 场景 / 对手
ST59战巡舰的实战定位与配队思路，针对新手玩家，涉及护航、奶船队、抗伤等体系

## 舰队例子
- 电磁59（电磁装甲模块）+ 8光锥 + 12 066（负）【电磁59不适合奶船队，维修量低，物理抗性低，需大量拦截，但此配置仍不理想】
- 装甲59（装甲模块）+ 少量拦截 + 奶船（胜）【装甲59适合奶船队，减少拦截人口，可上奶船回血，作为奶船队核心】
- 电磁59 + CV3000 + 前排抗伤船（如艾奥、重炮、防御牛）（胜）【电磁59作为第三阶段护航，硬抗伤害，配合CV3000拦截，前排抗伤】

## 实战结果
ST59战巡舰在奶船队中表现不佳，电磁59因维修量低和物理抗性低，不适合奶船队；装甲59更适合奶船队。电磁59在第三阶段护航中，配合CV3000和前排抗伤船，可发挥硬抗作用。整体上，ST59不如其他战巡（如风暴矛、大帝）

## 结论思路
- ST59不是新手船，新手应优先选择其他战巡
- 电磁59不适合奶船队，因维修量低（135% vs 150%）和物理抗性低
- 装甲59适合奶船队，可减少拦截人口，上奶船回血
- 电磁59适合第三阶段护航，通过硬抗伤害，配合CV3000拦截
- 电磁59应与高血量或防御船（如艾奥、重炮、防御牛）双排，而非066
- ST59的载机模块不如狩猎，超斩能力弱
- 电磁59需少量拦截，但不宜过多，因不是主要保护目标

## 适用限制
- 适用于有ST59且无其他更好战巡的玩家
- 电磁59需配合CV3000或高拦截能力，否则易被物理伤害击破
- 装甲59需奶船队支持，否则维修量不足
- 不适用于新手，因ST59整体强度不如其他战巡
- 电磁59不适合与066搭配，因066亏人口且奶量不足
