# A资料369

## 场景 / 对手
雷火之辉航母强度分析，涉及航母定位、舰载机加成、维修效果、作战场景（前中期无护航、防空碰瓷、高达副队）及对平民和氪佬的影响

## 舰队例子
- 雷火之辉航母，所有模块合计5个载机位（5大型战机或5炮艇），白板带瘟疫，M模块为维修核心（负）【载机位不如主流航母，加成仅比CV强一点，维修效果需测试且实战存疑】
- 苍穹航母带凌霄/星脉/坦克，或蓝十字带围蔽伤害（胜）【对比雷火之辉，苍穹和蓝十字对舰载机加成更强，蓝十字围蔽伤害可媲美十三余】
- CV航母带11G或8G舰载机/炮艇（胜）【CV载机位更多，可用炮灰保核心，效果与雷火之辉维修相当】
- 高达副队：天书提供载机位，雷火之辉提供维修，天权提供掩护，保护海尔兄弟（胜）【唯一较强使用场景，依赖天书，无天书无法发挥】

## 实战结果
雷火之辉航母在多数场景下不如主流航母，仅在高达副队中有优势；对平民无影响（打不过天书队），对氪佬影响较大（天书内战需此航母），但培养难度高（需先培养苍穹、主战航母、天书，各需100点航母点数），非刚需

## 结论思路
- 雷火之辉定位尴尬，消耗航母点数但载机位少（5个），加成仅比CV强一点，主战无上场空间
- 核心是M模块维修，但效果需测试，实战中舰载机往返受伤害，维修可能不足，类似纯格甲
- 适用场景有限：前中期无护航时有用，但CV也可替代；防空碰瓷可保空优机，但CV堆满效果可能更强
- 唯一强场景是高达副队，保护海尔兄弟，依赖天书和天权，是锦上添花而非刚需
- 对平民无影响，对氪佬影响大，但培养成本高（需先搞苍穹、主战航母、天书），实际遇到概率低

## 适用限制
- 适用于前中期无护航、需要舰载机输出或防空的环境
- 适用于高达副队，需搭配天书和天权
- 不适用于主战场景，载机位和加成不足
- 维修效果在大量防空面前存疑，不能保证舰载机不死
- 培养优先级低，需先完成其他航母（苍穹、主战、天书）
- 对平民无用，对氪佬也非必需，仅在高配高达队中锦上添花
