# A资料496

## 场景 / 对手
棕熊级巡洋舰评测，护航阶段（七本至后期）

## 舰队例子
- 棕熊级基础型号（离子炮，命中提伤加点，18人口）（胜）【七本刚开启护航时可直接使用，火力输出和锁定时间不错】
- 棕熊级防空型号（矿车防空导弹，防空强化加点）（胜）【可放副队，配合防空锥增强护航防空】
- 棕熊级突防型号（投射武器，配合创神星鱼雷）（负）【需特定投射配对，否则反拦截效果不佳，目前不推荐】

## 实战结果
棕熊级基础型号在护航阶段表现良好，防空型号适合副队；突防型号因配对限制实战效果差，需特定配置

## 结论思路
- 基础型号适合七本刚开启护航时直接使用，直射能量武器可协同防空
- 防空型号可配合防空锥增强护航防空，点防空强化而非范围
- 突防型号需特定投射配对（如创神星鱼雷），否则反拦截效果不佳
- 后期可带基础型号在主队，输出不错，尤其对面曲虎被消灭后

## 适用限制
- 基础型号适用于前中期护航阶段
- 防空型号适用于副队防空
- 突防型号需特定投射配对，否则不建议使用
- 后期基础型号仍可用，但需注意对面曲虎威胁
