# A资料284 · 战机与护航艇区别及用途

## 结论
- 战机是往复式飞行，打一轮伤害后返回母舰；护航艇独立作战，飞过去后持续打击目标
- 战机返回母舰时敌方丢失目标，重新锁定需要时间，因此战机生存能力更高
- 战机来回飞行耗时，导致输出时间变少；护航艇输出时间更长，所以轰炸多用护航艇
- 战机生存能力强，可放进轰炸队里挡刀
- 战机防空能力较多，护航艇防空不多
- 战机可用于干扰，天枢级-支援航空母舰需要放载机时最好用干扰机，干扰对面输出让自己更肉

## 配队与模块
- 碰瓷队配置：13鱼（S-列维9号-重型鱼雷艇（原文为"十三鱼"，疑似语音识别错误））放入碰瓷队，鱼内全放航空战机，搭配鱼的维修模块，返回母舰可回复10%血量
