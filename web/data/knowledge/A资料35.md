# A资料35 · 工程艾奥最优加点与数据测试

> 场景：对舰/攻城测试，目标前哨站

## 结论
- 对舰加点只有双伤害、双命中、双冷却一套，伤害未达预期
- 工程最优加点为双工程伤害、双伤害、双冷却，不点策略
- 策略调校后攻城时间仅快约5秒，收益与付出不成正比
- 不建议为策略耗费巨量技术值，技术值多可忽略
- 当前环境攻城属性只能打平台或城防，时间差距不够看
- 舰队中其他舰船也有攻城能力，不必为几秒调校策略
- 副本不能调校，策略未调校时纯属负收益
- 工程艾奥输出在三个艾奥子型号中最低，反大输出不如高速型
- 工程艾奥是特化攻城舰船，输出低于主流输出选项
- 没有其他输出选择时不要拿它打输出
- 有双艾奥需求时高速型和基础型已足够
- 实战以对舰输出为主，攻城属于附带，打完架才需要攻城
- 工程艾奥输出不足以进主力队，可造几个偷平台或前哨
- 副本更依赖攻城属性，对舰队和对舰输出要求不高，适合工程艾奥
- 艾奥三个子型号强度都高，仅缺防空能力

## 配队与模块
- 对舰加点：双伤害、双命中、双冷却
- 工程加点：双工程伤害、双伤害、双冷却
- 策略加点：将其中一个冷却换成策略并满调校

## 数值与数据
- 对舰最优加点反大分伤14.83万/分钟
- 对舰最优加点反小分伤12.89万/分钟
- 工程最优加点摧毁前哨站时间1分11秒
- 策略满调校摧毁前哨站时间1分06秒
- 策略满调校比不点策略仅快5秒
- 每场测试时间3分钟，每次打两场战报取最优表现汇总
- 反大分伤由航母、战巡和巡洋总数据平均计算
