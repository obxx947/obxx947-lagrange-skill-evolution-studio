# A资料67

## 场景 / 对手
当前版本，萤石基础型号与子型号，针对护航艇/战机，防空碰瓷，轰炸削弱预期

## 舰队例子
- 萤石基础型号+十三鱼，带干扰艇，后排定位，加点优先制导武器（胜）【用于单队十三鱼防空碰瓷，拦截鱼雷，干扰敌方艇】
- 萤石子型号+十三鱼，策略前三轮45%加成（胜）【优先战机，配合防空】
- 十三鱼+狼蜥+防御牛+双皮奶，增援萤石（胜）【传统防空配置，萤石加入增强】

## 实战结果
萤石基础型号针对护航艇，子型号针对战机，用于十三鱼防空碰瓷，初步削弱轰炸，但缝合轰炸（如十四双雄）仍强，十三鱼最多顶三分钟

## 结论思路
- 萤石基础型号主要用于护航艇防空，适合十三鱼单队碰瓷
- 萤石子型号优先战机，策略前三轮45%加成，之后下降
- 加点建议点制导武器，因为导弹多
- 萤石定位后排，怕制导，需注意
- 萤石加入变相削弱轰炸，但缝合轰炸另说
- 轰炸强在星脉，前期C2有点子强，中期缝合强
- 期待下版本轰炸削弱，鱼雷回归拼刺刀
- 平民建议存未央，溧阳性价比高

## 适用限制
- 适用于当前版本，轰炸削弱后可能变化
- 萤石怕制导，需后排保护
- 十三鱼防空最多顶三分钟，对缝合轰炸效果有限
- 子型号策略前三轮有效，后期下降
