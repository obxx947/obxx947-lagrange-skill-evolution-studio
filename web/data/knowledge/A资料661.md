# A资料661

## 场景 / 对手
高达内战，八分三十五秒，正面直射火力对抗，环境为常规PVP

## 舰队例子
- 左边主队：五个大毛（中排，中甲，练度高）+一个大盾（中排）+三个列兵（携带海尔波普技术型，超展后维修超主力）+开阳（前排）+耀光（后排）+零幺幺（大毛携带）（胜）【大毛打八十七万伤害，抗伤不如强势战巡但输出高；列兵携带海尔波普思路优秀，维修量高】
- 右边主队：一个大盾+三个天权（中甲，血量三十八万）+两个风暴（中甲，带C2）+光追+玉恒+开阳+天机（天权携带）（负）【前排混编开阳和天权，开阳白带；光追无六六，拦截优先级低；天权输出模块加点未满，伤害低】
- 右边输出队：四个十一+一个十三鱼+新迈八百（六个，未满）+凯士+维维币+混沌+游击兵+风暴+va+零五零（负）【防空能力弱，八百未满，无小米；直射火力集火前排未打穿，va和零五零反大导致前排存活】
- 左边输出队：两个一+三个三+坦克+尾臂+次要小米+零五零+三个苍穹+六个风暴+三个猎兵（超展）+八百（反小）+凌霄（胜）【配置完美，风暴输出稳定，六个风暴一百一十三万，围蔽伤害六十一万】

## 实战结果
左边打右边，左边胜。左边主副队各打一百八十七万，右边一百一十八万；维修量左边三百六十三万，右边四百多万；关键得失：右边副队舰载机配置错误，主队前排混编失效，输出队防空不足且直射火力未打穿前排；左边大毛输出高，海尔波普维修稳定

## 结论思路
- 刻度再高，配置思路比刻度重要
- 前排小船唯一目的是分摊直射伤害，若前排有超主力则小船失去意义
- 大毛不能当抗伤战巡，优势是伤害，在高达内战输出重要
- 副队舰载机应带炮灰，海蛇和小米等活得越久作用越大的应放主队
- 直射火力需打穿前排，否则无效；va和零五零应针对开阳降低闪避
- 风暴比混沌性价比高，输出稳定且伤害高
- 防空力量需针对海尔兄弟，否则维修量过高
- 天权无远峰技术，不适合前排混编，可全上天权节约人口

## 适用限制
- 适用于高达内战或类似战巡对抗场景
- 直射火力配置需极端化，否则难以穿透前排
- 防空不足时易被炮艇和维修舰拖垮
- 前排混编需谨慎，避免小船白带
- 大毛适合输出而非抗伤，需搭配中排站位
