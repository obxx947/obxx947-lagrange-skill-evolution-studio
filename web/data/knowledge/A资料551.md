# A资料551 · 无风暴M2能量直射配队思路

> 场景：无风暴M2模块、能量直射玩家；敌方前排开阳、后排瑶光、中排拦截盾+防空锥子+066支援

## 结论
- 无风暴M2只能能量直射时，旧思路是奇美拉弹炮+实弹舰载机反小，康纳马拉混沌离子反大
- 旧思路依赖实弹伤害快速清掉敌方小船，能量直射才能打出高额伤害
- 实战战报推翻旧思路：3分51秒仅打224万伤害，只炸几艘开阳和瑶光
- 康纳马拉混沌离子整场只打10万伤害，反小火力也极低，敌方小船从头活到尾
- 敌方没带玉衡C维修小船时战损已经很低，带玉衡C维修小船战损会更低
- 蓝图不好必须用巡洋舰直射时，应放弃全力反小，集中火力走超斩
- 巡洋舰直射面对开阳和瑶光本身是劣势，自身反小火力不强，不应硬冲
- 集中火力打敌方大船，打不赢也换战损，打炸大船后小船好清
- 刺水母好处是无视站位直接打大船，规避瑶光克制
- 重卡虽易被防空锥子拦截，但伤害比康纳马拉混沌离子高
- 敌方战巡在前排、防空锥子在中排时，重卡伤害还可以，值得赌一把
- 蓝图不好的玩家只要能打伤害，什么配置都行
