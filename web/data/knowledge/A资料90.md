# A资料90

## 场景 / 对手
当前版本，古神星级三个型号的运用，涉及载机携带、对空优、续航、辅助类舰船配合，以及前期打野怪和空战/对舰场景

## 舰队例子
- 古神星级主型号 + 凌霄或小米（载机）（胜）【对空优效果不错，入舱维修提升持续输出】
- 古神星级支援型 + 诺玛奶等奶船（胜）【作为66下位替代，提升续航】
- 古神星级战术型号 + 大帝（胜）【辅助类舰船不齐全时上场，命中提升对单发高但命中差的舰船明显】
- 古神星级 + 新人星 + 斗牛（胜）【前期打野怪战损比最低】
- 古神星级 + 维塔斯A（胜）【降低对方回家舰船数量，从战损角度考虑】

## 结论思路
- 主型号适合携带载机，尤其对空优类舰船有入舱维修效果，提升持续输出
- 支援型是66的下位替代，配合奶船可增强续航
- 战术型号在辅助舰船不全时配合大帝，提升命中效果
- 配合新人星和斗牛，前期打野怪战损比最低
- 载机选择多样：小米防空、凌霄对舰/空战、维塔斯A降低战损
- 前中期以携带载机为主，蓝点推荐100蓝点
- 主型号前期使用后可转型支援型，在六路奶未出前配合肉船

## 适用限制
- 适用于前中期，后期可能需转型
- 支援型需配合奶船才能发挥效果
- 战术型号仅在辅助类舰船不齐全时使用
- 载机选择需根据场景（防空/对舰/空战）调整
