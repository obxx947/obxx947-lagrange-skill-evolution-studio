# A资料276

## 场景 / 对手
当前战场环境，光锥防空限制，无拦截限制时输出，新手养成

## 舰队例子
- 大帝级 + M2（反大能量鱼雷）+ A1（反大实弹导弹）+ C3（命中加成）+ D1（防空导弹）（胜）【毕业配置，A1输出占80%以上，C3提供命中，D1用于防轰炸】
- 大帝级 + M1（反大力子炮）+ A2（反小导弹+反大能量导弹）+ B1（反小火炮）+ C1（附加能源）（负）【M1被开阳克制，A2伤害低于A1，C1对A系统无加成，不推荐】

## 实战结果
大帝级在无拦截时输出优于风暴，但遇拦截哑火；无装甲模块不能扛伤；新手易养成

## 结论思路
- M模块选M2，M1被开阳克制
- A模块选A1，暴击策略使伤害远超A2，占输出80%以上
- B模块按需选B1（反小直射）或B3（防空拦截），B2防空不如B3
- C模块选C3（命中），使A1可全点伤害冷却暴击，C2鸡肋不如其他舰载机模块
- D模块选D1（防空），D2/D3无扛伤需求不选
- 点数紧缺时E系统可不装模块省蓝点

## 适用限制
- 遇拦截时输出受限，不适合对抗拦截体系
- 无装甲模块，不能作为扛伤战巡
- 适合新手低成本养成，在无拦截环境发挥优势
- 面对重甲舰输出吃力
