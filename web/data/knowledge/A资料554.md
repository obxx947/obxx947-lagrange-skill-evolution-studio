# A资料554

## 场景 / 对手
25级野怪，800人口，正面战斗，环境为野怪明牌

## 舰队例子
- 矛（6条，含模块）（负）【带6条矛过多，实际抗伤只需2条，其余浪费人口】
- 矛（2条，含模块）+ 输出船（如星脉、蜂巢、蓝蝴蝶、大帝）（胜）【2条矛足够抗伤，输出靠后排，5-7分钟内解决】
- CV3000（5台，带维A绝育模块）（负）【绝育系统触发不稳定，需确保全部绝育才能防残血闪避】
- 太阳鲸（含回血模块）+ 谷神星（回血）（胜）【提供回血，维持前排血量，但需输出足够】

## 实战结果
玩家模仿零损阵容但配置不当，导致战损；正确配置为2条矛+输出船，可零损或低损取胜

## 结论思路
- 矛在阵容中仅用于抗伤，最多带2条，多余人口应换输出
- 前排坦度由后排输出决定，输出足够才能快速清敌
- 带奶需与输出匹配，否则奶量被输出抵消，无意义
- CV3000需带维A绝育，且确保全部绝育才能防残血闪避
- 空军需有回血支持（如太阳鲸或谷神星），否则易被击落
- 模仿阵容要理解每艘船的作用，而非盲目复制

## 适用限制
- 适用于25级野怪，800人口环境
- 需有毕业矛（含模块）或类似抗伤船
- 输出船需正确加点，否则伤害不足
- 不适用于无回血或输出不足的阵容
- 需根据敌方配置调整，避免带过多无用船
