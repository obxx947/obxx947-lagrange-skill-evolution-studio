# A资料554 · 25级野怪阵容思路纠错

> 场景：25级野怪

## 结论
- 借鉴阵容要理解每艘船的作用，不能只抄配置不抄思路
- 乌拉诺斯之矛（原文为"矛"，疑似简称）在此阵容中唯一作用是抗伤，最多带两条
- 前排坦度由后排输出能力决定，输出够快则两条矛足够抗伤
- 800人口野怪前排最多出伤100万对舰伤害，继续堆前排没有意义
- 不带矛省下的人口应全部做输出
- 残血新君士坦丁大帝级输出最高，是输出首选
- 超斩体系用于压血线，列维、星脉、蜂巢、蓝蝴蝶都是压血线手段
- 出伤速度要求高，7分钟打不完就撤退
- 护航艇体积庞大后蜂巢和星脉才能输出，时间线拉长星脉输出很恐怖
- 星脉整分钟有一轮小爆发，策略很关键
- 星脉活不久，要尽可能保护
- 带海尔波普回血与矛需要血线填充的思路自相矛盾
- 带奶的前提是输出足够让对面输出下降，否则奶量跟不上对面出伤
- CV3000级的作用是残血闪避，必须带满维塔斯A021做残血闪避
- 绝育系统带五台维塔斯A021不够，绝育效率太低
- 动力系统要打掉两次才会完全爆炸，不能赌25秒CV3000级自我修复
- 必须让对面CV3000级全部绝育，才能阻止残血闪避触发
- 虚灵是导弹艇，CV3000级能拦截，不如带蜂巢
- 对面小米和T800没有超锁，空军正常能顶住
- 没有太阳鲸时可用谷神星级制造回血
- 矛最多带两条，其他人口换输出船
- 输出船放后排也是输出，不一定非要放前排
- 泡泡龙等能输出的船都比多余的矛伤害高
- 奶矛在队伍中不合适，改成两条或三条才可能合适
- 废物人口太多需要清理
- 不做超斩且不带蓝无敌时，狩猎者级不如谷神星级
- 狩猎者级只是为了带小米和林鸮A100型-联合攻击机（原文为"凌霄"，疑似语音识别错误），没有其他意义
- 模仿零损过25级阵容要理解每艘船的作用，不能盲目抄袭
- 没有风暴或大帝也能打，作用相同的船可以替换

## 配队与模块
- 乌拉诺斯之矛：最多带两条，用于抗伤
- 新君士坦丁大帝级：残血输出最高，作为输出核心
- CV3000级：残血闪避，需带满维塔斯A021
- 维塔斯A021：带满用于残血闪避和绝育
- 蜂巢守卫者：护航艇输出
- 星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）：护航艇输出，整分钟小爆发
- S-列维9号：压血线
- 谷神星级：提供回血
- 海尔波普：回血与矛血线填充思路矛盾，不建议带
- 虚灵：导弹艇会被CV3000级拦截，不如蜂巢
- 狩猎者级：不做超斩且不带蓝无敌时不如谷神星级
- 泡泡龙：可替换多余矛的输出船

## 数值与数据
- 野怪前排最多出伤100万对舰伤害
- 一条矛约30万血量
- 5分钟到5分半可结束战斗
- 最多7分钟，7分钟打不完就撤退
- 维塔斯A021只带五台绝育效率不够
- 动力系统需打掉两次才会完全爆炸
- CV3000级自我修复时间25秒
