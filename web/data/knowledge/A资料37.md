# A资料37 · 主流奶船奶量数据与运用

> 场景：轰炸主导环境

## 结论
- 单位人口每分钟奶量排名：谷神星级-支援驱逐舰（原文为"古神"，疑似语音识别错误）与CAS066级-支援巡洋舰（原文为"六六"，疑似简称）并列第一
- 诺玛M470级-支援护卫舰（原文为"洛马"，疑似语音识别错误）总人口仅90，奶量超过卫士-支援驱逐舰（原文为"卫生奶"，疑似语音识别错误）和苔原级-战术驱逐舰（原文为"台源"，疑似语音识别错误）
- 小船奶优点：造价低、补充快、兼顾防空、奶量专一
- 小船奶缺点：续航较差、奶量较低
- CAS066级-支援巡洋舰优点：高维修量、高持久续航
- CAS066级-支援巡洋舰缺点：没防空、造价高、成型慢、奶量不稳定、更容易战损
- 小船奶的优点是CAS066级-支援巡洋舰的缺点，反之亦然
- 推荐小船奶与CAS066级-支援巡洋舰混编，单一配置行不通
- 没有CAS066级-支援巡洋舰时，拉满小船奶总体奶量与12个CAS066级-支援巡洋舰相近，但续航更差
- 有CAS066级-支援巡洋舰也不要盲目拉满，会导致扛线能力不稳定
- 光锥级-区域防空巡洋舰（原文为"光防"，疑似简称）防空能力不优秀，主要特点是拦截，靠它防空行不通
- 光锥级-区域防空巡洋舰也是大船，会抢奶量，造价同样不低

## 配队与模块
- 测试对象：谷神星级-支援驱逐舰、CAS066级-支援巡洋舰、诺玛M470级-支援护卫舰、卫士-支援驱逐舰、苔原级-战术驱逐舰
- 靶船选择ST59级-防御战列巡洋舰（原文为"五九"，疑似简称），可吃到150%维修加成
- 小船奶在舰队存在超主力时，奶量全部给超主力
- 苔原级-战术驱逐舰防空输出比肩米斯特拉-战斗攻击机（原文为"小米"，疑似简称）
- CAS066级-支援巡洋舰可造12个，谷神星级-支援驱逐舰只能造10个
- CAS066级-支援巡洋舰在维修序列中与大船平等，可能不奶超主力
