# A资料265

## 场景 / 对手
刷野区第一阶段，打海盗（红圈垃圾、督察中队、收集中队、二十级海盗）

## 舰队例子
- 五队打十字级海盗的配置（具体船和模块未提及）（胜）【用于同时打四个十九级海盗】

## 实战结果
打海盗时，直接点督察中队会先撞上收集中队，打完收集中队后督察中队逃跑；盲视野点垃圾回收时，随机接战，打督察中队概率略大，但可能先打收集中队导致督察中队逃跑

## 结论思路
- 先打督察中队，避免先打收集中队导致督察中队逃跑
- 正确做法是调动到督察中队旁边再点它
- 盲视野点垃圾回收可省时间省策略，但随机接战，有损人风险，不推荐
- 二十级海盗由四个十九级和一个二十级组成，需先打四个十九级
- 没有五队配置就不要碰二十级海盗，否则会炸船
- 十四级海盗可打，控完五级城后再处理二十级海盗

## 适用限制
- 适用于刷野区第一阶段
- 打二十级海盗需至少五队配置，否则避免
- 盲视野打法不推荐，可能损人利己
