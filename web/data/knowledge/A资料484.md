# A资料484

## 场景 / 对手
针对D赛级航母策略加点争议，涉及护航/轰炸体系、电焊队（康纳离子+高速I）实战环境

## 舰队例子
- D赛级航母（点策略：关闭其他武器、每轮+4伤害、延长射击时间、命中率+35%、持续时间加满、冷却时间上限20%）+ 康纳离子（泡泡龙）+ 高速I（8个）+ 基础I（增援6个）（胜）【强调策略必点，用于火力覆盖，高单发高频率】
- 基础AO（点策略）+ 高速AO（胜）【无高速AO时建议点基础AO策略，提升频率和命中】
- 列兵、列为九号、普卡、重卡（负）【列为九号三发鱼雷怕拦截，一分钟仅一发，伤害低，不推荐】

## 实战结果
玩家主张D赛点策略，反对者认为不点策略打小船；玩家反驳称护航/轰炸环境必须点策略，并指出电焊队（8康纳离子+8高速I+6基础I）实战中前排毛子30-50秒掉，矛盾放中排，泡泡龙点策略后打前排毛和中排毛有效

## 结论思路
- D赛级航母策略必点，关闭其他武器、每轮+4伤害、延长射击时间、命中率+35%，收益高
- 泡泡龙是高单发高频率箭船，作为火力覆盖，策略加点后持续一分钟更香
- 基础AO策略必点，尤其无高速AO时，提升频率和命中
- 电焊队配置：8康纳离子+8高速I+增援6基础I，矛盾放中排，避免前排过早损失
- 不推荐带列兵、列为九号、普卡重卡，怕拦截且伤害低

## 适用限制
- 适用于护航或轰炸体系，非小船对抗场景
- 需要点策略才能发挥高伤害，不点策略收益低
- 电焊队需配合高速I和基础I，否则效果差
- 列为九号等鱼雷舰在拦截环境下无效，避免使用
