# A资料165

## 场景 / 对手
天书航母培养流程

## 舰队例子
- 天书航母+第二装甲模块+点满装甲（胜）【血量45万，护甲与能量抗性提升，维修增益超100%，小毕业】
- 天书航母+C2附加维修模块（胜）【毕业，抗性如大毛，维修量超六六奶】
- 天书航母+B1载机模块+A3维修模块（胜）【彻底圆满，战斗力巅峰】

## 实战结果
天书航母从普通到毕业，克老之下无敌

## 结论思路
- 天书航母初始普通，维修量、载机、抗伤均一般，勉强可用
- 第二装甲模块是关键，点满后血量45万，抗性提升
- C2维修模块使维修量超六六奶，抗性如大毛
- 补齐B1和A3模块后彻底圆满，战斗力巅峰

## 适用限制
- 需要航母点数和装甲点满
- 需要抽到第二装甲模块、C2维修模块、B1载机模块、A3维修模块
- 适合有实力抽满模块的玩家
