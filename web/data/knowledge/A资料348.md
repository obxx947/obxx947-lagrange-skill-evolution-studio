# A资料348

## 场景 / 对手
大毛与平民舰队对比，涉及抗伤副队、大盾旗舰、输出战士配置

## 舰队例子
- 大毛（主扛战型）+ 大盾（旗舰）（负）【扛伤能力不如大盾，造价高，需分点给大盾旗舰】
- 单大盾（附加主播推荐）（胜）【适合平民，剩余资源养输出战士】

## 实战结果
大毛对平民不友好，因扛伤弱且贵，实战中不如大盾，仅适合高达、抗伤队

## 结论思路
- 大毛扛伤能力不如大盾，造价更高
- 抗伤副队刚需大盾旗舰，大毛主扛需额外配置大盾
- 平民推荐单大盾，剩余资源养输出战士
- 大毛仅适用于高达、抗伤队

## 适用限制
- 适用于有高达或抗伤队需求的玩家
- 平民玩家不建议使用大毛作为主扛
- 需大盾旗舰时，大毛性价比低
