# A资料261

## 场景 / 对手
讲解维A战斗机及系统伤害、暴击伤害底层逻辑，涉及超主力舰战斗和反小作战

## 舰队例子
- 维A战斗机，主武器投射导弹，加点：命中、反拦截、单发伤害、暴击率、暴击伤害，动力系统策略点满（胜）【适合打超主力舰，利用系统保底伤害】
- 凌霄战斗机，指挥系统策略（胜）【可重复打系统四次，保底伤害高】
- 新大地战斗机，武器/指挥系统策略（胜）【系统伤害超标】
- 050南十字战斗机，反小策略（胜）【基础面板高，命中率高，适合反小】

## 实战结果
维A打超主力舰，利用系统保底伤害，几胜几负未提及；关键得失：系统伤害保底，暴击伤害依赖单发伤害

## 结论思路
- 系统伤害是保底伤害，按目标总结构值上限计算，打高血量目标收益高
- 暴击伤害基于单发伤害，单发伤害越高暴击收益越大
- 维A适合打超主力舰，点满动力系统策略提升保底伤害
- 反小可用维A但浪费超展优势，推荐用050南十字等面板高的舰载机
- 凌霄、新大地等系统船因系统伤害而超标

## 适用限制
- 维A打系统伤害时，目标血量越高收益越大
- 反小场景不推荐维A，除非基础面板足够
- 暴击流需要点满单发伤害和暴击相关强化
- 系统伤害策略对低血量目标效果差
