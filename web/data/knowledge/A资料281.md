# A资料281

## 场景 / 对手
SP实战视频，快速控制三级城，二阶段/三阶段，对手为三级城守军，正面作战，环境为矿区附近

## 舰队例子
- 赤瑶（主武器策略，护甲1防守+3血量，动力1闪避，指挥可选）+ 鱼（不点锁敌，用于触发赤瑶策略）+ 顿 + 零六六 + 泡泡龙（1鱼+3泡泡龙或2鱼+2泡泡龙）+ 登录舰（11个以上，可用水母和落马补充）（胜，赤瑶扛伤40多万，鱼维修46万，几乎不掉船）【人口低，不需增援，分三或四队】

## 实战结果
玩家用低人口舰队（约300人口）控制三个三级城，分四队（含一队碰瓷控30万对空），一个半小时完成，几乎无损失

## 结论思路
- 迁移到离三级城最近的矿区，建哨站便于直达
- 赤瑶保护小船，大盾吃反大伤害，赤瑶吃反小伤害
- 鱼不点锁敌以触发赤瑶策略，拖长时间提升赤瑶肉度
- 登录舰数量需大于作业宽度（10），至少11个
- 分基地编队，人口低不需增援，节省策略
- 喷流退后撒300，边撒边控

## 适用限制
- 适用于11鱼配置，CV无法购买赤瑶，不适用
- 锁敌机制仅用于纯扛伤，实战需点满锁敌兼顾输出
- 适用于三级城，比副本对剑武略强
