# A资料504 · 护航组队出兵结构解析

> 场景：护航组队/主队

## 结论
- 直射武器按前排到后排顺序打击，低闪避目标出伤稳定但素质高
- 前排残血后撤机制会让直射伤害容易变成无效伤害
- 曲射武器可无视站位直接打击序列内目标，不受后撤机制干扰
- 曲射武器存在被拦截的风险
- 空军出伤主要直接打击区域内目标，不受武器类型影响
- 空军只在面对拦截时有武器类型之分
- 实弹伤害会被物理护甲减少单发，但不受能量护盾影响
- 能量伤害无视物理护甲单发减免，但会被护盾值百分比减伤
- 反小是优先攻击驱逐的伤害，反大是优先攻击巡洋及以上的伤害
- 包展是优先攻击超主力的伤害
- 只有输出航母、没有曲射输出战群的玩家，伤害约80%由直射武器提供
- 只有输出航母的玩家，剩余约20%伤害由超载空军或曲射伤害提供
- 有曲射输出战群但没有苍穹轰炸的主队，60%-70%伤害由曲射输出战群提供
- 有曲射输出战群的主队，约10%人口由超展提供
- 有曲射输出战群的主队，剩余约20%可能补直射伤害或曲射反大火力
- 同时拥有曲射输出战群和C2苍穹的主队，约20%伤害来源于抗争营销提供的破盾伤害提升
- 同时拥有曲射输出战群和C2苍穹的主队，约60%伤害来源于输出战群
- 同时拥有曲射输出战群和C2苍穹的主队，约10%伤害来源于超展
- C2苍穹是陆军分水岭，不光是轰炸强势，作为周围地推副航母也非常强势
- 地推C1苍穹基本没有作用，一般用C2苍穹补挺位
- 护航组队玩家分三级：一级只有输出航母无输出战群，二级有曲射输出战群加输出航母，三级拥有破盾苍穹明霄加曲射输出战群

## 配队与模块
- 只有输出航母的玩家普遍是2.0到1+2质量，可塞狩猎带海氏或猎兵搭载超载护航艇
- 有曲射输出战群的主队普遍由1+2到顶客，上不封顶
- 曲射输出战群代表配置：风暴或斩锥、持剑配合大帝打一个出伤
- 输出矛算直射伤害，不算曲射输出战群
- 雷火算曲射，不讨论
- 常规超展配置：狩猎带海氏
- 曲射反大火力可补重卡之类
- 三级玩家拥有破盾的苍穹、明霄，同时拥有曲射输出战群

## 数值与数据
- 只有输出航母的玩家，队内不含增援时约80%伤害由直射武器提供
- 只有输出航母的玩家，约20%伤害由超载空军或曲射伤害提供
- 有曲射输出战群无苍穹轰炸的主队，不含增援伤害60%-70%由曲射输出战群提供
- 有曲射输出战群无苍穹轰炸的主队，约10%人口由超展提供
- 有曲射输出战群无苍穹轰炸的主队，约20%伤害补直射或曲射反大火力
- 三级玩家约20%伤害来源于抗争营销破盾伤害提升
- 三级玩家约60%伤害来源于输出战群
- 三级玩家约10%伤害来源于超展
