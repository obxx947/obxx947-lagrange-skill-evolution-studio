# A资料541

## 场景 / 对手
绝育战报解读，飞机/无人机攻击手段，大帝、米斯特拉、ST59、066、艾奥等舰船体系

## 舰队例子
- 米斯特拉（7条）（胜）【对舰伤害14.61，对ST59结构伤害487，对066系统伤害35888，对艾奥系统伤害44588，爆4个系统】
- 刺鳐（胜）【爆系统伤害2万多，总伤害4万多，自身输出能力强】

## 实战结果
米斯特拉对ST59、066、艾奥，刺鳐对敌方，总体胜，关键：绝育伤害低，需破甲或高暴击

## 结论思路
- 战报中括号外伤害为结构伤害，括号内为系统伤害，系统伤害无护甲，易暴击
- 绝育船（如米斯特拉）主要打系统，结构伤害低，需破甲才能有效输出
- 系统伤害高代表刮痧速度快，暴击伤害提升，VA加点推荐双爆伤
- 真实有效伤害需剔除系统伤害，绝育伤害溢价严重
- 绝育船若自身输出强（如刺鳐），可兼顾津贴和实际伤害

## 适用限制
- 适用于解读绝育战报，理解伤害构成
- 绝育船需破甲或高暴击才能发挥效果
- 不破甲时伤害低，仅靠系统伤害难以造成大量结构伤害
- 不适用于非绝育体系或对护甲高的目标
