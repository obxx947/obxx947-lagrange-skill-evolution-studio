# A资料247

## 场景 / 对手
输出战群体系，正面输出，环境为常规PVP

## 舰队例子
- 大地（白板）+ A1模块（投射反大武器）+ 策略连上 + M2/C2模块（胜，输出高，但怕拦截）【适合新手，低散玩家无拦截时伤害极高】
- 风暴 + M2模块 + A2模块（优先）或A3/A1 + C模块（扛伤）（胜，输出稳定，不怕拦截）【输出略低于大地，但稳定；C3抗性提升强，C2为多战巡提供能量护盾】
- 大剑 + AR模块（核心）（胜，输出提升显著）【A2策略可指挥其他武器打击血量最低船，绕开前排】
- 雷火（无剑）（负，输出受限）【只能打前排，被太阳拦截，无法打到超主力】

## 实战结果
大地对低散玩家胜率高，但遇拦截无输出；风暴稳定输出；大剑提升输出；雷火被前排克制

## 结论思路
- 大地白板+A1点满+策略连上，输出可达金大地70%，适合新手
- 大地怕拦截，适合无拦截环境
- 风暴输出稳定，不怕拦截，适合替代大地
- 风暴A2最好用，A3次之，A1可用；C模块扛伤，C3抗性提升强，C2为多战巡提供护盾
- 战损多时C2强，反之C3强
- 风暴毕业后用大剑提升伤害，AR模块核心，A2策略打击低血量船
- 雷火输出爆炸但只能打前排，被太阳克制

## 适用限制
- 大地适合新手和低散玩家，但需无拦截环境
- 风暴适合需要稳定输出的场景，不怕拦截
- 大剑需要AR模块，适合已有风暴毕业的玩家
- 雷火不适合对抗有前排拦截的阵容
