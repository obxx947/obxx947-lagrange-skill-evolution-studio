# A资料665

## 场景 / 对手
游骑兵离子型更新后，针对主流配对（开洋前排、战巡中排）的对攻测试

## 舰队例子
- 游骑兵离子型（主炮+副炮，双系统，能量投射鱼雷）（待定）【伤害提升15%，六轮后达100%；主炮直射，冷却减40%，六秒冷却；副炮降低拦截率30%，冷却约12.5秒，打击周期20秒】
- 泡泡龙（离子体巡洋舰，单系统）（对比）【启动较慢，副炮冷却长，伤害频次为游骑兵一半】

## 实战结果
测试服对比，游骑兵离子型与泡泡龙对掏，具体胜负未定，以正式服为准

## 结论思路
- 游骑兵离子型伤害提升15%，六轮后满伤，启动快于泡泡龙
- 主炮直射，冷却减40%，六秒冷却，类似艾奥基础型
- 副炮降低拦截率30%，必点，针对中排光防效果好
- 双系统优于泡泡龙单系统，能量投射鱼雷可观
- 副炮打击周期约20秒，类似加长版七二幺离子炮

## 适用限制
- 适用于反大、优先巡洋级别目标
- 针对中排光防或盘古时效果显著
- 具体性能需正式服验证，测试服数据仅供参考
