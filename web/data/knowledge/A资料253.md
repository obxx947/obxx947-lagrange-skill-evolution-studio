# A资料253

## 场景 / 对手
拉格朗日舰船讲解系列，针对海氏中型战机，对手为1+1奶盾，正面作战，环境为超展体系

## 舰队例子
- 海氏战机（8个，占2位置）+ 狩猎母舰（2个，满配）（胜）【海氏打24.5万伤害，高于维A、次摇、零五零；狩猎提供5个buff加成】
- 海氏战机 + 南十字母舰（提供6个buff）（胜）【伤害与狩猎相近，约2-3万，暴击影响波动；长时间作战加成更高】

## 实战结果
打对面1+1奶盾，海氏8个造成24.5万伤害，优于同期超展维A、次摇、零五零；测试中狩猎和南十字载机伤害相近，南十字略高

## 结论思路
- 海氏是超展核心，需配合有锁敌冷却加成的母舰（如狩猎、南十字）才能发挥实力
- 加点建议：命中不点，加暴击并点满50%暴击伤害，实测提升明显
- 主武器为主动防空，不改锁敌会打护航艇登陆舰，导致对空无效，需填坑
- 锁定时间未点18秒，点满仍12.6秒，无母舰加成时输出延迟大
- 2.0以下玩家不建议带，点数不足；2.0-2.7优先养，围B、围A、050之后首选海氏
- 2.7-1+2阶段，配合巡洋或足够飞机数量，海氏作为超展核心效果佳
- C2轰炸时放仓库可用，无锁敌问题，持续输出，但需加点减伤防脆
- 2+2及以上，地位与050相当，050怕拦截，海氏怕转火，优先级在围A后因围A能绝育

## 适用限制
- 必须搭配有锁敌冷却加成的母舰，否则输出延迟大
- 不改变锁敌会打护航艇登陆舰，需调整
- 2.0以下玩家点数不足，不建议使用
- 怕转火，需注意战场保护
- 轰炸时需加点减伤，否则易损
