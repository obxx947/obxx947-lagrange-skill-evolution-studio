# A资料549

## 场景 / 对手
护航体系（新手到顶级阶段，含对手/体系/正面或轰炸/环境）

## 舰队例子
- 白板大帝（战巡，反大蛮命重，正确加点后与有无人机加成的大船相当）（胜（推荐新手首选））【白板可用，无需模块，适合新手；其他战巡需点数和模块堆积，成本高】
- 卡里斯托（20人口，输出占15-16人口）（胜（推荐作为输出））【后排输出船，人口利用率高，浪费少】
- 艾奥（18人口，输出占12人口）（负（不推荐作为输出））【前排船，人口含抗伤/闪避成分，输出浪费6人口】
- 列阵列（防空型/通用型/战术型）（胜（通用或战术型适合输出））【防空型占防空人口，不适合输出；通用有反小趋势，战术有对空命中加成】

## 实战结果
无具体实战记录；强调护航队坦度决定输出时间，输出能力弱则夹击无效

## 结论思路
- 护航不是简单的玻璃大炮加奶毛队，而是提供保护罩，新手也能受益
- 区分输出船和扛伤船：看人口分配，前排船无输出船，输出在后排找
- 新手阶段从大船（战巡）开始选，优先选白板大帝，因白板可用且反大蛮命重
- 战巡养成成本高，普通玩家一年内玩不起，模块选择不必纠结
- 先有输出再考虑抗伤，后排输出能力决定前排坦度
- 护航和solo一体，坦度决定输出时间，输出弱则夹击无意义

## 适用限制
- 新手阶段（一台航母和一台战舰）适用白板大帝
- 中期（两台战巡或航母）可参考第二套公式
- 顶级阶段（多战巡/航母）适用第三套公式
- 不推荐用艾奥或防空型列阵列作为输出
- 战巡需点数和模块堆积，白板无战斗力
