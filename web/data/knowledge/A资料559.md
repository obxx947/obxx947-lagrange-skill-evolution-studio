# A资料559

## 场景 / 对手
满课护航队，三航母+雷神之星，顶克玩家对战，第二阶段护航对第三阶段护航

## 舰队例子
- 雷神之星（输出战群）（胜）【对单目标持续输出，约20万伤害，适合当前奶包护航环境】
- 风暴（输出战群）（胜）【稳定输出，16-18万伤害，推荐主力】
- 大地（输出战群）（胜）【输出依赖条件（高护甲、拦截、残血），10-12万伤害，适合收尾】
- 剑（输出战群）（胜）【输出不高但有效，专注单目标，所有伤害均为有效输出】
- 维B十三余（副队）（胜）【靠回血生存，对空军伤害低，适合副队】
- 太阳精（副队）（胜）【血厚，不惧伤害，可吸引火力】

## 实战结果
右边玩家（第二阶段护航）被左边（第三阶段护航）全灭，左边损失一条CP3000，人口优势（780对680），血量近乎一倍，碾压性胜利

## 结论思路
- 护航分阶段，顶克阵容有当下最强配置，差距随刻度拉大
- 第三阶段护航（多航母+超主力）碾压第二阶段，血量坦度优势明显
- 奶毛光追为核心的阵容无法突破CV3000的坎
- 副队输出能力重要，盾对主队减伤但副队不减，维B十三余适合副队
- 雷神之星是靶击输出最高战群，适合当前奶包环境
- 剑输出不高但有效，专注单目标
- 风暴稳定输出，大地依赖条件，推荐风暴和雷神为主，大地收尾
- 推荐配置：3雷神+6风暴+2大地

## 适用限制
- 适用于满课或顶克玩家，低课可能不适用
- 当前环境以奶包护航队为主，雷神和风暴更优
- 大地需特定条件（高护甲、拦截、残血）才能发挥
- 副队需有回血能力，如维B十三余
- 仅针对护航模式，solo可能不同
