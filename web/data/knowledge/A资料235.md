# A资料235

## 场景 / 对手
主星系，抗伤队，光防盾体系，正面作战

## 舰队例子
- 大地（主武器未导弹，中排）（负）【主武器未导弹，难以突破光防盾，策略低血量时无法有效爆杀】
- 棕熊C（小拦截）（负）【小拦截仅在前期有效，后期作用有限】

## 实战结果
大地在主星系对抗光防盾体系，表现不佳，已沦为时代眼泪；棕熊C小拦截前期可用，后期失效

## 结论思路
- 大地最大问题是主武器未导弹，导致对光防盾体系输出不足
- 抗伤队普遍使用光防盾，中排难以触发低血量策略，爆杀能力受限
- 棕熊C的小拦截只在前期有作用，后期需更换或升级

## 适用限制
- 适用于主星系环境，对抗光防盾体系时大地表现差
- 不适用于后期高防盾战斗，棕熊C小拦截不宜长期依赖
