# A资料619

## 场景 / 对手
游戏内舰队配置思路，涉及直射、投射（超斩）及混编体系，讨论正面战斗和轰炸环境

## 舰队例子
- 风暴断奶 + 超斩火力（投射/超斩体系）（胜）【克制前排小船、中排战巡扛伤配置，超主力少时断奶成功率高，能快速打出战损】
- 纯直射队（混沌、艾奥、狂暴毛等）（胜）【输出总量高，需维A、次幺零、五零、八百星脉反小，针对高闪避前排】
- 直投滚边（风暴配混沌）（负）【火力分散，打战损困难，面对前排小船、中排战巡配置优势不明显】

## 实战结果
风暴超斩思路克制前排小船、中排战巡扛伤配置，但面对高达挑战队输出不足；纯直射队对高达抗伤配置有优势，但面对高闪避小船换战损亏；直投滚边在蒙战中有优势但战报难看

## 结论思路
- 纯投射或超斩思路：核心是风暴断奶配合超斩火力点杀超主力，需大量投射反大火力，在断奶空档期打出战损
- 纯直射思路：追求直射火力贯穿前排，需反小配置解放火力，输出总量高于投射队
- 直投滚边思路：追求极致数值，但火力分散，打战损困难
- 蒙战中各思路差距不大，靠人数和意识，但推荐风暴超斩思路，能给对面资源造成压力

## 适用限制
- 风暴断奶存在概率，非百分之百成功
- 投射武器受拦截限制，可选不多，可能降低总伤害
- 直射队面对高闪避小船时换战损亏，需反小配置
- 直投滚边面对前排小船、中排战巡配置优势不明显
- 直射和投射思路不意味着放弃优质输出，输出是前提
