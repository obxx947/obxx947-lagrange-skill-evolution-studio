# A资料619 · 输出配置思路：直射投射混编

> 场景：输出体系；盟战（原文为"蒙战"，疑似语音识别错误）

## 结论
- 输出方式分直射和投射，投射含超斩，衍生三种思路：纯投射/超斩、纯直射、直投混编。
- 纯投射/超斩核心为服务永恒风暴级：用断奶配合超斩火力，在断奶空档期斩掉超主力。
- 纯投射/超斩面对小船更简单，可顶着对面小船打掉战巡；但永恒风暴级断奶有概率，不是百分百成功。
- 纯投射/超斩克制前排小船、中排战巡扛伤配置，断奶成功率高，更易打战损。
- 纯投射/超斩面对高达抗伤队（原文为"高达挑战队"，疑似语音识别错误）输出不足，必须大量投射火力。
- 受拦截限制可选投射武器不多，常被迫放弃高输出舰船或航母，总伤害不高。
- 敌方超主力多时永恒风暴级断奶失效，总伤害不足，战损能力难保证。
- 纯直射输出总量高于投射队，直射武器输出普遍高。
- 纯直射核心是堆大量直射火力，以最快速度贯穿前排，攻击后方高价值目标。
- 前排多为高闪避小船（尤其更新后木星原户策略+吸尘器双型号），需用飞机反小并针对吸尘器闪避/动力系统。
- 只有飞机承担反小，直射火力才能最快解放出来打战损。
- 对方前排全小船时直射打战损能力差，换战损亏。
- 对方是高达抗伤队时直射总伤高，更易打战损并更快消灭副队。
- 直投混编无固定思路，追求极致数值，谁输出高用谁，常见永恒风暴级配混沌。
- 直投混编各打各的：永恒风暴级打大船无集火杀不死，混沌被前排拖住，战报常是残血不死。
- 直投混编面对前排小船、中排战巡扛伤配置火力分散，数值高但打战损费劲。
- 盟战中输出高的一方有优势，包夹更痛、对手跑更快，但直投混编战报难看。
- 三种思路各有利弊，盟战实际差距不大，靠人数、意识和队友支援；太阳鲸也架不住维欧。
- 个人更推荐永恒风暴级超斩思路，能给对面资源造成较大压力。
- 直射队和混编队输出更高，但对手会跑或撤退，优势不能完全发挥。
- 玩直射/投射不能放弃优质输出；不管什么配置，输出是前提。
- 玩直射也不能不上维塔斯-B010-轰炸机（原文为"围蔽"，疑似语音识别错误）、海氏追随者型-脉冲攻击机（原文为"海市"，疑似语音识别错误）。

## 配队与模块
- 纯投射/超斩：永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）（断奶）+超斩火力+大量投射反大。
- 纯直射高输出直射舰：混沌、艾奥、乌拉诺斯之矛（原文为"狂暴毛"，疑似语音识别错误）（狂暴矛）。
- 纯直射反小飞机：维塔斯A021-重型攻击机（原文为"维a"，疑似简称）、AT021（原文为"次幺零"，疑似语音识别错误）、BR050（原文为"五零"，疑似语音识别错误）、CV-T800型-脉冲炮艇（原文为"八百"，疑似语音识别错误）、星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）。
