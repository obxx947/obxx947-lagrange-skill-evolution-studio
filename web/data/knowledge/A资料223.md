# A资料223

## 场景 / 对手
扛伤队配置讨论，涉及分伤机制、巡洋舰与驱逐舰对比

## 舰队例子
- 巡洋舰（未指定模块）+ 战群（未指定）（负）【巡洋与大型船同优先级，敌方集中攻击，奶团来不及奶，伤亡高】
- 驱逐舰 + 战群（未指定）（胜）【敌方攻击目标分散，伤害分摊，船炸得慢，奶船来得及奶】
- 巡洋舰（充当大船）+ 小船（如驱逐）（胜）【适用于战群未成型或点数不够的平民，可达到分伤效果】

## 实战结果
未提供具体战报，仅理论分析：巡洋+战群易碎，驱逐+战群更稳

## 结论思路
- 分伤机制：敌方攻击目标分散，伤害分摊，减少单船压力
- 巡洋与大型船同优先级，易被集火，导致快速爆炸
- 驱逐等小船可分散敌方火力，降低伤亡，奶船更易支援
- 巡洋并非无用，可在战群未成型时充当大船，配合小船实现分伤

## 适用限制
- 适用于战群未成型或点数不足的平民玩家
- 不适用于战群已成型且点数充足的情况，此时巡洋可能不如驱逐分伤效果好
- 需注意敌方攻击目标分配机制，确保小船能有效分散火力
