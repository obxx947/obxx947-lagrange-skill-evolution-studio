# A资料411

## 场景 / 对手
矛盾队配置与思路

## 舰队例子
- 大毛（附加装甲模块）+ 开阳（少量）+ 零六六（八个）（胜）【大毛前排抗伤，开阳分散锁定，零六六支援】
- 中牌（附加盾）+ 零六六支援 + 光防（胜）【中牌提供减伤，光防拦截】

## 结论思路
- 矛盾队利用矛（大毛）前排抗伤和盾（中牌）减伤策略
- 大毛附加装甲模块提供高额物抗和维修加成，适配零六六支援
- 中牌附加盾提供780物抗、30能抗，大毛被击毁后逆境卫士提升为前排
- 配置少量开阳避免第一轮被索姆河锁定

## 适用限制
- 适用于需要前排承伤的正面战斗
- 依赖大毛和中牌的模块，需确保模块齐全
- 不适用于缺乏零六六支援或光防拦截的环境
