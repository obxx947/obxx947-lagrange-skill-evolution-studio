# A资料325

## 场景 / 对手
绝育机制讲解

## 结论思路
- 绝育指攻击敌方舰船系统导致损坏，不同系统损坏效果不同
- 四种可损坏系统：主武器系统、动力系统、指挥系统和主机护系统
- 任何系统损坏都会损失5%血量
- 主武器系统损坏使武器丧失攻击能力，可自行维修最多两次
- 动力系统损坏后舰船不能避险，这是VA成为矿车杀手的原因
- 矿车正常不炸，血量耗尽后避险，动力系统损坏可导致矿车爆炸
- 应对方法：让矿车呲血，使其立即避险，不给绝育机会
- 指挥系统损坏导致旗舰技能失效，若技能无关紧要则影响不大
- 主机库损坏可能影响飞机工作，但主播不确定

## 适用限制
- 动力系统损坏机制适用于矿车等可避险舰船
- 指挥系统损坏影响取决于旗舰技能的重要性
- 主机库损坏效果待验证
