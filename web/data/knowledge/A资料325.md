# A资料325 · 绝育机制与系统损坏解析

## 结论
- 绝育指攻击敌方舰船系统导致其损坏
- 可损坏系统共四种：主武器系统、动力系统、指挥系统、主机库系统
- 任意系统损坏都会损失5%血量
- 主武器系统损坏后丧失攻击能力，最多可自行维修两次
- 动力系统损坏后舰船无法避险
- 矿车正常不会炸，血量见底后会避险
- 矿车只有动力系统损坏无法避险时才会炸
- 应对方法：让矿车持续掉血，血量见底立即避险，不给VA绝育机会
- 指挥系统损坏会导致旗舰技能失效
- 旗舰技能可有可无时，指挥系统损坏影响不大
- 主机库损坏效果主播不了解，推测会导致飞机不工作
