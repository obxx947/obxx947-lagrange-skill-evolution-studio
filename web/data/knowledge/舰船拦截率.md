# 舰船拦截率（拦截机制 + 已知单舰数值）

> 机制权威见《战斗机制.md》第五节。本文件只列**资料明确写出数值**的舰船；没写数值的一律没有数据，**不要推测**。

## 一、三种拦截类型（覆盖范围）
| 类型 | 生效范围 |
|------|----------|
| 自身拦截 | 只保护自己 |
| 同排拦截 | 同排友方被攻击时都能拦 |
| 全局/全域拦截 | 全舰队任意船被攻击都拦 |

拦截范围只由初始防空范围决定，不受后天技能影响；加点命中、锁敌对拦截率无影响。

## 二、拦截率计算
- 单舰数值因舰而异：**雷火之星-B2 单舰 27%**、**光锥级防空型 单舰 23%**
- 多舰累乘：`总拦截率 = 1-(1-x)^n×(1-y)^m`（x、y 为不同舰单舰拦截率，n、m 为数量）
  - 大盾 B3：编队 2 艘 24%、3 艘 34%、4 艘 42%、5 艘 50%、6 艘 56% → 反推单舰 ≈ **12.8%**
    （1-(1-0.128)^6 = 56% ✓）
  - 太阳鲸 C3：同排拦截 5%，编队 5 艘约 23%（1-(1-0.05)^5 = 22.6% ✓）
  - 雷火之星 B2：同排拦截 27%，编队 3 艘 61%（1-(1-0.27)^3 = 61.1% ✓）
- 反拦截：`实际拦截 = 基础拦截 ×(1-反拦截率)`（如 30% 反拦截）
- 被拦截后果：`(1-全局)^a ×(1-同排)^b ×(1-自身)`，a=全局拦截舰数，b=同排拦截舰数
- 只有**投射武器**（导弹/鱼雷）会被拦截；**直射武器**（轨道炮/离子炮）不会被拦（永恒风暴 M2 除外）

## 四、其它相关（无精确数值）
- **永恒风暴级（D2 模块）**：高额自身拦截（资料无数值）；大盾 C2、雷火之星 B1 亦无数值
- **光锥级区域防空（光追级）**：同排拦截；前突策略可把防空范围扩到全场，但拦截范围仍是同排
- 拦截是纯概率机制，**不会**因多队攻击而降低，也不会因防空压力大而失效
