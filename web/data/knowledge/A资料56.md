# A资料56

## 场景 / 对手
巡洋舰输出火力测试，模拟实战环境，测试时间3分钟，策略上限测试6分钟

## 舰队例子
- 游骑兵离子型（主武器：通用命中、双冷却、易持续、一策略双伤害；副武器：双伤害、双冷却、一通用命中）（胜）【反大数据17.74万/分钟，单位人口伤害1232；反小数据14.29万/分钟，单位人口伤害992】

## 实战结果
测试游骑兵离子型输出，3分钟数据为巡洋舰中最低，6分钟策略上限输出提升至反大20万/分钟、反小17万/分钟，但实战难以达到；对比混沌离子、重卡等，输出和扛伤均无优势，且火力分散，同时受直射和投射克制，实战表现差

## 结论思路
- 游骑兵离子型主武器策略随时间提升伤害，上限约6分钟，但实战中难以持续，3分钟数据为准
- 副武器策略降低拦截率仅对前排生效，但优先反大，当前环境前排无大船，策略实用性低
- 输出数据在巡洋舰中最低，反大略高于I幺高速，反小不如，但I幺高速用于反小或抗伤，游骑兵无定位
- 火力分散（投射和直射）导致总伤害低且无效输出多，同时被直射分伤和投射拦截双重克制
- 实战中不如使用护卫舰或其他输出舰船，不推荐使用

## 适用限制
- 仅适用于测试环境，实战中战斗时长通常短于6分钟
- 不适用于需要高输出或扛伤的舰队配置
- 当前作战环境前排无大船，副武器策略难以发挥
- 不推荐作为主力输出，仅在没有其他选择时考虑
