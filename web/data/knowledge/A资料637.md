# A资料637 · 体验服风暴C3副队强度

> 场景：体验服；副队实战战报；中排大船队

## 结论
- 体验服调整提升永恒风暴级-攻击战列巡洋舰（原文为“风暴”，疑似简称）的防空伤害，G2与C3模块增强。
- 能量补偿装甲（原文为“C3能量装甲”，疑似简称）新增策略：血量越低能量抗性越高。
- 能量补偿装甲自身可提高能量抗性，并带误伤减免和爆伤减免；加点可进一步提升。
- 改后能量抗性至少超过ST59级-防御战列巡洋舰（原文为“电磁59”，疑似简称），伤害更高且自带拦截。
- 相比安东塔斯持剑者级-指挥舰（原文为“大剑”，疑似简称），永恒风暴级-攻击战列巡洋舰只差血量，血量仍太低。
- 永恒风暴级-攻击战列巡洋舰可进抗伤队。
- 永恒风暴级-攻击战列巡洋舰放副队可避免受普鲁图斯之盾级-防护战列巡洋舰（原文为“大盾”，疑似简称）减伤影响；生存够好则输出有保证。
- 建议永恒风暴级-攻击战列巡洋舰放中排；放前排也可，但需用乌拉诺斯之矛（原文为“大矛”，疑似简称）分摊伤害。
- 永恒风暴级-攻击战列巡洋舰优点：抗性高、有拦截、有输出、有能量抗性。
- 永恒风暴级-攻击战列巡洋舰缺点：血量低；被乌拉诺斯之矛直射实弹打仍很痛；放前排被持续直射扛不住。
- 战报结果：左边赢，右边输。
- 排除普鲁图斯之盾级-防护战列巡洋舰因素：双方炸点接近，其减伤在单挑中很重要。
- 胜负关键：永恒风暴级-攻击战列巡洋舰拉平双方结构值差距；乌拉诺斯之矛维修量拉平双方维修量差距。
- 右边天枢级-支援航空母舰练度、血量、维修量、结构值更高，但仍输。
- 永恒风暴级-攻击战列巡洋舰生存提升后伤害提升，副队伤害高于主队。
- 永恒风暴级-攻击战列巡洋舰副队强度高，当前难处理。
- 永恒风暴级-攻击战列巡洋舰放前排较好处理；对面直射多则扛不住，且无法撤到中排。
- 永恒风暴级-攻击战列巡洋舰放中排不好处理，前排其他船可挡乌拉诺斯之矛直射；投射武器拿他没办法。
- 维塔斯-B010-轰炸机（原文为“VB”，疑似简称）也因能量补偿装甲的高能量抗性拿永恒风暴级-攻击战列巡洋舰没办法，其还能持续输出，有点无解。
- 乌拉诺斯之矛中排生存好。

## 配队与模块
- 双方均为天枢级-支援航空母舰（原文为“天枢”，疑似简称），带干扰机。
- 右边带炮艇。
- 左边：乌拉诺斯之矛、普鲁图斯之盾级-防护战列巡洋舰、永恒风暴级-攻击战列巡洋舰、CAS066级-通用巡洋舰（原文为“66”，疑似简称）。
- 右边：乌拉诺斯之矛、普鲁图斯之盾级-防护战列巡洋舰、光锥级-区域防空巡洋舰（原文为“光防”，疑似简称）、开阳。
- 左边天枢级-支援航空母舰无载机模块，双维修加重甲。
- 右边天枢级-支援航空母舰双载机双维修，A3。
- 永恒风暴级-攻击战列巡洋舰战报中站前排；乌拉诺斯之矛为中排。
- 永恒风暴级-攻击战列巡洋舰带能量补偿装甲（C3）。
