# A资料637

## 场景 / 对手
风暴C3能量装甲调整后，副队实战表现分析，对手为天枢体系，正面战斗

## 舰队例子
- 风暴（C3能量装甲，新增策略血量越低能量抗性越高，最高40%，含G2和C3模块增强）+ 大矛 + 大盾 + 66 + 天枢（A1，双维修加重甲，无载机模块，血量47万）（胜）【副队配置，风暴放前排，大矛分摊伤害，风暴输出164万，生存时间3分23秒至8分26秒】
- 天枢（A3，双载机双维修，血量更高，维修量高）+ 大矛 + 大盾 + 光防 + 开阳 + 炮艇（负）【主队配置，结构值700万，维修量高，但风暴伤害161万，仍输掉战斗】

## 实战结果
左边副队（风暴体系）打右边主队（天枢体系），左边胜，右边负。关键得失：风暴拉平140万结构值差距，大矛奶量拉平维修量差距，右边天枢A3维修量虽高但无法弥补输出不足

## 结论思路
- 风暴C3装甲增强后，能量抗性至少超过电磁59，伤害更高，自带拦截，生存能力提升
- 风暴放副队可避免大盾30%减伤影响，输出有保证
- 风暴建议放中排，若放前排需大矛分摊伤害，否则实弹直射武器打它很痛
- 风暴优点：抗性高、有拦截、有输出；缺点：血量太低，前排扛不住直射
- 风暴副队强度高，放中排难以处理，投射和VB对其效果有限

## 适用限制
- 适用于风暴C3装甲调整后的副队配置，需搭配大矛分摊伤害
- 不适用于前排直面实弹直射武器，血量低易被击毁
- 依赖大矛奶量拉平维修差距，若无大矛则生存能力下降
