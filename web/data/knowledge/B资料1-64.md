# B资料1-64 · 轰炸教学3.0配队与加点

> 场景：轰炸体系；封锁防空普及、航母碰瓷多

## 结论
- 不想上课可直接抄此配置。
- 400人口带3个AC721-重型两栖突击舰（721载机）（原文为"七二幺"，疑似简称）；420人口可补2个到5个。
- 正常旗舰选永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）；视频因苍穹分基地后续增援，旗舰放猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误），不建议学习。
- 没有M3机库可用M1/M2机库；没有M3时M1/M2加点无所谓。
- 索姆河之影-装甲飞行坦克（原文为"索姆河"，疑似简称）不点集群。
- 封锁防空普及使地面防空增强，对轰炸艇秒杀快，索姆河点集群易一尸三命。
- 苍穹C2机库摆放没有很大讲究。
- 猎兵补15个CV-T800型-脉冲炮艇（原文为"八百"，疑似简称）；航母碰瓷多，800可有效杀伤对方防空飞机。
- CV-T800对飞机命中低，但能减轻后续轰炸盟友压力。
- 猎兵剩余艇位全带波次类型挡刀艇，不带多余输出艇。
- 当前轰炸输出高的只有苍穹载艇。
- 挡刀艇分波次类型与序列内类型；波次类型靠加点调整所在波次直接挡刀，序列内类型靠伪装被识别为战机填补机位空缺。
- 其他输出艇转成挡刀艇，为星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）和索姆河之影-装甲飞行坦克增加生存。
- 猎兵波次挡刀艇从天玑A型号（原文为"天机a型号"，疑似语音识别错误）、天玑-攻击护航艇（攻击B型）（原文为"天玑b型号"，疑似简称）、CV-II003型-轻型护航艇（原文为"零零三"，疑似简称）中选两者，按资源决定。
- 天玑A/B血量较厚但生产资源要求高；CV-II003型-轻型护航艇生产资源需求低。
- 721载机携带序列类挡刀艇，推荐RB7-13型-导弹艇（原文为"RB七"，疑似简称）和鳐。
- 苍穹M3机库可带干扰机：SC002型-量子侦察机（原文为"SC零幺二"，疑似语音识别错误）、AT021-战术攻击机-B（干扰型）（原文为"AT零二幺b"，疑似简称），平衡安德森SC020-侦察机（原文为"安德森"，疑似简称）、天璇A-轻型攻击机（原文为"天玄"，疑似语音识别错误）等也可。
- 苍穹M3机库最推荐AT021-战术攻击机-B（干扰型）和SC002型-量子侦察机。

## 配队与模块
- 舰队：5艘永恒苍穹级-无人机航空母舰、8艘猎兵级-重型载机巡洋舰、3艘AC721-重型两栖突击舰（721载机）。
- 420人口时：补2艘AC721-重型两栖突击舰，721载机总数5艘。
- 苍穹模块：C2机库、M3机库、指挥系统；无M3用M1/M2机库。
- 苍穹C2机库：10艘星云追逐者-脉冲炮艇（星脉）、9艘索姆河之影-装甲飞行坦克、1艘CV-T800型-脉冲炮艇。
- 苍穹M3机库：SC002型-量子侦察机、AT021-战术攻击机-B（干扰型）；可选平衡安德森SC020-侦察机、天璇A-轻型攻击机等；最推荐AT021-战术攻击机-B（干扰型）和SC002型-量子侦察机。
- 猎兵：32个艇位；15个CV-T800型-脉冲炮艇；剩余全部波次类型挡刀艇。
- 猎兵波次挡刀艇：天玑A型号、天玑-攻击护航艇（攻击B型）、CV-II003型-轻型护航艇中选两者。
- 721载机：携带序列类挡刀艇，推荐RB7-13型-导弹艇和鳐-装甲护航艇/鳐-特种护航艇（原文为"瑶"，疑似语音识别错误）（鳐）。
- 加点图：苍穹C2机库、M3机库、指挥系统；AT021-战术攻击机-B与SC002型-量子侦察机；星云追逐者-脉冲炮艇与索姆河之影-装甲飞行坦克武器/动力系统；天玑A/B、CV-II003型-轻型护航艇；CV-T800型-脉冲炮艇；猎兵轰炸；鳐与RB7；721载机。

## 数值与数据
- 人口：400带3艘721载机；420可带5艘721载机。
- 舰队数量：5苍穹、8猎兵、3/5个721载机。
- 猎兵32个艇位，其中15个CV-T800型-脉冲炮艇。
- 苍穹C2机库：10星脉、9索姆河、1个800。
- 苍穹M3机库最推荐：AT021-B、SC002；可选安德森、天璇等。
- 天玑A/B与CV-II003型-轻型护航艇选两者。
