# A资料418

## 场景 / 对手
现版本战机卡池，凌霄在苍穹上发挥高伤害，对空优先，对舰优先小船，指挥系统有优先攻击超主力策略

## 舰队例子
- 凌霄联合攻击机（巨能脉冲炮，130基础弹发，能量武器，无法被拦截）+ 苍穹（M1机库，分散攻击策略）（胜）【十个凌霄一分钟出伤7-8万，苍穹M1机库使伤害翻倍】

## 实战结果
凌霄在苍穹上可有效打击超主力和零六六，对空序列优先护航艇，对舰优先小船，通过苍穹策略提升伤害

## 结论思路
- 凌霄必须放在苍穹上才能打出高伤害
- 凌霄武器为能量武器，无法被拦截，优先攻击护航艇和小船
- 指挥系统有优先攻击超主力策略，使其适合主队
- 苍穹M1机库策略使凌霄伤害翻倍，分散攻击策略进一步拉高伤害
- 加点优先提升单发伤害，降低冷却收益最低，降低飞行时间有不错收益
- 凌霄策略不反小，选暴击属性，点伤害和通用命中
- 动力系统点频率、命中和锁敌，剩余空格点闪避策略或闪避加成
- 苍穹M1机库不点冷却，点策略、伤害和飞行时间，锁敌必须点满

## 适用限制
- 凌霄伤害本身不算出色，依赖苍穹加成
- 冷却加点对凌霄收益低，不建议点
- 需要苍穹M1机库支持才能发挥最大伤害
- 适用于有超主力和零六六的战场环境
