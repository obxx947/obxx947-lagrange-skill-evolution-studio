# A资料231 · 巡洋舰输出队怎么配

> 场景：零氪/平民玩家输出巡洋舰

## 结论
- 巡洋舰是零氪和平民玩家最重要的输出点，常比白板超主力伤害高
- 康纳马拉混沌级-高速等离子体巡洋舰（原文为"康马的 B 型号"，疑似简称）很好用，策略调校过就点，没调校不要点
- 游骑兵级-重型离子炮巡洋舰（原文为"游骑兵的 B 型号"，疑似简称）本版本加强，可搭配泡泡龙使用
- 卡利斯托-重型鱼雷袭击舰（原文为"卡利斯托 b 型号"，疑似简称）高单发反大且是曲射伤害，但会被拦截，伤害大减
- 卡利斯托-重型鱼雷袭击舰一般放高达队，低端局很多人没有光防，可大杀四方
- 艾奥级-高速离子炮巡洋舰（原文为"艾奥的 b 型号"，疑似简称）弥补了离子炮缺点，比较好用
- 光锥级-攻击导弹巡洋舰（原文为"光锥的 c 型号"，疑似简称）可克制开阳和瑶光盛行的环境，但不必刻意腾位置
- 上述船都没有时可用基础型，优先级为艾奥、卡利斯托、康纳马拉混沌、游骑兵
- 猎兵级和狩猎者级用载机型时必须有护航艇或战机
- 猎兵级一般放轰炸机，狩猎者级放组队搭配
- 狩猎者级最好搭配海氏追随者型-脉冲攻击机（原文为"海市"，疑似语音识别错误），其18秒锁定配合狩猎加点可降70%锁定时间，伤害很高

## 配队与模块
- 康纳马拉混沌级-高速等离子体巡洋舰：策略调校过就点，未调校不点
- 游骑兵级-重型离子炮巡洋舰：搭配泡泡龙使用
- 卡利斯托-重型鱼雷袭击舰：放高达队，适合低端局
- 狩猎者级-载机巡洋舰（原文为"狩猎"，疑似简称）：搭配海氏追随者型-脉冲攻击机，加点降低锁定时间

## 数值与数据
- 海氏追随者型-脉冲攻击机锁定时间18秒
- 狩猎者级加点可降低70%锁定时间
