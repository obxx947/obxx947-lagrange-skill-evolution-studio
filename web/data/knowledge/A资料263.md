# A资料263

## 场景 / 对手
萌新抗伤战巡选择

## 舰队例子
- 烧火棍59（无核心模块，需三个模块）（胜）【前期抗伤战巡，最脆但可用】
- 王大毛（旗舰策略锁敌90秒）（胜）【抗伤优于59，经久不衰】
- 大盾（初始480物抗，近20万血量；晚点后780物抗，27万血量，旗舰策略叠满30%减伤）（胜）【抗伤界最高山，最长的核】

## 结论思路
- 59在无核心时脆，但配齐三个模块可充当前期抗伤
- 王大毛虽非巅峰，抗伤仍强于59，旗舰策略锁敌90秒
- 大盾初始面板和成长后属性远超其他，旗舰策略减伤30%

## 适用限制
- 59适合前期资源有限时使用
- 王大毛适合需要锁敌策略的场景
- 大盾适合后期高抗伤需求
