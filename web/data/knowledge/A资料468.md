# A资料468

## 场景 / 对手
新版本盟战，轰炸队与封锁防空队的主流配置，正面作战

## 舰队例子
- 永恒苍穹（旗舰）+ 星脉护航艇 + 索姆河护航艇 + 800护航艇 + 蜂巢护航艇 + 003护航艇 + 天玑护航艇 + 挡刀艇（如AT021）（胜）【缝合轰炸核心，永恒苍穹提升星脉和索姆河攻击频次三倍，挡刀艇保护输出】
- 雷利亚特A型（旗舰）+ 狩猎者巡洋舰 + 投射武器驱逐/护卫舰（胜）【简化封锁防空队，低人口，控制战损，防空效果一般】
- 永恒苍穹（轰炸）+ 13鱼（封锁防空）（胜）【主战盟奢侈配置，强但贵】

## 实战结果
主战盟使用轰炸队和碰瓷队，缝合轰炸攻击敌方，封锁防空曲率投射打击敌方轰炸队，轰炸队为绝对主力，护航队不推荐

## 结论思路
- 轰炸队是盟战绝对主力，决定胜负
- 缝合轰炸过于强势，护航队难以生存
- 永恒苍穹是缝合轰炸核心，提升星脉和索姆河攻击频次三倍
- 轰炸队不带海氏，用AT021当炮灰机挡刀
- 封锁防空队用投射武器，封锁圈内所有舰队同时打击敌方轰炸队
- 雷利亚特A型旗舰提供机动撤退，控制战损
- 狩猎者巡洋舰提升安东尼奥斯集团小船命中率

## 适用限制
- 适用于主战盟盟战，敌方轰炸较多时
- 轰炸队需要挡刀艇，否则输出艇无法存活
- 永恒苍穹配置适合瞬发攻击的护航艇（星脉、索姆河）
- 简化封锁防空队防空效果一般，适合控制战损
- 奢侈配置（永恒苍穹+13鱼）成本高，需资源充足
