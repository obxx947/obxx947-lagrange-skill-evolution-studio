# A资料583

## 场景 / 对手
420人口组队配置推荐，以对剑为主的配置，当前主流作战环境为小船，轰炸多时需调整

## 舰队例子
- 后排：8混沌；后排：6列兵（14百和10星麦）；中排：1风暴（旗舰）；前排：6爱奥（高速型或基础型）（胜）【核心输出为混沌，爱奥可充当前排并输出，列兵提供防空和对剑，风暴补充输出】
- 支援航母带炮艇（800和星脉）时：主队中列兵下1个，换成列维，剩余5列兵带满星脉和列维，下掉的列兵换成重卡或光追（胜）【重卡和列维用于补刀，弥补直射伤害无法补刀的短板】
- 支援航母带星脉时：下掉所有列兵，换成重卡，重卡和列维仅用于补刀（胜）【重卡输出易被拦截，可换成水母、渔海等输出小船，人口120】
- 支援航母无炮艇（如13鱼和那是字）时：主队配置保持不变（胜）【无炮艇时无需调整】
- 炮艇参加轰炸时：后排6混沌，中排6风暴，前排6爱奥（胜）【风暴输出环境好，免疫拦截，输出可观】

## 实战结果
无具体实战数据，基于测试得出混沌和艾奥输出为巡洋最高，配置以对剑为主，强调极端化

## 结论思路
- 核心输出为混沌和艾奥，输出巡洋最高，但各有缺陷需弥补
- 艾奥打闪避船能力差，由星麦解决；混沌不能补刀，由维币、列兵、重卡等完成
- 配对核心思路是极端化，不能既要又要还要，否则对剑和防空都不高
- 列兵带14百和星麦，既能防空也能对剑，较为全能
- 风暴作为旗舰和输出补充，可替换
- 支援航母配置影响主队，带炮艇时调整列兵和重卡，无炮艇时保持不变
- 重卡输出易被拦截，可换水母、渔海等输出小船
- 配置需根据作战环境灵活调整，轰炸多时多带空军，少放对剑

## 适用限制
- 适用于420人口组队配置
- 当前主流作战环境为小船，对剑为主
- 不带空军时需追求对剑效率，带空军时需防空拉满
- 重卡和列维导弹输出不理想，面对超主力时拦截高
- 配置非无敌，需根据轰炸情况调整
