# A资料583 · 420人口对舰组队配置推荐

> 场景：对舰为主，无空军或轰炸环境

## 结论
- 主队以对舰输出为核心，不带对空飞机或舰船
- 混沌与艾奥是巡洋中输出最高的组合
- 艾奥打闪避船表现差，需星脉补足
- 混沌直射不能补刀，需维B、列兵、重卡补刀
- 艾奥可充当前排，战损后有反应时间可撤退
- 配队思路要极端，不能对舰防空都要
- 平民玩家尤其不要做东不成西不就的配置
- 列兵带800和星脉可兼顾防空与对舰
- 风暴可做旗舰并补充输出，也可替换
- 支援航母带炮艇时，主队800可换列维
- 支援有星脉时，可下掉列兵换重卡
- 重卡和列维导弹输出在当前环境不理想，主要补刀
- 重卡可换水母、雨海等输出小船，输出更稳定并加快曲率
- 支援航母无炮艇时，主队配置保持不变
- 炮艇参加轰炸时，下掉列兵上六个风暴
- 风暴免疫拦截，输出环境优于其他战巡
- 航母飞机配置可随意更改，不必照搬
- 配置需根据作战环境灵活调整
- 轰炸多就多带空军少放对舰，没有无敌配置

## 配队与模块
- 主队后排：8个康纳马拉混沌级-轨道炮巡洋舰（轨道炮型A）（原文为"混沌"，疑似简称）+6个猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误）
- 列兵内带14个CV-T800型-脉冲炮艇（原文为"八百"，疑似语音识别错误）和10个星云追逐者-脉冲炮艇（原文为"星麦"，疑似语音识别错误）
- 主队中排：1个永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）做旗舰
- 主队前排：6个艾奥级-攻坚离子炮巡洋舰（原文为"爱奥"，疑似语音识别错误）或艾奥级-高速离子炮巡洋舰（原文为"高速型"，疑似简称）
- 支援航母带炮艇时：主队800换S-列维9号-重型鱼雷艇（原文为"列维"，疑似简称），下掉1个列兵
- 剩余5个列兵带满星云追逐者-脉冲炮艇和S-列维9号-重型鱼雷艇
- 下掉的列兵换卡利斯托-重型鱼雷袭击舰（原文为"重卡"，疑似简称）或光锥级-攻击导弹巡洋舰（原文为"光追"，疑似语音识别错误）
- 支援有星脉时：下掉全部列兵换卡利斯托-重型鱼雷袭击舰
- 重卡可换刺水母级-战术护卫舰（原文为"水母"，疑似简称）、雨海级-突击护卫舰（原文为"渔海"，疑似语音识别错误）等输出小船
- 无炮艇航母支援时：主队保持8混沌+6列兵+1风暴+6艾奥
- 炮艇参加轰炸时：后排6混沌，中排6风暴，前排6艾奥
