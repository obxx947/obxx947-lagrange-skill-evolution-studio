# A资料668

## 场景 / 对手
账号配置优化，针对盘古体系、矛盾组合、副队输出，涉及航母点不足、舰队搭配、战术建议

## 舰队例子
- 33鱼、2个13鱼、31鱼、9松木河、9星鱼脉冲、16挺位、3个11鱼、5VA、2个13鱼带VB和050、沙龙洗给天璇、凌霄填空（胜）【航母点不足，优先小米和VA，平衡机位，天璇用于对敌方剑队之盲瘤降低命中】
- 3000型作为副航母、30挺位、15个800、星脉、驱灵或蜂巢、零幺幺重炮（胜）【3000型自带50点，优先800和星脉，驱灵优先于蜂巢，重炮可选】
- 25机位、10次摇、9凌霄、维B、小米、050、天璇（胜）【平衡机位，天璇洗点给之盲瘤，配合盘古体系】
- 海市单宅、战术狩猎、3000型拉满、36、光房、泡泡龙、富贵（胜）【海市最佳载具为战术狩猎，副队拉满3000型占200人口】
- 副队、副加毛、副加盾、风暴（无M2）、C3、毛、盾、3光房、开阳、瑶光、御衡（胜）【风暴输出不足，建议洗点给毛，玩矛盾组合，御衡作为白板提供buff】
- 白鳄双型号、熊二、3白鳄、3-5宗雄、3光房、萤石双型号、开阳（胜）【白鳄配熊二，萤石减敌方轰炸命中40%，近距离优势大】
- 前期轨道炮、锆石、特卡、水母、瑶光、5开洋、创世星（胜）【前期用轨道炮配创世星，打斗牛配开洋效果好，换战损佳】
- 两顿三毛、挺毛、谭普尔、零幺幺、高速、虚灵（胜）【矛盾组合带挺毛，护航挺优先吸引敌方飞机，零幺幺高速便宜耐造】

## 实战结果
粉丝账号梳理，无具体对战记录，主要提供配置优化建议，强调矛盾组合和盘古体系，关键得失为航母点不足需平衡机位，风暴输出不足建议洗点

## 结论思路
- 航母点不足时，优先小米和VA，平衡机位，天璇用于之盲瘤降低敌方命中
- 3000型作为副航母，优先800和星脉，驱灵优先于蜂巢
- 海市单宅进战术狩猎，副队拉满3000型占200人口
- 风暴无M2输出不足，建议洗点给毛，玩矛盾组合
- 白鳄配熊二，萤石减敌方轰炸命中40%，近距离优势大
- 前期用轨道炮配创世星，打斗牛配开洋效果好
- 矛盾组合带挺毛，护航挺优先吸引敌方飞机，零幺幺高速便宜耐造

## 适用限制
- 航母点不足时适用，需平衡机位
- 风暴无M2时建议矛盾组合，有C2后可考虑八战巡
- 前期轨道炮适合打斗牛配开洋，后期需调整
- 白鳄和萤石需双型号拉满，否则效果有限
- 副队需拉满200人口，不能少
