# A资料668 · 账号航母战巡配队梳理

> 场景：盘古体系；矛盾组合；前期木星工业轨道炮；副队

## 结论
- 账号很缺航母点，航母点不够，战巡部分需单独梳理。
- 三个11鱼机位优先上米斯特拉-战斗攻击机（原文为"小米"，疑似简称），上完再上5个维塔斯A021-重型攻击机（原文为"VA"，疑似简称）。
- 两个13鱼优先上维塔斯-B010-轰炸机（原文为"VB"，疑似简称）和BR050-标准轰炸机（原文为"零五零"，疑似简称），飞机点稍作平衡。
- 把砂龙-大气层拦截机（原文为"沙龙"，疑似语音识别错误）洗下来给天璇A-轻型攻击机（原文为"天璇"，疑似简称），天璇打敌方剑队对掏时可形成致盲，降低命中率。
- 两个13鱼共26个位置，剩余去补；剩余5个维塔斯A021后拿1个林鸮A100型-联合攻击机（原文为"林鸮A100型-联合攻击机"，疑似语音识别错误）填空，还剩9个林鸮，不着急。
- CV3000级-快速航空母舰（原文为"三千"，疑似简称）11级只有自带50/55点，建议以现点数作副航母。
- CV3000副航母30个艇位：优先15个CV-T800型-脉冲炮艇（原文为"八百"，疑似简称）和1个星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）；剩余给虚灵-隐身导弹艇（原文为"驱灵"，疑似语音识别错误）或蜂巢守卫者-重型鱼雷艇（原文为"蜂巢"，疑似简称），虚灵优先。
- 剩余25个机位先拉10个刺鳐-鱼雷轰炸机（原文为"次摇"，疑似语音识别错误）；加前面剩的9个林鸮共19个位置；剩余11个位置洗点吃经验书，或平衡维B、小米、050点数到80-90点；洗下约10点给天璇。
- 海氏追随者型-脉冲攻击机（原文为"海市"，疑似语音识别错误）要单宅出来，最好载具是狩猎者级-战术载机巡洋舰（原文为"战术狩猎"，疑似简称），直接进狩猎。
- 副队拉满CV3000先拉满，占200人口，加36共236人口，再配1个光锥级-区域防空巡洋舰（原文为"光房"，疑似语音识别错误）到256人口，剩余拉康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡龙"，疑似简称），用FG300型-多用途护卫舰（原文为"富贵"，疑似简称）或其他小船补位。
- 副队附加矛、附加盾核心都有，盾直接上。
- 永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）没有M2，只能进副队，输出不够；C3可以，但配合小盘古组合可上场；放副队好亏，不如洗点给乌拉诺斯之矛（原文为"毛"，疑似简称），玩矛盾组合两盾三矛。
- 后期机位占完，矛盾组合带三光锥级-区域防空巡洋舰，配合开阳级-机动驱逐舰（原文为"开阳"，疑似简称）与瑶光级-通用护卫舰（原文为"遥光"，疑似错字）打输出，尤其瑶光。
- 瑶光各造5个；造时副队200人口不能少；双信号每个信号各造5个；配开阳，加玉衡级-支援巡洋舰（原文为"御衡"，疑似错字）当白板给开阳和瑶光buff，形成盘古默认版，200人口不能少。
- 副队能拉都拉满，尽量输出，空幽全部拉满。
- 有白垩级-战术无人机巡洋舰/白垩级-综合防空巡洋舰（原文为"白鳄"，疑似语音识别错误）双型号都开出来，非常好用；巡洋主攻棕熊级-防空巡洋舰（原文为"熊二"，疑似简称），白垩配棕熊，三白垩、三棕熊或五棕熊，再配三光锥级-区域防空巡洋舰。
- 萤石（塔拉萨萤石级-信息驱逐舰/塔拉萨萤石级-电子驱逐舰，原文为"萤石"，疑似简称）一定要养起来，有开阳就直接洗点；除非经常下红矿可留背石；把卡利莱恩级-重炮护卫舰（原文为"重炮"，疑似简称）下了，直接给萤石，双型号拉满，能带多少带多少。
- 海雷丁家族白垩加成、技能全部点满，再带默认巡洋buff；配合萤石可给敌方轰炸减40%命中，近距离非常强。
- 前期以轨道炮为主；当前版本木星工业针对盘古体系是较好选择，前期很好用，不用拉双鱼海，人口少。
- 轨道炮配合锆石级-突击护卫舰（原文为"锆石"，疑似简称），有子型号最好；配少量卡利莱恩级-特种护卫舰（原文为"特卡"，疑似语音识别错误）、刺水母级-战术护卫舰（原文为"水母"，疑似简称）、瑶光；编组放5个开阳，剩余5开阳作增援。
- 配合木星工业创神星级-轨道炮驱逐舰（原文为"创世星"，疑似语音识别错误），打敌方斗牛级-脉冲炮驱逐舰（原文为"斗牛"，疑似简称）配开阳，非常好打，换战损也好。
- 打架建议两盾三矛组合，非常好。
- 八战巡以后需要C2；不出八战巡，五战巡可以上它；没有C2时盾不能点前置，前置后上不了能量护盾。
- 以现在模块建议玩矛盾组合，矛盾组合带艇矛；艇矛内放坦普尔1号-信息护航艇（原文为"坦克"，疑似简称）、CV-M011型-高速导弹艇（原文为"零幺幺，高速"，疑似简称；优先，便宜耐造）、虚灵-隐身导弹艇等，接战后敌方飞机优先打矛内护航艇。
- 五战巡在中排最好；等开出C2后再走八战巡也可以；风暴增强的是功能性，不是输出，理智玩矛盾组合。

## 配队与模块
- 三个11鱼：机位优先米斯特拉-战斗攻击机，之后上5个维塔斯A021-重型攻击机。
- 两个13鱼：优先维塔斯-B010-轰炸机和BR050-标准轰炸机；飞机点平衡；两个13鱼共26机位，剩余补位；剩余5个维塔斯A021后拿1个林鸮A100型-联合攻击机填空，还剩9个林鸮。
- 砂龙-大气层拦截机洗下来给天璇A-轻型攻击机，用于致盲。
- CV3000级-快速航空母舰作副航母：30个艇位优先15个CV-T800型-脉冲炮艇+1个星云追逐者-脉冲炮艇；剩余给虚灵-隐身导弹艇或蜂巢守卫者-重型鱼雷艇，虚灵优先；虚灵或S-列维9号-重型鱼雷艇（原文为"列为九号"，疑似语音识别错误）点子给坦普尔1号-信息护航艇，或上CV-M011型-重炮艇（原文为"零幺幺的重炮"，疑似简称）。
- 剩余25个机位先拉10个刺鳐-鱼雷轰炸机，加9个林鸮共19位；剩余11位洗点吃经验书，或平衡维B/小米/050到80-90点，洗下约10点给天璇。
- 海氏追随者型-脉冲攻击机单宅，载具用狩猎者级-战术载机巡洋舰，直接进狩猎。
- 副队：CV3000拉满占200人口，加36共236人口；配1个光锥级-区域防空巡洋舰到256人口；剩余拉康纳马拉混沌级-高速等离子体巡洋舰，用FG300型-多用途护卫舰或其他小船补位。
- 副队附加矛、附加盾核心都有，盾直接上；矛盾组合两盾三矛。
- 后期矛盾组合带三光锥级-区域防空巡洋舰，配合开阳级-机动驱逐舰与瑶光级-通用护卫舰打输出。
- 瑶光各造5个；双信号每个信号各造5个；配开阳，加玉衡级-支援巡洋舰当白板给开阳和瑶光buff，形成盘古默认版，200人口不能少。
- 白垩级双型号都开；巡洋主攻棕熊级-防空巡洋舰，白垩配棕熊：三白垩、三棕熊或五棕熊，再配三光锥级-区域防空巡洋舰。
- 塔拉萨萤石级-信息驱逐舰/塔拉萨萤石级-电子驱逐舰双型号拉满，能带多少带多少；把卡利莱恩级-重炮护卫舰下了给萤石；海雷丁家族白垩加成、技能点满，带默认巡洋buff。
- 艇矛（乌拉诺斯之矛 B2）内放坦普尔1号-信息护航艇、CV-M011型-高速导弹艇（优先，便宜耐造）、虚灵-隐身导弹艇等；接战后敌方飞机优先打矛内护航艇。
- 五战巡在中排最好；等开出C2后再走八战巡；没有C2时盾不能点前置，否则上不了能量护盾。
- 前期：轨道炮为主，木星工业针对盘古体系；不用拉双鱼海。
- 前期轨道炮配锆石级-突击护卫舰（有子型号最好），少量卡利莱恩级-特种护卫舰、刺水母级-战术护卫舰、瑶光级；编组放5个开阳级-机动驱逐舰，剩余5个作增援。
- 配合木星工业创神星级-轨道炮驱逐舰，打敌方斗牛级-脉冲炮驱逐舰配开阳，好打，换战损也好。
