# A资料635 · 天枢内战直射与投射战报

> 场景：天枢级-支援航空母舰内战、死战；直射队对投射队

## 结论
- 天枢级-支援航空母舰（原文为“天枢”，疑似简称）内战血量与维修接近，主队420人口锁死，输出差距主要靠副队打穿。
- 左边思路：能抗能打，主队抗伤，副队用永恒风暴级-攻击战列巡洋舰（原文为“风暴”，疑似简称）等高输出。
- 安东塔斯持剑者级-指挥舰（原文为“大剑”，疑似简称）能扛能打仅限主队；输出依赖舰队内维塔斯、星云追逐者-脉冲炮艇等，副队只扛不输出。
- 建议左边副队把安东塔斯持剑者级-指挥舰换成乌拉诺斯之矛（原文为“大矛”，疑似简称），伤害更高；永恒风暴级-攻击战列巡洋舰可保留。
- 右边思路：叹息之墙，直射靠康纳马拉混沌级-轨道炮巡洋舰（轨道炮型A）（原文为“混沌”，疑似简称）、开阳级-机动驱逐舰（原文为“开阳”，疑似简称）、瑶光级-通用护卫舰（原文为“瑶光”，疑似简称）限制，投射由乌拉诺斯之矛和天枢级-支援航空母舰分摊。
- 双方天枢模块不齐：左边少载机、双维修、无重甲；右边双载机、双维修、无重甲。
- 结果右边小胜，双方基本全灭，右边天枢残存1个。
- 右边主舰队走投射，无直射火力，卡利斯托-重型鱼雷袭击舰（原文为“重卡”，疑似简称）也拉上来。
- 卡利斯托-重型鱼雷袭击舰在天枢内战强，前提对面拦截少；超主力中唯一集火战巡，不被天枢限制。
- 星云追逐者-脉冲炮艇（原文为“星脉”，疑似简称）反小强、集火战巡；尽量放十一，放猎兵级-重型载机巡洋舰（原文为“列兵”，疑似语音识别错误）伤害低。
- CV-T800型-脉冲炮艇（原文为“八百”，疑似简称）被干扰机克制；对面带干扰机时建议补枪骑兵级-区域防空驱逐舰（原文为“枪防”，疑似简称）或光锥级等信息链，否则清不完。
- 海氏追随者型-脉冲攻击机（原文为“海誓/海市”，疑似语音识别错误）在天枢内战建议对空，减少海尔波普-维修支援护航艇（原文为“海尔波普”，疑似简称）奶量；超主力会被天枢限制。
- 米斯特拉-战斗攻击机（原文为“小米”，疑似简称）要么带信息链，要么去绝育动力系统，要么不带；无信息链清不完SC002型-量子侦察机（原文为“零零二”，疑似简称）。
- BR050-标准轰炸机（原文为“零五零”，疑似简称）面对无重甲天枢伤害高，优先打航母，绝育效率可以。
- 海尔波普-维修支援护航艇在天枢内战威胁大，有奶但死得快。
- 左边直射穿甲思路：反小火力拉满也花约3分半才穿对面前排；穿后对中排造成伤害。
- 直射与投射关键看单位人口伤害与数值；死战下区别是战损方式：投射打战损更快，直射更慢，先后顺序不同。
- 数值给够时直射或投射都行，混沌和风暴可一起上打数值。
- 两边数值差距不大，左边并不明显优于右边。
