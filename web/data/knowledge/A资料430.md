# A资料430

## 场景 / 对手
护航机制教学，涉及基地升级、护航部署、舰队协同防空

## 结论思路
- 护航需要基地升至七级并建造护航部署中心
- 选择被保护舰队后点击护航，黄色图标表示被保护，灰色表示主动接敌
- 护航状态下，只有接敌舰队死亡后，被保护舰队才会受到攻击（轰炸和偷袭除外）
- 护航状态下两支舰队协同防空，但被保护舰队受轰炸时保护舰队不参与防空
- 护航状态下移动消耗策略值双倍
- 可为队友提供护航，但一支舰队一次最多被三队护航，一个人只能对一支舰队护航一次

## 适用限制
- 护航不适用于轰炸和偷袭情况
- 被保护舰队受轰炸时保护舰队不协同防空
- 护航移动消耗策略值双倍
- 护航数量有限制：一支舰队最多三队护航，一人对一舰队仅一次
