# A资料28

## 场景 / 对手
混沌（泡芙龙）加点推荐与输出数据对比测试，针对巡洋舰、航空母舰、战列巡洋舰、驱逐舰和护卫舰，理想输出条件下进行

## 舰队例子
- 混沌（双命中、一冷却、一策略双伤害，策略满调效）（负收益）【反大分商21.81万/分钟，反小分商18.75万/分钟；策略提升命中率和攻击持续时间，针对高闪避目标（如卡特、艾奥）有压制性，但总体伤害低于无策略加点】
- 混沌（双命中、双冷却、双伤害，无策略）（胜）【反大伤害23.19万/分钟，反小伤害18.26万/分钟；输出接近满调校重卡，策略完全负收益】
- 混沌（双命中、双伤害、一冷却一攻击持续时间）（胜）【反大伤害20.24万/分钟，反小伤害16.36万/分钟；冷却加点收益高于攻击持续时间】
- 混沌（双命中、双伤害、双冷却）（胜）【反大伤害19.6万/分钟，反小伤害15.39万/分钟；双伤害加点提升反大但降低反小】

## 实战结果
混沌对多种靶船（大毛、太阳鱼、零六六、斗牛、卫士、股神）进行3分钟输出测试；无策略加点反大23.19万/分钟、反小18.26万/分钟，优于策略加点；策略满调效反大21.81万/分钟、反小18.75万/分钟，仍为负收益；关键得失：策略提供命中加成但牺牲伤害，适合高闪避目标，不适合常规输出

## 结论思路
- 混沌加点分两种情况：策略满调效和无策略，根据武器技术值决定
- 无策略加点（双命中、双冷却、双伤害）输出最高，反大23.19万/分钟，反小18.26万/分钟
- 策略加点即使满调效也是负收益，但可针对高闪避目标（如卡特、艾奥）提供专项打击
- 伤害加点收益高于冷却加点，冷却加点收益高于攻击持续时间加点
- 平民玩家不建议点策略，氪佬可点策略并满调校以应对特定环境

## 适用限制
- 测试基于理想输出条件，实际受命中率、目标魔抗影响
- 策略加点适用于高闪避目标，不适用于常规输出
- 武器技术值不足时不要点策略，否则负收益
- 数据为3分钟作战时间，长时间作战可能变化
