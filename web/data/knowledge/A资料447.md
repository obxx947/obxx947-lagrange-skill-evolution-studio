# A资料447

## 场景 / 对手
双航母VB架具选择，对比十三鱼与苍穹C1模块

## 舰队例子
- 十三鱼（VB载具，含M2模块）（胜）【VP六分十秒输出105万】
- 苍穹C1模块（VB载具）（胜）【VP六分十秒输出96万，可替代十三鱼】

## 实战结果
十三鱼与苍穹C1对比，十三鱼输出105万，苍穹C1输出96万，差距小，苍穹C1可用

## 结论思路
- 十三鱼因性价比高常用，但南十字性价比不高
- 无M2模块或点数不足时，可选苍穹C1模块
- 苍穹C1模块提供60往返，对比十三鱼20命中55冷却25伤害，差距小
- 苍穹C1的VB输出接近十三鱼，可作替代

## 适用限制
- 适用于双航母且点数有限的情况
- 无M2模块时适用
- 不适用于追求极致输出的场景
