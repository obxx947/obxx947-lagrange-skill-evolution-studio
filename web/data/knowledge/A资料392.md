# A资料392

## 场景 / 对手
七户大战，输出加扛箱定位

## 舰队例子
- 细神重炮型（直射输出）（负）【输出刮痧，除非全直射队，否则无效】
- 细神AC型号（副队扛伤）（负）【抗伤效果不如开阳，但差距不大】

## 实战结果
细神重炮型在七户大战中表现不佳，输出无效，抗伤有限；AC型号抗伤尚可但不如开阳

## 结论思路
- 重炮型输出直射，仅在全直射队中有效，否则无效
- 重炮型唯一作用是进攻抗伤，但闪避有限，扛伤能力弱
- AC型号定位副队扛伤，配合卡利斯通，但抗伤效果略逊于开阳

## 适用限制
- 重炮型适合全直射队，否则不建议使用
- AC型号适合作为副队扛伤，但需接受不如开阳的差距
