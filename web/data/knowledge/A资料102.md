# A资料102

## 场景 / 对手
控制点玩法，内城/外城据点，一级护卫怪、二级驱护怪、三级巡洋驱逐怪，飞机编队，据点炮环境

## 舰队例子
- 一大盾前排 + 三奶 + 60雷隐石古神 + 其他输出（胜）【标准控制配置，保护登陆舰】

## 实战结果
打海盗外控制稳定爆率高，需打据点，保护登陆舰，要塞小船吸引火力

## 结论思路
- 控制点分内城外城，需打据点才能控制
- 一级据点刷护卫怪，二级刷驱护怪，三级刷巡洋驱逐怪
- 飞机编队正常配对支援航母可轻松打过
- 配对思路：一大盾前排三奶60雷隐石古神其他配输出
- 飞机不能上灵鸟，因A次摇会被据点炮一直打
- 登陆舰有多少拉多少，后期有大用

## 适用限制
- 控制前先看还有没有货
- 飞机避免上灵鸟以防据点炮攻击
- 适用于控制点玩法，非海盗
