# A资料189

## 场景 / 对手
沙龙更新后防空体系，对手为敌方载机，正面防空作战

## 舰队例子
- 沙龙 x5，加点：防空扩展（+10%命中，主动防空），冷却/锁定时间优化（胜，评价：防空伤害达8万，直追小米，存活率高）【60秒冷却期，但伤害打满，反击防空】

## 实战结果
沙龙五艘对敌方载机，防空伤害8万，关键得失：主动防空提升命中，反击保证存活

## 结论思路
- 沙龙指挥系统防空扩展策略提高10%命中并转为主动防空
- 冷却和锁定时间短，能持续输出
- 不依赖载机配置，适合防空狩猎或主队

## 适用限制
- 需点防空扩展加点
- 适合防空场景，对载机威胁大
- 60秒冷却期需注意节奏
