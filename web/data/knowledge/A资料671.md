# A资料671 · 航母缺模块与副队配队

## 结论
- 南十字星元帅级-武装航空母舰（原文为“南石”，疑似语音识别错误）缺C1，太阳鲸-武装战略航空母舰（原文为“鱼”，疑似简称）缺M2与C1，当前两艘航母无法使用。

- 机位优先放维塔斯-B010-轰炸机（原文为“vb”，疑似简称）、BR050-标准轰炸机（原文为“零五零”，疑似简称），再放维塔斯A021-重型攻击机（原文为“va”，疑似简称）。
- 主队至少4狩猎者级-载机巡洋舰（原文为“狩猎”，疑似简称）、1猎兵级-重型载机巡洋舰（原文为“猎兵”，疑似简称）、1光锥级-区域防空巡洋舰（原文为“光房”，疑似语音识别错误）；以康纳马拉混沌级-高速等离子体巡洋舰（原文为“泡泡龙”，疑似简称）为基础拉满。
- 副队核心为乌拉诺斯之矛（原文为“大毛”，疑似语音识别错误）与普鲁图斯之盾级-防护战列巡洋舰（原文为“盾”，疑似简称）；乌拉诺斯之矛建议附加艇矛，放中排；有节点直接买改站位，无节点用策略改。
- 乌拉诺斯之矛艇内放中排CV-M011型-高速导弹艇（原文为“零幺幺，高速”，疑似简称）；S-列维9号-重型鱼雷艇（原文为“列为九号”，疑似语音识别错误）直接洗掉，往返机制不好用。
- 加点平衡：给80点，剩10点给坦普尔1号-信息护航艇（原文为“坦克”，疑似语音识别错误）或星云追逐者-脉冲炮艇（原文为“星脉”，疑似简称）；CV-T800型-脉冲炮艇（原文为“八百”，疑似简称）点子给多了。
- 无开阳级-机动驱逐舰（原文为“开阳”，疑似简称）、瑶光级-通用护卫舰（原文为“妖光”，疑似语音识别错误）时副队走木星工业，选火炮或装甲；火炮基础型号闪避率最高，10个拉满前排。
- 副队要带1个艾奥级-攻坚离子炮巡洋舰（原文为“艾奥”，疑似简称），为木星工业阋神星I级-机动突击驱逐舰（原文为“吸神星”，疑似语音识别错误）开木星工业buff。
- 副队剩余人口优先补狼蜥级-防御护卫舰（原文为“狼西”，疑似语音识别错误）基础型号，可吃诺玛集团buff；也可放刺水母级-防御护卫舰（原文为“防御次水母”，疑似错字）。
- 副队增援为省人口：1大盾+3乌拉诺斯之矛+1光锥级-区域防空巡洋舰。
- 账号强度不高，需慢慢养；太阳鲸-武装战略航空母舰（原文为“鱼海”，疑似语音识别错误）点子前期双型号可上。
- 优先养枪骑兵级-轻型导弹驱逐舰（原文为“枪械兵”，疑似语音识别错误）；塔拉萨萤石级-信息驱逐舰（原文为“银石”，疑似语音识别错误）给少量点子；进红矿给少量位；AC721-重型运载驱逐舰（原文为“七二幺”，疑似简称）、斗牛级-脉冲炮驱逐舰（原文为“斗牛”，疑似简称）、斗牛级-防御驱逐舰（原文为“防御牛”，疑似简称）可用。
- 棕熊级-综合巡洋舰（原文为“棕熊”，疑似简称）好用，副队有人口可养，给够点子，上3-4个；对空打艇猛。

## 配队与模块
- 主队航母载机：CV3000级-快速航空母舰（11级）；机位放维塔斯-B010-轰炸机、BR050-标准轰炸机、维塔斯A021-重型攻击机；方案10维塔斯-B010+10维塔斯A021+5BR050-标准轰炸机。
- 停位：索姆河之影-装甲飞行坦克（原文为“松河”，疑似语音识别错误）、星云追逐者-脉冲炮艇、11个CV-T800型-脉冲炮艇刚好补满30停位；剩余8+5=13加3米斯特拉-战斗攻击机（原文为“小米”，疑似简称），进狩猎者级-载机巡洋舰。
- 主队编成：4狩猎者级-载机巡洋舰+1猎兵级-重型载机巡洋舰+1光锥级-区域防空巡洋舰；康纳马拉混沌级-高速等离子体巡洋舰为基础拉满，剩余去拉L（原文不明）；增援3个，5个11级。
- 副队：乌拉诺斯之矛（附加艇矛，中排；艇内中排CV-M011型-高速导弹艇）+普鲁图斯之盾级-防护战列巡洋舰；两盾三矛。
- 副队前排：无开阳级-机动驱逐舰/瑶光级-通用护卫舰则走木星工业，火炮或装甲；10个拉满。
- 副队中后：CAS066级-支援巡洋舰；光锥级-区域防空巡洋舰（编队只放2个，看打架强度）；1艾奥级-攻坚离子炮巡洋舰；阋神星I级-机动突击驱逐舰10个、谷神星级-载机驱逐舰（原文为“股神”，疑似语音识别错误）5个；6个CAS066级-支援巡洋舰（原文为“六奶”，疑似简称）、3个光锥级-区域防空巡洋舰。
- 补位：狼蜥级-防御护卫舰基础型号；也可刺水母级-防御护卫舰。
- 副队增援：1普鲁图斯之盾级-防护战列巡洋舰+3乌拉诺斯之矛+1光锥级-区域防空巡洋舰。
- 碰瓷投射队：斗牛级-防御驱逐舰（直射）+双皮奶+AC721-重型运载驱逐舰+枪骑兵级-区域防空驱逐舰（原文为“枪房”，疑似语音识别错误）。
- 投射干扰队：3光锥级-区域防空巡洋舰+棕熊级-防空巡洋舰（熊二）+白垩级-战术无人机巡洋舰（原文为“白鳄”，疑似语音识别错误）+塔拉萨萤石级-信息驱逐舰。
