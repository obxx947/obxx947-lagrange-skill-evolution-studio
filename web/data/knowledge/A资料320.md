# A资料320

## 场景 / 对手
超斩舰队配置讨论，涉及航母、载机、战群、巡洋等体系

## 舰队例子
- 南十字（航母）+ 列维（载机，实弹，单发1200，破甲）（胜）【超斩用于载机，需高单发和破甲】
- 南十字（航母）+ 星脉/威碧海市（载机，能量伤害）（胜）【能量伤害单发可低，考虑击杀效率】
- 南十字（航母）+ 凌霄/维A（载机，打击系统）（胜）【打击系统可减血和阻断输出】
- 猎兵/狩猎（替代航母）+ 海市（载机）（胜）【狩猎减索敌70%，海市适合超斩】
- 大地（战群，M2模块）+ 棕熊（辅助）（胜）【大地伤害高但怕拦截，棕熊反拦截需至少两艘】
- 风暴（战群，M2模块）（胜）【伤害较低但稳定，不被拦截】
- 卡迪斯托B型（巡洋，宗申重卡）（胜）【第一攻击序列超阻力，单发高，怕拦截】
- 自水母（巡洋，补人口）（胜）【点超感即可】

## 结论思路
- 超斩需航母（南十字）或替代（猎兵/狩猎）
- 实弹载机需高单发（至少大几百）和破甲，列维最佳
- 能量载机单发可低，选击杀效率高的如星脉、海市
- 若未装满，用打击系统载机（凌霄、维A）
- 战群需M2模块，大地怕拦截需棕熊辅助，风暴稳定
- 巡洋中卡迪斯托B型适合超斩但怕拦截
- 平民可用猎兵/狩猎替代，狩猎配海市效果好

## 适用限制
- 超斩仅限特定船型（南十字、猎兵、狩猎、大地、风暴等）
- 实弹载机需破甲和高单发，否则无法穿透高护甲
- 大地需棕熊辅助且至少两艘，否则易被拦截
- 卡迪斯托B型怕拦截，需考虑防空
- 平民玩家可能缺蓝点或南十字，需用替代方案
