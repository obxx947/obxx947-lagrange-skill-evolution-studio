# A资料320 · 超斩载机与舰船选择

> 场景：超主力斩杀

## 结论
- 南十字星元帅级是唯一能点超斩的航母，超斩作用于其搭载的载机
- 实弹载机需具备破甲能力，否则打不穿超主力高护甲
- 实弹载机单发伤害至少大几百，不能低于未加点ST59级的180护甲
- 能量载机单发可低一些，能量伤害减免按百分比计算
- 载机装不满时可选用能打击系统的载机，打击系统可使超主力损失5%血量并阻断输出
- 平民可用猎兵级或狩猎者级替代南十字星元帅级，两者也能点超斩
- 狩猎者级与海氏追随者型是绝配，狩猎者级可减免约70%索敌
- 海氏追随者型有连续打击同一目标伤害提升的策略，适合打大团
- 战巡中普通玩家主要用新君士坦丁大帝级和永恒风暴级，均需M2模块
- 新君士坦丁大帝级伤害高但怕拦截，永恒风暴级伤害较低但不会被拦截，胜在稳定
- 上大地时建议带棕熊级，其反拦截策略可降低被拦截概率60%
- 棕熊级先给航母引导再给战巡引导，带航母时至少需两艘才能引导到大地
- 巡洋中卡利斯托-重型鱼雷袭击舰（原文为"卡迪斯托的B型号宗申重卡"，疑似语音识别错误）是战巡杀手，第一攻击序列为超主力且单发高
- 卡利斯托-重型鱼雷袭击舰有优先打击战巡并提高25%伤害的策略，但同样怕拦截
- 护卫舰基本只用于补人口，用刺水母级点超斩即可
