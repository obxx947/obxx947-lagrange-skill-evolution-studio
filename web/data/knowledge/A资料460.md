# A资料460 · 066奶船定位与副队配置分析

> 场景：副队护航/奶船体系；066、谷神星、海尔波普、奶矛、苍穹C3对比

## 结论
- 066定位是奶船，深度绑定护航副队，不是主队船
- 066奶量在奶船中只是标尺级，不是最强奶
- 副队核心任务是保证大盾生存，谁盾活得久谁赢
- 副队血量只要比对方多，正常情况下不会输
- 双方输出瓶颈难突破时，胜负取决于副队血量
- 靠奶量追平血量差距不现实，6分钟才能追回200万血量差
- 纯大船队分摊伤害，盾掉得比少超主力的队伍慢
- 066是小船，混不进超主力大船体系，带越多越亏人口
- 066单船均伤回血不到2万，18人口需9分钟后才回本
- 066自身9万血量没有有效抗性，维修加成低，奶不回来
- 风暴类取舍武器3分钟就能飘死066，066在副队必死
- 066奶量容易奶歪，战报中32万奶量有10万奶歪
- 谷神星奶量干净，只奶该保护的目标，到死都不奶自己
- 谷神星只要不是队内唯一小船，就不容易暴毙
- 超斩海尔波普奶量精准，只奶大船，且奶量更高
- 20台海尔波普奶量超过100人口066的奶量
- 海尔波普更省人口，增援优先给南十字或航母
- 066不考虑生存已是废物船，考虑生存直接暴毙
- 若为保066生存上护航，人口可能从18涨到28，更难回本
- 玉衡不能奶战巡和航母，不适合主流副队
- 诺玛支援奶与原奶量相同，但少了防空无人机，副队站不住
- C3苍穹单位人口奶量比066还低一倍，不如C1、C2
- 奶矛只适合已有大量艇位、不需要副队提供艇位的玩家
- 99%玩家应玩艇矛，不是奶矛
- 有B2没人会带B3奶矛

## 配队与模块
- 066作为副队奶船，需绑定护航副队使用
- 谷神星需搭配开阳、摇光使用，避免成为队内唯一小船
- 超斩海尔波普作为副队奶船，优先超载并坐前排
- C3苍穹可放副队，但奶量不如066，不推荐
- 奶矛适配已有大量艇位、不需要副队提供艇位的阵容
- 诺玛支援奶因缺少防空无人机，不适合需要站住的副队

## 数值与数据
- 066单船均伤回血不到2万
- 066需要18人口，对应18万血量才能回本
- 066在副队需9分钟以上才能体现价值
- 066自身约9万血量
- 风暴一分钟出伤4万，按5000单发计算，6台3分钟可击杀066
- 战报中32万奶量有10万奶歪
- 副队一分钟30万奶量是带满066都不一定达到的水平
- 20台海尔波普奶量超过100人口066奶量
- 奶矛强度约0.75，苍穹约1，诺玛约0.5，谷神星约1.2超载，海尔波普约3-4，天枢约5
