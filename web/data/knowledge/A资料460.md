# A资料460

## 场景 / 对手
066奶船在副队中的定位与强度分析，对手为常规玩家，环境为PVP对战

## 舰队例子
- 066奶船，18人口，奶量约2万/分钟，自身9万血量（负）【奶量低，生存差，3分钟可被风暴击毁，9分钟才能回本】
- 谷神星奶船，精准奶，不奶自己（胜）【奶量精准，生存有保障，适合副队】
- 超斩海尔波普，20台，奶量高，精准奶大船（胜）【奶量高，精准，优于066】
- C3苍穹，4护航艇+4战机，奶量低于066（负）【奶量低，不如C1/C2输出】
- 奶矛，适合有大量挺位的阵容（负）【生存差，99%玩家应玩挺矛】

## 实战结果
对方带鸡精战损，我方32万奶量中10万奶歪，066在副队中必死，奶量贡献有限

## 结论思路
- 066定位是奶船，但奶量低，18人口需9分钟回本，实战中难以存活
- 副队生存取决于血量，奶量难以弥补血量差距
- 谷神星和海尔波普精准奶优于066，066在副队中不应存在
- 066适合平民玩家，但强度有限，非主流选择

## 适用限制
- 适用于平民玩家无其他选择时
- 不适用于高强度对战，066生存差，奶量不足
- 副队中应优先选择精准奶船如谷神星或海尔波普
