# A资料61

## 场景 / 对手
测试银石级对舰船输出限制能力，对手为混沌和艾奥输出体系，正面作战，环境为模拟战斗

## 舰队例子
- 三个大毛（靶船）（负）【无银石时2分38秒损毁；加入10个银石后2分43秒损毁，仅提升5秒】
- 两个航母（靶船）（负）【无银石时2分06秒损毁；加入银石后2分17秒损毁，提升11秒】
- 十个卡特（靶船）（负）【无银石时2分钟损毁；加入银石后2分44秒损毁，提升44秒】
- 十个卡特（靶船）加8个混沌（输出）（负）【无银石时2分34秒损毁；加入银石后4分28秒损毁，提升近2分钟】

## 实战结果
测试银石级对舰船输出限制，混沌和艾奥集火靶船，银石加入后生存时间提升有限，但对卡特提升显著，几胜几负不适用，关键得失为银石对舰船限制能力优于对舰载机，但受目标数量影响

## 结论思路
- 银石级对舰载机限制能力差，但对舰船输出限制有效
- 银石级锁定逻辑为全范围覆盖，不同于其他舰船的分摊原则
- 银石级与高闪避舰船（如卡特）搭配效果最佳
- 银石级干扰目标越集中，效果越显著

## 适用限制
- 适用于对抗高命中输出舰船（如混沌、艾奥）
- 适合搭配高闪避舰船（如卡特）使用
- 对低闪避舰船（如大毛、航母）效果有限
- 不适用于针对舰载机
