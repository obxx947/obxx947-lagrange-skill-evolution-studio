# A资料180

## 场景 / 对手
单战群扛伤，对手未知，正面扛伤，环境未知

## 舰队例子
- 五九（中排，不点前突策略）+ 前排小船 + 光防奶船（胜）【五九放中排，小船先扛伤，五九只吃取射伤害，小船没了后五九再吃直射伤害】
- 大毛（旗舰，点策略调整到中排）+ 前排小船 + 奶船（胜）【大毛旗舰可用，调整到中排保证生存，绝育后回前排保护奶船】
- 大盾（旗舰，30%免伤，点前突策略）+ 6个盾 + 前排小船 + 光防奶船（胜）【前排小船炸后盾前突，有六分之五概率不打旗舰，旗舰盾被打掉后坚持不久】
- 大盾（旗舰，不点前突策略）+ 前排小船 + 光防奶船（胜）【小团掉后中排有光防奶船和大盾，打旗舰概率不高，可省战损点】

## 实战结果
单战群扛伤，四类舰队（五九、大毛、大盾、天权）中天权不适用单战群，五九、大毛、大盾各有优劣，大盾最强

## 结论思路
- 五九不点前突策略，避免战损奇高，放中排让小船先扛伤
- 大毛旗舰可用，点策略调整到中排保证生存，绝育后回前排保护奶船
- 大盾旗舰有30%免伤，点前突策略时需考虑盾数量和旗舰盾被打掉的风险
- 大盾不点前突策略可减少旗舰被攻击概率，省战损点

## 适用限制
- 天权不适合单战群，需多战群配合
- 五九必须不点前突策略，否则战损高
- 大毛需保证旗舰生存，不能掉旗舰
- 大盾点前突策略时需带满6个盾，否则风险大
- 扛伤战群需考虑队友支援和战损值，不值时可撤退
