# B资料1-28 · 三航母账号配置与舰船点评

## 结论
- 账号质量高，点数平均分配后可玩三航母。
- 三航母为满模块太阳鲸-武装战略航空母舰（原文为「鱼」，疑似简称）、差一个模块的永恒苍穹级-无人机航空母舰（原文为「苍穹」，疑似简称）和白板天枢级-支援航空母舰（原文为「天枢级-支援航空母舰」，疑似语音识别错误）。
- 舰载机基本齐全：维塔斯-B010-轰炸机（原文为「维b」，疑似简称）、海氏追随者型-脉冲攻击机（原文为「海狮」，疑似语音识别错误）、林鸮A100型-联合攻击机（原文为「林鸮A100型-联合攻击机」，疑似语音识别错误）。
- 可用护航艇有四个：星云追逐者-脉冲炮艇（原文为「星脉」，疑似简称）、CV-T800型-脉冲炮艇（原文为「八百」，疑似简称）、坦普尔1号-信息护航艇（原文为「坦克」，疑似语音识别错误）、天枪-战术护航艇（原文为「天枪」，疑似简称）。
- 天枪-战术护航艇是维塔斯A021-重型攻击机（原文为「VA」，疑似简称）的上位替代。
- 维塔斯A021-重型攻击机是导弹武器，单发低、破不了防、易被拦截，只能靠殉爆打伤害。
- 天枪-战术护航艇是等离子武器无法被拦截，能量伤害且有伤害保底。
- 天枪-战术护航艇打系统效率与维塔斯A021一致，动力系统与绝育效率也相同。
- 天枪-战术护航艇策略可降目标闪避，能针对永恒风暴级-攻击战列巡洋舰（原文为「风暴」，疑似简称）的C2配置，并有类似分散打击的效果。
- 天权级-重型防御战列巡洋舰（原文为「天泉」，疑似语音识别错误）为白板。
- 安东塔斯持剑者级-指挥舰（原文为「大剑」，疑似简称）只有一个模块（A1+A2），但算小毕业、能用。
- 大剑A1是轨道炮直射武器，面板不高、输出效率低，不如带卡利斯托-重型鱼雷袭击舰（原文为「重卡」，疑似简称）。
- 大剑A2自带能量鱼雷，有保底伤害且面板不错。
- 大剑的残血斩杀机制在克岛内战与超主力对战中很强，能快速打战损建立优势。
- 普鲁图斯之盾级-防护战列巡洋舰（原文为「大盾」，疑似简称）3.0有重甲，乌拉诺斯之矛（原文为「大毛」，疑似简称）有中甲模块。
- 永恒风暴级-攻击战列巡洋舰的白板模块不用看。
- 点数玩三战巡可以，玩四战巡勉强，所以乌拉诺斯之矛可以不考虑。
- 普鲁图斯之盾级伤害低但抗伤能力比乌拉诺斯之矛强，乌拉诺斯之矛的抗性在抗伤战巡里垫底。
- 巡洋舰主要看有没有卡利斯托-重型鱼雷袭击舰，该号有；猎兵、狩猎者不用看。
- 小船用不到，不用考虑小船。
- 主队走现在常用的苍鱼队。
- 狩猎者不推荐超斩，超斩后对空下降，需要针对对面海尔波普-维修支援护航艇（原文为「海尔兄弟」，疑似简称）的维修量。
- 副队是风盾队。
- 副队不带拦截：大盾护甲高，现版本实弹武器大部分伤害都能挡住，拦截需求不高。
- 若对面新君士坦丁大帝级-综合战列巡洋舰（原文为「大帝」，疑似简称）威胁到CAS066，可以下掉光锥级-综合导弹巡洋舰换一艘拦截舰。

## 配队与模块
- 主队（苍鱼队）：3个永恒苍穹级-无人机航空母舰，携带林鸮A100型-联合攻击机与CV-T800型-脉冲炮艇。
- 主队：3个狩猎者级-载机巡洋舰（原文为"狩猎者"，疑似简称），携带海氏追随者型-脉冲攻击机（原文为「海蛇」，疑似语音识别错误）；不推荐超斩。
- 主队：3个猎兵级-重型载机巡洋舰（原文为"猎兵"，疑似简称）走超斩，带10个星云追逐者-脉冲炮艇与2个CV-T800型-脉冲炮艇。
- 主队：3个卡利斯托-重型鱼雷袭击舰补伤害，3个安东塔斯持剑者级-指挥舰作为主要伤害来源。
- 主队：1个光锥级-区域防空巡洋舰（原文为「光防」，疑似简称）当旗舰。
- 主队支援：三个「十一」、两个「十三」编队（原文如此），编队内带坦普尔1号-信息护航艇与天枪-战术护航艇。
- 舰载机另有米斯特拉-战斗攻击机（原文为「小米」，疑似简称）与刺鳐-鱼雷轰炸机（原文为「思瑶」，疑似语音识别错误）；两个「十三鱼」编队（原文如此）带VB050（BR050系列轰炸机）。
- 副队（风盾队）：中排1个A3普鲁图斯之盾级-防护战列巡洋舰（A模块）。
- 副队：6个永恒风暴级-攻击战列巡洋舰放在中排，3个C3+3个C2，C2加buff、C3作主要抗性。
- 副队：8个CAS066级（原文为「六六」，疑似简称）、6个光锥级-综合导弹巡洋舰（原文为「股权」，疑似语音识别错误），不带拦截。
- 副队支援：5个普鲁图斯之盾级-防护战列巡洋舰（前排A1大盾）。
- 护航艇可互换：把支援编队里的天枪-战术护航艇换成星云追逐者-脉冲炮艇、把猎兵里的星云追逐者-脉冲炮艇换成天枪-战术护航艇都可以，看个人理解。
