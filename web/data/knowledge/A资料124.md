# A资料124

## 场景 / 对手
萌新八载机CV3000配队讨论，正面输出环境

## 舰队例子
- CV3000（8载机）+ B4无人机模块（满加成）+ 索姆河、苏杯、B2050等对舰输出舰船（胜）【B4模块输出达17000/分钟，相当于5艘CV携带2艘金康纳马拉高速等离子巡洋舰】
- 猎兵（狩猎）+ 载机 + 骑兵（防控）（胜）【猎兵提供信息链，骑兵防控】
- 海脉冲、水母等小型高输出舰船 + 康纳马拉高速等离子（胜）【配合能量输出，适合萌新】

## 实战结果
萌新使用八载机CV3000配B4模块，输出超过B2三加成垃圾护航体模块，实战中表现良好

## 结论思路
- B4无人机模块满加成输出达17000/分钟，相当于5艘CV携带2艘金康纳马拉高速等离子巡洋舰
- CV Boost后可持续输出，增援舰队选择5艘8级航母
- 优先携带索姆河，但索姆河单发不强，面对高护甲大船乏力，不推荐放猎兵主队
- 能量输出是萌新最佳攻击手段，即使现在流行开阳瑶光

## 适用限制
- 适用于萌新玩家，能量输出对高护甲大船效果有限
- 索姆河不适合对抗高护甲大船
- 需配合CV Boost和增援舰队
