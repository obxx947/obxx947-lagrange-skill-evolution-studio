# A资料221

## 场景 / 对手
前期舰队主要输出，后期配合开阳、瑶光体系

## 舰队例子
- 次水母（战斗无人机，能量伤害）（胜）【前期T0级输出，伤害高且不被拦截】
- 开阳（前排）+ 瑶光 + 次水母（点策略优先攻打超主力舰）（胜）【后期可跳过开阳直接攻击超主力舰】
- 泡泡龙（直射武器）（负）【无法攻击中排和后排，实测无法打出伤害】

## 实战结果
次水母对比泡泡龙，次水母胜，泡泡龙因直射武器限制无法有效输出

## 结论思路
- 次水母拥有特殊战斗无人机，能量伤害高且不被拦截
- 前期作为舰队主要输出，打人打成都是T0级别
- 后期配合开阳前排和瑶光，点策略可优先攻打超主力舰，跳过开阳
- 泡泡龙直射武器无法攻击中后排，性价比低
- 次水母能使战损最大化

## 适用限制
- 适用于平民玩家，从头到尾可用
- 泡泡龙不适合作为主要输出，因直射武器限制
- 次水母需点策略以发挥后期跳过前排能力
