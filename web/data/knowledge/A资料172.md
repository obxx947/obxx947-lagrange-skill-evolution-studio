# A资料172

## 场景 / 对手
塔拉萨萤石级驱逐舰新版本更新后实战测试，对手为白垩纪巡洋舰体系，正面作战环境

## 舰队例子
- 塔拉萨萤石级驱逐舰主型号，60蓝点，满配电子干扰系统（加点二频率、二命中），装甲系统（加点二结构），动力系统（紧急闪避）（胜）【利用驱逐舰数量优势，在无大船抗伤时仍能发挥作用，避免巡洋瞬间暴毙】

## 实战结果
塔拉萨萤石级驱逐舰对阵白垩纪巡洋舰，多场测试，塔拉萨胜多负少，关键得失为驱逐舰数量弥补单体劣势，巡洋舰因体力不足易暴毙

## 结论思路
- 塔拉萨萤石级驱逐舰是巅峰驱逐舰，未在公告中明确说明
- 主型号优先干扰护航艇，具有白垩纪没有的特性
- 驱逐舰在无大船抗伤时仍能发挥作用，巡洋舰体力不足会瞬间暴毙
- 加点优先电子干扰系统（二频率、二命中），装甲系统（二结构），额外蓝点加动力紧急闪避

## 适用限制
- 适用于无大船抗伤的早期或低配战场
- 需要足够蓝点（60点）支持满配加点
- 不适用于已有强力巡洋舰抗伤的后期场景
- 注意加点时避免误点对区户命中，应专注干扰和结构
