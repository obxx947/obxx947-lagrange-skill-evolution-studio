# A资料153

## 场景 / 对手
新版本更新后，输出巡洋选择，涉及重卡泡泡龙和阳光组合等体系，正面作战环境

## 舰队例子
- 重卡泡泡龙（重卡+泡泡龙）（胜/评价：策略优先打击战巡，有增伤，但面对阳光组合不稳定）【重卡策略好，不乱打；泡泡龙人口反大，dpm爆发与风暴相当】
- 星脉超斩（星脉）（负/评价：骗局，需破掉前台泡泡龙才能发力）【适合做超展，不适合单挑；辛娜不要超整】

## 实战结果
玩家分析输出巡洋选择，重卡泡泡龙在特定条件下有效，但面对阳光组合不稳定；星脉超斩表现不佳，需配合其他输出打穿前排

## 结论思路
- 输出巡洋分三个阶段，第一阶段选重卡泡泡龙
- 重卡策略优先打击战巡，有增伤优势
- 泡泡龙人口反大，dpm爆发与风暴相当，但受阳光组合影响不稳定
- 若巡洋输出占大头，面对中排大船乏力，泡泡龙打不穿前排
- 星脉超斩是骗局，需破前台泡泡龙才能发力
- 星脉适合做超展，不适合单挑；辛娜不要超整
- 配合其他输出可打穿前排

## 适用限制
- 适用于新版本输出巡洋配船选择
- 重卡泡泡龙面对阳光组合时不稳定
- 星脉超斩需破前台泡泡龙，否则无效
- 不适合喜欢单挑的玩家使用星脉超斩
