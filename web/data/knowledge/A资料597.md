# A资料597 · CV3000级B4模块伤害测试

> 场景：靶船（原文为“把船”，疑似语音识别错误）为航母、战巡、巡洋及1艘小船

## 结论
- B4模块为非对空模块，加索敌无收益。
- 航母主要作用仍是携带舰载机，不指望该模块提供高输出。
- 当前输出表现比较满意。
- 攻击序列优先锁定战巡，其次航母，具超斩属性。
- 适合放入主舰队作输出补充，属锦上添花模块。

## 配队与模块
- CV3000级-快速航空母舰（原文为“cv”，疑似简称）装配B4模块（原文为“b四模块”，疑似语音识别错误）；加点全输出，索敌（原文为“索迪”，疑似语音识别错误）不点。

## 数值与数据
- 作战时长3分钟。
- 反大伤害5.91万/分钟；反小伤害6.39万/分钟。
- 索敌与冷却均为6秒；转火时同步计算，首波出击不计冷却时间。
