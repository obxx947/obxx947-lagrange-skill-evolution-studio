# A资料506 · 轰炸教学全面翻新

> 场景：轰炸队/封锁防空/挡刀艇

## 结论
- 新出盘古及新机制加入，旧轰炸教学已滞后，以本版为准
- 本体无增援，指挥值420
- 锁母盒以三架为一个编队吃集群作战，分三个苍穹各放一个锁母盒加三个一放，刚好九个
- 苍穹剩余一个载机位可补八百或任意单位，按个人喜好
- 苍穹载机干扰机可选SC002型-量子侦察机（原文为"零零二"，疑似语音识别错误）、AT021-战术攻击机-B（干扰型）（原文为"零二幺b"，疑似语音识别错误）或平衡安德森SC020-侦察机（原文为"安德森"，疑似简称）
- 平衡安德森SC020-侦察机因服役限制只有十个，待不满且需同时养两个干扰机，不划算，主推AT021-战术攻击机-B（干扰型）和SC002型-量子侦察机
- 挡刀艇用CV-II003型-轻型护航艇（原文为"零三"，疑似语音识别错误），放在有汽车索尼的载具上并加点正确即可挡刀
- 新飞机不能点冷却，点冷却后波次会落到最后面，不点冷却可跑到CV-II003型-轻型护航艇前面
- 苍穹选M3模块，M2模块触发有条件，运气不好不触发闪避，M3对挡刀艇掩护更稳定
- 猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误）舍弃一个伤害换导弹闪避，因天机出现后挡刀艇占比变大且封锁防空强，导弹闪避很有必要
- AC721-重型两栖突击舰（原文为"七幺幺"，疑似语音识别错误）不点导弹闪避，该闪避施加给待机船自身，不施加在舰载机上
- 海氏追随者型-脉冲攻击机（原文为"海事"，疑似语音识别错误）不建议放苍穹，苍穹锁敌加成只有50%，不足以满锁，出伤效率低
- 海氏追随者型-脉冲攻击机对空和打小船伤害很低
- 轰炸时舰载机吃不到母舰策略，海氏追随者型-脉冲攻击机做不到超展，会优先防空且防空伤害不高
- 若坚持用海氏追随者型-脉冲攻击机，建议选苍穹M2，M2加点与M3一致，仅提供效果不同
- 不推荐用米斯特拉-战斗攻击机（原文为"meceva"，疑似语音识别错误）和林鸮A100型-联合攻击机进行绝育，苍穹M5快在轰炸时更多充当挡刀能力，往复战机输出很低
- 林鸮A100型-联合攻击机等往复战机第一轮输出时极大概率直接毙命，往往只能造成第一轮绝育，打不出战损

## 配队与模块
- 本体无增援，指挥值420
- 永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）×5，猎兵级-重型载机巡洋舰×8，AC721-重型两栖突击舰×5
- 苍穹载机：锁母盒×1加一放×3，分三个苍穹各放一组，共九个
- 苍穹剩余载机位补CV-T800型-脉冲炮艇（原文为"八百"，疑似语音识别错误）或任意单位
- 苍穹干扰机可选SC002型-量子侦察机、AT021-战术攻击机-B（干扰型）或平衡安德森SC020-侦察机
- 挡刀艇用CV-II003型-轻型护航艇，放在有汽车索尼的载具上
- 风好位置可换CV-T800型-脉冲炮艇或RB7-13型-导弹艇（原文为"rpg"，疑似语音识别错误）等任意护航艇
- 苍穹模块选M3，M2为备选
- 苍穹M2加点与M3一致，仅提供效果不同
- 猎兵级-重型载机巡洋舰加点：舍弃一个伤害换导弹闪避
- AC721-重型两栖突击舰加点：不点导弹闪避
- AT021-战术攻击机-B（干扰型）加点参考图
- 海氏追随者型-脉冲攻击机轰炸加点：不点香味性能打击，因该技能对空无帮助
- 海氏追随者型-脉冲攻击机配苍穹M2
