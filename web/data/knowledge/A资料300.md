# A资料300

## 场景 / 对手
反驱护实战测试，对比星云A（星云弹炮型）与蜂巢，靶船为高出场率驱护，环境为接近真实战况

## 舰队例子
- 10个蜂巢护航艇（胜（伤害37万））【作为对比组】
- 10个星云A（星云弹炮型）护航艇（胜（伤害102万））【主武器实弹，优先打击驱护，无视瑶光能量护盾】

## 实战结果
十个蜂巢打三十七万伤害，十个星云A打一百零二万伤害，星云A伤害接近蜂巢三倍，反驱护能力大幅超过蜂巢

## 结论思路
- 星云A是T0主力输出，强度高
- 主武器实弹，优先打击驱护，克制小船
- 无视瑶光能量护盾，反扫效果显著
- 实战反驱护能力大幅超过蜂巢，值得携带

## 适用限制
- 适用于反驱护场景，对驱护目标效果突出
- 不适用于对大型舰船或非驱护目标，可能效果有限
