# A资料586 · 护航输出队搭配思路

> 场景：单挑或半夜偷家，不考虑防空

## 结论
- 优先拉飞机和护航艇，之后考虑战巡，最后才考虑巡洋舰
- 飞机和护航艇同人口输出更高，且可无视站位直接攻击敌方序列舰船
- 这个版本是飞机海的天下，飞机只要有伤害，打系统或打结构值都带
- 能量直射能打多少输出取决于敌方开阳级驱逐舰和瑶光级护卫舰能活多久
- 能量直射需先清掉前排舰船，才会集中火力攻击敌方中排战巡和巡洋舰
- 开阳级驱逐舰闪避率极高，瑶光级护卫舰可给小船施加能量护盾，导致能量直射打不出伤害
- 能快速清掉敌方开阳级驱逐舰和瑶光级护卫舰时，直射武器也可以用
- 推荐能量反大、实弹反小，先用实弹清小型舰船，再用能量输出集火大船
- 平民玩家战巡缺模块无法使用时，才考虑巡洋舰输出
- 能量直射被开阳级驱逐舰和瑶光级护卫舰克制，非被逼无奈不推荐

- 护航艇推荐：索姆河之影-装甲飞行坦克（原文为"索姆河"，疑似简称）、CV-T800型-脉冲炮艇（原文为"800"，疑似简称）、RB7-13型-B-突防护航艇（原文为"rb7突防"，疑似简称）
- 缺输出时护航艇可上天玑-攻击护航艇（原文为"天玑护航艇"，疑似简称）
- 飞机拉完后人口约230，剩余人口考虑战巡，主推永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）输出
- 永恒风暴级-攻击战列巡洋舰M2投射武器无法被拦截，输出稳定
- 超主力模块充足时可用安东塔斯持剑者级-指挥舰（原文为"大剑"，疑似简称）和新君士坦丁大帝级-综合战列巡洋舰（原文为"大帝"，疑似简称）
- 巡洋舰缺卡利斯托-重型鱼雷袭击舰（原文为"重卡"，疑似简称）时，放弃艾奥级-B-高速离子炮巡洋舰（原文为"高速艾奥"，疑似简称），改用奇美拉级-B-火炮巡洋舰（原文为"奇美拉弹炮"，疑似简称）实弹反小、康纳马拉混沌级-B-高速等离子体巡洋舰（原文为"康纳马拉混沌离子"，疑似简称）能量反大
- 实弹反小推荐BR050-鱼雷轰炸机-C（鱼雷型）、RB7-13型-B-突防护航艇
- 能量输出推荐星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）、CV-T800型-脉冲炮艇、海氏追随者型-脉冲攻击机、林鸮A100型-联合攻击机（原文为"林鸮"，疑似简称）
