# A资料527

## 场景 / 对手
当前版本开阳、遥光等前排高闪避小船副队盛行，直射武器难以输出，输出战巡用于绕过前排直射克制，实现全方位打击

## 舰队例子
- 大地：a1+m1+b2+c1（可选下e模块）+a2核心（负）【a1暴击依赖m1锁定目标半血以下，但面对高护甲或拦截时dppm极低（614-416），当前版本表现不佳】
- 雷火：m2+a2+b2+c2+d2（胜）【m2能量鱼雷可绕过直射克制，dppm高达1650-1418，反拦截加点使其不惧拦截，是测试中最意外的高输出】
- 风暴：m2+a2+b2或d2+c3（主队）/c2（副队）（负）【保底伤害稳定但面对高能抗或拦截时dppm仅556-646，表现拉胯，不如雷火】

## 实战结果
测试了除持剑外所有输出战巡（大地、雷火、风暴）对四种目标（无拦截高护甲、无拦截低护甲、有拦截高能抗、有拦截高护甲），雷火全面胜出，大地和风暴均不理想

## 结论思路
- 选择输出战巡原因：绕过开阳等前排高闪避小船，直射武器打不出输出，战巡人口伤害优于巡洋
- 战巡输出火力不能是直射，雷火m1/m3、大地m2等直射模块自动淘汰
- 大地a1暴击判定依赖m模块锁定目标，m1直射更容易让前排大船半血触发暴击
- 雷火m2能量鱼雷有反拦截加点，不惧拦截，是当前版本最优选择
- 风暴适合主队扛伤选c3，副队套盾选c2，但输出上限有限

## 适用限制
- 大地仅适合打无拦截低护甲单位，面对高护甲或拦截时输出大幅下降
- 雷火需要时间叠层，短时间战斗伤害未达巅峰，且能量鱼雷仍会被拦截
- 风暴不适合高能抗或高拦截环境，仅作保底输出
- 持剑为公认最强输出战巡，未纳入测试
