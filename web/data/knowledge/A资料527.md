# A资料527 · 输出战巡选择与模块测评

> 场景：当前版本开阳、瑶光等高闪避前排小船副队盛行；测试目标含无拦截单附加盾、单附加天枢级-支援航空母舰、带拦截补偿风暴、带拦截附加盾

## 结论
- 当前版本直射武器难打高闪避前排小船，巡洋人口伤害不如战巡且易被直射克制，因此输出优先选战巡
- 输出战巡主火力不能是直射，雷火之星M1、M3自动淘汰
- 输出战巡可绕过开阳这类难啃前排，并做到全方位打击
- 输出战巡能分散奶量，避免对方高额奶量过于集中
- 输出战巡可直接打击序列中的目标
- 新君士坦丁大帝级A1因半血以下暴击策略优于A2
- 新君士坦丁大帝级A1暴击目标判定跟随M模块锁定目标，M模块为直射，前排小船或前排战巡更易先到半血以下触发暴击
- 雷火之星M2可绕过开阳，M1、M3直射不推荐
- 雷火之星A系统为直射反小火炮，A1单发伤害比A2更尴尬，A2单发更高，但影响不大
- 雷火之星B2为反导且有一定防空能力，体验服加强防控协调效率后防空增强；没有B2可用B1
- 雷火之星C系统因M2不太吃命中，且M2对全舰武器有高加成，每隔六秒激发随机武器额外射击
- 雷火之星可下掉E模块，让舰首M2武器更容易吃到C1激发
- 永恒风暴级在当前开阳前排盛行下直射武器打不出输出，M2配B2或D2可用于防空
- 永恒风暴级放主队或副队作主要扛伤选C3，放副队给其他战巡或航母套能量盾选C2
- 永恒风暴级A2大核心必须有，没有A2就是直射战巡，不建议玩
- 安东塔斯持剑者级是当前版本公认最强输出战巡，未参与测试
- 新君士坦丁大帝级当前版本表现不行，多组测试DPM均未超过1000
- 新君士坦丁大帝级相比高护甲更怕拦截
- 雷火之星M2是本次测试中最意外的输出战巡，DPM非常高
- 雷火之星M2主要伤害来源为能量武器，打高护甲无拦截目标畅通无阻
- 雷火之星M2有反拦截加点，并不非常惧怕拦截
- 永恒风暴级定位是保底伤害战巡，测试表现中规中矩
- 永恒风暴级打补偿风暴时因补偿装甲能抗太高且物理能量双减伤，DPM惨淡
- 永恒风暴级打五光防加附加盾时表现拉胯，伤害没比新君士坦丁大帝级好多少
- 当前输出战巡优先顺序：安东塔斯持剑者级、M2雷火之星、M2永恒风暴级、新君士坦丁大帝级
- 新君士坦丁大帝级甚至可换成卡利斯托-重型鱼雷袭击舰（原文为"重卡"，疑似简称），重卡效果可能更好
- M2雷火之星需要对应模块，没有模块就选有模块的下位替代
- 雷火之星M1、M3仍不推荐使用
- 策划方向是让永恒风暴级去副队，雷火之星代替永恒风暴级主队位置

## 配队与模块
- 新君士坦丁大帝级推荐M1+A1
- 雷火之星推荐M2+B2+C1，可下掉E模块
- 永恒风暴级推荐M2+A2+B3+C2+D2
- 永恒风暴级主队或副队主要扛伤选C3，套能量盾选C2
- 测试中永恒风暴级带D2未带D1，更贴近实战
