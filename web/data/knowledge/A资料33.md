# A资料33

## 场景 / 对手
战略打击舰载机出击顺序测试，涉及炮艇混编、轰炸环境

## 舰队例子
- 星脉801（攻击持续时间短）（胜）【优先出击，但第一波易被秒，需保护】
- 零零三（点策略）（胜）【可替星脉挡刀，优先级最高】
- 八百（保留策略）（胜）【降低冷却策略可提前出击顺序】
- 瑶（降低冷却策略）（胜）【优先级低于零零三和星脉】
- 虚灵、RB7、蜂巢（测试冷却影响）（负）【RB7总时间高，出击顺序靠后】
- 新炮（负）【无法稳定为星脉挡刀，无降低冷却策略】

## 实战结果
测试了攻击持续时间、冷却时间、锁敌时间对出击顺序的影响；结论是出击顺序由攻击持续时间和冷却时间总和决定，锁敌时间无影响；零零三可挡刀，新炮不能

## 结论思路
- 战略打击波次顺序由攻击持续时间和冷却时间相加的总时间决定，时间越高出击越靠后
- 锁敌时间对出击顺序无影响，调整锁敌无法保护星脉
- 降低冷却时间的策略可提前出击顺序，如零零三、星脉、八百、瑶
- 零零三策略优先级最高，可替星脉挡刀
- 新炮无法稳定挡刀，因无降低冷却策略且总时间高于星脉

## 适用限制
- 适用于战略打击中炮艇混编场景
- 需点策略才能发挥挡刀效果
- 不适用于战机，因战机第一波易被消灭
- 母舰选择需避免索敌干扰，如太阳星
