# A资料33 · 战略打击舰载机出击顺序测试

> 场景：战略打击/护航艇波次顺序测试

## 结论
- 战略打击波次顺序不看锁定时间，锁敌时间对出击顺序无影响
- 出击顺序由攻击持续时间与冷却时间相加的总时间决定，总时间越高越靠后
- 降低冷却时间的策略会被提前计入总时间，从而提升出击顺序
- 护航艇中带降低冷却策略的有800、星脉、003、摇
- 003点策略后优先级最高，可在星脉前出击挡刀
- 星脉下策略、800保留策略时，星脉会排到800后面
- 星炮无法为星脉稳定挡刀，无降低冷却策略且总时间更长
- 战机第一波基本送掉，战略打击核心仍是炮艇

## 配队与模块
- 测试母舰用太阳鲸，不点索敌，双反点满
- 003需点策略才能在星脉前出击挡刀
- 800、星脉可通过是否点策略调整出击顺序
- 星脉、800、003、摇四个炮艇带降低冷却策略

## 数值与数据
- 800攻击循环4.8秒，011攻击循环2.6秒
- RB7攻击循环高达22秒
- 蜂巢点冷却时总时间15.2秒，下冷却后总时间20秒
- 摇总时间5.6秒，800总时间4.8秒
- 降低冷却策略优先级：003最高，其次星脉，然后800，最后摇
