# A资料463 · 投射配置思路

> 场景：投射队对066常规奶队与天枢级-支援航空母舰（原文为"天书"，疑似语音识别错误）高达队

## 结论
- 投射武器按分摊原则和攻击策略选目标
- 舰载机固定带六个：三个战机三个炮艇，多余机位补050、维A、小米
- 舰船只推荐风暴和大剑
- 风暴必须有M2，大剑A2可用，抽到B3毕业
- 没有风暴和大剑可用重卡和大地替补，但会被拦截、输出不稳定
- 大地单发打中甲费劲
- 没有风暴和大剑又不想玩直射只能退而求其次
- 投射配置现版本优势大，直射三分钟没打穿前排时投射可能已打掉超主力
- 投射缺点：面对少量超主力的066奶队集火换战损效率高
- 对手是多超主力高达配置时投射集火优势消失，换战损不如直射队
- 没有天枢级-支援航空母舰的配置奶妈一定是066，让投射打066逼它修自己
- 066护甲低、维修争议差，开始修自己就顾不上超主力
- 所有舰载机全部超载，趁断奶空窗期集火超主力斩杀
- 除重卡外上述舰船都能做到断奶
- 天枢级-支援航空母舰高达队断奶无意义，天枢级-支援航空母舰维修量比066高、抗性高、转火快
- 直射核心思路是穿防效率，投射核心思路是火力密度
- 面对多超主力配置输出分叉，总火力高则变为覆盖
- 多战巡多航母配置能让部分舰载机在专用航母上发挥更强
- 星脉放鱼里伤害高很多，投射为主也可放鱼里提高总火力
- 800同理，为节约人口拉战巡一般放航母上面对空
- 提高舰队总火力，微弱优势在天枢级-支援航空母舰内战可能是决胜关键
- 投射火力主要集火大转、太阳耀光，不用管
- 没必要浪费人口针对大转、太阳耀光
- 箭队机位足够可携带绝育主武器战机降低对方副队伤害
- 信系列在投射队很重要，决定800和小米能否先清完战机参与对决或协助打炮艇
- 防空在天枢级-支援航空母舰内战关键，靠空优机压低海尔兄弟维修量并应对轰炸

## 配队与模块
- 风暴：M2
- 大剑：A2可用，B3毕业
- 替补：重卡、大地
- 舰载机固定：三个战机、三个炮艇
- 多余机位补：050、维A、小米
- 800放航母上面对空
- 星脉放鱼里
- 箭队机位足够时携带绝育主武器战机
