# A资料463

## 场景 / 对手
当前版本，对手为常规奶队（零六六）和天书高达队，正面作战

## 舰队例子
- 风暴（M2模块）+ 大剑（A2模块，B3毕业）（推荐）【投射输出核心，需特定模块】
- 重卡或大地（替补）【会被拦截，输出不稳定，大地单发打中甲费劲】
- 舰载机：三个战机+三个炮艇（必备），多余机位补充零五零、为a四幺、小米（必备）【所有配对必备】
- 星脉（放鱼或猎兵超转）（评价）【放鱼伤害更高，提高总火力】
- 八百（放航母）（评价）【节约人口，对空】

## 实战结果
投射队对零六六奶队集火换战损效率高；对多超主力高达队换战损能力不如直射队。

## 结论思路
- 投射武器按攻击策略选择目标，遵循分摊原则
- 投射队核心思路是火力密度，直射是穿防效率
- 面对无天书配置，让六六修自己断奶，舰载机超载集火超主力
- 面对天书高达队，断奶无意义，需提高总火力覆盖
- 提高总火力是决胜关键，包括舰载机配置和舰船选择

## 适用限制
- 适用于前排小船配置，投射优势大
- 面对多超主力时投射集火优势消失
- 没有风暴和大剑时，替补选择输出不稳定
- 天书内战需防空和信系列支持
