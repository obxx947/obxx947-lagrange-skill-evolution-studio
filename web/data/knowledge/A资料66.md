# A资料66 · 大帝输出环境与断奶能力

> 场景：高端局光防拦截环境

## 结论
- 大帝是战巡中输出最高的，打靶反大分伤30万-48万/分钟
- 大帝A1策略血量越低伤害越高，分伤极限不止48万
- 大帝最低分伤也超过混沌轨道和风暴
- 大帝能进主队，但必须看战况
- 对面拦截少时，大帝进主队完全没问题
- 打城、打NPC、打低端局适合上大帝
- 对面光防多时，大帝抢伤害能力比不过舰队中其他输出
- 光防满天飞的高端局，大帝210人口每分钟18万输出，性价比不如混沌轨道
- 大帝能断奶，攻击序列和风暴一样
- 对面拦截很高时，带大帝断奶不理智，可能连66都打不动
- 高端局主力队普遍不带很高投射火力，光防带太多浪费人口
- 光防是投射武器针对卡，对面不带投射时意义消失
- 大帝输出依然耀眼，但已被版本淘汰

## 配队与模块
- 大帝模块：M1、A1、B1、C3
- 测试输出方：6个大帝
- 测试防御方：奶矛、前排小船、大矛在中台
- 拦截测试：3个光锥级-区域防空巡洋舰（原文为"光防"，疑似简称）
- 拦截测试：5个光锥级-区域防空巡洋舰

## 数值与数据
- 6大帝打靶：9分45秒结束，总伤害320万，分伤32.86万/分钟
- 6大帝+3光防：15分钟，总伤害接近400万，分伤26.37万/分钟
- 6大帝+5光防：半个多小时，总伤害634万，分伤18万多/分钟
- 大帝人口：210（6艘）
- 大帝反大打靶分伤：30万-48万/分钟
