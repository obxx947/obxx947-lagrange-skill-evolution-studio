# A资料66

## 场景 / 对手
针对大帝战巡在高端局与低端局中的输出环境测试，涉及拦截（光防）影响

## 舰队例子
- 6个大地（M1、A1B1、C3模块），满调效（胜）【打靶测试，9分45秒结束，总伤害320万，分伤32.86万/分钟】
- 6个大地 + 3个光防（负）【作战时长15分钟，总伤害近400万，分伤26.37万/分钟，输出被拦截限制】
- 6个大地 + 5个光防（负）【作战时长超30分钟，总伤害634万，分伤仅18万/分钟，输出大幅下降】

## 实战结果
大地打靶测试：无拦截时输出高（分伤32.86万），加入3个光防后分伤降至26.37万，5个光防时降至18万；大地在拦截环境下性价比低，不适合高端局

## 结论思路
- 大地输出数据最高，打靶分伤30-48万/分钟，策略血量越低伤害越高
- 大地能否进主队取决于作战环境：拦截少时（打城、NPC、低端局）可带，拦截多时（高端局）不建议
- 大地能断奶，但拦截高时输出受限，断奶效果差
- 光防是针对性卡，数量需根据对面投射火力调整，高端局通常带3个而非5个

## 适用限制
- 适用于拦截少的环境，如打城、打NPC或低端局
- 不适用于高端局，光防满天飞时大地输出性价比低
- 断奶时需考虑对面拦截强度，拦截高时不建议带大地
