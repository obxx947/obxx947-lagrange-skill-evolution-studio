# A资料621 · 中甲五九碰瓷队战报解析

> 场景：轰炸/缝合队

## 结论
- 中甲五九碰瓷队防空与抗伤能力均在线，两分钟可打23万以上防空伤害
- 五九能吸引坦克火力并保持满血，保护小船生存
- 碰瓷队尽量不支援，避免浪费策略，直接返回仅消耗5策略
- 七二一导弹对空基础命中60%，加上母舰与自身命中加成，对空军杀伤力大
- 七二一导弹在五九战场有策略可提高40%命中，强度很高且造价便宜
- 剑对空命中只有50%-70%，中型更低，命中低对空军威胁小
- 股神伤害低是因为去打安德森和AT021，两者闪避高且股神基础命中低
- 不推荐碰瓷队带股神、苔原，打战机浪费人口且伤害不高
- 股神、苔原要搭配十三鱼使用，小米清理安德森后再打炮艇才快
- 后期可支援五九带舰载机分散八百伤害，提高小船生存
- 枪防攻击循环慢，冷却11秒锁敌4秒，抢伤害能力弱，主要作用是提供旗舰
- 十三鱼碰瓷队策略消耗严重，中甲五九碰瓷队日常使用更省策略
