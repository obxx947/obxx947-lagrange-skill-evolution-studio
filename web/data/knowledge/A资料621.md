# A资料621

## 场景 / 对手
控制超主力对接点出巅峰凭证；中甲五九碰瓷队防空与抗伤实战

## 舰队例子
- 五鱼一毛，十二肉，又奈三光追防空，协助控制，带上落马云海水母，氙灯，共四十艘登陆舰，航母搭载小米、vb、海狮、t八百、索姆河等，氙灯里塞雷神、沙龙或盘古飞机（胜）【控制超主力对接点，有门槛但无敌】
- 中甲五九，十个七二一导弹，十个股神，十个斗牛，防御十个枪防，总人口328（320人口下股神一个）（胜）【防空伤害两分钟23万+，五九满血，抗伤强】
- 中甲五九，多带七二一导弹，人口拉高（胜）【防空伤害一分半22.85万，斗牛防御8万，无战损】

## 实战结果
控制超主力对接点：硬控14个超主力对接点，出诺马航母巅峰凭证，太阳精升7级巅峰。中甲五九碰瓷队：对缝合队（新麦坦克、零零三炮灰、新麦八百坦克等）多场战报，2分钟防空23万+，1分半22.85万，2分半37万，五九满血，小船少量损失，整体胜多负少

## 结论思路
- 控制超主力对接点：三级对接点为主，极少数二级，刷在五级以上城市或城市群周边工业基地；维克托城可退小队当散人无视限制；工业基地对接点可打掉拆除刷新
- 中甲五九碰瓷队：五九吸引坦克伤害，小船针对新麦，防空能力强，两分钟23万+伤害
- 七二一导弹：基础命中60%，母舰和自身命中加成，五九战场策略提高40%命中，对空杀伤大，造价便宜
- 斗牛防御：防空伤害最高，两分钟4万+，强度高
- 枪防：攻击循环慢（冷却11秒，锁敌4秒），伤害不稳定，主要提供旗舰
- 股神：打高闪避目标（安德森、at零二幺）效率低，不推荐碰瓷队带，除非搭配十三鱼小米清安德森
- 碰瓷队不要支援，避免浪费策略，直接回城补船
- 后期可带舰载机分散八百伤害，提高小船生存

## 适用限制
- 控制超主力对接点：需蓝图齐全，有门槛；维克托城限制可退小队规避
- 中甲五九碰瓷队：适合防空和抗伤，但面对高单发坦克（如调校后单发800+）可能破防，需奶妈支援
- 七二一导弹依赖五九策略，无策略时强度下降
- 股神、抬圆等打高闪避目标效率低，需搭配十三鱼小米
- 枪防攻击循环慢，不适合抢伤害
