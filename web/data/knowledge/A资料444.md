# A资料444

## 场景 / 对手
控制超主力对接点，对抗城防和护航艇

## 舰队例子
- 15个T800 + 10个小米（胜）【对防空有效，可对付所有防空】
- 泡泡龙或猎兵其他位置装坦克（胜）【对舰输出，猎兵可解决一切】
- 附加维修巴基天书 + 附加盾 + 附加损管（胜）【抗伤配置，防止控制船暴毙】
- 2个开阳或卡特（胜）【必须带，用于抗伤】

## 实战结果
主包控制超主力对接点，空78个未出巅峰认证道具，但成功消灭目标护航艇，雷达回波消失

## 结论思路
- 控制超主力对接点有概率获得巅峰认证道具，但概率低
- 城防对T800和小米无伤害，可用其应对防空
- 对舰输出依赖猎兵，可解决一切
- 抗伤需带附加维修、盾、损管，以及开阳或卡特防止暴毙

## 适用限制
- 适用于控制超主力对接点场景
- 需要T800和小米数量充足
- 必须配备抗伤船和维修模块
- 不适用于无防空或对舰输出需求低的场景
