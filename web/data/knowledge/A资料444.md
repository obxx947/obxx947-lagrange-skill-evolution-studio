# A资料444 · 超主力对接点控点经验

> 场景：攻城/控超主力对接点

## 结论
- 控制超主力对接点有概率获得对应超主力巅峰认证道具
- 城防对CV-T800型-脉冲炮艇（原文为"T800"，疑似简称）和米斯特拉-战斗攻击机（原文为"小米"，疑似简称）无伤害
- 带15个CV-T800型-脉冲炮艇和10个米斯特拉-战斗攻击机可对付所有防空
- 对舰输出用康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡龙"，疑似简称）或猎兵级-重型载机巡洋舰（原文为"猎兵"，疑似简称）
- 猎兵级-重型载机巡洋舰其他位置装坦克即可
- 理论上输出靠猎兵级-重型载机巡洋舰可以解决一切
- 抗伤用附加维修、附加盾、附加损管
- 不想控制船暴毙必须带2个开阳级-机动驱逐舰（原文为"开阳"，疑似简称）或卡利莱恩级-特种护卫舰（原文为"卡特"，疑似简称）

## 配队与模块
- 15个CV-T800型-脉冲炮艇
- 10个米斯特拉-战斗攻击机
- 对舰输出：康纳马拉混沌级-高速等离子体巡洋舰或猎兵级-重型载机巡洋舰
- 猎兵级-重型载机巡洋舰其他位置装坦克
- 抗伤：附加维修、附加盾、附加损管
- 2个开阳级-机动驱逐舰或卡利莱恩级-特种护卫舰
