# A资料629

## 场景 / 对手
对手/体系：轰炸队；正面或轰炸：轰炸；环境：实战三队配置，需考虑策略消耗

## 舰队例子
- 前排：斗牛x10（防御）、枪系x10（防空，旗舰）；中排：七二一导弹x14、中甲五九x1；后排：股神x10、瑶光x10；支援：无（胜）【主力输出为斗牛、枪防、七二一导弹，打击炮艇；瑶光提升小船心脉抵抗；股神保中甲五九生存】

## 实战结果
谁打谁：瑶光中甲碰瓷队 vs 轰炸队；几胜几负：未明确，但大量实战验证；关键得失：奶量足够，中甲五九屹立不倒，但面对叠加轰炸圈可能战损

## 结论思路
- 碰瓷队不支援，节省策略，适合三队频繁调动
- 不支援性价比高，小船支援不划算，巡洋舰扛不住且防空弱
- 瑶光带十个提高容错率，因持续时间和覆盖范围限制
- 股神十只奶量足够，避免送轰炸圈即可
- 中甲五九提供七二一导弹40%额外命中，不可替换
- 不带台元，因台元优先打战机，对炮艇威胁小，轰炸队战机损失不影响战力
- 配置除股神外全部打炮艇，使对面轰炸队失去持续作战能力

## 适用限制
- 适用于对抗轰炸队，特别是炮艇为主的轰炸
- 不支援航母，否则航母可能顶不住轰炸
- 中甲五九需护甲超700，且推荐中甲五九而非其他战巡
- 台元不适用此配置，但可用于航母碰瓷队
- 若对面坦克多，可能面临极大战损风险
