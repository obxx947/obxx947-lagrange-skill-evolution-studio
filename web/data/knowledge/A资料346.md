# A资料346

## 场景 / 对手
测试CR工程无人机模块的伤害类型，使用电磁59进行对比测试

## 舰队例子
- CR工程无人机模块（未加点）（胜）【对未加点59，4分26秒造成23.5万伤害，其中结构级伤害11.5万】
- CR工程无人机模块（加点）（胜）【对加点电子59，5分24秒造成24.5万伤害，其中结构级伤害12.2万】

## 实战结果
用CR工程无人机模块分别攻击未加点与加点的电磁59，两份战报伤害无明显变化，证明伤害类型为实弹伤害，不受能量护盾影响

## 结论思路
- CR工程无人机模块的伤害类型是实弹伤害，不是能量伤害
- 该模块核心玩法是攻击敌方超主指挥系统和决议，能有效击毁敌方船只
- 对高物抗船只依然强势

## 适用限制
- 适用于需要针对敌方指挥系统的战斗场景
- 对高物抗目标有效，但可能受实弹抗性影响
