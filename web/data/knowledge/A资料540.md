# A资料540

## 场景 / 对手
新护卫舰告示级（出击型/特种型）评测，涉及前期过渡、后期输出、solo与护卫舰玩家视角

## 舰队例子
- 告示级出击型（8人口，2000对剑、2000防空，武器需先防空后对剑）（负）【输出虚高，防空后对剑间歇性，前期伤害不足造价贵，后期易被反手武器锁定剔除】
- 告示级特种型（纯对剑输出，5000+面板，加点后过万，含轨道炮，策略统一目标攻击15秒）（胜）【输出可媲美赤水母，策略配合凯斯瑞士/蓝蝴蝶可秒杀目标，前期后期均看好】

## 实战结果
评测新船告示级，出击型被认为一般（前期伤害不足、后期无用），特种型被认为强（输出高、策略猛），但子型号抽取难度大，主型号不强则整体废铁

## 结论思路
- 新船主型号不强则整船废铁，公式适用于所有新船
- 告示级出击型输出虚高，防空后对剑间歇性，前期不如赤水母，后期小船无输出位置
- 告示级特种型纯对剑输出高，策略统一目标可秒杀，前期可媲美水母，后期可秒大船
- 子型号抽取难度大，非重氪玩家难以获得，故特种型再强也与多数玩家无关

## 适用限制
- 适用于solo玩家或护卫舰玩家，前期过渡需高性价比前排输出船
- 出击型不适合前期过渡（伤害不足造价贵）和后期输出（易被剔除）
- 特种型需配合策略（如凯斯瑞士/蓝蝴蝶）发挥秒杀效果，且需抽到子型号
- 不适用于非重氪玩家，因子型号抽取概率低
