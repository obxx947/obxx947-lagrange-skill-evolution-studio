# A资料46 · 斗牛级驱逐舰万金油解析

## 结论
- 斗牛级主型号、突击型、防御型在各阶段都有不错表现
- 游戏早期双牛配置曾称霸一时，普牛配合突击牛可对大船和小船造成毁灭性打击
- 早期常见配置为增援五航母，其余以双牛带满并搭配舰载机
- 后续大版本更新后双牛人口数上升，逐渐淡出主流视野
- 三个型号制造时间、制造成本和资源消耗在驱逐舰中偏高
- 优势在于极高的单发伤害，且为能量伤害
- 极低的冷却使其能对小型和中大型舰船造成极高伤害
- 现阶段选择多根据基地等级更换，前期用普牛和防御牛，中后期换突击牛打击超主力舰船
- 加点方案有效加点多，无用加点很少
- 主型号抽到即可直接上场，动力系统有两层闪避，生存能力较强
- 后期可换防御牛作为前期中流砥柱上场

## 配队与模块
- 早期双牛配置：普牛配合突击牛
- 早期增援配置：五航母增援，其余以双牛带满并搭配舰载机
- 前期上场：普牛、防御牛
- 中后期上场：突击牛，用于打击超主力舰船
- 加点方案参考：普牛、防御牛、突击牛分别加点
