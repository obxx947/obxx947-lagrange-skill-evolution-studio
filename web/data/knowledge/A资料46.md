# A资料46

## 场景 / 对手
斗牛级舰船解析，涵盖主型号、突击型、防御型，涉及开荒、中后期对超主力舰船打击

## 舰队例子
- 普牛（斗牛级主型号）+ 突击牛（斗牛级突击型），数量未指定（胜）【双牛组合可对大船和小船造成毁灭性打击，曾称霸一时】
- 增援五航母 + 其余双牛带满 + 舰载机（胜）【最优配置之一，利用双牛高伤害】

## 实战结果
双牛组合在早期版本中称霸，对大小船有效；大版本更新后因人口数上升逐渐淡出视野

## 结论思路
- 斗牛级三个型号在驱逐舰中制造时间、成本、资源消耗较高，但单发伤害极高且为能量伤害，冷却极低，对小型和中大型舰船伤害高
- 前期使用普牛和防御牛，中后期更换为突击牛对超主力舰船打击
- 加点方案有效，无用加点少；主型号抽到即可上场，动力有两层闪避提升生存能力
- 后期可用防御牛作为中流砥柱

## 适用限制
- 适用于驱逐舰定位，需考虑人口数变化影响
- 前期适合普牛和防御牛，中后期需更换突击牛
- 加点需参考具体型号（普牛、防御牛、突击牛）
