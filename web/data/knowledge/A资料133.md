# A资料133

## 场景 / 对手
正面/抗伤队

## 舰队例子
- SD 59 + D舰载机模块 + 中型机库（胜）【相当于塞了一个狩猎，回本18人口，可携带干扰机拖延战斗时间】
- SD 59 + C二电磁装甲 + 中排光防（胜）【获得全游戏最高70%能抗，换战损一流】

## 结论思路
- SD 59仅需两个模块就能成为完全体，性价比高
- D舰载机模块提供四加成优秀的中型机库，增加输出和功能性
- C二电磁装甲是核心模块，提供40能抗点，达到全游戏最高70%能抗

## 适用限制
- 适合平民玩家，容易成型
- 抗伤队中可携带干扰机拖延战斗时间
- 需搭配中排光防以最大化换战损效果
