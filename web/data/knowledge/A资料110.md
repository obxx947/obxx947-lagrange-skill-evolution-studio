# A资料110

## 场景 / 对手
驱护队配置推荐，320加5配置，对抗以牛炮为核心的传统驱护队，正面战斗

## 舰队例子
- 开阳、谷神奶、灼热水母、瑶光AB型号混编，380人口（胜）【以两开阳一瑶光代价歼灭对方375人口舰队】
- 脉冲牛、重炮水母、古奶、三卡特，375人口（负）【传统驱护队，被清理水母后失去战斗力】

## 实战结果
我方320加5驱护队以30人口战损击败对方375人口传统驱护队，关键为优先清理对方水母，我方灼热打80万、水母71万、开阳53万，结构伤害仅50万，可继续作战

## 结论思路
- 开阳加入提升舰队取舍火力
- 优先清理对方水母可奠定胜局
- 红血灼热伤害高于满血，最高可达11万
- 二代配队总造价仅比传统高60万金属，比纯护卫多半条鱼成本

## 适用限制
- 适用于驱护队对抗传统牛炮体系
- 需注意灼热红血状态的位置变化
- 造价对比基于前期开荒资源消耗
