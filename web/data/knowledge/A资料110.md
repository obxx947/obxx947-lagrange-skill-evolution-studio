# A资料110 · 320+5驱护队配置推荐

> 场景：驱护队内战，对手为牛炮核心传统驱护队

## 结论
- 开阳、瑶光与灼热混编驱护队，以30人口战损击败375人口传统驱护队
- 传统配队仅靠水母作直射收割，加入开阳后舰队直射火力明显提升
- 第一波集火对方5只水母，约两分钟全部清理干净
- 清掉对方水母后战斗失去悬念
- 我方仅损失2开阳1瑶光，全歼对方375人口舰队
- 打完结构伤害仅50万，舰队仍可继续作战
- 部分灼热在战后提前进入中排
- 红血灼热对舰伤害最高11万，满血灼热仅6到7万
- 二代配队总造价比传统配队仅高60万金属
- 比纯护卫舰队仅多半条鱼的成本

## 配队与模块
- 我方380人口：开阳、谷神星级-支援驱逐舰（原文为"古奶"，疑似语音识别错误）、灼热、刺水母、瑶光A/B型号混编
- 对方375人口：脉冲牛炮、重炮水母、谷神奶、3卡特
