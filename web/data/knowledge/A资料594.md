# A资料594

## 场景 / 对手
二加三阶段输出战巡选择，正面输出与防空环境

## 舰队例子
- 风暴（M2+A2+B1+D1+C1）x6，苍穹、太阳鲸、超斩（胜）【输出队，全反大，适合当前环境】
- 风暴（M2+A2+B2+D2+C2）x6，前排战巡（天权/毛）、天书（胜）【防御队，防空与奶前排，需前排战巡和天书】

## 实战结果
风暴在二加三阶段作为输出战巡，输出队六风暴组合反大效率高，能有效打击敌方战巡、航母、巡洋；防御队需前排战巡和天书支撑，否则无法发挥。

## 结论思路
- 风暴是二加三玩家绕不开的输出战巡，因该阶段可选战巡少，且风暴提供保底伤害
- 输出模块必选M2和A2，其他模块输出效率低
- B和D模块选择：B1+D1增加直射输出，B2+D2增强防空，不因主副队强制选择
- C模块：主队带C1，副队带C2，C2仅从不可用变为可用，需前排战巡和天书支持
- 添加模块比强化更划算，B/D模块即使不强化也应添加
- 输出队六风暴组合适合当前环境，反大武器即使分散也能命中敌方主力

## 适用限制
- 风暴适合二加三阶段玩家，低门槛上手
- 输出队需六风暴及苍穹、太阳鲸、超斩等反大船
- 防御队需前排战巡（如天权、毛）和天书，否则无法顶前排
- C2模块仅适合有前排战巡的玩家，非所有玩家适用
- B2+D2防空模块适合应对飞机多的对手，但拦截效果有限（约2万伤害）
