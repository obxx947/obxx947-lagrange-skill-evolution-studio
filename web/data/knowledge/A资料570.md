# A资料570 · 新大地与系统伤害解析

> 场景：空军填充位/绝育船/轰炸机反小

## 结论
- 新大地是空军填充空余位置的优选，不知道带什么时上新大地不会错
- 新大地加点灵活，可自我超速适配多种载具模块
- 新大地打实弹伤害即保底伤害，时间到了就能输出
- 新大地每隔一段时间有爆发期，但越往后输出越平
- 新大地只靠绝育出伤，自身武器刮不出伤害
- 新大地撤退时机非常关键，爆发期后基本是无效输出
- 打系统的船都要点转火，新大地每40秒优先选超速力即转火
- 新大地面板64/50/16清晰，这些格子必点
- 冷却时间与索敌二选一，更偏向自身点索敌
- 新大地自身加点没有反大命中，只有反小加点
- 载具做选择时尽可能让载具去点命中
- 苍穹是绝育伤害提升最高的飞机，推荐冷却加伤害方案
- 林鸮A100型-联合攻击机自身锁敌不合格只有4.8秒，新大地完全可以
- 更多玩家选林鸮A100型-联合攻击机苍穹而非新大地苍穹，因林鸮A100型-联合攻击机自身有伤害、撤退时机不需精准
- 新大地绝育完足疾系统后一定从指挥系统开始
- 战斗训练中写中/低也能绝育，对绝育船都有效
- 新大地单发43，打高时花40伤害打指挥系统、3伤害打结构值
- 系统伤害必定暴击，暴击叠上去后伤害不低，只是绝育慢
- 系统伤害可累积，像果园理论一样终会爆出来
- 新大地塞在什么角落带上终有一天会爆系统
- 带数量少时不要上苍穹，普通新大地更划算
- 苍穹与新大地差距约两倍，但问题不大
- 大船血量只有两万六千八
- 050输出普遍比刺鳐高，因刺鳐写中砍伤害多
- 刺鳐绝育更快但出伤更低，因写了中
- 不选牛蛙因单发只有250还写中且优先反大，砍伤害太多
- 轰炸机推荐做反小，前排小船基本缺乏拦截
- 第三军阶段护航队把050、刺鳐放CV3000上很不错
- 系统伤害更注重把轮次挤压提前，而非单纯靠时间出伤

## 配队与模块
- 新大地载具加点：去掉超速换频率，频率也加伤害但少一点
- 新大地最终加点：点面板64/50/16，冷却与索敌二选一偏索敌
- 苍穹推荐加点：冷却加伤害方案，而非冷却加锁敌
- 新大地苍穹方案：苍穹多出伤害换新大地一个频率，频率加得少伤害加得多，优先选伤害
- 第三军阶段护航队：050、刺鳐放CV3000上

## 数值与数据
- 新大地面板64/50/16
- 新大地单发43
- 新大地每40秒优先选超速力
- 指挥系统冷却25秒，期间不能出伤
- 指挥系统血量约1万，一场战斗绝育两次但伤害可达3万
- 新大地普通载具打1.8万，带苍穹打5.3万，砍掉系统后约4万多
- 苍穹与新大地差距约两倍
- 大船血量两万六千八
- 050单发450，写低抽10%打指挥系统
- 刺鳐单发400写中，砍30%-50%伤害打指挥系统
- 牛蛙单发250写中优先反大，真实打大船约100单发
- 林鸮A100型-联合攻击机锁敌4.8秒
- 唯一反小不点策略打25万伤害，点开看三千、一千、一万五，加起来不超过三万
