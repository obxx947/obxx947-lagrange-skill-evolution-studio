# A资料570

## 场景 / 对手
空军编队中填充空余位置，对抗敌方舰队，涉及系统伤害（绝育）机制，正面战斗

## 舰队例子
- 新大地（载具：苍穹，模块：M1，加点：冷却+伤害，数量：未明确）（胜）【输出约5.3万，爆过一个系统后仍4万多，优于普通新大地】
- 新大地（普通载具，数量：未明确）（胜）【输出约1.8万，与苍穹新大地差距约2倍】
- 维A（反小，不点策略）（负）【总伤害25万，实际有效伤害不超过3万，因不转火】
- 凌霄（载具：苍穹，加点：冷却+锁敌）（胜）【自身有伤害，淡化爆发期，输出稳定】

## 实战结果
新大地对抗敌方舰队，多场战斗，新大地苍穹体系胜，普通新大地胜，维A反小不点策略负；关键得失：新大地依赖爆发期，需把握撤退时机，系统伤害可累积，但纯靠绝育输出后期刮痧

## 结论思路
- 新大地适合填充空军空余位置，加点灵活，可超速适配模块
- 新大地打实弹保底伤害，但系统伤害有爆发期，需把握撤退时机
- 新大地必须点转火策略，否则输出大幅降低
- 载具加点优先命中，如五九点命中提升，优于伤害
- 苍穹载具对新大地提升最大，但数量少时普通载具更划算
- 系统伤害可累积，最终能爆出系统，但纯靠绝育后期输出不足
- 凌霄苍穹比新大地苍穹更稳定，因凌霄自身有伤害，不依赖爆发期

## 适用限制
- 适用于空军编队有空余位置时
- 需配合载具超速或命中加点
- 必须点转火策略
- 数量少时不宜用苍穹载具
- 不适合长时间战斗，后期输出刮痧
- 对高护甲目标可能破防困难
