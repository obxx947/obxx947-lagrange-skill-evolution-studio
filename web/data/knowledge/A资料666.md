# A资料666 · 大盾模块选择与盾矛副队配队

> 场景：战巡大船队副队体系（盾矛组合）

## 结论
- 普鲁图斯之盾级-防护战列巡洋舰（原文为"大盾"，疑似简称）别称"叹息之墙"，与乌拉诺斯之矛（原文为"矛""大毛"，疑似简称）组成"矛盾组合"，是副队必备
- 大盾M系统优先级：M1＞M3＞M2
- 大盾必须放中排；加点不点站位、不点前置，吃的是舰船自带策略（在指挥系统内）
- A系统最好用A2、A3：A2是救援无人机，能吸引敌方舰载机火力；A3也是救援无人机，吸收敌方曲射伤害
- B系统有哪个带哪个，都非常好用；没有B2就优先B3（反拦截好），综合维修也不错
- C2是大盾核心模块：降低自身拦截反击并防空，防空还能减冷却
- 五战巡阶段矛带艇矛（原文为"挺毛"，疑似语音识别错误）最好用：艇矛当炮灰做分伤，避免敌方对舰与空中单位直接集火
- 盾、矛自带拦截时，副队光锥数量可以减下来
- 前排至少带一点特卡（卡利莱恩级-特种护卫舰（原文为"特卡"，疑似简称），原文为"特卡"，疑似简称）和66奶，由前排做分伤
- 后期资源充足直接上八战巡

## 配队与模块
- 大盾A系统用A2、A3；B系统用B2（没有B2则用B3）；C系统用C2
- 盾矛副队：普鲁图斯之盾级-防护战列巡洋舰 + 乌拉诺斯之矛，全部站中排
- 矛带艇矛（乌拉诺斯之矛B2模块）
- 副队配光锥级-区域防空巡洋舰（原文为"光锥"，疑似简称）；盾/矛自带拦截时可减少其数量
- 前排分伤：卡利莱恩级-特种护卫舰 + CAS066级-支援巡洋舰（原文为"溜溜奶"，疑似语音识别错误）
- 前排特卡可搭配狼蜥级（原文为"郎溪"，疑似语音识别错误）或阋神星I级（原文为"牺牲星"，疑似语音识别错误）
- 队伍演进：一盾一矛 → 两盾三矛（5战巡）→ 三盾五矛（8战巡）

## 数值与数据
- 副队战巡规模：5战巡＝2盾3矛；8战巡＝3盾5矛
- 光锥级-区域防空巡洋舰带3～5个，最低3个
