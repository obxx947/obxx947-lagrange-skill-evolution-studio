# A资料557 · 第三阶段护航碾压第二阶段战报

> 场景：第三阶段护航 vs 第二阶段护航；正面护航战斗

## 结论
- 第三阶段护航完全碾压第二阶段护航，且有余力接第二队
- 第二阶段护航接大规模战斗时奶船优势消失，接第二队勉强
- 护航队不管空战时，海尔波普生存极低，奶效率远不如CAS066级-支援巡洋舰（原文为"零六十六"，疑似语音识别错误）
- 奶船队里飞机、护航艇很少时，人机是更好的选择
- 副队塞航母是第三阶段护航的核心思路
- 航母能发挥账号整体优势，增援人口比对方多15-20
- 玩护航艇必须强化艇线，艇线处理不掉时海尔波普才能存活
- CV3000级-快速航空母舰（原文为"cp三千"，疑似语音识别错误）在队伍中主要任务是做拦截，可取代光锥
- 光锥拦截只对同一排导弹和鱼雷免伤，前提多、效果不强
- 更推荐塞装甲ST59级或装甲普鲁图斯之盾级，而不是堆光锥
- 提高物理护甲能免疫绝大多数导弹和鱼雷伤害，还省光锥人口
- 光锥带两三条没问题，带七八条不推荐
- CV3000级-快速航空母舰不亏人口，40人口有40万血量
- 护航队出生伤害不超过四百万时一条船都不会掉
- 护航队有奶，打到四百万时已回血120-150万
- 航母加战舰的根基是CV3000级-快速航空母舰加乌拉诺斯之矛（原文为"毛"，疑似简称）
- 苍穹的两种无人机一个攻击一个奶，契合这个阵容
- 往队伍里加大船第一要血量达标，第二要提供人机或艇
- 这个队伍可以拓展成战略打击队伍
- 安德森降低命中调校意图不明，没东西带时带它也可以
- AT021干扰命中效果很弱，加点应优先点索敌
- 猎兵做超斩会奶散，奶到CV3000级-快速航空母舰上不划算
- 更希望奶量集中在乌拉诺斯之矛上，CV3000级-快速航空母舰残血可接受
- 中排放大船时，前排堆近50人口小船不如塞大船
- 支援舰40人口能带3个艇，可把8分摊变成14分摊
- 这个阵容是有奶的队伍，不是奶船队伍，靠血量接伤害而非回血
- 克老应追求第三阶段护航，往血量方向填充
