# A资料215 · 星脉护航艇正确用法

> 场景：进化协议环境；搭配猎兵级载机巡洋舰反大

## 结论
- 星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）是护航艇中唯一T0输出
- 脉冲型主武器优先打小型舰船，实战会先打开阳、瑶光等小船
- 默认攻击序列导致伤害分散，打不出伤害且让对面奶盾活更久
- 搭配猎兵级-重型载机巡洋舰（原文为"猎兵"，疑似简称）可矫正攻击序列，优先反大
- 矫正后与维塔斯-B010-轰炸机（原文为"VB"，疑似简称）形成集火，优先打击战巡或航母
- 星云追逐者-脉冲炮艇基础命中较高，可不加点命中
- 猎兵级-重型载机巡洋舰同样不需要加点命中
- 猎兵级-重型载机巡洋舰加点唯一策略为三频率一伤害

## 配队与模块
- 星云追逐者-脉冲炮艇搭配猎兵级-重型载机巡洋舰
- 猎兵级-重型载机巡洋舰载机模块的攻击序列模块可矫正星脉优先反大
- 星云追逐者-脉冲炮艇与维塔斯-B010-轰炸机形成集火

## 数值与数据
- 星云追逐者-重型护航艇主型号弹炮型在进化协议加持下对舰伤害可达15000
- 弹炮型实际输出效果与脉冲型差距不大
- 猎兵级-重型载机巡洋舰加点：三频率一伤害
