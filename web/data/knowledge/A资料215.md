# A资料215

## 场景 / 对手
新版本星脉护航艇使用讲解，涉及主型号弹炮型和B型号脉冲型，正面作战环境

## 舰队例子
- 星脉主型号弹炮型（进化协议加持，对舰伤害一万五）（胜）【实际输出效果与B型号差距不大】
- 星脉B型号脉冲型（主武器优先小型舰船）（负）【攻击序列优先打小船，实战中会优先打开阳瑶光，导致伤害不集中，打不出效果】
- 星脉搭配猎兵（猎兵载机模块攻击序列模块）（胜）【可矫正攻击序列，优先打击战巡或航母，与VB形成集火反大能力】

## 实战结果
星脉B型号单独使用效果不佳，搭配猎兵后能有效反大；关键得失是攻击序列调整和加点优化

## 结论思路
- 星脉B型号是护航艇中唯一T0输出，但攻击序列优先打小船，实战中会优先打开阳瑶光，导致伤害不集中
- 通过搭配猎兵的载机模块攻击序列模块，可以矫正星脉攻击序列，优先打击战巡或航母，与VB形成集火反大能力
- 星脉基础命中较高，加点不考虑命中；猎兵加点同样不需要命中，唯一策略是加三频率和易伤害

## 适用限制
- 适用于新版本星脉护航艇使用场景
- 星脉B型号单独使用不推荐，需搭配猎兵调整攻击序列
- 加点策略仅适用于星脉和猎兵，不适用于其他舰船
