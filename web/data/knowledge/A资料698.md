# A资料698

## 场景 / 对手
航母体系分析，对手为游戏内玩家，正面讨论，环境为游戏内航母选择与发展路径

## 舰队例子
- CV3000（1+1）（胜）【基础款，过渡到太阳鲸或苍穹】
- 鱼（8+6）（胜）【进阶款，可单上，带主流飞机和护航艇】
- 天枢（M1+B1+C2）（胜）【进阶款，可单上，有维修无人机】
- 苍穹（M1+C2）（胜）【基础款，适合轰炸，需配合凌霄】
- 南十字（负）【基础款，超斩方向，但缺乏艇位，输出弱】

## 实战结果
玩家分析航母选择，CV3000玩家可升级鱼或天枢，鱼玩家可升级苍穹或天枢，天枢性价比高，苍穹适合主队，南十字不推荐

## 结论思路
- 航母分基础款和进阶款，基础款包括CV3000、南十字、苍穹，进阶款包括鱼和天枢
- 天枢对标太阳鲸，不超标，但性价比高，模块明码标价
- 鱼和天枢都是CV3000的升级版，可单上，带主流飞机和护航艇
- 苍穹只能作为副手，不能成为主航母，需配合凌霄
- 南十字缺乏艇位，输出弱，不适合作为主航母
- 升级路径：CV3000可升级鱼或天枢，鱼玩家可升级苍穹或天枢

## 适用限制
- 适用于航母选择和发展路径分析
- 不适用于南十字发展，因其输出弱
- 苍穹需配合凌霄，不能单独作为主航母
- 鱼和天枢需带主流飞机和护航艇才能发挥实力
