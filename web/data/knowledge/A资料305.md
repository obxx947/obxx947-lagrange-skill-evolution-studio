# A资料305

## 场景 / 对手
超斩队（优先攻击超主力/航母/战群）的强度与适用性讨论，涉及前期护队、后期战群环境

## 舰队例子
- 超斩队（含猎兵、狩猎等需点策略的船）（视情况而定）【需点超斩策略，若对面无超主力则策略点浪费】

## 实战结果
无具体战报，讨论超斩队优劣：打超主力可赚（如打掉大盾），但若打不炸超主力且不打小船则零作用；独狼易陷入尴尬，有盟友夹击时更划算

## 结论思路
- 超斩队优先打超主力（航母/战群），好处是打掉高价值目标（如大盾）使对面血亏
- 超斩坏处：部分船需点策略，若对面无超主力则策略点浪费；超主力防御高，打不炸则零作用
- 船好（伤害够）时必出超斩，打超主力比打小船划算
- 船不好时：独狼不建议出超斩，避免打不中超主力又不打小船的尴尬；有联合体/盟友夹击时可出，因输出够
- 前期护队阶段不加超斩策略，后期战群出现后重置加点再点

## 适用限制
- 适用于对面有超主力（航母/战群）的场景
- 船好（伤害足够）时适用
- 独狼且船不好时不适用
- 有盟友夹击时适用
- 前期护队阶段不建议加超斩策略
