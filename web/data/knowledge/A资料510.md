# A资料510

## 场景 / 对手
天书之间的加9护航对冲，双方明牌，针对化配置，正面冲突

## 舰队例子
- 10航母（5天书+5CV）+5战巡+6阋神星+15超主，无衡C，无附加维修模块（负）【前排小船硬度不足，天书无C2模块，奶量劣势】
- 9航母+4战巡+泡泡龙+开阳+玉衡C+衡C（胜）【泡泡龙快速清前排，直射打中排战群，衡C奶开阳】
- 6风暴+2列兵（突防RB7）+7泡泡龙+2狩猎（胜）【突防RB7对无衡C高质阵容伤害有限，但整体输出有效】

## 实战结果
左边（高质）对右边（低质），左边输掉护航对冲；关键损失：左边前排开阳存活3分钟，中排战巡和旗舰盾同步死亡，雷火直射被开阳拖延；右边利用泡泡龙和衡C取得优势

## 结论思路
- 高科玩家有能力做全取舍阵容时，应全做取舍伤害，不要被开阳体系影响
- 天书C2附加维修模块非常重要，没有则奶量劣势明显
- 有玉衡C时，前排开阳数量可适当减少，避免分奶和浪费人口
- 直射伤害在对方有闪避前排时效率低，应集中火力做取舍伤害
- 前提是必须有风暴和苍穹破盾，否则仍需直射

## 适用限制
- 适用于高科玩家（2322以上）且拥有风暴和苍穹破盾
- 缺少风暴或苍穹破盾时，不建议全取舍，应保留直射
- 对方有大量闪避前排（如开阳）时，直射效果差，取舍更优
- 天书无C2模块时，奶量不足，需注意前排生存
