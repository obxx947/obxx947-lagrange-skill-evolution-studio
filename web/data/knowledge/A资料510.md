# A资料510 · 天枢级-支援航空母舰（原文为"天书"，疑似简称）加9护航对冲战报分析

> 场景：护航对冲，双方明牌，高质量超主+航母体系

## 结论
- 左边质量更高、超主数量更多，却输在伤害被分散
- 左边前排6条阋神星无前凸，穿后由15条超主纯中排分摊，决策合理
- 右边用泡泡龙快速清掉阋神星，再打中排战群，是取胜关键
- 左边没有衡C，小船前排硬度不如右边
- 左边主队用雷火之心打直射，大部分直射伤害落在航母上，对前排太阳伤害有限
- 雷火之心被对方开阳拖住，开阳普遍3分钟左右才死，浪费近一半对局时间
- 左边中排战巡和旗舰盾死得比前排开阳还早，前排与中排几乎同步死亡
- 左边有能力不管前排小船直接清掉中后排大船，却做了部分直射导致伤害分开
- 高质量玩家应尽量全做取舍伤害，不要被开阳瑶光体系影响
- 有风暴和苍穹破盾是玩全取舍的前提，缺其一就老实玩直射
- 左边副队天枢级-支援航空母舰奶量不如对方，主因是缺少天枢级-支援航空母舰C2附加维修模块
- 右边做10个开阳反而分奶，做5个可能扛得更久
- 有玉衡C时前排开阳可适当减少，对方很难快速秒掉开阳
- 右边输出队带突防RB7，面对无玉衡C的高质量超主伤害有限，6分钟仅20万

- 右边用康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡龙"，疑似简称）（泡泡龙）快速清前排
- 右边有衡C奶开阳
- 左边主队带雷火之星-综合武库舰（原文为"雷火之心"，疑似语音识别错误）打直射
