# A资料550 · 护航队三阶段配置思路

> 场景：护航队/副队/抗伤队/输出队

## 结论
- 玩这个游戏要的是思路，不是直接给配置
- 第二阶段玩家通常有1个能用的航母加2个能用的战巡
- 第二阶段队伍应分成纯输出队和纯抗伤队，减少浪费人口
- 抗伤队要有明确集火目标，奶船才能集中治疗
- 队伍中战巡数量不宜过多，超过5个会触发分摊导致奶不过来
- 输出队核心是让新君士坦丁大帝级尽早进入残血狂暴阶段
- 新君士坦丁大帝级不是带得越多越强，关键是能否进入狂暴
- 只有能打到后半程的战斗才适合上新君士坦丁大帝级
- 输出队其他船都要为压血线服务，帮助新君士坦丁大帝级狂暴
- 第三阶段思路是把航母放进抗伤队，利用本体血量参与分伤
- 第三阶段副队核心是分伤，不是纯奶
- 分伤玩明白后，支援舰和止战级才有上场空间
- 最强护航模板是输出战巡加输出航母，配防御战巡加防御航母
- 纯航母配纯战巡不如混合类型船，混合才能把伤害分干净

## 配队与模块
- 第二阶段输出航母选数字型即可，从增援位带
- 太阳鲸-武装战略航空母舰（原文为"太阳鲸"，疑似简称）用11+13组合，因该组合在梯度榜排T0
- 维塔斯-B010-轰炸机（原文为"维b"，疑似简称）最强载具是13，新麦最强载具是11
- 南十字星元帅级-武装航空母舰（原文为"南石志"，疑似语音识别错误）维塔斯-B010-轰炸机输出强，但会分叉，超主力多时单船伤害被摊薄
- 永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）M1是输出模块，但不适合作为输出航母，只适合放副队当奶船
- 永恒苍穹级-无人机航空母舰只有3个载机模块，4台才能带10个B192新大地-重型攻击机（原文为"新大地"，疑似简称）
- CV3000级-快速航空母舰（原文为"cv三千"，疑似语音识别错误）中规中矩，有护航艇有载机，可作输出航母
- 只有一个可用战巡时，可洗点拆成3.0加1.0，做两个将军两个队伍
- 抗伤队由乌拉诺斯之矛（原文为"茅"，疑似语音识别错误）带领一众奶船组成
- 输出队由新君士坦丁大帝级带领，其他船为压血线服务
- 输出队可配重卡、康纳马拉混沌级等打战巡的船帮助压血
- 第三阶段推荐后排航母：南十字星元帅级-武装航空母舰、永恒苍穹级-无人机航空母舰、CV3000级-快速航空母舰
- CV3000级-快速航空母舰带多不吃亏，可提供更多艇线
- CV3000级-快速航空母舰40人口有近40万血量，还有超高闪避和拦截
- 光锥级-区域防空巡洋舰（原文为"光锥"，疑似简称）上拦截很亏人口，CV3000级-快速航空母舰拦截等于白嫖
- 前排4条战巡加多台航母，空军庞大，海尔波普-系统支援护航艇（原文为"海尔波普"，疑似简称）奶量充足
- 维塔斯-B010-轰炸机打到该队伍有30%减伤，海尔波普-系统支援护航艇可能回得比打得还多
- 永恒苍穹级-无人机航空母舰也有奶，队伍核心是分伤不是奶
- 050或打航母的船以曲射形式呈现，CV3000级-快速航空母舰可参与分伤
