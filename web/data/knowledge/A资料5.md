# A资料5

## 场景 / 对手
新赛季更新后，八三分摊阵容讨论，涉及矛（ST59）与艾奥（IO）的搭配，以及重卡与泡泡龙的对比

## 舰队例子
- 2个艾奥（IO）在前排 + 6个战巡（如大矛）（胜）【利用八三分摊原理，艾奥在前排吸引反大武器伤害，形成分摊效果】
- 2个ST59 + 6个大矛（胜）【ST59可吃规避和VB伤害，但不如艾奥灵活】

## 实战结果
从26号开始打了三到四场，第一场最有意义，使用艾奥+战巡阵容成功实现八三分摊，对抗对面大矛和康纳马拉伤害

## 结论思路
- 八三分摊不需要八个同位置船，只要攻击序列包含目标，不同船型也能分摊伤害
- 艾奥相比ST59，少吃VB和重卡伤害，但残血可后退输出，更克制纯紫色阵容
- 矛（ST59）是游戏中最关键的船，优先练矛，其次风暴和大地，最后才考虑ST59
- 重卡和泡泡龙不是一个等级，不应放在一起比较

## 适用限制
- 八三分摊需考虑己方武器攻击序列和对方前排船型
- 艾奥阵容不适合应对VB攻击序列优先战巡的情况
- ST59不是第一条该练的战巡，需按优先级顺序培养
