# A资料104

## 场景 / 对手
副队扛伤队选择，当前版本主流抗伤为大毛、大盾配合六奶，剩余位置补光环拦截和闪避类小船或奶船

## 舰队例子
- 大毛（大盾）+六奶+光环拦截+闪避类小船/奶船（胜）【主流抗伤配置】
- 盘古重工开阳机（近半血高额生存，基础血量近五万多，可拉长扛伤至一分钟以后，三分钟才全部阵亡）（胜）【生存能力强，对小船有影响】
- 盘古重工瑶光机（为残血舰船增加护盾）（胜）【对大船克制效果明显，可能因护盾导致多几轮武器锁定和攻击】

## 实战结果
对方主队以小船为主，副队以战机护航艇和轻小船类配置，我方副队承伤达一百四十多万，奶量维修效果集中在前排大毛，最终结果不错

## 结论思路
- 副队扛伤选择大毛、大盾配合六奶，剩余位置补光环拦截和闪避类小船或奶船
- 开阳机和瑶光机生存能力好，适合上场
- 开阳机近半血获得高额生存，基础血量高，可延长扛伤时间
- 瑶光机为残血舰船加护盾，对大船克制明显，可能增加敌方锁定和攻击轮次
- 开阳机和瑶光上场不会过多干扰主队奶量

## 适用限制
- 适用于当前版本主流抗伤配置
- 开阳机和瑶光机需抽到才能上场
- 适合对抗以小船为主的敌方主队和战机护航艇副队
