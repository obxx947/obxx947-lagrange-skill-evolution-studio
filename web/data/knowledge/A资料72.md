# A资料72 · 雨海脉冲型加点与伤害测试

## 结论
- 雨海级-脉冲炮护卫舰（原文为"余海脉冲"，疑似语音识别错误）仅需80人口，前期可作主力输出，后期可作输出补充人口
- 策略应选重型目标，而非功能切换
- 功能切换仅前两分钟生效，最后一分钟无增益
- 重型目标策略在敌方无超主力时依然生效，全战斗时长覆盖
- 雨海脉冲武器没有攻击持续时间，重型目标策略的降低攻击持续时间增益无效
- 重型目标策略冷却缩减比功能切换高5%
- 武器调校后输出增幅约7%

## 配队与模块
- 加点顺序：双伤害、双命中、一策略、双冷却
- 策略选择：重型目标

## 数值与数据
- 10艘雨海级-脉冲炮护卫舰，3分钟作战时长
- 调校前平均反大伤害7.38万/分钟，单位人口伤害923
- 调校前反小伤害10.12万/分钟，单位人口伤害1265
- 调校后平均反大伤害7.99万/分钟，单位人口伤害999
- 调校后反小伤害10.68万/分钟，单位人口伤害1335
