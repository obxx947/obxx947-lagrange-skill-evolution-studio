# A资料72

## 场景 / 对手
余海脉冲型武器测试，正面输出环境，无特定对手体系

## 舰队例子
- 十个鱼海脉冲，80人口，武器调校前（胜）【三分钟作战，平均反大伤害7.38万/分钟，单位人口伤害923；反小伤害10.12万/分钟，单位人口伤害1265】
- 十个鱼海脉冲，80人口，武器调校后（胜）【三分钟作战，平均反大伤害7.99万/分钟，单位人口伤害999；反小伤害10.68万/分钟，单位人口伤害1335；调校增幅约7%】

## 实战结果
测试余海脉冲型输出，调校前后对比，调校后输出提升约7%；策略选择重型目标优于功能切换，因功能切换仅前两分钟生效，重型目标全战斗生效

## 结论思路
- 最优加点为双伤害、双命中、一策略、双冷却，策略选重型目标
- 余海脉冲型输出数据耀眼，80人口在前期可作主力输出，后期作补充
- 重型目标策略在敌方无超主力时依然生效，全战斗时长覆盖
- 功能切换策略仅前两分钟生效，最后一分钟无增益，输出低于重型目标

## 适用限制
- 适用于余海脉冲型武器配置
- 策略选择需根据战斗时长考虑，重型目标适合长时间战斗
- 功能切换策略仅适合短时间爆发场景
