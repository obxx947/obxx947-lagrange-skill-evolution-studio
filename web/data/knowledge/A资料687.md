# A资料687

## 场景 / 对手
巡洋舰选择与搭配，康纳玛拉与重卡对比，正面输出与精准补刀，环境为常规PVP战斗

## 舰队例子
- 康纳玛拉（巡洋舰，主武器系统，数量4-5条）（胜）【大面积前排输出，适合持久战（4分钟以上），点数需求低（30-40点），加点优先双伤害、双冷却、命中，策略视情况】
- 重卡（巡洋舰，攻击模块，数量1-2条）（胜）【精准补刀，适合短时间战斗（1-2分钟），点数需求低（50-60点），策略优先点（25%提升），加点可选命中+暴击】

## 实战结果
康纳玛拉与重卡搭配，康纳玛拉负责前排大面积输出，重卡负责精准补刀，几胜几负未明确，关键得失：重卡补刀能力不可替代，康纳玛拉适合持久战，重卡适合速战

## 结论思路
- 康纳玛拉和重卡是巡洋中的有效输出，非最高输出但精准
- 康纳玛拉类似加藤，大面积前排输出；重卡类似狙击手，精准补刀
- 重卡比重应少于康纳玛拉，只需补最后10%血量
- 不带重卡需保证空战取胜，带重卡可忽略空战
- 重卡可编入纯战巡队伍，康纳玛拉不行，两者可共生
- 战斗超4分钟选康纳玛拉，1-2分钟选重卡
- 加点：康纳玛拉优先双伤害、双冷却、命中，策略视情况；重卡优先策略，其次命中+暴击

## 适用限制
- 康纳玛拉不适合纯战巡队伍
- 重卡依赖对面无拦截，否则输出受限
- 重卡补刀需配合其他输出船，不能单独依赖
- 加点需根据对面阵容调整（如小船多则点大船命中无效）
