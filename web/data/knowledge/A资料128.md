# A资料128 · 艾格勒姆星球登陆入门

> 场景：艾格勒姆副本星球登陆

## 结论
- 星球登陆是艾格勒姆副本最特殊的玩法，难度和收益远超捡垃圾、挖成、控制等玩法
- 可获得先登级两栖突击舰（原文为"老登"，疑似简称）、理智级A101战斗机（原文为"理智"，疑似简称）等舰船碎片，以及A级拉格朗日级装备
- 星球登陆对玩家账号质量和数量有要求
- 没有先登级两栖突击舰靠诺玛M470级（原文为"诺玛"，疑似简称）和云海级（原文为"云海"，疑似简称）也能玩，但掉船会很严重
- 控制三级以下控制点还好说，往上升级会掉特别多船
- 没有轨道打击帮助控不下高级控制点
- 登陆星球表面需要花费50策略
- 登录后界面变为跳棋式界面，每跳一格花费30策略
- 没有先登级两栖突击舰带平衡安德森SC020侦察机（原文为"安德森"，疑似简称）会掉船严重，基本无法持续在星球进行控制
- 没有先登级两栖突击舰别玩星球登陆，掉船太严重

## 配队与模块
- 必备先登级两栖突击舰
- 先登级两栖突击舰带平衡安德森SC020侦察机

## 数值与数据
- 登陆星球表面花费50策略
- 跳棋界面每跳一格花费30策略
- 物资仓库遗址分1~3三个级别，控制后补充X8小型工程舰
- 危机点分两栖基地和军事基地两种，分别对应舰载机打击和导弹打击
- 危机点分小中大三个等级，分别对应红色导弹图形一、二、三个
