# A资料85

## 场景 / 对手
索姆河之影护航艇解析

## 舰队例子
- 索姆河之影护航艇（3架以上）（胜）【编队内均摊伤害，延长T800和围蔽等输出舰船的输出时间】

## 结论思路
- 索姆河之影定位为输出与生存于一体的舰载机，基础单发伤害550，在护航艇家族中位列第二，仅次于猎卫九号
- 基础强化项以伤害、冷却和命中为主，指挥系统策略在携带3架以上时实现编队内均摊伤害
- 均摊伤害变相延长输出类舰载机（如T800）和扛伤类舰载机的输出时间，降低资源损耗和阵亡率
- 基础血量7100，仅次于零幺幺，生产成本为C级，性价比高
- 战略打击中舰载机也能受益，生存时间提升与输出时间成正比，未来长期难有替代品

## 适用限制
- 需至少携带3架索姆河之影才能触发均摊伤害策略
- 适用于以输出和扛伤类舰载机为主的编队
- 不适用于追求单舰高爆发或缺乏舰载机体系的场景
