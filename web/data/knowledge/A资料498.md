# A资料498

## 场景 / 对手
开阳驱逐舰实战评测，涉及盘古集团体系，正面作战，环境为常规PVP

## 舰队例子
- 开阳驱逐舰（基础型号，鱼雷，反大，暴击+溶解弹，加点：反拦截+冷却+命中，装甲策略+血量+闪避）（胜）【t0级别，替代重西山星装甲，生存能力强】
- 开阳驱逐舰（对建型，后排，实弹投射，策略闪避换命中）（负）【t1级别，伤害一般，不建议使用】
- 10个太阳+10个开阳+5个耀光（盘古集团buff触发）（胜）【触发盘古集团巡洋buff，效率高】

## 实战结果
开阳驱逐舰在盘古集团体系中表现优秀，基础型号胜率高，对建型表现不佳；关键得失为生存能力和反大效率提升，损失为对建型伤害不足

## 结论思路
- 基础型号为t0，鱼雷反大，暴击和溶解弹效果强，前六轮施加溶解效果，结构值叠加30层
- 加点必点反拦截和命中，两个冷却，其余可加伤害或暴击
- 装甲策略必点，低于60%血量时降低命中提高冷却，其余点血量和闪避
- 开阳配合耀光可替代重西山星装甲，人口略高但更耐打
- 对建型为t1，实弹伤害一般，不建议使用
- 基础型号即可，配合盘古集团buff（10太阳+10开阳+5耀光）效果最佳

## 适用限制
- 适用于盘古集团体系，需配合耀光触发buff
- 基础型号适合反大场景，对建型不推荐
- 人口略高，需考虑舰队容量
- 加点需优先反拦截和命中，否则效果下降
