# A资料645

## 场景 / 对手
超斩队配置，针对平民可替换选择多

## 舰队例子
- 风暴（M2模块）（胜）【核心作用是断奶，伤害高，版本T0，输出稳定性仅次于舰载机，能无视中奖、免疫拦截、不受开阳限制，限制只有C3风暴自己】
- 猎兵（超斩策略，舰载机800引擎）（胜）【点超斩策略】
- 狩猎（超斩策略，舰载机凌霄、凯士与VA）（胜）【剩余人口加入，点超斩策略】
- 5个CV（B4模块，集火战巡、航母，搭配3个五加3于2个八机，携带轰炸机与坦克）（胜）【支援用】

## 结论思路
- 超斩队必须加入风暴，断奶对单超主配对生效，高达对基本免疫断奶影响
- 风暴必须有M2才能上场
- 猎兵和狩猎都点超斩策略，舰载机选择特定型号
- 支援5个CV，选择B4模块集火战巡、航母
- 平民可替换选择多，可用舰载机不够时，猎兵与狩猎可替换为中它旋木与战雷

## 适用限制
- 断奶只对单超主配对生效
- 风暴必须有M2模块
- 针对平民可替换选择多
