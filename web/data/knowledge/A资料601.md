# A资料601 · 高达抗伤队配置与取舍

> 场景：对抗反小舰载机、混沌/艾奥直射与投射输出

## 结论
- 小船前排容易被舰载机克制；当前BR050-标准轰炸机（原文为"050"，疑似简称）、刺鳐-鱼雷轰炸机（原文为"刺鳐"，疑似简称）、CV-T800型-脉冲炮艇、星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）等都会反小。
- 体验服测试显示小船前排扛不久，故改用大船前排抗伤。
- 若不用CAS066级-支援巡洋舰，改带后排小船奶，前排可扛更久但奶量严重下降，属另一套思路。
- 旧方案靠ST59级-防御战列巡洋舰限制混沌和艾奥、靠乌拉诺斯之矛限制投射输出，理论强但战损换不过。
- 旧方案战巡造价高，断奶有炸大矛风险，资源消耗大、成型慢，只停留在纸面，是废弃方案。
- 能限制康纳马拉混沌级与艾奥级直射伤害的大船是艾奥级-高速离子炮巡洋舰。
- 高速艾奥造价明显低于ST59；反大武器命中普遍不高，策略启动期间闪避高，抗伤不逊电磁59。
- 前排16大船分摊伤害，能大幅延长战巡与前排生存，有实战战报。
- 支援战巡带舰载机很关键，副队带舰载机能大幅削弱主队伤害，主要针对CV-T800型-脉冲炮艇与海氏追随者型-脉冲攻击机。
- 舰载机必须选高生存：SC002型-量子侦察机（原文为"002"，疑似简称）、平衡安德森SC020-侦察机（原文为"安德森"，疑似简称）合适；炮艇选海尔波普。
- 海尔波普无攻击能力，对面带苔原级-载机驱逐舰（原文为"苔原"，疑似简称）时不会受其伤害，只拖住主队CV-T800型-脉冲炮艇与海氏追随者型-脉冲攻击机；带别的炮艇死得快。
- 可选扛伤战巡还有普鲁图斯之盾级-防护战列巡洋舰、安东塔斯持剑者级-指挥舰（原文为"大剑"，疑似简称），但均为中排，无法给前排艾奥分摊伤害，故战巡必须前排。
- 乌拉诺斯之矛与ST59级-防御战列巡洋舰扛伤无本质区别；乌拉诺斯之矛输出更高，可协助主队更快处理对面副队。
- 乌拉诺斯之矛残血触发狂暴，高血量与高护甲带来维修量加成，换战损能力更强。
- ST59级-防御战列巡洋舰造价更低，但护甲限制吃不到太高维修量，换战损略劣；其舰载机能更好限制敌方主力CV-T800型-脉冲炮艇。
- 乌拉诺斯之矛与ST59级-防御战列巡洋舰如何选择看玩家想用哪个。
- 前排16大船必然奶量分散；艾奥对维修利用率高，虽奶量低于重甲目标，但生存提升很大。
- 不带艾奥时奶量也会分散到CAS066级-支援巡洋舰；永恒风暴级-攻击战列巡洋舰（原文为"风暴队"，疑似简称）队同样奶量分散，奶给066浪费，给艾奥能极大提高生存。

## 配队与模块
- 前排：8×艾奥级-高速离子炮巡洋舰（原文为“艾奥高速”，疑似简称），3×光锥级-区域防空巡洋舰（原文为“光防”，疑似简称）。
- 中排：1×普鲁图斯之盾级-防护战列巡洋舰（原文为“大盾”，疑似简称），10×CAS066级-支援巡洋舰（原文为“066奶”，疑似简称）。
- 支援方案1：5×前排ST59级-防御战列巡洋舰（原文为“电磁59”，疑似简称），带10×平衡安德森SC020-侦察机、10×SC002型-量子侦察机。
- 支援方案2：5×前排乌拉诺斯之矛（原文为“重甲大矛”，疑似简称），带15×海尔波普。
- 旧方案：前排6×ST59级-防御战列巡洋舰（原文为“电磁59”，疑似简称），支援5×乌拉诺斯之矛（原文为“拦截矛”，疑似简称），配12×CAS066级-支援巡洋舰。
- 副队舰载机重点针对敌CV-T800型-脉冲炮艇（原文为“800”，疑似简称）与海氏追随者型-脉冲攻击机（原文为“海氏”，疑似简称）。
- 可选扛伤战巡：普鲁图斯之盾级-防护战列巡洋舰、安东塔斯持剑者级-指挥舰，但为中排，不适合本队。
- 海尔波普沿用原文名称，未指定A/B型号。

## 数值与数据
- 体验服小船测试：卡利莱恩级-特种护卫舰（原文为"卡特"，疑似简称）、阋神星I级（原文为"阋神"，疑似简称）等20艘船最多扛2分30秒。
- 不用CAS066级-支援巡洋舰、改后排小船奶时，前排可扛4-5分钟，多20小船分摊火力。
- 旧方案6艘ST59级-防御战列巡洋舰面对大量伤害仅扛3分钟全灭。
- 新方案前排总共有16艘大船；实战前排至少扛4分钟，有战报。
- 乌拉诺斯之矛与ST59级-防御战列巡洋舰实战战损时间都在5分钟左右。
- 副队带舰载机最高可减免800、600的总伤害。
