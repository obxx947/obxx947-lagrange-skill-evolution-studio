# A资料601

## 场景 / 对手
针对敌方反小火力（050、刺鳐、800、星脉）的正面抗伤作战，环境为实战测试和体验服测试

## 舰队例子
- 前排：8艾奥高速+3光防；中排：1大盾+10个066奶；支援：5前排电磁59+10安德森+10个002（胜）【造价较低，能限制敌方混沌和艾奥，但换战损略劣势】
- 前排：8艾奥高速+3光防；中排：1大盾+10个066奶；支援：5前排重甲大矛+15海尔波普（胜）【输出高，换战损强，但造价较高】
- 前排：6电磁59+5拦截矛+12个066奶（负）【废弃方案，战损换不过，59仅扛3分钟，造价高且成型慢】

## 实战结果
用8艾奥高速+3光防+1大盾+10个066奶+支援5大矛或59的配置，对抗敌方反小火力，前排至少扛4分钟，副队带舰载机可减免800和600总伤害；6电磁59+5拦截矛方案多场实战战损换不过，59仅扛3分钟

## 结论思路
- 小船前排易被舰载机克制，扛不住反小火力，故用高达抗伤
- 高速艾奥造价低且闪避高，抗伤能力接近电磁59
- 前排16个大船分摊伤害，延长生存
- 副队带高生存舰载机（如002、安德森）可削弱主队伤害
- 支援战巡必须选前排（如大矛、59），中排战巡无法分担前排伤害
- 大矛输出高、换战损强，59造价低但维修量受限
- 奶量分散到艾奥上比浪费在066上更有效

## 适用限制
- 适用于敌方有大量反小火力（050、刺鳐、800、星脉）的场景
- 支援舰载机需高生存，炮艇选海尔波普（无攻击能力，避免被苔原攻击）
- 不适用于资源紧张或需要快速成型的场合
- 若敌方断奶，有炸大矛风险，需谨慎使用
