# A资料699 · 航母升级路线与8+6鱼

> 场景：航母发展路线；护航母地推/团战轰炸区；反大与防空环境

## 结论
- 航母输出升级路线：11机CV3000级-快速航空母舰（原文为"cv三千"，疑似简称） → 11鱼太阳鲸-武装战略航空母舰（原文为"鱼"，疑似简称） → C1天枢级-支援航空母舰（原文为"天书"，疑似语音识别错误） → 11+13天枢 → 8+6太阳鲸。
- 基础款航母为CV3000级-快速航空母舰、永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）、南十字星元帅级-武装航空母舰（原文为"南斯治"，疑似语音识别错误）；天枢级-支援航空母舰和太阳鲸-武装战略航空母舰是升级款。
- B4优于B2，任何玩家角度都选B4。
- B4不应与B2上的CV-T800型-脉冲炮艇（原文为"t八百"，疑似简称）、星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）比伤害，而应与420人口队伍里的弱船比伤害。
- 11机CV3000对应新手或无太阳鲸玩家，队伍常无像样输出船，甚至没有输出巡洋舰、康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡龙"，疑似简称）、艾奥级-攻坚离子炮巡洋舰、刺水母级-战术护卫舰（原文为"吃水母"，疑似语音识别错误），可能凑不齐420人口。
- 有B4一定选B4：原本上CV3000的船下放，艇位下放给超主力；坦克可由M1带，15艇位为坦克准备。
- 只需满足坦克和维塔斯-B010-轰炸机（原文为"vb"，疑似简称），甚至只带3台；无人口带其他轰炸机；没抽到BR050-标准轰炸机（原文为"零五零"，疑似简称）A可把人口给B192新大地-重型攻击机（原文为"大地"，疑似简称）；B4不冲突。
- 因此11机在B4面前反而是劣势，需要把更多艇带在CV3000线上。
- 永恒苍穹级-无人机航空母舰是11机CV3000的进化版。
- 11鱼太阳鲸是太阳鲸末尾或CV3000进化版：增援11鱼后30艇25战机，与CV3000载机完全重复，带坦克和维塔斯-B010-轰炸机，所以最基础太阳鲸是11机升级版。
- C1天枢模块主强化M1；M1有双返回加双伤害，维修无人机叠加；单抓艇、单抓战机，艇机一起加，最终到8+6太阳鲸。
- 8+6太阳鲸是11+13天枢的升级款。
- 配队从两个13、三个11改为两个11、三个13；星云追逐者-脉冲炮艇的矫正地位比伤害更重要；输出人口少的玩家推荐这样。
- 刚上太阳鲸的偏弱玩家，星云追逐者-脉冲炮艇输出占大头；不矫正会打到加能量抗性的小船上被卡死。
- 矫正超载星脉后，只需带两台太阳鲸，坦克带满；剩下三个带CV-T800型-脉冲炮艇；T800第一时间对空不打小船，整体围绕反大。
- 护航母两个场景：地推拆家或两队组起来干架；打团战进轰炸区。
- 多带10个米斯特拉-战斗攻击机（原文为"小米"，疑似简称）不等于轰炸区横行；遇防空仍要跑，对方6台永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）有压力。
- 默认不带米斯特拉-战斗攻击机，就是大部分玩家对舰的11+13组合；可把BR050-标准轰炸机改成10个米斯特拉。
- 米斯特拉绝育上舰前提是打大船；不防空时带米斯特拉与带对舰机无区别，仍无防空。
- 11+23副队上CV3000：CV3000是超主力，40万血，可开铜牌拦截，能带很多飞机和护航艇。
- 副队带25战机时不应突然搞反小SC002型-量子侦察机（原文为"零零二"，疑似简称）、平衡安德森SC020-侦察机（原文为"安德森"，疑似简称）；队伍反大、防空、反大循环不合理，且对方副队小船未必有25台。
- 刻度问题：1+1连CV3000都没到2.0的玩家，只有11+13太阳鲸输出，养不起8台战机；若非米斯特拉或BR050双兄弟，可能还要1.5。
- 有些博主配副队CV3000、主队11+13太阳鲸不负责任；配置都联动，8+6更合适。
- 8+6合适原因：艇位机位多但优秀飞机护航艇少；单太阳鲸不用考虑，双、三、四航母时问题明显。
- C2虽写攻城问题，但伤害几乎可与BR050双兄弟、刺鳐-鱼雷轰炸机（原文为"次摇"，疑似语音识别错误）持平或弱一点没关系；它博弈对象是SC002型-量子侦察机、平衡安德森SC020-侦察机等弱船，不是050双兄弟和刺鳐；这些弱船不能输出，别人不管你组队是否带防空。
- CV3000到天枢是强化：CV3000拦截子弹算拦截伤害，拦一发可能对应20万伤害；天枢一次奶1万，常100、100、100奶；一颗子弹1000伤害要拦1000颗，两条换一条不亏，天枢是CV3000上位替代。
- 天枢站中排，可与普鲁图斯之盾级-防护战列巡洋舰（原文为"盾"，疑似简称）分摊；后排CV与盾无联动，前排被突破时天枢可解决。
- 人口不足时少带CV，人口多可多带，不冲突。
- 玩到2、3、4航母时路线走通：11 CV无人机 → CV11鱼 → 天枢 → 11+13 → 8+6太阳鲸。

## 配队与模块
- 输出升级路线：11机CV3000级-快速航空母舰 → 11鱼太阳鲸-武装战略航空母舰 → C1天枢级-支援航空母舰 → 11+13天枢 → 8+6太阳鲸。
- B4优于B2；有B4选B4。
- B4方案：艇位下放给超主力；坦克由M1带，15艇位给坦克；只带坦克和维塔斯-B010-轰炸机，甚至3台；没抽到BR050-标准轰炸机A可把人口给B192新大地-重型攻击机。
- 11鱼太阳鲸：30艇、25战机，带坦克和维塔斯-B010-轰炸机。
- C1天枢：上11+13；C1主强化M1；M1双返回加双伤害；维修无人机叠加。
- 8+6太阳鲸：两台太阳鲸即8鱼+6鱼；矫正超载星脉；坦克带满；剩三个带CV-T800型-脉冲炮艇。
- 太阳鲸配队：过去两个13、三个11，现在两个11、三个13。
- 默认对舰11+13不带米斯特拉-战斗攻击机；可把BR050-标准轰炸机改成10个米斯特拉。
- 副队上CV3000，25战机位；不建议带SC002型-量子侦察机、平衡安德森SC020-侦察机。
- 天枢站中排；CV3000超主力40万血，开铜牌拦截。
- 推荐8+6太阳鲸。

## 数值与数据
- 420人口。
- 11机CV对应新手或无太阳鲸玩家，可能凑不齐420人口。
- 11鱼太阳鲸：30艇、25战机。
- 星脉输出：总100万伤害中约20万。
- CV3000：40万血，铜牌拦截。
- 拦截：拦一发可能对应20万伤害；天枢一次奶1万；奶量常见100、100、100；一颗子弹1000伤害要拦1000颗。
- 副队战机数量：1、2、3、5、6、7、8台；1+1连CV3000没到2.0；非小米或050双兄弟可能1.5。
- 对方6台永恒风暴级-攻击战列巡洋舰。
