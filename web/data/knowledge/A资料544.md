# A资料544 · 风暴与大帝solo：大帝吃亏

> 场景：永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）与新君士坦丁大帝级-综合战列巡洋舰（原文为"大帝"，疑似简称）单挑，双方均带拦截，正面作战

## 结论
- 带新君士坦丁大帝级-综合战列巡洋舰打solo且双方都有拦截时，大帝很吃亏，不推荐。
- 新君士坦丁大帝级-综合战列巡洋舰优势是残血收割，适合处理残血狂暴的乌拉诺斯之矛（原文为"矛"，疑似简称）。
- 对方6条拦截矛展开后，新君士坦丁大帝级-综合战列巡洋舰会非常难受。
- 光锥级（原文为"光追"，疑似语音识别错误）站位应跟保护对象同排；保前排就前突，放中排不合理。
- 前排带艾奥级-高速离子炮巡洋舰（原文为"艾奥"，疑似简称）可分摊火力、降低对面矛伤害；前排巡洋不宜过多。
- 出门/增援前检查加点；航母载机模块和返回未加，空战失利，米斯特拉-战斗攻击机（原文为"小米"，疑似简称）开局被击落。
- 坦普尔1号-信息护航艇（原文为"坦普尔"，疑似简称）单挑极强，能摊开空战伤害并提升回血；不是空战失利元凶。
- 队伍要带小船，否则星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）被空军攻击后触发反击防空、持续对空且不易死。
- CV-T800型-脉冲炮艇（原文为"T800"，疑似简称）用0.1秒索敌有小幅提升，但索敌更契合T810。

- 己方：新君士坦丁大帝级-综合战列巡洋舰、太阳鲸-武装战略航空母舰（原文为"太阳鲸"，疑似简称）、南十字星元帅级-武装航空母舰（原文为"南十字"，疑似简称）；光锥级放中排保护这些中/后排对象。
- 对手：永恒风暴级-攻击战列巡洋舰，另有太阳鲸-武装战略航空母舰；含6条拦截矛（乌拉诺斯之矛），光锥级误放中排，应前突。
- 双方均带拦截；己方用装甲矛（乌拉诺斯之矛）扛线。
- 前排放艾奥级-高速离子炮巡洋舰用于火力分摊/减伤。
- 己方太阳鲸-武装战略航空母舰载机模块忘加点；携带刺鳐-鱼雷轰炸机（原文为"刺鳐"，疑似简称）、维塔斯-B010-轰炸机（原文为"VB"，疑似简称）、米斯特拉-战斗攻击机。
