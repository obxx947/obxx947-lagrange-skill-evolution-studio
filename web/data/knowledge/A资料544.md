# A资料544

## 场景 / 对手
风暴和大帝之间的solo，以身入局测试大帝进solo的体验，涉及拦截、光锥位置、装甲矛、坦普尔、星脉等体系，正面战斗

## 舰队例子
- 大帝（含光锥中排、太阳鲸、南十字、装甲矛、艾奥、坦普尔、星脉、VB、刺鳐、小米、沙龙）（负）【大帝在solo中劣势明显，光锥位置不当，VB未加点导致空战失利，小米被爆】
- 风暴（含拦截、装甲矛、光锥、坦普尔、星脉、VB、刺鳐、小米、沙龙）（胜）【风暴在solo中优势明显，伤害高，装甲矛血量厚，坦普尔干扰强】

## 实战结果
风暴打大帝，大帝多场失利（百分百生存打七万、四万，风暴打十万），关键损失：大帝光锥位置错误、VB未加点、小米被爆；关键得失：装甲矛血量优势、坦普尔干扰空战、星脉防空发力

## 结论思路
- 大帝在solo中劣势明显，尤其在对面有拦截时，伤害相差大，不推荐大帝做solo
- 光锥位置应前突保护前线，而非中排，大帝阵容中光锥应保护大帝、太阳鲸等中排主力
- 装甲矛血量厚，狂暴时间长，优势明显，但面对装甲时可能打不进去
- 艾奥在前排可分摊火力，降低对面矛的伤害，但前排不能带太多巡洋，否则太阳鲸狂暴难受
- 出门前必须检查船点数是否加点，否则VB不干活导致空战失利
- 坦普尔非常强，可干扰超锁空优机，均匀分摊伤害并回血，适合单挑
- 不带小船时星脉会发力，持续对空且不易死，适合配在CV3000、太阳鲸或矛上

## 适用限制
- 大帝solo仅适用于特定情况，对面有拦截时劣势明显
- 光锥位置需根据阵容调整，保护关键单位
- 装甲矛适合对抗大帝，但面对装甲时可能无效
- 前排巡洋数量需控制，避免太阳鲸狂暴
- 坦普尔适合对抗超锁空优机，但需注意空战顺序
- 星脉防空需满足被空军攻击的条件，适合配在矛等被攻击目标上
