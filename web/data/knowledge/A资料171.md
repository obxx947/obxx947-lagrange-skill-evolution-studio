# A资料171 · 拦截船选择与平民副队配置

> 场景：高强度盟战/副队拦截

## 结论
- 拦截一般放副队，但副队会炸船，超主力放副队性价比低
- CV3000级-快速航空母舰（原文为"C B 三千"，疑似语音识别错误）放副队不如放光环，炸完难补
- 高强度盟战一天多场，上午满员、中午减员、晚上更少，资源有限补不起超主力
- 乌拉诺斯之矛（原文为"大毛"，疑似简称）与普鲁图斯之盾的拦截模块和附加装甲模块冲突，上拦截会变脆，不推荐
- 雷火之星-综合武库舰（原文为"雷火"，疑似简称）拦截看网上说很强，但一般放挺对，且对刻度要求高，主播没用过
- 阋神星I级（原文为"细尘星"，疑似语音识别错误）有拦截能力，效果低但小船可靠数量取胜，主播非常推荐
- 平民副队炸了也能快速补上，比追求最肉更实用

## 配队与模块
- 平民副队：前排阋神星I级+开阳级（原文为"开眼"，疑似语音识别错误），中排开阳级+奶船，后排瑶光级（原文为"摇光"，疑似语音识别错误）
- 副队末尾追加乌拉诺斯之矛和4个光锥级-区域防空巡洋舰（原文为"光防"，疑似简称）

## 数值与数据
- 高强度盟战一天打好几场，上午约100人，中午约70人，晚上约50人
