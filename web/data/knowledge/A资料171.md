# A资料171

## 场景 / 对手
拦截船选择与配置讨论，涉及高强度盟战环境

## 舰队例子
- C B（拦截模块）（不推荐）【拦截放副队易炸，资源消耗大，影响后续作战】
- 大盾（拦截模块）（不推荐）【拦截模块与附加甲模块冲突，上拦截后变脆】
- 大毛（拦截模块）（不推荐）【同C B问题，资源消耗大】
- 雷火（拦截模块）（不推荐）【拦截强但放副队，对刻度要求高】
- 光防（拦截模块）（推荐）【拦截效果低但小船可数量取胜】
- 细尘星（拦截模块）（推荐）【平民副队核心，易补充】
- 前排：西城星+开眼；中排：开启键+奶；后排：摇光；额外：毛+4光法（推荐）【平民副队配置，非最肉但易补充】

## 实战结果
高强度盟战中，副队炸后需快速补充，C B等大船炸后资源不足导致参战人数下降（如100人→70人→50人）

## 结论思路
- 拦截船选择需考虑资源消耗和补充速度
- 大船（C B、大盾、大毛）拦截模块不实用，因易炸且资源有限
- 雷火拦截强但条件苛刻，不推荐
- 小船（光防、细尘星）拦截效果低但可数量取胜，推荐使用
- 平民副队配置应注重快速补充能力

## 适用限制
- 适用于高强度盟战环境，资源有限
- 不适用于资源充足或低强度作战
- 大船拦截模块需谨慎使用，避免脆化
- 雷火需高刻度支持，不适合普通玩家
