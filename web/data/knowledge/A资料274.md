# A资料274 · 大盾各阶段用法与模块选择

> 场景：三战巡以下玩家扛伤核心；奶盾副队；高达副队；顶氪副队

## 结论
- 三战巡以下玩家，大盾是扛伤核心，高血条、高护甲、高能抗，面板除天权外无人能及
- 除天权旗舰队或偶尔带大矛外，大盾减伤策略是所有卡方队必带
- 模块核心为M3、C3、A1；C2可用但自身拦截效果不高
- C3反击伤害非常可观，优先选C3
- 没有附加模块时，反导拦截可用，尤其氪佬中排有天权分伤时性价比高
- 大盾拦截与反导二选一；副队没有高达的玩家老实玩附加
- 损管模块维修量还不如几个谷神星级支援驱逐舰，非常垃圾，不要用
- A3是虐菜用模块，个人建议带A1，伤害可观
- M1可要可不要，有M2、M3最好带上，M3投射伤害非常高
- 点数不够点旗舰时，旗舰一定要点，可点两层旗舰后补装甲，但建议点满
- 2.0左右玩家大盾是最必不可缺的战巡，必须练，减伤扛伤传统奶盾副队有标准战斗力
- 天权战斗力如果是三，大盾战斗力就是一；奶盾副队经历天权称霸后已没那么强势，但对小船仍有优势
- 1+1玩家大盾仍是核心，但该开始养永恒风暴级，1+2会好很多
- 大盾装甲与减伤策略一定要点，能养多少养多少
- 1+1以下不要考虑前突，奶量跟不上；没有永恒风暴级C2也不要玩前突
- 前突用得好是扛伤加强，用不好是送死策略
- 扛伤队有永恒风暴级加buff且中排不缺分伤时，太阳鲸副队里可以点前突
- 可给大盾定制两个方案：中排旗舰方案和前突方案，太阳鲸死亡后大盾前移进行五二分伤
- 前突方案不太适配永恒风暴级C2，尤其开阳队伍
- 永恒风暴级C2只对前一分钟有高额加成，之后加成大幅减少，是抵抗爆发伤害的
- 大盾顶到前排通常在两分半之后，状态不高扛不住爆发，风暴buff也被削弱
- 没有南十字星元帅级反导情况下，大盾前移约两分半
- 不点前突时，通过损失CAS066级支援巡洋舰来自保
- 高达副队之后，大盾带一到两个即可，核心是它不能到前排扛伤害
- 大盾除远峰信息限定技术外，不可能放到前排，除非前排死完
- 高达副队前排必须有乌拉诺斯之矛（原文为"大毛"，疑似语音识别错误）、天权等战巡，战巡死完大盾再上基本是送人头
- 高达副队核心是摒弃所有小船，用绝对血量装甲维修优势扛住对面伤害
- 大盾不会出现在对面输出序列里，交战80%时间只吃到附带概率伤害
- 高达副队阶段推荐点系统伤害抵抗，应对二加二起步敌人的永恒苍穹级系统伤害
- 只有两个扛伤战巡时，大盾可以前突，建议五二分伤并搞好生产方案
- 有三个扛伤战巡时，大盾变成挂件，可参与中排分伤，但受人口影响建议只带一两个当挂件
- 顶氪阶段附加装甲与反导拦截可二选一，副队进南十字星元帅级后防空拦截较缺
- 拦截与血量相比比不过，但顶氪副队分伤足够多，带拦截可提升扛伤能力

## 配队与模块
- 大盾核心模块：M3、C3、A1；C2可用但拦截效果不高
- 无附加模块时可用反导拦截，拦截与反导二选一
- 副队没有高达的玩家使用附加模块
- 损管模块不推荐使用
- A3虐菜可用，推荐A1
- M1可要可不要，有M2、M3最好带上
- 标准高质量无天权账号配队：前排乌拉诺斯之矛、中排大盾、配永恒风暴级，增援天权
- 高达副队后大盾带一到两个当挂件
- 只有两个扛伤战巡时：永恒风暴级C2加前突大盾，增援天权，带CAS066级支援巡洋舰
- 顶氪副队进南十字星元帅级后，附加装甲与反导拦截二选一

## 数值与数据
- 大盾装甲三十多万
- 物理护甲780，能量抗性30
- M3高端点满投射面板约六七万
- 永恒风暴级只点M2需要70个点
- 永恒风暴级C2前一分钟有高额加成，之后加成大幅减少
- 大盾前移时间约两分半，无南十字星元帅级反导情况下约两分半
- 中排有十二个分伤时，大盾被打概率不高
