# A资料184

## 场景 / 对手
艾格勒姆副本，星球登陆控制队，正面/轰炸，环境含陨石

## 舰队例子
- 支援舰（护航艇船坞模块）+ 列兵x10 + 先登级x30 + 云海x10 + 诺玛x10（胜）【基础控制队配置，列兵带10个列为防陨石】
- 载机支援舰 + 列兵x10（带列为）+ 老登x20（带安德森x20）（胜）【老登降低城防伤害，提高续航】
- 登陆水母替代诺玛（胜）【可替代诺玛位置】
- 天玄B型号替代安德森（胜）【攻击能力超一流，可对抗登陆舰队】

## 实战结果
橙子遭遇拥有30个老登的队伍，失败，损失惨重

## 结论思路
- 控制队需吃奖励，优先选择有护航艇船坞模块的支援舰
- 防陨石是刚需，列兵带列为可防陨石
- 续航重要，老登带安德森降低城防伤害
- 优先级：老登 > 登陆水母 = 云海 > 诺玛 > X8
- 遇到30个老登的队伍应远离

## 适用限制
- 适用于艾格勒姆副本星球登陆控制队
- 需有护航艇船坞模块的支援舰
- 列兵带列为刚需，否则易被陨石砸回
- 老登带安德森为刚需，提高续航
- 不适用于无陨石环境或缺乏关键模块
