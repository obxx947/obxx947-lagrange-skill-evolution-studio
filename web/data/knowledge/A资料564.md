# A资料564

## 场景 / 对手
新船野火型评测，针对护航艇/战机体系，正面作战，环境为solo对战

## 舰队例子
- 野火型（母体）：S型装甲，策略：结构值降至60%时获得30%闪避，数量1（胜）【生存能力与维B、SP瑶相当，但闪避略低（10%差距），适合挡刀】
- 野火型（第二型号）：主动防空，策略：结构值降至60%时子母弹额外增加3个，数量1（胜）【攻击序列优先战机，面板约1100-1200，与零幺幺相当，但低于T800；锁敌时间短，可能影响命中】
- 南十字（载具）：策略：发动期间提升舰载机50%闪避，数量1（胜）【与野火搭配，延长闪避时间至2.5-3分钟，提升生存和输出】

## 实战结果
评测野火型两型号，母体生存强，第二型号输出依赖策略；搭配南十字后，野男组合在solo中表现优秀，但未提及具体胜负场次

## 结论思路
- 野火型母体生存能力与维B、SP瑶同级，但闪避略低，适合挡刀
- 第二型号主动防空，但攻击序列优先战机，不如优先护航艇理想
- 策略触发需血量降至60%，可通过加点（巅峰5-10级）和装甲强化降低难度
- 残血爆发策略不实用，因护航艇被锁定后不会撤退，且野怪攻击不均匀
- 正确打开方式：巅峰洗点，配合南十字提升闪避和锁定同一目标，增强输出
- 野男组合（野火+南十字）在solo中能显著提升生存和伤害

## 适用限制
- 适用于solo对战，特别是需要防空和挡刀的场景
- 野火型第二型号对战机效果一般，对护航艇更佳，但攻击序列限制
- 依赖南十字载具，无南十字时效果大打折扣
- 不适用于对舰作战，空优机定位
- 需投入资源进行加点（巅峰）和装甲强化，否则策略触发困难
