# A资料564 · 野火型护航艇强度与配队

> 场景：solo空战、护航艇对舰载机

## 结论
- 野火型两个型号都还可以，值得关注
- 野火A型装甲与维塔斯B010、SP瑶同档，但仅凭一个策略评为S级略夸张
- 野火A型血量降至60%时获得30%闪避，生存能力与SP瑶接近
- 野火B型是第二个拥有主动防空的护航艇
- solo中主动防空、支援防空、反击防空差距不大，但支援防空打不到干扰型或奶船
- 野火B型攻击序列优先打战机，不如优先打护航艇理想
- 野火B型面板偏低，约等于CV-M011型水平，只有CV-T800型一半
- 野火B型血量降至60%时子母弹额外增加3个，可同时攻击4个目标
- 残血爆发思路在护航艇上不成立，因为护航艇被锁后不会回家
- 靠野怪压血再回载具不现实，会浪费时间且被逐个击破
- 野火B型正确打开方式是巅峰洗点：白板造出后加满点，保持低血量高血槽
- 野火B型装甲无法强化，但护航艇可调校强化，进一步降低触发60%血量难度
- 野火B型巅峰到5级或10级即可达到60%血量，比维塔斯B010成本低
- 南十字星元帅级是野火B型最佳载具，提供舰载机50%闪避
- 南十字星元帅级策略期间野火B型空优机约60%闪避，前四轮打击可延长至两分半到三分钟
- 南十字星元帅级锁定同一目标攻击可解决野火B型子母弹尿分叉问题，伤害提升至少一倍
- 野火B型配南十字星元帅级是绝杀组合

## 配队与模块
- 野火B型搭载于南十字星元帅级
- 野火B型利用南十字星元帅级策略：发动期间提升舰载机50%闪避
- 野火B型利用南十字星元帅级锁定同一目标进行攻击

## 数值与数据
- 野火A型血量降至60%时获得30%闪避
- 野火B型面板约1000-1200，相当于CV-M011型水平，约为CV-T800型一半
- 野火B型血量降至60%时子母弹数量额外增加3个，可同时攻击4个目标
- 野火B型技术血量5860，巅峰到15或20级后血量可达10111
- 野火B型配南十字星元帅级后前四轮打击可延长至约两分半到三分钟
- 野火B型配南十字星元帅级后空优机闪避约60%
