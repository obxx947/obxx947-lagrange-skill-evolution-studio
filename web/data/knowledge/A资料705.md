# A资料705 · 第二阶段护航副队配队

> 场景：第二阶段护航、二加二副队、反大环境

## 结论
- 第三阶段护航靠堆血量与分摊提升坦度，可接多队。
- 第二阶段护航自身血量不足，被迫用奶量换生存，可能在高刻度队伍中5-6分钟都撑不住。
- 不跨阶层，玩好自己阶段的护航。
- 副队原固定带CAS066级-支援巡洋舰（原文为“零六六”，疑似简称）与光锥级-综合导弹巡洋舰（原文为“光追”，疑似语音识别错误）的思路已放弃。
- 新阵容不推荐带CAS066级-支援巡洋舰，反而更完整。
- CAS066级-支援巡洋舰是大船、中排，主流二加二中风storm反大，前排开阳被突破后易被反大武器锁。
- CAS066级-支援巡洋舰基础18人口，绑定光锥后等效人口升到20-25，亏人口。
- 谷神星级-支援驱逐舰（原文为“谷神性”，疑似语音识别错误）应作为副队核心奶，需保护，8人口，后排，奶量纯粹。
- 有开阳等小船分摊时，敌方反小武器第一时间射不到后排谷神星。
- 反例：大船队带枪骑兵级-综合导弹驱逐舰（原文为“枪击兵”，疑似语音识别错误），无论中后排都会被反小武器锁。
- 顶级玩家输出船多为反大：太阳鲸-武装战略航空母舰（原文为“太阳鲸”，疑似简称）、安东塔斯持剑者级-指挥舰（原文为“剑”，疑似简称）、永恒风暴级-攻击战列巡洋舰（原文为“风暴”，疑似简称）、超主力；唯一反小为星云追逐者-脉冲炮艇（原文为“星脉”，疑似简称），但会被开阳拦截。
- 两个瑶光级-通用护卫舰（原文为“耀光”，疑似语音识别错误）有74%生存，因为没人处理开阳和瑶光。
- 海尔波普奶量最高，第二/第三阶段护航均可考虑；客老战报中生存不低于50%。
- 有观点称副队不带防空、T800不用带、米斯特拉-战斗攻击机（原文为“小米”，疑似简称）不适用；作者不认同，认为海尔波普生存足够。
- 副队不带防空的说法不成立；有100万防空时海尔波普仍有50%生存，50万防空更不用担心。
- CV-T800型-脉冲炮艇（原文为“t八百”，疑似简称）至少5-6分钟威慑不到海尔波普生存；若3-5分钟打不出30万防空，则海尔波普保护不住。
- 海尔波普带在第三阶段护航任何位置都有正向奶量；带在有巡洋的非第三阶段队伍会优先奶巡洋，奶量拉不开。
- 第二阶段玩海尔波普需用超展/超载维持最高奶量（原文术语，疑似语音识别错误）。
- 天枢级-支援航空母舰（原文为“天枢级-支援航空母舰记”，疑似语音识别错误）是最好的奶，因是大船，能参与大船分摊，更适配第三阶段护航。
- 五台CV3000级-快速航空母舰（原文为“c p三千”，疑似语音识别错误）带30个艇，提供拦截、艇位和分摊，是阵容最后一块拼图。
- 大船数量刚好卡在八三分摊，敌方反大武器需选3目标。
- 队伍20个小船做分摊，谷神星在后排优先锁不到。
- 本期只放副队，下期讲主队怎么带。

## 配队与模块
- 副队核心奶：谷神星级-支援驱逐舰，后排，8人口，需保护。
- 不推荐副队带CAS066级-支援巡洋舰；若带必须绑定光锥级-综合导弹巡洋舰，等效人口20-25。
- 奶船：海尔波普-系统支援护航艇+海尔波普-维修支援护航艇（原文为“海尔波普双兄弟”，疑似简称），维持最高奶量；第二阶段需配合超展/超载配置。
- 前排：开阳级-机动驱逐舰（原文为“开洋”，疑似语音识别错误）承担分摊/拦截，保护后排谷神星。
- 航母：5台CV3000级-快速航空母舰，拉满艇位，共30个艇，用于拦截、艇位和分摊。
- 小船：20个小船做分摊，降低谷神星被反小武器锁的概率。
- 反例：大船队中带枪骑兵级-综合导弹驱逐舰，无论中后排都会被反小武器优先锁定。
- 顶级玩家输出船多为反大：太阳鲸-武装战略航空母舰、安东塔斯持剑者级-指挥舰、永恒风暴级-攻击战列巡洋舰、超主力；唯一反小是星云追逐者-脉冲炮艇（星脉），但会被开阳拦截。
- 两个瑶光级-通用护卫舰有74%生存，因无人处理开阳和瑶光。
- 老一辈配队带艾奥级-攻坚离子炮巡洋舰（原文为“艾奥”，疑似简称）、康纳马拉混沌级-轨道炮巡洋舰（原文为“康纳、马拉”，疑似语音识别错误），会突破前排后锁CAS066级-支援巡洋舰。
- 天枢级-支援航空母舰可参与大船分摊，适配第三阶段护航体系。
- 海尔波普带在第三阶段护航任意位置均有正向奶量；带在有巡洋的普通队伍会优先奶巡洋。
- 本期副队，下期主队。

## 数值与数据
- 第三阶段护航靠血量与分摊堆坦度，可接多队；第二阶段可能在5-6分钟内被高刻度队伍打没。
- 海尔波普只奶大船时，5分40秒奶100万血量。
- 海尔波普满载估算：10条每分钟共奶30万，5分钟约150万。
- 海尔波普通过超展/超载奶量可达约2万/分钟。
- 争议数据：CAS066级-支援巡洋舰被群内称15分钟奶90万；作者称海尔波普5分钟可奶100万。
- CAS066级-支援巡洋舰基础18人口；绑定光锥级-综合导弹巡洋舰后等效20-25人口。
- 谷神星级-支援驱逐舰8人口，几乎全部对应奶量。
- 5台CV3000级-快速航空母舰带30个艇；按每艇1万血，挡刀约30万血。
- 3-5分钟内需用CV-T800型-脉冲炮艇打出30万防空，否则海尔波普保护不住。
- 客老有100万防空时，海尔波普在副队仍有50%生存；无低于50%的战报。
- 两个瑶光级-通用护卫舰有74%生存。
- 大船数量卡在八三分摊，敌方反大武器需选3目标。
- CV-T800型-脉冲炮艇至少5-6分钟威慑不到海尔波普生存。
- 队伍20个小船做分摊。
