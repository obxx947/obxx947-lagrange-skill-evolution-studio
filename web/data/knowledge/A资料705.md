# A资料705

## 场景 / 对手
第二阶段护航，对手/体系：二加二主流队伍、风暴、反大武器，正面/轰炸：正面护航，环境：高战对抗、客老与平民差异

## 舰队例子
- 超载海尔波普双兄弟（奶量最高，超展后约2万/分钟）+ 5台CP3000（拉满艇位，30个艇，挡刀约30万血）（胜，评价：奶量高，生存有保障，适合第二阶段护航）【奶量在5分40秒内两条船100万血（未超载），超载后每分钟可奶3万，5分钟150万】
- 零六六（中排大船，奶量高，需配光追）（负，评价：亏人口，生存差，不适合副队）【人口成本高（含光追约25人口），中排易被反大武器锁定，奶量无提升】
- 谷神星（小船，作为核心奶船）（胜，评价：需保护，有开洋分担伤害时生存好）【小船可避免反小武器锁定，适合副队核心】

## 实战结果
第二阶段护航玩家 vs 第三阶段护航玩家，第二阶段用海尔波普奶量不足（因优先奶巡洋），第三阶段用海尔波普奶量高（奶大船）；零六六在副队中生存差，被反大武器克制，实战中奶量低（15分钟仅90万），不如海尔波普（5分钟100万）

## 结论思路
- 第二阶段护航靠奶量，但奶是血量不足的被迫选择，非长久之计
- 海尔波普是奶量最高的船，超展后可达2万/分钟，适合第二阶段
- 第三阶段护航靠血量堆积和分摊，第二阶段靠奶量，跨阶层不可取
- 零六六在副队中亏人口、生存差，不如用谷神星等小船
- 带海尔波普需保证生存，用CP3000拉艇位挡刀
- 副队不带防空（如T800），海尔波普生存反而更好

## 适用限制
- 适用于第二阶段护航玩家，不适用于第三阶段（跨阶层无效）
- 海尔波普适合客老（生存高），平民需谨慎（可能被防空克制）
- 零六六不适合副队，尤其在有风暴、反大武器的环境
- 需带超展海尔波普和CP3000，否则奶量和生存不足
- 副队不带防空，否则浪费人口，影响奶量
