# A资料677 · 账号配队与模块拆分建议

> 场景：战巡/航母/巡洋体系账号配队

## 结论
- 南十字星元帅级策略引导维塔斯-B010-轰炸机（原文为"维b"，疑似简称）和BR050-标准轰炸机（原文为"050"，疑似简称）优先攻击敌方战巡，可越过开阳级-机动驱逐舰（原文为"开阳"，疑似简称）；引导可点可不点。
- 南十字星元帅级输出不弱，尤其打大船；但能量直射怕开阳级-机动驱逐舰，拆双航时左右各1个即可。
- 南十字星元帅级作为副航母值得拆点子，载机与自身输出优于CV3000级-快速航空母舰（原文为"3,000"，疑似语音识别错误）。
- 普鲁图斯之盾级M3不一定不行，但实弹伤害需点反拦截；遇3个光锥级-区域防空巡洋舰（原文为"光防"，疑似简称）时拦截难受。
- 普鲁图斯之盾级M1反击伤害很高，优先M1。
- 战巡站位不要点前排，永远中排；中排能受光锥级-区域防空巡洋舰保护，点前排会让乌拉诺斯之矛（原文为"毛"，疑似语音识别错误）和普鲁图斯之盾级优先暴毙。
- 5战巡过渡阶段用光锥级-区域防空巡洋舰副队组合，增援位放剩余1个普鲁图斯之盾级和1个乌拉诺斯之矛。
- 有永恒风暴级C3和M2可玩风暴；不拆点走风盾组合，拆点可到8战巡。
- 有白垩级-战术无人机巡洋舰（原文为"白垩"，疑似简称）上基础型号即可，账号较欧。
- 做单队干扰投射大队需拆点子给棕熊级-防空巡洋舰（原文为"熊二"，疑似语音识别错误）、白垩级-战术无人机巡洋舰和艾奥级-攻坚离子炮巡洋舰（原文为"艾奥"，疑似简称）；中期可不上CAS066级-支援巡洋舰（原文为"66奶"，疑似简称），直接憋永恒风暴级。
- 白垩级-战术无人机巡洋舰给塔拉萨萤石级-信息驱逐舰（原文为"萤石"，疑似简称）加buff；补位放刺水母级-战术护卫舰（原文为"水母"，疑似简称）子型号，带诺玛集团巡洋默认buff即形成。
- 当前账号巡洋优势大，单队干扰投射大队强度优于开封锁搞投射。
- 红宝石级-重型轨道炮护卫舰（原文为"钻石"，疑似语音识别错误）继续养，子型号输出不弱，轨道炮针对敌方开阳级-机动驱逐舰。
- 可略过中期巡洋，只造狩猎者级-载机巡洋舰（原文为"狩猎"，疑似简称）和猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误），转干扰投射大队，直接走战巡；避免出中途巡洋拖资源与时间。
- 6本左右开始造巡洋，避免升本过慢。
- 艇南玩法需点引导让南十字星元帅级打来回；小型机位优先林鸮A100型-联合攻击机（原文为"林萧"，疑似语音识别错误）。

## 配队与模块
- 太阳鲸当前只能上11鱼：缺M2模块与核心。
- 太阳鲸艇位优先索姆河之影-装甲飞行坦克（原文为"苏荷"，疑似语音识别错误）、星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）、CV-T800型-脉冲炮艇（原文为"800"，疑似简称）；9/10/19艇位后补11个CV-T800，剩余4个CV-T800进猎兵级-重型载机巡洋舰。
- 太阳鲸机位：11鱼有25机位，放10个维塔斯A021-重型攻击机（原文为"VA"，疑似简称），剩余5个刺鳐-鱼雷轰炸机（原文为"次摆"，疑似语音识别错误）补位。
- 南十字星元帅级玩10机，副航母造3个左右；拆分后六大机四中机。
- 机位拆分：6大机放10个维塔斯-B010-轰炸机、8个BR050-标准轰炸机；剩余2个BR050和林鸮A100型-联合攻击机进小机库。
- 海氏追随者型-脉冲攻击机（原文为"海式"，疑似语音识别错误）全部进狩猎者级-载机巡洋舰。
- 造2个狩猎者级-载机巡洋舰和1个猎兵级-重型载机巡洋舰；剩余4个CV-T800进猎兵。
- 后期补3个永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称），再补康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡龙"，疑似简称），增援太阳鲸作防线。
- 艇南玩法：南十字星元帅级上6艇4机，3个南十字星元帅级；6艇上S-列维9号-重型鱼雷艇（原文为"列维9号"，疑似简称）、天玑-重型护航艇（原文为"天机"，疑似语音识别错误）、虚灵-隐身导弹艇（原文为"虚灵"，疑似简称）、CV-M011型-重型导弹艇（原文为"011"，疑似简称）/高速导弹艇；小型机位约12个优先林鸮A100型-联合攻击机。
- 太阳鲸调整：11鱼把维塔斯-B010-轰炸机、BR050-标准轰炸机、维塔斯A021-重型攻击机丢进太阳鲸；放弃刺鳐，米斯特拉-战斗攻击机（原文为"小米"，疑似简称）和剩余海氏及5个维塔斯A021进狩猎者级-载机巡洋舰。
- 普鲁图斯之盾级选M1；若选M3点反拦截。
- 5战巡2盾3矛时战巡中排；2盾3矛、2盾3风暴等也在中排。
- 2盾3矛时上光锥级-区域防空巡洋舰副队组合；增援位为剩余1个普鲁图斯之盾级和1个乌拉诺斯之矛。
- 不拆点时可用5盾5分2分伤，前排加小盘古组合：开阳级-机动驱逐舰、瑶光级-通用护卫舰（原文为"瑶光"，疑似简称）、玉衡级-防御巡洋舰（原文为"玉衡"，疑似简称）。
- 有永恒风暴级C3和M2可玩风盾组合：2盾3风暴，3个进副队；也可2盾3矛、2盾3风暴并加小盘古。
- 拆完点为2盾3矛3风暴，全中排，可达到8战巡；不拆点就风盾组合。
- 副队风盾组合；想拆点就8战巡，风/矛/盾组合，3个南十字星元帅级占120，再增援给太阳鲸。
- 巡洋有白垩级-战术无人机巡洋舰上基础型号即可。
- 单队干扰投射大队：拆点子给棕熊级-防空巡洋舰和白垩级-战术无人机巡洋舰，艾奥级-攻坚离子炮巡洋舰点子也拆，均摊至少100/80点或互相80点；玉衡级-防御巡洋舰点子也可拆，给二者各100点。
- 副队可塞1个白垩级-战术无人机巡洋舰或棕熊级-综合巡洋舰（原文为"棕熊"，疑似简称），加少量棕熊级-防空巡洋舰增加容错。
- 单队干扰投射大队用3个棕熊级-综合巡洋舰、3个光锥级-区域防空巡洋舰，再加AC721-重型导弹驱逐舰（原文为"721导弹"，疑似简称），自行计算人口。
- 补位可放刺水母级-战术护卫舰子型号，配合诺玛集团巡洋默认buff。
- 前期落地开阳级-机动驱逐舰、鱼海双型号、瑶光级-通用护卫舰。
- 中期只造2个狩猎者级-载机巡洋舰和1个猎兵级-重型载机巡洋舰，然后转干扰投射大队，直接走战巡；不出中途巡洋。
