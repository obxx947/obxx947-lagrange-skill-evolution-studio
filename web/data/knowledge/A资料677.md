# A资料677

## 场景 / 对手
账号配置优化，针对11鱼、南10、战巡、巡洋体系，正面作战，环境为常规PVP

## 舰队例子
- 11鱼（无M2模块，缺核心）+ 苏荷、星脉800（9个10个19个位置补11个800，剩余4个800进列兵）+ 南10（10机，副航母3个，六大机10维B、8个050、2个050和林萧进小机库）+ 11鱼25机位（10VA、5次摆补位）+ 海式进狩猎（胜）【艇位优先，机位拆分，南10作为副航母，维B和050集中攻击战巡】
- 战巡：2盾3毛（M1模块，中排站位）+ 光防副队（增援位剩余盾毛）+ 小盘古组合（开阳、瑶光、玉衡）（胜）【M1有反击伤害，中排受光防保护，避免前排暴毙】
- 风暴：C3+M2，2盾3风暴（中排）+ 3风暴进副队 + 小盘古组合（胜）【风盾组合，拆点后可达8战巡，不拆点用风盾】
- 副队：狩猎（海式全部）+ 猎兵（4个800）+ 3风暴 + 泡泡龙 + 增援11鱼（胜）【防线补充】
- 巡洋：白垩（基础型号）+ 熊二 + 艾奥 + 玉衡（基础型号，拆点给白垩和熊二各100点）+ 3棕熊 + 3光防 + 721导弹 + 水母子型号（胜）【单队干扰投射大队，白垩给萤石buff，棕熊和水母提供默认buff】
- 南10艇南：6艇4机（3个艇南，列维9号、天机、天骑虚灵、011或高速）+ 小型机位（3南10，12位置优先林萧）（胜）【引导策略，打来回，11鱼调整：V8050、VA进鱼，次摆放弃，小米、海式、5VA进狩猎】

## 实战结果
鱼账号配置优化，针对11鱼、南10、战巡、巡洋体系，多舰队组合，整体胜势，关键得失：南10策略引导怕开阳，M3实弹怕光防，需拆点优化

## 结论思路
- 11鱼艇位优先苏荷、星脉800，剩余补列兵
- 南10作为副航母，机位拆分六大机四中机，维B和050集中攻击战巡
- 战巡用M1模块，中排站位，避免前排暴毙，2盾3毛组合
- 风暴用C3+M2，风盾组合，拆点后可达8战巡
- 巡洋用白垩、熊二、艾奥，拆点给各100点，形成单队干扰投射大队
- 南10艇南玩法，6艇4机，引导策略，11鱼调整机位

## 适用限制
- 适用于有11鱼、南10、风暴、白垩、熊二等账号
- M3模块需点反拦截，但怕光防，建议用M1
- 南10策略引导怕开阳，需谨慎使用
- 拆点需足够点子，否则优先憋风暴
- 副队需光防保护，避免前排暴毙
