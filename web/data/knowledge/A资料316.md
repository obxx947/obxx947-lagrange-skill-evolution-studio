# A资料316

## 场景 / 对手
盟战，双方各50人参战，实力相当，正面战斗

## 舰队例子
- 超斩队（超主力+斩击模块）（胜）【在盟战中用于压制敌方超主力，迫使敌方撤退】

## 实战结果
超斩队打敌方超主力，敌方半血撤退，我方加入队友夹击，最终盟战胜利

## 结论思路
- 单人作战时超斩队效果有限，因敌方会撤退
- 盟战中超斩队可迫使敌方撤退，解放自身兵力
- 加入队友夹击可形成二打一优势，滚雪球扩大战果
- 盟战管理常要求战损达60%-70%才能撤退，避免坑队友

## 适用限制
- 适用于大规模盟战，双方人数相当
- 不适用于单人作战或敌方无撤退意愿的情况
- 需队友配合，否则效果降低
