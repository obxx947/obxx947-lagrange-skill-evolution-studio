# A资料22

## 场景 / 对手
前期打架、增加战损、偷袭嘎矿船、被追杀时使用；无苍穹（轰炸）之前的阶段

## 舰队例子
- 10个股神 + 10个小米 + 10个维A（胜）【前期配对常用，利用维A打动力系统特性】

## 实战结果
玩家用维A嘎矿船（偷袭），被追杀时表现良好；无具体胜负记录

## 结论思路
- 维A前期定位是增加战损，适合前期打架和后期增伤
- 加点优先动力系统（往复、锁敌），主武器系统点降低拦截率（必点）
- 反击火炮几乎无用，可忽略
- 前期优先加血量，有护航后点满动力、指挥、主武器系统
- 维A是T一阵列，适合偷袭和逃跑

## 适用限制
- 适用于无苍穹（轰炸）之前的前期阶段
- 主武器系统降低拦截率是必点，其他加点可选暴击、冷却、命中
- 反击火炮伤害低，不建议投入
