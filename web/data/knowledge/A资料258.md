# A资料258

## 场景 / 对手
低赛后期护航配对，面对飞机海和强势战群，蓝点数量少，无法以战群航母为主力，巡洋数量有限

## 舰队例子
- 泡泡龙（巡洋）+ 斗牛A系 + 神星全型号 + 水母A，增援CV或大帝，总人口320（胜）【推荐配置，性价比高】
- 普卡/重卡/爱尔（替代泡泡龙）+ 云海/雷里亚特/创神星（替代小船）（胜）【替代方案，强调输出能力】

## 实战结果
低赛玩家使用推荐配置对抗飞机海和强势战群，未提供具体胜负记录，关键得失为蓝点限制下需优先输出，忽略拦截

## 结论思路
- 低赛阶段蓝点少，无法依赖航母或大量巡洋，应优先使用巡洋输出，不足时用小船补充
- 巡洋输出优先选择泡泡龙，小船选择斗牛A系、神星全型号、水母A
- 增援选择CV或大帝性价比高
- 替代选择：巡洋可用普卡、重卡、爱尔等，小船可用云海、雷里亚特、创神星等
- 此阶段无需考虑武器和拦截，只要能打出伤害即可

## 适用限制
- 适用于低赛后期，蓝点数量较少的情况
- 不适用于飞机海或强势战群作为主力的情况
- 不适用于需要拦截或复杂战术的场景
