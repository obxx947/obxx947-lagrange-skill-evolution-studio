# A资料489

## 场景 / 对手
大件（大舰）在主队配合大地的体系，正面作战，环境为常规PVP

## 舰队例子
- 大件（M1模块）+ 主队，VB护航艇（胜）【平民用法，M1为VB加攻击，打护航时有效】
- 大件（M3模块）+ 大地（M1模块、A2模块、AR）+ 6个大地（胜）【高要求，克劳的玩具，两个大件管6个大d，A2能量伤害且结构值提升命中率，配合AR不被拦截】
- 大件（B3模块、02或03装甲）+ 主队（胜）【B3性价比极高，装甲融化减敌方魔抗和物抗，能量伤害不被拦截】
- 大件（M2模块）+ 副队，666奶（负）【性价比低，大件管三个巡洋，奢侈且易损失】

## 实战结果
玩家实战中推荐主队矛盾组合（两盾三矛或三盾五矛），大件放主队配合大地优于副队，副队作用低且损失大

## 结论思路
- 大件放主队配合大地更好，可带M1或M3模块
- M1模块为VB加攻击，适合平民；M3模块配合大地，要求高
- 大地带M1模块和AR，A2能量伤害且结构值提升命中率，配合大件M3不被拦截
- 主队B3模块性价比高，减敌方抗性且能量伤害
- 大件放副队性价比低，不如主队配合大地或矛盾组合

## 适用限制
- M3模块和大地体系要求高，适合高配置玩家
- 大件放副队仅适合特定奶队，但成本高不推荐
- 主队优先矛盾组合，配件灵活不常规化
- 光追必带时，大件A系统可选A1或A2
