# A资料626

## 场景 / 对手
游戏《无尽的拉格朗日》输出配置思路，涉及直射和投射攻击方式，针对不同敌方配置（前排小船、中排战巡、高达抗伤队）的实战环境

## 舰队例子
- 风暴断奶配合超斩火力，大量投射反大火力（胜）【速度点杀敌方超主力，克制前排小船和中排战巡扛伤配置，但面对高达抗伤队输出不足】
- 纯直射火力，如混沌、艾奥、狂暴毛，搭配维A、次幺零、五零、八百星脉反小（胜）【输出总量高，能快速贯穿前排，但面对高闪避小船时需反小，否则换战损亏】
- 直投混编，如风暴配混沌，追求极致数值（负）【火力分散，打战损费劲，但蒙战时有优势】

## 实战结果
三种配置思路各有优劣，蒙战实际差距不大，靠人数和意识；风暴超斩思路能对敌方资源造成压力，直射和混编输出高但敌方会撤退，优势难发挥

## 结论思路
- 纯投射或超斩思路核心是为风暴服务，利用断奶空档期点杀超主力，克制前排小船和中排战巡，但面对高达抗伤队输出不足
- 纯直射思路追求输出总量，快速贯穿前排，但需反小以解放火力，面对高闪避小船时换战损亏
- 直投混编思路无明确核心，追求数值，但火力分散，打战损费劲，蒙战时有优势
- 推荐风暴超斩思路，能对敌方资源造成压力，直射和混编优势在实战中难发挥

## 适用限制
- 纯投射思路需风暴断奶成功，存在概率性，敌方超主力多时失效
- 纯直射思路需反小配置，否则面对高闪避小船换战损亏
- 直投混编思路在蒙战有优势，但打战损费劲，点开战报难受
- 所有思路需保证输出为前提，不能完全放弃优质输出
