# A资料695 · 坦克+雷火solo配队分析

> 场景：solo对局；对手为永恒风暴级+大剑输出队、纯大剑队；当前版本主流防御小船多为能量抗性

## 结论
- 坦克可引导全队直射武器统一攻击同一目标，这是体系的核心价值。
- 不带坦克时全队直射武器分散打不同舰船，很难快速融化敌方前排战巡、航母。
- 有坦克后全队直射伤害汇聚单点，先拆关键舰船，断对方输出与载机。
- 雷火之星-综合武库舰（原文为“雷火”，疑似简称）为纯直射伤害且无法被拦截，完美适配坦克引导。
- 坦克负责聚拢伤害、雷火之星负责稳定高额直射输出，二者互为双输出核心。
- 只要坦克存活，雷火之星的输出就能全部打在同一个目标上。
- 永恒风暴级-攻击战列巡洋舰（原文为“风暴”，疑似简称）为曲射伤害，不受坦克引导、输出分散。
- 安东塔斯持剑者级-指挥舰（原文为“剑”，疑似简称）单点伤害高，但缺少持续稳定的直射补伤。
- 对手前排被快速融化后，后排输出环境直接崩盘。
- 不必带光锥级-综合导弹巡洋舰（原文为“光锥”，疑似简称）等拦截巡洋：雷火之星不吃拦截克制，敌方拦截只能挡曲射战机，白占人口还压缩输出船数量。
- 开战坦克先锁定敌方血量最低的舰船，全队直射集火。
- 优先处理对方大剑、光锥级这类巡洋：血量低，集火几秒即可击沉，断掉对方拦截与副输出。
- 剩余战巡、航母失去巡洋分摊后承受全额伤害，战损差距瞬间拉开。
- 开阳、瑶光这类能量抗性阵容克制不了雷火之星：它是物理直射伤害，开阳只减免能量伤害。
- 当前版本主流防御小船全是能量抗性，物理直射几乎没有克制手段。
- 纯大剑solo队输出上限高但依赖模块，持续输出能力远不如满编雷火之星。
- 雷火之星获取难度低、不需要关键模块，抽到就能拉满输出，平民与满氪玩家都能用。
- 坦克一旦阵亡，全队直射伤害立刻分散，阵容强度直接腰斩。
- 不要搭配曲射输出船（风暴、新大地），曲射不受坦克引导，与体系冲突且挤占人口。
- 队伍只保留直射船：乌拉诺斯之矛、雷火之星、坦克，再加少量功能船。
- 该组合优势：伤害集中、输出无法被拦截、不惧能量抗性小船、适配所有氪度玩家。
- 唯一短板是坦克生存压力大，前排必须做好分摊。

## 配队与模块
- 主队：坦克 + 雷火之星-综合武库舰，纯直射双输出组合。
- 前排优先堆分摊抗伤船，乌拉诺斯之矛（原文为“毛”，疑似语音识别错误）是最优前排。
- 多条乌拉诺斯之矛分摊伤害可提前触发狂暴增伤，其双直射武器也能吃到坦克引导。
- 队伍只保留直射船：乌拉诺斯之矛、雷火之星-综合武库舰、坦克，少量功能船即可。
- 不推荐配光锥级拦截巡洋（雷火之星不吃拦截克制，只会挤占人口）。
- 不推荐搭配曲射输出船，如永恒风暴级、B192新大地-重型攻击机（原文为“大地”，疑似简称）。
- 纯大剑队依赖模块，单A2即可玩。

## 数值与数据
- 前排乌拉诺斯之矛尽量凑5~6艘，形成五二分伤，避免单船承伤被快速秒掉。
- 敌方巡洋血量低，集火几秒即可击沉。
