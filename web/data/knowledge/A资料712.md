# A资料712

## 场景 / 对手
超战时代主队对抗，分析对面输出队与扛伤队调整方向

## 舰队例子
- 超高达队（15超战，分商6个）（胜）【正规超高达队需15超战，分商6个，对应5对2 8对30 43对5】
- CV航母（12艇位，10波波）（负）【无加速时，防空强则奶量不足，2万都奶不下来，浪费艇位】
- 06（6个或5个，最多8个）（胜）【奶量可达41万，但主队2分钟仅64万伤害，奶量偏低】
- 光防（3个）（负）【无B2大盾时带光防亏人口，有B2大盾+风暴则不需要】
- 输出队（斗牛、水母、鱼海）（负）【30天仍用旧船，伤害低，斗牛和云海是能量伤害，反小效果差】
- 太阳晶+CV（14鱼）（负）【太阳晶B模块是关键，14鱼伤害低，不如索姆河、林萧、VVb】
- 狩猎林萧（负）【加点错误，点频率不点武器加成，伤害仅1万多，打小船无意义】
- 叶维（塞太阳晶，10艇位）（负）【2分钟仅4万伤害，加点错误，三位一体亏伤害】

## 实战结果
对面主队2分钟64万伤害，我方输出8万，050 7万，索姆河5万，林萧6万，VVb 9万；对面奶量7万，我方奶量41万；我方胜

## 结论思路
- 扛伤队超战数量需根据指挥系统集火说明调整，正规15超战
- 无加速能力时不要带CV做航母，浪费艇位
- 06数量推荐6个或5个，最多8个，超过则奶量不足
- 有B2大盾+风暴时不需要光防，光防只对大地重卡有效
- 输出队应淘汰斗牛、水母、鱼海，改用齐拉A做反小
- 太阳晶与CV差别在B模块，做十字鱼不如用索姆河、林萧、VVb
- 狩猎林萧需点频率，不点武器加成，否则伤害低
- 叶维加点错误，三位一体亏伤害
- 超战时代应多造超战，调整整体思路

## 适用限制
- 适用于超战时代主队配置
- 需有足够超战和模块支持
- 不适用于无加速或防空强的环境
- 光防仅在无B2大盾时使用
- 输出队需根据对手前排调整反小船
