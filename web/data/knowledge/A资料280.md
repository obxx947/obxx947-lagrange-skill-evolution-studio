# A资料280

## 场景 / 对手
021型舰船讲解，包括主型号、B型号（干扰型）和C型号（多功能型）在轰炸体系中的使用

## 舰队例子
- 021 B型号（干扰型），加点：频率点满、闪避、被直射命中率下降、防空武器锁定下降、结构值（负）【轰炸挡刀核心，但干扰在轰炸中不起效，结构值优先于闪避】
- 021 C型号（多功能型），加点：伤害暴击点满、目标、精确攻击、动力（胜）【可挡刀和补输出，但单发40实弹伤害低，破不了超主力甲，适合打系统】

## 实战结果
轰炸玩家使用021 B型号对抗苍穹加鱼组合，打了五分钟无干扰施加；地推撞碰瓷队时干扰优先反小，但优先目标区护；C型号在萌新期使用，补充伤害和挡刀

## 结论思路
- 021主型号面板低，定位模糊，不推荐使用
- B型号是轰炸挡刀核心，必须点满频率、闪避、被直射命中率下降、防空锁定下降
- 结构值优先于闪避，但团战强度高时洗点改点
- B型号干扰在轰炸中不起效，仅在地推时可能有用，干扰点不点无所谓
- C型号是强输出船但输出不高，可打系统，加点伤害暴击点满，不点频率
- C型号可替代B型号补输出，但补不了多少，建议还是带B

## 适用限制
- B型号适用于轰炸挡刀，但干扰效果在轰炸中无效
- C型号适用于萌新期或打系统，但破不了超主力甲
- 点数不够时干扰完全没必要点
- 分散攻击不建议点
