# B资料1-61 · 护卫舰全解析与培养优先级

> 场景：现版本环境

## 结论
- 必养三艘：刺水母级-战术护卫舰（原文为"水母"，疑似简称）、卡利莱恩级-特种护卫舰（原文为"特卡"，疑似疑似简称）、云海级，为前期开荒三幻神
- 刺水母级至少要养两个型号，B型、C型都要用到
- 云海级前期控矿帮助极大，控矿带来的资源产量很可观，建议每个玩家前期都去控矿
- 卡利莱恩级-特种护卫舰前期打城帮助大，第一天第二天的二级城守军基本都是直射武器，正好被它压制
- 卡利莱恩级-特种护卫舰造价便宜，人口虽高但前期港口填不满，对人口利用率要求不高，不算问题
- 瑶光级套盾机制强，能让对方能量武器直接少一大半伤害
- 狼蜥级A型、C型都很强力，自身伤害不高但最终能打出很高的防空
- 狼蜥级第一序列目标是护航艇，在碰瓷船体系里这个序列优先级最高
- 苔原级不够强，就是因为它优先打战机而不是护航艇
- 静海级-脉冲炮护卫舰（原文为"载脉冲"，疑似语音识别错误）与狼蜥级一样第一序列为护航艇，命中略逊于狼蜥级，优先级排同一档
- 红宝石级A型、B型在当前实战环境没有就业空间，直射且DPM低，一般不使用
- 红宝石级-重型防御护卫舰（原文为"红宝石c型号"，疑似简称）不用于扛伤，而是远程远射敌方前哨站
- 红宝石级-重型防御护卫舰有自奶，鱼雷属攻城属性，磨得慢但相对算快，主要图它造价低廉、炸了不心疼
- 锆石级对不玩轰炸的玩家没用；对轰炸底座玩家很重要，前期缺载机平台时A型、B型可提供挡刀
- 锆石级挡刀艇被炸掉后不需要花资源补，缓解了前期补艇的资源负担
- 诺玛M470级-支援护卫舰（原文为"诺马"，疑似语音识别错误）前期可被谷神星级-支援驱逐舰（原文为"古神奶"，疑似语音识别错误）直接替代，不必出诺玛奶
- 着急出船时可先出诺玛M470级-支援护卫舰过渡一下
- 雨海级面对开阳级加瑶光级的组合时经常打不出伤害
- 雨海级“切入作战”原为良性bug，作主目标时也能选三个结构值最低目标攻击，约5月被修复，现在只有夹击时才能选结构值最低目标，意义不大
- 雷里亚特级-隐身护卫舰以前前期开荒很强，现在过渡驱逐太快，不再需要它扛伤害
- 雷里亚特级三个型号中最有用的是B型，前期没用，后期组队补人口很好用
- 雷里亚特级A型的策略类似小AC721，但只在指挥值低于200时生效，实际作用偏小
- FG300型理论上只需18个点，点满侦查移速即可
- 实战中侦查会互殴，把火炮点满的侦查FG300型很重要；对方没点装甲和火炮，侦查就打不过你

## 配队与模块
- 刺水母级-战术护卫舰：加点200以上，B型（防御）与C型（登陆）至少养两款
- 云海级：前期控矿使用
- 卡利莱恩级-特种护卫舰：前期打一级、二级城
- 狼蜥级A型（防御）、C型（攻坚）：碰瓷队中承担对护航艇序列
- 静海级-脉冲炮护卫舰：与狼蜥级同档，同一队中可互换
- 红宝石级-重型防御护卫舰：远程拆敌方前哨站
- 锆石级A型（突击）、B型（特种）：给轰炸队提供挡刀艇
- 谷神星级-支援驱逐舰：替代诺玛M470级-支援护卫舰的奶位
- 雷里亚特级-B型（战术鱼雷护卫舰）：后期组队补人口零头
- FG300型-侦察护卫舰（原文为"侦查富贵"，疑似简称）：点满侦查移速，同时把火炮点满

## 数值与数据
- 刺水母级建议加点200以上
- 第一天300人口的港口，很多人都是填不满的
- 破盾、出现大战损时舰队指挥值一般已拉到300以上
- 雷里亚特级A型策略触发条件是指挥值低于200
- 组队时剩4人口零头（如416人口）可用雷里亚特级B型补足
- 锆石级A型、B型能提供40个挡刀艇，数量很多
- FG300型理论上只需18个点（点满侦查移速）
