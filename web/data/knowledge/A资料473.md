# A资料473

## 场景 / 对手
对抗缝合轰炸（含永恒苍穹），正面防空/干扰作战，环境为常规PVP

## 舰队例子
- 白鳍鱼干扰型（干扰护航艇输出，降低命中率，延长冷却）（胜）【核心干扰，压制敌方高伤害护航艇】
- 八百、零幺高速（防空火力）（胜）【专门打击敌方护航艇】
- 谭普尔一号干扰型（干扰索敌）（胜）【使敌方武器乱打】
- 小米雷、火（防空飞机）（胜）【强化防空火力】
- 富加顿（吸引火力）（胜）【保证其他舰船存活，非旗舰】
- 枪骑兵防空（旗舰）（胜）【提升舰载机命中率和防空暴击率】
- 防御牛、台元支援、股神支援（防空舰船）（胜）【配合光追提升对空伤害】
- 光追通用型（诺马巡洋舰）（胜）【提升诺马驱逐/护卫防空伤害，多引导5个小船】
- 遥光（能量护盾）（胜）【克制敌方八百和星脉】

## 实战结果
十四鱼碰瓷队 vs 缝合轰炸（含永恒苍穹），多场战报：第一场41秒，敌方伤害22.4万，我方仅损4个护皇艇，无其他战损；第二场1分03秒，敌方伤害29.5万，我方仅损2个护皇艇。总体胜，关键得失：干扰和防空压制敌方输出，自身损失极小

## 结论思路
- 白鳍鱼干扰型可大幅降低敌方护航艇输出，延长冷却
- 强力防空火力（八百、零幺、小米雷火等）专门清理护航艇
- 谭普尔干扰索敌，使敌方武器乱打
- 富加顿吸引火力，保护核心舰船
- 枪骑兵防空旗舰提升舰载机命中率和暴击率
- 光追通用型提升诺马阵营防空伤害，使防御牛等输出起飞
- 遥光提供能量护盾，克制特定敌方舰船

## 适用限制
- 舰船配置不固定，可根据蓝图替换（如无雷火可换弹普尔B或挡道艇）
- 适用于对抗缝合轰炸体系，尤其含永恒苍穹
- 需要一定蓝图基础，如白鳍鱼、光追等
- 不适用于无护航艇的敌方阵容，干扰效果可能减弱
