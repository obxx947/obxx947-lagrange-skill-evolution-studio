# A资料323

## 场景 / 对手
大帝舰队输出测试，正面战斗，环境为常规PVP

## 舰队例子
- 大帝x6（胜）【两分钟总输出63万，单舰最高17万，最低7万，落差10万】
- 大帝x6（胜）【两分半总输出99万，单舰最高21.8万，最低11.52万，落差10万+】

## 实战结果
两场战斗均以大帝舰队获胜，但六艘大帝输出极不稳定，总有一艘超神、一艘拖后腿，其余四艘正常，输出落差普遍在10万以上

## 结论思路
- 大帝单舰输出波动极大，同一舰队内最高与最低差距可达10万+
- 六艘大帝中通常一艘表现超神，一艘表现低迷，其余四艘输出中等
- 输出落差并非偶发，而是普遍现象，可能受随机因素影响
- 大帝适合作为爆发输出核心，但需接受其不稳定性

## 适用限制
- 适用于大帝数量较多（如6艘）的舰队配置
- 不适用于追求稳定输出的场合，如持久战或需要精确控制的战术
- 对运气依赖较高，不适合作为唯一输出依赖
