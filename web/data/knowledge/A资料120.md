# A资料120

## 场景 / 对手
防空碰瓷，针对缝合苍穹轰炸，正面/轰炸环境

## 舰队例子
- 防御牛（石加抬原石）+ 瑶光石 + 枪防石 + 光锥A + 大盾 + 一起剑空位盆骨神奶或其他防空船增援；十四鱼M一装载T800×15 + 高速零幺幺信号15；C一装载小米雷火包子；沙龙、凌霄、海市根据蓝图搭配；B2装载谭普尔双型号凯波尔辅币其他炮灰艇（胜）【可单队无伤吃缝合，背两三个集火也能无伤吃半数炮艇】

## 实战结果
橙子所在盟经过大量盟战证实，该队可单队无伤吃缝合苍穹轰炸，配合封锁防空威力更上一层楼

## 结论思路
- 防空输出以T800、高速十一、小米雷火、防御牛和财源为绝对核心
- 针对星脉优先反小的特点，加入瑶光进行制裁，因星脉是能量伤害，瑶光克制极其严重
- 针对索姆河优先反大的特点，加入重甲战巡进行制裁，重甲战巡严重限制其伤害
- 苔原奶和古神奶优先奶大船，使大盾成为索姆河输出障碍
- 光锥A的诺玛阵营提供群羊buff，90秒内为15个护卫舰/驱逐舰提供引导，主武器获得暴击效果，对舰船15%概率额外100%暴击，对舰载机15%概率额外350%暴击；光锥A可额外加5个引导，加上防御牛和苔原奶共20个引导

## 适用限制
- 适用于防空碰瓷场景，针对苍穹轰炸中的星脉和索姆河
- 需要特定蓝图（如防御牛、瑶光、光锥A、T800等）
- 优先级按顺序搭配，需根据自身蓝图调整
