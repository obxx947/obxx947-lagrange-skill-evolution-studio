# A资料654

## 场景 / 对手
实战被偷，主队副队无护航，副队面对三队夹击（含轰炸），环境复杂

## 舰队例子
- 天书x5（a3，满点，旗舰满点，加9，56万血，465护甲，25魔抗）（胜）【副队核心抗伤，维修量235万】
- 大毛x3（中甲，29万血，l模块，中排站位）（胜）【输出约70万，防空弱】
- 风暴x3（c2，加4加9，m2模块）（胜）【输出63万，提供能量闪避率】
- 天权x6（中甲，35万血，585护甲，35魔抗，满点，双输出模块）（胜）【输出67万，防空8万，综合性能强】
- 大盾x1（旗舰，中甲，毕业）（胜）【旗舰】
- 风暴x2（c2，m2模块）（胜）【主队配置】
- 天权x6（主队，少加护甲加血量）（负）【主队战损2个】
- 大毛x2（主队，损管，中甲，中排）（负）【主队配置】
- 风暴x4（m2，鱼）（负）【夹击队主要输出】
- 混沌x8（夹击队）（负）【输出54万，受c2风暴影响减半】
- 坦克维b（鱼）（负）【输出28万】
- cv队（星脉800，维b，斗牛，混沌）（负）【输出257万，斗牛打轰炸】

## 实战结果
副队（天权高达队）1v3，三队夹击，三分钟无战损，最终战损仅炮艇，主队战损2天权1风暴，副队输出227万，夹击队219万，cv队257万，副队总血量约800万，维修量313万

## 结论思路
- 天权高达队抗伤极强，三队夹击三分钟才出现战损
- 风暴c2提供能量闪避率，对混沌等能量输出减半效果显著
- 天权综合性能强，输出和防空兼备
- 大毛输出高但防空弱
- 无护航时副队仍能硬抗多队，有护航可全穿

## 适用限制
- 配置基于实战有什么用什么，非标准模板
- 需应对轰炸等复杂战况
- 风暴c2对高命中载机（如维b、星脉）效果有限
- 混沌怕风暴c2，不仅怕开洋
- 天权装甲模块对护甲和魔抗有加成（待测试）
