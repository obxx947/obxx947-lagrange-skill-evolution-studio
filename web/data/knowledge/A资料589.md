# A资料589 · 南十字加强后玩法与模块解析

> 场景：正式服/体验服对比；氪佬对撸；主队/副队；机南/艇南

## 结论
- 南十字在测试服加强后，是除太阳鲸以外输出能力最强的航母
- 南十字再强也只是副航母，地位与苍穹齐平，一个主攻一个主辅
- 苍穹不是输出航母，点分散作战后有效输出低，定位是辅助航母
- 南十字伤害集中倾泻在前排盾上，属于真正意义上的输出船
- 南十字适合林鸮A100型-联合攻击机（原文为"凌霄"，疑似语音识别错误）、苍穹已毕业的队伍，用来给队伍增加输出
- 狩猎者位置可能被勇士全面取代，苍穹会被南十字取代
- 直射武器与曲射武器无高低之分，只是输出形式不同
- 氪佬对撸时前排无巡洋，南十字伤害基本全是有效伤害
- 开阳和瑶光组合挡不住氪佬直射武器推进
- 南十字可取代狩猎者、苍穹或CV3000的位置，但永远逃不出副航母定位
- 南十字取代CV3000后，除超主力、空军站位、拦截外还多一项输出
- 南十字对艇区保护能力比CV3000更强
- 机南放主队做输出，艇南放副队做防御
- 不推荐M1和M2混搭，也不推荐A1和A2混搭，太耗点数

## 配队与模块
- M模块推荐M2，但必须绑定B2使用
- M1配合B1面板最高，但可能被前排开阳瑶光组合克制
- B1强化对轨道炮无用，B2提供15%命中提升
- B2命中提升可让载机少点命中、多点伤害，如蜂巢可只点下面两排
- A模块更新后多一个格子和加点，点后面有20%命中提升
- 机南不推荐点优先攻击前排，直接点斩击即可
- 艇南推荐点优先攻击前排，与斩击不冲突
- C模块一般以C1为主，带维塔斯A021-重型攻击机（原文为"维A"，疑似简称）和小米
- 对面有防空时小米优先反小，无防空时维塔斯A021-重型攻击机输出
- C3适合用侦察无人机，可施加命中，一台能带三个
- 主炮加点优先基础命中，反命中不如基础命中重要
- 小米需要超速，必须点系数，返回是刚需，再加伤害和策略

## 数值与数据
- 苍穹5分钟可打42万输出，但有效输出只有约10万
- 南十字3分20秒连同队伍所有船吞没四五百万血量
- B1强化：离子炮冷却下降15%，离子炮伤害提升10%
- B2提供15%命中提升，另有30%命中提升绑定
- 南十字基础命中约50-70，B2再调两层后基本满命中
