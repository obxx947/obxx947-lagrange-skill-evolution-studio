# A资料681

## 场景 / 对手
游戏《无尽的拉格朗日》中阋神星驱逐舰的三种型号（A、B、C）的用途、加点和实战分析

## 舰队例子
- 阋神星A型（火炮+拦截搭，动力系统三个闪避，装甲抵抗）（胜）【作为木星远护队（预制队）常驻前排，全游戏最肉驱逐，点满后血量提升显著】
- 阋神星B型（重炮，双伤害或一伤害两命中）（胜）【前期中坚力量，万金油，闪避和单发高，作战能力强】
- 阋神星C型（装甲，三格血量+一格抵抗，旗舰）（胜）【用于封锁，泛用性广，点满血量提升生存】

## 实战结果
无具体实战记录，仅分析各型号优劣和适用场景

## 结论思路
- 阋神星A型是全游戏最肉驱逐，因残血40%闪避和常驻41%闪避，加上高结构值，适合作为预制队前排，地位不可撼动。
- A型加点：火炮点拦截搭，动力系统三个闪避必点，装甲点抵抗，有条件点满以提升血量。
- B型重炮在人口削落后仍是前期最实用舰船，闪避和单发高，作战能力强。
- B型加点：因火力星界策略降低命中，推荐舍弃一个伤害换两个命中，除非调满策略。
- C型装甲型在护航出现前无人问津，坦度不如A型，火力不如B型，但封锁功能有独特价值。
- C型加点：点满三格血量和一格抵抗，不点两抵抗因后期单发高，抵抗效果有限。
- C型旗舰值得点，因能加血和快速解底，且阋神星C是少数有封锁能力的舰船。

## 适用限制
- A型适合预制队前排，但需点满闪避和血量才能发挥最大作用。
- B型适合前期作战，但需注意命中问题，不调满策略时需点命中。
- C型适合封锁战术，但坦度不如A型，面对高火力时生存能力有限。
- 所有型号加点需根据资源情况调整，武器技术升级成本高。
