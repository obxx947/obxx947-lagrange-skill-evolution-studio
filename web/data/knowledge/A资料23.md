# A资料23

## 场景 / 对手
050舰船加点与型号选择，针对一加一、双航、十三余等玩家群体，涉及护航、对舰、轰炸等体系

## 舰队例子
- 050基础型号（对舰型），指挥系统选索敌，优先加往复型，点两个锁敌，头段选第二个，实弹伤害，优先加第二排以解锁反拦截（胜）【推荐一加一玩家使用，伤害足够】
- 050防御型（B型号），动力系统加满，电子防御系统可选，指挥系统加第一个，实弹伤害，加点可变动，反拦截B点，可点冷却和暴击（负）【伤害太低，不如新大帝或孢子，不推荐用于护航】
- 050鱼雷型（C型号），绑定苍穹C1和M1，用于分散打击（胜）【有苍穹C1时可用，无C1则只用基础型号】

## 实战结果
实测中防御型伤害低，不如新大帝或孢子；基础型号表现良好，推荐使用

## 结论思路
- 一加一玩家玩050基础型号即可，防御型没必要上
- 防御型伤害太低，上它不如上新大帝或孢子
- 基础型号加点：指挥系统选索敌，优先加往复型，点两个锁敌，头段选第二个，实弹伤害，优先加第二排解锁反拦截
- 防御型加点：动力系统加满，电子防御系统可选，指挥系统加第一个，加点可变动，反拦截B点，可点冷却和暴击
- C型号鱼雷型绑定苍穹C1和M1，用于分散打击，无C1则只用基础型号
- 二加二、二加三玩家不推荐用防御型，但可用来给维币挡刀

## 适用限制
- 适用于一加一玩家，基础型号为主
- 防御型不推荐用于护航，伤害低
- C型号需有苍穹C1才能发挥
- 加点可随意变动，根据战斗需求调整
