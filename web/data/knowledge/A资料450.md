# A资料450

## 场景 / 对手
肉队中大毛的定位（抗伤和辅助），当前大环境下前排附加矛抗伤能力下降，大毛转为副抗伤或辅助性战巡

## 舰队例子
- 大毛+附加装甲模块（提供150物抗和近6万血量）+装甲系统调教加点拉满（胜（抗伤定位，但当前环境效果有限））【刚需附加模块，调教加点建议拉满】
- 蓝睫毛+核心模块（全域拦截）+M1系统弱点定位（胜（辅助定位，拦截效果高））【拦截效果与雷火相同，但缺少附加模块物抗，面对坦克自保能力弱，可通过中排分商提高生存】
- 大毛+M1系统（单发反大能力）（胜（反大能力不错））【M1拥有不错的单发与反大能力】
- 大毛+M2系统离子炮（胜（反大实战效果更高））【反大实战效果比M1高，但设施惩罚严重】
- 大毛+B3系统（提高自身判断）（胜（生存能力提升））【有效提高生存能力，适用性强】
- 大毛+B2护航艇（搭载奶瓶）（胜（奶量更高））【奶量比B3高，但舰载机生存是问题；在副队增援五天数情况下，可带01等短刀技为天书提供生存环境】

## 实战结果
当前大环境下，大毛从主要抗伤战巡转为副抗伤或辅助性战巡；蓝睫毛作为辅助性战巡表现突出，但需注意生存能力

## 结论思路
- 大毛在肉队中定位为抗伤和辅助，抗伤刚需附加装甲模块，提供150物抗和近6万血量，装甲系统调教加点建议拉满
- 当前大环境下，前排附加矛抗伤效果下降，大毛作用转为副抗伤或辅助性战巡
- 蓝睫毛核心模块提供全域拦截，拦截效果高，通常配合M1系统弱点定位使用
- 蓝睫毛缺少附加模块物抗，面对坦克自保能力弱，可通过中排分商提高生存
- M系统选择：M1单发反大能力不错，M2离子炮反大实战效果更高但设施惩罚严重
- B系统选择：B3提高自身判断，生存能力强，适用性广；B2护航艇奶量高但舰载机生存问题，在副队增援五天数情况下可带短刀技为天书提供生存环境

## 适用限制
- 大毛抗伤定位需附加装甲模块，否则无法有效抗伤
- 蓝睫毛辅助定位需核心模块，且面对坦克时需额外生存措施
- M2系统设施惩罚严重，需权衡反大效果与惩罚
- B2护航艇舰载机生存问题，需考虑增援天数等环境因素
