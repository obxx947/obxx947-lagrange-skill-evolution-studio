# A资料693

## 场景 / 对手
平民玩家CV3000航母使用，空战/护航/轰炸体系，正面作战

## 舰队例子
- CV3000普通版，5+6（5护航艇+6战机），含M1模块（超锁空优艇）和M3模块（弓箭手）（胜）【推荐配置，护航艇多，分工明确，适合护航版本】
- CV3000，8+3（8战机+3护航艇），含B1模块（防空导弹平台）（胜）【适合保VB生存，赖住空战，但需地面部队配合输出】
- CV3000，5+3+3（5护航艇+3战机+3护航艇），含M1和M3模块（胜）【5+6的变体，模块加点不同，弓箭手和肉盾分工】
- 太阳鲸，8+3，含C3模块（对空输出）（胜）【比CV3000强，有对舰和防空输出，但造价高】

## 实战结果
CV3000玩家对太阳鲸玩家，CV3000 8+3 vs 太阳鲸 8+3，CV3000胜（靠赖空战和地面输出），但太阳鲸在战斗力上更优；CV3000 5+6 vs 8+3，5+6更推荐，8+3单挑更强

## 结论思路
- CV3000白板有护航艇和战机，配比合理，适合平民
- 5+6配置推荐，护航艇多，分工明确，适合护航版本
- 8+3配置适合保VB生存，赖住空战，但需地面部队配合
- CV3000打空战吃力，不推荐主动突破，应赖住空战
- 加点优先M模块（护航艇），再B1模块（防空），2.0即可点满
- 前凸CV3000可玩，造价便宜，能开拦截，但需叠护甲

## 适用限制
- 适合平民玩家，不推荐越级到太阳鲸
- 5+6适合非solo玩家，8+3适合solo玩家
- 8+3需地面部队配合输出，否则效果差
- 不推荐CV3000玩家打空战，除非有地面反哺
- 前凸CV3000只推荐给CV3000，不推荐其他航母
