# A资料457

## 场景 / 对手
舰队配置对比，涉及十一加十三与十一加苍穹C一体系，正面作战

## 舰队例子
- 十一鱼（含星脉、坦克）+ 苍穹C一（含T八百）（胜）【T八百输出高于苍穹C二上的配置】
- 十一鱼（含星脉、坦克）+ 十三鱼（含VB）（胜）【VB输出与苍穹C一上的配置相差不大】
- 十一鱼（含星脉、坦克）+ 苍穹C一（含VB）（胜）【可作为十一加十三苍穹C二的平替】

## 实战结果
对比十一加十三与十一加苍穹C一，十一加苍穹C一在T八百和VB配置上表现接近，可替代苍穹C二

## 结论思路
- 十一加苍穹C一可作为十一加十三苍穹C二的平替
- T八百放在十一鱼上输出高于苍穹C二
- VB放在苍穹C一上与十三鱼上数据相差不大

## 适用限制
- 适用于十一鱼和苍穹C一配置的舰队
- 不适用于需要苍穹C二特定模块的场景
