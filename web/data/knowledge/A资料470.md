# A资料470

## 场景 / 对手
进阶版护航队搭配，针对2+2以上多航母玩家，盟战与单挑兼顾，正面作战

## 舰队例子
- 永恒苍穹（轰炸）+ 721（支援位空出缝合盟友航母）+ 13鱼护航 + 风暴 + 重卡 + 刺水母（超载）（胜）【护航输出不强，但可同时轰炸和护航冲锋】
- 5艘13鱼 + 3艘南十字 + 风暴 + 大帝，拉满高伤害飞机（胜）【八航母输出队，实战效果不错】
- 风暴 + 大帝 + 大剑 + 13鱼 + 南十字，支援加9完全体（胜）【大剑熔甲效果，大帝投射武器，伤害翻倍】
- 大盾旗舰 + 天枢 + 天权（m1模块）+ 护航艇（维修）+ 拦截矛 + 盘古阵营小船 + 玉衡c型号（胜）【盘古抗伤队，能扛能打能维修，天权物抗破千】

## 实战结果
轰炸加护航配置，盟战可同时开轰炸和护航冲锋；盘古抗伤队可单挑敌方护航队；多航母输出队实战效果不错

## 结论思路
- 多航母配置时，不要急着护航，可考虑轰炸加碰瓷或轰炸加护航
- 轰炸加护航指两套配置同时使用，盟战可开轰炸同时护航冲锋
- 护航队推荐13鱼，拉满飞机，搭配风暴重卡输出，补刺水母超载
- 进阶版可用南十字替代部分13鱼，形成八航母输出队
- 奢侈配置加风暴大帝大剑，支援加9完全体，大剑熔甲效果显著
- 抗伤队中规中矩，但盘古阵营抗伤队特殊，天枢维修量大，天权物抗破千

## 适用限制
- 适用于2+2以上多航母玩家
- 奢侈配置需要支援加9才能完全体
- 盘古抗伤队依赖天枢维修无人机，用完前有效
- 护航队输出不强，需配合轰炸或输出队
