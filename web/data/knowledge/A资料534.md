# A资料534

## 场景 / 对手
各类舰载机适合的机库选择，反轰炸环境，正面空战

## 舰队例子
- 沙龙 + 鱼C1模块（70%索敌，55%往复）（胜）【沙龙点满索敌4.8秒，需70%索敌机库，最适配鱼C1】
- 雷火A + 鱼C1模块（70%索敌）（胜）【雷火A点满索敌3.5秒，需70%索敌，不依赖往复，但鱼C1最优】
- 林鸮 + 鱼C1模块（70%索敌）（胜）【林鸮索敌长，需70%索敌，优先级低于沙龙和雷火】
- 雷火B + 13鱼M2模块（55%往复，2格伤害）（胜）【雷火B点满索敌2秒，不选往复，选索敌，适合M2】
- 小米 + 13鱼M2模块（2格伤害）（胜）【小米索敌短，不依赖高索敌，适合M2，伤害加成高】
- 050A + 13鱼M2模块（命中加成）（胜）【050A命中低，更吃M2的命中加成】
- Va + 13鱼M2模块（胜）【Va功能性飞机，结构伤害低，优先级低于050和Vb】
- 海氏 + 狩猎机库（70%索敌）（胜）【海氏索敌18秒，需70%索敌，狩猎最佳，避免防空】
- 海氏 + 南十字A1模块（超斩减持续）（胜）【适用于高氪内斗，战斗时间短，目标存活久】
- 星脉 + 11鱼M1模块（70%索敌）（胜）【加点动力2索敌+主系统1索敌，达90%索敌】
- 索姆河 + 11鱼M1模块（胜）【固定最佳机库】
- 800 + 苍穹C2模块（70%索敌）（胜）【地推时用，不需额外加索敌】
- 800 + 无索敌机库（胜）【需点2格索敌，舍弃伤害，保留命中】
- 特种瑶 + 南十字A2模块（闪避策略）（胜）【生存高，适合挡刀】
- 天机B/A + 南十字A2模块（胜）【万血挡刀艇，增强艇线硬度】
- 坦普尔B + 南十字A2模块（胜）【触发稳定，万血，为海尔波波挡刀】

## 实战结果
空优机：沙龙、雷火A、林鸮需70%索敌机库，鱼C1最优；雷火B、小米索敌短，适合13鱼M2。输出机：050、Va、Vb最优鱼M2，优先级050>Vb>Va。海氏需70%索敌，狩猎最佳，南十字A1仅限高氪内斗。护航艇：星脉、索姆河固定11鱼M1；800用苍穹C2或无索敌机库需点索敌；挡刀艇如特种瑶、天机B/A、坦普尔B放南十字A2。

## 结论思路
- 空优机机库选择主要根据索敌，索敌需压制在2秒以内
- 沙龙最适配鱼C1，因吃往复；雷火A不依赖往复但鱼C1最优
- 林鸮需70%索敌，但优先级低于沙龙和雷火
- 雷火B和小米索敌短，适合13鱼M2，伤害加成高
- 输出机最优鱼M2，050优先级高于Va，因命中低
- 海氏需70%索敌，狩猎最佳，南十字A1仅限高氪内斗
- 护航艇分有/无70%索敌机库，星脉、索姆河固定11鱼M1
- 800用苍穹C2或无索敌机库需点索敌，保留命中
- 挡刀艇放南十字A2，增强生存，奶艇浪费加成

## 适用限制
- 适用于反轰炸环境，正面空战
- 鱼C1和13鱼M2数量有限，需优先分配给高优先级飞机
- 海氏南十字A1仅适用于高氪内斗，战斗时间短
- 800无索敌机库需点索敌，舍弃伤害
- 坦普尔A在对面无空军时不触发，坦普尔B更稳定
