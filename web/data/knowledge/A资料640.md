# A资料640

## 场景 / 对手
正面抗伤，应对直射火力与投射武器

## 舰队例子
- 开阳（小船，高血量高闪避）（胜）【限制直射火力，作为前排核心】
- 姚光（双型号，基础型+稳定比例型）（胜）【提供能量抗性，增强开阳生存】
- 均衡C型号（少量）（胜）【提供续航，但不宜过多，避免浪费人口】
- 风暴C三以D二（胜）【中后排吸引投射火力，应对投射与能量武器，输出不错且造价亲民】
- 大盾坐骑舰（1艘）（胜）【补充人口，增强整体抗性】
- 天书航母（5艘，需C二或A三模块）（胜）【支援后排，提供输出或辅助】

## 实战结果
盘古抗伤队整体配置，未提及具体对战记录，但强调能应对绝大部分战局

## 结论思路
- 开阳作为前排核心，利用高血量闪避限制直射火力
- 姚光提供能量抗性，增强开阳生存能力
- 均衡C型号提供续航，但需控制数量避免浪费
- 风暴C三以D二吸引投射火力，减轻前排压力
- 大盾坐骑舰和天书航母补充人口和支援

## 适用限制
- 天书航母需至少C二或A三模块才能单独上场
- 均衡C型号不宜过多，小船易战损，维修不及时
- 适用于应对直射和投射武器，但需注意小船生存
