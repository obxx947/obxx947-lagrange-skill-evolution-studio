# A资料303

## 结论思路
- 列维九号重型鱼雷艇搭载重卡鱼雷的舰载机版本，继承高单发反舰鱼雷特性。
- 武器系统为三发实弹鱼雷，单发伤害1200点，满调教后1500点，足以击穿任何舰船装甲。
- 战斗序列优先反大，第一目标是航母，可对航母造成威胁，适合进主队进行超斩。
- 锁定时间长达15秒，且加点中只有一项索敌，刚需母舰机库加70%锁定，否则输出大打折扣。
- 装甲和动力系统为护航艇标配，策略和加点可提高生存，但生存能力在护航艇中较差，带进主队无需考虑。
- 加点优先武器系统和动力系统两个频率项，满配需114蓝点，比较吃蓝点。
- 武器系统加点方案固定，直接抄伤害最高；动力系统频率项优先点，对伤害加成高。

## 适用限制
- 需要母舰机库加70%锁定，否则输出不足。
- 生存能力较差，不适合单独作战，需依赖主队保护。
- 蓝点需求高，需114点，点数不足时优先动力频率。
