# A资料367

## 场景 / 对手
航母体系对比，涉及正面/轰炸/碰瓷队，环境为盟战/散人/重天盟

## 舰队例子
- 十三鱼（M2A1B1C1），载机位13个飞机，无护航艇，带维修模块，配防空飞机（胜/评价：适合碰瓷队，生存强，防空强）【盟战不带VB，但可下防空换VB050】
- 十一加十三鱼（11+13鱼），载机位含飞机和护航艇，带苍穹轰炸（胜/评价：航母伤害最高，闷人和打神强）【只能进地推队，怕轰炸多】

## 实战结果
十一加十三鱼与十三鱼对比，十一加十三鱼伤害高但地推队易被轰炸克制，十三鱼输出低但生存强，适合碰瓷队；无具体胜负记录

## 结论思路
- 十一加十三鱼定位为高伤害航母，适合散人或重天盟，但只能进地推队，打盟战轰炸多时可能零作用
- 十三鱼全飞机，生存能力强，适合碰瓷队，维修模块能回血，发挥防空优势
- 十三鱼带防空飞机，盟战不带VB，但可备用换VB050
- 十三鱼伤害低，闷人可能打不过；防空飞机可能打无效伤害（优先打战机）
- 十三鱼适合有苍穹轰炸或大猫的玩家，必须做碰瓷队

## 适用限制
- 十一加十三鱼仅适用于地推队，不适合轰炸多的盟战
- 十三鱼不适合高输出需求场景，闷人可能劣势
- 防空飞机可能被挡刀艇干扰，需注意配置
- 十三鱼必须配合碰瓷队和维修模块
