# A资料239

## 场景 / 对手
配船教学，主队2.0CV带B4模块，猎兵未点超斩，飞机坦克海狮未带满，小船带斗牛，次水母点超斩，于海可替换

## 舰队例子
- 主队2.0CV带B4模块（胜）【B4模块在挺不够时是最佳选择，V2虽强但需更多资源】
- 猎兵未点超斩策略（负）【点超斩可优先打掉超主力，避免大盾被击破】
- 飞机坦克和海狮未带满，海狮可放狩猎身上（负）【未带满导致输出不足，影响战局】
- 小船带斗牛（胜）【斗牛没问题，但气神心带枪防不如带输出巡洋】
- 次水母带超斩（胜）【超斩策略有效，但前面猎兵未点导致不一致】
- 于海可不用带，巡洋输出更高（胜）【替换于海可提升整体输出】

## 实战结果
分析战报，主队带B4模块表现良好，但猎兵未点超斩导致大盾被击破，飞机坦克海狮未带满影响输出，小船斗牛可用但巡洋更优，次水母超斩有效，于海可替换为巡洋提升输出

## 结论思路
- B4模块在资源不足时是最佳选择，V2虽强但需更多资源
- 猎兵应点超斩策略，可优先打掉超主力，避免关键舰船被击破
- 飞机坦克和海狮应带满，海狮可放狩猎身上以增强输出
- 小船带斗牛可行，但气神心带枪防不如带输出巡洋，泡泡龙艾尔游骑兵更优
- 次水母点超斩有效，但需保持策略一致性
- 于海可替换为巡洋，提升整体输出

## 适用限制
- 适用于资源有限时选择B4模块
- 适用于需要优先打击超主力的战斗场景
- 适用于输出不足时优化舰队配置
- 适用于巡洋输出优于小船的场合
- 适用于策略点分配需一致性的情况
- 适用于追求高输出的配船思路
