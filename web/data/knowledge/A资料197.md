# A资料197

## 场景 / 对手
巡洋舰为主的副队配件讲解

## 舰队例子
- 奇美拉级防护型（巡洋舰，高血量、护甲、维修加成）（胜）【核心肉盾】
- 御衡级综合型（优先维修巡洋舰）（胜）【补充奶量】
- 零六六支援型（维修）（胜）【继续补充奶量】
- 光锥级防空型（3个）（胜）【增加拦截率，补防空】
- 瑶光级通用型（套盾）（胜）【提供40%能量抗性】
- 卡利莱恩级特种型（闪避）（胜）【大量闪避限制直射武器】

## 结论思路
- 以奇美拉级防护型为核心肉盾，提供高血量、护甲和维修加成
- 搭配御衡级综合型和零六六支援型增强维修能力，提升整体肉度
- 加入光锥级防空型增加拦截率，补足防空能力
- 使用瑶光级通用型提供护盾，增加能量抗性
- 卡利莱恩级特种型提供闪避，限制直射武器

## 适用限制
- 适用于中期巡洋舰为主的副队配置
- 需要多种舰船模块配合，可能对资源要求较高
