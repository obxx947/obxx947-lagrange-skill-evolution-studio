# A资料518 · 舰船系统被破坏效果

## 结论
- 只有蓝图中标记M字母的系统才是主系统，机库同理，游戏内只有主系统会被破坏
- 主武器系统被破坏后无法攻击，类似被维塔斯A021-重型攻击机（原文为"维斯"，疑似语音识别错误）大招控制
- 主机库系统被破坏后舰载机无法起降，往复式舰载机回库后无法出击
- 独立式舰载机在主机库被破坏后不再受到机库增幅
- 武器和机库系统战斗中可自维修两次，第三次被破坏后彻底无法修复，战斗结束后复原
- 指挥系统被破坏后所有策略无法使用，只能用常规手段输出
- 指挥系统可自维修三次，第三次维修后无法被再次锁定，指挥室变为移动指挥
- 动力系统被破坏后舰船失去闪避能力，且不能紧急避险脱离战斗
- 动力系统被破坏后若被击沉就是真的没了，无法逃跑
- 动力系统无法在战斗中维修，只能在战斗结束后维修
- 动力系统被破坏是现在还有人带维塔斯A021-重型攻击机的原因

## 数值与数据
- 武器和机库系统可自维修2次
- 指挥系统可自维修3次
- 动力系统战斗中维修次数为0
