# A资料518

## 场景 / 对手
舰船系统被破坏机制讲解，无具体战斗对手/体系/环境

## 结论思路
- 主武器系统被破坏后无法攻击，类似维斯大招控制效果；主机库系统被破坏后舰载机无法起降，独立式舰载机失去机库增幅
- 武器和机库系统战斗中可自维修两次，第三次被破坏后彻底无法修复，战斗结束后复原
- 指挥系统被破坏后所有策略无法使用，只能常规输出；可自维修三次，第三次维修后无法被再次锁定
- 动力系统被破坏后失去闪避能力且无法紧急避险脱离战斗，被击沉则彻底损失；动力系统无法战斗中维修，只能战后维修，因此带va有价值

## 适用限制
- 仅适用于主系统（蓝图标记M字母）被破坏的情况
- 指挥系统第三次维修后无法被锁定，但具体机制可能受环境或舰船类型影响
- 动力系统无法战斗中维修，需注意携带维修模块或避免超主力被留下
