# A资料644

## 场景 / 对手
正面抗伤，针对混沌、艾奥、大帝、重卡等威胁，环境为常规舰队战

## 舰队例子
- 天权（C3装甲模块，其余灵活）（核心抗伤单位）【基础护甲500多，M模块提升数值，掩护炮艇】
- 大矛（模块灵活）x2（分担伤害）【前排共8个战巡，提高容错率】
- 风暴C2 x2（提供能量闪避）【针对混沌与艾奥】
- 光防（中排或前排）（补齐拦截能力）【中排减少大帝威胁，前排限制重卡火力；拦截需求不高可换同人口航母】
- 大盾（旗舰）（旗舰）【剩余人口加入】
- 天枢航母（C2或A3模块）x5，搭载干扰机和海尔兄弟（支援）【必须C2或A3才能单独使用】

## 结论思路
- 天权为核心抗伤单位，必须有C3装甲模块才能上场
- 前排加入两个大矛分担伤害，提高容错率
- 中排风暴C2提供能量闪避，针对特定舰船
- 光防灵活调整位置，根据拦截需求选择
- 支援用天枢航母搭载干扰机和海尔兄弟

## 适用限制
- 天权必须装备C3装甲模块
- 天枢航母必须C2或A3模块才能单独使用
- 光防位置需根据敌方威胁调整
- 拦截需求不高时可替换光防为同人口航母
