# A资料710

## 场景 / 对手
体验服测试，对手为顶氪玩家，使用零六六+四盾+天书组合，正面战斗

## 舰队例子
- 御痕级C（维修）+ 八三零（伪装小船）（负）【奶量高但只能奶小船，伪装成小船让御痕奶，但缺乏反小武器时压榨大船生存，solo队中不佳】
- 零六六 + 四盾（全点前途）+ 天书（满改高巅峰）（负）【顶氪玩家配置，但5分钟被击败，输出不足，后续只剩天书更快被灭】

## 实战结果
我方主队670万+副队230万，5分钟内总输出900万，击败零六六组合；对方零六六玩家5分钟撤退，后续天书被快速消灭

## 结论思路
- 巡洋调整中，游骑兵在输出队中优先级低，三加四以上玩家不依赖其强化
- 游骑兵设计不合理，直射和投射各半，不如重卡或泡泡龙
- 战巡和航母（除未央）都有用，雷火M2加强优于M3，但M3打靶输出最高，车雷可能保留
- 南十字加强显著，基础伤害翻倍，新增策略可无视50%能量护盾，配合维A或M2可有效破前排
- 南十字适合顶氪玩家，普通玩家仍以纯直队伍为主
- 御痕+八三零组合在solo队中不实用，缺乏反小武器时压榨大船生存

## 适用限制
- 游骑兵不适合主队输出，仅适合特定副队
- 御痕+八三零组合需有反小武器配合，否则不推荐
- 零六六在顶氪队伍中效果不佳，可能因配置或战术问题
- 南十字加强适合顶氪玩家，普通玩家需谨慎使用
