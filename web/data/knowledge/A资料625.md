# A资料625

## 场景 / 对手
超主力控制作业，控制难度10，对手为超主力舰队（对舰火力/防空火力/混合火力），正面控制，环境为城市控制点

## 舰队例子
- 对舰火力：登陆舰（10诺马+10云海）+驱逐舰（若干），具体配置见群（胜）【基本无损，简单】
- 防空火力：同对舰配置，但舰载机（如海尔波普、凌霄）会被敌方800打死（胜）【微损，注意顺序】
- 混合火力：单队配置，掉4个特卡+1个登陆舰（最好情况），平时掉2-3个特卡和1-5个登陆舰（胜）【最难，M011导弹有概率打，登陆舰会死，但可回家秒下】
- 双队混合：主队配置不变，副队加1条盾+8个066（或任意战群+066）+支援点+登陆点（胜）【百分百无损，只掉1个登陆舰】

## 实战结果
玩家单队控制超主力，对舰火力无损，防空微损，混合火力最好掉4特卡+1登陆舰，平时掉2-3特卡和1-5登陆舰；双队混合可无损。关键得失：C V优于鱼，因时效性和拦截能力；登陆舰在后排可被C V拦截保护；050爆炸伤害与血量相关，C V血少更优

## 结论思路
- 控制前用护卫舰+登陆舰探明火力类型，优先控对舰（无损），再控混合（掉登陆舰和特卡），最后控防空（海尔波普可能死）
- 控制时95%和70%会刷怪，需在线，否则登陆舰死光
- C V优于鱼，因出得快、便宜、有拦截能力保护登陆舰，且血少受050爆炸伤害低
- C V加点优先维修（物理看星、受维修），不点结构，因血多炸得痛
- 无海尔波普时可用古神星替代，配置需调整
- 双队控混合可无损，副队上盾+066+登陆点，主队不变

## 适用限制
- 适用于控制难度10的超主力，需先探明类型
- 控制时需在线，否则登陆舰损失
- C V配置需点维修，不点结构
- 混合火力有概率被M011导弹打，需注意
- 无海尔波普时需换古神星
- 双队控混合需额外资源（盾+066）
