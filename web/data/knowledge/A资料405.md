# A资料405

## 场景 / 对手
舰船攻击手段基础教学

## 舰队例子
- 大毛（直射，火炮/能量炮）（胜）【需按站位顺序攻击】
- 泡泡龙IO（直射，火炮/能量炮）（胜）【需按站位顺序攻击】
- 大剑（直射，策略影响）（胜）【可无视站位，优先打击百分比血量最低的船】
- 风暴M2（投射，导弹/鱼雷）（胜）【唯一不可拦截投射武器】
- 大地重卡（投射，导弹/鱼雷）（胜）【可被拦截，任意打击所有站位】
- 次水母登陆舰（无人机）（胜）【母舰存活即可持续发挥作用】
- 奶船（无人机/维修）（胜）【母舰存活即可持续发挥作用】

## 结论思路
- 舰船攻击方式分为直射、投射和无人机三种
- 直射武器需按站位顺序攻击，但大剑可无视站位
- 投射武器可被拦截，但风暴M2不可拦截
- 无人机机制类似不可拦截的投射武器，依赖母舰存活

## 适用限制
- 直射武器受站位限制，需注意攻击顺序
- 投射武器可能被拦截，需考虑拦截风险
- 无人机依赖母舰存活，母舰被击毁则失效
