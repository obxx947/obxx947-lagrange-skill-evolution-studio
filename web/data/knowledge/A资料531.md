# A资料531

## 场景 / 对手
老版本空战体系基础，涉及战机与护航艇分类、往复式与独立式运作方式

- 维b、零五零（轰炸机）（未提及）【后缀带轰炸机，属于轰炸机类型】
- 小米（攻击机）（未提及）【虽防空水平高，但分类为攻击机】

- 沙龙（拦截机）（未提及）【唯一后缀为拦截机的战机，可视为战斗机】

## 实战结果
未提及具体战斗，但解释了往复式空军单位存活率高于独立式，战机比护航艇存活率高，因战机停留时间短且能受维修模块影响

## 结论思路
- 空战是拉格朗日中最复杂体系，是轰炸和反轰炸等流派的基础，理解空战有助于提升整体游戏理解
- 战机分类依据后缀，如战斗机、轰炸机、攻击机、拦截机，但小米和凌霄虽防空强仍属攻击机，沙龙可视为战斗机，海氏是特殊战斗机
- 护航艇仅分两类：不越半场（如海尔波普、坦普尔b）和越半场（其他），分类简单
- 往复式空军运作循环：锁定、去程、攻击、回程、冷却，去回程和冷却时无敌，其他时间可被防空锁定
- 独立式空军运作：机库内锁定后瞬移攻击，不回仓，无无敌时间，无脱锁策略则被锁定至死，且不受维修模块影响
- 往复式空军因无敌时间和停留时间短，存活率更高，独立式如摔炮

## 适用限制
- 适用于老版本空战体系，当前版本以护航和轰炸为主，空战接触较少
- 往复式空军无敌时间仅限去回程和冷却，攻击阶段仍会被锁定
- 独立式空军无脱锁策略时会被持续攻击至死，且无法被维修模块修复
- 护航艇分类简单，但需注意是否越半场以判断受击风险
