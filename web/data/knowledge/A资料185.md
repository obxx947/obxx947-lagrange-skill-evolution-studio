# A资料185

## 场景 / 对手
平民玩家航母选择与培养

## 舰队例子
- CV（白板）+ 5战机 + 3炮艇 + B4模块 + 50蓝点（胜）【白板功能最强，活动赠送B4和50蓝点后小毕业，可作主力】
- CV + M3大型机库 + B2护航艇机库（胜）【搭配更灵活，但强度上限不够】
- 太阳经 + C1模块 + 90蓝点（胜）【培养难度最高，但替代CV的核心模块，定向难度高】
- 蓝十字 + C1模块 + A1机库加成（平）【吃舰队配置，直射输出队可用，否则与CV类似】
- 苍穹 + C2模块（轰炸核心）（负）【炮艇轰炸三倍伤害，但需同盟配合，单一轰炸弱】
- 苍穹 + C1模块（胜）【机库加成高于CB，可替代CV，定向不易歪】
- 天书 + CE模块（胜）【舰载机伤害略高，主要扛伤定位，培养价值高】

## 实战结果
平民玩家从CV起步，利用活动资源过渡，根据财力选择太阳经、苍穹或天书，蓝十字不优先；200蓝点后可培养第二航母

## 结论思路
- 优先培养蓝点，核心模块才拿，非核心模块换蓝点
- 至少90蓝点后才考虑其他模块
- CV成型简单但上限低，活动后转移重心
- 太阳经需C1模块，定向难度高，适合高财力
- 蓝十字需C1和直射队，否则与CV类似
- 苍穹C2用于轰炸需同盟配合，C1可替代CV
- 天书配CE模块，扛伤定位，培养价值高
- 200蓝点后可培养第二航母，按思路选择

## 适用限制
- 活动50蓝点仅限CB使用
- 太阳经定向易歪，需财力支持
- 苍穹C2轰炸需同盟数量配合
- 蓝十字不适合作为第一航母
- 航母培养需模块与点数，门槛高
