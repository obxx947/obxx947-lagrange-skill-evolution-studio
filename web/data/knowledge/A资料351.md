# A资料351 · 天枪应放副队当挡刀

> 场景：护航艇副队/主队定位对比

## 结论
- 天枪对舰B、支援S、无防空，官方定位偏资源型引导船
- 天枪引导优先锁结构值最高的船，带航母时容易引导绝育船打航母
- 天枪面板低且策略是集火，不适合放主队当输出
- 绝育船要打散才能出伤，天枪集中策略与出伤逻辑冲突
- 天枪会跟维塔斯A021-重型攻击机（原文为"维A"，疑似简称）抢动力系统绝育伤害
- 动力系统不能反复爆，天枪抢伤害会压低维A绝育收益
- 天枪适合放副队，副队结算伤害不打折，主队结算约打七折
- 带往复作战标签的护航艇都适合放副队，如天枪、S-列维9号-重型鱼雷艇（原文为"列维九号"，疑似简称）
- 天枪在副队抢到伤害是好事，还能挡刀
- 天枪是盘古公司船，基础护甲5，比普通护航艇更硬
- 天枪输出能力高于其他挡刀艇，能自己打出系统伤害
- 天枪放副队可把主队绝育伤害结算到副队，变相提高维A动力系统伤害

## 配队与模块
- 天枪加点优先锁敌和载机超锁，让目标更快锁定自己
- 天枪加点优先护甲，提高坦度
- 天枪加点优先暴击，暴击够高才能更早抢到结算
- 暴击打底后再点策略强化，没机会结算时强化无用
- 天枪不点锁敌信息，否则无法打战巡
- 天枪武器序列散，航母战巡要一起打
- 天枪点武器命中，因CV-T800型-脉冲炮艇（原文为"T800"，疑似简称）可能最多
- 天枪可点自刀武器，慢速武器在空军中没有

## 数值与数据
- 天枪对接面板2100，与输出挂钩的加点很少
- 粉丝战报6分32秒：坦克50万、T800 41万、星脉64万、天枪38万
- 天枪38万伤害中系统伤害加起来15万，低于T800
- 维A绝育39万，动力系统伤害加起来不到10万
- 天枪绝育爆5万，打毛打了16万，自己砸出12万伤害
- 天枪暴击加点41和27二选一
