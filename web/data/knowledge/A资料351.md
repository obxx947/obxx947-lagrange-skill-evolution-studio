# A资料351

## 场景 / 对手
天枪护航艇定位分析，涉及主队/副队、绝育船、挡刀、战报对比

## 舰队例子
- 天枪（主队输出）（负）【战报中伤害38万，刨去系统15万，低于T800的41万，输出不足】
- 天枪+维A（主队）（负）【维A绝育伤害39万，但动力系统伤害不足10万，天枪抢伤害导致维A输出降低】
- 天枪（副队挡刀）（胜）【身板硬、往复作战、可结算伤害，绝育爆5万但实际打毛16万，输出和挡刀兼备】

## 实战结果
粉丝战报：天枪在主队输出伤害38万，低于T800的41万，表现不佳；副队天枪战报显示其能有效抢伤害和挡刀，优于主队表现

## 结论思路
- 天枪定位是资源型引导船，但索敌优先结构值最高，不适合主队输出
- 天枪应放副队，利用往复作战和挡刀属性，提高生存和结算效率
- 副队天枪可抢主队绝育伤害，变相提高维A等船的绝育效果
- 加点优先索敌、护甲、暴击，再点策略强化，不点锁敌（避免打战巡）
- 盘古公司护航艇基础护甲5，天枪坦度优于普通护航艇

## 适用限制
- 适合副队挡刀和抢伤害，不适合主队输出
- 需搭配绝育船（如维A）发挥结算优势
- 加点需平衡坦度和暴击，避免过度强化策略
- 不适用于需要快速击毁航母或战巡的场景
