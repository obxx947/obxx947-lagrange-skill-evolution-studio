# A资料398

## 场景 / 对手
白板天书配对，针对电焊队、投射队等对手，正面作战

## 舰队例子
- 大毛（前排抗伤）（胜）【能量抗性弱，易被电焊队焊死】
- 开阳（闪避小船）（胜）【克制电焊队】
- 瑶光（能量护盾）（胜）【给前排小船套护盾，数量与开阳二比一】
- 光防（反导）（胜）【防投射队，有反导盾可替换】
- 零六六奶（治疗）（胜）【补充人口】
- 玉衡C（输出）（胜）【有条件可加】
- 风暴C2（能量闪避）（胜）【给大毛加能量闪避】
- 天书（增援）（胜）【增援五天书】

## 实战结果
白板天书配对，核心是盾策略减伤30%，大毛前排抗伤，搭配开阳瑶光克制电焊队，光防防投射，增援五天书，整体胜率提升

## 结论思路
- 核心是盾策略，减伤30%增加副队生存
- 大毛前排抗伤，但能量抗性弱，需搭配闪避小船
- 开阳和瑶光数量二比一，瑶光套护盾增强生存
- 加光防防投射队，有反导盾可替换
- 剩余人口放零六六奶或玉衡C
- 有条件加风暴C2给大毛能量闪避
- 增援五天书

## 适用限制
- 适用于白板天书配对
- 大毛能量抗性弱，需搭配闪避小船
- 开阳瑶光数量需二比一
- 有反导盾可替换光防
- 需根据对手调整（电焊队、投射队）
