# A资料697

## 场景 / 对手
战巡分类与配船思路，面向不同阶段玩家

## 舰队例子
- 盾（白板/拦截/装甲）+ 矛（中排）+ 其他输出战巡（胜）【盾提供buff和分伤，矛可前可中，配合形成双防御战巡，提高生存】
- 盾 + 剑（防御）（负）【防御线不足，无法达到14分伤，剑更适合输出】
- 盾 + 天权（前排）（负）【位置冲突，天权前排易被集火，不适合作为第二防御】

## 实战结果
玩家强调战巡分类基于阶段而非T0/T1，防御战巡选择盾、矛、天权等，双防御战巡提升分伤，实战中高氪玩家可承受更多伤害

## 结论思路
- 战巡是游戏核心，融合输出、防御、防空等，分类按护航人口分输出和防御
- 防御战巡基础是盾，提供buff和分伤，是护航队轴心
- 双防御战巡优于单防御，盾+矛组合可达到10分伤，盾+剑仅9分伤，无法突破14分伤
- 第三防御战巡选天权，配合盾和矛形成14分伤，适合毕业玩家
- 战巡选择基于账号阶段和模块，白板船不一定是T0

## 适用限制
- 适用于有足够战巡模块和点数的玩家
- 低氪或白板玩家不适合追求高级防御战巡
- 天权作为第三防御需前排填充，适合高刻度玩家
- 盾+剑组合不推荐，防御线不足
