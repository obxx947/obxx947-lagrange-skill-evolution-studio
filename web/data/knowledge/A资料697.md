# A资料697 · 战巡分阶段与配队思路

> 场景：战巡体系/护航队/团战/氪佬内战

## 结论
- 舰船不应按T0/T1/T2排行，应按玩家阶段、账号模块与使用场景适配。
- 白板太阳鲸-武装战略航空母舰（原文为"太阳鲸"，疑似简称）、白板永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）未必算T0；氪到阶段且有模块才玩太阳鲸，不选CV3000级-快速航空母舰（原文为"CV3000"，疑似简称）。
- 舰船分析分四板块：航母；战巡；驱逐/护卫/巡洋；战机/护航艇；战巡是重中之重。
- 战巡是融合体，涵盖输出、防空、对舰、抗伤、回血，是能载机不易死的航母，也是巡洋/驱逐/护卫加强版，定位中间档。
- 战巡按护航人口标准分为输出与防御两大类。
- ST59级-防御战列巡洋舰（原文为"59"，疑似简称）不是基础必养防御船；其他战巡毕业且多余点数才考虑，应优先练更好战巡，白板也可。
- 普鲁图斯之盾级-防护战列巡洋舰（原文为"盾"，疑似简称）是护航基础/副队轴心，有盾后才组其他护航队。
- 白板普鲁图斯之盾级纯开策略，作为buff存在。
- 拦截盾比白板盾多队伍其他船功能，继承性更高，可取代光锥部分功能。
- 装甲盾是拦截盾升级，满级盾自保能力更强；若队伍带CAS066级巡洋舰，不如不带。
- 争议模块只向下保护，不向上保护；战巡开拦截仍保护巡洋等更弱船；驱逐/护卫/巡洋同属主力舰/小船，只能相互保护。
- 双防御战巡比单防御更强，因为分摊；对手高氪带两种超主力时可怕。
- 双防御战巡第二位置排除天权级-重型防御战列巡洋舰（原文为"天权"，疑似简称）：前排与盾中排冲突，低刻度不如前排小船。
- 双防御战巡第二位置排除安东塔斯持剑者级-指挥舰（原文为"剑"，疑似简称）：盾6条+剑3条=9条，过不了14分摊门槛；剑更推荐输出。
- 双防御战巡第二位置选乌拉诺斯之矛（原文为"矛"，疑似简称）：可前可中可攻防，与盾契合。
- 玩盾时乌拉诺斯之矛放中排与盾同排分摊；分伤是队伍不死船的关键。
- 第三条扛伤战巡选天权级-重型防御战列巡洋舰，不选安东塔斯持剑者级-指挥舰。
- 第三条扛伤意味着至少毕业5条战巡，并对应3台输出战巡，属毕业玩家。
- 毕业阶段主队输出人口不足，航母载机位固定强度有限，剑进主队反而挤占输出位。
- 到该阶段天权被前排武器打可接受；防御队有航母、天枢级-支援航空母舰（原文为"天书"，疑似语音识别错误）等中排人口承接。
- 有天权时乌拉诺斯之矛放前排，与天权做14分摊；矛前排优于中排，因前排船可后退保命。
- 天权与矛都能狂暴，需被揍/受伤才能输出、后退转火；低氪面对该队不用怕死，高氪紫武前后排区别不大。
- 输出战巡也不分T0/T1/T2，按适合人群分为新君士坦丁大帝级-综合战列巡洋舰（原文为"大地"，疑似语音识别错误）、永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）、安东塔斯持剑者级-指挥舰、雷火之星-综合武库舰（原文为"雷、火"，疑似简称）等。
- 新君士坦丁大帝级是新手福音/入门必选，适合无拦截、无高护甲、对手死磕且希望队伍残血的阶段。
- 新君士坦丁大帝级靠自带A1输出，点满A1并升约50级即可达4.0大帝70%-80%输出，其他模块可不带。
- 从新君士坦丁大帝级切换到永恒风暴级，不是叠加；当对方全大船、高护甲、高拦截且会跑时切换。
- 永恒风暴级是保底输出船，伤害与时间挂钩，不随阵容降低；未见能克制其输出的船。
- 永恒风暴级打击面广，M2为反大能量武器且不能被拦截；团战多数情况强于新君士坦丁大帝级，但部分场景大帝更优。
- 风暴进阶需洗点，不是大帝加分包；第三阶段输出选安东塔斯持剑者级，其为风暴升级版。
- 白板安东塔斯持剑者级不能玩；A2是核心且为唯一投射武器，A1/A3含直射板块。
- A2可被拦截，但A2引导的直射武器不被拦截，称“阎王点名”，点到必死。
- 安东塔斯持剑者级A2优先攻击战巡/航母/巡洋中血量最少船；对方有巡洋时约一分钟掉一台巡洋。
- 雷火之星-综合武库舰适用氪佬内战；M3打前排，但多数队伍前排为小船，适用性不如剑，不能适配任意阵容。
- 氪佬内战哪方有雷火之星哪方赢；氪佬队伍前排带小船会输。
- 防御战巡需形成体系，线性升级；不能因某船排T0就重金刻出直接玩。
- 战巡是航母缩影、驱逐/护卫/巡洋放大版，处于绝对中间力量。

## 配队与模块
- 防御核心配置：普鲁图斯之盾级-防护战列巡洋舰 + 乌拉诺斯之矛；双防御战巡。
- 玩普鲁图斯之盾级时，乌拉诺斯之矛放中排同排分摊。
- 第三条扛伤战巡上强度时，天权级-重型防御战列巡洋舰 + 乌拉诺斯之矛放前排做14分摊。
- 双防御第二位置选乌拉诺斯之矛；不选天权级，不选安东塔斯持剑者级-指挥舰。
- 若坚持带CAS066级巡洋舰，不如直接不带；可另上光锥等补充。
- 中排人口可用天枢级-支援航空母舰等承接。
- 输出入门：新君士坦丁大帝级-综合战列巡洋舰只点满A1，其他模块可不带。
- 输出进阶：永恒风暴级-攻击战列巡洋舰用M2反大能量武器；从新君士坦丁大帝级切换需洗点。
- 第三阶段输出：安东塔斯持剑者级-指挥舰A2核心，A1/A3含直射板块；A2引导直射武器不可拦截。
- 雷火之星-综合武库舰用于氪佬内战，M3打前排；普通阵容加不进去。
- 太阳鲸-武装战略航空母舰与CV3000级-快速航空母舰二选一：有模块氪度选太阳鲸，不选CV3000。

## 数值与数据
- 普鲁图斯之盾级-防护战列巡洋舰防御线6条；安东塔斯持剑者级-指挥舰防御线3条；合计9条，过不了14分摊门槛。
- 乌拉诺斯之矛服役限制6条；6矛+4盾=10分摊打底；敌方打三百万伤害时队伍可不死船。
- 雷火之星-综合武库舰、安东塔斯持剑者级-指挥舰服役限制3条；占105人口；普通战巡200人口起步；队伍约420人口。
- 新君士坦丁大帝级-综合战列巡洋舰A1点满需20点战巡点；升约50级后A1毕业，达4.0大帝70%-80%输出。
- 新君士坦丁大帝级在不适场景约一分钟伤害2万。
- 永恒风暴级-攻击战列巡洋舰平均一分钟约3-4万伤害；安东塔斯持剑者级-指挥舰也约一分钟3-4万保底伤害。
- 安东塔斯持剑者级A2对方有巡洋时效率约一分钟10万；三台剑约一分钟打掉一台巡洋，约12万血。
- 天权级-重型防御战列巡洋舰+乌拉诺斯之矛前排做14分摊；百万伤害分摊后约25万。
- 面对毕业防御队时，99.99%队伍前排不会出现大量战巡，多为小船。
