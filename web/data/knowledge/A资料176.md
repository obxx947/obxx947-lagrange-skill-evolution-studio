# A资料176

## 场景 / 对手
护航艇坦克的加点与搭配，涉及太阳金载机、鱼级机库对比

## 舰队例子
- 坦克（主武器满点、动力系统满点、策略满点）+ 太阳金载机（胜）【太阳金维护系统提供高额冷却加成，弥补坦克7秒冷却的短板】
- 坦克（同上）+ 鱼M1机库（胜）【伤害约为CV机库的两倍，B1加成对冷却提升显著】
- 坦克（同上）+ CV M1机库（负）【伤害较低，CV加成频率不如鱼级】
- 三条11鱼 + 两条13鱼（胜）【配对示例，用于搭载坦克】

## 实战结果
对比鱼M1和CV M1机库搭载坦克，鱼级伤害约为CV两倍，鱼级胜出；关键得失在于冷却加成对坦克的重要性

## 结论思路
- 坦克是现版本最强护航艇，主武器重型火炮系统不受拦截削弱
- 加点优先主武器上下两排、动力系统和策略
- 搭配太阳金载机，利用维护系统冷却加成大幅提升输出
- 坦克主武器优先反大，单发伤害800+，优于星脉和T800
- 鱼级机库的冷却加成比CV的伤害加成更适合坦克

## 适用限制
- 需要太阳金载机才能发挥最大效果
- 坦克冷却时间长，依赖冷却加成，否则输出不足
- 不适用于反小或反舰载机场景，主武器序列限制
