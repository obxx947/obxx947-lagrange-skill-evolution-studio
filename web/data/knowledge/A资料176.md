# A资料176 · 最强护航艇坦克加点与搭配

> 场景：护航艇强度对比与载机搭配

## 结论
- 坦克是现版本最强护航艇
- 坦克主武器为重型火炮系统，不受拦截削弱
- 坦克主炮加点后单发伤害可达800多
- 坦克主武器攻击序列优先反大
- 星脉主武器序列是反小
- T800主武器序列优先攻击舰载机
- 坦克上太阳鲸与不上太阳鲸差距非常大
- 太阳鲸的舰船维护系统冷却加成对坦克提升极高
- 苍穹的CR对坦克加成频率不如CV上的伤害加成

## 配队与模块
- 坦克加点：主武器点满，上下两排动力系统和策略依次点满
- 载机必须上太阳鲸-武装战略航空母舰（原文为"太阳金"，疑似语音识别错误）
- 配队：三条11鱼加两条13鱼

## 数值与数据
- 坦克武器冷却时间加满点后为7秒
- T800冷却时间为2.8秒
- 星脉冷却时间为2.5秒
- 坦克主炮加点后单发伤害800多
- 大地A一加点后单发伤害1100
- 坦克在鱼的M1机库与CV的M1机库伤害差距接近两倍
