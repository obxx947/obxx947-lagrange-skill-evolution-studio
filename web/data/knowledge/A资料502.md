# A资料502

## 场景 / 对手
59模块选择与实战应用，涉及护航、防空、反轰炸等环境

## 舰队例子
- 59（M3模块，通用反大重型鱼雷）（胜）【推荐使用，有暴击和分奶效果，但曲射易被拦截】
- 59（M1模块，原装重型轨道炮）（负）【高单发直射，但面对重甲前排和打小船命中不足】
- 59（M2模块，反小）（胜）【契合前排小船环境，但命中不高】
- 59（A3模块，反小脉冲炮）（胜）【推荐，单发不低，反小命中高】
- 59（A1模块，原装反小火炮）（胜）【无A3时可用，与M2相似】
- 59（A2模块，反大直射）（负）【单发低，面对重甲战巡乏力，不推荐】
- 59（B2模块，载机，搭载4个中型战机）（胜）【推荐，可放防空机或干扰机降低闪避】
- 59（B1模块，投射）（胜）【有分奶效果，但伤害受拦截影响】
- 59（B3模块，舰船校射支援和无人机支援）（负）【无人机支援无明确序列，实战无用，不推荐】
- 59（C2模块，电磁装甲）（胜）【当前主流，防护维B等输出】
- 59（C1模块，附加载机）（负）【附加结构少，护航火力下不够看，已没落】
- 59（C3模块，重甲）（胜）【用于防空/反轰炸队，抵抗索姆河伤害，分摊13鱼压力】

## 实战结果
59在护航队中配合盾和前排小船（如双阎神星）形成59盾体系，造价低成型快；在碰瓷队中帮13鱼分摊索姆河火力，但索姆河出现后13鱼生存堪忧，需重甲保护。

## 结论思路
- M系统推荐M2或M3，M1原装不优
- A系统推荐A3，无则用A1，A2不推荐
- B系统主推B1和B2，B3无用
- C系统当前主推C2电磁装甲，C1已没落，C3用于防空/反轰炸
- 59两种主流方案：碰瓷队（重甲+载机）和护航队（中排配合盾）
- 护航时59不建议前突

## 适用限制
- M3和B2易被拦截，伤害可能不高
- M1和A2面对重甲前排乏力
- B3无具体使用说明，不建议使用
- C1附加结构少，不适合当前护航火力
- C3仅适用于防空/反轰炸队，需配合13鱼等
