# A资料512

## 场景 / 对手
420+5打25级，正面战斗，环境为一般星系

## 舰队例子
- 3个南十字+3个卡特+3个护韩挺+大地（数量未明确），飞机：10个新大地、RBC虚灵、3个列维（胜，三分三十四，死1个大地）【二加二配置，输出高但可能翻车】
- 3个南十字替换为5个狩猎+1个大毛，3个卡特，3个护韩挺，大地（数量未明确），飞机：10个小米、10个凌霄（胜，预计四分钟内，稳定不掉大地）【一加一配置，牺牲部分输出换稳定性】

## 实战结果
420+5打25级，两场：一场胜（三分三十四，死1个大地），一场翻车（四分零七，掉4个战群，死3个大地）；对比420+9打25级，加9最快两分五十五，其他加9四分四十七，420+5均碾压

## 结论思路
- 420+5配置可快速打25级，三分半左右，优于加9
- 二加二配置输出高但可能翻车，一加一配置更稳定，牺牲少量输出
- 一加一配置可稳定打进四分钟，适合一般星系拿榜一
- 配置有优化空间，多打几次可能打进三分半或三分二十几

## 适用限制
- 适用于25级目标，一般星系环境
- 二加二配置有翻车风险，需多次尝试
- 一加一配置适合追求稳定，输出略低
- 不适用于高难度或特殊环境
