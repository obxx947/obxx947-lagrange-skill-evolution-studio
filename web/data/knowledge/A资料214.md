# A资料214

## 场景 / 对手
航母体系对比，正面/轰炸，平民与大佬配置

## 舰队例子
- CV（白板）（胜）【载机量最大且便宜，可玩】
- 苍穹（白板）（负）【太贵且载机量不大，不推荐】
- 太阳鲸（白板）（负）【太贵且载机量不大，不推荐】
- 南十字（白板）（负）【太贵且载机量不大，不推荐】
- 天书（白板）（胜）【载机不多但能奶，可玩】
- 太阳鲸（有模块）（胜）【全面，地推轰炸均可，主要用途地推】
- 11+13鱼（主流）（负）【伤害最高但被神话，带走星脉、索姆河等最强输出，轰炸缺失】
- 瑜伽苍穹（13鱼）（胜）【护航艇给苍穹轰炸，空军强，但点数要求高】
- 瑜伽CB（11鱼）（胜）【CB走四队，最强艇放鱼身上】
- CB3000（B2模块）（胜）【造价便宜，成型快，点数要求低，适合平移，放主队用V2】
- CB3000（B4模块）（胜）【放副队，无人机不炸，持续伤害】
- 苍穹（C2模块）（胜）【用于轰炸，点数要求不高，C1也能玩】
- 南十字（C1模块）（负）【不推荐，可开箱子换诺玛或木星】
- 天书（C2+第二附加甲+A1）（胜）【盘古队毕业，俗称叹息之墙】
- 天书（B1或B2+C1飞行系统）（胜）【可当载机用】

## 实战结果
平民玩家用瑜伽苍穹或瑜伽CB，大佬用天书盘古队；主流11+13鱼虽伤害高但牺牲轰炸，实战中地推易败给大门

## 结论思路
- 航母无绝对强弱，各有长处
- 白板CV可玩，白板苍穹、太阳鲸、南十字不推荐
- 天书白板可玩因能奶
- 太阳鲸有模块时全面，主要地推
- 11+13鱼伤害高但被神话，带走最强输出导致轰炸缺失
- 平民玩家建议瑜伽苍穹或瑜伽CB，根据点数选择
- CB3000造价便宜，成型快，适合平移
- 苍穹用于轰炸，C2即可
- 南十字不推荐，可换其他
- 天书盘古队是毕业配置
- 配船不是极致输出，要听管理指挥，避免共性

## 适用限制
- 11+13鱼需要高点数（约250点），平民难满足
- 瑜伽苍穹点数要求高
- CB3000放副队用B4，B2易被打掉护航艇
- 天书平民难获得
- 南十字即使加强也不推荐
- 配船需根据管理要求，不能有共性
