# A资料272

## 场景 / 对手
二阶段控城，围绕七级城和五级城挖水母，对手为海盗守军，正面作战，环境为地图固定点位

## 舰队例子
- 赤瑶9个、雷影4个（扛反小），位置可下一条零六六（胜）【用于打七级城，最后一对子弹反小火力强，雷影需带满】
- 通用配置（11个八百，无小米）（负）【错误配对，打对空城五级，应带一组小米】
- 两鱼、四个零六六、一个盾，带11个登录舰（胜）【用于三级城，作业宽度为10】

## 实战结果
打七级城，损失约9赤瑶和4雷影；打五级对空城，通用配置单吃成功，但碰瓷队扛不住炸完，直接清了两队守军；多对控制需扛得住第一队，否则易出事故

## 结论思路
- 二十级和十四级海盗缩形点位相同，可记点位；高级层位置固定，对空或对舰随机
- 挖水母有两种思路：围绕七级城和五级城，或围绕三级城，各有好处
- 七级城有三对守军，分别在5%、30%、70%时出现，配置为两对相同和一对子站加59
- 打七级城需带足雷影扛反小，特别是最后一对子弹
- 五级对空城对空42万，但无载机舰加成，通用配置可单吃，碰瓷扛不住
- 控高级城需准备保镖队防偷，最好碰瓷护航五航母在旁边
- 多对控制时第一队必须扛得住，否则易出事故
- 通用配置需带一组小米，不能只带八百

## 适用限制
- 适用于二阶段控城，围绕七级城和五级城挖水母
- 七级城配置需针对反小火力，雷影数量要充足
- 五级对空城适合通用配置单吃，碰瓷不适合
- 控高级城需额外保镖队，防他人偷袭
- 三级城需带11个登录舰，作业宽度为10
- 通用配置必须包含小米，否则对空城可能失败
