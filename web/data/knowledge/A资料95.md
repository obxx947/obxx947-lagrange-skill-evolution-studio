# A资料95 · 大盾扛伤思路

> 场景：1V1护航对战

## 结论
- 光防无法帮大盾拦截
- 用蓝睫毛点中排，附加盾点前突
- 附加盾不要一开始就前突，等前排无船时靠策略触发前突
- 前排放闪避船，如开阳、双系神
- 双系神指卡利斯托无人机带阋神星主型号和装甲型
- 有条件可多带卡特、卡侦察
- 前排闪避在1V1可扛三四分钟甚至全程
- 大船会更安全，整体扛伤思路在1V1护航对战中非常占便宜

## 配队与模块
- 蓝睫毛点中排
- 附加盾点前突
- 前排：开阳
- 前排：卡利斯托无人机带阋神星主型号、阋神星装甲型
- 可选前排：卡特、卡利侦察

## 数值与数据
- 前排闪避1V1可扛3-4分钟甚至全程
