# A资料95

## 场景 / 对手
1V1护航对战，大盾扛伤，正面防御

## 舰队例子
- 蓝睫毛（中排）+ 附加盾（前突）（胜）【蓝睫毛拦截，附加盾策略前突】
- 开阳（前排闪避）（胜）【提供闪避，延长前排存活】
- 卡利斯托无人机 + 细神主型号 + 细神装甲型（双系神）（胜）【至少带三个，增强闪避】
- 卡特、卡侦察（可选）（胜）【有条件可多带，提升闪避】

## 实战结果
1V1护航对战，大盾扛伤思路，前排闪避船扛三四分钟甚至全程，大船安全，占便宜

## 结论思路
- 光防无法帮大盾拦截，需用蓝睫毛拦截
- 蓝睫毛点中排，附加盾点前突，但不要一开始前突
- 附加盾策略：前排没有传时才前突，需利用好
- 前排放闪避船（开阳、双系神等），提高闪避
- 前排闪避足够时，大船安全，扛伤效果好

## 适用限制
- 适用于1V1护航对战
- 需有蓝睫毛、附加盾、闪避船（开阳、双系神等）
- 不适用于无前排闪避船或策略使用不当的情况
