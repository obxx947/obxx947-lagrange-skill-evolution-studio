# A资料577

## 场景 / 对手
新公司蓝图活动，航母、战巡、飞机、潜艇、驱逐、护卫、巡洋，自选抽取

## 舰队例子
- 天枢级支援型航空母舰（A3、C2、D2模块，搭载大型战机、护航艇，维修无人机）（胜）【抗伤航母，可攻可防，中排定位，精准奶，适合护航】
- 天枢级支援型航空母舰（C1、D1模块，搭载战机护航艇，铜牌拦截）（胜）【CV3000上位替代，中排拦截，适合副队航母】
- 开阳级驱逐舰（五级）（胜）【新手推荐，性价比高，但强度一般】

## 实战结果
无具体实战记录，主要分析天枢级航母模块组合，强调其抗伤和维修能力，适合护航体系

## 结论思路
- 自选优先航母和战巡，其他船纯废铁，新手可抽开阳驱逐到五级
- 技术档案有保底机制，每个赛季免费十个箱子，小船强度不会高
- 抽大船时小垃圾会顺带来，且50次内必出超主力，不要为小船垫点数
- 天枢级航母是成就型船，模块锦上添花，基础模板强，可攻可防
- 天枢级定位抗伤航母，需先读太阳经、苍穹等基础船，适合护航

## 适用限制
- 适合护航玩家，天枢级需搭配其他航母模块才能发挥
- 不建议放输出队，主要利用维修无人机和抗伤能力
- 新手需花时间积累箱子，白嫖小船强度有限
