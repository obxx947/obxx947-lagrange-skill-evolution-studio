# A资料577 · 新公司蓝图抽取与天枢解析

> 场景：新公司蓝图活动，自选航母/战巡，护航队体系

## 结论
- 自选只选航母和战巡，其余驱逐护卫纯废铁
- 技术档案有保底机制，想要的船最终都能得到，只是时间问题
- 充钱最多到五级，每赛季白送十个箱子，免费固定产出蓝图
- 保底约1/6航母每赛季，驱逐护卫100%
- 新公司是新手福音，但前提是花时间玩
- 白嫖的驱逐护卫强度一定不高，不用测
- 抽天权、天枢时经典小船会顺带来，同时增长心愿值
- 选大船抽满60次至少得一台大船，50次内必出超主力
- 三个箱子独立计算，先选超主力组，别为驱逐护卫垫点数
- 玩护航的玩家两条大船都可要，最推荐天枢级
- 天枢像新手号慢慢成长，基础是模板，抽到的模块都是锦上添花
- 天枢可定向选，不像其他箱子要在战巡航母间博弈
- 天枢定位抗伤航母，不建议放输出队，应利用维修无人机
- 天枢可攻可防，自身回血、身板硬、输出不低
- 天枢纯中排，是不能调排星系玩副队航母的解法
- 天枢是CV3000的上位替代，铜牌拦截一开即可
- 天枢像三角洲，把太阳鲸维修、苍穹B模块、CV3000拦截都缝进来
- 天枢是抗伤航母，不宜单独早出，需先读完太阳鲸、苍穹两本地书
- 下期讲战巡，也是比较厉害的船

## 配队与模块
- 天枢M1搭载护卫舰，M2搭载战机，加成可能不同
- 天枢M2基础可搭载大型战机，比太阳鲸好
- 天枢系统内无人机：50%几率造成100%额外暴击伤害，对载机无影响
- 天枢M模块正常配双伤害、双返回、一命中或锁定，相当于CV3000主机库套壳
- 天枢A模块白给：战斗开始后每隔30秒维修缩短30秒，后续策略多为回血或装甲
- 天枢B模块加点双返回加双伤害，30%有50%提升，约15%伤害提升，是太阳鲸C2模块强化版
- 天枢B模块下一系统提供无人机、舰载机20%飞行时间缩短加10%武器冷却，与任何载机不冲突
- 天枢C2结构降低30%后维修提高100%
- 天枢D模块有拦截加附加，与前面不冲突
- 推荐组合A3、C2、D2：双附加加北斗三号无人机，前凸航母
- C1类似太阳鲸维修模块，八个可搭载战机护航艇，17个飞机可享加成
- C1加D1也可行，D1若是铜牌拦截即CV3000上位替代
- 天枢可缝太阳鲸维修模块、苍穹B模块、CV3000拦截
