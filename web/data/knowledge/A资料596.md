# A资料596

## 场景 / 对手
小船能否顶替战巡扛伤位的讨论

## 舰队例子
- 小船（如护卫舰/驱逐舰）作为前排炮灰，数量若干（负）【闪避优势有限，面对围壁坦克等舰载机时生存差，无法有效扛伤】
- 战巡（如ST59或类似）若干，搭配小船（胜）【战巡分摊反大伤害，小船仅作炮灰吸收灼热伤害】

## 实战结果
战巡在主流反大输出下死亡快，但小船无法替代其扛伤角色；混合编队中战巡仍被集火，小船仅起辅助作用

## 结论思路
- 战巡死亡快是因反大伤害集中，非坦度问题
- 小船闪避对舰载机效果有限，无法顶替战巡扛伤
- 减少战巡数量会加剧集火，导致战巡更快被击毁
- 小船优势仅在造价低，适合作为炮灰分摊伤害
- 资源充足时优先使用战巡，小船仅作辅助

## 适用限制
- 适用于资源有限或需要低成本炮灰的场景
- 不适用于面对高命中或舰载机体系（如围壁坦克）
- 若需稳定扛伤，必须保留足够战巡数量
