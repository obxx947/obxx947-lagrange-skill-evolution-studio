# A资料669 · 太阳鲸十一鱼地推配队建议

> 场景：地推、盘古版本；副队干扰投射吃轰炸

## 结论
- 账号只有十一鱼且无M2，直接打地推，出五个十一鱼。
- 不建议混编十四鱼；B1模块对M1/M2均有加成，综合约55%，牺牲B1会降低十四鱼体加成。
- CV3000有加四才可做，可混编海尔波普、CV-M011型、虚灵、蜂巢、坦普尔到增援副队。
- 普鲁图斯之盾正常用；乌拉诺斯之矛（原文为"毛"，疑似简称）只能中排，无节点则策略改中排。
- 风暴无C2，有C3可上但受蓝点限制，看分点。
- 巡洋调整：拆猎兵、艾奥、CAS066级-支援巡洋舰（原文为"六奶"，疑似简称）的点子给狩猎者级和白垩级；猎兵留50点够。
- 奇美拉可上场，重炮奇美拉全是直射火炮，不会被拦截，反小和打大船都能打动；怕富加顿高护甲，建议洗点。
- 棕熊级-防空巡洋舰（原文为"熊二"，疑似简称）有就慢慢开出来。
- 白垩级非常强，优先养，针对轰炸和混编副队均强。
- 奇美拉第二个型号给点子。
- 副队打地推200人口不能省，瑶光基础型号要用。
- 前期驱护配队：主队约300人口编5开阳，剩5开阳增援，加瑶光和水母；雨海基础型号上满，子型号最多6个；同人口不如换锆石级-特种护卫舰（原文为"锆石特种"，疑似简称），因雨海脉冲能量武器打敌方开阳+瑶光组合前期易被闪避。
- 纯血十一鱼优先养林鸮，伤害高，大艇/打小船/攻击指挥系统都好用；之后养雷火V022。
- 砂龙有加四才进CV3000。
- 后期航母可上苍穹等，优先考虑干扰、防空；苍穹作副航母；没有苍穹，南十字星元帅级也可作副航母，前提飞机点够。
- 主队输出队至少生产1猎兵；放1光环上信息链；狩猎至少6位置；剩下拉泡泡龙；增援纯血十一鱼。
- 推荐干扰投射大队，不做传统双皮奶碰瓷队，专门吃轰炸。
- 红矿可上位置，无红矿多上萤石拉满。
- 配千二幺增援一个五九，专吃对方轰炸。

## 配队与模块
- 太阳鲸：十一鱼纯血，打地推出5个十一鱼；不混编十四鱼。
- CV3000：有加四时，增援副队混编海尔波普、CV-M011型、虚灵、蜂巢、坦普尔。
- 中排矛盾组合：2普鲁图斯之盾级-防护战列巡洋舰（原文为"盾"，疑似简称）+3乌拉诺斯之矛；小盘古组合=开阳级-机动驱逐舰（原文为"施开阳"，疑似语音识别错误）+瑶光级-通用护卫舰（原文为"施妖光"，疑似语音识别错误），配玉衡级-支援巡洋舰（原文为"御衡"，疑似错字）给开阳/瑶光默认巡洋buff；艇推荐CV-M011型、CV-M011型-高速导弹艇（原文为"零幺幺高速"，疑似简称）、虚灵、坦普尔1号-信息护航艇（原文为"坦普尔"，疑似简称）。
- 风暴：有C3可上，无C2；蓝点有限。
- 传统碰瓷队：斗牛级-防御驱逐舰+5枪骑兵级-区域防空驱逐舰（原文为"枪防"，疑似简称）+双皮奶+千二摇导弹（点命中侧位）+增援1个ST59级-防御战列巡洋舰（原文为"五九"，疑似简称）。
- 前期配队：主队约300人口，5开阳级-机动驱逐舰编入，5开阳级增援，加瑶光级-通用护卫舰，配刺水母级-战术护卫舰（原文为"水母"，疑似简称）；雨海级-突击护卫舰（原文为"鱼海"，疑似语音识别错误）基础型号上满，雨海级-脉冲炮护卫舰子型号最多6个；同人口可换锆石级-特种护卫舰。
- 纯血十一鱼艇位：9索姆河之影-装甲飞行坦克（原文为"松木"，疑似语音识别错误）+10星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）+11 CV-T800型-脉冲炮艇（原文为"八百"，疑似简称）；机位：10维塔斯-B010-轰炸机（原文为"为币"，疑似语音识别错误）+10 BR050-标准轰炸机（原文为"零五零的基础"，疑似语音识别错误）+5维塔斯A021-重型攻击机（原文为"维a"，疑似简称）+10米斯特拉-战斗攻击机（原文为"小米"，疑似简称）；共23人头，补位林鸮A100型-联合攻击机（原文为"凌霄"，疑似语音识别错误）。
- 主队输出队：至少1猎兵级-重型载机巡洋舰（原文为"猎兵"，疑似简称）；放1光环上信息链；狩猎者级-载机巡洋舰（原文为"狩猎"，疑似简称）至少6位置；剩下康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡龙"，疑似简称）；增援纯血十一鱼。
- 副队：矛盾组合两盾三毛+小盘古组合；再出投射队，白垩级-战术无人机巡洋舰（原文为"白鳄"，疑似语音识别错误）最少3个为基础；萤石拉满，枪骑兵级-区域防空驱逐舰拉满；投射队放1安东尼奥的猎兵级-重型载机巡洋舰，猎兵内可放奶艇、CV-M011型或虚灵；配千二幺增援1个ST59级-防御战列巡洋舰。
- 安东尼奥猎兵：不需要旗舰，带上即触发安东尼奥区域防护默认巡洋buff，提升15%命中。
- 红矿可上位置，无红矿多上塔拉萨萤石级-信息驱逐舰（原文为"萤石"，疑似简称）拉满。

## 数值与数据
- B1模块对M1/M2均有加成，综合约55%。
- 太阳鲸账号只有十一鱼，无M2；地推出5个十一鱼。
- 毛放中排；中排矛盾组合2盾3毛。
- 猎兵留50点即可。
- 前期主队单队约300人口；开阳5编入+5增援；雨海子型号最多6个；副队打地推200人口不能省。
- 纯血十一鱼：9索姆河+10星脉+11个CV-T800型-脉冲炮艇；机位10维B+10个050基础+5维A+10小米；18人头+5=23，补位林鸮。
- 主队狩猎至少6位置。
- 副队白垩级最少3个；3个白垩级配合10枪防。
- 安东尼奥提升15%命中。
- 千二摇导弹点命中侧位；增援1个五九。
- 奇美拉直射不会被拦截。
