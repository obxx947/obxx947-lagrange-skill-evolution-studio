# A资料25

## 场景 / 对手
舰队决战/攻风作战，针对大中小型舰船，正面输出

## 舰队例子
- 斯坦丁大地级战略巡洋舰（伽马风暴M2主炮系统+CT2×600型能量鱼雷+A1投射系统（CM8×608B常规导弹）+AR投射系统（CM-8×608脉冲能量导弹）+B1通用火炮（双连装对舰炮390×2+自卫火炮78×1）+C3侦察无人机+第三损管系统+C1附加能源模块（RIT650型能量压缩装置））（胜）【极限火力配置M2A、二B1C3D三，配合卡利斯托重型鱼雷袭击舰可打出意想不到的战损比】

## 实战结果
大地级配合卡利斯托重型鱼雷袭击舰，通常可打出意想不到的战损比，受到广大玩家青睐

## 结论思路
- 大地级凭借伽马风暴毁灭性输出、双排站位、韧性及多功能模块协同，位列现役战巡巅峰
- 主炮自动锁定航母等大型高价值目标，能量武器无视常规装甲抗性，是全舰队核心输出支柱
- C1附加能源模块可大幅提升M1、M2主炮冷却与伤害，是追求极限输出的首选
- 极限火力配置可实现针对大中小型舰船的超高攻击效果

## 适用限制
- 适合作为中台火力平台，兼具输出与生存
- 优先获得30%延长支援，需强化损管系统以提升维修效能
- 能量武器对任何舰船类型均有效，但需注意冷却周期管理
