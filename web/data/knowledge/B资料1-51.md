# B资料1-51 · 超主力核心模块解析

> 场景：超主力模块体系

## 结论
- 永恒风暴级定位输出战群，核心任务是输出。
- M2为投射反大武器且不可被拦截，是核心优势。
- 战群点少时只点满M2即可。
- A2是永恒风暴级第二输出点，但鱼雷可被拦截，有则带。
- C2/C3作用均为增加坦度，平民更推荐C3。
- 只有C2/C3没有M2时不建议玩，有M2的永恒风暴级才叫风暴。
- 普鲁图斯之盾级核心是B2，有B2即毕业，其他模块锦上添花。
- 普鲁图斯之盾级最重要是提供旗舰，白板也能上。
- 为保证普鲁图斯之盾级生存，B2附加盾最佳。
- 普鲁图斯之盾级M模块最好M3实弹反大；A模块最好A2或A3，可吸引火力提高奶船生存。
- 普鲁图斯之盾级C模块（原文为"z模块"，疑似语音识别错误）最好C2或C3；C2提供自身拦截但效率低，C3伤害高。
- 乌拉诺斯之矛（原文为"大毛"，疑似语音识别错误）当前版本不推荐玩前排抗伤，更偏向辅助抗伤加输出。
- 乌拉诺斯之矛M模块只推荐M1，可调站位到中排，输出不错。
- 乌拉诺斯之矛A模块A2为核心，残血爆发强，是主要输出手段。
- 乌拉诺斯之矛B模块B2/B3都行；个人认为B2强于B3。
- 乌拉诺斯之矛C2/C3均可；C2增加坦度，C3是拦截模块且为光环上位替代；C2适合普通玩家，C3适合高达队。
- 新君士坦丁大帝级核心A1为自带模块，白板也能玩。
- 新君士坦丁大帝级A1的暴击一定要点，打残血时暴击很疼。
- A1可被拦截，碰到光锥级-区域防空巡洋舰（原文为"光防"，疑似简称）可能打不出伤害。
- 新君士坦丁大帝级M模块两个都能用，更推荐M2投射版大，没有M2则M1也好用。
- 新君士坦丁大帝级C3提高命中率，为A1服务；有C3后A1可不点命中，其他模块不重要。
- ST59级最核心C2，能让坦度上一个台阶，其他两个C模块也能用。
- ST59级B2吸收防空火力并给舰队分伤，其他模块不重要。
- 安东塔斯持剑者级作扛伤战群时核心只有C2，作用同ST59级。
- 安东塔斯持剑者级定位输出战群，机制为输出能力越强则自身越强。
- 安东塔斯持剑者级输出最核心A2攻击敌方血量百分比低的船，需配合M模块才能最大化。
- 安东塔斯持剑者级M1指挥舰载机，M2能指挥同排巡洋；M1+A1可指挥舰载机一起攻击低血量船，M2同理，更推荐M1。
- 安东塔斯持剑者级B1融甲剑没有也能玩，D2/D3属可有可无。
- 天权级能用的前提是天枢级也毕业；无天枢时放前排同时吃直射与曲射反大火力，容易扛不住。
- 天枢级超高奶量加天权级高护甲，提高奶量加成，前排站得住；站得住时前排战群比中排好。
- 雷火之星-综合武库舰（原文为"雷果"，疑似语音识别错误）不推荐使用，只有顶氪才会玩。

## 配队与模块
- 永恒风暴级：核心M2；次选A2、C2/C3；战群点少只点M2；没有A2可用A模块；C2/C3增坦，平民推荐C3；只有C2/C3无M2不推荐玩。
- 普鲁图斯之盾级：核心B2；白板可上；B2附加盾；M模块M3实弹反大；A模块A2或A3；C模块C2或C3。
- 乌拉诺斯之矛：M1调中排；A2核心；B2搭载护航艇放海尔波普提供奶量并分伤；B3损管奶自己；C2增坦；C3拦截；C2普通玩家用，C3高达队用。
- 新君士坦丁大帝级：A1自带并点两个暴击；M2投射版优先，M1可用；C3提高命中，A1可不点命中。
- ST59级：核心C2；其他两个C模块可用；B2搭载战机。
- 安东塔斯持剑者级：扛伤仅C2；输出A2打低血量船并配M模块；M1指挥舰载机，M2指挥同排巡洋，M1+A1指挥舰载机打低血量；更推荐M1；B1融甲剑，D2/D3可有可无。
- 天权级：C3加自带ME模块；需搭配毕业天枢级；定位前排扛伤。
- 雷火之星-综合武库舰：不推荐。

## 数值与数据
- 永恒风暴级点满M2可发挥约70%伤害。
- 普鲁图斯之盾级B2附加盾后护甲约780，应为全游戏最高。
- 乌拉诺斯之矛B2可搭载3架护航艇。
- ST59级B2可搭载4架战机。
- 新君士坦丁大帝级A1有2个暴击点。
