# A资料209 · 平民护航艇培养选择

> 场景：平民玩家护航艇培养

## 结论
- 护航艇是现版本主力输出位之一，也是战略打击主要伤害来源
- 护航艇培养方向只看输出
- 第一梯队只有三个：坦克、新麦、八板
- 坦克优先打大船，单发接近一千，能破开绝大部分重甲目标防御
- 坦克攻击序列包含所有大船，巡洋舰和航母也一起打
- 坦克常规配置伤害稳定，唯一短板是面对高达抗伤队输出乏力
- 新麦优先打击小型舰船，属于能量伤害，获取难度略高，需要子型号
- 新麦输出在护航艇里能排第一，与VB并称载机双雄，大小船通吃
- 新麦与坦克一起参与苍穹轰炸后伤害都能翻三倍，没有明显短板
- 瑶光理论上克制新麦，但实战中新麦有概率优先处理瑶光，实际限制效果不明显
- 八板是炮艇里唯二的主动防空，属于能量伤害，大小船通吃
- 八板对舰与防空伤害都非常可观，既是战略打击输出核心，也是常规舰队对抗战略打击最有效手段
- 八板唯一不足是打战机命中率太低，不上猎兵超斩时所有干扰机都是它的克星
- 有以上三个护航艇就列为重点培养目标
- 一个都没抽到就只能培养第二梯队护航艇
- 第二梯队输出会低一点，且大部分使用局限很大
- 蜂巢前期打小船或巡洋舰伤害非常高，步入战巡阶段后单发破不了防，后期基本报废
- 列尾单发比蜂巢和坦克都高，有穿甲策略，但必须配合猎兵超斩，不然伤害不理想，且很怕拦截
- RB7单发不高，优先打小船，不会存在蜂巢一样的问题，但没有小船会打战巡，使用条件比较苛刻
- RB7的SP型号每小船会打巡洋舰，实战作用会大一点，但获取难度也更高
- 野火护航艇获取难度很高，需要特定SP箱子才能开出来
- 野火基础型没有攻击持续时间，没有星脉或坦克可以把它带上苍穹轰炸，优先打小船输出也不错
- 野火子型号是护航艇里第二个主动防空，优先打战机，但攻击循环很长，强度没那么高
- 以上护航艇都是过渡选择，抽出星脉、坦克和八板后大部分就可以退休
- 能玩战略打击就培养天机护航艇，它是战略打击的挡刀炮艇，在轰炸中很重要
- 天机有不错的输出能力，但很依赖溶解弹层数，和盘古体系配套，单独上场输出能力一般，不建议作为输出定位
- 003也能为轰炸炮艇挡刀，但不用花精力培养，吃经验书、点满装甲和策略就行
- 要应对战略打击可以培养零一一C型号或坦克二
- 零一一C型号是防空支援护航艇，防空伤害不错
- 坦普尔基础型能扰乱对面空军索敌序列，打乱战略打击输出节奏
- 坦普尔子型号能提高舰船防空锁定效率，对胖瓷舰船有较大提升
- 有天枢级-支援航空母舰（原文为"天枢"，疑似简称）或天权能用就培养哈尔波普，它能为大船提供维修量，是舰载机形态的奶妈
- 剩下两个护航艇主要作用都是抗伤，培养优先级最后
- 有天枢航母需要扛伤护航艇时才会用到它们，主要作用都是为海尔分摊伤害

## 配队与模块
- 坦克：优先打大船，单发接近一千，攻击序列包含所有大船
- 新麦：优先打击小型舰船，能量伤害，需要子型号
- 八板：主动防空，能量伤害，大小船通吃
- 蜂巢：前期打小船或巡洋舰伤害高，后期破不了防
- 列尾：单发比蜂巢和坦克都高，有穿甲策略，必须配合猎兵超斩
- RB7：优先打小船，没有小船会打战巡
- RB7的SP型号：每小船会打巡洋舰
- 野火基础型：没有攻击持续时间，可带上苍穹轰炸，优先打小船
- 野火子型号：主动防空，优先打战机
- 天机：战略打击挡刀炮艇，依赖溶解弹层数，与盘古体系配套
- 003：为轰炸炮艇挡刀，吃经验书、点满装甲和策略
- 零一一C型号：防空支援护航艇
- 坦普尔基础型：扰乱对面空军索敌序列
- 坦普尔子型号：提高舰船防空锁定效率
- 哈尔波普：为大船提供维修量，舰载机形态奶妈
- 剩下两个护航艇：抗伤，为海尔分摊伤害

## 数值与数据

- 新麦与坦克参与苍穹轰炸后伤害翻三倍
- 游戏里有十四个护航艇
