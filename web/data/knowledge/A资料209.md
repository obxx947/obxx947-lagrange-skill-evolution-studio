# A资料209

## 场景 / 对手
护航艇培养方向，战略打击与防空环境

## 舰队例子
- 坦克护航艇（常规配置）（胜）【优先打大船，单发近1000，破重甲，攻击序列含巡洋和航母，伤害稳定】
- 苏迈护航艇（子型号）（胜）【优先打小船，能量伤害，输出第一，与VB并称载机双雄，无短板】
- 八零零护航艇（胜）【主动防空，能量伤害，大小船通吃，对舰防空可观，打战机命中率低】
- 蜂巢护航艇（负）【前期打小船巡洋伤害高，战巡阶段单发破不了防，后期报废】
- 列尾护航艇（负）【单发高，有穿甲策略，但需猎兵超斩配合，怕拦截，不适合现环境】
- RB7护航艇（负）【优先打小船，有增伤策略，但无小船时打战巡，条件苛刻】
- RB7 SP型号（胜）【无小船时打巡洋，实战作用大，但获取难度高】
- 野火护航艇（基础型）（胜）【获取难，无攻击持续时间，需星脉或坦克带苍穹轰炸，优先打小船】
- 野火护航艇（子型号）（负）【主动防空，优先打战机，但攻击循环长，强度不高】
- 天机护航艇（胜）【战略打击挡刀炮艇，依赖溶解弹层数，与盘古体系配套，单独输出一般】
- 零一一C型号护航艇（胜）【防空支援，防空伤害不错】
- 坦普尔护航艇（基础型）（胜）【扰乱空军索敌序列，打乱战略打击节奏】
- 坦普尔护航艇（子型号）（胜）【提高舰船防空锁定效率，对胖瓷舰船提升大】
- 哈尔波普护航艇（胜）【为大船提供维修量，舰载机形态奶妈】
- 其他抗伤护航艇（胜）【为海尔分摊伤害，培养优先级最后】

## 实战结果
平民玩家培养护航艇，第一梯队（坦克、苏迈、八零零）为核心，第二梯队为过渡；战略打击用天机，防空用零一一C或坦普尔，维修用哈尔波普，抗伤最后考虑

## 结论思路
- 护航艇培养只看输出，第一梯队为坦克、苏迈、八零零
- 坦克优先打大船，单发高，但面对高达抗伤队乏力
- 苏迈优先打小船，能量伤害，输出第一，无短板
- 八零零主动防空，能量伤害，对舰防空可观，但打战机命中率低
- 第二梯队输出低，使用局限大，如蜂巢后期报废，列尾怕拦截
- RB7条件苛刻，SP型号更好但获取难
- 野火基础型需配合苍穹轰炸，子型号防空但循环长
- 战略打击培养天机，防空培养零一一C或坦普尔
- 维修用哈尔波普，抗伤护航艇最后培养

## 适用限制
- 适用于平民玩家，资源有限
- 第一梯队护航艇需重点培养，第二梯队为过渡
- 战略打击需天机护航艇，防空需零一一C或坦普尔
- 抗伤护航艇仅在特定航母（如天枢）需要时培养
- 获取难度高的护航艇（如苏迈、野火）需特定条件
