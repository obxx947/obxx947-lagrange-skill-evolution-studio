# A资料580

## 场景 / 对手
分析御衡、开阳、耀光组合强度，对比顶配玩家与普通玩家适用性，涉及天书级副队配置

## 舰队例子
- 太阳金（金八+金维B）、坦克（直射反大）、星脉（直射反小+维A反大）、凌霄、苍穹（9反大）、T800（直射反小）、指见者（3台，跨排优先血量最低）、风暴（曲射反大）、雷火电（直射反大）、追随者（超斩），人口420+5（胜）【顶配输出队，无直射武器被拦截，克制前排小船】
- 艾奥、康纳马拉、风暴、大地（主队攻击副队）（负）【低效输出，被开阳+耀光组合克制，不适合顶配】
- 天书级、剑、盾、矛（战巡分摊）（胜）【天书级与战巡搭配合理，替代矛和零六六】
- 御衡、耀光、零六六、开阳（副队）（负）【体系割裂，奶量不足，不适合大船队】

## 实战结果
顶配玩家（太阳金、金星、苍穹等）对阵开阳+耀光组合，顶配队无直射武器被拦截，轻松取胜；普通玩家使用艾奥、康纳马拉等被克制，几负。关键得失：顶配队避免直射武器，普通玩家依赖能量直射导致失败

## 结论思路
- 开阳、耀光、御衡组合强，但仅适用于普通玩家，顶配玩家无需使用
- 天书级是好船，不破坏平衡，与战巡搭配，替代矛和零六六
- 顶配输出队优先输出航母、战巡，避免输出巡洋，尤其是前排巡洋
- 开阳+耀光组合克制能量伤害，但顶配队用物理伤害可自然克制
- 耀光机buff只加给驱逐护卫，不适用于大船，设计合理
- 零六六奶量低，人口高，不如U盘性价比，不适合大船队

## 适用限制
- 开阳+耀光组合适用于普通玩家（使用艾奥、康纳马拉阶段），不适用于顶配
- 天书级仅与战巡搭配，不与航母搭配
- 顶配队需避免直射武器，防止被前排拦截
- 耀光机buff仅对驱逐护卫有效，不适用于战巡或航母
- 零六六不适合大船队，人口高奶量低
