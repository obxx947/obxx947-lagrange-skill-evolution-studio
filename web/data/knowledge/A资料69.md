# A资料69

## 场景 / 对手
测试环境，三分钟作战时长，八艘奇美拉重炮型，针对小船、巡洋舰、重甲战巡和航母

## 舰队例子
- 奇美拉重炮型 x8，加点：双冷却、双命中、一策略、双手伤害、反弹命中（胜）【对小船和巡洋舰输出亮眼，对重甲战巡和航母伤害低】

## 实战结果
测试奇美拉重炮型，对小船和巡洋舰表现良好，对重甲战巡几乎无伤害，调校效果有限

## 结论思路
- 奇美拉重炮型反大能力差，反小能力可圈可点
- 调校减少策略启动时间，拉满仅减12秒，实战作用不大，不建议投入
- 在当前环境（前排小船、中排巡洋）有上场空间，可作为输出下位替代
- 与IO相比，更推荐IO，奇美拉重炮型不适合作为主力输出

## 适用限制
- 适用于前中期对抗小船和巡洋舰
- 不适合对抗重甲战巡和航母
- 不建议作为主队主力输出使用
