# A资料694

## 场景 / 对手
沙龙与包子（凌霄）空优机体系，正面空战，护航艇版本环境

## 舰队例子
- 太阳鲸C1模块+沙龙（11+13载具）（胜）【保底伤害均伤4万以上，依赖载具加成】
- 狩猎者+沙龙（普通载具）（负）【均伤约3万或更低，载具加成不足】
- 南十字+凌霄（垃圾载具）（胜）【能打出5000多伤害，出伤能力优于包子】
- 包子（任意模块）（负）【出伤低，2分半9万对空但有效伤害仅1-2万】

## 实战结果
沙龙对战机输出，小米配合，包子辅助绝育；沙龙保底4万，小米8万，包子有效伤害低；关键得失：沙龙需最优载具和索敌加点，包子仅用于填充和绝育

## 结论思路
- 沙龙伤害由主动防空和反击防空组成，主要打战机，保底4万
- 沙龙必须配最优载具（11+13太阳鲸C1），纯11或11+2无位置
- 沙龙出伤低原因：载具差、不点索敌、加点错误
- 包子用途：填充血量、绝育目标、加速击杀，但出伤能力弱
- 凌霄比包子更实用，优先对护航艇，出伤实打实
- 小米和沙龙配合，沙龙帮小米砍血触发策略

## 适用限制
- 仅推荐11+13玩家玩沙龙，纯11或11+2不适用
- 沙龙需点索敌，否则出伤困难
- 包子仅在空战体系需要绝育和填充时使用，否则不推荐
- 护航艇版本下空优机整体无力，需谨慎选择
