# A资料607

## 场景 / 对手
测试雷火之星反小能力，对比主流驱护抗伤舰船（开阳、瑶光、斗牛防护、阋装甲、阋火炮），正面输出环境

## 舰队例子
- 雷火之星（M1轨道炮模块、C2火控系统、B1/D1/E1副武器，军工强化轨道炮和火炮伤害，数量3艘）（胜）【反小伤害超过艾奥对舰、奇美拉、游骑兵，面对开阳+瑶光组合优势明显】
- 艾奥对舰（数量满编）（负）【反小伤害略高于雷火之星面对斗牛防护时，但面对开阳+瑶光时低于雷火】
- 奇美拉（数量满编）（负）【反小伤害远低于雷火之星】
- 游骑兵（数量满编）（负）【反小伤害远低于雷火之星】

## 实战结果
雷火之星（3艘）对比艾奥对舰、奇美拉、游骑兵（满编），在三分钟测试中，面对开阳+瑶光时雷火伤害最高；面对斗牛防护时略低于艾奥但差距极小；面对阋装甲/阋火炮时低于艾奥但远高于其他。综合排名雷火反小强度高于艾奥对舰。关键得失：雷火造价高但指挥值低（105点），主力武器为直射轨道炮，不受光防拦截影响

## 结论思路
- 雷火之星M1模块是反小核心，单发伤害高但命中低，需强化命中并缩短攻击间隔
- 新增策略技能备用弹药可90%缩短攻击间隔，几乎零冷却零锁定
- 搭配C2火控系统提升命中，副武器B1/D1/E1需军工强化轨道炮和火炮伤害
- 雷火服役上限3艘，总指挥值105点，低于其他反小巡洋舰满编
- 面对主流抗伤小船（开阳+瑶光）时，雷火反小伤害超过艾奥对舰，且直射武器不受干扰
- 面对斗牛防护时与艾奥差距极小，面对阋装甲/阋火炮时略逊但远高于奇美拉和游骑兵
- 综合当前环境，雷火反小强度高于艾奥对舰

## 适用限制
- 适用于反小作战，特别是针对开阳+瑶光等主流抗伤小船
- 造价高昂，需考虑资源消耗
- 服役上限仅3艘，不适合大规模舰队
- 依赖M1模块和策略技能，需强化命中
- 面对高闪避或能量抗性目标时可能效果受限
