# A资料435

## 场景 / 对手
护卫篇，前期区护选择与舰队配置，涉及舰船定位、输出能力、扛伤能力

## 舰队例子
- 水母（能量武器+无人机）（胜）【输出能力强，但血量不高】
- 海脉冲（策略爆发）（胜）【可爆发输出两分钟，但面对高闪避舰船乏力】
- 锆石级（搭载定制护航艇）（负）【护航艇被打掉后无法持续作战】
- 狼系特种型（胜）【血量越低伤害越高，但前排输出环境不理想】
- 红离子（直射能量武器）（负）【面对高闪避舰船伤害低，人口上调后少用】
- 雷利亚特隐身型（胜）【闪避不错，中排生存性好，但输出一般】
- 卡特（超高闪避+闪避策略）（胜）【前期重要扛伤护卫舰】
- 红宝石防护型（胜）【作为卡特下位替代】
- 瑶光护卫舰（无人机提供能量护盾）（胜）【搭配开阳组成阳光组合】
- 诺玛护卫舰（奶船）（胜）【奶量不错，适合落地开荒】

## 结论思路
- 选择护卫舰需考虑舰船定位、输出能力和扛伤能力
- 水母和海脉冲适合输出，但需注意生存和闪避问题
- 卡特是扛伤首选，红宝石作为替代
- 瑶光和开阳组合可增强防御，诺玛提供治疗支持

## 适用限制
- 水母血量低，需保护
- 海脉冲面对高闪避舰船效果差
- 锆石级依赖护航艇，无法持续作战
- 狼系特种型前排环境不理想
- 红离子对高闪避舰船伤害低
- 雷利亚特输出一般
- 红宝石仅作为卡特替代
- 阳光组合需瑶光和开阳搭配
