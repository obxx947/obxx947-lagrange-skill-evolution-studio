# A资料700

## 场景 / 对手
巡洋舰体系分析，涵盖各分段玩家适用性、舰队配置与实战对比

## 舰队例子
- 光追（20人口，铜牌拦截）（负）【性价比低，仅适合无替代时使用】
- CB300（40人口，铜牌拦截+分商+载机位）（胜）【光追的上位替代，综合性能更优】
- 天书（副队巡洋）（胜）【副队巡洋的上位替代，无拦截但整体更强】
- 零六六（奶大船）（胜）【需保护，与光追不冲突】
- 御衡器（奶小船，人口两倍）（胜）【实战中奶量14万，约为零六六的2.5倍】
- L（低分段推荐）（胜）【适合新手，前排船优先】
- 重卡（攻击蓄力系列）（胜）【低分段强力，高分段无用】
- 列兵（A6模块）（胜）【唯一无上位替代的船，超展位不可优化】

## 实战结果
零六六与御衡器对比：御衡器奶量14万，人口两倍，奶量约2.5倍；重卡实战中精准伤害优于总伤害，如50万反大伤害中20万精准盖战巡

## 结论思路
- 巡洋舰因‘上有老下有小’特性，生存能力最佳，是游戏中的连接角色
- 巡洋舰是过渡阶段，高手队伍中几乎无巡洋，只有战巡航
- 光追性价比低，可用CB300或天书替代
- 零六六需保护，光追可辅助，但奶船优先于拦截
- 低分段应优先前排船，如L，输出与防御不可分
- 重卡适合低分段，高分段无用，攻击蓄力决定一切
- 列兵是唯一无上位替代的船，超展位不可优化
- 其他巡洋如尤奇兵、中雄、KCG2.0、白鳄级强度有限，仅特定功能可用

## 适用限制
- 光追仅适合无替代时使用，否则性价比低
- 重卡仅适合低分段，高分段对手强时无效
- 列兵需有能力抛弃超展位的玩家，否则不适用
- 中雄级对高刻度玩家无用，低刻度玩家成本过高
- 巡洋舰在高端局中不适用，应过渡到战巡航
