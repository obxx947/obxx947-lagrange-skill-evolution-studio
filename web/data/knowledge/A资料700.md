# A资料700 · 巡洋舰定位与分段配队

> 场景：巡洋舰体系，按玩家分段与配队环境

## 结论
- 巡洋舰被视为大船，但反大武器不会第一时间锁定它，生存环境好。
- 巡洋舰连接大小船，是游戏里生存最好的船之一。
- 队伍能过渡掉巡洋舰时，才算真正高手。
- 高端玩家主队副队几乎不带巡洋，只带战巡。
- 还在玩巡洋说明未达顶端。
- 每艘热门巡洋基本都有大船作为上位替代。
- 巡洋几乎没有特别值人口的船，除非附带载机可找补。
- 20人口铜牌拦截不值得，队伍负担不起。
- 队伍只能选光锥级-区域防空巡洋舰（原文为"光追/光堆"，疑似语音识别错误）且需要拦截时，可以用。
- 副队最重要的是分伤，不是拦截。
- 奶船未满载前不优先看光锥级-区域防空巡洋舰。
- 光锥不仅保战巡，更主要保护CAS066级-支援巡洋舰（原文为"零六六/零六"，疑似简称），两者不冲突。
- 低分段优先从前排找船，巡洋/驱逐/护卫皆前排更重要。
- 该分段玩家很难把输出和防御完全分开。
- 只有最强和最弱玩家才玩前排船：最弱玩七秒，最强玩乌拉诺斯之矛（原文为"毛"，疑似语音识别错误）+天权级-重型防御战列巡洋舰（原文为"天权"，疑似简称）。
- 还觉得艾奥级-攻坚离子炮巡洋舰（原文为"艾奥"，疑似简称）或七秒很强，说明仍在低分段。
- 卡利斯托-重型鱼雷袭击舰（原文为"重卡"，疑似简称）不绑定分段，中低氪队伍有一律拉满。
- 高氪对手越强，卡利斯托-重型鱼雷袭击舰作用下降，但仍是好东西。
- 有攻击系列的船基本不落，攻击蓄力先决定一切。
- 卡利斯托-重型鱼雷袭击舰母体鱼雷策略为目标选项式增伤，无精准锁定，仍是蓄力，不强。
- 猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误）可能是唯一没有上位替代的船。
- 猎兵级-重型载机巡洋舰模块非输出模块，要带超主力时可能只能优化超主力。
- 有能力抛弃超主力的玩家，队伍反大输出够，不需要望远镜。
- 游骑兵级-综合作战巡洋舰（原文为"尤奇兵"，疑似语音识别错误）、棕熊级-综合巡洋舰（原文为"中雄"，疑似语音识别错误）、KCCPV2.0-轻型攻击巡洋舰（原文为"kcg二点零"，疑似语音识别错误）、白垩级（原文为"白鳄级"，疑似错字）强度有限。
- 棕熊级（突防）与新君士坦丁大帝级-综合战列巡洋舰（原文为"大帝"，疑似简称）突防冲突，高氪不需要。
- 低氪CV3000级-快速航空母舰（原文为"cb三千/CV三千/c v三千"，疑似语音识别错误）+新君士坦丁大帝级-综合战列巡洋舰玩家用不起/抽不到棕熊级，不值得强抽。
- 强做棕熊级的价格不如买成品号。

## 配队与模块
- 护航队：光锥级-区域防空巡洋舰开拦截，主要保护CAS066级-支援巡洋舰。
- 光锥级-区域防空巡洋舰上位替代链：CV3000级-快速航空母舰→天枢级-支援航空母舰（原文为"天书"，疑似语音识别错误）；天枢级-支援航空母舰可作整个副队巡洋上位替代。
- CV3000级-快速航空母舰兼做超主力分伤，并提供大量载机位。
- 南十字星元帅级-武装航空母舰（原文为"南狮志"，疑似语音识别错误）替代狩猎者级-载机巡洋舰（原文为"狩猎"，疑似简称）：1艘6个超主力载机位，换8架海氏追随者型-脉冲攻击机（原文为"海狮追击者"，疑似语音识别错误）不够；2艘共12位又超；单位人口南十字更划算，凑强迫症推荐狩猎者级-载机巡洋舰+南十字星元帅级-武装航空母舰。
- 最强前排组合为乌拉诺斯之矛+天权级-重型防御战列巡洋舰。
- 星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）可改反小，队伍不需要望远镜。
- 破盾时游骑兵级-综合作战巡洋舰可反小，针对小船精准打击。

## 数值与数据
- 光锥级-区域防空巡洋舰拦截500/1000发子弹，折算伤害不超过10万。
- 同时间同人口，奶船通常比光锥级-区域防空巡洋舰拦截更多。
- 玉衡级-支援巡洋舰（原文为"御衡器/御衡"，疑似语音识别错误）单次奶14万，人口为CAS066级-支援巡洋舰两倍，奶量约2.5倍。
- 玉衡级-支援巡洋舰约等于CAS066级-支援巡洋舰：一个奶小船，一个奶大船。
- 1艘南十字星元帅级-武装航空母舰有6个超主力载机位，2艘共12位。
- 8架海氏追随者型-脉冲攻击机换1艘南十字星元帅级-武装航空母舰不够。
- 光锥级-区域防空巡洋舰做铜牌拦截需20人口；CV3000级-快速航空母舰为40人口。
- 卡利斯托-重型鱼雷袭击舰反大伤害50万中约20万精准命中战巡；对方不分摊战巡会死。
