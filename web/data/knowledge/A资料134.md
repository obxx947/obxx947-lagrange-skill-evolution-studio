# A资料134 · 天冲航母功能性解析

> 场景：副本/海盗/联防夹击

## 结论
- 当前版本主流航母仍以CV3000级-快速航空母舰（原文为"三千"，疑似语音识别错误）或太阳鲸-武装战略航空母舰（原文为"鲸鱼"，疑似简称）为主
- 太阳鲸模块齐全时11鱼和13鱼依旧强势
- 副航母优先选永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称），其次南十字星元帅级-武装航空母舰（原文为"南十字"，疑似简称）
- 永恒苍穹级与南十字星元帅级都有不错的战机增幅效果
- 天冲航母自带维修系统，可提供8个战机机库
- 天冲航母在战机阵亡后可持续为舰队维修
- 天冲航母功能性远优于CAS066级-支援巡洋舰（原文为"零六六奶"，疑似语音识别错误）和玉衡级-支援巡洋舰（原文为"玉衡集 徐阳建"，疑似语音识别错误）
- 天冲航母基础血量高，配合高额抗性很难被调船
- 前排单乌拉诺斯之矛（原文为"大毛"，疑似语音识别错误）承伤，让全队维修量集中于前排
- 避免航母直接受击导致奶量过于分散
- 用康纳马拉混沌级补充直射输出
- 核心输出类舰船、轰炸机和后顶上场后补充防空火力
- 该配置打副本和海盗都比较受用
- 战巡有蓝点或核心输出时，可拉乌拉诺斯之矛、新君士坦丁大帝级-综合战列巡洋舰（原文为"大地"，疑似语音识别错误）上场，效果更好
- 航母携带灵活，可用于粘垃圾、重振、辅助队友联防或夹击

## 配队与模块
- 前排：单乌拉诺斯之矛承伤
- 输出：康纳马拉混沌级补充直射输出
- 航母：天冲航母，自带维修系统，8个战机机库
- 副航母：优先永恒苍穹级-无人机航空母舰，其次南十字星元帅级-武装航空母舰
- 可选战巡：乌拉诺斯之矛、新君士坦丁大帝级-综合战列巡洋舰
