# A资料134

## 场景 / 对手
当前版本主流航母携带以三千或鲸鱼为主，副航母选择苍穹或南十字，苍穹优先级更高。本期主角是天冲航母，用于打副本或海盗。

## 舰队例子
- 天冲航母（自带维修系统，8个战机机库）+ 大毛（前排单舰承伤）+ 康纳（直射输出）+ 轰炸机 + 后顶（防空火力）（胜）【全队维修量集中于前排，避免航母受击导致奶量分散。】

## 实战结果
天冲航母配置在打副本或海盗中取得不错成绩，具体对手未提及。

## 结论思路
- 天冲航母功能性优于零六六奶和玉衡集徐阳建，自带维修系统且提供8个战机机库。
- 基础血量高且配合高额抗性，难以被调船。
- 前排单大毛承伤，使维修量集中，避免奶量分散。
- 康纳补充直射输出，轰炸机和后顶提供防空火力。
- 若战巡有蓝点或核心输出，可考虑拉大毛或大地增强效果。
- 航母携带灵活，可用于粘垃圾、重振、联防或夹击，运用得当可起核心作用。

## 适用限制
- 适用于打副本或海盗场景。
- 需要天冲航母模块齐全。
- 前排需有大毛承伤。
- 若缺乏战巡蓝点或核心输出，效果可能受限。
