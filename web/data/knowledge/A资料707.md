# A资料707

## 场景 / 对手
顶克玩家副队空战，对手为高刻度玩家，正面交锋，环境为常规PVP

## 舰队例子
- 海尔波普（护航艇）+ 虚零（3）+ 零幺幺 + 列维九号 + 塔普尔 + 天鸡 + 沙龙头子 + 四幺零五零（胜，战损仅掉两个天权，敌方团灭）【副队配置，但存在无效船只，如零幺幺、列维九号、塔普尔、沙龙头子等】
- 南十字（输出航母）（负，5分半打590万伤害）【上期配置，输出效率低】
- 苍穹（输出航母）（胜，4分半打630万伤害）【本期配置，时间减少1分钟，伤害增加100万】

## 实战结果
老板队伍打敌方，1胜0负，关键得失：副队空战保护海尔波普，敌方团灭，我方仅掉两个天权；输出从88万提升至140万，敌方地面输出仅33万

## 结论思路
- 副队空战核心：快速解决对方海尔波普，同时保护己方海尔波普
- 副队中艇的地位高于战机，因为艇能直接挡刀，战机若无小米则无意义
- 主队带战机，副队带艇，但坦克星脉等输出艇除外，需放主队保生存
- 护航艇挡刀顺序：优先带天鸡（A/B），其次无持续时间船（如星云弹炮），再带攻击顺序正确的船（如SP摇、SP RB7）
- 避免带无效船，如零幺幺（只打战机）、列维九号（生存高但无挡刀效果）、塔普尔（无对空对舰）、沙龙头子（不打艇）
- 副队中应带攻击顺序正确的船，确保全程有效输出，如星云弹炮打巡洋

## 适用限制
- 适用于顶克玩家，高刻度账号
- 副队中不带坦克星脉等输出艇，因其易被集火
- 若敌方带小米，战机挡刀才有意义，否则不带
- 天鸡因底层代码生存差，需优先带满
- 副队中避免带巡洋，因敌方全针对巡洋
