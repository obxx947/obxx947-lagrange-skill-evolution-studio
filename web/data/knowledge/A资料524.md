# A资料524

## 结论思路
- 武器模块工作流程分为目标选择、开火射击、武器冷却三个阶段，目标选择可在冷却阶段同时进行。
- 目标选择阶段在战斗开始或原目标被消灭后触发，锁定时间决定选择时长，依据敌方阵型和攻击序列锁定目标。
- 开火射击阶段执行一轮攻击，若目标未毁则进入冷却，若击毁则立即停止射击并进入冷却和目标选择。
- 武器冷却阶段可同时进行锁敌，提高效率。
- 武器命中率取决于类型和目标：轻型武器对小型舰船命中高但伤害低，重型武器对中大型舰船效果好但对小型目标命中率低。

## 适用限制
- 适用于理解武器机制，不涉及具体舰队配置。
- 重型武器不适宜攻击小型目标，轻型武器对大型船只效果有限。
