# A资料524 · 武器工作原理与命中率

## 结论
- 武器工作流程依次为目标选择、开火射击、武器冷却三个阶段
- 目标选择阶段在战斗开始或原锁定目标被消灭后触发
- 目标选择时间即武器锁定时间，期间依据敌方阵型与自身攻击序列锁定目标
- 目标选择可与武器冷却阶段同时进行
- 开火射击阶段按攻击次数执行一轮攻击
- 一轮攻击后目标未被击毁则进入冷却阶段，冷却结束后进行下一轮攻击
- 一轮攻击击毁目标则立即中止开火，进入冷却阶段和目标选择阶段
- 武器冷却阶段可同时进行锁敌
- 武器按类型与目标船只分为轻型武器和重型武器
- 轻型武器攻击小型舰船命中率更高，但单发伤害普遍偏低，不易对大型船只造成有效伤害
- 重型武器适合打击装甲厚重、机动性较差的中大型舰船
- 重型武器瞄准小型目标时命中率大幅降低
