# B资料1-78 · 066奶未退环境需变革配队

> 场景：副队奶船选择；无航母/有航母副队；反小火力、防空火力、轰炸环境

## 结论
- CAS066级-支援巡洋舰（原文为“溜溜奶”，疑似简称）未退环境，只是不能无脑带满，需要配队变革。
- 玩家放大了CAS066级-支援巡洋舰缺点；它在战斗前半段仍能提供稳定奶量。
- CAS066级-支援巡洋舰最大诟病是乱奶/奶自己：奶序列广，多艘大船挨打时目标分散，甚至在序列内随机选择。
- 奶船优先选择自身序列内最先挨打的船；战斗开始最先挨打通常是超主力。
- 海氏追随者型-脉冲攻击机（原文为“海事”，疑似语音识别错误）放狩猎者级-战术载机巡洋舰（原文为“战术狩猎”，疑似简称）上，可开局灵锁摸超主力，使CAS066级-支援巡洋舰首奶落在超主力。
- 奶目标转移条件为目标满血或死亡；乱奶发生在第一个锁定的超主力死亡后。
- 战巡一般约5艘，无天赋时奶量难超对方输出量，战巡会死；战巡死亡后CAS066级-支援巡洋舰索敌丢失并开始乱奶。
- CAS066级-支援巡洋舰是巡洋舰，大船中较难死；专精反巡洋的船几乎没有，永恒风暴级-攻击战列巡洋舰（原文为“风暴”，疑似简称）、索姆河之影-装甲飞行坦克（原文为“索魔”，疑似语音识别错误）等通用反大散射难以击杀。
- CAS066级-支援巡洋舰定位偏保底；谷神星级-支援驱逐舰（原文为“股神/古神”，疑似语音识别错误）与海尔波普-维修支援护航艇（原文为“海尔波普”，疑似简称）偏上限，奶量更稳定但生存更差。
- 三者不是同定位奶船，应混搭使用，不能无脑带满CAS066级-支援巡洋舰。
- 谷神星级-支援驱逐舰是小船，反小火力面前易死；不点紧急维修会因血低暴毙。
- 用小船帮谷神星级-支援驱逐舰分伤会占人口，导致战巡等大船塞不下。
- 谷神星级-支援驱逐舰生存不如CAS066级-支援巡洋舰；瑶光级-通用护卫舰（原文为“瑶光”，疑似简称）套盾也会给CAS066级-支援巡洋舰套，不能因此说谷神赢066。
- 海尔波普-维修支援护航艇人口奶量比CAS066级-支援巡洋舰高很多，满编约等于6个CAS066级-支援巡洋舰。
- 天枢级-支援航空母舰（原文为“天枢级-支援航空母舰”，疑似语音识别错误）出来前，海尔波普-维修支援护航艇上CV3000级-快速航空母舰（原文为“CV”，疑似简称）并增援副队是最强增援单位。
- 海尔波普-维修支援护航艇易被防空火力干掉，只能靠挡刀机挡刀，整场存活基本不可能。
- 若对面没有防空，海尔波普-维修支援护航艇活得很好，但属个例不讨论。
- 副队无航母时，可适当用谷神星级-支援驱逐舰替换部分CAS066级-支援巡洋舰，提升奶量稳定性；谷神还有防空能力。
- 副队带海尔波普-维修支援护航艇时应增援航母；超主力数量多后减少CAS066级-支援巡洋舰数量。
- CAS066级-支援巡洋舰数量少后，其他大船可帮它分伤，弥补易被通用反大火力干掉的缺点。
- 天枢级-支援航空母舰是断层第一，不纳入比较。

## 配队与模块
- 海氏追随者型-脉冲攻击机搭载在狩猎者级-战术载机巡洋舰上，凑100索敌开局灵锁。
- 谷神星级-支援驱逐舰可点紧急维修策略：自身结构降至20%时无人机自修；不点则血低易暴毙。
- 副队无航母：适当用谷神星级-支援驱逐舰替换部分CAS066级-支援巡洋舰。
- 副队带海尔波普-维修支援护航艇：用CV3000级-快速航空母舰搭载并增援副队，同时减少CAS066级-支援巡洋舰数量。
- 可带开阳级-机动驱逐舰（原文为“开阳”，疑似简称）、瑶光级-通用护卫舰帮谷神星级-支援驱逐舰分伤/套盾，但会占人口，影响战巡等大船。
- 海尔波普-维修支援护航艇靠挡刀机掩护；但难以保证整场存活。
- 不推荐无脑带满CAS066级-支援巡洋舰。
- 天枢级-支援航空母舰不纳入比较。

## 数值与数据
- 海氏追随者型-脉冲攻击机自身30索敌 + 狩猎者级-战术载机巡洋舰70索敌 = 100索敌。
- 战巡一般约5艘。
- 谷神星级-支援驱逐舰巅峰8仅5万出头血量。
- 谷神星级-支援驱逐舰紧急维修触发阈值为结构值20%。
- 小船数量少于20时，谷神星级-支援驱逐舰非常容易暴毙。
- 海尔波普-维修支援护航艇满编奶量约等于6个CAS066级-支援巡洋舰。
- 海尔波普-维修支援护航艇约1-2分钟后必死。
