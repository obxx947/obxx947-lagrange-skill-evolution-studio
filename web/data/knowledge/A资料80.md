# A资料80

## 场景 / 对手
前期放弃速本追航母，选择拉出大毛（大帝级）的舰队配置，正面战斗，环境为前期星系战斗

## 舰队例子
- 大毛（大帝级）+奶船（台原股神、诺玛）+AC721+海尔波普（带满）（胜）【维修量达38万，大毛血量未掉，小船血量保持一半以上】

## 实战结果
我方以一艘海尔沃普换掉对方整支小船队，对方威胁性高的输出为轰炸机和海事，清掉我方奶船，但核心输出目标是大毛，奶船有效保存

## 结论思路
- 大毛前期威胁性高，因超高物理护甲，少有舰船能突破防御
- 大毛携带需讲究，建议侧击锁定敌方配置，否则维修成本和时间过长
- 配合队友打击可起最佳效果，避免被围攻
- 基地护盾存在期间，舰船无损耗打架，可百分百回家，护盾消失后正常计入战损比，前期打架无需顾虑战损比

## 适用限制
- 适用于前期放弃速本追航母、选择拉大毛的战术
- 大毛需配合奶船和侧击策略，避免被围攻
- 护盾期间可无损耗打架，护盾消失后需注意战损
