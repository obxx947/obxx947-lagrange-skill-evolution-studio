# A资料36

## 场景 / 对手
420人口主队配置推荐，以对舰为主，当前主流作战环境，需走极端（防空拉满或对舰拿满）

## 舰队例子
- 后排：混沌x8 + 猎兵x6（猎兵带800x14 + 星脉x10）；中排：风暴x1（旗舰/伤害补充）；前排：爱奥x6（高速型或技术型）（胜）【主队配置，对舰输出高，混沌和爱奥为巡洋最高输出，但需弥补缺陷】
- 支援航母带炮艇（800/星脉）时：主队中猎兵减少，下掉一个猎兵换重卡或光锥；猎兵带满星脉和列维（胜）【根据支援航母调整，重卡/列维补刀，但导弹易被拦截】
- 支援航母带星脉时：下掉列维，猎兵全换重卡（胜）【重卡补刀，但输出受拦截影响】
- 支援航母无炮艇（如13余、蓝十字）时：主队配置不变；若炮艇去轰炸，则下猎兵，上风暴x6，后排混沌x6，中排风暴x6，前排爱奥x6（胜）【风暴输出环境好，免疫拦截】

## 结论思路
- 混沌和爱奥是巡洋中输出最高的，适合主队核心
- 爱奥打闪避船能力弱，用星脉弥补；混沌不能补刀，用维蒂、猎兵、重卡等完成
- 核心输出点是混沌，爱奥可当前排，副盾战损后提供反应时间
- 配对思路要极端：要么防空拉满，要么对舰拿满，不能既要又要
- 猎兵带800和星脉，兼顾防空和对舰，比较全能
- 风暴作为旗舰和伤害补充，可替换
- 支援航母配置影响主队调整：有炮艇则减少猎兵，换重卡/光锥；无炮艇则主队不变或换风暴
- 重卡和列维导弹输出易被拦截，可换水母、鱼海等输出小船，增加曲率速度
- 配置根据作战环境灵活调整，轰炸多则多带空军

## 适用限制
- 适用于420人口主队，对舰为主
- 当前主流环境需走极端，不适合均衡配置
- 重卡/列维导弹易被拦截，需考虑对手拦截能力
- 支援航母类型影响配置，需根据实际情况调整
- 配置非无敌，需根据轰炸环境调整空军比例
