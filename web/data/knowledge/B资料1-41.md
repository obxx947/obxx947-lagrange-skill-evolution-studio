# B资料1-41 · 苍穹风暴队打航母队实况

> 场景：对面 C 位航母队（前排 CAS066/开阳级），己方苍穹队＋风暴扛伤队，正面交战

## 结论
- 普鲁图斯之盾级-防护战列巡洋舰（原文为"大盾"，疑似简称）是否在场是胜负关键：对手大盾被拆后己方基本胜局已定
- 大盾是每个配置必带；想保大盾只能多带战巡，带航母都不一定保得住
- 对手航母队很肉，但战巡分伤太少，战巡容易被集火，一被集火就没了
- 己方防空很差，没带多少防空
- 对手海尔波普全程存活，但活着也没用
- CV-T800型-脉冲炮艇（原文为"八百"，疑似简称）有一部分被拉去对舰，防空进一步变弱
- 永恒风暴级前期无法给自己加盾，加盾后前排能吃到，但自身依旧脆、掉血很平均
- 己方维塔斯-B010-轰炸机（原文为"VB"，疑似简称）火力打不到航母，只在对手 3~5 个目标间分散
- 己方没有策略后开始给自己加盾，依旧很脆
- 己方结构值反超对手，对手大盾已掉、航母被击沉，胜负已定
- 对手还剩航母，己方战巡先掉完，3 战巡拼 3 航母撑不住，选择撤退
- 对手航母血线仍太高；此时撤退已经赚，超主力打完就撤，之后要休整几天

## 配队与模块
- 己方主队（未变）：3 永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）＋6 永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）＋3 卡利斯托-重型鱼雷袭击舰（原文为"重卡"，疑似简称）补伤害＋2 狩猎者级-载机巡洋舰（原文为"狩猎"，疑似简称）
- 主队配置原文为"11逢13"（原文如此，含义未明）
- 苍穹队带维塔斯-B010-轰炸机与林鸮A100型-联合攻击机，点分散打击、火力分散
- 扛伤队继续测试永恒风暴级"高达队"
- 对手为 C 位航母队，前排 CAS066级-通用巡洋舰（原文为"六六"，疑似简称）与开阳级，带普鲁图斯之盾级
