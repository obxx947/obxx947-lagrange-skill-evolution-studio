# A资料204

## 场景 / 对手
平民玩家巡洋舰培养，常规舰队配置，输出与功能性选择

## 舰队例子
- 混沌离子巡洋舰（子型号）（胜）【输出可观，但遇到开阳瑶光出伤慢】
- 重卡巡洋舰（子型号）（胜）【优先打战巡，避开阳光组合干扰，但被拦截限制】
- 游骑兵离子巡洋舰（子型号）（胜）【体验服加强，打法数据略低于混沌，受阳光组合与拦截双重限制】
- 艾奥巡洋舰（A型）（负）【打大船强，遇闪避报废，工程型偷家和副本强】
- 奇美拉巡洋舰（A/B型）（负）【反小厉害，打闪避前排不弱，遇重甲无伤害】
- 狩猎/列兵巡洋舰（机库型）（胜）【机库加成接近航母，点数要求低，能集火超主力】
- 拦截/奶妈巡洋舰（如六六、玉衡）（胜）【抗伤队拼图，六六配重甲超主力，玉衡配开阳瑶光】
- 棕熊C型巡洋舰（胜）【降低被拦截率，针对光防】
- 玉衡B型巡洋舰（负）【掩护炮艇，作用不大，点数多才考虑】
- 白鳄/棕熊防空巡洋舰（胜）【提高碰瓷队防空能力，应对轰炸】

## 实战结果
平民玩家培养巡洋舰，输出优先选第一梯队（混沌、重卡、游骑兵），第二梯队偏科不推荐；功能性优先选狩猎/列兵或拦截/奶妈，抗伤队成型后考虑针对卡。整体以输出和抗伤为核心，未提及具体胜负次数。

## 结论思路
- 巡洋舰核心是功能性而非输出，培养方向需结合舰队作用
- 无输出战巡时，优先培养混沌、重卡、游骑兵作为下位替代
- 第二梯队巡洋舰输出偏科，如艾奥怕闪避、奇美拉怕重甲，不推荐
- 输出小船多时，只用第一梯队，开不出可不用巡洋舰输出
- 航母不行或载机位不够时，培养狩猎/列兵提供机库加成
- 输出队成型后，培养拦截/奶妈（六六、玉衡）补抗伤队
- 针对特定对手培养棕熊C（防拦截）或玉衡B（掩护炮艇）
- 碰瓷队应对轰炸，需抗伤队先成型，平民不宜优先培养
- 平民培养顺序：先保证输出，再搞定抗伤

## 适用限制
- 适用于平民玩家，蓝图和点数有限
- 输出巡洋舰受阳光组合（开阳瑶光）和拦截限制
- 第二梯队巡洋舰怕闪避或重甲，适用场景有限
- 碰瓷队需同盟质量高，个人未成型时不适用
- 玉衡B型作用不大，点数不多不建议培养
- 抗伤队未成型前，不建议培养碰瓷相关舰船
