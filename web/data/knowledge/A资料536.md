# A资料536 · 新版本护航舰队防空化配队

> 场景：新版本实战护航舰队，防空协同增强、轰炸削弱，盟战接轰炸

## 结论
- 防空协同效率增强与轰炸削弱，使护航地推舰队可与碰瓷防空舰队结合
- 大船原废防空模块增强后具备实战价值，甚至可能超越原核心模块
- 风暴D1离子炮打开阳收益低，可换D2提升接轰炸生存
- 主队中刺鳐、050等易被拦截且实战伤害小的载机可换防空机
- 舰队防空能力靠多个小幅增强叠加，整体防空自然提升
- 新版本轰炸伤害降低幅度不符合命中降低逻辑，疑似有额外调整
- 副队载机位可由干扰机、挡刀艇、奶艇换成防空机
- 主队没位置的800可去副队，兼具挡刀与防空
- 坦普尔在对方副队普遍有载机的环境下可上，血量厚可挡刀且干扰对空战影响大
- 有白垩的玩家可在主、副队各塞1-2个，20-40人口对整体配队影响不大
- 盟战接轰炸直接燕返对个人有利，但会破坏局部多打少，放大到整个盟战易崩盘
- 部分T1、T联盟已出现小船碰瓷增援、13鱼、怠慢空分等极端配队，甚至不要地推主队
- 极端配队未推广是考虑环境强度与接受度，故给出护航舰队增加防空能力的折中方案

## 配队与模块
- 普鲁图斯之盾级C2模块防空协同效率210
- 永恒风暴级B2、D2模块受防空协同增强影响大，防空协同效率250
- 永恒风暴级D1离子炮可换D2
- 主队载机可换砂龙、雷火V022-轻型战斗机（原文为"雷火"，疑似简称）等防空机
- 鹈鹕C为小船中防空协同效率增强最大受益者
- 氪佬雷火的范围拦截可用于防空，防空协同效率高
- 副队可放雷火V022-轻型战斗机、砂龙
- 800可放副队，点满约一万血量，兼具挡刀与防空
- 坦普尔可放副队，血量厚可挡刀，干扰对空战影响大
- 白垩可在主、副队各塞1-2个
