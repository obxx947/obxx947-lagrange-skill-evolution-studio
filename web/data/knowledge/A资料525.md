# A资料525 · 拉格朗日武器类别与伤害类型

## 结论
- 直射武器通过轨道结构加速炮弹射击，攻击力高，但受阵型阻挡，优先攻击敌方前排
- 投射武器通过制导系统投射攻击，攻击灵活，可无视阵型阻挡，对中后排船只造成杀伤
- 大部分火炮、轨道炮、脉冲炮和离子武器属于直射武器
- 导弹、鱼雷等武器属于投射武器
- 等离子体武器有直射和曲射两种，康纳马拉混沌级-高速等离子体巡洋舰（原文为"康纳马拉混沌b型"，疑似简称）装载的是直射型等离子体武器
- 永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）的M2主武器是投射型等离子体武器，属于特例
- 实弹伤害通过弹丸高速动能冲击或高爆炸药爆炸，对舰船结构造成直接形变打击
- 实弹伤害可理解为动能伤害或物理伤害，会被船只装甲抵消部分
- 大部分火炮、轨道炮、导弹和绝大部分鱼雷的伤害类型为实弹伤害
- 能量伤害通过高能粒子流轰击或等离子弹药投射，对舰船造成无视厚重装甲的热能伤害
- 能量伤害会被能量护盾抵消部分
- 离子炮、脉冲炮等等离子体武器的伤害均为能量伤害
