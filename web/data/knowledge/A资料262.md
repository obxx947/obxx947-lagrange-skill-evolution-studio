# A资料262

## 场景 / 对手
萌新舰船搭配，护航体系，正面作战

## 舰队例子
- 卡莉侦察（前排抗伤）（胜）【作为前排吸收伤害】
- 艾奥（两个型号，输出）（胜）【容易培养，输出核心】
- 风暴（航母，护航）（胜）【提供护航和输出】
- 水母（奶船）（胜）【补充奶量】
- 苔原（奶抗伤）（胜）【兼顾奶量和抗伤】
- 066（新手手册50级获得）（胜）【补充抗伤】
- FP-59（新手手册获得）（胜）【补充输出】
- 太阳奶（奶船）（胜）【最终补位】

## 实战结果
萌新搭配护航体系，未提及具体对战，但整体配置合理，胜率较高

## 结论思路
- 队伍需包含扛伤、输出和奶船
- 优先使用容易培养的舰船如艾奥
- 护航体系适合航母和输出舰船
- 奶船如水母、苔原、太阳奶保证续航
- 新手手册奖励舰船如066、FP-59可补充战力

## 适用限制
- 适用于萌新阶段，舰船蓝图有限
- 护航体系需有航母或护航舰船
- 奶船数量需充足，否则续航不足
- 不适用于高战对抗，需逐步升级
