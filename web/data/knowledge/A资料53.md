# A资料53

## 场景 / 对手
320人口扛伤队配置推荐，当前环境轰炸居多，本配置对轰炸无抵抗能力，走极致抗伤路线

## 舰队例子
- 前排：7卡特 + 10牺牲基础；中排：1大盾或大毛（旗舰）+ 10零六六奶；支援：3光防 + 2六六（胜）【极致抗伤，能扛，但被轰炸锁住则等死】

## 实战结果
320人口阶段，66奶很强，无针对火力，前排扛住则中排战巡全程吃到维修；后期420人口，66奶维修分散劣势凸显

## 结论思路
- 320人口资源紧张，只带一个战巡，用巡洋奶，容错低，被绝育后失效
- 66奶会奶歪，但320人口阶段很少存在足够火力分散到巡洋舰，断奶效果差
- 断奶逻辑是火力分散打巡洋舰，但战巡输出队（风暴、大地）资源需求大，320阶段少见
- 普卡和海事断奶效果差，尤其海事单一火力针对巡洋舰无用
- 320人口输出配置以混沌和IO为主，被前排卡特和牺牲基础限制
- 66奶在320人口中期很强，无针对火力，后期420人口维修分散劣势凸显

## 适用限制
- 对轰炸无抵抗能力，适合纯抗伤路线
- 前期资源紧张，战巡容错低，战损影响大
- 被轰炸锁住则等死，需厌烦战术频繁往来前线
- 320人口阶段适用，后期420人口不适用
