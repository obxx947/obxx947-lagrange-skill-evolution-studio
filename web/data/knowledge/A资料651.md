# A资料651 · 艾奥高速型对闪避小船测试

> 场景：现版本、以10个开阳作靶船的闪避小船打击测试

## 结论
- 打闪避小船的排名：混沌离子第一，艾奥高速型第二，游骑兵离子第三，艾奥基础型基本不考虑
- 打开阳战报看，艾奥高速型明显优于艾奥基础型
- 混沌离子的优势来自调校策略，不点策略时与艾奥高速型基本持平
- 游骑兵离子仅排第三档，强度低于预期
- 艾奥基础型人口性价比很低，基本不予考虑
- 此前认为艾奥高速型很垃圾属于主观判断，本期实测推翻了该结论
- 作者就此前的误导向观众道歉，表示以数据为准
- 往期舰船测试会重新调整、优化测试条件，以匹配现有作战环境

## 配队与模块
- 测试组：被测主船 + 8艘星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）（星脉）补充伤害，靶船为10个开阳
- 混沌离子调校了策略（增加持续时间）；艾奥高速型也点了策略，但调校增强的是闪避率

## 数值与数据
- 艾奥高速型：清理10个开阳耗时6分钟，输出为星脉的两倍以上，其中离子炮伤害占约70%
- 艾奥基础型：清理10个开阳耗时8分49秒，比艾奥高速型多近3分钟；144人口输出不如40人口的星脉
- 混沌离子：耗时5分09秒，比艾奥高速型快约1分钟，伤害也更高；不点策略时比艾奥高速型多9秒、伤害略低
- 游骑兵离子：清理10个开阳耗时7分21秒，伤害略高于星脉，离子炮伤害占约70%
