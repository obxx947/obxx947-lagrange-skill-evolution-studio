# B资料1-45 · 永恒风暴C2多战巡实战

> 场景：对手阳光抗察队（开阳+瑶光）；正面舰队战；后期多超主对抗

## 结论
- 前排乌拉诺斯之矛（原文为“大毛/大矛”，疑似简称）硬吃伤害，中排永恒风暴级-攻击战列巡洋舰（原文为“风暴/C2风暴/CR风暴”，疑似简称/语音识别错误）C2加盾，3艘光锥级-区域防空巡洋舰（原文为“光防”，疑似简称）提供拦截，CAS066级-支援巡洋舰（原文为“六六/零六六”，疑似简称）奶。
- 永恒风暴级C2核心是护盾提供的能量闪避：基础15%，调校+10%，策略前60秒+15%，单风暴前60秒给目标40%能量闪避。
- 永恒风暴级护盾/抗性buff可叠加，多风暴覆盖全超主；4风暴可给5乌拉诺斯之矛叠到12层，并覆盖普鲁图斯之盾级-防护战列巡洋舰（原文为“大盾”，疑似简称）和风暴自身。
- 主流伤害为能量，超主力与抗伤战巡普遍缺能量抗性；除电磁大剑和电磁ST59级-防御战列巡洋舰（原文为“五九/59”，疑似简称）外，永恒风暴C2抗性是刚需。
- 多战巡分摊优势明显：11战巡14分摊，敌方集火难秒；单战巡或6战巡队伍易被集火秒。
- 乌拉诺斯之矛单战巡弱势，没有普鲁图斯之盾级强；敌方失去大盾后乌拉诺斯之矛掉血很快。
- 永恒风暴级放副队可免疫大盾30%减伤，伤害更高；主队空出人口带卡利斯托-重型鱼雷袭击舰（原文为“重卡”，疑似简称）拉上限。
- 永恒苍穹级-无人机航空母舰（原文为“苍穹/C一苍穹”，疑似简称/语音识别错误）C1分散打击导致火力雨露均沾，集火差；打阳光配置影响小，打高达队难。
- 永恒苍穹级C1加点必须点返回，不要点伤害，点频率/返回很强。
- 多超主配置不易奶歪；小船队换战损、资源有优势，但后期上限低，大矿车出来后不必用小船。
- 后期建议基地搬到对面脸上、机库拉满不造船，只玩换战损/资源；小船只是炮灰，开阳/瑶光无伤害，拉上限不够。
- 没天枢级-支援航空母舰（原文为“天枢级-支援航空母舰”，疑似语音识别错误）可用CAS066级-支援巡洋舰替代；没核心模块/航母点也可玩半高达。
- 首次尝试该思路效果不错，练度低于对手仍打赢；敌方阳光抗察队靠开阳前排、瑶光后排。
- 己方未激活小船火力，敌方开阳/瑶光存活强；永恒风暴C2前60秒强，1分钟后全覆盖也强。
- 永恒风暴C2 buff锁定逻辑不明，但实战可全超主覆盖。

## 配队与模块
- 己方总配置：6艘乌拉诺斯之矛（5艘支援前排+主队1艘）、1艘普鲁图斯之盾级-防护战列巡洋舰（白板旗舰，血量未满）、4艘永恒风暴级-攻击战列巡洋舰C2（中排/副队核心）。
- 乌拉诺斯之矛加点：只点抗性，护甲点满，少点1护甲、多点1血量提高容错，防被秒。
- 永恒风暴级C2加点：护盾与M2点满，装甲系统未点满/未点血量；核心是护盾与策略。
- 拦截与奶：3艘光锥级-区域防空巡洋舰+9艘CAS066级-支援巡洋舰；无拦截模块，用光锥提供拦截。
- 己方主队：3艘CV3000级-快速航空母舰（原文为“CV”，疑似简称）带CV-T800型-脉冲炮艇（原文为“八百/八佰”，疑似简称/错字）和坦克；2艘永恒风暴级；6艘卡利斯托-重型鱼雷袭击舰填人口；4艘猎兵级-重型载机巡洋舰（原文为“猎兵”，疑似简称）带米斯特拉-战斗攻击机（原文为“小米/新麦/星迈/星败”，疑似简称/语音识别错误）；若干CV-T800型-脉冲炮艇、2艘狩猎者级-载机巡洋舰（原文为“狩猎”，疑似简称）。
- 己方航母队：5艘永恒苍穹级-无人机航空母舰，10架林鸮A100型-联合攻击机、维塔斯-B010-轰炸机（原文为“维B/VB/违币”，疑似简称/语音识别错误）、刺鳐-鱼雷轰炸机（原文为“刺瑶/赐瑶”，疑似语音识别错误）；5架米斯特拉-战斗攻击机。
- 敌方：典型阳光抗察队，前排开阳级-机动驱逐舰（原文为“开阳”，疑似简称），后排瑶光级-通用护卫舰（原文为“遥光/摇光”，疑似语音识别错误/错字）；支援5艘满配乌拉诺斯之矛（中排奶矛）。
- 敌方主队：普鲁图斯之盾级-防护战列巡洋舰白板旗舰；3艘光锥级-区域防空巡洋舰+9艘CAS066级-支援巡洋舰；3艘永恒苍穹级、6艘永恒风暴级、3艘卡利斯托-重型鱼雷袭击舰；舰载机含11或13架米斯特拉、坦克、维塔斯-B010、米斯特拉等。
- 模块/加点关键词：C2风暴、M2、护盾、策略、调校、返回、分散打击、分散进攻、前60秒。
