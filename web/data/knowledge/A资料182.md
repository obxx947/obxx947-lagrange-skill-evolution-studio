# A资料182 · 副本刷怪打榜配置

> 场景：副本刷怪榜

## 结论
- 堆满舰载机的配置后期舰载机掉太多，且强力舰载机有限
- 把没用的舰载机优化出去，换上大地
- 大地模块有什么用什么，并非最优解
- 用载机模块带防空舰载机可能更好
- 这种打榜必须带天枢级-支援航空母舰（原文为"天书"，疑似语音识别错误）
- 高巅峰账号或许能硬抗配队，但没条件尝试
- 排行榜按对舰加对空伤害排名，要带一些防空
- 祝兄弟们战利品都能开出指战箱子

## 配队与模块
- 五个大帝
- 一鱼两天枢级-支援航空母舰支援剑
- 支援剑没啥模块就用送的
- 海尔B型号奶量不错
- 每天输奶量不够会掉大地
- 带围蔽小米加海尔币多的位置
- 带几个艾提干扰
