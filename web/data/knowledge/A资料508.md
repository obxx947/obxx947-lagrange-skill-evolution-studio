# A资料508

## 场景 / 对手
1+1左右大众玩家护航问题，前排战群与前排小船抉择，直射与超展路线选择，扛伤战群选择

## 舰队例子
- 59盾（无附加模块）作为主抗战巡，无溜溜奶，不完整残图（负）【被夹击，战损较大，无附加盾无资格作为主抗战巡】
- 前排毛（59盾）（负）【强度低，战损比对方大，被CV玩家直射队伍打出高战损】
- 超展（古法超展）配列兵带艇（800、蜂巢、列为）（负）【超展打不动中排战群，分伤低，蜂巢列为被拦截，亏人口】
- 直射巡洋（艾欧泡泡龙）（胜）【两条泡泡龙12万伤害，上满四条可近60万，能斩前排毛】
- 盾（无附加）作为主队（负）【守家被闷，副队全灭，主队炸3条鱼，无附加盾不可用】

## 实战结果
粉丝（CV玩家）被夹击，对方前排毛，粉丝直射队伍战损优于对方；守家战报中粉丝被闷家，副队全灭，主队损失3条鱼；对方超展（重卡大帝）打粉丝队伍，4分钟出伤200万，分伤不足70万

## 结论思路
- 前排战群强度低，前排毛尤其弱，直射队伍可有效打击
- 1+1玩家应坚持直射路线，超展无法穿透中排战群
- 开阳瑶光体系克制直射，但直射仍可应对多数前排毛玩家
- 列兵补艇只建议补800，蜂巢列为不建议带，因被拦截且亏人口
- 扛伤战群推荐电磁59或附加盾，无附加盾用矛需点站位

## 适用限制
- 适用于1+1左右大众玩家
- 直射路线在对方使用前排毛时有效
- 超展仅对脆中排战巡可能有效，正常会玩玩家不可行
- 无附加盾不可作为主抗战巡，需配主抗战群
- 矛必须点站位，否则送
