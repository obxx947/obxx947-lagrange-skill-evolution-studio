# A资料633 · 天枢航母副队战报：打不动

> 场景：对手天枢级支援航母抗伤配置；投射/直射混合环境

## 结论
- 天枢级支援航空母舰组成的副队达到叹息之墙级别，正面打不动。
- 我用整队接近全灭的代价，仅换掉对方1艘天枢级支援航空母舰和1艘安东塔斯持剑者级-指挥舰（原文为"大剑"，疑似简称）。
- 若对方旗舰给普鲁图斯之盾级-防护战列巡洋舰（原文为"大盾"，疑似简称），连安东塔斯持剑者级-指挥舰都换不掉。
- 投射火力打不动天枢：断奶无效，天枢血量太高，短时间斩不掉，奶量转火后又能奶回。
- 投射火力集中打天枢连战损都打不出来；打战巡还能打出战损。
- 直射被开阳级-机动驱逐舰（原文为"开阳"，疑似简称）闪避限制，瑶光级-通用护卫舰（原文为"瑶/遥光/姚光"，疑似简称）克制康纳马拉混沌级。
- 直射还需面对玉衡级-支援巡洋舰（原文为"御衡/预横"，疑似语音识别错误）的奶量和开阳级-机动驱逐舰血量，击穿前排不现实。
- 对方配置完全克制输出：直射躲不开开阳/玉衡/瑶光，投射躲不开天枢。
- 战巡放前排可解决奶量分散问题，奶量大部分集中在战巡上。
- 之前用电磁布局前排太脆，反响不好；用奶量硬拼也拼不过。
- 断奶只针对CAS066级-支援巡洋舰（原文为"六六奶/六六/66"，疑似简称），针对不了天枢，带断奶也没用。
- 没有天枢航母，任何高达配置一对一都打不赢对方天枢抗伤配置，即使对方配得差。
- 小船队扛不住：纯小船对约3分钟死完前排；带少量战巡加奶妈5分钟内必死。
- 只有纯高达队能勉强支撑约6分钟，前提是奶量不分散。
- 我方副队扛6分多钟，强度算高；小船顶天5分钟。
- 对方旗舰错误给安东塔斯持剑者级-指挥舰，若给普鲁图斯之盾级-防护战列巡洋舰，我方伤害可能只有600多万。
- 对方用枪骑兵级-区域防空驱逐舰（原文为"枪房"，疑似语音识别错误）针对我方舰载机（原文为"建奶机/建仔机"，疑似语音识别错误），效果明显。
- 海尔波普-维修支援护航艇不处理奶量会非常夸张，需用战机处理。
- 刺鳐-鱼雷轰炸机（原文为"次摇/次瑶"，疑似语音识别错误）打超主力不行，但打小船伤害高，带它是为了反小。
- 永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）伤害上限低，不如B192新大地有暴击提升上限。
