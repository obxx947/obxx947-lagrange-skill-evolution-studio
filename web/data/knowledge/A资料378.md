# A资料378

## 场景 / 对手
直射队实战，对手为前排开阳，正面作战，环境为后期主力对抗

## 舰队例子
- 大毛（A2+C1模块，半血以下进入舰队，主C，420人口），数量1，结果：胜，备注：高单发直射，高命中，不怕阳光，大小通吃
- 猎兵（超斩可选，反小狩猎），数量1，结果：胜，备注：输出补充
- 混沌（补伤害），数量1，结果：胜，备注：补伤害
- 零五、零V A（反小区列），数量若干，结果：胜，备注：快速穿防
- 狩猎（6个大毛作为直射，可少带两个上L高速），数量6，结果：胜，备注：直射主力，可调整
- 舰载机（RB7/011/天枪，可选），数量若干，结果：胜，备注：看个人选择

## 实战结果
直射队对前排开阳，三分钟前无有效伤害，三分钟后穿防爆发，战损快速，锁锚创造两分钟打击窗口，最终获胜

## 结论思路
- 直射队有爆发阈值，三分钟是分界线，前排开阳三分钟前打不出伤害，三分钟后穿防爆发
- 锁锚是核心细节，创造两分钟打击时间，用于打战损
- 主C只有大毛能胜任，需A2+C1模块，半血以下进入舰队
- 大毛抗性不如大盾天权，但输出穿防效率高，优于混沌艾尔（被瑶光克制）和奇美拉光追（小船打完报废）
- 直射队需投入至少200人口以上才能有较好穿防效率
- 配置是模板，可举一反三调整

## 适用限制
- 适用于后期主力直射队，对手为前排开阳
- 大毛必须半血以下进入舰队，否则效果不佳
- 需至少200人口投入直射，否则穿防效率差
- 混沌艾尔被瑶光克制，不适合作为主C
- 奇美拉光追反小但小船打完报废，影响战斗力
