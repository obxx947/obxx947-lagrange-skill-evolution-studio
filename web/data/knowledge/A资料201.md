# A资料201 · 副队单战巡抗伤搭配思路

> 场景：副队抗伤/单战巡

## 结论
- ST59无重甲时一律放中排，增加存活时间并吸引直射与超斩
- ST59重甲700多物抗可前突，硬扛对方物理直射
- 没有风暴C2尽量不要让ST59前突
- 乌拉诺斯之矛一定不要前突，点中台策略老实待在中台
- 乌拉诺斯之矛用锁锚策略可多吃驱射伤害，多活一会
- 普鲁图斯之盾作旗舰时舰队整体减伤30%
- 普鲁图斯之盾全部前突不好，旗舰容易被超斩斩掉
- 天权非常不建议单独使用，其掩护护航艇提高自身坦度的机制不适合单独上场

## 配队与模块
- ST59无重甲放中排，中排配光锥级-区域防空巡洋舰（原文为"光防"，疑似简称）和CAS066级-支援巡洋舰（原文为"66奶"，疑似简称）
- ST59重甲前突充当前排
- 普鲁图斯之盾设两个生产方案：武盾集体前突，仅留一条旗舰盾防守中排
