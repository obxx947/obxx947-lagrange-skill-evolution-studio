# A资料32

## 场景 / 对手
鱼海级护卫舰解析，含主型号与子型号对比，正面作战环境

## 舰队例子
- 鱼海级护卫舰主型号（主武器系统+装甲系统+机动作战）（胜）【生存能力优异，前期扛伤和输出能力提升】
- 鱼海级护卫舰子型号（主系统+装甲系统）（胜）【输出爆发高，生存能力下降，适合副队】

## 实战结果
鱼海级护卫舰配合水母和卡特在前中期打出高战损比，主型号和子型号均表现优异

## 结论思路
- 主型号生存能力优异，子型号后期爆发高，实弹伤害转为能量伤害
- 主武器系统和装甲系统必点，副系统无需加点，指挥系统机动作战必点
- 子型号加点方案统一，主系统和装甲系统加点即可
- 子型号造价略高但可接受，适合作为副队输出船
- 鱼海级护卫舰是万金油舰船，可配合水母和卡特打出高战损比

## 适用限制
- 适用于前中期配置，配合水母和卡特效果佳
- 子型号生存能力下降，需注意保护
- 对舰载机打击能力无实质增幅，不适用于防空场景
