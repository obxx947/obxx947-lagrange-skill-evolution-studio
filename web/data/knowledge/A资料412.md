# A资料412

## 场景 / 对手
天书队 vs 战巡队，六分钟战斗，正面冲突，环境为常规PVP

## 舰队例子
- 大盾旗舰（重甲）+ 2风暴C3（做八三分摊）+ 光锥 + 玉衡 + 2六六 + 开阳 + 瑶光（阳光扛伤队）（胜）【大盾存活5分40秒，开阳存活近5分钟，有效分摊伤害】
- 5天书（A1双维修，缺重甲）+ 次摇小米天玄 + 5大毛（中奖包前排）+ 大盾旗舰 + 风暴C2 + 光锥 + 白鳄 + 2六六 + 开阳（负）【大毛3分23秒全灭，输出仅454万，风暴投射与混沌直射混编导致伤害不足】
- 鱼仓队（鱼+十三十一+坦克新卖）+ 苍穹风暴混沌（胜）【输出767万，大毛在前排参与有效伤害】

## 实战结果
右边天书队（5天书+5大毛） vs 左边战巡队（大盾+风暴+开阳等），右边血量多100多万但输出不足，左边以767万输出获胜，右边仅454万。关键损失：右边大毛3分23秒全灭，左边大盾存活5分40秒。

## 结论思路
- 副队配置要么前排纯超主（靠风暴C2加buff），要么纯小船（大毛中排分摊），避免混编
- 风暴C2需带2个以上，提供能量闪避（25%），对抗混沌等能量输出
- 开阳在前排有大毛时意义不大，应换成同人口风暴
- 输出队避免直射与投射混编，风暴配重卡，混沌配IO
- 小米是空军主C，应放主队，副队用沙龙或包子
- 白鳄性价比低，可用绝育或天玄干扰替代

## 适用限制
- 适用于战巡前排与天书队对抗场景
- 不适用于敌方大毛在中排时（战鼓效果受限）
- 需注意敌方开阳数量，少时配置更易获胜
- 避免在副队使用小米，以免浪费主C能力
