# A资料622

## 场景 / 对手
对手/体系：前排大船多的队伍，常见于刻度善来的单挑；正面/轰炸：正面输出；环境：有旗舰盾减免伤害

## 舰队例子
- 子战（M1离子炮、工程无人机、C2离子炮塔、D2投射导弹、普通装甲、普通动力、离子强化装置、H1脉冲炮）（胜）【实战中打198万伤害（扣除系统伤害），dpm约1253，加点未满，仍有提升空间】
- 大建（反小配置，加点基本满）（胜）【打157.7万伤害，dpm约1283，略高于子战】

## 实战结果
号主与Mok g老哥对战，子战打198万（扣除系统伤害），dpm 1253，大建打157.7万，dpm 1283；子战加点未满，最佳状态伤害可超大建；子战在无盾减免时dpm约1500-1600

## 结论思路
- 子战拥有全游戏最多模块组，但反小船能力孱弱，适合打大船
- M1离子炮优先反大，反小命中差，M2投射易被拦截，选M1
- A1/A2小型投射武器不适合反小，需测试选优
- B模块选工程无人机，工程鱼雷无单发和训爆伤害，不适合打人
- C1离子炮塔虽标反小但数据差，C2优先反大更优
- D模块选D2优先反大的投射，单发伤害高
- E模块选普通装甲，优于帝国式装甲（血量、抗性更高）
- 动力系统选普通动力，帝国动力数值更低
- J模块选离子强化装置，提升离子炮伤害，优于附加装甲
- H模块选H1脉冲炮，能打一点伤害，H2实弹投射防空无效
- 子战输出与大建同级，加点优化后略高，dpm约1500-1600
- 子战适合前排大船多的队伍，如刻度善来单挑副队

## 适用限制
- 不适合反小船，反小伤害低且命中差
- 依赖大船环境，无大船时输出乏力
- 离子炮缺命中，加点需优先命中
- 投射武器易被拦截，需避免使用
- 帝国模块（装甲、动力）性能差，不推荐
