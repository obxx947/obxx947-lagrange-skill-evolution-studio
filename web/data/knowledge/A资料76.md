# A资料76

## 场景 / 对手
诺玛吉舰船解析，护卫篇最后一艘，针对敌方基地和海盗建筑群，支援型维修能力贯穿赛季中前期

## 舰队例子
- 四水母卡特 + 诺玛（胜）【中前期最标准配置，后续可能换驱逐舰】

## 实战结果
无具体实战记录，主要介绍诺玛吉在前期对建筑伤害和支援型维修能力，配合卡特等小船队提高站桩能力

## 结论思路
- 诺玛吉新手阶段效果不俗，超高对建筑伤害，抽到后作为针对敌方基地和海盗建筑群的大杀器
- 支援型可最大化效果，贯穿赛季中前期，维修能力数一数二，拥有两次维修强化和三次冷却强化
- 常见配置配合四水母卡特和诺玛，组成中前期标准配置，后续可能换驱逐舰但为追航母少点驱逐板块
- 没有六六奶时可与其他奶船编队，提高大毛或大盾站桩能力，是六六下位替代之一
- 小船队扛伤主力，配合高闪避舰船如卡特、你演，因小船攻击序列和巨舰大炮锁敌效率低，上场效果更好

## 适用限制
- 适用于新手阶段和中前期赛季
- 适用于针对敌方基地和海盗建筑群
- 适用于缺乏六六奶时的替代方案
- 适用于小船队扛伤和高闪避舰船配合
- 不适用于后期驱逐舰板块已开发的情况
