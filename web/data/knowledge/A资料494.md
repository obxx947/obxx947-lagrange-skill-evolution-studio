# A资料494

## 场景 / 对手
南石（南十字）航母在无C2苍穹玩家中的使用，涉及护航和轰炸，环境为PVP战斗

## 舰队例子
- 南石（双航母）+ 鱼（挺难增援14鱼），模块：无C2，可能含CE（胜）【形成T2级别轰炸，圈够，适合普通玩家】
- 单航母南石 + 鱼（无CE模块）（胜）【老实玩时机南石，吃鸡打法，双航也可】
- 双航母南石 + 林宵 + VA（纯输出），模块：CE（胜）【暴力输出，不放VB以避免分伤和越过前排】
- 双航母南石 + 挺难 + 坦破尔（干扰型）（胜）【干扰敌方围蔽，适合护航】

## 实战结果
南石在护航和轰炸中表现良好，双航母纯输出可有效打击，但需注意VB的负面效果；具体胜负未详述

## 结论思路
- 南石适合无C2的苍穹玩家，用于护航或轰炸
- 开轰炸配合鱼时，二加二配置（双航母+鱼）可形成T2轰炸
- 单航母无CE时，应使用时机南石（吃鸡打法）
- 双航母追求暴力输出，主队放林宵和VA，不放VB以避免分伤和越过前排
- 护航时可用挺难和坦破尔干扰型，干扰敌方围蔽
- 开轰炸时优先加点特定模块（三个优先加）

## 适用限制
- 适用于无C2的苍穹玩家
- 单航母时需无CE模块，否则需调整
- 双航母时避免放VB，否则影响清前排速度
- 护航时需搭配干扰型船只（如坦破尔）
