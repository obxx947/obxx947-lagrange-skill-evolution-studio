# A资料431

## 场景 / 对手
正面扛伤，对抗能量武器，环境为舰队战

## 舰队例子
- 战巡+支援共8艘，八三分摊；旗舰大盾，额外2艘风暴（C3模块）；瑶光、玉衡、太阳三件套，玉衡2-3艘；2艘光锥拦截；6艘六六奶妈；剩余人口换战巡（胜）【优化版，提高超主力生存，克制能量武器】

## 实战结果
粉丝配置优化，未提及具体对战，关键得失为奶量降低但稳定性提高

## 结论思路
- 八三分摊提高超主力生存能力
- 风暴用C3不用C2，更好分伤和克制能量武器
- 玉衡带2-3个即可，避免浪费人口
- 光锥需求不大，可少带或不带，必要时减少御魂增加光锥
- 六六奶妈带6个，多余人口换战巡，提高抗性和稳定性
- 六六重要性前提是核心要素完备，低刻度玩家可带满

## 适用限制
- 适用于高刻度玩家，核心要素多
- 低刻度玩家可带满六六
- 避免二极管思维，根据作战环境决定
