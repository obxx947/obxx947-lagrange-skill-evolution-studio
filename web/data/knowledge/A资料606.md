# A资料606

## 场景 / 对手
针对灼热级SP驱逐舰的反小能力测试，对手为开阳、阋装甲、阋火炮、卡特等前排抗伤舰船，环境为常规战斗模拟

## 舰队例子
- 灼热级SP驱逐舰（主副武器反小直射火炮，6人口）×10（胜）【测试用，针对不同抗伤舰船】
- 开阳（抗伤舰船）（负）【存活时间最长，约13分钟被摧毁】
- 阋神星（装甲型/火炮型）（负）【两种型号生存时间相近】
- 卡特（抗伤舰船）（负）【存活时间最短，约5分钟被摧毁】

## 实战结果
灼热级SP对开阳、阋神星、卡特等抗伤舰船进行测试，每场至少两战，全部获胜；关键得失为灼热级SP反小效率高，摧毁时间5-13分钟，优于艾奥对舰和奇美拉的反小效果，且实弹伤害不受瑶光辅助影响

## 结论思路
- 灼热级SP反小强度高，至少T1级别
- 主副武器反小直射火炮，优先攻击前排，适合针对开阳等强势前排
- 6人口性价比高，优于资产版15人口的灼热级重型火炮突击舰
- 实弹伤害对瑶光辅助的抗伤舰船仍有效

## 适用限制
- 获取门槛高，需在进化协议中收集大量碎片研究获得
- 仅适用于反小场景，对大型舰船效果未知
- 测试基于10艘灼热级，数量不足时效果可能下降
