# A资料286

## 场景 / 对手
控制作业，涉及开拓者、银海、诺玛、云海，控城环境

## 舰队例子
- 10个银海 + 诺玛 + 云海（控制配对）（胜（控制效率提升））【诺玛不直接参与控制，但提高整体控制效率】
- 10个云海（无诺玛）（负（控制效率慢））【控城时效率低，可能达到战斗时间上限】

## 实战结果
主播控制配对中，带诺玛的配置优于纯云海，关键得失是诺玛提升控制效率，避免因时间上限导致撤退

## 结论思路
- 诺玛虽不直接参与控制，但能提高控制效率
- 纯云海控制效率慢，尤其在控城时
- 单场战斗时间上限为两个半小时，超时自动撤退

## 适用限制
- 适用于控制作业场景
- 需注意战斗时间上限，避免超时
