# A资料701

## 场景 / 对手
护航艇体系，主队副队，正面/轰炸，当前环境

## 舰队例子
- 坦克星（护航艇，数量未指定）（胜）【越早拿出越好，强势期长】
- 星云弹炮（护航艇，数量未指定）（胜）【与坦克星同排，无持续时间，对舰机器，超速，挡刀能力强】
- 天机八百（护航艇，数量未指定）（胜）【唯一剑无人机，凌驾于机制之上，挡刀最佳，但掉得最凶，需跟在海尔波普后】
- 野花一七幺（护航艇，数量未指定）（胜）【无持续时间，适合轰炸，强度高】
- 曼海尔（护航艇，数量未指定）（胜）【需有空军后使用，奶船，限制对方回血】
- 海尔波普A/B（护航艇，数量未指定）（胜）【两型号都强，无巡洋时奶量夸张，有巡洋时A型暂缓】
- t八百（护航艇，数量未指定）（胜）【仅限制对方海尔波普回血，不能不上也不能不下】
- 野火二b七（sp型号，护航艇，数量未指定）（胜）【反小能力强，上手门槛高，与蜂巢不冲突】
- 瑶（sp型号，护航艇，数量未指定）（胜）【反小能力强，上手门槛高】
- 分槽（护航艇，数量未指定）（胜）【前期强势，适合新手，后期不适合】
- 列为九号（护航艇，数量未指定）（胜）【中期昙花一现，需点满冷却和锁定才能发挥】

## 实战结果
谁打谁未明确，几胜几负未明确。关键得失：天机掉得最凶，分槽前期贡献五分之一伤害，列为九号需满配否则无力

## 结论思路
- 护航艇只有能用和不能用，不搞t0/t1/t2
- 坦克星、曼海尔、天机八百、野花一七幺、列为九号、分槽优先考虑
- 零零三四零和零幺幺优先级低，点数不充裕先不碰
- 顺序代表生涯和赛季制造顺序，强度分五常
- 野火二b七和瑶有上场空间但门槛高
- 分槽和列为九号适合新手，强势期短
- 海尔波普需有空军后使用，t八百限制对方回血
- 天机是挡刀最佳，因无持续时间、对舰机器、超速
- 星云弹炮和星云脉冲无持续时间，但不如天机挡刀
- t八百不能不上也不能不下，仅限制回血
- 海尔波普A/B在无巡洋时奶量夸张，有巡洋时A型暂缓
- 野火二b七和蜂巢不是上位替代，使用时段不同
- 蜂巢有自己使用场景，坦克和蜂巢才是上位替代
- 分槽前期暴杀，后期不适合就不炸
- 列为九号需点满冷却和锁定，否则打不出伤害

## 适用限制
- 点数不充裕时，先点优先船，再考虑零零三四零和零幺幺
- 海尔波普需有空军支持，否则纯奶船无用
- t八百仅用于限制对方回血，不提供额外加成
- 野火二b七和瑶需一定规模才能发挥
- 分槽适合前期，后期不适合
- 列为九号需满配（冷却、锁定）否则无力
- 海尔波普A在队伍有巡洋时暂缓使用
