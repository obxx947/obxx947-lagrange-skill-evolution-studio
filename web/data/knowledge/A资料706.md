# A资料706

## 场景 / 对手
顶客玩家第三阶段护航内战，正面战斗

## 舰队例子
- 5天权+5盾+1雷神+4CBB+5天书（负）【前排天权死伤惨重，中排盾几乎无伤，分伤配置不合理】
- 6天权+4毛（或5毛+3盾）（胜）【前排毛与天权共同分摊，保护空战，提升生存】
- 单战巡+CV3000（胜）【CV3000替代五九，分摊伤害，血量高，适合副队】

## 实战结果
粉丝投稿多张战报，分析第三阶段护航队配置问题，指出前排天权死亡快而中排盾存活，因分伤分配不当，推荐调整前排配置

## 结论思路
- 第三阶段护航队需大量超主力堆积分伤，提高抗风险能力
- 前排应使用毛与天权共同分摊，优于盾，因毛为前排船且分伤效率更高
- 盾在战巡数量多时作用有限，仅用于开策略
- CV3000在单战巡或单航母队伍中优势明显，替代五九，因血量高、抗伤面广、养成成本低
- 增援船应根据队伍需求选择，非所有人适合CV3000

## 适用限制
- 适用于顶客玩家第三阶段护航队配置
- 不适用于组队战报分析
- 前排分伤需至少14分摊，两台扛伤战巡无法达到
- CV3000在副队中生存优势不明显，仅适合单战巡或单航母队伍
