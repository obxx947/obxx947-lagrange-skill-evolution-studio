# A资料706 · 第三阶段护航队分摊与配队

> 场景：第三阶段护航内战；顶客账号；地面队

## 结论
- 组队战报不看；组队配队容易，只需分清输出船与防御船。
- 多数玩家主队配得好，副队问题较多。
- 看战报先看阵型判断阶段；三阶段护航内战才需细析，二阶段碾压正常。
- 超主力堆满通常是第三阶段护航，靠高分摊数量提高抗风险。
- 原阵前排、中排、后排都有船，核心不明确，前后排分摊不合理。
- 直射武器主要打前排，前排天权先掉，中排盾存活更好。
- 二阶段推荐前排小船减速带、中排大体量组合。
- 带天权是为保空战；保空战因海尔波普-维修支援护航艇（原文为“海尔波普/海尔伯虎”，疑似简称/语音识别错误）奶量高。
- 保天权应带更多前排矛，而非中排盾；矛可与天权一起分摊。
- 盾矛数量可灵活调整，重点前排做分摊。
- 盾数量越多队伍坦度越低；盾在单盾队强，多战巡队只沦为开策略。
- 雷火之星是否带不作评价，原作者以后会删。
- 后排CV3000可能是盲目模仿，需明确增援目标与作用。
- 后排选择需按账号养成与作战目标决定，不要盲从CV3000。
- 副队航母也应有输出，不只是抗伤。
- 99%队伍打不过用分摊扛伤的队伍，多数玩家止步于此。
- 空军内容等强军内战/同门师兄再研究，下一期讲空军。

## 配队与模块
- 原战报：前排5天权级-重型防御战列巡洋舰（原文为“天权”，疑似简称）；中排5普鲁图斯之盾级-防护战列巡洋舰（原文为“盾”，疑似简称）+1雷火之星-综合武库舰（原文为“雷神/雷火神”，疑似语音识别错误）+5天枢级-支援航空母舰（原文为“天枢级-支援航空母舰”，疑似语音识别错误）；后排4 CV3000级-快速航空母舰（原文为“cbb/cd三千/cb三千/cv三千”，疑似语音识别错误/简称）。
- 原战报载机：未带有效大型载机，使用中型载机，浪费大型载机位。
- 推荐阵容：6天权级-重型防御战列巡洋舰+4乌拉诺斯之矛（原文为“毛”，疑似简称）；也可4乌拉诺斯之矛+2普鲁图斯之盾级-防护战列巡洋舰或5乌拉诺斯之矛+3普鲁图斯之盾级-防护战列巡洋舰。
- 单战巡/单航母队：用CV3000级-快速航空母舰替代ST59级-防御战列巡洋舰（原文为“五九”，疑似简称）。
- CV3000级-快速航空母舰带艇位/载机；有太阳鲸-武装战略航空母舰（原文为“太阳金”，疑似语音识别错误）、永恒苍穹级-无人机航空母舰（原文为“苍穹”，疑似简称）、南十字星元帅级-武装航空母舰（原文为“南食志/男士字”，疑似语音识别错误）、CV3000时，后排优先南十字星元帅级-武装航空母舰。
- 南十字星元帅级-武装航空母舰提供输出、保护护航艇、机位和20个中型载机位。
- +9位置增援4台船，优先南十字星元帅级-武装航空母舰等有输出/载机能力的航母，不要无脑CV3000级-快速航空母舰。
- CV3000级-快速航空母舰选B2非对舰配置时无输出，仅抗伤；大型载机位应带有效大型载机。

## 数值与数据
- 对维塔斯-B010-轰炸机（原文为“维b”，疑似简称）约14分摊；直射武器打前排约5-2分摊，突破前排后中排约11分摊，加后排CV3000仍约14分摊。
- 10台海尔波普-维修支援护航艇在6分25秒奶120万；11台CAS066级-支援巡洋舰（原文为“零六六”，疑似简称）奶130万。
- 6乌拉诺斯之矛+6天权级=12分摊，与10分摊无本质区别；13分摊才有区别。
- 当前游戏只有2台前排战巡；服役限制为6。
- ST59级-防御战列巡洋舰送20蓝点，至少2.0/2.5/3.0才能用；血量20万。
- CV3000级-快速航空母舰白送50点+抽到20点；2.0可用，比肩3.0；血量40万。
- 五二分摊不如八三分摊，更不如十四分摊。
- 原阵前排天权快掉光，中排盾几乎没掉血。
- 单战巡硬上CV3000级-快速航空母舰可把BR050-标准轰炸机（原文为“零五零”，疑似简称）伤害从战巡分到航母。
