# A资料592

## 场景 / 对手
针对顶克玩家，讨论雷火之心的模块选择与实战应用，涉及直射/曲射武器、防空、轰炸环境

## 舰队例子
- 雷火之心（M3直射模块 + C1辅助模块，半改）（胜）【半改雷火即可运作，M模块输出占70-80%，C1每6秒激发武器，打特定阵容与满改区别不大】
- 雷火之心（M3 + C2防空模块 + 全防空模块如A1/B2/D1）（胜）【碰瓷雷火，协调防空效率250%，可在轰炸区游走，不损失对舰能力】
- 雷火之心（M1直射模块，锁敌10秒）（负）【针对小船前排（开阳、耀光）设计，但通用性差，不推荐】
- 雷火之心（M2曲射模块）（负）【输出不足，怕拦截，不如风暴M2，不推荐】

## 实战结果
宋老板猎户行动战报：主队+副队+护航，雷火未完全改防空模块，输出3万-6万不等，防空效果显著，轰炸压力小；雷火输出差距大时吃到快速装弹策略

## 结论思路
- 雷火武器输出模块最多，但主武器输出占比近80%，选择M模块是关键
- M2曲射不如风暴M2，M1针对小船但通用性差，最终选M3直射
- M3适合大船对局，锁敌15秒但转火少，打谁奶谁
- C1是核心辅助模块，半改雷火即可玩，C2加强后防空价值高
- A1比A2更推荐，单发低但强化效果触发稳定
- B2无对舰火力，不抢击发震荡，但防空改版后可能变化
- 主武器策略（快速装弹）触发时输出翻倍，需拉满命中（+25%）降低空枪惩罚
- C2防空模块配合全防空配置，可做防空船，在轰炸区游走

## 适用限制
- 雷火是针对性牌，非通用，适合特定阵容（大船对局）
- M1适合小船前排，但需特定环境
- M2不推荐，怕拦截且输出不足
- C2防空需全防空模块配合，否则不如C1
- 命中要求高，需调教加点
- 普通玩家轰炸对雷火无效，但凶狠轰炸套仍可能吃压力
