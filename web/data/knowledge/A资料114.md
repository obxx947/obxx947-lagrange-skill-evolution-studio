# A资料114

## 场景 / 对手
光防开窑队，前期向后期过渡，针对以水母开阳为主的驱护队伍，正面作战

## 舰队例子
- 开阳（前排）+ 光防（巡洋）+ 古神（奶）+ 瑶光双型号（辅助）+ 灼热（直射输出）+ 711导弹（胜）【核心配置，光防吸收反大火力，灼热提前进入中排】
- 开阳 + 光防 + 古神 + 瑶光双型号 + 创神星鱼雷（替代灼热）（胜）【无灼热时使用，取舍反大能力】
- 开阳 + 光防 + 古神 + 瑶光双型号 + 枪宗（替代灼热）（胜）【无灼热时使用，取舍反小能力】
- 开阳 + 光防 + 古神 + 瑶光双型号 + 防御牛（替代灼热）（胜）【补充防空能力】
- 开阳 + 光防 + 古神 + 瑶光双型号 + 台源（替代711导弹）（胜）【转型碰瓷队，提高防空和持久战能力】

## 实战结果
面对纯驱护队（除开阳水母、战术雷、鱼雷创神星全携带外）碾压；面对普卡和重卡队伍劣势；面对突击追队伍均势；面对800星脉猎兵优势；面对索姆河蜂巢可打过但光防可能被摧毁；面对高斯奥尔和泡泡龙队伍优势

## 结论思路
- 光防、古神和瑶光组合能稳定吸收水母和开阳的反大火力
- 光防选择原因：高速IO靠高闪避和高护甲维修，单巡洋可吸收输出；御衡A需两艘，光防需三艘，光防可掩护前排后撤小船
- 巡洋吸收反大驱射火力后，后排区护受伤减少，瑶光加盾更集中
- 巡洋吸收奶量后，灼热提前进入中排且不会因奶船回前排，直接火力倾泻
- 灼热65%血进入中排，瑶光加盾优先给生命百分比最低舰船，灼热不抢光防护盾，光防维持65%血量
- 光防为灼热提供近50%拦截率，克制突击追、711导弹、枪宗等反小区射
- 瑶光双型号可叠加供能，提供75%能量抗性，必不可少
- 创神星鱼雷和水母替换灼热与711导弹可克制本阵容变体，但反响能力下降
- 面对纯驱护队时，替换配置可能花费更长战斗时间

## 适用限制
- 适用于前期抓以水母开阳为主的驱护队伍
- 面对普卡和重卡队伍劣势，因反拦截威胁大
- 面对突击追队伍均势，需注意光防和711导弹反制
- 面对索姆河蜂巢需做好光防被摧毁准备
- 造价较高（45分），需考虑资源
- 单挑能力低（10分），不适合单挑场景
