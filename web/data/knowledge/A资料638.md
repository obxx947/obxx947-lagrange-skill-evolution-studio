# A资料638

## 场景 / 对手
风暴错误使用方法，双方配置均为支援天书，左边大毛配大盾配风暴，右边中排超主力配前排小船，环境为常规对战

## 舰队例子
- 风暴（前排）（负）【生存差，五分钟死完，第一个一分钟就没了，受伤害最高来自对面风暴45万和大毛52万】
- 大毛（中排）（负）【思路错误，高价值高伤害船放前排送，扛伤船放中排保护】
- 风暴（中排）（胜）【生存好，适配中排，能应对大地、重哈、围壁，唯一怕坦克】
- 大毛（前排）（胜）【血量接近风暴两倍，抗伤能力更强，生存力更强】
- 天泉（前排）（胜）【稀少但可用】
- 开阳（前排）（胜）【等效血量超主力级别，配御狠赖皮】

## 实战结果
左边打右边，八分钟，左边输出高一百万，右边奶量高一百万，左边输出全由风暴打出，风暴前排生存差，五分钟死完，主队风暴打145万，副队风暴打100万

## 结论思路
- 风暴自带拦截，节约人口，伤害高，提高剑队上限
- 风暴提升能量抗性但血量未提升，怕高端直射如大毛，前排生存差
- 风暴应放中排，生存好，能应对大地、重哈、围壁，唯一怕坦克
- 前排可放大毛、天泉、开阳等抗伤船
- 风暴在副队收益好，分到中排前排放开一样，带奶妈难处理

## 适用限制
- 风暴适合中排，不适合前排
- 对面纯直射队时风暴活不久
- 风暴怕坦克
- 大毛放前排需血量高但护甲低，怕高单发
