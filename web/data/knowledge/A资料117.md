# A资料117

## 场景 / 对手
CAS零六六炮击型对前排闪避小船

## 舰队例子
- CAS零六六炮击型，主武器系统加点：一轻型弹药、两伤害、两命中、一频率、一暴击；副武器系统加点：两伤害、一命中、一预警、一频率；装甲系统加点：两血量、二能抗；动力系统加点：二普通移速、一驱率移速（胜）【针对前排闪避小船，利用高单发伤害和策略命中加成】

## 实战结果
CAS零六六炮击型对抗前排闪避小船，凭借高单发伤害和策略命中加成，快速清理目标，取得优势

## 结论思路
- 主武器系统策略提供30%对护卫舰额外命中，克制闪避小船
- 高单发输出无视瑶光能抗加成，有效清理前排
- 加点方案优化伤害、命中、频率和暴击，提升输出效率

## 适用限制
- 适用于对抗护卫舰等前排闪避小船
- 对高血量或高能抗目标效果可能有限
- 依赖主武器策略触发，需注意策略使用时机
