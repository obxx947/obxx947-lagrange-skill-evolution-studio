# A资料203

## 场景 / 对手
当前版本护航艇体系，正面输出与轰炸环境

## 舰队例子
- 索姆河护航艇，武器系统+动力系统，70蓝点（胜）【输出高，能断奶，能上轰炸】

## 实战结果
索姆河在组队和轰炸中表现优秀，能有效对抗副队，但面对重甲舰时穿甲能力有限

## 结论思路
- 索姆河单发800多，能打穿除超主力附加模块外装甲
- 可上轰炸，配合苍穹策略伤害翻三倍
- 作战序列第一位有巡洋舰，打副队能断奶
- 加点推荐动力系统锁敌，不点脱壳穿甲弹策略
- 生存优秀，护甲高，集群作战策略分摊伤害

## 适用限制
- 需要70蓝点投入
- 面对重甲舰时穿甲能力有限
- 不推荐点脱壳穿甲弹策略
