# A资料94

## 场景 / 对手
配合护航艇的扛伤队，面对常规地推队伍里的T800

## 舰队例子
- 御衡B（3~4艘）+ 海尔波普防空护航艇 + 高闪避护航艇 + 带艇模块的战巡 + 能携带护航艇的航母（胜）【能大幅度延长护航艇的生存时间，让海尔波普生存时间拉到三分钟以上】

## 实战结果
面对常规地推队伍里的T800，3~4艘御衡B能让奶艇有效生存时间延长到三分钟左右

## 结论思路
- 御衡B必须配合护航艇才有登场的必要
- 在扛伤队里搭配海尔波普防空护航艇或高闪避护航艇，能大幅度延长护航艇的生存时间
- 御衡携带的无人艇在半飞T800时，不会与舰载机打同一目标，只有玉衡本身被舰载机攻击时，无人艇才会打出防空伤害
- 玉衡的掩护效果对每一艘护航艇只生效一次，不存在一艘艇被掩护两次的情况，带再多御衡也没用

## 适用限制
- 必须配合护航艇使用
- 掩护效果对每艘护航艇只生效一次，不能重复叠加
- 无人艇防空伤害仅在玉衡本身被舰载机攻击时触发
