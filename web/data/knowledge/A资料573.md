# A资料573

## 场景 / 对手
ST59战巡舰使用分析，针对新手玩家，探讨电磁与装甲模块的适用场景

## 舰队例子
- 电磁59 + 8光锥 + 12个066（负）【电磁59不适合奶船队，维修量低，物理抗性低，需大量拦截】
- 装甲59 + 少量拦截 + 奶船（胜）【装甲59适合被奶，减少拦截人口，配合奶船队】
- 电磁59 + CV3000 + 前排抗伤船（艾奥、重炮、防御牛）（胜）【第三阶段护航，电磁59作为引子吸收伤害，配合CV3000拦截】

## 实战结果
分析ST59的两种玩法，电磁59在奶船队中表现差，装甲59更适合奶船队；电磁59适合第三阶段护航，与CV3000配合。关键得失：电磁59维修量低、物理抗性低，需拦截；装甲59适合被奶，减少拦截人口。

## 结论思路
- ST59不是新手船，新手应优先选择其他战巡
- 电磁59不适合奶船队，因维修量低和物理抗性低
- 装甲59适合奶船队，减少拦截人口，配合奶船
- 电磁59适合第三阶段护航，作为引子吸收伤害，与CV3000双排
- 队伍中应搭配大量抗伤船（如艾奥、重炮、防御牛），而非066

## 适用限制
- 电磁59需配合拦截和抗伤船，不适合单独作为奶船队核心
- 装甲59适合有奶船支持的阵容
- ST59不适合新手，除非有特定阵容支持
- 避免在无拦截情况下使用电磁59，易被物理伤害击破
