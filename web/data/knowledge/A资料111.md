# A资料111

## 场景 / 对手
前期320+5驱护队，携带鱼海旗舰（脉冲型号）的实战分析，涉及单挑和夹击环境

## 舰队例子
- 驱护队（320人口+5）携带鱼海旗舰（脉冲型号）（胜）【鱼海策略在单挑和夹击时触发，选择结构值最低目标攻击，优先集火前排】
- 同配置但不带鱼海旗舰（负）【对方舰船分伤均匀，战损较低，但难以打出有效战损】

## 实战结果
我方带鱼海旗舰打对方，胜；不带鱼海旗舰打对方，负。关键得失：带鱼海旗舰时，损失多14人口，战斗时间多约1分半，但能快速集火低结构值目标（如卡特、水母），扩大战损；不带时，分伤均匀，战损低但难以击杀。

## 结论思路
- 携带鱼海旗舰时，必须选择脉冲型号，避免主型号轨道炮被集火秒掉
- 鱼海策略在单挑和夹击时均触发，选择结构值最低的三个目标攻击
- 优先集火前排舰船（如卡特），当前排数量少于7时转火后排（如水母）
- 带鱼海旗舰能快速击杀低血量高危险单位，扩大战损，提高队友生存能力
- 不带鱼海旗舰时，输出分散，难以打出有效战损

## 适用限制
- 适用于前期驱护队（320+5）配置
- 鱼海旗舰必须为脉冲型号，主型号不适合
- 需要对面前排数量足够多（大于8）时，优先集火前排效果更佳
- 带鱼海旗舰会增加自身损失和战斗时间，需权衡战损收益
