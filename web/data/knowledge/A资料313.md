# A资料313

## 场景 / 对手
二点零后期，战巡点数不高，模块不够

## 舰队例子
- 大盾（旗舰）+ 大盾（增援）（胜）【作为旗舰和增援，提供抗伤】
- 五十九舰队（2增援）+ 4个光防 + 8个六十六奶 + 8个开阳 + 4个瑶光（胜）【完整配队，增强抗性】

## 实战结果
二点零玩家使用该配置，比纯小船更能抗，但缺少模块和点数，差距不大

## 结论思路
- 选择大盾作为旗舰和增援，提升生存能力
- 五十九舰队中配置增援、光防、奶、开阳和瑶光，形成完整配队
- 该配置在抗性上优于纯小船，但受限于模块和点数，优势有限

## 适用限制
- 适用于二点零后期，战巡点数不高、模块不足的情况
- 需要足够的大盾和五十九舰队相关舰船
- 不适用于模块和点数充足的高配场景
