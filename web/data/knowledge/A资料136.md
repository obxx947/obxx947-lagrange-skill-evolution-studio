# A资料136 · 066级三型号解析

> 场景：开荒、反高护甲前排、副队奶船

## 结论
- 基础型开荒好用，主武器与子系统兼具反大和反小，两边输出差不多
- 基础型面对大矛、大盾等高护甲舰船打击效果好，攻击频率高
- 炮击型核心输出集中在主武器，单发伤害1500，但牺牲了反向火力
- 炮击型锁定时间长，作为直射武器易受卡特类闪避小船影响导致输出下降
- 对方前排多高物理护甲舰船时，炮击型收益可观
- 支援型是当前最热门奶船之一，配合大矛可提升整体维修量和站桩能力
- 支援型是当前版本副队核心成员之一
- 支援型上场空间逐渐被玉衡级、天枢级航母等舰船替代
- 后续可灵活使用舰船，不必局限于单一舰船上场

## 配队与模块
- 基础型子系统加点：两层伤害、两点冷却、一点小船命中
- 基础型主武器加点：双伤害、双冷却、对大型命中
- 基础型主武器可点快速输出，每60秒触发一次
- 支援型加点：优先策略加点，再点锁定，之后依次点维修量和冷却
- 支援型配合大矛使用

## 数值与数据
- 炮击型主武器单发伤害1500
- 基础型主武器快速输出每60秒触发一次
