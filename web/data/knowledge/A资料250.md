# A资料250

## 场景 / 对手
前期小七二零抗伤队，正面轰炸

## 舰队例子
- 3艘雷里亚特点（内核）+ 避险旗舰 + 10艘开阳石特卡卡（指挥值200以内）（胜）【触发避险旗舰，可随意出击】
- 3艘雷里亚特点（内核）+ 避险旗舰 + 10艘开阳石诺乃（指挥值192）（胜）【替代方案】
- 3艘雷里亚特点（内核）+ 避险旗舰 + 9艘开阳石系神（指挥值190）（胜）【替代方案】

## 实战结果
前期小七二零抗伤队，使用上述配置可轻松应对，未提及具体对手

## 结论思路
- 核心为3艘雷里亚特点，提供抗伤能力
- 搭配避险旗舰，控制指挥值在200以内以触发效果
- 开阳石系列（特卡卡、诺乃、系神）作为补充输出或辅助

## 适用限制
- 适用于前期小规模战斗
- 指挥值需严格控制在200以内
- 依赖雷里亚特点的获取（人人都有）
