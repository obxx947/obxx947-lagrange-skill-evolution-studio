# A资料331 · 超斩队克制开阳瑶光前排

> 场景：对手为开阳瑶光前排体系；正面作战

## 结论
- 开阳高闪避与瑶光能量护盾让常规直射火力难以快速清前排
- 常规队带星云追逐者-脉冲炮艇（原文为"心脉"，疑似语音识别错误）和康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡龙"，疑似简称），四分钟仍清不完前排
- 超斩队要求武器要么反大，要么投射，以越过前排小船直接打大船扩大战损
- 超斩的投射火力容易被拦截
- M2永恒风暴级-攻击战列巡洋舰（原文为"M2风暴"，疑似简称）的投射火力不被拦截，是超斩核心之一
- 超斩队主要输出是舰载机
- 超斩遇到多超主力分摊伤害时表现不佳
