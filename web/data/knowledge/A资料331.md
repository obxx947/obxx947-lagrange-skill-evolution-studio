# A资料331

## 场景 / 对手
当前版本PVP，针对开阳瑶光前排组合，讨论超斩与直射火力优劣

## 舰队例子
- M2风暴超斩（不被拦截投射火力）+ 坦克（六十六奶严复）（胜）【核心输出，可越过前排打大船，扩大战损】
- 六十六奶（严复）（胜）【提供奶盾，其余反大火力打没奶的盾】
- 舰载机（胜）【主要输出，但超斩遇多超主分摊时效果不佳】

## 实战结果
超斩队对抗开阳瑶光前排，四分钟内清前排困难，但超斩可绕过前排打大船，具体胜负未明确

## 结论思路
- 超斩队要求武器反大或投射，直接越过前排小船打大船
- M2风暴超斩是不被拦截的投射火力，是超斩核心之一
- 超斩队用风暴超斩打奶盾，其余反大火力打没奶的盾
- 舰载机是主要输出，但超斩遇多超主分摊时效果不佳

## 适用限制
- 适用于对抗开阳瑶光前排组合
- 超斩投射火力易被拦截，需依赖M2风暴等不被拦截武器
- 超斩遇多超主分摊时效果不佳，需谨慎使用
