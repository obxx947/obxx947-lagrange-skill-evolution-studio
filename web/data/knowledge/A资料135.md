# A资料135

## 场景 / 对手
新手前期载机舰船护航艇搭载系统超斩策略

## 舰队例子
- 猎兵级巡洋舰+五加乘机库+超斩点法+星脉蜂巢（胜）【超斩点法锁定双返回命中，推荐携带星脉蜂巢】
- 猎兵级巡洋舰+五加乘机库+非超斩点法+八百索姆河（胜）【非超斩点法锁定双返回命中伤害，推荐携带八百索姆河】

## 实战结果
猎兵级巡洋舰作为新手最优载机舰船，搭配超斩策略在前期实战中表现良好，具体胜负未详述

## 结论思路
- 猎兵级巡洋舰是新手玩家最容易获取的最优载机舰船
- 五加乘机库搭配超斩策略是前期萌新最佳载机舰船方案
- 超斩点法推荐携带星脉蜂巢
- 非超斩点法推荐携带八百索姆河

## 适用限制
- 适用于新手前期阶段
- 需搭配护航艇搭载系统
- 超斩点法与非超斩点法需根据携带舰载机选择
