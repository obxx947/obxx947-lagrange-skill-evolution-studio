# A资料188 · 护航输出队配队思路

> 场景：护航输出队/虐菜输出队

## 结论
- 输出队带锁锚夹击也能生效
- 虐菜输出队可带锁锚航母，按自己号选择主力航母优先
- 主队还要加航母就上永恒苍穹级或南十字星元帅级
- 永恒苍穹级带林鸮A100型-联合攻击机打系统伤害
- 南十字星元帅级加强后也能用
- 输出队带不带防空看实际情况，但小米还是得带
- 鱼上面可以拉满输出
- 小米用狩猎者级带蜂巢，单发低且优先打大船
- 打架可优化出去RB7-13型-B-突防护航艇（原文为"RB7的SD型号"，疑似语音识别错误）
- 事先打区护巡洋就能克制瑶光级与开阳级
- S-列维9号-重型鱼雷艇（原文为"列维"，疑似简称）感觉不好使，没玩

## 配队与模块
- 永恒苍穹级带林鸮A100型-联合攻击机
- 小米用狩猎者级带蜂巢守卫者-重型鱼雷艇（原文为"蜂巢"，疑似简称）
- RB7-13型-B-突防护航艇可优化出去
