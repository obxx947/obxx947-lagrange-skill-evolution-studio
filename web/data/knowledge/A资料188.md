# A资料188

## 场景 / 对手
输出队配置思路，涉及锁锚夹击、航母选择、防空配置、克制关系

## 舰队例子
- 锁锚航母（主力航母优先或C位主队），可选苍穹或南十字M，苍穹带凌霄打系统伤害，南十字加强后可用（胜）【虐菜输出队可带锁锚航母，根据号选择主力航母】
- 小米（带狩猎蜂巢，单发低优先打大船）（胜）【防空配置中建议带小米，输出拉满】
- RB7的SD型号（事先打区护巡洋）（胜）【打架可优化，克制瑶光开阳】

## 实战结果
输出队带锁锚夹击有效，RB7克制瑶光开阳，列维不好使未使用

## 结论思路
- 输出队带锁锚夹击也能生效
- 虐菜输出队可带锁锚航母，主力航母优先或C位主队
- 航母选择苍穹或南十字M，苍穹带凌霄打系统伤害，南十字加强后可用
- 防空配置根据实际情况，建议带小米，输出拉满
- 小米用狩猎带蜂巢，单发低优先打大船
- 打架可优化RB7的SD型号，事先打区护巡洋克制瑶光开阳
- 列维感觉不好使，未采用

## 适用限制
- 输出队配置需根据自身号选择主力航母
- 防空配置需根据实际情况调整
- RB7克制特定船型（瑶光开阳），需事先打区护巡洋
- 列维不推荐使用
