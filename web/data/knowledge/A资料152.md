# A资料152 · 风暴两种配置用法

## 结论
- C2雷暴无人机模块可优先锁敌前排战巡，提供能量护盾支援
- C2配置使前排战巡获得15%能量输出闪避，提高5%能量抵抗
- C3电磁装甲常态风暴拥有55%能量抵抗
- C3配置随血量下降提升能量抵抗比率，血量30%左右达到完全体，拥有90%能量抗性
- C3配置可配合中排减伤策略盾及光防拦截，保证中排大船生存率
- 前排多利用瑶光开阳体系分担直射伤害

- C3配置：电磁装甲系统（原文为"电磁装甲"，疑似简称），配合中排减伤策略盾及光防拦截
- 前排使用瑶光级-通用护卫舰（原文为"瑶光"，疑似简称）、开阳级-机动驱逐舰（原文为"开阳"，疑似简称）体系分担直射伤害
