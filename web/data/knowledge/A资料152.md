# A资料152

## 场景 / 对手
风暴两种配置，针对能量输出和能量抵抗，配合不同舰队体系

## 舰队例子
- C2雷暴无人机模块，无人机优先锁敌前排战巡提供能量护盾支援，前排战巡获得15%能量输出闪避和5%能量抵抗，配合前突附加盾或中牌附加盾加前排附加矛（胜）【增强前排战巡生存和输出】
- C3电磁装甲，常态55%能量抵抗，血量下降提升至90%，配合中排减伤策略盾和光防拦截，前排瑶光开阳体系分担直射伤害（胜）【高能量抗性，保护中排大船】

## 结论思路
- C2配置利用能量护盾支援提升前排战巡的闪避和抵抗，适合对抗能量输出
- C3配置通过高能量抵抗和减伤策略，适合持久战和能量密集环境
- 前排瑶光开阳体系可有效分担直射伤害，配合C3增强整体生存

## 适用限制
- C2配置依赖无人机模块，需确保无人机存活
- C3配置在低血量时效果最佳，需避免被快速击破
- 两种配置均针对能量伤害，对直射伤害防护较弱
