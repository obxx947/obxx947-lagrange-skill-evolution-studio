# A资料225

## 场景 / 对手
巡洋舰强度与适用度综合评估，涉及护航、航母队、防空、输出环境等

## 舰队例子
- 061奶（林乐佑奶）（胜）【第二三阶段护航核心，分奶能力，强度高适用度高】
- 狩猎（载机VA或海市）（胜）【超斩能力，VA提升痊愈，海市分奶，强度高适用度高】
- 列兵（载机T800）（胜）【超斩或反艇，需防空配合，强度高适用度高】
- 玉衡C（配瑶光、开阳）（胜）【限制能量伤害，奶小船，强度高适用度中】
- 炮龙（负）【输出受限制，面对五九和开阳低效，强度中适用度中】
- 光锥B（负）【拦截暗改后投射无效，强度中适用度低】
- IOC（胜）【拆家能力强，输出低，强度高适用度低】
- 卡托比（负）【依赖对面无拦截，强度高适用度低】

## 实战结果
评估各巡洋舰，061奶、狩猎、列兵为顶级；玉衡C次之；炮龙、光锥B、IOC、卡托比受限；有骑兵和爱好评价差

## 结论思路
- 061奶因天书成本高，仍是护航主力
- 狩猎和列兵因航母队需求，适用度高
- 列兵超斩需防空支持，否则无效
- 狩猎载机VA或海市，海市分奶
- 玉衡C强度高但适用度低，因普及率低
- 炮龙输出受能量限制，环境差
- 光锥B因拦截暗改，投射无用
- IOC只适合拆家，输出低
- 卡托比依赖对面无拦截，风险高

## 适用限制
- 061奶适合第二三阶段护航
- 狩猎和列兵需航母队配置
- 列兵超斩需防空能力
- 玉衡C只能奶小船
- 炮龙不适合面对高能量抗性
- 光锥B不适合当前拦截环境
- IOC仅用于拆家
- 卡托比需判断对面拦截
