# A资料311

## 场景 / 对手
副队，面对大矛、大盾、59等重甲舰，正面轰炸

## 舰队例子
- 蜂巢守卫者重型鱼雷艇（四连装鱼雷+火炮+态势感知系统，武器系统满点满调教，动力系统锁敌点满）（负）【鱼雷单发低，实弹伤害，打不穿重甲；防空能力弱】

## 实战结果
开服老版本蜂巢输出力压新麦和索姆河，人手一台；现版本因拦截和护航机制，鱼雷易被拦截，面对重甲乏力，表现不佳

## 结论思路
- 蜂巢鱼雷单发低且实弹伤害，面对重甲舰无法有效输出
- 攻击序列优先战巡，但副队战巡多为高护甲，鱼雷打不穿
- 鱼雷易被拦截，但反拦截词条限制不大
- 若攻击序列加入巡洋舰，伤害和使用力将提高
- 蓝图少缺输出时可带，点数需求少，点满武器和动力锁敌即可

## 适用限制
- 适合蓝图少、缺输出的玩家
- 不适合面对重甲舰（大矛、大盾、59）
- 防空能力可忽略，生存能力一般
