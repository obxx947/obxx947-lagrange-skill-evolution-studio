# A资料598 · 普鲁图斯之盾30%减伤致惨败

> 场景：争锋单挑；对手普鲁图斯之盾级旗舰，3普鲁图斯之盾级+5乌拉诺斯之矛（原文为"大毛"，疑似错字）；正面舰队战

## 结论
- 普鲁图斯之盾级-防护战列巡洋舰（原文为"大盾"，疑似简称）减伤是败因，开局即压低我方输出。
- 对手普鲁图斯之盾级旗舰未受伤并持续到结束，我方打不动其前排，对方奶量维持。
- 无普鲁图斯之盾级时我方大概率赢或不会输得这么惨。
- 应对3普鲁图斯之盾级+5乌拉诺斯之矛只剩永恒苍穹级-无人机航空母舰带林鸮A100型-联合攻击机，靠分散攻击。
- 单带绝育遵循分摊原则，不能稳定绝育普鲁图斯之盾级；有绝育优先绝育旗舰。
- 断奶有效，永恒风暴级断奶可压制普鲁图斯之盾级回血；无断奶普鲁图斯之盾级几乎不掉血。
- 海尔波普-系统支援护航艇/维修支援护航艇（原文为"海尔波普"，疑似简称）实战无用，不建议带，尤其对面有防空。
- 前排乌拉诺斯之矛扛不住且战损大；ST59级-防御战列巡洋舰（原文为"五九"，疑似简称）能扛，资源低，炸了能补。
- 乌拉诺斯之矛造价高，炸了很伤；护航作战副队先炸者输，拼战损。
- 对手重甲普鲁图斯之盾级+重甲乌拉诺斯之矛吃满150%维修量，奶量高；我方护甲低吃不满。
- 绝育乌拉诺斯之矛指挥系统无效，其仍三分钟死完。
- 普鲁图斯之盾级系统三四分钟才被绝育，已强弩之末。
- 康纳马拉混沌级被电磁ST59级克制惨，伤害不优秀。
- 炮艇中仅星云追逐者-脉冲炮艇（原文为"新脉"，疑似语音识别错误）与CV-T800型-脉冲炮艇（原文为"八百"，疑似简称）能打伤。
- 林鸮A100型-联合攻击机分散攻击优于指挥系统绝育；本局指挥系统未绝育掉对方。
- 主要输出为S-列维9号-重型鱼雷艇（原文为"鱼"，疑似简称）、康纳马拉混沌级、星云追逐者-脉冲炮艇、CV-T800型-脉冲炮艇、海氏追随者型-脉冲攻击机（原文为"海狮"，疑似语音识别错误）、维塔斯-B010-轰炸机（原文为"vb"，疑似简称）；建议配队带入。
- 需调整配队应对普鲁图斯之盾级，优先考虑普鲁图斯之盾级、苍穹林鸮A100型-联合攻击机、断奶、绝育旗舰。
- 我方高配就差一个普鲁图斯之盾级，白板也想要。
- 战斗中期靠断奶击杀一个普鲁图斯之盾级，但副队先没，最终撤退。
