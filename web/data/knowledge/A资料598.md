# A资料598

## 场景 / 对手
正面战斗，对手配置为五个大毛、三个大盾（含重甲盾、官方六六六），我方配置为六毛、六五九、十二个六六奶，环境为常规战斗，无特殊环境描述

## 舰队例子
- 大毛（重甲毛，前排）+ 大盾（重甲盾，官方六六六）+ 光防 + 六六奶 + 补人口舰船，数量：5毛、3盾、若干奶和辅助（胜）【大盾提供30%减伤，大毛后排输出，重甲盾吃满150%维修量，旗舰持续存活】
- 大毛（前排毛，无电磁）+ 五九 + 六六奶 + 高达副队，数量：6毛、6五九、12六六奶（负）【前排毛扛不住，战损大，五九能扛但资源少，副队脆，伤害被大盾减伤30%】
- 鱼（八级三挺，带无人机）+ 混沌 + 星脉 + 八百 + 海氏VB + 蓝狮子（带VB）+ 大毛旗舰，数量：5鱼、8混沌、若干炮艇（胜）【鱼输出73万，无人机单发700多，绝育效率高，星脉和八百是唯二能打伤的炮艇】

## 实战结果
我方（六毛、六五九、六六奶）对战敌方（五毛、三盾、大盾旗舰），我方1负，敌方1胜。关键得失：大盾30%减伤导致我方伤害减少约30万，副队战损大；敌方大盾旗舰持续存活，奶量维持，我方断奶效果有限但不足以翻盘

## 结论思路
- 大盾提供30%减伤，分伤舰队时伤害直接减少30%，非常恶心，是核心优势
- 前排毛（无电磁）扛不住，战损大，五九能扛但资源少，大毛炸了损失惨重
- 应对三个大盾和五个大毛唯一方法是苍穹凌霄的分散攻击，其他绝育系统遵循分摊原则，难以打到大盾
- 风暴断奶在战斗中有效，能加速敌方盾掉血，但若无断奶，盾掉血很慢
- 海尔波普不适合当前作战环境，实战输出低（7-8万），不如奶毛（21万），不建议带
- 鱼、混沌、星脉、八百、海氏VB是主要输出，配队时应优先考虑
- 大盾旗舰（重甲猫）持续存活，减伤效果贯穿战斗，是胜负关键

## 适用限制
- 大盾适合需要减伤和持久战的舰队，但依赖重甲模块和维修量
- 前排毛不适合作为主坦，除非有电磁模块或足够资源补充
- 绝育系统需配合苍穹凌霄的分散攻击才能有效应对多战群目标
- 海尔波普不适用于当前作战环境，避免在副队中使用
- 炮艇中只有星脉和八百能有效打伤，其他炮艇输出有限
