# A资料255

## 场景 / 对手
针对巡洋的主力输出，中后期使用，正面作战

## 舰队例子
- 坦克（主武器，破甲高单发，不可拦截）（胜）【打巡洋稳定，输出仅次于星脉】
- 坦克（C2轰炸模块，无攻击持续时间）（胜）【完美适配苍穹BUFF】
- 鱼（M1模块，调教命中率5%以上）（胜）【提高坦克命中率，减少演的情况】

## 实战结果
空号手将坦克装入列兵超载，被福牙盾打成哨子；坦克打巡洋稳定，但打超主力或小船效果差

## 结论思路
- 坦克定位是针对巡洋的主力输出，类似风暴，不适合打超主力
- 坦克攻击序列与风暴相似，可对巡洋进行随机斩杀
- 坦克输出仅次于星脉，是必带舰船
- 坦克反小能力差，命中率低，打重甲或小船受克制
- 星脉是坦克的上位替代，优先使用星脉
- 带坦克时需调教鱼M1命中率至5%以上

## 适用限制
- 适用于中后期打巡洋体系
- 不适合打超主力（如福牙盾）或小船（如卡特、吸尘、开阳A）
- 打重甲或高闪避目标时效果差
- 不建议当超展使用，对面有2.5或附加盾时不如带列维或八百
