# A资料613 · 加九护航对冲战报解析

> 场景：双方氪佬加九护航对冲，多超主力配置，航母抗战队对矛盾队

## 结论
- 护航对冲决胜点是大盾，谁的大盾先炸谁就输
- 大盾提供30%减伤，绝育后对方相当于多30%伤害
- 苍穹能分散攻击绝育大盾，是胜负关键
- 三个苍穹价值远超所占人口，绝育效率极高
- 大剑作为输出战巡绝对合格，输出无法被拦截
- 大剑输出仅次于风暴，buff舰载机伤害算在大剑上
- 大地输出已成弟弟，不推荐携带
- 大地被光锥克制且单发低，打不动重甲
- 风暴不推荐放副队，造价高且脆，主队输出选择会减少
- 风暴放副队会减少主队输出选择，混沌和艾奥可替代但艾奥打闪避难
- 断奶奶在多超主力配置下失效，奶量会散到超主力
- 风暴可降低对面奶量，护甲越高奶量越高，打巡洋舰奶量下降
- 航母抗战队很强，直接让八百少40万伤害
- 720是玩高达抗战队的核心，能紧急避险，动力系统被打也能避险
- 720稀有，决定战损，弥补高达抗战队造价缺点
- 光锥现在主队作用小，光防防空不强，拦截不了风暴投射
- 高端局带光锥少，因为没人带大帝和重卡
- 林鸮A100型-联合攻击机（原文为"凌霄"，疑似语音识别错误）绝育效率高，三个林鸮A100型-联合攻击机可绝育大盾，一个不够
- 大矛重甲被戎甲降护甲后奶量降低严重
- 戎甲降低对面奶量，对高护甲大盾作用小，对大矛作用大
- 右边配置改正点：下大地，提苍穹和林鸮A100型-联合攻击机数量
- 右边血量更高理论上更能扛，但输在大盾被绝育
- 风暴能量闪避buff不稳定，不推荐带副队
