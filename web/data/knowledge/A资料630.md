# A资料630

## 场景 / 对手
航母碰瓷队配置讲解，针对防空火力与航母生存的体系，正面作战

## 舰队例子
- 前排：斗牛防御x10，枪骑防空x7（旗舰）；中排：光追x2；后排：台员x10，遥光x10，狩猎x6（防空型，带8雷火基础型、8海誓、8沙龙）；支援：CV（8机库：小米x10，雷火特种x8，凌霄x7，八百x15；3机库：高速零幺幺x15）（胜）【人口420，防空火力高于传统碰瓷队，通过快速清理敌方炮艇保障航母生存】

## 实战结果
无具体实战记录，仅配置讲解

## 结论思路
- 航母生存保障优先通过快速清理敌方火力点，而非增加维修量，因维修量对航母增益低且会降低防空火力
- 航母加入提升舰载机数量与生存，防空火力高于传统碰瓷队，目标是在航母被击毁前消灭敌方炮艇
- 狩猎和光追不仅提供空投与buff，还通过吸引巡洋舰和航母火力分担航母伤害，减少生存压力
- CV选择因便宜且有拦截模块，能提高后排狩猎生存率；舰载机带满所有防空型，不刻意追求八百生存
- 空优舰载机索敌需短，CV机库无索敌加点，故携带小米、雷火特种等自身索敌短的机型
- 台员因防空火力高且血量厚，配合信息链快速解决战机后发挥输出；斗牛因血厚与光追配合

## 适用限制
- 需配齐足够空优舰载机，否则防空火力下降导致航母生存降低
- 不建议为保护航母带大量奶船或替换防空火力，违背碰瓷队初衷
- 不刻意追求八百生存，避免带无关炮艇，因空战看脸且对面不一定带八百
- 狩猎需防空型，光追基础型或防控型均可，不指望其拦截或防护伤害
