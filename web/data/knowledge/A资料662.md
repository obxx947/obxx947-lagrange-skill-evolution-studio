# A资料662 · 改版碰瓷队配置思路

> 场景：改版后碰瓷队（投射+直射混编）

## 结论
- 改版后碰瓷队与之前基本无差别，新增斗牛级-脉冲炮驱逐舰（原文为“斗牛”，疑似简称）。
- 碰瓷队是投射加直射的混编队伍。
- 以AC721-重型导弹驱逐舰（原文为“721导弹”，疑似简称）和枪骑兵级-轻型导弹驱逐舰（原文为“枪骑兵/枪骑”，疑似简称）为中心。
- 枪骑兵级-轻型导弹驱逐舰可少上几个，以AC721-重型导弹驱逐舰为准。
- 有白鳄可上白鳄，并带银石。
- 红矿可上卫士-支援驱逐舰（原文为“卫士”，疑似简称）；卫士资源高，仅限红矿，出了红矿不要用。
- 可放或增援ST59级-防御战列巡洋舰（原文为“59”，疑似简称）触发AC721-重型导弹驱逐舰策略。
- 有人口时推荐雷里亚特级-快速鱼雷护卫舰（原文为“雷利亚特”，疑似错字），其策略称“小720”。
- 雷里亚特级-快速鱼雷护卫舰有少量对空；其他两个型号无对空；仅基础型号有该策略。
- 纯投射队不建议放雷里亚特级-快速鱼雷护卫舰，碰瓷队可以放。
- 雷里亚特级-快速鱼雷护卫舰可救船，减少资源浪费。
- 碰瓷队可委派，用于低活跃度或与对面交战。
- 没有精力搞分舰队/分基地、不想花资源赶升本进度时，出碰瓷队即可。
- 不用搞两队开封锁，很费策略。
- 新版轰炸以舰队自身为半径开启，容易在节点中被敌人加速突刺；出碰瓷或纯投射均可。
- 下一期讲纯投射队。

## 配队与模块
- 改版碰瓷队：斗牛级-脉冲炮驱逐舰 + 双皮奶（谷神星级-支援驱逐舰（原文为“股神奶”，疑似语音识别错误）+ 苔原级-战术驱逐舰（原文为“弹源奶”，疑似语音识别错误））。
- 核心：AC721-重型导弹驱逐舰、枪骑兵级-轻型导弹驱逐舰；枪骑兵级-轻型导弹驱逐舰可少上，以AC721为准。
- AC721-重型导弹驱逐舰用导弹型；可放/增援1艘ST59级-防御战列巡洋舰。
- 有白鳄可上白鳄，并带银石。
- 红矿可上卫士-支援驱逐舰；仅限红矿，出了红矿不要用。
- 有人口时加入雷里亚特级-快速鱼雷护卫舰；40点加满，至少3艘；碰瓷队旗舰给它，造3-5艘。
- 纯投射队不配雷里亚特级-快速鱼雷护卫舰。

## 数值与数据
- AC721-重型导弹驱逐舰策略：己方舰队存在未央技术路线超主力舰时，命中率提升40%。
- 未央技术路线超主力舰可用ST59级-防御战列巡洋舰，放1艘或增援1艘。
- 雷里亚特级-快速鱼雷护卫舰“小720”策略：低于200时提升60%，可救回100多近200。
