# A资料352 · 大件核心模块及加点讲解

## 结论
- M1模块虽是直射对象，但策略非常强劲，实战可增加索姆河等火力最高的舰载机输出
- M1模块加点除对空命中不点，其他拉满
- A2模块是两大核心之一，策略必点，实战拥有断奶效果
- B3模块可降低对面物理护甲，是两大核心之一
- D模块中的第二或第三属于锦上添花小核心
