# A资料365

## 场景 / 对手
刷盘古船，涉及海盗基地、护航/轰炸、中立协议小号

## 舰队例子
- 大号舰队（未指定具体船型，用于封锁/护航/轰炸）（胜）【用于刷海盗基地，掉盘古箱】
- 小号中立协议舰队（12级海盗协助进攻）（胜）【协助大号进攻，增加掉率】

## 实战结果
大号配合小号刷海盗基地，通过护航或轰炸方式，小号协助，实现盘古箱稳定获取，多开小号可增加产量

## 结论思路
- 盘古船在现代版本作用大，完全体可一打三
- 获取盘古箱方式：未央积分商城、赛季必买、拍卖行、抢海盗基地
- 海盗基地掉率高但数量有限，需抢
- 海盗NPC舰队有概率掉盘古，可还基地后拉封锁守株待兔
- 在基地密集处起工作平台可增加收益，但需防被吃
- 多开小号选中立协议，中期攒积分换五级海盗基地，大号封锁轰炸，小号协助进攻
- 护航比封锁更优，停在小号基地前，隔半分钟派一队，战损可控

## 适用限制
- 需要多开小号，适合有资源玩家
- 小号需选中立协议并攒积分
- 海盗基地数量有限，需抢
- 护航方式需控制战损，避免被坏人吃掉
- 掉率不高，依赖数量堆叠
