# A资料340

## 场景 / 对手
御衡B型号防御型巡洋舰强度分析，无特定对手或环境

## 舰队例子
- 御衡B型号防御型巡洋舰（20人口，协同作战无人艇，掩护护航艇）（负）【单发20实弹伤害，破不了开阳45护甲；掩护效果有限，一场最多掩护2个护航艇，每个只修10%结构值】

## 实战结果
无具体实战记录，仅评测：该舰定位辅助，但性价比低，不如太阳鲸或天权

## 结论思路
- 御衡B型号防御型巡洋舰非常拉胯，意义不明
- 协同作战无人艇伤害低，单发20实弹，破不了常见小船护甲
- 掩护效果鸡肋，一场最多掩护2个护航艇，每个只修10%结构值，有次数限制
- 20人口性价比极低，不如用太阳鲸长期维修或天权掩护同时提升自身属性
- 加点无特色，掩护期间加伤或维修值提升有限，持续时间短

## 适用限制
- 仅适用于需要保护护航艇的舰队，但效果差
- 人口20，不适合高性价比配置
- 当前版本无适合作战环境，不建议使用
