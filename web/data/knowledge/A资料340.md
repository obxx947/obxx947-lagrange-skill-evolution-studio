# A资料340 · 御衡B防御型（原文为"御衡的B型号防御型"，疑似简称）强度评价

## 结论
- 御衡B防御型定位防御奶妈/辅助，整体强度非常拉胯且意义不明
- 协同作战无人艇选择舰队中输出最高的护航艇协同打击同一目标
- 协同无人艇为实弹伤害，单发仅20，连开阳级（原文为"开阳"，疑似简称）45护甲都破不了
- 掩护护航艇功能触发条件为护航艇血量低于35%，提供15秒掩护
- 掩护期间伤害全部由该巡洋舰承担，一场战斗最多掩护2个护航艇
- 每个护航艇只能被掩护一次，被掩护时修复10%结构值
- 维修效果与太阳鲸-武装战略航空母舰（原文为"太阳鲸"，疑似简称）同为10%，但太阳鲸长期生效且无次数限制
- 御衡B防御型维修有次数限制，且只能掩护2个护航艇，非常鸡肋
- 20人口只用来掩护2个护航艇，性价比极低
- 护航艇在扛伤舰队中本身属于消耗品，花20人口提高消耗品生存能力不合理
- 天权级-重型防御战列巡洋舰（原文为"天权"，疑似简称）掩护时还能提高自身属性，御衡B防御型纯掩护无增益
- 加点可提高掩护期间护航艇12%伤害，但掩护仅十多秒，效果不明显
- 加点可提高维修值，但只能掩护一次，约1500左右，提升有限
- 加点可增加掩护目标，一次一个专剑可掩护3个护航艇
- 目前没有适合御衡B防御型的作战环境
- 若人口只有十多点可以考虑，20人口性价比非常低
- 相比御衡其他型号，B防御型用处不大
