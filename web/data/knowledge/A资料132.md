# A资料132

## 场景 / 对手
航母体系，正面作战，环境为常规PVP

## 舰队例子
- 太阳鲸（C1模块，五舰载机双返回+命中/锁敌）+ VB（命中）+ B1模块 + 小米（M1模块）（胜）【最佳空优机库，B1提供星脉50%增伤、VB30%增伤、050增伤20%、风潮增伤30%，小米沙龙防空能力巨大加强】
- 增援舰队：输出护航艇 + 输出战机VA（可替换为小米）（胜）【根据敌对是否航母部队选择更换VA或小米】
- 主舰队：战机 + 舰船输出，不带小米，增加康纳马拉高速数量（胜）【小米可选不带，以增强康纳马拉高速】

## 实战结果
十一鱼体系对抗常规航母舰队，多胜少负，关键得失在于C1模块的载机效率和B1增伤，损失可能为护航艇或战机

## 结论思路
- C1模块是核心载机模块，五舰载机双返回加命中或锁敌
- VB选择命中，其他情况选择锁敌
- 最佳空优机库配合B1获得最强小米
- 增援舰队携带输出护航艇及输出战机VA，根据敌对航母部队更换小米
- 主舰队依靠战机及舰船输出，可减少小米数量增加康纳马拉高速

## 适用限制
- 适用于航母体系正面作战
- 需根据敌对航母部队调整增援配置
- 小米选择需权衡防空与高速舰船数量
