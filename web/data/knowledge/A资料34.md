# A资料34 · 艾奥高速型加点与伤害测试

> 场景：反大/反小靶船测试、高闪避舰船测试

## 结论
- 艾奥级-高速离子炮巡洋舰（原文为"IO高速型"，疑似简称）最优加点为双命中、双伤害、双冷却
- 伤害加点提升最高，不能动；冷却和命中收益都较低
- 策略提供40%命中和20%闪避，但输出收益很低甚至负收益
- 策略对生存提升较大，需要扛伤时可以点
- 艾奥级-高速离子炮巡洋舰反大乏力，反小亮眼，定位为对小船特攻舰船
- 闪避对艾奥级-高速离子炮巡洋舰克制严重
- 点策略后打击高闪避舰船能力反而下降
- 策略命中加成对艾奥级-高速离子炮巡洋舰提升很差，原因待讨论
- 副武器导弹打小船约占总伤害20%，加点对总输出影响不大
- 导弹单发较高，能打动巡洋和航母，打战巡吃力
- 导弹加点方向：四个冷却加一个伤害，剩下两个可选双反小命中、一大一小命中或再上一个伤害

## 配队与模块
- 最优加点：双命中、双伤害、双冷却
- 扛伤加点：放弃一个反小命中，上策略
- 导弹加点：四个冷却加一个伤害，剩余两个可选双反小命中、一大一小命中或再上一个伤害

## 数值与数据
- 最优加点反大分伤16.25万/分钟，单位人口伤害1128
- 最优加点反小分伤20.79万/分钟，单位人口伤害1444
- 反小数据接近21万/分钟，为测试舰船中最高
- 不同加点输出差距约2万/分钟
- 点策略后反大平均伤害15万/分钟
- 下掉一个命中上冷却后反大平均伤害14.71万/分钟
- 8个艾奥级-高速离子炮巡洋舰摧毁10个卡利莱恩级-特种护卫舰（原文为"卡特"，疑似简称）需4分钟
- 面对艾奥级-高速离子炮巡洋舰自身时，分伤仅10.39万/分钟
- 点策略后击杀卡利莱恩级-特种护卫舰需4分36秒
- 巡洋和航母魔抗差距5%，伤害差距接近2万
- 战巡魔抗25%，与航母差距10%，伤害差距接近2万
- 巡洋和战巡魔抗差距15%，伤害差距接近5万
