# A资料567

## 场景 / 对手
攻击循环概念讲解，涉及冷却、锁定、攻击持续，空战与舰船输出对比

## 舰队例子
- 小米（攻击持续16，攻击次数3乘4）（胜/评价：示例）【攻击持续16秒，从零秒开始每隔4秒打一次，每次三发单发；目标死亡时带剩余攻击重新锁敌】
- 雷火（锁定15秒，面板12万）（负/评价：输出被锁定浪费）【打1111万血富贵需一分半，锁定导致输出大量浪费】
- 维塔斯必（降低80%锁定）（胜/评价：对空战机优势）【普通零锁打维塔斯必刮痧，超索可提升输出】
- 古神载机（维修加点增加小米50%武器冷却）（胜/评价：前期适用）【冷却拆分，两秒增加影响小，10%维修提升坦度】

## 实战结果
无具体实战记录，主要理论分析：空战冷却快一秒可决定秒杀与被秒杀；舰船输出受锁定影响大，飞机秒索输出高

## 结论思路
- 攻击循环由锁定、冷却、攻击持续组成，一轮攻击时长不止取决于冷却
- 锁定对实战影响大，目标多单体小则转火耗时多，减少锁定优先
- 冷却对每个船提升不同，空战冷却拉满可决定胜负
- 古神维修加点在前期空战输出不足时适用，后期不适用
- 通过攻击循环可建立秒平均伤害模型，计算加点收益

## 适用限制
- 适用于理解舰队战斗机制和加点计算
- 空战冷却拉满适用于后期空战，前期输出不足时古神维修加点更优
- 减少锁定优先适用于输出船或母舰，尤其空战机需超索
- 不适用于无锁定或特殊机制舰船
