# A资料26 · 先登获取方式与用途

> 场景：星球登陆/控制

## 结论
- 先登蓝图需特定箱子开出碎片合成，共需8个碎片
- 07、08碎片箱最贵，单个约6000群星币
- 01-06碎片可靠诺玛积分箱慢慢获取
- 集齐后合成需3小时
- 先登另一型号没必要拿，只拿主型号
- 先登控制系统与诺玛登陆一致，控制能力并不强
- 先登贵在机库，可带中型两栖战机
- 玩星球登陆副本没先登根本玩不了
- 先登是9人口驱逐舰，血量护甲高，生存能力较好
- 云海、诺玛更容易被打，一般其他船掉得差不多才开始掉先登
- 星球登陆产出好东西，但工作室聚集且老六蹲撤离点，普通玩家难拿
- 不推荐平民玩家花钱获取先登

## 配队与模块
- 先登加点优先重型控制作业系统
- 先登机库只能带中型两栖战机：安德森干扰、砂龙反击防空、理智绝育
- 安德森干扰点闪避
- 砂龙、理智都能打防空，少点一个闪避
- 系统结构不点

## 数值与数据
- 先登人口9，可带2个中型两栖战机
- 07、08碎片箱单个约6000群星币
- 合成时间3小时
