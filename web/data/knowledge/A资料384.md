# A资料384

## 场景 / 对手
驱护优先养哪些，驱逐舰优先级与配队

## 舰队例子
- 斗牛BC型号、系神星BC型号、台原A型号、枪骑兵C型号（胜）【可进胖子队】
- 斗牛A型号、系神星B型号（胜）【可进前期主队】
- 开阳A型号、谷神B型号、玉衡C（胜）【可进小船扛伤队，前提有玉衡C】

## 结论思路
- 驱逐舰优先级：开阳、系神星、斗牛、古乃、财源枪房
- 斗牛BC、系神星BC、台原A、枪骑兵C可进胖子队
- 斗牛A、系神星B可进前期主队
- 开阳A、谷神B可进小船扛伤队，需玉衡C

## 适用限制
- 开阳A和谷神B进小船扛伤队需有玉衡C
- 不同型号适配不同队伍，需按配置选择
