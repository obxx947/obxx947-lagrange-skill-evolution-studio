# A资料375

## 场景 / 对手
对空测试，VST800舰载机，股神与721母舰，满编机库，动力索敌和武器系统点满

## 舰队例子
- 股神母舰（机库满）+ T-800舰载机（动力索敌和武器系统满）（胜）【8对8测试，损失1架，剩余海市】
- 721母舰（机库满）+ T-800舰载机（动力索敌和武器系统满）（负）【8对12测试，未打过】
- 满编15架T-800（胜）【15对8测试，损失7架，优势在我】

## 实战结果
测试T-800对空能力，8对8胜，8对12负，15对8胜，关键损失为15对8时损失7架

## 结论思路
- T-800数量优势明显时胜率更高
- 8架T-800在数量劣势时难以对抗12架
- 满编15架T-800能有效压制8架

## 适用限制
- 适用于对空作战场景
- 需母舰机库满配和舰载机武器系统点满
- 数量劣势时可能失败
