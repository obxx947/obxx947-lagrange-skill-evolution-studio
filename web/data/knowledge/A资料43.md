# A资料43

## 场景 / 对手
卡利安系列舰船解析，前期肉盾和后期直射类大船干扰项

## 舰队例子
- 卡利安主型号（基础血量8340，35%闪避，机动规避每场触发一次）（胜）【作为肉盾，提供约20秒输出环境】
- 卡利安特种型（装甲全点，血量近15000，干扰系统降低主武器70%锁定效率，加点后命中率额外降低30%）（胜）【对艾奥和康纳等直射类舰船不友好】

## 实战结果
卡利安系列在开荒和后期作为万金油，面对直射类舰船有优势，配合光防和防空舰船可威胁轰炸机和炮艇

## 结论思路
- 卡利安系列可贯穿赛季，前期肉盾后期干扰
- 主型号靠闪避和机动规避提供生存，特种型靠干扰系统降低敌方输出
- 适合搭配防空舰船应对轰炸机和炮艇

## 适用限制
- 不擅长输出，需依赖后排输出
- 面对直射类舰船效果显著，但对其他类型可能效果有限
