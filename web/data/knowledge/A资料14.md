# A资料14

## 场景 / 对手
拉格朗日游戏，正常打架（逆风或资源紧缺时）的副队配置，涉及护航和轰炸环境

## 舰队例子
- 毛子（中排，远峰改）+ 7-8个光锥（中排）+ 12个六六奶 + 特卡侦察卡（前排）（胜（护航中即使炸了也不心疼））【远峰改中排享受光锥拦截，策略改不享受；单毛时使用】
- 电磁59 + 光锥 + 六六奶（无毛子C2模块时）（胜（替代方案））【电磁模块优于C1和C3，因前排优先受攻击】

## 实战结果
老陆分享副队配置，强调逆风或资源紧缺时用单毛+光锥+奶+侦察卡，避免琉璃大炮（资源消耗大、炸后恢复慢），实战中护航炸了不心疼；无C2时用电磁59替代

## 结论思路
- 玩毛子必须用远峰改中排，享受光锥拦截，策略改不享受
- 单毛时配7-8个光锥、12个六六奶、特卡侦察卡，护航炸了不心疼
- 避免琉璃大炮，因其资源消耗大且炸后恢复慢，影响基地升级和造船
- 一矛一顿时旗舰盾至少30级（经验书或点子）
- 无毛子C2模块时，优先电磁59，电磁模块优于C1和C3
- 顺风可多造战巡，焦灼或逆风建议只出一个毛子

## 适用限制
- 适用于逆风或资源紧缺时
- 适用于单毛配置，无C2时用电磁59替代
- 不适用于顺风或资源充足时（可多造战巡）
- 不适用于琉璃大炮（资源消耗大）
