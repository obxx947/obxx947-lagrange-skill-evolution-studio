# A资料342

## 场景 / 对手
低赛战巡选择，抗伤战巡对比

## 舰队例子
- 大毛（59大队）+ C2模块 + A2模块 + C3拦截模块，中排（胜）【C2提供540物抗和25%能量抗性，A2旗舰火力倾泻缩短冷却，C3全域拦截替代光防】
- 平民激光59 + C2模块（负）【C2提供能量抗性但受奶量低，物抗低且血量薄，过渡型】
- 重甲59 + C3模块 + B2模块（胜）【用于碰瓷队，B2提供四个中型机位，但不可超斩】
- 天权 + C3模块 + 天书开阳瑶光玉衡C（负）【成型难，输出不如大毛，培养困难，建议1+1后培养】
- 大盾 + C2附加装甲模块（胜）【点满后20%能量抗性和750护甲，旗舰策略庇护作战，护航核心】

## 实战结果
低赛玩家推荐抗伤战巡，大毛和大盾表现优秀，59和天权过渡或难培养

## 结论思路
- 低赛优先培养抗伤战巡，输出战巡可替代性强
- 大毛有C2和C3模块时性价比高，适合低赛使用
- 59是过渡型，有就用，不推荐定向培养
- 天权成型难，不适合低赛，大佬可培养
- 大盾是最能扛的战巡，旗舰策略庇护作战，强烈推荐低赛定向培养

## 适用限制
- 适用于低赛玩家，资源有限
- 大毛需C2和C3模块才强，否则定位尴尬
- 59不适合高配护航队，仅低赛可用
- 天权需大量模块支持，获取难度高
- 大盾需点满C2模块和旗舰策略
