# A资料652 · 康纳马拉混沌轨道炮解析

> 场景：测试靶船：中甲乌拉诺斯之矛（原文为"大毛"，疑似疑似语音识别错误）、CAS066级-支援巡洋舰（原文为"六十六支援"，疑似简称）、开阳级；3分钟满编128人口

## 结论
- 定位输出，主火力为AR2500C型轨道炮，是现版本少数可规避激光且打穿重甲的火力。
- 轨道炮基础命中率仅50%~70%，被高闪避目标克制，打中甲也吃力。
- 加点优先冷却、输出增幅点满；命中不足需靠命中加点弥补。
- 命中加点推荐通用、命中；当前前排多为小船，反大命中打小船不生效。
- 剩余三个蓝位绑定策略与双伤害；策略为正向收益，伤害增幅大于反大命中。
- 输出不稳定，但按人口输出合格，属合格输出点；单船仅16人口。
- 策略可调校缩短启动时间；调校后输出有提升，打中甲提升较小。
- 满编测试总输出不高；打闪避和中甲效果差，闪避天然克制，中甲削减面板。

## 配队与模块
- 康纳马拉混沌级-轨道炮巡洋舰（轨道炮型A）（原文为"康纳马拉混沌级轨道炮巡洋舰"，疑似简称）搭载AR2500C型轨道炮作为主要火力。
- 主炮加点六格：冷却、输出增幅优先点满。
- 命中加点推荐通用、命中；剩余三蓝位绑定策略与双伤害。
- 策略可调校以减少启动时间。

## 数值与数据
- AR2500C型轨道炮点满单发1500。
- 轨道炮基础命中率50%~70%。
- 测试靶船：中甲乌拉诺斯之矛护甲540；CAS066级-支援巡洋舰护甲80；开阳级闪避率70%以上。
- 测试时长3分钟，康纳马拉混沌级-轨道炮巡洋舰（轨道炮型A）满编，总128人口；单船16人口。
- 每人口输出可破1000。
- 中甲540护甲使单发1500伤害削减约三分之一。
- 策略调校后，3分钟输出提升约20%；打中甲提升较小。
