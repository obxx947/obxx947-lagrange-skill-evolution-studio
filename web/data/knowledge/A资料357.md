# A资料357

## 场景 / 对手
超主力船坞控制，对手为守军（含反登陆、反小），正面作战，环境为星系橙皮伤害低

## 舰队例子
- 盾（旗舰）+零六六+猎兵+狩猎级，飞机：八百+海事（可换小米），清迈可换蜂巢或坦克，带一个云海（胜）【第一队用于打城防，盾扛伤，飞机生存无忧】
- 满奶+登陆，不用零六六（胜）【第二队用于控制进度，厌烦后撤退】

## 实战结果
鲤鱼王打超主力船坞守军，共接站八队，损失一个云海，第二队仅掉血皮，厌烦两次后控制完成，胜

## 结论思路
- 建停机坪区库，调动到停机坪，主队控制，区户跟上
- 进度到5%时出四队守军，第二队厌烦撤退
- 盾血量不低于四分之一，慢慢磨守军
- 进度到30%时出第二次守军，再次厌烦后不再出守军
- 清完第二波守军后开始控制可满血
- 白板盾即可，防御点满，利用旗舰坦度

## 适用限制
- 适用于超主力船坞控制，守军有反登陆和反小
- 需厌烦大法规避伤害
- 进度过高会被八队夹击，扛不住
- 打太慢可增援输出，不想浪费体力就慢慢磨
