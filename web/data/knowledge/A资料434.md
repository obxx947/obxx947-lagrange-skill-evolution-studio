# A资料434

## 场景 / 对手
大地反制与破解反制，对手为奶巡队（高护甲战巡、回血多、拦截大），正面作战，环境为舰队对抗

## 舰队例子
- 锁穴大毛（战巡，直射火力）（胜）【用于快速解决前突光防】
- 大剑（巡洋，优先锁光防）（胜）【通过快速打击光防使其下场】
- 回避、超展海（能量输出舰船）（胜）【无视站位，高额能量伤害，针对高护甲战巡】
- 莱西市066（打巡洋舰，断奶流）（胜）【降低奶量，削弱战巡续航】

## 实战结果
大地面对奶巡队，通过舰队配合可破解反制，但需满足条件；未提及具体胜负次数，关键得失为拦截和高护甲是硬伤，需直射火力、能量伤害和断奶流配合

## 结论思路
- 拦截是大地最大硬伤，需强大直射火力快速解决前突光防
- 高护甲战巡需能量伤害（如回避、超展海）快速打掉
- 暴击策略触发可提升输出，即使面对高护甲也能造成伤害
- 断奶流（如莱西市066）可降低奶量，削弱战巡续航
- 大地本质是助攻输出单，需舰队提供实际对舰火力基础
- 舰队需具备直射火力、超斩火力、反小能力等条件

## 适用限制
- 适用于高刻度舰队，能提供强大直射火力和能量伤害
- 中低刻度若无法触发暴击策略，大地输出腰斩，性价比低
- 条件苛刻，需满足多种火力要求，否则难以破解反制
