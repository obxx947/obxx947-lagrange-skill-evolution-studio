# A资料16

## 场景 / 对手
落地初期打架，资源紧缺，过渡到巡洋阶段

## 舰队例子
- 双鱼海 + 水母 + 特卡（4-6个）+ 谷神星（10个，带小米和VA）+ 西神重炮（增援）（胜）【资源要求少，过渡到巡洋】
- 泡泡龙（8个）+ 高速IO（8个）+ 水母（2个）+ 猎兵（5个增援）（胜）【300人口过渡，泡泡龙高单发高频率】
- 泡泡龙或高速IO（先造8个）+ 水母 + 余海脉冲（替代）（胜）【过渡阶段配件灵活，余海脉冲两分钟爆发不弱于水母】

## 实战结果
老六分享落地初期打架的过渡配置，强调资源紧缺下优先双鱼海配水母，过渡到巡洋泡泡龙和高速IO，未提及具体胜负

## 结论思路
- 落地初期资源紧缺，优先选择资源消耗少的配置，如双鱼海配水母
- 点子够时优先双鱼海，点子不够才考虑诺玛奶
- 过渡阶段配件要灵活，不要死板，可用余海脉冲替代水母
- 巡洋阶段优先造泡泡龙，高单发高频率，配合高速IO和水母
- 增援可用西神重炮或猎兵，提升战斗力

## 适用限制
- 适用于落地初期资源紧缺的打架场景
- 适用于点子够的情况，点子不够需调整配置
- 不适用于资源充足或后期阶段，后期可考虑航母
- 雷影等昂贵船只在资源紧缺时不推荐，适合前版本
