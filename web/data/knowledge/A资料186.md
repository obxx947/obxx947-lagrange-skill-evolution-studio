# A资料186

## 场景 / 对手
飞机与艇的加点攻略，针对萌新和高级玩家，涉及空战、对舰、轰炸等体系

## 舰队例子
- T800：1锁定、2冷却、2伤害、1策略，动力2频率（萌新）；2频率、2冷却、1伤害、1策略（高级）（胜）【萌新推荐放猎兵走超斩，空战伤害不足】
- 坦克：策略、3维修、3附加，动力频率加满（胜）【不点阵型，避免降伤害和统一锁定，分奶效果差】
- 星脉：1命中、3伤害、2冷却，动力2频率（胜）【伤害做满，不点命中】
- 蜂巢：2频率、2伤害、2暴击，动力2频率（胜）【南十字加强后可用，适合有难时】
- 波A：3维修、1频率、2冷却，动力2频率，闪避策略（胜）【闪避策略可点】
- 波B：3冷却、1频率、3维修、1频率、2冷却，动力2频率（胜）【策略不同，推荐主动机动A】
- 天机A：3结构、3闪避，不点频率（胜）【挡刀近身，优先装甲】
- 天机B：与A类似（胜）【策略相同】
- 列维：1策略、第二排4个全点，下3随意，频率冷却加一（胜）【吃前两轮，打完就废】
- VB：1频率、中排4个、1暴击，动力3频率（胜）【不点空城、闪避、命中】
- BR050：暴击、1命中、1伤害、2伤害、2冷却，动力3频率，指挥系统加频率（胜）【吃命中，快速鱼雷策略】
- 次瑶：1暴击、1冷却、1策略、1频率、1伤害，命中可选，动力3频率（胜）【闪避用于副队，主队用攻击】
- 小米：1策略、2策略、频率、命中、2冷却，动力2频率、1命中、1频率（胜）【只做空战，不做对舰，不点暴击】
- 凌霄：中3下3，动力中排4个，指挥点反超主力（胜）【只推荐上苍穹，否则打不出伤害】
- V：乘胜追击、暴击，频率、伤害，动力3频率（胜）【矿船神器，不点拦截】
- 用歪：1频率、1策略、暴击，上1中4下1（胜）【加强后比新大帝有用，点拦截】

## 结论思路
- T800萌新推荐1锁定、2冷却、2伤害、1策略，高级用2频率、2冷却、1伤害、1策略
- 坦克不点阵型，避免降伤害和统一锁定
- 星脉伤害做满，不点命中
- 蜂巢用2频率、2伤害、2暴击
- 波A/B用3维修、频率、冷却，动力2频率
- 天机A/B优先装甲和闪避，不点频率
- 列维吃前两轮，策略加第二排全点
- VB不点空城、闪避、命中
- BR050吃命中，用快速鱼雷策略
- 次瑶主队用攻击，副队用闪避
- 小米只做空战，不点暴击
- 凌霄只推荐上苍穹，指挥点反超主力
- V点乘胜追击和暴击，不点拦截
- 用歪加强后值得养，点拦截

## 适用限制
- 萌新和高级玩家加点不同
- T800适合空战或超斩
- 坦克避免轰炸和正面冲突
- 蜂巢需南十字加强
- 小米不适合对舰
- 凌霄需苍穹支持
- 列维只适合前两轮
- 飞机整体弱势，艇是主流
