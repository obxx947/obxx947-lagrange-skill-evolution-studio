# A资料186 · 战机与护航艇加点梳理

## 结论
- 萌新T800推荐走猎兵级-重型载机巡洋舰（原文为"猎兵"，疑似简称）超斩路线，不点双锁定
- T800空战伤害不足时，满锁意义有限
- 坦克策略上三下三加满即可
- 三维一体阵型会降伤害且统一锁定目标，分奶效果差，不推荐点
- 三维一体阵型优先攻击航母和战巡，对CAS066级-通用巡洋舰（原文为"066"，疑似简称）分奶效果很好
- 星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）不要点命中，伤害做满即可
- 蜂巢守卫者-重型鱼雷艇（原文为"蜂巢"，疑似简称）在南十字星元帅级-武装航空母舰（原文为"南十字"，疑似简称）加强后可用
- 蜂巢守卫者-重型鱼雷艇不考虑拦截，直接堆频率、伤害、暴击
- 海尔波普-系统支援护航艇（原文为"波a"，疑似语音识别错误）闪避策略可以点
- 海尔波普-维修支援护航艇（原文为"波b"，疑似语音识别错误）推荐点主动机动A策略
- 当前反艇主要靠CV-T800型-脉冲炮艇（原文为"T800"，疑似简称），米斯特拉-战斗攻击机（原文为"小米"，疑似简称）打对面战机作用有限
- 天玑-攻击护航艇（攻击B型）（原文为"天机A"，疑似语音识别错误）优先加装甲，鱼雷伤害无所谓，主要作用是挡刀
- 天玑-攻击护航艇（攻击B型）不点频率，点三结构三闪避
- 天玑-攻击护航艇（攻击B型）与天玑-攻击护航艇（攻击B型）策略基本一致
- S-列维9号-重型鱼雷艇（原文为"列维"，疑似简称）主要靠前两轮伤害，之后基本没输出
- S-列维9号-重型鱼雷艇点一个策略加第二排四个，剩余点位加频率和冷却
- S-列维9号-重型鱼雷艇不塞副队，闪避不用加
- 当前战机整体弱势，护航艇才是输出主流
- 维塔斯-B010-轰炸机（原文为"VB"，疑似简称）不需要加攻城、闪避、命中
- BR050-标准轰炸机（原文为"050"，疑似简称）比较吃命中
- BR050-标准轰炸机策略推荐快速鱼雷，不点攻击系统
- BR050-标准轰炸机指挥系统里的频率必须加，提升很大
- 刺鳐-鱼雷轰炸机（原文为"次爻"，疑似语音识别错误）推荐攻击系统，不点闪避
- 刺鳐-鱼雷轰炸机配置高且放主队第一个机位时可以用闪避
- 刺鳐-鱼雷轰炸机命中看个人喜好，可选命中五步点罚两阙
- 米斯特拉-战斗攻击机只推荐做空战，不推荐做对舰
- 米斯特拉-战斗攻击机单发伤害10，连护卫舰都打不动
- 米斯特拉-战斗攻击机绝对不要点暴击
- 林鸮A100型-联合攻击机（原文为"凌霄"，疑似语音识别错误）只推荐上永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称），否则打不出伤害
- 林鸮A100型-联合攻击机指挥需要点反超主力目标，否则绝育不了大盾的指挥系统模块
- 维塔斯A021-重型攻击机（原文为"v"，疑似简称）是矿船神器，乘胜追击和暴击要点
- 维塔斯A021-重型攻击机不需要点拦截，直接堆频率和伤害
- 沙龙很强、先养小米等说法基本是错误观点
- 用歪的船最近加强了，加了新策略，伤害绝对比养新君士坦丁大帝级-综合战列巡洋舰（原文为"养新大帝"，疑似语音识别错误）有用
- 用歪的船弹药次数比BR050-标准轰炸机少很多，冷却时间偏长
- 阋神星I级-机动突击驱逐舰（原文为"岩神星A"，疑似语音识别错误）、虚灵-隐身导弹艇（原文为"虚零零幺幺"，疑似语音识别错误）等基本没用

## 配队与模块
- 萌新T800加点：一锁定、两冷却、两伤害、一策略，动力两频率
- 高级T800加点：两频率、两冷却、一伤害、一策略
- 坦克策略上三下三加满，动力只点频率
- 星云追逐者-脉冲炮艇：上一中三下二，动力两频率
- 蜂巢守卫者-重型鱼雷艇：两频率、两伤害、两暴击，动力两频率
- 海尔波普-系统支援护航艇：三维修、一频率、两冷却，动力两频率，闪避策略可点
- 海尔波普-维修支援护航艇：三冷却、一频率、三维修、两冷却，动力两频率，点主动机动A策略
- 天玑-攻击护航艇（攻击B型）：三结构、三闪避，不点频率
- S-列维9号-重型鱼雷艇：一个策略加第二排四个全点，剩余点位加频率和冷却
- 维塔斯-B010-轰炸机：一频率、中排四个、一个暴击，动力三频率
- BR050-标准轰炸机：暴击、命中、一伤害、两伤害、两冷却，动力三频率，指挥系统频率必加
- 刺鳐-鱼雷轰炸机：一个暴击、一个冷却、一个策略、一频率、无伤害，动力三频率
- 米斯特拉-战斗攻击机：两个策略、频率、命中、两冷却，不点伤害和暴击，动力两频率、一命中、底下一个频率
- 林鸮A100型-联合攻击机：中三下三，动力中排四个点完，指挥点反超主力目标
- 维塔斯A021-重型攻击机：乘胜追击、暴击、频率、点伤害，动力三频率
- 用歪的船：一个频率、法兰杰斯可点、上衣中周四、下面一个策略、暴击点下，频率点一下

- BR050-标准轰炸机指挥系统频率提升约十五的左地
- 维塔斯A021-重型攻击机一次可打一乘四
