# A资料127 · 无航母无飞机控艾格勒姆配船

> 场景：艾格勒姆控场

## 结论
- 无航母无飞机时，可用高伤害快速锁敌小船替代控场
- 对舰控制优先选刺水母、狼蜥、雨海脉冲、雷里亚特、创神星鱼雷
- 对空混合控制可搭配谷神星或狩猎者，配米斯特拉
- 无对空需求时找纯对舰控制点
- 前排可用阋神星ABC型、特种卡利莱恩、防御斗牛、防御红宝石
- 奶船可用谷神星支援、苔原登陆舰、诺玛M470或云海
