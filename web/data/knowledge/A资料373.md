# A资料373 · 列维九号重型鱼雷艇强度与加点

> 场景：当前副队拦截人口减少、直射穿防慢的环境

## 结论
- 强度在T级，当前环境地位在上升
- 鱼雷怕拦截，与重卡类似
- 副队要带奶船、开阳、玉衡、瑶光、超主力，留给拦截的人口很少
- 拦截效果下降，投射武器地位上升
- 当前强度至少比直射更强
- 开阳环境下直射三分钟内打不出有效伤害
- 直射伤害与投射差不多，但换战损很难
- 多超主配置中它不是最强一批，只能当替代
- 策略前两轮穿防，无视护甲
- 打大盾前两轮可多约700点伤害
- 策略约一分半失效，属于前期短收益
- 基础命中太低，命中必点
- 鱼雷命中率普遍只有50到70
- 伤害加点收益相对更高，但单发加点只有1500
- 打500护甲目标伤害少约三分之一
- 伤害比坦克高，但坦克免疫拦截
- 暴击必点，其余加点都不理想
- 冷却和索敌不点
- 攻击循环约30秒，冷却收益极低
- 猎兵母舰提供约70%索敌，打超主力不需要频繁转火
- 打小船和空军才需要频繁转火
- 动力系统往返必点，相当于变相减冷却
- 打击时间必点
- 点满变形需要约160点，在护航艇里消耗很高
- 其他护航艇约100点就够用

## 配队与模块
- 刚需猎兵级载机，才能把收益最大化

## 数值与数据
- 大盾护甲约700点
- 大矛护甲约500点
- 猎兵超转不拦截时，一分钟约十多万伤害
- 有拦截时一分钟约六七万到七八万
- 加上大段减伤后一分钟约三四万到四五万
- 冷却时间只有4秒
- 攻击循环约30秒
- 往返加点降30%
- 点满变形需要约160点
