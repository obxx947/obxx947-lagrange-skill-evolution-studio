# A资料373

## 场景 / 对手
当前作战环境，副队元素多，拦截人口减少，投射武器地位上升

## 舰队例子
- 列维九号重型鱼雷艇（加点：策略、命中、伤害、暴击、动力系统往返、打击时间）（胜）【强度T级别，怕拦截但当前拦截减少，有效伤害高】

## 实战结果
列维九号在猎兵超转不拦截情况下，一分钟约十多万伤害，与新麦相当；拦截时降至六七万，加大段减伤后三四万

## 结论思路
- 列维九号强度在T级别，当前环境拦截减少，地位上升
- 策略必点，前两轮穿防，对大盾多700伤害
- 命中必加，基础命中低（鱼雷命中率50-70）
- 伤害和暴击要点，收益相对较高
- 冷却和索敌不点，攻击循环长，收益低
- 动力系统往返和打击时间必点，相当于冷却
- 点满变形需160点，消耗高但强度OK

## 适用限制
- 怕拦截，拦截多时伤害大幅下降
- 适合多超主配置，但非最强，是虾皮替代
- 需要猎兵母舰支持，否则收益低
- 打超主力有效，打小船需频繁转火，索敌不足
