# A资料488

## 场景 / 对手
载机巡洋舰列兵使用讨论，涉及300/320人口配置、13鱼、星脉800等体系

## 舰队例子
- 列兵载机巡洋舰（自带70%检索，用于补艇位）（胜）【适合300/320人口，配合13鱼或星脉800时需注意检索和解锁】
- 列为9号护航艇（三发鱼雷，往复式飞行）（负）【此版本不建议使用，因光锥拦截，三发仅中一发，收益低】
- 列兵子型号（实弹伤害）（负）【人口占用多，收益低，仅用于污染卡池，不建议使用】

## 实战结果
无具体实战记录，主要讨论列兵及其子型号的适用性，强调列为9号因拦截问题表现差

## 结论思路
- 列兵自带70%检索，用于补艇位时需注意检索和解锁条件
- 列为9号因往复式飞行和光锥拦截，三发鱼雷仅中一发，收益低，此版本不建议使用
- 列兵子型号人口占用多且实弹伤害收益低，不建议使用

## 适用限制
- 列兵适用于300/320人口配置，配合13鱼或星脉800时需检查检索
- 列为9号不适用于当前版本，因拦截问题导致命中率低
- 列兵子型号不推荐，因人口和伤害效率差
