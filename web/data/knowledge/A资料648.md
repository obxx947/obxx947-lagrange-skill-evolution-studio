# A资料648

## 场景 / 对手
盟战/单挑，多超主力配置

## 舰队例子
- 大盾（白板，无核心模块）（胜）【作为旗舰提供30%减伤，零成本高收益】
- 大盾（有核心模块）（胜）【单超主力配置中作为抗伤主力】

## 实战结果
多超主力配置中，氪佬带1-2个大盾，主要利用旗舰技能；大盾在抗伤外功能性和输出不足，不如风暴、天权和大毛

## 结论思路
- 大盾旗舰技能30%减伤，白板可用，是核心优势
- 多超主力配置中，大盾仅作旗舰，其他超主力毕业，零成本高收益
- 氪佬追求抗伤外的功能性和输出，大盾不满足
- 大毛伤害稳定、全域拦截，前排更稳定，大盾仅剩旗舰优势

## 适用限制
- 适用于多超主力配置，利用旗舰技能
- 不适用于需要高输出或高功能性的场景
- 单超主力配置中，有核心模块时作为抗伤主力
