# A资料429

## 场景 / 对手
游骑兵离子舰船评价，对比泡泡龙、高速艾奥、攻坚艾奥

## 舰队例子
- 游骑兵离子（离子轮炮设施，输出型鸟）（负）【伤害叠满略高于泡泡龙，但尿分叉和设施惩罚严重，难以快速打穿前排】
- 泡泡龙（输出型鸟）（胜）【优于游离子，集中火力】
- 高速艾奥（输出型鸟）（胜）【优于游离子】
- 攻坚艾奥（输出型鸟）（负）【弱于游离子】

## 实战结果
游骑兵离子在输出型鸟中排名第三，低于泡泡龙和高速艾奥，高于攻坚艾奥；组队通常放两种输出鸟，不缺图时不上场

## 结论思路
- 游离子两个武器输出基本相同，自带尿分叉属性，雨露均沾输出是最大缺点
- 离子轮炮设施惩罚严重，胆小乏力，不能快速打穿前排
- 伤害叠满略高于泡泡龙，但缺点无法弥补，加强后仍是牢船

## 适用限制
- 适用于输出型鸟对比场景
- 组队有足够输出鸟时不宜使用游离子
- 不适用于需要集中火力快速击破前排的战术
