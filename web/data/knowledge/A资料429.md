# A资料429 · 游骑兵离子强度评价

## 结论
- 强度排序：康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡龙"，疑似简称）＞艾奥级-高速离子炮巡洋舰（原文为"高速艾奥"，疑似简称）＞游骑兵级-重型离子炮巡洋舰（原文为"游离子"，疑似简称）＞艾奥级-攻坚离子炮巡洋舰（原文为"攻坚艾奥"，疑似简称）
- 组队一般放得下两种输出型巡洋舰，不缺图时游骑兵级-重型离子炮巡洋舰不会上场
- 两个武器输出基本相同，自带尿分叉属性，无法集中火力
- 配输出队最忌讳雨露均沾的输出，舰船同理，这是最大缺点
- 离子炮设施惩罚严重，胆小乏力，不能快速打穿前排
- 伤害叠满后略微高于康纳马拉混沌级-高速等离子体巡洋舰，但不足以弥补缺点
- 加强后依然不推荐使用
