# A资料503

## 场景 / 对手
石榴鱼（16鱼）航母配置讨论，涉及地推航母、战机加成、护航艇模块

## 舰队例子
- 鱼（航母）+ B1维修模块 + M机库模块，带维币、小米、沙龙、新麦、坦克等战机（胜）【B1提供往返和冷却加成，使战机面板大幅提升，如维币对界面加成1100，小米面板200，沙龙冷却加成500多】
- 16鱼（航母）+ C1 + M2 + B2模块，带3个护航艇（负）【抛弃B1灵魂，仅增加3个护航艇，护航艇伤害低且易被拦截，作用有限】

## 实战结果
有鱼玩家普遍不用16鱼，16鱼需集齐所有载具模块但作用最低，被比喻为‘跟狗抢粪吃’

## 结论思路
- B1是鱼的灵魂，提供机库高加成（15往返和3%伤害），是地推最强航母的关键
- 16鱼抛弃B1换取仅4格加点的护航艇模块，只能带3个艇，性价比极低
- 战机在护航中伤害有限，除个别无法拦截的武器外，多数攻击机轰炸机效果差
- 16鱼需集齐所有核心模块但发挥最差，不推荐使用

## 适用限制
- 适用于有鱼且拥有B1模块的玩家，强调B1对战机加成的核心作用
- 不适用于无鱼玩家或追求护航艇输出的场景，16鱼配置应避免
- 战机选择需依赖往返和冷却加成，如维币、小米、沙龙等
