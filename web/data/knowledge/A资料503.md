# A资料503 · 锐评十六鱼：抛弃灵魂的配置

> 场景：航母载机配置对比

## 结论
- 十六鱼是抛弃鱼灵魂的配置，不推荐玩
- 鱼的灵魂是B1维修模块，提供高额机库加成
- 单看M机库加成，鱼与CV3000级-快速航空母舰（原文为"cv"，疑似简称）相同
- B1模块额外提供15%往返和3%伤害加成
- 十六鱼仅换来一个只有4格加点的护航艇模块，只能带3个艇
- 十六鱼是13机3艇配置，战机在护航中打不出高伤害
- 除回避、林鸮A100型-联合攻击机（原文为"凌霄"，疑似语音识别错误）等无法被拦截的武器外，攻击机轰炸机伤害很低
- 十六鱼抛弃机库高加成，换取的提升非常不值当
- 十六鱼需要集齐鱼的所有核心模块，但作用是所有鱼中最低的

## 配队与模块
- 十六鱼配置：C1+M2+B2，13机3艇
- B1维修模块：提供15%往返和3%伤害加成
- M机库加成：双返回、双冷却、双伤害、一命中

## 数值与数据
- 维塔斯-B010-轰炸机（原文为"维币"，疑似语音识别错误）对界面板加成1100来自往返加点
- 米斯特拉-战斗攻击机（原文为"小米"，疑似简称）面板加成200来自往返加点
- 砂龙-大气层拦截机（原文为"沙龙"，疑似语音识别错误）一格冷却加500多面板
- B1模块的往返和冷却在同一格子上
