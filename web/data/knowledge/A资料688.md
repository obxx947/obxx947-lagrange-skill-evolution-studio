# A资料688

## 场景 / 对手
游戏《无尽的拉格朗日》护航队配置讨论，涉及第一、二、三阶段护航，针对主力队输出、战损交换、拦截与减伤机制

## 舰队例子
- 第二阶段护航1.0版本：主队含风暴、大帝、苍穹、玉衡等，副队含拦截船、奶船（胜）【强调少上风暴，换大帝以提升拦截效果，减少战损】
- 第三阶段护航：核心为分伤，含苍穹（不点分散作战）、凌霄（点返回提升伤害）、列维等（胜）【分伤机制，避免绝育船集中，提升生存】
- C1/C2选择：C1用对舰船（如050、次瑶），C2用于战巡、航母、巡洋（负）【C1对高甲目标无效，C2更优】

## 实战结果
玩家讨论护航队配置，强调换战损、拦截减伤，未提及具体对战记录，但指出配置优化可提升胜率

## 结论思路
- 护航队核心是换战损，强输出船固定，需在有限时间内最大化输出
- 第二阶段护航减少风暴，增加大帝，利用拦截减伤，层层剥削敌方输出
- 第三阶段护航核心是分伤，避免集中打击，提升生存
- 拦截在副队中需配合奶船，否则效果有限
- 能量伤害和闪避高的船更优，避免输出单一
- C1适合对舰船，C2适合打高甲目标，根据敌方配置选择

## 适用限制
- 适用于刚入手玩家，需理解护航阶段机制
- 拦截需配合奶船，否则不推荐
- C1不适合高甲目标，需根据敌方配置选择
- 苍穹不点分散作战，避免绝育船集中
- 配置需根据自身船池和模块调整
