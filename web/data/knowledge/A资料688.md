# A资料688 · 护航三阶段与副队改版

> 场景：护航体系/副队减伤/主队输出

## 结论
- 护航分第一、第二、第三阶段，第三阶段核心是分伤。
- 第二阶段护航1.0模板已发布，本期讲改版。
- 主队强输出船固定，护航队在有限时间内换战损。
- 大部分玩家主力护航队成型依赖第二阶段模板。
- 目标打的船越少越好，优先超斩、全干盾。
- 副队改版核心：用新君士坦丁大帝级替代永恒风暴级；永恒风暴级不是高输出船。
- 新君士坦丁大帝级兼开荒，没有该船难上榜。
- 拦截是副队对主队输出的减伤，但减伤层层剥削，带少拦不住。
- 拦截主要针对导弹和鱼雷，直射武器不受拦截。
- 副队常见减伤为拦截与奶船；拦截不足时不如不上拦截。
- 队伍伤害类型覆盖M2能量、永恒风暴级能量、维塔斯-B010-轰炸机（原文为"维B"，疑似简称）能量、林鸮A100型-联合攻击机（原文为"林鸮"，疑似简称）能量、无人艇，避免输出单一。
- 组队需考虑能量闪避足够高的船。
- C1适合对舰船，但BR050-标准轰炸机（原文为"050"，疑似简称）单发500难破甲；C2可打战巡、航母、巡洋，刻度升高后可斩超主力。
- 苍穹不点分散作战，避免多艘绝育船打同一目标。
- 苍穹点返回可提升林鸮A100型-联合攻击机伤害，因协同作战无人艇有返回。
- 不推荐加成低的选择，可考虑S-列维9号-重型鱼雷艇（原文为"列维"，疑似简称）。

## 配队与模块
- 第二阶段护航1.0：3台永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）；强绑定C2。
- 搭配玉衡级-支援巡洋舰（原文为"玉衡"，疑似简称）组合。
- 副队：少上2台永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称），改上新君士坦丁大帝级-综合战列巡洋舰（原文为"大帝"，疑似简称）。
- 新君士坦丁大帝级模块：C2载机可打巡洋/战巡/航母，C1适合对舰船；高刻度C2可斩超主力。
- 永恒苍穹级：不点分散作战；点返回提升林鸮A100型-联合攻击机伤害；协同作战无人艇提供返回。
- 副队拦截：光锥级-区域防空巡洋舰（原文为"光追"，疑似语音识别错误）全图拦截；针对导弹和鱼雷。
- 副队减伤：常用奶船；必要时上两个普鲁图斯之盾级-防护战列巡洋舰（原文为"大梯"，疑似语音识别错误）。
- 伤害类型：M2能量、永恒风暴级能量、维塔斯-B010-轰炸机能量、林鸮A100型-联合攻击机能量、无人艇。
- 可选S-列维9号-重型鱼雷艇；不推荐加成低的选择。

## 数值与数据

- 强绑定模块不超过5个。
- 新君士坦丁大帝级只需几十个点数。
- 蜂巢守卫者-重型鱼雷艇（原文为"蜂巢"，疑似简称）可发射1000发蜂巢。
