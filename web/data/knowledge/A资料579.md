# A资料579

## 场景 / 对手
针对C2太阳鲸全对舰航母的争议，回应玩家关于防空能力的质疑，并分析护航队配置思路

## 舰队例子
- C2太阳鲸（8+6），M1+M2模块，全对舰配置，携带坦克、星脉等强力护航艇，无C1模块（胜）【作者认为最强，输出能力突出，但防空依赖队伍其他舰船】
- 太阳鲸（11+13），携带小米、雷神、风暴（能量补偿）、凌霄、海氏追随者、T800（负）【玩家投稿，防空配置看似全面，但实际防空能力有限，被轰炸后仍需撤退】
- 太阳鲸（5+6），携带T800、小米、海氏追随者、抗马拉狩猎，无C2无人机（负）【常见配置，机位紧张，无法携带轰炸机，防空能力不足】

## 实战结果
作者回应玩家质疑，强调C2太阳鲸全对舰配置的合理性，认为防空应由队伍其他舰船承担，而非航母本身；玩家投稿显示防空配置在实际战斗中效果有限

## 结论思路
- C2太阳鲸全对舰配置是最强选择，输出能力优先，防空由队伍其他舰船负责
- 6鱼太阳鲸不推荐，因护航艇数量有限，且需另起航母压缩人口
- 配船应从备战角度出发，追求极致输出，而非过度关注防空
- 团战胜负取决于活跃度，而非单一配船，防空问题可通过走位和团队协作解决

## 适用限制
- 适用于有强力护航艇（如坦克、星脉）的玩家
- 需要队伍其他舰船提供防空支持
- 不适用于缺乏团队协作或活跃度低的场景
- 不适合追求全面防空或依赖航母对空的玩家
