# A资料87

## 场景 / 对手
主星系打架导致太阳鲸大毛等舰船无法下副本，使用CV3000控制副本

## 舰队例子
- CV3000（M3：两频率、两伤害、一命中；A2：一频率、二伤害、一命中；装甲：二物理抵抗、二结构；动力：一闪避、二常规、一驱率；B4无人机系统：两伤害、三频率）（胜）【可连续控制二级副本，控制五级会掉一两个小船，混合五级掉较多舰载机】

## 实战结果
橙子使用CV3000配队控制副本，可多次连续控制二级，控制五级有损失

## 结论思路
- CV3000配队可连续控制二级副本
- 控制五级副本会掉小船，混合五级掉较多舰载机
- 加点方案为M3两频率两伤害一命中，A2一频率二伤害一命中，装甲二物理抵抗二结构，动力一闪避二常规一驱率，B4两伤害三频率

## 适用限制
- 适用于副本控制，不适用于主星系战斗
- 密集陨石干扰时无法控制
- 控制五级副本有损失，混合五级损失更大
