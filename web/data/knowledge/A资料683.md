# A资料683

## 场景 / 对手
风暴超主模块讲解，涉及单队/现版本环境、正面输出、抗伤、防空等

## 舰队例子
- 风暴m1 + 挺毛（战巡搭配）（胜（历史单队时期））【老版本单队时期前排集火反大武器，现版本下水道】
- 风暴m2 + 海氏步点超斩（负（乱奶效果有限））【尝试扰乱溜溜奶，但概率低，实际意义不大】
- 风暴c1 + 毛（单队solo）（胜（单队作战））【防空优势可演化成压倒性胜利，适合单挑队】
- 风暴c3（能量补偿）（胜（抗伤核心））【坦度大幅提升，接近电磁五九，抗伤队核心】
- 风暴d1（直射离子炮）（胜（对大型舰船））【对前排矛/盾伤害不错，对小船或高闪避表现一般】
- 风暴d2（自拦截）（胜（配合拦截盾））【用于网上队，可省光防，但输出时非优先】

## 实战结果
风暴m1在单队时期高克配对中表现优秀，现版本无用；m2为现版本核心，但乱奶效果有限；c3抗伤核心，c1单队有用，c2鸡肋；d1输出优先，d2看需求

## 结论思路
- m1模块现版本基本无用，属下水道
- m2是现版本核心，用于保底伤害、补刀和压血线
- m2乱奶效果有限，因出伤速度慢于维b等，难以致命影响奶量
- a2优于a1，因多高攻城伤害，a3数值低且武器系统有抽风问题，不建议用
- b1略优于b2，但两者都只是添头，影响不大
- c1防空对轰炸无效，但单队solo中有用
- c2激光护盾机制改进但意义不大，持续时间长且加目标不准
- c3能量补偿是核心，大幅提升坦度
- d1对大型舰船伤害不错，d2有自拦截但输出时非优先

## 适用限制
- m1仅适合老版本单队时期，现版本不推荐
- m2乱奶需特定条件（如第一条战巡死亡后），概率低，不依赖此效果
- a2适合推城，a1可替代，a3不建议使用
- c1仅适合单队solo，对轰炸无效
- c2不适合实战，c3是抗伤核心
- d1适合对大型舰船，d2适合特定配队（如网上队）
