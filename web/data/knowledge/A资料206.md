# A资料206

## 场景 / 对手
新手配对误区，针对开阳瑶光体系成型后的对抗，正面作战

## 舰队例子
- 主队：狩猎海市VA（可替换为凌霄、烈冰）+ 风暴M2 + 水母无人机（胜）【超斩集中伤害，配合风暴M2和水母进行斩杀】
- 增援：五航母 + VVBR + 零五零 + VA + 索姆 + 八零零（胜）【VA限制超主力舰发挥，索姆和八零零输出】

## 实战结果
针对开阳瑶光体系，利用风暴M2和水母无人机突破光防，超斩增援取得优势

## 结论思路
- 新手误区是必须打穿前排才能清理后排，实际可绕过
- 常规物理能量直射被吸收，投射被光防克制
- 风暴M2作为不可拦截的能量投射，输出不被光防压缩
- 水母无人机输出可上场，配合超斩集中伤害
- 增援舰队用VA限制超主力舰，索姆和八零零输出

## 适用限制
- 适用于开阳瑶光体系成型后的对抗
- 需要风暴M2和水母无人机等特定舰船
- VA可替换为凌霄、烈冰，但效果可能不同
