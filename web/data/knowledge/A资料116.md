# A资料116

## 场景 / 对手
瑶光时代，能量直射被压制，奇美拉火炮作为主力输出舰船

## 舰队例子
- 奇美拉火炮巡洋舰（堡垒、火炮系统策略两伤害两冷却三命中，装甲系统两血量一能量抗性一物理抗性，动力系统二普通移动速度）（胜）【反小输出强势，取代康纳马拉和艾奥】

## 实战结果
奇美拉火炮在瑶光时代对抗能量直射体系，凭借反小输出取得优势，关键得失为压制能量直射舰船

## 结论思路
- 奇美拉火炮凭借不俗反小输出成为主力
- 火炮系统策略强化伤害和命中
- 装甲和动力系统提升生存和机动

## 适用限制
- 适用于能量直射被压制的环境
- 需搭配策略强化模块
- 不适用于能量直射优势场景
