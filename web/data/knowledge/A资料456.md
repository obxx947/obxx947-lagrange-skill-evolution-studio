# A资料456 · 舰载机与护航艇养成优先级

> 场景：超展队/轰炸队

## 结论
- 舰载机优先养维塔斯A021-重型攻击机（原文为"VA"，疑似简称）、维塔斯-B010-轰炸机（原文为"VB"，疑似简称）、BR050-标准轰炸机（原文为"050"，疑似简称）
- 护航艇优先养坦普尔1号-信息护航艇（原文为"坦克"，疑似语音识别错误）、星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）、CV-T800型-脉冲炮艇（原文为"T800"，疑似简称）
- 舰载机主要用于超展队快速击毁敌方超主力
- 护航艇主要用于轰炸队
- CV-T800型-脉冲炮艇要放在猎兵级-重型载机巡洋舰（原文为"猎兵"，疑似简称）上
- CV-T800型-脉冲炮艇主要打对空并保护星云追逐者-脉冲炮艇、坦普尔1号-信息护航艇等输出护航艇
