# A资料599

## 场景 / 对手
游戏环境以直射高爆发火力为主，投射火力受限，防空队通过炮灰前排和高抗性战巡配合奶船形成坚固防线

## 舰队例子
- 风暴M2（风暴级-导弹型，M2模块）（胜）【唯一能兼顾输出和断奶的船，其他模块可有可无】
- 普卡（8艘）（负）【有巡洋舰增伤策略，但伤害被光防拦截，不足以断奶】
- 海氏（海氏八百）（负）【输出表现高，但单一火力断奶无效】

## 实战结果
针对防空队，断奶流通过风暴M2分散维修量，降低对方坦度，最终击杀超主力；多次战报印证，输出不足时断奶失败

## 结论思路
- 断奶目的：让维修量不集中到重甲战巡，使投射火力能斩杀超主力
- 断奶目的：降低维修量，减少对方总血量，削弱坦度
- 断奶方法：优先攻击巡洋舰，因巡洋舰护甲低、无法施满维修量
- 断奶前提：总输出需足够，否则无法分散奶量
- 风暴M2是唯一能兼顾输出和断奶的船，其他火力无效
- 断奶效果需分析战报，看奶量是否降低，注意电磁五九等干扰因素

## 适用限制
- 适用于对抗高抗性战巡和奶船组成的防空队
- 需有足够输出，否则断奶无效
- 风暴M2需配备M2模块，其他模块非必需
- 断奶不彻底时，需增加风暴数量
- 不适用于无奶船或低坦度敌方
