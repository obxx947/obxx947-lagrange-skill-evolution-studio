# A资料397 · 普鲁图斯之盾平民三方案

> 场景：平民抗伤队

## 结论
- 普鲁图斯之盾级-防护战列巡洋舰（原文为"普鲁图斯之盾及战略巡洋舰"，疑似语音识别错误）是平民第一艘质变战巡
- 白板盾用60蓝点点出庇护作战旗舰策略，降低30%作战目标之外舰队伤害
- 白板盾是平民抗伤队主体框架最重要结构
- 拦截盾增加B3拦截模块，单艘24%铜牌拦截率
- 5艘拦截盾提供50%拦截，6艘提供56%拦截
- 拦截盾可直接取代三光防，给抗伤队更多变换可能
- 附加盾是最终形态，拥有B2附加模块
- 附加盾单体785物抗、30%能抗，基本免疫索姆河、蜂巢等单发不足的护航艇物理攻击
- 附加盾在抗伤队位置突出，是抗伤无法绕开的最重要战巡

## 配队与模块
- 白板盾：无模块，60蓝点点出庇护作战旗舰策略
- 拦截盾：B3拦截模块
- 附加盾：B2附加模块

## 数值与数据
- 庇护作战旗舰策略降低30%所受作战目标之外舰队伤害
- 单艘拦截盾24%铜牌拦截率
- 5艘拦截盾50%拦截率
- 6艘拦截盾56%拦截率
- 附加盾单体785物抗、30%能抗
