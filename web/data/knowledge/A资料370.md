# A资料370

## 场景 / 对手
前期控制作业，四级金属和晶体矿，两种守军配置

## 舰队例子
- 旗舰带奶船，两支舰队，无空军守军配置（胜）【有激进战损，建议旗舰带奶船】
- 一队空军共15架，伤害较低，另一队简单（胜）【控制难度和对舰队要求更低】

## 实战结果
前期控制四级矿，两种守军配置均成功，无空军配置有战损，空军配置更简单

## 结论思路
- 前期优先选择四级金属和晶体矿进行控制
- 四级矿守军实力不强，两种配置均可应对
- 无空军配置需旗舰带奶船减少战损
- 有空军配置伤害低，控制难度更低
- 控制作业收益高，数量足够可加速速本和造船

## 适用限制
- 适用于前期发育阶段
- 仅针对四级矿的守军配置
- 无空军配置需注意旗舰战损，建议带奶船
