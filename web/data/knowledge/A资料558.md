# A资料558

## 场景 / 对手
雷火新型战机实战测试，对手为有护甲的护航艇/轰炸机（VB、050、VA等），正面空战，环境为常规PVP

## 舰队例子
- 小米（护航艇）+ 雷火（战斗机）（胜）【小米稳定输出1.5万，雷火稳定1.5万，有时跳至2万，对高护甲船出伤能力不错】
- 小米（护航艇）对无高护甲船（胜）【2分钟打1.4万，对比雷火2分钟打1万，小米对无护甲目标效率更高】
- 雷火（战斗机）对高护甲船（胜）【破甲伤害高，能有效打击VB、050等重轰炸机】

## 实战结果
悠悠老板及其盟友提供战报，测试雷火对小米，雷火在打有护甲战机时达到小米水平，小米对无护甲目标更优，雷火主型号表现突出，C型号表现差

## 结论思路
- 雷火是偏solo的船，护航玩法基本不用考虑
- 主型号对空能力不错，值得期待，特种型是功能性舰船，可干扰对方VB攻击序列
- C型号表现差，基本无用
- 雷火对高护甲船破甲能力强，小米对无护甲目标效率高
- 雷火可替代砂龙位置，但机位够时建议都带
- 雷火有攻击时间限制，子母弹只延长至前八轮，约2分钟，但足以将VB、050等打残血
- 雷火不能对舰，是主要限制
- 雷火生存性好，不易被优先攻击
- 推荐用林鸮和砂龙与雷火测试，效果更合理
- 雷火出现后，小米可点聚焦空战，优先解决拦截机/攻击机，雷火负责大船输出

## 适用限制
- 适用于solo玩家，护航玩法不适用
- 雷火有攻击时间限制，前八轮后伤害下降
- 雷火不能对舰，需配合其他舰船
- 雷火对高护甲目标有效，对无护甲目标效率不如小米
- 加点建议：持续时间强化必点，命中强化不点（信息链提供命中）
- 装甲系统、动力系统加点无争议
