# A资料634

## 场景 / 对手
天书内战，双方均为天书航母体系，正面作战，环境为持久战

## 舰队例子
- 支援5天书（带干扰机，无炮艇模块）+ 主队5大毛、4大盾、1光追、5开阳、4耀光（胜）【能扛能打思路，大毛在副队中表现突出，输出72万，维修166万】
- 支援5天书（带摇、海尔波普、干扰机）+ 主队1大盾、2大剑、3光追、10开阳、6耀光（负）【叹息之墙思路，但战巡数量少，大盾承伤过大，旗舰早炸】

## 实战结果
左边打右边，左边胜。左边炸1航母、6战巡；右边炸2航母、3战巡。左边输出110万，右边64万。右边旗舰5分17秒炸，导致雪球效应。关键得失：左边大毛输出和维修量高，右边战巡少、维修量低

## 结论思路
- 副队输出决定胜负，副队多50万伤害可打爆关键单位滚雪球
- 旗舰生存关键，右边旗舰早炸导致劣势
- 多战巡分摊伤害优于少战巡，能配合维修量
- 大毛在天书队中能扛能打，比风暴更适配，输出和维修量高
- 小船（均衡配开阳）只能扛伤无输出，不如天书配大毛持久
- 天书队核心是维修量，副队需围绕维修量配置

## 适用限制
- 适用于天书内战持久战场景
- 多战巡配置优势明显，少战巡易导致旗舰和大盾承压
- 大毛需配合天书维修体系才能发挥最大作用
- 小船在持续作战中效果有限，不适合作为主要抗伤单位
