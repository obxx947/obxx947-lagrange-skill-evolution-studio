# A资料505

## 场景 / 对手
卡利斯托各型号的历史演变与当前版本适用性，涉及对手体系（附加毛、光防拦截、护航版本）、正面或轰炸（爆破战群）、环境（版本机制、玩家蓝图质量）

## 舰队例子
- 卡利斯托A型（点满单发，约500单发）（胜（早期强势，后期被克制））【早期T0，因高单发和增伤可打穿远洋混搭；后期被附加毛（540甲）和光防拦截压制，序列分散导致伤害不集中】
- 卡利斯托B型（重卡，高爆高冷却）（胜（历史强势，当前仍可玩））【依赖击杀重置冷却机制，曾为第一巡洋；机制修复后强度下降，但反拦截和优先攻击战群特性使其在拦截不足时仍能爆破】
- 卡利斯托C型（配合木星元户）（负（当前冷板凳））【曾配双西神（20个目标），但盘古开阳出现后西神被弃，C型无人问津】

## 实战结果
卡利斯托A型早期打穿远洋混搭，后期被附加毛和光防拦截压制；B型在击杀重置冷却机制下无敌，机制修复后仍强，当前在拦截不足时可爆破战群；C型仅短暂配合双西神，后因版本更迭被弃

## 结论思路
- 卡利斯托A型早期强势因高单发和增伤，但后期被高甲和拦截克制，序列分散是弱点
- 卡利斯托B型依赖击杀重置冷却机制，机制修复后强度下降，但反拦截和优先攻击战群特性使其在拦截不足时仍可爆破
- 当前版本拦截盛行，重卡可针对减少光防的玩家，作为爆破战群的选择
- C型仅适合特定阵容（如双西神），当前版本无用

## 适用限制
- A型不适合对抗高甲（如附加毛）和拦截队伍
- B型需要对方光防不足（少于3-4个）才能发挥，且依赖优先攻击战群特性
- C型仅适用于木星元户和双西神组合，当前版本不推荐
- B型在当前版本需赌对方减少光防，不适合面对满编光防
