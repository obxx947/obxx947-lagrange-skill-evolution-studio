# A资料218

## 场景 / 对手
扛伤队配船，涉及小船、巡洋和奶船选择

## 舰队例子
- 开阳A型号（闪避策略点满，125蓝点，武器不点需65蓝点）（胜）【首选，闪避高】
- 斗牛C型号（同等人口价，血量高，防空）（胜）【替代开阳，无闪避】
- 细神星A型号（前期用，后期洗点给C）（胜）【过渡选择】
- 斗牛AB型号（抗伤弱但伤害高）（胜）【最后选择】
- 卡利莱恩C型号（直射闪避点满）（胜）【护卫舰首选，A型号效果差】
- 瑶光AB型号（能量护盾，5艘）（胜）【增强小船肉度】
- 奇美拉C型号（巡洋）（胜）【巡洋扛伤替代】
- 奇美拉A型号（下位替代）（胜）【无C时用】
- 066基础型（巡洋）（胜）【无扛伤但提供奶船】
- 光锥B型号（4-5艘，铜牌拦截）（胜）【关键辅助】
- 御衡C（奶船，只奶小船）（胜）【搭配066奶】
- 066奶（盘古前最好用）（胜）【奶小船】
- 御魂A型号（奶船，前排，只奶巡洋）（胜）【巡洋队用】
- 谷神星B型号（奶量高但脆）（胜）【替代066】
- 台源A型号（奶量低但防空强，加伤害）（胜）【替代谷神星】
- 卫士奶或诺玛奶（胜）【最后选择】

## 实战结果
无具体实战记录，为配船建议

## 结论思路
- 小船优先开阳A，其次斗牛C，细神星过渡
- 护卫舰卡利莱恩C必选，闪避点满
- 瑶光加能量护盾，5艘即可
- 巡洋无扛伤，用奇美拉C或066基础型
- 光锥B提供拦截，4-5艘
- 奶船搭配：御衡C+066奶，或谷神星/台源替代
- 御魂A适合巡洋队

## 适用限制
- 开阳A需蓝点充足
- 斗牛C无闪避，依赖其他闪避船
- 御衡C只奶小船，需搭配其他奶
- 谷神星脆，需稳定环境
- 台源需加伤害点
- 卫士/诺玛奶为最后选择
