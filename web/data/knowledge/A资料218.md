# A资料218 · 扛伤队配船与奶船选择

> 场景：前排扛伤队

## 结论
- 开阳级A型号必上闪避策略，点满需125蓝点，不点武器系统最少需65蓝点
- 斗牛级C型号是开阳级A型号的同人口替代，血量更高且能防空，但无闪避
- 没有斗牛级C型号可用阋神星I级，前期用A型号造价低，后期洗点给C型号更肉
- 斗牛级A/B型号也能扛伤，扛伤弱但伤害更高
- 卡利莱恩级C型号闪避必须点满，前排优先选直射闪避
- 卡利莱恩级A型号可替代C型号，但效果差一点
- 瑶光级给己方小船加能量护盾，A/B型号搭配使用效果最佳，单独型号也能用
- 瑶光级不用上满，上5个即可
- 其他护卫舰都不推荐，不如上述驱逐舰
- 巡洋舰没有真正扛伤解，凑不齐上述舰船可用奇美拉级C型号
- 奇美拉级C型号下位替代是奇美拉级A型号
- 奇美拉级都没有就用CAS066级通用巡洋舰基础型
- 光锥级B型号是除超主力外唯一拥有范围拦截能力的舰船，扛伤队必带
- 光锥级B型号不用造满，造4-5个即可
- 扛伤队需要奶船，玉衡级C型号奶量最高但只奶小船
- 肉队不全是小船时，不建议只放玉衡级C型号，可搭配CAS066级支援巡洋舰
- CAS066级支援巡洋舰是盘古系列之前最好用的奶船，目标里没有小船但实际也奶小船
- 玉衡级A型号奶量高但是前排且只奶巡洋舰，除非扛伤队全是巡洋舰否则不好用
- CAS066级支援巡洋舰下位替代是谷神星级B型号，同人口奶量更高但太脆，不如066稳定
- 谷神星级B型号也没有可用苔原级A型号，奶量差很多但防空强
- 苔原级A型号加点要加伤害，加伤害同时加奶量
- 苔原级A型号也没有只能用卫士级支援驱逐舰或诺玛M470级支援护卫舰，没有其他奶船

## 配队与模块
- 开阳级A型号：闪避策略点满，不点武器系统
- 斗牛级C型号：同人口替代开阳级A型号
- 阋神星I级A型号：前期低造价扛伤，后期洗点给C型号
- 卡利莱恩级C型号：闪避点满，选直射闪避
- 瑶光级A/B型号：搭配使用，上5个
- 奇美拉级C型号：巡洋扛伤首选
- 奇美拉级A型号：巡洋扛伤下位替代
- CAS066级通用巡洋舰：巡洋扛伤最后选择
- 光锥级B型号：范围拦截，上4-5个
- 玉衡级C型号：奶小船，搭配CAS066级支援巡洋舰使用
- CAS066级支援巡洋舰：主力奶船
- 谷神星级B型号：066下位替代
- 苔原级A型号：谷神星下位替代，加点加伤害
- 卫士级支援驱逐舰/诺玛M470级支援护卫舰：最后备选奶船

## 数值与数据
- 开阳级A型号闪避策略点满需125蓝点
- 开阳级A型号不点武器系统最少需65蓝点
- 瑶光级上5个即可
- 光锥级B型号造4-5个即可
