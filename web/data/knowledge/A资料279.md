# A资料279

## 场景 / 对手
平民舰队抗伤，风暴盾配置，增援五战巡盾白板，旗舰减伤策略

## 舰队例子
- 风暴盾（C二无人机或C三能量补偿装甲，59电磁装甲同位替换盾，B3拦截可选）（胜）【抗伤配置，旗舰减伤策略，60蓝点】
- 五战巡盾白板（胜）【增援，提供基础抗伤】
- 光防066（减少一个，若拥有B3拦截）（胜）【支援战巡维修加成】

## 实战结果
平民配置，未提及具体对手，强调抗伤和维修支援，关键得失为减少光防066以换取维修加成

## 结论思路
- 风暴盾配置优先选择C二无人机或C三能量补偿装甲
- 59电磁装甲可同位替换盾，降低成本
- 旗舰减伤策略需60蓝点
- 拥有B3拦截时减少光防066，增援战巡维修加成

## 适用限制
- 适用于平民玩家，资源有限
- 需要旗舰减伤策略解锁
- B3拦截为可选，非必需
- 战巡盾白板，无高级模块
