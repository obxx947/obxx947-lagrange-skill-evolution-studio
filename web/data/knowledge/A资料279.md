# A资料279 · 平民风暴盾抗伤配置

> 场景：增援五战巡

## 结论
- 盾白板即可，60蓝点给到旗舰减伤策略
- 风暴选择C2无人机或C3能量补偿装甲
- 可用59电磁装甲同位替换盾
- 拥有B3拦截可减少一个光防
- 066支援为战巡提供维修加成
