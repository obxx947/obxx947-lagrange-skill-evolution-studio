# A资料380

## 场景 / 对手
海尔波普护航艇在当前环境下的强度分析，涉及账号质量、航母扛伤队、防空环境

## 舰队例子
- 海尔A和海尔B，20个（胜）【奶了接近一百万，维修量高于六六】

## 实战结果
无具体对战记录，仅提及一个战报示例

## 结论思路
- 海尔波普强度与账号质量直接挂钩，账号质量高则强度高，反之则低
- 生存决定上限，维修量高但需保证存活
- 基础型不加索尼，锁敌时间3.5秒足够
- 闪避技能触发条件苛刻，受战机打击才触发，优先点生存而非维修
- 基础型系统维修技能在高达队中作用高，独立判定，十个可保证概率
- 子型号维修序列优先战巡，适配高大队，额外维修效果强
- 推荐双型号一起带，抗伤同时修船，单型号推荐子型号

## 适用限制
- 账号质量差，副队无航母或战巡载机位时，性价比低
- 防空环境强，800防空可快速秒杀，需谨慎使用
- 巡洋队中效果差，因优先维修巡航舰，性价比低
