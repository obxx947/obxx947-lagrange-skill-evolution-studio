# A资料187 · 护航肉队配队思路

> 场景：护航肉队

## 结论
- 旗舰优先用普鲁图斯之盾级，60点旗舰减伤很关键
- 白板普鲁图斯之盾级都没有就玩电磁ST59级
- 光锥级-区域防空巡洋舰（原文为"光防"，疑似简称）和CAS066级-支援巡洋舰（原文为"六十六奶"，疑似语音识别错误）都要有
- 纯大船移速慢、生存成本高，带点小船提高曲率
- 后期增加肉队配置再加乌拉诺斯之矛（原文为"大毛"，疑似语音识别错误）、永恒风暴级、ST59级
- 多带战巡一定要点数模块够用，否则别人炸护航队自己炸战巡

## 配队与模块
- 旗舰：普鲁图斯之盾级
- 光锥级-区域防空巡洋舰
- CAS066级-支援巡洋舰
- 开阳级
- 瑶光级
- 玉衡级-支援巡洋舰
- 后期追加：乌拉诺斯之矛、永恒风暴级、ST59级

## 数值与数据
- 旗舰减伤60点
