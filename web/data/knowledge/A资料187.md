# A资料187

## 场景 / 对手
护航肉队配对思路，正面/轰炸环境

## 舰队例子
- 旗舰：大盾（附加装甲可选）+ 光防六十六奶 + 开阳瑶光 + 玉衡C + 大毛风暴五十九多代战巡（点数模块够用）（胜）【旗舰减伤60点，大盾白板可用，但需奶妈支持】
- 替代：电磁五九（无大盾时）（负）【白板大盾缺失时使用，但效果较差】

## 实战结果
无具体实战记录，仅提供配置思路

## 结论思路
- 旗舰优先大盾，减伤60点关键，白板也可用
- 无大盾时改用电磁五九
- 光防六十六奶必备，天书可少但奶不可缺
- 加入开阳瑶光和玉衡C提高区率，避免纯大船移速慢
- 后期增加大毛风暴五十九多代战巡，但需点数模块够用

## 适用限制
- 大盾无附加装甲时仍可用，但需奶妈支持
- 点数模块不足时不宜加战巡，否则易被炸
- 纯大船生存成本高，需小船搭配
