# A资料569 · 林鸮苍穹输出与加点解析

> 场景：舰优机对舰输出，针对大盾/超主力绝育

## 结论
- 舰优机除维塔斯-B010-轰炸机（原文为"维B"，疑似简称）和海氏追随者型-脉冲攻击机（原文为"海氏追随者"，疑似简称）外基本无输出
- 能输出的舰优机分两类：打保底伤害的与不打保底伤害的
- 不打保底伤害的受高护甲、高拦截、闪避克制，输出条件限制多
- 保底伤害到时间自然打出，不易被克制
- 第一档：11维B、13维B、南十字星元帅级-武装航空母舰（原文为"南十字"，疑似简称）的维B、海氏追随者
- 第二档基本无人
- 林鸮A100型-联合攻击机（原文为"林鸮"，疑似简称）与新大地带在永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）上数据好看，出伤可达海氏追随者水平，但人口高
- 正常不把林鸮排第二梯队，能输出基本在第三梯队
- 第四梯队：超斩的林鸮、超斩的AT021、新大地
- 新大地是第三或第四梯队领头羊，靠绝育出伤，带任何机库都能输出
- 林鸮只有在分散作战时才能出伤，超载林鸮出伤不好
- 分散绝育导致伤害打散，与集火输出逻辑违背，作为输出船没戏
- 苍穹林鸮可输出且面板好看，正确加点下一个林鸮约等于三分之二个维B，与海氏追随者伤害差不多
- 但人口消耗完全不同：18人口超载狩猎可带四个海氏追随者，18人口苍穹带不了
- 40人口海氏追随者带满还多四人，苍穹只能带三个林鸮
- 苍穹组合：本体AB模块加无人机5万、T800 8万、林鸮10万，三分钟共约23万
- 康纳马拉三台26.2万，两台约17.3万
- 林鸮单位人口输出远超康纳马拉，合格但代价大得多
- 康纳马拉伤害稳定对前排单船，苍穹伤害四者分散各自目标
- 苍穹面板合格且能打完战斗，但专一伤害欠缺
- 以康纳马拉为参考，苍穹绝对合格，建议作为第二台输出航母
- 南十字星元帅级-武装航空母舰作为输出航母绝对不沾边，苍穹强得多
- 大盾盛行下队伍非常有必要带林鸮绝育大盾
- 绝育效果：运气好一分钟内绝育掉，最差两分钟内稳定绝育对面所有超主力
- 对面护盾一定会掉一次
- 对面超主力少时（如四个）九个林鸮分散打击会重叠，绝育效果更高
- 林鸮尽量不超过三个，超过可带新大地

## 配队与模块
- 林鸮对舰固定加点五项必点
- 林鸮策略：45秒缩短50%持续时间、延长70%冷却时间，持续30秒
- 林鸮特种弹药系统：攻击前五轮造成伤害额外40%，可维持约三分钟
- 苍穹加点：打系统时系统伤害加成必点，强化项消耗35格
- 苍穹必点分散攻击，让每条大盾均匀吃绝育伤害
- 苍穹伤害必点，否则后续无法解锁
- 苍穹频率减少40%必点
- 苍穹最后两格抉择：第一套冷却加伤害，第二套冷却加锁定
- 选冷却因加40%相当于林鸮自身两格多提升
- 苍穹本体也输出，强化频率后载具面板3000多
- 无AB模块苍穹本体4.1万伤害，有AB模块约5万
- 最终锁定林鸮方案：冷却加伤害或冷却加锁定
- 15%伤害强化是林鸮苍穹拉开差距的关键
- 18人口超载狩猎可带四个海氏追随者
- 40人口苍穹带三个林鸮
- 苍穹组合：本体AB模块加无人机、T800、林鸮
- 康纳马拉三台或两台对比
