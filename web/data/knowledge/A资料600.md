# A资料600

## 场景 / 对手
木星公司巡洋舰新增旗舰技能紧急援护，测试扛伤舰队配置，面对混沌和艾奥为主要输出的主力舰队

## 舰队例子
- 前排：阅神基础x10，阅神装甲x10，卡特x9；中排：六六奶x10，大盾x1（旗舰）；后排：重卡无人机支援x1，光防x3，大盾x2，总人口420（胜）【重卡无人机旗舰技能加点增加5个目标，覆盖20个木星前排小船；后排位置保证buff持续】

## 实战结果
测试配置对抗混沌和艾奥主力舰队，表现能扛，换战损策略有效，关键得失为前排小船扛直射、大盾减伤、光防拦截

## 结论思路
- 木星旗舰技能紧急援护提供20%闪避，大幅提升阅神基础型和装甲型坦度
- 重卡无人机选择基于两点：旗舰技能增加目标数量覆盖前排，后排位置保证buff持续
- 配置走换战损策略，前排扛直射，大盾减伤，光防拦截投射火力
- 双阅神加木星巡洋舰增加坦度和造价，性价比划算
- 模板可举一反三调整

## 适用限制
- 适用于对抗混沌和艾奥为主要输出的主力舰队
- 旗舰大盾不能移动，支援战巡可选五九、大盾或大毛
- 木星小船对闪避需求不高，最适配阅神
- 无人机卡防空能力有限，仅作添头
