# A资料402 · 星云追逐者脉冲炮艇加点

## 结论
- 武器为能量伤害，不加点时对驱逐护卫命中70%到100%
- 每次武器加点百分比均按基础数值计算
- 白板武器冷却3秒，锁敌10秒
- 舰载机快速输出建议点，相当于每分钟狂暴一次后缓口气
- 主武器共6个加点位，基础命中高且基伤有加成，不需要额外命中加点
- 先点满两伤害一暴击，再点一个频率后锁敌由10秒变为7秒
- 动力系统双锁敌冷却点满后，锁敌由7秒减为1秒，实际冷却减少6秒
- 武器冷却加点5%，按基础3秒计算减少0.45秒，实际减少0.5秒
- 信息增强系统点直射闪避与制导闪避，因为这两种武器最广泛
- 装甲系统点三结构保证最高血量
