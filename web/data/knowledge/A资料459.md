# A资料459 · 廉价驱护碰瓷消耗缝合轰炸

> 场景：碰瓷消耗缝合轰炸

## 结论
- 驱护碰瓷可行，不必非用白鳄带十三余大船
- 船尽量集中在一排，发挥反击防空铜牌未被击中的协助铜牌作用
- 防空鸭脖碰瓷很强，没有可用枪骑兵替换
- 打完完全没战损
