# A资料563

## 场景 / 对手
苹果阵容对战满调教CV3阵容，正面战斗，环境为常规PVP

## 舰队例子
- CV3（5台，动力和装甲强化）+ 大帝（白板，投影火炮）+ 台原（后排）+ 强击兵（小船）+ 特卡（前排）+ 狩猎防空（提供命中）+ 超斩（列兵+海尔波普）+ 凌霄（追随者）+ 维B + 小米（载机）（胜）【典型苹果阵容，通过后排CV3保护大帝和台原，小船填充防空，超斩对空，但存在奶溢出和加点问题】
- CV3（3.99满调教，800人口）+ T800 + 新脉蜂巢 + 维B + 维A + 小米 + 不屈级（前排）（负）【对手阵容，输出高但被苹果阵容克制，载机被防空压制】

## 实战结果
我方（760人口）击败对手（800人口），关键得失：通过后排CV3保护大帝和台原，拦截鱼雷，防空打掉载机，但奶量溢出和超斩对剑目标不当

## 结论思路
- 苹果阵容需相互配合，一加一大于二，如CV3保护大帝和台原
- CV3强化应侧重输出而非防御，因CV3不易死
- 小船（如强击兵）需其他小船填充体积，避免被反小武器秒杀
- 奶量需与对方输出对碰，避免溢出浪费人口
- 超斩应优先对空或对前排，而非对后排航母，因后排生存高
- 攻击序列需统一，集中激活同一目标，避免分散
- 台原可替代部分超斩，节省人口并提高生存

## 适用限制
- 适用于有CV3、大帝、台原等核心船的阵容
- 需有狩猎防空提供命中，否则需额外强化
- 不适合无小船填充或奶量溢出的情况
- 对剑目标需根据对方前排和载机情况调整
