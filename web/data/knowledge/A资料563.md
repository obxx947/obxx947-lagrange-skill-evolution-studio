# A资料563 · 苹果阵容与战机载具搭配

> 场景：正面战报；对手3.99满调校CV3000级-快速航空母舰（原文为"cv3"，疑似语音识别错误），800人口

## 结论
- 好阵容先要好船底子，再用配合打出1+1>2。
- 新手应先从止战级-攻坚战列舰（原文为"战神"，疑似语音识别错误）输出打底，无模块也能用。
- 新君士坦丁大帝用远程作战调到后排，由前排止战级先接敌，CV3000级在后排保护大帝。
- CV3000级停在后排而非中排，是为同时保护新君士坦丁大帝和苔原级-载机驱逐舰（原文为"台源"，疑似语音识别错误）。
- 带枪骑兵级做防空/信息链时，必须塞其他小船分担反小火力，否则两个枪骑兵也会被秒。
- CV3000级生存极强，应强化输出，不优先强化动力或装甲系统。
- 枪骑兵防空非必需；有狩猎者级-防空载机巡洋舰（原文为"狩猎防空"，疑似简称）可提供45%命中并省人口。
- 海尔波普-维修支援护航艇（原文为"海尔波普"，疑似简称）超斩奶量溢出，可削减奶量转为输出。
- 米斯特拉-战斗攻击机（原文为"小米"，疑似简称）不建议放CV3000级：缺少载机加成，只靠90锁定，难打满调校回避。
- 海氏追随者型-脉冲攻击机（原文为"海是追随者"，疑似语音识别错误）应先打空战，不要优先点超载打后排CV3000级。
- 林鸮A100型-联合攻击机（原文为"林霄"，疑似语音识别错误）对舰伤害偏低，应先打空战解放CV-T800型-脉冲炮艇（原文为"t800"，疑似简称），或改上重卡/泡泡龙打舰。
- 攻击序列要统一，先集火前排不屈级-TE-导弹战列巡洋舰（原文为"不屈级"，疑似简称），再按回避顺序打后排。
- 苔原级-载机驱逐舰放后排受CV3000级保护，可打出对空并替代部分海尔波普。
- 战机选载具先分四类：本身强、可加点成材、再扶也白搭、功能型挂件。
- 米斯特拉-战斗攻击机、维塔斯-B010-轰炸机（原文为"维b"，疑似简称）本身强，应配最优载具加成。
- 砂龙-大气层拦截机（原文为"沙龙"，疑似语音识别错误）吃伤害、返回、冷却三加成，应放狩猎者级-载机巡洋舰（原文为"狩猎"，疑似简称）或永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）冷却位。
- 载机位取舍看需求：砂龙更吃冷却，米斯特拉不靠冷却，冷却位让给砂龙。
- 林鸮A100型不需要冷却，优先找高伤害和返回的载具。
- BR050系列轰炸机（原文为"零五零"，疑似语音识别错误）、刺鳐-鱼雷轰炸机（原文为"次摇"，疑似语音识别错误）是抗伤型，不指望输出；维塔斯A021-重型攻击机（原文为"维a"，疑似简称）只负责2-3分钟内绝育超主力。
- 雷火V022-两栖战斗机-C（干扰型）（原文为"零二二"，疑似语音识别错误）放新君士坦丁大帝级-综合战列巡洋舰（原文为"大帝"，疑似简称）只做功能/索敌，不追求伤害。

- 雷火V022-两栖战斗机-C（干扰型）放新君士坦丁大帝级-综合战列巡洋舰只提供功能/索敌。
