# A资料264 · 低赛护航抗伤队配法

> 场景：低赛护航抗伤队

## 结论
- 大盾旗舰不可替代，是低赛可养的船，无模块就能玩，把旗舰点满即可
- 066支援可用谷神星级-支援驱逐舰（原文为"古神奶"，疑似语音识别错误）、诺玛M470级-支援护卫舰（原文为"诺玛奶"，疑似简称）代替
- 拦截有就上，没有就把人口给奶船
- 太阳摇光有就用，没有就给闪避高的小船
- 前排可用卡利莱恩级-特种护卫舰（原文为"卡莉特种"，疑似语音识别错误）、阋神星I级（原文为"系弦"，疑似语音识别错误）全型号代替
- 奶船和拦截有什么用什么
- 配队思路是理解船的用途和适用时机，而不是照抄配置
