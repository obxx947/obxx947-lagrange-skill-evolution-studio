# A资料264

## 场景 / 对手
低赛护航配对讲解，抗伤队配置，320人口环境

## 舰队例子
- 大盾旗舰（光防拦截）+ 零六六支援（奶量）+ 太阳摇光前排小船 + 增援盲或五十九（胜）【标准一加一配对，核心在大盾旗舰和零六六支援奶量】
- 大盾旗舰 + 古神奶或诺玛奶代替零六六（胜）【零六六可用古神奶或诺玛奶替代】
- 大盾旗舰 + 前排小船（闪避高）+ 拦截（如有）（胜）【拦截有就上，没有则把人口给奶船；太阳摇光有就用，没有给闪避高的小船】

## 实战结果
讲解一加二抗伤盾配置，强调大盾旗舰不可替代，零六六可替代，实战中需根据环境调整

## 结论思路
- 大盾旗舰是必不可少的，低赛可以养，没有模块就能玩，把旗舰点满就好
- 前排可以用卡莉特种系弦全型号代替
- 奈川和兰姐留什么用什么
- 教理解船的用途和何时用什么船，而非直接抄配置

## 适用限制
- 适用于低赛护航场景
- 大盾旗舰无法替代
- 战场环境变化时需灵活调整配置
