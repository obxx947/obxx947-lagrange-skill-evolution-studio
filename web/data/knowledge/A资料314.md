# A资料314

## 场景 / 对手
分基地维修速度提升，支援舰基本用法

## 舰队例子
- FSV830，基础模块，数量1（胜）【造价最低，10蓝点，分基地维修速度80%】
- 艾迪卡拉，基础模块，数量1（胜）【造价高，15蓝点，维修速度90%】

## 实战结果
无具体实战，仅演示支援舰停靠分基地和资源点，提升维修速度

## 结论思路
- 支援舰主要用途是提高分基地对舰船的维修速度
- FSV830性价比高，10蓝点即可获得80%维修速度
- 艾迪卡拉维修速度更高（90%），但造价和点数需求更高
- 支援舰停靠分基地后自动触发维修效果
- 支援舰可停靠资源点展开为前哨站，但占用分基地名额且需等待1小时
- 支援舰可提供补给，使舰队获得临时维修效果，需舰队与支援舰停靠同一资源点并对接

## 适用限制
- 需要分基地才能发挥维修效果
- 展开前哨站会占用分基地名额
- 补给效果需舰队与支援舰在同一资源点
- 点数不足时优先选择FSV830
