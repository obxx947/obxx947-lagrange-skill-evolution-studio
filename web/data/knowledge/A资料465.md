# A资料465

## 场景 / 对手
无尽的拉格朗日，安东塔斯持剑者（大剑）战巡实战测试，对抗高护甲值舰船，正面输出与轰炸环境

## 舰队例子
- 大剑（M2模块增加同排巡洋舰攻击频次，C2电磁装甲模块，A1模块策略优先攻击防空能力最高舰船）+ 刺鳐（实弹伤害）+ 050（实弹伤害）+ 大帝（投射武器）+ 13鱼（防空能力强，携带实弹飞机如050、刺鳐）（胜）【大剑熔甲效果提升刺鳐伤害从24万到82.8万，050伤害从48.4万到85.5万，战斗时间缩短2分33秒】

## 实战结果
大剑熔甲效果对比：无大剑时刺鳐14分52秒打24万伤害，有大剑时12分19秒打82.8万伤害；050无大剑时14分52秒打48.4万，有大剑时12分19秒打85.5万。大剑M3模块加成下，自身和飞机护航艇提升15.8万伤害。利用A1策略优先清除防空锥子，配合大帝投射武器实现高效输出。

## 结论思路
- 大剑不仅扛伤出色，还拥有熔甲效果，能直接降低敌方护甲值和受维修量加成，提升我方实弹伤害输出
- 大剑熔甲效果显著，刺鳐伤害提升三倍多，050伤害提升近一倍，战斗时间缩短
- 大剑M3模块可增加安东尼奥斯阵营舰船攻击频次，提升自身和飞机护航艇伤害
- 13鱼防空能力强，搭配大剑后对舰能力更强，伤害甚至超过11鱼
- 利用大剑A1策略优先攻击敌方防空能力最高的舰船（如防空锥子），清除后配合大帝投射武器进行输出

## 适用限制
- 大剑需要模块和蓝点足够的情况下才推荐使用
- 适合对抗高护甲值舰船，对实弹伤害舰队加成明显
- 需要合理搭配防空锥子清除策略，否则可能被拦截
