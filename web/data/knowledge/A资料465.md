# A资料465 · 安东塔斯持剑者输出实战

> 场景：高护甲敌方舰队；配合13鱼/大帝投射

## 结论
- 大剑不只适合扛伤，输出与熔甲效果同样出色
- 大剑熔甲可降低敌方护甲与受维修量加成，提升我方实弹伤害
- 大剑M3模块可增加安东尼奥斯阵营舰船攻击频次
- 大剑A1策略会优先攻击敌方防空能力最高的舰船
- 利用大剑A1可优先清除敌方防空锥子，再让大帝投射武器输出
- 大剑需模块和蓝点足够时才推荐使用

## 配队与模块
- 大剑M2模块增加同排巡洋舰攻击频次
- 大剑C2电磁装甲模块提供超高能量抗性，约28万血量
- 大剑A1模块策略：战斗开始时按战斗序列选择敌方防空能力最高舰船攻击
- 大剑M3模块增加安东尼奥斯阵营舰船攻击频次
- 推荐配置：大剑配合13鱼及多艘大帝

## 数值与数据
- 无大剑熔甲：刺鳐14分52秒伤害24万
- 有大剑熔甲：刺鳐12分19秒伤害82.8万，伤害提升58.8万，约三倍多
- 无大剑熔甲：20艘050在14分52秒伤害48.4万
- 有大剑熔甲：20艘050在12分19秒伤害85.5万，伤害接近翻倍
- 大剑M模块加成给自身和飞机护航艇提升15.8万伤害
