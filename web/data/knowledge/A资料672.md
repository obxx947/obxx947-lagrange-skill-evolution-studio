# A资料672

## 场景 / 对手
战巡体系，正面作战，环境为常规PVP，无海狮，无开阳

## 舰队例子
- 鱼（2艘11鱼+3艘13鱼），11鱼：10星脉+2八百，机位10小米；13鱼：10维B（M2大机库）+10零五零基础+维A，共39机位（胜）【优先利用雷火点子，加四可增援三千放副队】
- 大盾（1艘，仅反导模块可带可不带），毛（3艘，满模块，M1模块，中排站位）（胜）【五战巡时两盾三毛，毛放中排；八战巡时毛可前排，上反导损管或风暴】
- 副队：3光房+6六六奶+西神星基础（或装甲），高速艾奥，摇光（60人口）（胜）【摇光必带，为艾奥提供盾和buff，西神星吃木星工业buff】
- 主队输出：列兵（3艘，800型）+光防（1艘）+奇美拉重炮，剩余点子（胜）【列兵填线，奇美拉输出】
- 副队增援：3大毛+1大盾+1光防（胜）【无开阳时增援配置】

## 实战结果
粉丝账号配置优化，无具体对战记录，关键得失：无开阳需木星工业配置，摇光必带，鱼和毛调配，战巡成型后风暴可上场

## 结论思路
- 优先鱼配置，无坦克时用2艘11鱼配3艘13鱼，机位满配
- 维B放M2大机库，次要点子洗给林霄补位
- 大盾反导模块可不用，毛满模块放中排，八战巡后可前排
- 副队以木星工业为核心，摇光必带，艾奥前排抗伤
- 主队输出用列兵和奇美拉，剩余点子分配
- 前期养锆石特种、摇光耀、于海脉冲、萤石，鸭脖暂不养

## 适用限制
- 适用于无开阳、无海狮的账号
- 五战巡和八战巡阶段配置不同，需调整站位
- 风暴需M2和C3模块，大后期使用
- 副队需木星工业buff，西神星基础型号闪避更高
- 人口需注意，未开出的舰船不上
