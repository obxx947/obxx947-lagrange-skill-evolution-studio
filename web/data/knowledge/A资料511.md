# A资料511

## 场景 / 对手
大件全模块解析，实战机制测试

## 舰队例子
- 大件（m一蜂群无人机作战中书）（胜）【m一适配绝大部分战场环境，原装机核心易获取】
- 大件（m二联合无人机作战中书）（负）【与溜溜奶配合鸡肋，触发次数少】
- 大件（m三同频无人机作战中书）（负）【无适配搭档，暂时无用】
- 大件（a一力剑指挥系统）（胜）【配合索姆河可斩杀光防，但受高防空超主限制】
- 大件（a二）（胜）【百分比血量锁定目标，核心模块】
- 大件（a三）（负）【配合b三熔甲不切实际，打大盾正中下怀】
- 大件（b一护航艇搭载系统）（负）【载精不在多，需求少】
- 大件（b二导弹发射系统）（负）【不如b三，冷板凳】
- 大件（b三脉冲炮）（胜）【直射武器，跨排攻击，配合a二/a一】
- 大件（c系统自维修）（负）【维修量低，鸡肋】
- 大件（cr电磁装甲）（负）【无详细评价】

## 实战结果
测试大件各模块，a二为核心，a一配合索姆河有效，m二/a三/b一/b二/c系统表现不佳

## 结论思路
- m一最适配大部分战场环境
- m二与溜溜奶配合鸡肋，不建议副队使用
- m三无适配搭档
- a一可斩杀光防，但受高防空超主限制
- a二按百分比血量锁定目标，核心模块
- a三配合b三熔甲不切实际
- b一载机需求少，不如b三
- b二不如b三，冷板凳
- b三直射武器可跨排攻击，配合a二/a一
- c系统自维修鸡肋

## 适用限制
- a一受高防空超主限制
- a三打大盾正中下怀
- b一载机需求少
- b二不如b三
- c系统维修量低
