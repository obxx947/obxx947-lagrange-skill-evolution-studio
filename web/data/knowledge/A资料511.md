# A资料511 · 安东塔斯持剑者级全模块解析

## 结论
- 安东塔斯持剑者级M1会指挥舰队中火力更高的舰载机，对大剑当前目标每3轮追加1次打击
- M1最适配大多数战场且容易获取；常指挥索姆河之影-装甲飞行坦克（原文为"锁母河"，疑似语音识别错误）或维塔斯-B010-轰炸机（原文为"回避"，疑似语音识别错误）
- M2会指挥与大剑同排巡洋每4轮追加1次打击，但用M2副队触发CAS066级-支援巡洋舰（原文为"溜溜奶"，疑似语音识别错误）额外维修不成立
- CAS066级-支援巡洋舰单轮持续32秒，M2额外维修触发很少，实战鸡肋
- 大剑应留在主队发挥输出与指挥，副队只是大号电磁ST59级-防御战列巡洋舰（原文为"五九"，疑似简称），很浪费
- M3会指挥同公司舰船每4轮追加1次攻击；可搭配对象无输出或被克制，暂不推荐
- A1会选防空能力最高的舰船攻击；A系统能调动全舰武器与指挥对象攻击当前目标
- 没有索姆河之影时，A1斩杀光锥级-区域防空巡洋舰（原文为"光防"，疑似简称）不现实：剑只能追加1轮且自身伤害不足
- 索姆河之影-装甲飞行坦克可被指挥且索敌序列含巡洋，能黏住光锥级-区域防空巡洋舰直到击毁
- A1弊端：遇到防空高的超主力，如M2天枢级-支援航空母舰（原文为"天书"，疑似语音识别错误）、M2永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称），会转打超主力而非光防
- A2不是按文本的绝对结构值最低索敌，而是按百分比血量最低、血条比例更短选目标
- A2索敌范围为航母、战巡、巡洋；战报中锁住先掉血的天枢级-支援航空母舰，不到2分钟集火斩杀
- A2是公认为T0（原文为"替零"，疑似错字）的核心模块；无A2时A1配好其他核心模块后可作次选
- A3选序列内护甲最高舰船攻击，绝大多数场景无出场必要
- A3配合B3熔甲后，普鲁图斯之盾级-防护战列巡洋舰（原文为"富家盾"，疑似语音识别错误）仍有约680护甲，实弹依然打不穿
- 集火普鲁图斯之盾级会帮对方集中奶量，削减100护甲也难压低其受维修效率
- B1护航艇搭载系统不如B3；载机/护航艇在精不在多，不需要大剑再补载机
- B2导弹发射系统是能量反小导弹，因开阳级-机动驱逐舰（原文为"开阳"，疑似简称）与瑶光级-通用护卫舰（原文为"遥光"，疑似语音识别错误）体系出现且不如B3而冷板凳
- B3脉冲炮系统为直射武器，优先打大船，带装甲溶解
- B3配合A2或A1选中中后排目标时可跨排攻击，属稀有品质
- A2+M2让康纳马拉混沌级-高速等离子体巡洋舰（原文为"泡泡龙"，疑似简称）调中排跨排直射实测不可行，只有大剑自身直射可跨排
- C1自维修每分钟约6000点，很弱
- C2电磁装甲提升主队生存，不是用来把大剑丢副队扛伤
- C3附加装甲提供高物理护甲但弊端明显，C2才是C系统核心
- D1防空导弹面板差，类似新君士坦丁大帝级-综合战列巡洋舰（原文为"大地"，疑似语音识别错误）的近程防空导弹，污染卡池
- D2为能量伤害且优先打小船，不被拦截，斩杀小船效率高
- D3为大型投射武器，遇到拦截或光锥级-区域防空巡洋舰后无伤害
- D2是D系统最强模块，主要靠D1、D3太弱衬托

- M2：「联合」无人机作战中枢-反大离子炮塔（原文为"联合无人机作战中书"，疑似语音识别错误）
- M3：「同频」无人机作战中枢-反大能量导弹（原文为"同频无人机作战中书"，疑似语音识别错误）

- A3：「阔剑」指挥系统-离子炮
