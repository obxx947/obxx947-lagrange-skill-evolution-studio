# A资料469

## 场景 / 对手
新版本护航队搭配，针对盘古阵营姚光级护卫舰对直射武器的克制，讨论护航队如何快速清掉敌方前排小船

## 舰队例子
- 护航输出队：多拉飞机和领航（如八百、凌霄、海氏、小米），康纳马拉混合离子反大，奇米拉弹炮反小，十一鱼混十三鱼（搭载星脉和八百）（胜）【主打舰载机对舰，无视站位优先攻击超主力舰；若敌方无姚光则带奇米拉弹炮反小】
- 护航抗伤队：大盾起，见防空锥子拦截，零六六支援回血，前排开阳（高闪率），后排姚光（能量护盾）（胜）【一加一配置，适用于九八档和平民玩家】

## 实战结果
敌方带姚光及护翼箭时，十一鱼里的八百优先打小船伤害约九千；放在猎兵里走超载的八百伤害约两万三，差距明显

## 结论思路
- 多拉飞机和护航艇，输出主要走超载，以舰载机对舰为核心
- 八百和星脉优先放在猎兵里走超载，避免姚光能量护盾削减伤害
- 若风暴可用，可放弃康纳马拉离子，因风暴M2投掷武器无法被防空拦截
- 防空不必特别强调，被轰炸后应立刻验反，前线造好零九两前哨
- 配置中已有防护飞机（如八百、凌霄等），日常对舰时也会防空

## 适用限制
- 适用于新版本有姚光级护卫舰的环境
- 若敌方配置未更新（无姚光），需带奇米拉弹炮反小
- 十一鱼混十三鱼不实用，单纯十一不适合此版本
- 抗伤队配置按一加一，适合九八档和平民玩家
