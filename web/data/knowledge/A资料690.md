# A资料690

## 场景 / 对手
CV3000玩家对撸，空战绞杀，轰炸机体系（050、刺鳐、VB）

## 舰队例子
- CV3000 + 050轰炸机 + 刺鳐 + VB（数量多，如30轰）（胜）【通过数量保证VB生存，提升输出】
- 太阳鲸 + 11金（T800+小米） + 13主（M2模块）（胜）【暴力空战，空优机效率高】
- CV3000 + 枪骑兵（满编）（胜）【空军输出弱，用地面反哺】

## 实战结果
CV3000玩家对撸，30轰阵容曾有效，但当前空战水平下空优机优势大，50轰和20轰无区别

## 结论思路
- CV3000空战绞杀能力弱，空战耗时长，需保VB生存
- 保VB生存有两种思路：杀光对面飞机或增加轰炸机数量
- 30轰思路通过数量填充血量，但当前空优机效率更高，不推荐
- 轰炸机除VB外无输出，050和刺鳐主要作用是挡刀
- 050物理护甲高，出伤高且时间长，适合超载；刺鳐能量抗性，攻击序列顺应VB
- 推荐050用于高输出或南十字加酒，刺鳐适合solo单挑
- 挡刀需做好超索，确保轰炸机飞在VB前面

## 适用限制
- CV3000玩家适用，太阳鲸不适合30轰
- 当前空战水平下，轰炸机数量优势无效
- 050和刺鳐需超索加点，否则无法挡刀
- 牛蛙出伤低，不推荐
