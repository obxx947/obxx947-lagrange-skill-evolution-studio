# A资料620 · 索姆河之影强度与应对

> 场景：剑对剑、轰炸

## 结论
- 索姆河之影能扛能打，强度远超68元蓝图应有水平
- 剑对剑对战中能与维塔斯-B010-轰炸机（原文为"威必"，疑似语音识别错误）争锋
- 轰炸中能与永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）、星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）五五开
- 攻击蓄力同时打巡洋舰和超主力，与永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）相同
- 单发伤害打巡洋舰几乎全真实伤害，巡洋舰护甲普遍不到200扛不住
- 攻击时间为零，上永恒苍穹级-无人机航空母舰后和米斯特拉-战斗攻击机（原文为"新麦"，疑似语音识别错误）一样无赖
- 血量高、护甲高、输出高，还能分摊伤害，轰炸中无解
- 索姆河之影上线后轰炸强度直接质变，单人轰炸也能玩
- 常规碰瓷行不通，索姆河之影优先反大且火炮无法被拦截
- 敢支援S-列维9号-重型鱼雷艇（原文为"十三鱼"，疑似语音识别错误）碰瓷队，四五十个索姆河之影直接废掉鱼雷艇
- 米斯特拉-战斗攻击机反小威胁不到鱼雷艇，索姆河之影可以直接打鱼雷艇
- 应对方法一：谷神星级-战术驱逐舰（原文为"股神"，疑似语音识别错误）的打击协助可套给抗伤剑队，无伤清理敌方战略打击炮艇
- 打击协助打战机很慢，遇到平衡安德森SC020-侦察机（原文为"安德森"，疑似简称）带大量CV-T800型-脉冲炮艇（原文为"八百"，疑似语音识别错误）要打三分钟
- 应对方法二：靠AC721-重型两栖突击舰（原文为"七二幺"，疑似语音识别错误）协助封锁防空，单发330多且有防控特种弹药
- 除这两种方法外没有其他应对轰炸的手段
- 现在应对轰炸需要更多协调配合，否则轰炸圈一放跑不掉
- 官方有意削弱轰炸让海军能打正面，但这个蓝图让轰炸直接起飞
- 希望官方削弱索姆河之影

## 配队与模块
- 索姆河之影总共只能造9个，3个为一组，3个为一边队出击
- 索姆河之影分摊伤害只有索姆河之影才会触发，其他舰船不会触发
- 轰炸配队：40个星云追逐者-脉冲炮艇加40个索姆河之影
