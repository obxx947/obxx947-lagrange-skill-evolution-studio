# A资料403 · 索姆河之影装甲飞行坦克

> 场景：太阳鲸走地、永恒苍穹级轰炸

## 结论
- 主武器重型火炮系统为直射实弹，高单发伤害，定位主力输出艇
- 主武器推荐加点三频率、三伤害
- 动力系统推荐加点二锁敌频率
- 独立指挥系统加武器无攻击耗时，索敌时间仅1秒，实战可短时间打出多轮伤害
- 武器命中率略低、冷却时间较高，需红箭加成补齐短板
- 走地玩法推荐放入太阳鲸，机库加成55%冷却、20%命中，可补齐两个短板
- 空架玩法推荐放入永恒苍穹级C2，拥有T0级轰炸输出强度
- 无论进太阳鲸走地还是进永恒苍穹级开轰炸，都是强势主力输出艇，非常建议养成

## 配队与模块
- 走地：放入太阳鲸-武装战略航空母舰（原文为"太阳金"，疑似语音识别错误），吃机库加成
- 空架：放入永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）C2

- 单发伤害高达800多
- 索敌时间仅1秒
- 太阳鲸机库加成55%冷却、20%命中
