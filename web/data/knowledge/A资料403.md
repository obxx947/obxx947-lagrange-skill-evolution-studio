# A资料403

## 场景 / 对手
索姆河之影装甲飞行坦克，诺玛印秀集团出品，主武器重型火炮系统，直线武器，实弹伤害，高单发伤害，主力输出体，对舰面板，电磁五九噩梦，附加队，走地或轰炸环境

## 舰队例子
- 索姆河（主武器重型火炮系统，加点三频率、三伤害；动力系统加点二锁敌频率）+ 太阳金（机库加成55%冷却、20%命中）（胜）【走地玩法，补齐命中率低和冷却高的短板，实战中能打出大量伤害】
- 索姆河（同上）+ 苍穹C2（胜）【空架玩法，拥有T0级轰炸输出强度】

## 实战结果
索姆河对电磁五九和附加队，多轮伤害，高实弹伤害，实战中短时间内造成多轮伤害，关键得失是命中率略低、冷却时间较高，需红箭加成补齐短板

## 结论思路
- 索姆河主武器为直线实弹武器，高单发伤害，定位主力输出体
- 主武器推荐加点三频率、三伤害，动力系统推荐加点二锁敌频率
- 满点后对舰面板高达七千，单发伤害八百多，高实弹伤害对电磁五九是噩梦
- 独立指挥系统无攻击耗时，走地时间仅一秒，实战中能快速多轮伤害
- 武器命中率略低、冷却较高，需红箭加成补齐短板
- 走地玩法放入太阳金，机库加成55%冷却、20%命中，能补齐短板
- 空架玩法放入苍穹C2，拥有T0级轰炸输出强度
- 索姆河无论走地还是轰炸都是强势主力输出体，建议养一个

## 适用限制
- 适合对电磁五九或附加队作战
- 需要红箭加成或太阳金/苍穹C2配合以弥补命中率和冷却短板
- 不适用于需要高命中率或低冷却的场合，若无加成则表现受限
