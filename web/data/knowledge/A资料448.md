# A资料448

## 场景 / 对手
抗伤类大船核心模块评测

## 舰队例子
- 大盾 + B2模块（胜）【T0抗伤船，模块要求低，B2即毕业】
- 天书 + A3模块（胜）【T0.5，维修量高但持续不足】
- 天书 + A2模块（胜）【A3替代，持续作战强但维修量较低】
- 乌拉诺斯之矛 + C2模块 + 第三损管系统（胜）【C2提供150点装甲和14%结构，搭配损管系统成最硬船之一】
- TRST 59 + CR模块（负）【勉强上场，仅限打一打电焊队】

无具体实战记录，仅模块评价

## 结论思路
- 大盾是T0抗伤船，B2模块即可毕业
- 天书A3维修量高但持续差，A2可替代但持续强
- 乌拉诺斯之矛配C2和第三损管系统可成最硬船
- TRST 59仅在有CR时勉强可用，限对电焊队

## 适用限制
- 大盾适合低模块要求场景
- 天书A3适合短时高强度战斗，A2适合持久战
- 乌拉诺斯之矛需C2和损管系统配合
- TRST 59仅限特定对手（电焊队）
