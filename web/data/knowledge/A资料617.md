# A资料617

## 场景 / 对手
测试棕熊级c型号（法兰杰型号）对重卡输出的增益效果，防御方为大盾（390护甲白板）配合六六支援，输出选择重卡，作战时长三分钟

## 舰队例子
- 8重卡（无光防）（胜）【三分钟输出73万，作为输出模板】
- 8重卡 + 3光防（负）【输出降至43万，光防严重限制重卡】
- 8重卡 + 3棕熊级 + 3光防（胜）【输出恢复至接近模板，棕熊抵消光防威胁】
- 8重卡 + 5光防（负）【输出仅30多万】
- 8重卡 + 8光防（负）【输出仅16万，重卡失去输出能力】

## 实战结果
测试8重卡在不同光防数量下，配合棕熊级的效果。3棕熊级可抵消3光防，但面对5-8光防时重卡输出大幅下降。棕熊级对投射武器增幅显著，但buff不可叠加

## 结论思路
- 棕熊级可有效抵消光防对重卡的威胁，3棕熊（18人口）可抵消3光锥（20人口），性价比高
- 棕熊级对投射武器增幅大，3棕熊可提升重卡20-30万输出
- 棕熊级buff不可叠加，需根据舰队配置数量（如重卡+大地需5棕熊覆盖15目标）

## 适用限制
- 棕熊级使用条件苛刻，需合理搭配
- 面对大量光防（5个以上）时，重卡输出仍受严重限制
- buff不可叠加，需精确计算目标数量
