# A资料196 · 五至八赛季萌新超斩配置

> 场景：五至八赛季、98党萌新、超斩体系

## 结论
- 航母用B4C位，不推荐B2模块
- 800与星云不适用于B2模块，整体强度偏低
- 五至八赛季飞机点不支撑B2玩法
- B4实战效果与B2差不多，锁定目标干净
- B4伤害偏低但是能量伤害，没有蜂巢那种弊端
- 狩猎者带野火A和维A，维A用来打战损
- 维A打动力系统，把对面战损打出来即可
- 超斩情况下把800和星云上到猎兵级
- 巡洋输出里没几个能用的，奇美拉打不出伤害
- 重炮单发才450，大盾有780
- 卡托现在被官方砍得很难受
- 瑶光镜面很难受，闪避率也高，基本不出伤
- 泡泡龙顶多算艾奥的上位替代，打不出上位输出
- 巡洋输出选项里选择泡泡龙
- 不用066奶是因为绑船成本太高
- 066奶主武器系统点满就要六七十点
- 狩猎者打不出那么多输出
- 用电磁59，实际收尾圈酒量增加量也就四十多
- 上古神和诺玛主要是不想让他死那么快
- 59挺便宜，下去当炮灰
- 开阳一滴人口换一滴水，十二人口强度毋庸置疑
- 光锥A原本带五个就可以，放古神和诺玛带十个
- 有模块跟没模块都推荐洗电磁59
- 59强度依然在线，扛着两队被反杀了一队

## 配队与模块
- 航母用B4C位
- 狩猎者带10个野火A和8个维A
- 超斩情况下800和星云上到猎兵级
- 巡洋输出选择泡泡龙
- 奶船用秋护奶，不用066奶
- 用电磁59
- 上古神和诺玛放进光锥A里
- 光锥A带十个，原本带五个即可
- 用RCR风暴提升59

## 数值与数据
- 800锁定时间1秒，点两个频率后0.7秒
- 0.7秒锁定时间吃70锁定减免后约0.21秒
- 重炮单发450伤害
- 大盾单发780伤害
- 066奶主武器系统点满需六七十点
- 电磁59收尾圈酒量增加量四十多
- 开阳12人口
- 20个维B一分二十八秒打三万伤害
- 6个泡泡龙一分二十八秒打三万四
- 20个800打三万三
- 20个维B打五万五
