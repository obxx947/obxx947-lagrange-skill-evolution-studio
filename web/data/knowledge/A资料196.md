# A资料196

## 场景 / 对手
五赛到十赛阶段，萌新配置，超斩体系，正面作战

## 舰队例子
- 航母B4C位，带飞机和艇虎，具体数量未提及（胜）【推荐B4而非B2，B2不适合带800和星脉，整体强度偏低】
- 狩猎带10个无业A和8个V，V用于打战损（胜）【V打动力系统，超斩体系下打战损】
- 列兵带800和星脉，超斩情况下（胜）【800和星脉在B2中不适用，但列兵可用】
- 阿卡陶海龙，作为输出选项（胜）【在循输出选项中，阿卡优于其他，如奇美拉、卡托等】
- 秋护奶，而非006奶（胜）【006奶绑床成本高，主武器系统需六七十点，不适合】
- 电磁五九，带古神和诺玛（胜）【五九便宜，作为炮灰，古神和诺玛防止过快死亡】
- 光A带五个，古神和诺玛带四个（胜）【光A原本五个即可，但带古神和诺玛增强】

## 实战结果
阿什列格战报：20个微币一分二十八秒打三万四，20个八百达拉斯打三万三，20个未必打五万五，用RCR风暴提升，59强度在线，扛着两队被反杀一队

## 结论思路
- 航母用B4而非B2，B2不适合带800和星脉，整体强度偏低
- 800和星脉锁定时间短，但B2模块下提升不大
- 超斩体系下，V用于打战损，800和星脉上列兵
- 输出选项选阿卡陶海龙，优于奇美拉、卡托等
- 用秋护奶而非006奶，因006奶成本高
- 电磁五九便宜，作为炮灰，带古神和诺玛防死
- 光A带五个，古神和诺玛带四个增强

## 适用限制
- 适合五赛到十赛，技数不低于五赛
- 零氪玩家或技数低于五赛时需谨慎使用
- 飞机点不支撑完，需根据实际情况调整
- 面对瑶光镜面或高闪避时输出受限
