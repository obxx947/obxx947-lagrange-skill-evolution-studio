# B资料1-1 · 列维老九门兴衰

> 场景：航母队；副本防陨石；高防拦截环境；后期打海盗

## 结论
- S-列维9号-重型鱼雷艇（原文为"列为"，疑似语音识别错误）是拉格朗日公认的“老九门”之一。
- 其单发伤害超高。
- 曾为航母队核心主力之一。
- 副本低成本防陨石的不二选择。
- 高爆发型输出，接战后可极短时间斩杀航母。
- 曾因强度过高让许多氪佬心碎退游。
- 猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误）“重点出击”策略后大幅改动削弱。
- 护航玩法上限与优化、高防拦截大量普及，使其输出大打折扣。
- 因此曾淡出玩家视野。
- 并非完全不能用，对部分玩家仍是强力输出。
- 缺点明显但别无选择。
- 后期仍能欺负海盗。

## 配队与模块
- S-列维9号-重型鱼雷艇搭配猎兵级-重型载机巡洋舰，使用“重点出击”策略，可优先攻击敌方航母。
