# A资料608 · 当前版本扛伤队梯队排行

> 场景：当前版本/扛伤队

## 结论
- 强度按基础档、CV档、天枢档、第一档、超一档分梯队。
- 基础档是最基本盘，普鲁图斯之盾级和CAS066级已出很久。
- 单战巡时可通过战巡点数调整。
- 更新后永恒风暴级可替代乌拉诺斯之矛（原文为"大毛"，疑似语音识别错误）。
- 天枢级缺A3或C2关键模块时需补CAS066级-支援巡洋舰（原文为"零六六"，疑似简称）。
- 天枢级A3+C2齐全可不带CAS066级-支援巡洋舰。
- 天枢级缺迪二/迪奥无影响。
- 标准2+2适用于天枢级缺关键模块的情况。
- 第一档核心是三战巡，乌拉诺斯之矛拦截，永恒风暴级补输出。
- 有天权级可取代乌拉诺斯之矛。
- 无天权级则乌拉诺斯之矛+永恒风暴级，常用。
- 不推荐硬出超一档。
- 超一档坦度与第一档相同，输出更高。
- 超一档输出高是因用更高输出战巡替代低输出战巡。
- 超一档对刻度要求很高。
- 战巡数量可随配置调整，几个普鲁图斯之盾级、几个乌拉诺斯之矛均可调。
- 迪奥护甲提升可降伤，但最大影响是提高治疗量。
- 超一档用雷火之星-综合武库舰（原文为"雷火"，疑似简称）拦截，输出比乌拉诺斯之矛拦截高很多。
- 超一档用天权级代挺，输出比乌拉诺斯之矛高。

## 配队与模块
- 基础档：乌拉诺斯之矛+普鲁图斯之盾级-防护战列巡洋舰（原文为"矛盾"，疑似语音识别错误）+CAS066级-支援巡洋舰。
- 次一档：CV3000级-快速航空母舰（原文为"cv"，疑似简称）+普鲁图斯之盾级-防护战列巡洋舰+CAS066级-支援巡洋舰。
- 更新后：可用永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）替代乌拉诺斯之矛。
- 天枢档：天枢级-支援航空母舰（原文为"天书"，疑似语音识别错误）+普鲁图斯之盾级-防护战列巡洋舰+CAS066级-支援巡洋舰。
- 天枢级缺A3或C2时，用CAS066级-支援巡洋舰补治疗量；A3+C2齐全可不带。
- 标准2+2：普鲁图斯之盾级-防护战列巡洋舰+永恒风暴级-攻击战列巡洋舰或乌拉诺斯之矛+CAS066级-支援巡洋舰。
- 第一档：天枢级-支援航空母舰+普鲁图斯之盾级-防护战列巡洋舰固定，剩余出三战巡。
- 三战巡：乌拉诺斯之矛负责拦截，永恒风暴级-攻击战列巡洋舰补输出。
- 天权级-重型防御战列巡洋舰（原文为"天权"，疑似简称）可取代乌拉诺斯之矛。
- 无天权级：乌拉诺斯之矛+永恒风暴级-攻击战列巡洋舰。
- 超一档：雷火之星-综合武库舰拦截，或天权级-重型防御战列巡洋舰代挺。
- 战巡数量可调整，几个普鲁图斯之盾级、几个乌拉诺斯之矛均可调。

## 数值与数据
- 天枢级缺模块时补3-4个CAS066级-支援巡洋舰。
- 天枢级A3+C2=很强治疗量。
- 天枢级多195护甲值，受到治疗量会高很多。
- 战巡数量可调为8战巡或11战巡。
