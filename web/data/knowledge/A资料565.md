# A资料565 · 雷火与大剑重卡solo配队思路

> 场景：solo/单挑，正面，带战群阵容

## 结论
- 带四个乌拉诺斯之矛（原文为"毛"，疑似简称）加四个永恒风暴级加两个雷火之星加两个光锥级，虽然遵循分商机制，但前排一条船一条船掉血，风险更高
- 不带奶时，五二分台比单船依次扛伤更好，不容易被秒
- 雷火之星严重超模，打靶输出全游戏最高，应带满
- 雷火之星作用完全大于永恒风暴级，队伍应围绕雷火之星做输出
- 前排五个乌拉诺斯之矛时，队伍以前排直射加少量补刀为主，不应再堆取射
- 光锥级在solo中只提供信息链和拦截，对这套阵容没有意义
- 这套阵容不靠空军输出，赢空战不是核心，核心是维币伤害
- solo底层逻辑是柿子挑软的捏，先打脆的空战单位
- 空战胜利的标准是维币伤害比对面高，不是单纯对空伤害高
- 右边阵容的对空武器全在拖时间，光锥级带在这里没有意义
- 雷火之星做输出时，应继续辅助它，把雷火之星带满，去掉光锥级
- 安东塔斯持剑者级最克制这套阵容，它挑血最少的巡洋舰打
- 安东塔斯持剑者级不是让队友伤害提高，而是把队友伤害集中到自己头上发射出去
- 安东塔斯持剑者级优先打巡洋舰，会先秒掉光锥级
- 满配时更推荐安东塔斯持剑者级加卡利斯托-重型鱼雷袭击舰（原文为"重卡"，疑似简称）的组合
- 卡利斯托-重型鱼雷袭击舰是全游戏最强武器机制，和维币平齐
- 光锥级拦截被清掉后，卡利斯托-重型鱼雷袭击舰就能发挥
- 最强solo组合是安东塔斯持剑者级加卡利斯托-重型鱼雷袭击舰
- 安东塔斯持剑者级可以先打掉对面光锥级，自己不带光锥级，双方都没有拦截
- 带雷火之星时，光锥级无法处理，不如用安东塔斯持剑者级加卡利斯托-重型鱼雷袭击舰
- 安东塔斯持剑者级输出效率约四万一分钟，三台十二万，一分钟内能打掉光锥级
- 带战群的阵容，安东塔斯持剑者级加卡利斯托-重型鱼雷袭击舰绝对好打
- 这套阵容更适合在家酒中出现，家酒做会损失太多空军力量，有点四不像
- 雷火之星被很多人认为是路边一条，输出不如永恒风暴级或新君士坦丁大帝级
- 满配雷火之星玩家也不会玩，因为玩不来

## 配队与模块
- 原阵容：四个乌拉诺斯之矛、四个永恒风暴级、两个雷火之星、两个光锥级
- 改进前排：五个乌拉诺斯之矛，甚至六个乌拉诺斯之矛
- 改进阵容：五个乌拉诺斯之矛、三个雷火之星、三个安东塔斯持剑者级
- 推荐组合：安东塔斯持剑者级加卡利斯托-重型鱼雷袭击舰
- 雷火之星带M3模块加十一的雷火之星
- 光锥级在solo中只提供信息链和拦截

## 数值与数据
- 原阵容总人口十四分
- 乌拉诺斯之矛伤害十六万和十八万
- 五个乌拉诺斯之矛加起来可能七八十万甚至一百万伤害
- 队伍总伤害可能三百万
- 空军伤害：七万、两万、三万、十五万，系统伤害八十六万、十万
- 维币伤害五十万对比八十万
- 安东塔斯持剑者级输出效率约四万一分钟，三台十二万
