# A资料568

## 场景 / 对手
护航反小，前排闪避小船+中排大船+奶组合，讨论维A反小策略

## 舰队例子
- 维A（主武器+指挥系统+策略）（胜）【推荐加点：反小+命中+冷却，不点攻击超主力，先反小后反大】
- 维A（主武器+策略）（负）【博主加点：只点反小，不点攻击超主力，导致赖在小船上，出伤效率低】

## 实战结果
维A打11万伤害，绝育13个目标，但出伤总和不超过2万，单凭自身无法击败小船；另一战报中维A打0.1结构，伤害全打在系统上

## 结论思路
- 维A自带攻击序列（战巡→航母→其他）是优点，应保留
- 精准打击策略每30秒优先攻击超主力，提升60%系统伤害，循环输出
- 点反小可让维A在30秒内绝育小船，转火后重新选择目标，提高出伤效率
- 不点反小会导致维A被赖在小船上，效率低，无法出伤
- 维A面板高但伤害多在系统上，实际结构伤害低，需配合队友
- 推荐加点：反小+命中+冷却，先反小后反大，兼顾绝育和出伤

## 适用限制
- 适用于有大量前排小船的护航场景
- 维A单挑小船能力弱，需队友配合
- 不适用于无大船目标或需要快速击杀大船的场景
- 加点需根据队伍配置调整，避免本末倒置
