# A资料568 · 维A加点与反小思路解析

> 场景：护航队/反小与反大取舍

## 结论
- 维A自带战巡→航母→其他船的递进攻击序列，值得肯定
- 五级策略“精准打击”每30秒优先攻击超主力并提升60%系统伤害，持续30秒
- 常见加点：点攻击序列，不点指挥系统反小
- 某博主加点：点反小、不点攻击超主力、不点拦截，点命中和冷却
- 该加点会让维A完全被赖在小船上，反完小才转回战巡和航母
- 作者加点初衷是打散攻击系统，让维A出伤，不是专门反小
- 点反小后，维A可先绝育小船，再重新选择大船目标，避免一直盯同一台战巡
- 不点反小时，若对方无航母只有一台战巡，维A会一直打同一台战巡
- 维A半分钟绝育小船较轻松，19秒可绝育两条船
- 不转火时维A会被赖在小船上，目标没死前不会重新选择
- 维A出伤效率低，面板高但伤害主要打在系统上，结构伤害很少
- 维A单靠自身很难打死小船，1分33秒只打出少量结构伤害
- 050出伤高是因为伤害主要打结构，只有少部分打指挥系统
- 维A面板显示高，但绝大多数伤害打系统，不刮结构
- 维A打大船能出伤，例如打锐剑30万，其中15万是结构值
- 作者加点兼顾反小与反大，比单纯反小更合理
- 护航队应以维B为输出核心，维A不应被抠去只打小船
- 队伍中其他反小船手段不差，如011、虚灵等，不必只靠维A绝育动力系统
- 维A应保持反大为主，只反小属于大材小用

## 配队与模块
- 维A加点：点攻击序列，不点指挥系统反小
- 某博主加点：点反小、不点攻击超主力、不点拦截，点命中和冷却
- 作者加点：点反小后再反大，兼顾绝育小船与打大船
- 护航队输出核心为维B，维A不应只反小
- 反小船手段：011、虚灵等

## 数值与数据

- 维A 28秒内绝育4个目标，其中1个由小米打一轮
