# A资料530 · 天权全模块解析

> 场景：前排承伤巡洋

## 结论
- 天权属于前排承伤巡洋，自带维修机制，定位是前排抗伤兼顾小额维修
- A1纯坦度模块，缺前排承伤船就用它
- A2残血触发一次性大额修船，适合搭配A3给前排残血战巡紧急抬血
- A2维修次数有限，打完装甲就失效，泛用性一般
- A3是天权核心奶模块，战斗一分钟后维修效率翻倍，前排持续回血
- B1对舰输出偏低，不推荐，天权本职是承伤，没必要堆输出战机
- B2能补队伍防空，仅缺防空小船时选择，常规承伤编队不用
- C1仅轰炸队天权搭配B2才用，常规前排完全不用
- C2是天权必备模块，持续群体维修，大幅提升全队回血效率
- D1拦截数值低，占用模块位，完全垃圾，不推荐使用
- D2锦上添花模块，有就带，没有不影响天权核心玩法
- 天权核心只看A3加C2
- 常规前排奶天权标准配置A3+C2，D2可选，放弃所有载机模块，专心承伤维修
- 缺防空时换成B2，A3C2不变
- 纯前排抗伤无奶需求就选A1，舍弃维修模块
- 天权全系锁敌速度拉满，不用点锁敌词条，所有维修相关舰船通用这点
- 天枢是后排专职奶船，天权是前排承伤顺带维修，两者搭配效果最佳

## 配队与模块
- A1能量装甲型：纯坦度模块，大量护甲、能量抗性、结构值，无维修相关词条
- A2定向维修装甲：兼顾坦度与单次爆发维修，残血时触发一次性大额修船
- A3超量维修：战斗一分钟后维修效率翻倍，与天枢A3机制一致
- B1载机模块：搭载两架中型战机，对舰输出向，无人机自带对舰伤害，无对空加成
- B2载机模块：两架护航艇搭载位，无人机附带高额对空火力，可搭配干扰艇、挡刀艇
- C1飞行管控：给舰载机往返冷却加成，和天枢C1效果相同
- C2附加维修：持续群体维修，搭配A3直接成型强力前排奶船
- D1拦截系统：低效拦截
- D2强化结构：高额结构、护甲小幅提升
- 标准配置：A3+C2，D2可选
- 缺防空配置：B2+A3+C2
- 纯前排抗伤配置：A1，舍弃维修模块

## 数值与数据
- A1加点优先护甲、能量抵抗、结构值，旗舰生存策略必点
- A3加点必点超量维修策略，两格冷却，维修装甲视蓝图富裕程度点
- C2加点生存策略、冷却拉满，最后一格高额维修效果必点
- 维修装甲资源充足多点，资源紧张优先冷却和维修加成
