# A资料108

## 场景 / 对手
舰队配置思路讨论，涵盖轰炸、防空、输出、抗伤四种体系

## 舰队例子
- C二苍穹为核心，轰炸模块（胜）【顶着轰炸往前跑，适合正面推进】
- 棕熊防空为核心，防空模块（胜）【对抗轰炸的碰瓷队】
- 风暴、混沌离子等为核心，输出模块（胜）【护航状态下打出较高对舰输出】
- 大队为核心，抗伤模块，前排闪避（胜）【现版本大船扛伤基础上增加前排闪避】

## 结论思路
- 以C二苍穹为核心的轰炸队，可顶着轰炸推进
- 以棕熊防空为核心的防空碰瓷队，专为对抗轰炸设计
- 以风暴、混沌离子等为核心的输出舰队，在护航状态下打出高对舰输出
- 以大队为核心的抗伤队，现版本增加前排闪避以提升生存

## 适用限制
- 轰炸队适合正面推进，但需注意防空威胁
- 防空碰瓷队仅针对轰炸体系，对其它输出可能乏力
- 输出舰队依赖护航状态，脱离护航则效果下降
- 抗伤队依赖大船和前排闪避，对高命中或无视闪避的敌人效果有限
