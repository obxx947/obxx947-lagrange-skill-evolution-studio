# A资料529

## 场景 / 对手
天枢舰船模块解析，涉及空战、奶船辅助、对舰等

## 舰队例子
- 天枢 + B1 + M1（胜）【毕业难度低，适合新手，但无人机伤害不如M2】
- 天枢 + M2 + B2（胜）【推荐选择，对空火力高，但毕业难度较高】
- 天枢 + A3 + C2（胜）【核心奶量组合，超量维修和附加维修系统提供高奶量】
- 天枢 + C1 + B2（胜）【75%往返加成，强化轰炸机输出，适合副队】

## 实战结果
天枢在副队中收益高于主队，A3和C2组合能有效应对爆发伤害，奶量充足；A2模块实战意义不大，D1模块为垃圾模块

## 结论思路
- M2对空火力高于M1，优先选择M2
- 副队配置遵循4艇加4机平衡，推荐M2+B2或B1+M1
- A3超量维修是核心，应对爆发伤害奶量足，甲片限制影响不大
- C2附加维修系统提供大部分奶量，加点策略保生存、冷却、维修
- A1作为备选，加点策略加维修；A2杯水车薪，不建议使用
- C1配合B2强化轰炸机输出，但天枢主队收益低，副队更佳
- D2提供结构值和护甲，但非必需，有维修模块即可

## 适用限制
- A3甲片有限，长时间战斗可能耗尽，但正常对局影响不大
- A2维修量少，不适合高强度战斗
- D1模块无用，不建议使用
- 天枢适合副队，主队收益低
- C1天枢在第二家园中可用
