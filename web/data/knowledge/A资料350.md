# A资料350

## 场景 / 对手
加五状态下的天枢肉队与十一加十三鱼单航母配对，正面作战

## 舰队例子
- 天枢肉队：增援武天书，护艇双海波，飞机天玄加沙龙或新大帝；副队前排开阳加瑶光，御衡C提供续航，逆境卫士附加盾（胜）【肉队核心，抗伤能力强】
- 第二家C三的矛：全域拦截和挡刀（胜）【提供拦截和挡刀】
- 主队：M2风暴战列，大件提供龙甲，重卡狩猎、猎兵补充超斩伤害；航母十一加十三鱼（胜）【输出稳定，航母点数足够可用苍穹替代卡托和猎兵】
- 替代方案：十一鱼或八加三的CD巡洋风，更多护体物和飞机尾（胜）【适用于航母点数不足或无重卡的玩家】

## 实战结果
天枢肉队配合十一加十三鱼单航母，对抗开阳瑶光体系，多胜少负，关键得失在于次摇和零五零优先点反响应对开阳瑶光，主队输出稳定

## 结论思路
- 肉队增援武天书，护艇双海波，飞机天玄加沙龙或新大帝，增强抗伤和输出
- 副队前排开阳加瑶光吸收直射火力，御衡C提供续航，逆境卫士附加盾
- 第二家C三的矛提供全域拦截和挡刀
- 主队M2风暴作为输出核心，大件提供龙甲，重卡狩猎、猎兵补充超斩伤害
- 航母点数足够用苍穹替代卡托和猎兵，点数不足用十一鱼或八加三CD巡洋风

## 适用限制
- 适用于加五状态下的天枢肉队和十一加十三鱼单航母
- 航母点数不足或无重卡时需调整配置
- 次摇和零五零需优先点反响以应对开阳瑶光
