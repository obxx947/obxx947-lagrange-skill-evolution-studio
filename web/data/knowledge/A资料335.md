# A资料335

## 场景 / 对手
针对盟内成员不愿出碰瓷队的问题，讨论碰瓷队的配置、作用和实战价值

## 舰队例子
- 开渊、乃斗牛防空、亚伯防空、水母防空、狼溪防御、古神奶、锆石突击、静态脉冲、云海防空、白垩纪装萤石、装阳光、棕熊防空（可选）（胜）【以驱护为主，低成本、生产时间短，兼顾防空和生存，凑齐300人口不难，其中5个船是诺玛的，条件好可带棕熊防空兼顾碰瓷和投防】

## 实战结果
碰瓷队用于吃掉对面轰炸，与己方空大夹击，中期可上五毫米增加输出，大量碰瓷与敌对换轰炸战损，稳赚不赔；碰瓷队是接地灭的第一关，否则被炸只能在停滞屏往返跑

## 结论思路
- 碰瓷队用最低成本、更少生产时间兼顾防空生存，以驱护为主
- 碰瓷队虽无输出，但吃掉对面轰炸后对面也无输出，且地面多为喷子，需快速冲到对面航空炸地面前
- 中期碰瓷可上五毫米增加输出
- 碰瓷队是完整舰队体系的一部分，需配合碳磁头、房地推、肉奶、轰炸等至少五个舰队，不是只造碰瓷
- 碰瓷队是接地灭的第一关，否则被炸只能停滞屏往返跑

## 适用限制
- 适用于中期或资源有限时，以驱护为主，低成本快速成型
- 需有分舰队配合，不能只造碰瓷队
- 条件好时可带棕熊防空，否则不带
- 不适合单独作战，需与轰炸等舰队协同
