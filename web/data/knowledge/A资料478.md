# A资料478

## 场景 / 对手
风暴模块选择，抗伤队和输出队，正面或轰炸环境

## 舰队例子
- 风暴（抗伤队，不抗轰炸）：b一+d一+a二（胜）【b一对舰武器加低对空，d一偏输出，a二单发够且数量多】
- 风暴（抗伤队，扛轰炸）：b二+d二+a二（胜）【b二主要对空，d二防空伤害高且带拦截效果】
- 风暴（打高护甲目标）：a三+b一+d一（胜）【a三能量伤害，针对大盾、大矛、天权等高护甲目标】
- 风暴（输出队）：m二+a二或a三+b一+d一（胜）【c模块不上以节约点数，打背刺不扛伤】

## 实战结果
无具体实战记录，主要讲解模块搭配思路

## 结论思路
- 抗伤队不抗轰炸时，关键模块是d一和b一，b一有对舰武器加低对空，d一偏输出
- 抗伤队扛轰炸时，选择b二加d二，d二防空伤害高且带拦截效果
- a模块影响不大，一般选a二，因为单发够且数量多
- 对面高护甲目标多（如大盾、大矛、天权）时，可选a三能量伤害
- 输出队核心是m二，a二或a三根据情况，b一和d一，c模块不上以节约点数

## 适用限制
- 抗伤队不抗轰炸时，不选b二和d二
- 扛轰炸时必须选b二和d二
- a三仅在对面高护甲目标多时使用
- 输出队打背刺不扛伤时，不上c模块
