# A资料71

## 场景 / 对手
光锥突击型反小专精巡洋舰，测试环境为三分钟打靶，靶船为卡特（小型舰船）和巡洋舰，未测试航母和战巡（因单发不破四百，受高护甲限制）

## 舰队例子
- 8个光锥突击型（共160人口），主武器导弹系统加点：通用命中、双冷却、一策略、双伤害；无人机系统加点：一冷却、一索敌、一命中（负）【反小输出不及格，总伤害和分钟伤害均低于混沌；对卡特击杀效率低，无人机调校收益低】
- 光锥突击型（被无人机命中增益8层）（胜）【对卡特伤害达3万，但仅3个光锥获得增益，其余无增益光锥对卡特伤害仅8千多】
- 光锥突击型（调校后）（胜）【对巡洋舰伤害出奇高，分伤20多万，中期巡洋对拼有优势】

## 实战结果
光锥突击型（8个）打靶卡特和巡洋舰，反小数据拉胯，击杀效率低于混沌，但反巡洋伤害高；关键得失：无人机分摊机制导致增益不均，反小能力受限，反巡洋能力突出

## 结论思路
- 光锥突击型定位反小专精，但反小输出不及格，前期上场存疑
- 加点推荐：主武器通用命中、双冷却、一策略、双伤害；无人机一冷却、一索敌、一命中
- 无人机调校收益低，日常使用不建议点
- 无人机命中增益受分摊机制影响，仅部分舰船受益，导致整体反小效率低
- 对巡洋舰伤害高，中期巡洋对拼有优势，造价可接受

## 适用限制
- 适用于中期巡洋对拼场景
- 不适用于对抗高护甲目标（如航母、战巡）
- 反小能力弱，不适合作为主力反小舰船
- 无人机调校不建议使用，收益低
