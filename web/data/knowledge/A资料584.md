# A资料584

## 场景 / 对手
副队超主力搭配选择

## 舰队例子
- 大盾（胜）【单金战训账号优先】
- 大矛（胜）【单金战训账号次选】
- 59（胜）【单金战训账号第三】
- 风暴（胜）【单金战训账号与其他战训优先级持平】
- 矛盾组合（胜）【双金战训账号首选】
- 59配大盾（胜）【双金战训账号次选】
- 59配大矛（胜）【双金战训账号第三】
- 风矛盾组合（胜）【三金战训账号优先级最高】
- 59搭配矛盾（胜）【三金战训账号次选】
- 天权（胜）【养成度高于大矛时可互换】

## 结论思路
- 单金战训账号优先大盾、其次大矛，再到59，风暴和其他战训优先级持平
- 双金战训账号首选矛盾组合，其次59配大盾，再选59配大矛
- 1+2配置账号不建议风暴放副队，风暴放主队更佳
- 三金战训账号风矛盾组合优先级最高，其次59搭配矛盾
- 天权养成度高于大矛时，两者可互换位置

## 适用限制
- 单金战训账号适用
- 双金战训账号适用
- 1+2配置账号不适用风暴副队
- 三金战训账号适用
- 天权养成度需高于大矛才可互换
