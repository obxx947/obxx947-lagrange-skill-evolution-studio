# A资料539

## 场景 / 对手
SOLO空战，对手为米斯特拉、VB、列兵（T800）等空优阵容，正面交锋，环境为体验服

## 舰队例子
- 南十字+鳐（8条）+坦普尔+矛（4-5条）+雷影+虚灵+T800（胜）【鳐限制米斯特拉1.5-2分钟，坦普尔分伤减少前排压力，VB伤害被削减】
- 鳐（4条）（负）【数量不足，限制效果不明显】

## 实战结果
我方以鳐+坦普尔为核心的阵容，对战米斯特拉、VB等空优阵容，三把实战中后期增加鳐数量后效果显著，限制米斯特拉火力，VB伤害被分伤削减，最终获胜。关键得失：鳐的生存和数量是关键，坦普尔分伤保护前排，信息链缺失导致对方空战效率低下。

## 结论思路
- 鳐可伪装成战机，基础8000血，强化后可达1万血，80%闪避，能长时间限制米斯特拉等空优机
- 坦普尔分伤效果显著，减少前排负担，保护矛等主力舰
- 信息链在空战中至关重要，缺失则空战效率减半
- 护航艇血量普遍高于战机，鳐和虚灵等有提升空间
- 雷影等小船混搭可吸引VB火力，配合坦普尔分伤
- 纯空优阵容适合打滞空阵容，但怕大帝后期发力

## 适用限制
- 适用于SOLO空战，特别是面对米斯特拉、VB等空优阵容
- 鳐数量需足够（至少8条）才能发挥明显限制效果
- 坦普尔需保证生存，数量不重要
- 怕大帝等后期强力舰船，可能被清空飞机
- 苍穹在组队中表现不佳，不推荐使用
- 包子对空效率极低，不建议携带
