# A资料491

## 场景 / 对手
D赛策略争议，涉及航母、康纳离子、高速舰队、电焊队等体系，正面作战环境

## 舰队例子
- 单航母+康纳离子泡泡+高速舰+补机位+增援护航（胜）【正常伤害配置，需点D赛策略获得额外加成】
- M3+AE优先+光锥清除（胜）【快速清除敌方拦截，减少拦截数量】
- 毛子（5个）放前排+矛盾中排（胜）【30-40秒完成，适合当前矛盾组合】
- 纯电焊+8个高速I（胜）【基础型号有反大命中，频率好，冷却9.4秒】
- 列为9号+3发鱼雷（胜）【不怕拦截，最多中两发，可能未命中或被拦截】

## 实战结果
玩家讨论D赛策略，强调点策略的重要性，对比不同舰队配置，未明确胜负次数，关键得失是策略加成和配置选择

## 结论思路
- D赛策略必须点，提供额外加成如伤害、命中率、持续时间等
- 当前主流是矛盾组合，配康纳离子和高速舰
- 大剑配M3和AE优先清除光锥，减少拦截
- 毛子放前排，矛盾中排，效率高
- 电焊队用8个高速I，基础型号有反大命中，频率好
- 列为9号鱼雷不怕拦截，但命中有限

## 适用限制
- 适用于有D赛策略的玩家
- 需要康纳离子和高速舰配合
- 毛子数量需5个以上
- 电焊队需基础型号有反大命中
- 列为9号鱼雷最多中两发，可能未命中或被拦截
