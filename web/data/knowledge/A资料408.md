# A资料408

## 场景 / 对手
卡利莱恩级特种型，前排炮灰定位，高闪避低血量，前期环境

## 舰队例子
- 卡利莱恩级特种型（纯抗伤，无输出模块）（负）【血量低，扛伤能力差，75秒策略启动前易被击毁】

## 实战结果
卡利莱恩特种型作为前排炮灰，实战中表现不佳，因血量过低导致扛伤能力不足，策略启动前常被击毁，无输出贡献

## 结论思路
- 卡利莱恩特种型定位前排炮灰，但血量太低，扛伤能力远逊于系神
- 75秒策略触发时间过长，启动前可能已阵亡
- 前期花五人口放纯抗伤船非常亏，性价比低
- 唯一作用是在前期充当筛泡（炮灰）使用

## 适用限制
- 仅适用于前期作为临时炮灰，不适合长期或后期使用
- 不适用于需要稳定扛伤或输出的场景
- 高闪避无法弥补低血量的致命缺陷
