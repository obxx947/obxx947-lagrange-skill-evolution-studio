# A资料162

## 场景 / 对手
平民副队配置讨论，涉及矛和盾的组合、前排坦度与资源消耗的权衡

## 舰队例子
- 矛（前排）+ 盾（旗舰）（负）【高强度作战时矛损耗大，建造时间长（5小时以上），资源消耗高，易资源不足】
- 小船（如阳气神星凯特）替代矛（胜）【坦度与矛相近，但造价低、建造快（2-3小时），适合平民】
- 五九替代矛（带电磁模块）（胜）【坦度略逊于矛，但有电磁模块对能量伤害减伤，造价更便宜】

## 实战结果
无具体战报，为配置讨论；关键得失：矛虽强但资源压力大，小船或五九更经济

## 结论思路
- 平民副队最优解是矛和盾的组合，但需根据资源情况调整
- 高强度作战时矛损耗大，建造慢且贵，可用小船替代以节省资源
- 小船（如阳气神星凯特）坦度接近矛，但成本低、建造快
- 若需打头，可用五九替代矛，五九有电磁模块减伤且更便宜
- 出矛的条件：需要锁人防撤退、经济充裕、或副队需极肉时，可前排小船加五个矛

## 适用限制
- 适用于平民玩家资源有限的情况
- 不适用于资源充足或需要极致坦度的场景
- 小船替代矛时需注意坦度差异，五九需电磁模块才能发挥优势
