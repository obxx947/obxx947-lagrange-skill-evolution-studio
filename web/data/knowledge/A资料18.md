# A资料18

## 场景 / 对手
当前版本轰炸较多，防空队应对敌方轰炸圈，洗对面飞机和艇

## 舰队例子
- 古神之源（双倍奶量，防空无人机可同排和跨排防空）（胜）【配合台源组成双皮奶，防空较好】
- 台源（可跨排防空）（胜）【奶量可怜，主要防空】
- 防御牛（加点正确）（胜）【防空可观】
- 领猎级防御驱逐舰（城或对接点购买）（胜）【防空武器优先打战机】
- 卫士（万金油）（胜）【造价高】
- 枪骑兵（调后排或中排）（胜）【防空好，但前排易死，造价时间长】
- 水母防御（护卫舰）（胜）【全镇型防空，稳定高效】
- 静海脉冲（胜）【防空可用】
- 澄海防空型（散射弹头，联动同排防空策略）（胜）【造价低，实测中整个舰队建设防空好】
- 红宝石离子（负）【防空不稳定】
- 721导弹型（低赛）（胜）【防空不错，后排便宜】

## 实战结果
防空队扔进敌方轰炸圈，洗对面艇和飞机，主要靠区护防空队配合特卡、富贵等，需调站位并至少近三个吃旗舰

## 结论思路
- 古神之源配合台源组成双皮奶，防空效果好
- 台源主要防空，奶量不足
- 防御牛防空可观，需加点正确
- 领猎级防空优先打战机
- 卫士万金油但造价高
- 枪骑兵防空好但需调后排，造价时间长
- 水母防御稳定高效
- 澄海防空型造价低，散射弹头联动策略，实测好
- 红宝石离子防空不稳定
- 低赛可选721导弹型，防空不错且便宜
- 防空队需调站位，至少近三个吃旗舰，配合特卡等

## 适用限制
- 适用于当前版本轰炸较多的情况
- 防空队需扔进敌方轰炸圈，适合碰瓷
- 需注意站位和旗舰配合
- 红宝石离子不推荐
- 枪骑兵需调后排避免前排死亡
