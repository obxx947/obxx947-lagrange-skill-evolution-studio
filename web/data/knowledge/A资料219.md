# A资料219

## 场景 / 对手
对抗开阳极（高闪避小船）

## 舰队例子
- 南十字石基 + VA + 小米，优先打前排，无视50%能量护盾（胜）【针对开阳高闪避，通过动力系统绝育快速摧毁】
- 超斩队，无视小船直接打大船（胜）【让对面战损最大化】

## 实战结果
无具体战报，提供两种有效遏制开阳极的方法

## 结论思路
- 开阳存活依赖高闪避，需通过攻击动力系统（绝育）来降低闪避
- VA和小米是开阳克星，装在南十字石基上优先打前排，且无视50%能量护盾，不怕摇光效果
- 超斩队可无视小船直接攻击大船，造成对面战损最大化

## 适用限制
- 适用于对抗开阳极（高闪避小船）
- 需配置南十字石基、VA、小米或超斩队
- 不适用于无高闪避目标的场景
