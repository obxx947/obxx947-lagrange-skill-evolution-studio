# A资料64

## 场景 / 对手
工会玩家400人口输出主队，对手/体系：无特定对手，正面/轰炸：正面输出，环境：工会玩家炮艇缝合导致输出不足

## 舰队例子
- 前排8个L，中排3个风暴，后排8个混沌，总人口400（胜）【主要输出配置，依赖航母防空】
- 增援航母：零幺幺（8+3载具），炮艇15个位置（胜）【公会玩家炮艇缝合，剩余选择零幺幺】
- 战机：唯一B、小米、050、次遥（反小），CV玩家用火炮型零幺幺，蓝十字玩家可选凌霄（胜）【弥补星脉缺失的反小压力】

## 实战结果
无具体实战记录，配置推荐针对工会玩家，关键得失：缺乏星脉导致反小能力弱，需调整战机选择

## 结论思路
- 配置核心是混沌和艾奥快速打穿前排，风暴用于巡洋舰斩杀和输出补充
- 战机数量不少于40个，选择050和次遥并调整攻击序列为反小，弥补反小短板
- 小米和凌霄用于绝育动力系统，优先打击超主力，CV玩家用火炮型零幺幺，蓝十字玩家用凌霄

## 适用限制
- 适用于工会玩家，炮艇缝合导致输出不足
- 防空完全依赖航母，航母质量不高时对轰炸抵抗弱
- 配置仅供参考，需根据自身航母和战机调整
