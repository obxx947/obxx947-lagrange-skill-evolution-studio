# A资料81 · 阋神星I级三型号解析

## 结论
- 主型号首充可得，改版后火力输出较高，易击穿中小型舰船护甲
- 重炮型号从开服至今未淡出视野，单发输出极高，对大中小型舰船都有威胁
- 重炮型号护甲穿透能造成很好伤害，生存能力也较好
- 重炮型号基础25%闪避强化之外还有额外两次加点
- 重炮型号在输出、生存、制造成本上都比较优秀
- 装甲型号基础血量相比前两个型号有质的飞跃
- 装甲型号后续有三次额外基础血量加点，最终血量加点可到五万多
- 装甲型号策略优秀，封锁后可掩护同类型舰船并优先承伤
- 装甲型号配合诺玛M470级-支援护卫舰（原文为"诺玛奶"，疑似简称）全奶可打出一定平摊效果
- 大炮巨舰时代大船对中小型舰船锁敌速度较慢，装甲型号上场可拖延作战时长，为主力部队制造机会

## 配队与模块
- 重炮型号加点参考视频图进行加点即可
- 装甲型号配合诺玛M470级-支援护卫舰全奶

## 数值与数据
- 装甲型号最终血量加点可到五万多
- 重炮型号基础闪避强化25%
- 重炮型号额外两次加点
- 装甲型号额外三次基础血量加点
