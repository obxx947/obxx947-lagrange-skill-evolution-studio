# A资料328

## 场景 / 对手
对抗输出队，正面战斗，涉及防空和奶量体系

## 舰队例子
- 波波（天机）加点：主武器优先频率、冷却，策略点闪避，建议一闪避一策略一频率（胜）【提高生存率，减少被锁定概率】
- 瑶光一：AB双信号齐时按2:1配置（胜）【优化配置】
- 八股神：减少数量，补上006（至少5-6个）（胜）【奶量足够，避免过多占用人口】
- 防空队：小米和八百全部向上，带枪防（胜）【有效对抗对空输出，小米可打艇】
- 对面：八个泡泡龙配奇美拉（负）【无双航，奇美拉输出不错但整体配置不足】

## 实战结果
我方对对面输出队，几胜几负未明确，关键得失：我方防空有效抵消对面奶量，对面奶量不足且配置问题

## 结论思路
- 股神奶在扛伤队中不是第一位，正常上几个006即可，不必上满
- 波波加点应优先频率和冷却，策略点闪避提高生存率
- 瑶光一按2:1配置，需AB双信号齐全
- 防空必须带枪防，小米和八百向上可有效对空
- 对面奶量不足，006过多不如股神奶效率高

## 适用限制
- 适用于对抗输出队场景
- 需要防空配置支持
- 波波加点需点数充足
- 瑶光一需AB双信号齐全
- 对面无双航时可用泡泡龙配奇美拉
