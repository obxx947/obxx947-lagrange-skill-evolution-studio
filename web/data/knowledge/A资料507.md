# A资料507

## 场景 / 对手
针对不同等级玩家（level一/二/三）的舰队克制策略，正面战斗，环境为常规PVP

## 舰队例子
- 预制队：四条战群（如零六六）+ 足量拦截 + 奶量（御痕c、光房）+ 前排高闪避小船（如富家顿、摇光）（胜）【对level一玩家压制力强，前排小船抗直射，中排战群拖住反大火力】
- 预制队变种：多上布加顿战群，走分摊路线（胜）【针对level二玩家，分散锁母河火力，提升中排生存】
- 天书航母 + 海尔波普b型号（或cv三千 + 海尔波普b + 摇臂sp前排）（胜）【克制level三玩家，天书奶量稳定，b型号需保证存活】
- 摇臂sp（四百子币一个箱子，全传三千二子币）（胜）【最便宜sp，适合平民，用于航父前排挡刀】

## 实战结果
预制队对level一玩家多胜，对level二玩家略吃力但可用，对level三玩家力不从心；天书体系可克制level三。关键得失：预制队性价比高但怕取射战群和苍穹；天书奶量稳定但需保护b型号

## 结论思路
- level一玩家靠直射堆积，预制队用前排高闪避小船和中排战群分开承伤，可有效压制
- level二玩家取射战群喜欢打巡洋，预制队需多上布加顿分摊，变相吸走锁母河火力
- level三玩家有苍穹，破阵快，预制队中排战群易被斩杀，需用天书或cv三千搭载海尔波普b型号
- 天书奶量按自身，不死则奶量永存，是克制level三的唯一稳定路子
- 摇臂sp是最便宜sp，适合平民，用于航父前排挡刀

## 适用限制
- 预制队适合对付level一和部分level二玩家，但面对level三时效果差
- 天书体系需保证海尔波普b型号存活，否则cv成废铁
- 坦普尔a型号不推荐，面对无空军时不起飞；b型号血厚闪避高
- cv三千需点满装甲和动力闪避，作为天书替代但需主挡刀
