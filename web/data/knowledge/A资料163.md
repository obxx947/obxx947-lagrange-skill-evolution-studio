# A资料163

## 场景 / 对手
碰瓷队组队与实战

## 舰队例子
- 血卡（喷射炮）（胜）【核心碰瓷单位】
- 石台（奶食防御）（胜）【提供防御支援】
- 牛池（水母防空）（胜）【防空作用】
- 基亚博（防控）（胜）【防控】
- 四枪（防增援）（胜）【防止增援】
- 未放光防护（棕熊防空）（胜）【防空】
- 封锁投射队（15个七二幺导弹、6个枪房、1个SP五九）（胜）【由蒙内佛耶戈尔提供】

## 结论思路
- 碰瓷队需要所有血卡，通常用喷射炮
- 常用配对包括直射、石台奶食防御、牛池水母防空、基亚博防控、四枪防增援、未放光防护、棕熊防空
- 封锁投射队配置为15个七二幺导弹、6个枪房、1个SP五九，由蒙内佛耶戈尔提供

## 适用限制
- 需要特定舰船和模块，如血卡、石台、牛池等
- 适用于碰瓷战术，需注意防空和防增援
