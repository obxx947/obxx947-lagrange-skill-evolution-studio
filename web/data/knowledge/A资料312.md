# A资料312

## 场景 / 对手
天枢级支援航空母舰上线后的玩法误区解析，涉及舰船定位、搭配思路及适用人群

## 舰队例子
- 天枢级支援航空母舰（A3+C2+G2模块，四级搭配）（胜）【最优模块搭配，需至少150-200蓝点，加点维修和装甲】
- 天枢级支援航空母舰（A3+C2模块）（胜）【次优搭配，单独A3模块也可用】
- 天枢级支援航空母舰（A1+C2模块）（胜）【替代搭配，适合特定情况】

## 实战结果
天书作为奶妈在高达副队中提供百万级回复量，作为超主力分摊伤害，提升副队持久性；搭配天权掩护策略提高物抗，为海尔双兄弟挡刀，增加存活时间

## 结论思路
- 天书对模块要求不算太高，但白板无法使用
- 最优模块搭配为A3+C2+G2，至少150-200蓝点
- 加点需兼顾维修和装甲，保证抗性和血量
- 天书定位为奶妈、超主力分商和机位提供者
- 搭配天权掩护策略可提高物抗和存活率
- 天书最好进入全超主力组成的高达部队，矛盾队也可
- 补天书使用增援位即可

## 适用限制
- 平民不建议使用，模块造价高（少则几千，多则几万子币）
- 只建议2+2级以上玩家使用，否则效果不明显甚至降低战斗力
- 平民可每天买半价箱替代
