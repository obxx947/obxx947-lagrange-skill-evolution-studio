# A资料356

## 场景 / 对手
新舰船雷火之辉无人机航空母舰的机制解析，无具体对手或实战环境

## 结论思路
- 雷火之辉无人机航空母舰初始搭载5个定制护航艇，以M系统为主导。
- 舰载机在结构低于10%时可返回维修，45秒内恢复60%结构值，维修后结构值高于60%。
- M1模块：维修后90秒内，攻击舰载机时延长目标飞行时间10秒，效果持续60秒。
- M2模块二选一：辉光翼维修后对系统损坏目标造成额外50%系统伤害；辉光二在维修前触发特殊打击，降低目标武器系统结构值上限50%，并在下次损坏时造成5%结构值伤害，延长武器冷却10秒。
- M3模块：维修后为我方火力最高舰船提供掩护，吸引舰船火力30秒。
- C1或C2模块可触发紧急维修，C2在结构低于10%时返回维修，50秒恢复50%结构值，维修后可强化武器伤害、冷却或飞行时间。
- 综合来看，该航母偏辅助，实战能力待验证。

## 适用限制
- 适用于辅助定位，依赖舰载机维修机制。
- M2模块选择需根据战场需求（系统伤害或武器压制）。
- M3掩护效果需配合高火力舰船使用。
- 实战效果未知，需进一步测试。
