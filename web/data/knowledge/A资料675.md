# A资料675

## 场景 / 对手
账号配置优化，地推体系，正面作战

## 舰队例子
- 鱼：三个十一加两个十三，中排指挥系统不点，洗点（胜）【鱼刚拿回枢纽，先不加点，老实使用】
- 战巡：白板大盾，旗舰（胜）【白板可用，吃大盾旗舰】
- 五九：载机和电磁模块，无m3和a2（胜）【能用，但大毛附加挺毛更佳】
- 附加挺毛：中排，改站位，放零幺幺高速徐陵、哈尔波普、谭普尔（胜）【洗掉九号和蜂巢，平衡加点】
- 巡洋：康纳、泡泡龙为主，点策略调满（胜）【高单发高频率，点策略两伤害一策略三冷却】
- 副队：开阳，矛盾为主，两盾三毛，带六个六奶（胜）【以太阳、盘古为主，主输出泡泡龙】
- 鱼：九个锁母河，九个星脉，鸡胃放小米十个，维a五个（胜）【三个鱼的品位配置】
- 两个十三鱼：维b十个，零五零十个，剩余维a补位（胜）【补位可用】
- 凌霄：造三千可带，否则丢机库（胜）【进狩猎亏人口】
- 八g三千：大型战机，放营销和八百十五个（胜）【加点必点反拦截】
- 雷火：基础型号防空强，造三千时八个倒满（胜）【洗次摇或凌霄点子给雷火】
- 海市：放狩猎，加点三冷却一伤害一命中一暴击一伤害（胜）【锁定时间长，需高额解锁，优先对空】
- 光防：主队放一个，前三排点满，第二排不点，第三排全点（胜）【拦截靠主武器模块，区域防空无人机范围小】
- 维b：策略不点（胜）【打地推时副队未炸完不受攻击】
- 盾：装甲系统优先护甲四，血量二，不点守卫球（胜）【六六奶量取决于战群护甲值】

## 实战结果
粉丝账号配置优化，无具体对战记录，主要提供地推体系建议，矛盾组合五战群两盾三毛，后期可造三千

## 结论思路
- 鱼中排指挥系统不点，洗点用十一加十三
- 战巡白板大盾可用，给旗舰
- 五九可用但大毛附加挺毛更佳，挺位中排改站位
- 巡洋以康纳、泡泡龙为主，点策略调满
- 副队以矛盾为主，两盾三毛，带六个六奶
- 造三千则猎兵不造，海市放狩猎，凌霄可带或丢机库
- 八g三千加点必点反拦截
- 雷火基础防空强，造三千时倒满
- 海市加点三冷却一伤害一命中一暴击一伤害
- 光防前三排点满，第二排不点，第三排全点
- 维b策略不点，打地推时副队未炸完不受攻击
- 盾装甲优先护甲四血量二，不点守卫球，奶量依赖护甲值

## 适用限制
- 适用于地推体系，矛盾组合
- 造三千需考虑人口和加点资源
- 不造三千至少上四个列兵，八百两所
- 光防区域防空无人机范围小，拦截效果有限
- 维b策略在特定战斗场景无效
- 海市需高额解锁，适合狩猎载具
