# A资料433 · 天权盾矛站位骗锁战报

> 场景：天权航母体系对轰，正面直射环境

## 结论
- 矛退中排时前突盾可骗对面直射一波锁定
- 矛武器系统被打爆后回前排，盾变回中排再骗一波索敌
- 矛武器系统25秒恢复后回中排，盾继续前走再骗一波索敌
- 该站位操作只针对直射，对投射无效
- 天权带B2会多20个艇位，整场打起来更吃力
- 天权带B1会多3个艇位
- 天权奶附加盾多时，奶天权会更多
- 11鱼+13鱼+苍穹C2与11鱼+苍穹C1输出差距不大
- 点数不够时威力可放到苍穹上，与13鱼差距不大

## 配队与模块
- 我方：5天权、1CV3000级-快速航空母舰（原文为"CV"，疑似简称）、5乌拉诺斯之矛（原文为"毛"，疑似语音识别错误）、5普鲁图斯之盾
- 我方天权模块：A1、C2、D2
- 我方矛：中排矛，点站位
- 我方盾：前突盾，点站位
- 我方输出队：5个11鱼、3个苍穹碎叶、1个A2舰载机
- 我方风暴：4个，M2A2，输出95万
- 我方威力：放苍穹星仪上，输出96万
- 我方T800：放11鱼里，输出38万、31万
- 对面：5天权，模块A1、B2，比A1多20个艇位
- 对面天权无附加，有B1，多3个艇位
- 对面矛：附加前排矛
- 对面输出队：3个11鱼、2个13鱼、4个苍穹C2
- 对面T800：放苍穹C2里，输出27万、28万
- 对面13鱼上威力输出105万
- 光锥提供信息链
