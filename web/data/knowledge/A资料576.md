# A资料576

## 场景 / 对手
针对C2太阳鲸全对舰航母的争议，回应玩家关于防空能力的质疑，讨论配船思路与团战关系

## 舰队例子
- C2太阳鲸（8+6），M1+M2模块，全对舰，带工程无人机，无C1模块（胜）【作者认为最强，输出能力突出，但防空依赖队友】
- 太阳鲸（11+13），带小米+雷神，风暴（能量补偿），凌霄，海氏追随者（负）【防空能力有限，被轰炸后仍需撤退】
- 太阳鲸（5+6），带T800、小米、海氏追随者、星脉、抗马拉狩猎（负）【防空配置但轰炸后仍不能硬吃，机位紧张】

## 实战结果
作者分析粉丝战报，对比左右两套阵容，指出防空配置不足，被轰炸后无法硬抗；作者观点：配船应追求输出，防空靠队友，团战胜负取决于活跃度

## 结论思路
- C2太阳鲸全对舰是最好用的，输出最强，防空可交给队友
- 8+6配置优于6+4，因人口和护航艇数量限制
- 配船应从备战角度出发，追求极致输出，而非过度防空
- 团战胜负主要靠活跃度，配船与团战关系不大

## 适用限制
- 适用于有队友配合防空的环境
- 不适用于单挑或缺乏防空支援的场合
- 6+4配置不推荐，因护航艇数量不足
- 防空配置（如小米、T800）会牺牲对舰能力
