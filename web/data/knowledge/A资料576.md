# A资料576 · 回应C2太阳鲸防空质疑

> 场景：护航队/团战/轰炸环境

## 结论
- C2太阳鲸仍是最强最好用的太阳鲸配置
- M1+M2可放满强力战机护航艇后，才放心抠掉C1换工程无人机
- 不推荐6+4遛鱼太阳鲸，护航艇只有19条强力，两台带T800的太阳鲸强度不足
- 6鱼玩家另起航母带维塔斯B010会压缩420人口，8+6太阳鲸无需压缩
- 全对舰航母不等于队伍没防空，420人口中T800、雷神、脑残无人机、C3大帝都在防空
- C3大帝防空非常需要命中，对舰满命中的大帝有防空加成
- 右边11+13太阳鲸带小米+雷神，但风暴用能量补偿风暴零防空
- 左边5+6太阳鲸带T800、小米、海氏追随者、星脉，仍不能硬吃轰炸不跑
- 5+6太阳鲸机库只有25个位置，带050+维塔斯B010后只剩5个位置
- 配船只按输出最强做，防空交给队伍其他船
- 团战打不过多因走位不好被夹，不是配船问题
- 团战核心是活跃度，活跃度够再差都能打赢，没活跃度船都造不出
- 配船与团战没有关系，团战是一场场小事故

## 配队与模块
- 8+6太阳鲸：M1+M2放强力战机护航艇，C1换工程无人机
- 6+4太阳鲸：只放护航艇，M模块无足够强力护航艇
- 420人口队伍：太阳鲸外带T800、雷神、脑残无人机、C3大帝
- 11+13太阳鲸：小米+雷神组合
- 风暴：能量补偿风暴零防空
- 5+6太阳鲸：T800带满，海氏追随者，康纳马拉混沌级轨道炮型狩猎者补机位
- 5+6太阳鲸机库：050+维塔斯B010组合后只剩5个位置

## 数值与数据
- C2太阳鲸曾打出250万对点伤害
- 强力护航艇只有19条
- 5+6太阳鲸机库25个位置
- 11+13太阳鲸为2.0左右配置
