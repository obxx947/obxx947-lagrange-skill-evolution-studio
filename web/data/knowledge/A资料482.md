# A资料482

## 场景 / 对手
针对当前轰炸横行环境，应对低配或高配（14个苍穹）轰炸的防空碰瓷体系

## 舰队例子
- 斗牛（防护型号）+ 精密射击模块（胜）【必点精密射击，核心防空输出】
- 双皮奶（裁员）+ 台元 + 股神（胜）【三者必上，形成跨牌防空】
- 枪骑兵（至少5艘）（胜）【同型号3艘生效，对空能力优秀】
- 台元（防空无人机，不加奶量）（胜）【奶量忽略不计，应加伤害】
- 静海脉冲（或澄海防空型）（胜）【澄海防空型对空有溅射伤害】
- 水母（防空刺）（胜）【打挺非常强】
- 郎溪（基础型号）（胜）【只用基础型，非常好用】
- 光锥（增援）（胜）【用于扛住苍穹缝合轰炸】
- 13鱼（防空碰瓷）（胜）【放凌宵、小米、包子半场防空、沙龙，安德森可选】

## 实战结果
防空碰瓷队可应对除14个苍穹轰炸外的多数轰炸，13鱼单对时需配置特定飞机，安德森策略可干扰敌方战机

## 结论思路
- 斗牛防护型号必须点精密射击
- 双皮奶、台元、股神必上形成跨牌防空
- 枪骑兵至少5艘以激活同型号效果
- 台元不加奶量，加伤害提升防空能力
- 补充便宜舰船如静海脉冲、澄海防空型、水母
- 郎溪只用基础型号
- 扛苍穹轰炸可增援光锥
- 13鱼防空碰瓷需放凌宵、小米、包子、沙龙，安德森可选

## 适用限制
- 不适用于14个苍穹的轰炸
- 台元奶量忽略不计，不应投资奶量
- 沙龙伤害依赖被攻击，需敌方对空单位打它
- 根据账号质量调整配对
