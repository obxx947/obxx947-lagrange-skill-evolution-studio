# A资料364

## 场景 / 对手
雷火之辉无人机航空母舰评测，针对其模块、定位及对副队飞机海体系的影响

## 舰队例子
- 雷火之辉（白板，35人口，中排航母，无舰载机）（负）【白板无舰载机，基础血量28万，加点后约30多万血、200多护甲、25能量抗性，比战巡肉但无重甲模块，定位类似战巡】
- 雷火之辉（M1+A1模块，定制护航艇）（负）【A1为定制护航艇，能量伤害优先打大船，主动防空但无空军攻击序列，伤害一般，适合扛伤队对空】
- 雷火之辉（M2+A2模块，5个护航艇）（负）【A2为5个护航艇，6个加点位，无冷却加成，伤害加成约10%，对护航艇增益有限，强度一般】
- 雷火之辉（M3+A3模块，5个大型战机）（负）【A3为5个战机，6个加点位，维修后关闭系统类武器并为输出最高舰船提供掩护，类似天权但保护效果更好】

## 实战结果
无实战记录，仅基于模块和加点分析，评价为克老玩具，以刻度换战斗

## 结论思路
- 雷火之辉白板无舰载机，定位类似战巡，比战巡更肉但无重甲模块
- M模块围绕舰载机生存设计，特种维修仅作用于本舰搭载的舰载机，不作用于舰队其他舰载机
- A1定制护航艇伤害一般，适合扛伤队对空，加点可优先攻击舰载机
- A2护航艇模块加点位多但无冷却，伤害加成有限，强度一般
- A3战机模块维修后提供掩护效果，类似天权但保护效果更好，能保护万通和基因
- 该船是副队飞机海体系的升级，针对克老的高达副队，以刻度换战斗

## 适用限制
- 适合作为扛伤队或副队飞机海的辅助舰船
- 白板无舰载机，需搭配模块才能发挥作用
- 不适合作为输出主力，伤害较低
- 特种维修仅对本舰搭载的舰载机有效，不适用于舰队其他舰载机
- 模块获取难度高，爆率低，适合高投入玩家
