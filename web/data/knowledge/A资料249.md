# A资料249

## 场景 / 对手
当前版本，针对某舰船（疑似“荒挺”或“护王鼎”）的加点与配置分析，未涉及具体战斗

## 结论思路
- 主型号策略效果对敌方施加闪避下降，必点；暴击加点中，大命中推荐必点，因荒挺需要命中率
- 动力系统加点推荐打击间隔和双闪避，以提升保命能力
- 装甲系统推荐血量加成（三项）
- 信息系统优先点“率大”，可提升整体打击效率
- 攻击序列以大型舰船（尤其是航母战群）为主要输出方向
- 主武器系统偏向输出和动力系统打击，子型号输出效率下降，更多偏向支援型效果
- 主武器系统对武器绝育效果更多，且以肩带机buff加成为主，配合舰船打击
- 两个型号生存效果均不错，基础闪避和额外闪避加成，配合血量加点，生存和输出兼具
- 基础血量在护王鼎中较高

## 适用限制
- 适用于当前版本，具体加点可能随版本调整
- 适用于荒挺或护王鼎类舰船，其他舰船需另行分析
- 子型号输出效率较低，不适合纯输出场景
- 测试需使用天阳集账号，未实际验证表现
