# A资料166

## 场景 / 对手
风暴与大剑的舰队配置讨论

## 舰队例子
- 大剑（含脉冲炮系统核心模块）（胜）【高输出且能物理融甲，适合主队替换风暴】
- 大地（白板）（胜）【平民战神，不吃经济，白板即可发挥极大战斗力】

## 实战结果
风暴在副队表现优秀，但大剑更适合主队作为主力输出；大地作为经济型替代方案

## 结论思路
- 大剑伤害高，拥有脉冲炮系统模块即可实现高输出和物理融甲
- 大剑应进主队替换风暴，风暴则留在副队
- 大地白板即可使用，适合经济有限的玩家

## 适用限制
- 大剑需要核心模块脉冲炮系统才能发挥高输出
- 大剑经济成本较高，不适合资源紧张的玩家
- 大地适合平民，但可能输出上限低于大剑
