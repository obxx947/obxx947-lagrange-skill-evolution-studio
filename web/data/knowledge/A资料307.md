# A资料307

## 场景 / 对手
2.5阶段对抗，双方配置正规，对手带高铁、天梯、猎鬼、风暴、坦克克，我方带波波、天枪、蜂巢、066、小米、八百

## 舰队例子
- 波波（带队，包铁带队）+ 天枪 + 蜂巢（负）【波波存活率低，天枪蛋糕优先级在波波下，导致波波先死】
- 对面高铁 + 天梯 + 猎鬼（胜）【高铁天梯存活率不高但死在波波前，猎鬼挡刀但花人口不划算】
- 066（超斩，三十二万人口）（胜）【人口差距小，血量比驱逐高，奶量相近，但怕断奶】
- 小米 + 八百（超斩）（胜）【双对口时决胜在内功伤害，能快速解决对面配队】

## 实战结果
老板对对面，我方胜，关键在八百和小米快速解决对面，波波虽死但奶量仍解决大部分，对面纯驱射伤无一件伤害导致反伤偏弱

## 结论思路
- 波波奶量不足时，包铁必须带队，蜂巢存活率低因无闪避策略和高锁定
- 天枪蛋糕优先级在波波下，导致波波先死
- 对面天机强势因死在波波前，猎鬼挡刀但花人口不划算
- 066全代码不推荐，尤其对方断奶多时，风暴和坦克克都能断奶
- 有能力养小米和八百时，八百没必要做，走超斩，关键在配对是否有效
- 小米和八百要放主队，不放副队，因信息链影响安全
- 决胜取决于内功伤害能否打到对面，优先解决对面配队
- 波波活到六分钟阶段则强度高，否则靠其他解决奶量
- 老板需更好挡刀和修护，可养困觉或风暴，音效狩猎不如苍穹

## 适用限制
- 适用于2.5阶段对抗
- 波波需包铁带队，否则存活率低
- 对方断奶多时避免066全代码
- 小米和八百需放主队，不放副队
- 需有能力养小米和八百双对口
