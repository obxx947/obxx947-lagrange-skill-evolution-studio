# A资料609

## 场景 / 对手
巡洋舰对比测试，对手为电磁五九，正面攻击，环境为五分钟战斗模拟

## 舰队例子
- 泡泡龙（直射型等离子投射器，主武器）（胜（对舰伤害60万））【直射不可拦截，但需先打前排】
- 游离子（重型离子炮主武器，投射导弹副武器）（胜（对舰伤害76万））【副武器可补刀，但可被拦截】

## 实战结果
泡泡龙打电磁五九60万，游离子76万；复杂战场中泡泡龙45-48万（反大8万），游离子35万（反大19万）

## 结论思路
- 游离子伤害已超泡泡龙，主武器相当，副武器加成
- 游离子副武器可补刀残血大船
- 复杂战场中游离子反大伤害更高
- 游离子上场优先级高于泡泡龙

## 适用限制
- 测试条件为赛季调教拉满，五分钟战斗
- 抗伤舰船为电磁五九，能量抗性低时伤害更高
- 直射武器受前排影响，投射武器可被拦截
