# A资料526

## 场景 / 对手
拉格朗日装甲系统讲解，无具体对手/体系/正面或轰炸/环境

## 结论思路
- 抵抗伤害可抵消实弹伤害，计算公式为单发伤害减去护甲值。
- 高额抵抗伤害可提供额外治疗量，最高达150%，用于后期保证前排生存。
- 护盾值可百分比削减能量伤害，计算公式为单发伤害乘以（1减护盾值）。
- 常规舰船护盾值最高30%，能量伤害通常能打出70%以上伤害。
- 面对能量伤害时，优先使用高闪避舰船通过规避命中提升生存能力。

## 适用限制
- 抵抗伤害对高单发伤害武器（如反大武器）效果有限，需依赖治疗量加成。
- 护盾值对能量伤害有效，但无法完全抵消，需结合闪避策略。
- 适用于装甲系统配置和舰船选择，不适用于具体战斗场景。
