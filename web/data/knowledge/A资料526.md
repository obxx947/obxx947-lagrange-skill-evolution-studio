# A资料526 · 装甲系统抵抗伤害与护盾值

## 结论
- 抵抗伤害类似物理护甲，可抵消实弹伤害
- 单发实弹伤害先减护甲值再结算实际伤害
- 后期反大武器单发伤害普遍300以上，战巡护甲也难完全抵挡
- 高额抵抗伤害最多可获得150%额外治疗量，保障前排后期生存
- 护盾值类似魔法抗性，按百分比削减能量伤害
- 能量伤害对护盾值一视同仁，常规舰船护盾值最高只能点到30%
- 能量伤害面对大部分舰船都能打出70%以上伤害
- 面对能量伤害最好用高闪避舰船规避命中来增加生存

## 数值与数据
- 示例：单发伤害40、护甲20，实际受到实弹伤害20
- 示例：单发伤害100、护盾值10%，实际受到能量伤害90
- 抵抗伤害最高额外治疗量150%
- 常规舰船护盾值上限30%
