# B资料1-3 · 天璇A降命中辅助解析

> 场景：对手：克劳高达队；体系：盘古阵营

## 结论
- 天璇A-轻型攻击机（原文为“天玄”，疑似语音识别错误）是盘古阵营唯一飞机。
- 天璇A-轻型攻击机伤害不突出甚至很低，推荐携带不是为输出。
- 核心机制是降低敌方副队舰船命中率，使敌方副队伤害大幅降低。
- 常规队主队打伤害、副队扛伤；克劳高达队主队和副队都打伤害。
- 面对克劳高达队时，降低敌方副队输出在实战中很有用。
- 天璇A-轻型攻击机门槛不低，放输出队会挤占其他飞机位置，所以使用不多。
- 有条件的玩家可以使用。

## 配队与模块
- 天璇A-轻型攻击机（原文为“天选”，疑似语音识别错误）放副队，不放输出队。
- 副队用天璇A-轻型攻击机吸引敌方火力，并持续降低敌方舰船命中率。
- 天璇A-轻型攻击机搭配盘古阵营其他舰船叠熔迭战效果，让敌方舰船持续掉血。
