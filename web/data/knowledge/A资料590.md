# A资料590

## 场景 / 对手
针对顶克玩家，雷火之心战巡舰的模块选择与实战应用，涉及直射/曲射武器、防空、对舰输出，环境为常规PVP及猎户行动轰炸区

## 舰队例子
- 雷火之心 + M3模块（直射主武器）+ C1模块（激发震荡辅助）（胜）【半改雷火，依靠M系统输出，C1提供激发，打特定阵容与满改区别不大】
- 雷火之心 + M3 + C2模块（防空协调）（胜）【体验服加强后，C2提供防空命中，配合全防空模块（A1/B2/D1）成为防空船，在轰炸区游走】
- 雷火之心 + M1模块（快速锁敌）（负）【针对小船前排（开阳、耀光）锁敌快，但通用性差，不推荐】
- 雷火之心 + M2模块（曲射武器）（负）【输出不足，不如风暴，怕拦截，不推荐】

## 实战结果
宋老板猎户行动，主队+副队+护航，雷火未完全改防空模块，但轰炸压力小；雷火输出战报3万、3万、5万，差距大，5万、5万、5万接近，3万、6万、3万差距大，差距大时吃到快速装弹策略

## 结论思路
- 雷火武器输出模块多，但主武器输出占比80%，选择M模块是关键
- M2曲射不如风暴，M1针对小船但通用性差，最终选M3直射
- 雷火是针对性卡牌，针对克劳（大船）使用，不是通用对局
- C1模块是核心辅助，半改雷火（M3+C1）即可玩，与满改区别不大
- C2模块加强后，可提供防空命中，配合全防空模块成为防空船，在轰炸区有效
- 主武器策略（快速装弹）触发时输出翻倍，需拉满命中（+25%）降低空枪惩罚
- A模块推荐A1（重炮），单发高，对舰更优；B2无对舰火力，不抢激发震荡
- D模块选D1（反大）或D2（反小），根据启动速度或输出需求
- 体验服加强保守，防空加强显著，普通轰炸对雷火无效

## 适用限制
- 适用于顶克玩家或特定阵容（大船对轰），不适用于通用对局
- M3直射需队伍中前排为大船，避免转火问题
- C2防空雷火需全防空模块（A1/B2/D1），适合轰炸区环境
- 需高命中加点（+25%），否则空枪惩罚严重
- M2曲射不推荐，怕拦截且输出不足
- M1仅针对小船前排，通用性差
