# A资料45

## 场景 / 对手
当前版本作战环境，以能量直射（混沌、艾奥）为主输出，带少量投射和舰载机（围蔽、心脉）补刀；也有蓝十字猎兵、狩猎、超转、重卡风暴、大地等投射输出为主的护航玩法。

## 舰队例子
- 大盾（中排站位，重甲模块，780护甲，30%能量抗性，B2附加装甲，A嘲讽模块，AE站位调整，A2吸收舰载机火力，A3吸收投射火力，C反击模块，旗舰技能减少三支舰队30%伤害）（胜）【排名第一，能扛能打，培养难度低，白板旗舰点满即可生效，核心模块B2抽到即毕业。】
- 大毛（中奖模块，540护甲，25%能量抗性，135%维修量加成，主武器策略可跑中排，C2模块，旗舰技能突入作战增加撤退时间90秒，拦截模块全域拦截）（胜）【排名第二，能扛能打，但生存能力较差，主武器被绝育后回前排易被集火，旗舰技能双刃剑，培养难度低，C2毕业。】
- 五九（C1附加装甲，C2电磁装甲70%能量抗性，330固甲，82.5%维修量加成，C3重甲模块730护甲，150%维修量，30%能量抗性，可调整站位）（胜）【排名第三，造价便宜，纯扛伤定位，输出差，推荐电磁装甲（C2）适应性强，C3重甲也可用，但怕断奶。】

## 实战结果
大盾、大毛、五九三个扛伤战巡对比，大盾第一（抗伤、减伤、嘲讽、反击全面），大毛第二（旗舰技能功能性，但生存差），五九第三（造价低，纯扛伤）。关键得失：大盾无缺点，大毛怕绝育和集火，五九输出差且依赖奶量。

## 结论思路
- 大盾排名第一，因高护甲、能量抗性、旗舰减伤、嘲讽和反击，培养难度低，无明显缺点。
- 大毛排名第二，因旗舰技能突入作战能限制撤退，但生存能力差，需谨慎使用。
- 五九排名第三，因造价便宜、成型快，但输出差，推荐电磁装甲应对断奶和轰炸。
- 扛伤战巡适合低质量玩家，培养难度低，能扛伤为队友创造输出机会。
- 高质量玩家可优先大盾，200点以上蓝点可当旗舰。
- 拦截模块非核心，因需大量大船资源，光防更经济；大毛拦截模块可全域拦截，有特殊玩法。

## 适用限制
- 大盾适合中排站位，需前排小船限制直射伤害，奶量集中时效果最佳。
- 大毛主武器被绝育后回前排易被秒杀，不适合持久战，旗舰技能需操作意识。
- 五九C1不适合当前环境，C2适合能量输出环境，C3怕断奶，别拿五九打输出。
- 拦截模块需大量资源，非悠闲对局不建议配置。
