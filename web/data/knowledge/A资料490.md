# A资料490 · 毛与矛盾组合配队要点

> 场景：正面打架/副队矛盾组合

## 结论
- 乌拉诺斯之矛（原文为"毛"，疑似简称）M1模块优于M2
- 乌拉诺斯之矛A2正常带B系统模块
- 有B2或艇矛时尽量带艇矛
- 乌拉诺斯之矛必须放中排
- C系统有附加就带附加，没有附加C3拦截效果也不错
- 更推荐乌拉诺斯之矛带C2
- 乌拉诺斯之矛加点优先加护甲，护甲越高66奶量越高
- 乌拉诺斯之矛改站位可调整为中排，节点里也可用节点道具改站位
- 矛盾组合中普鲁图斯之盾级（原文为"盾"，疑似简称）没有B2可带B3，B3反导系统拦截效果不错
- 矛或盾都上反拦截后，光锥级（原文为"光锥"，疑似简称）可以少上一些
- 副队玩矛盾组合时旗舰必须要点
- 打架时所有战群一定要放中排或前排
- 前排最少要放10个特卡吸收伤害
- 矛盾组合一定要放在中排
- 矛盾组合上少量光锥级即可
- 矛盾组合非常好用，也是现在比较通用的配置
- 安东塔斯持剑者级（原文为"大剑"，疑似简称）只推荐放在主队，M1或M3模块都很好用

## 配队与模块
- 乌拉诺斯之矛：M1模块、A2、B2或艇矛、C2优先，无附加时可用C3
- 普鲁图斯之盾级：B2优先，无B2可用B3
- 矛盾组合：前期2盾3矛，后期3盾5矛，8战巡分伤
- 护航艇：优先上双型号，先上子型号，其次基础型号，两者都是高效挡刀
- 没有海尔波普（原文为"海尔"，疑似简称）可上坦普尔1号（原文为"丹普儿"，疑似语音识别错误）
- 图便宜可上CV-M011型-C-高速导弹艇（原文为"011"，疑似简称），便宜且比较肉
- 也可上虚灵-隐身导弹艇（原文为"虚灵"，疑似简称）
- 光锥级少量上即可

## 数值与数据
- 前排最少放10个特卡
- 前期2盾3矛，后期3盾5矛
- 8战巡分伤
