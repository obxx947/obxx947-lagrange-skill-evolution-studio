# A资料385 · 超战队舰船与载机选择

> 场景：超主力舰对战

## 结论
- 南十字星元帅级-武装航空母舰（原文为"南十字航母"，疑似简称）主机库超战策略可强制战机集火超主力舰并加成可观
- 无南十字星元帅级-武装航空母舰或航母蓝点不足时可用猎兵级-重型载机巡洋舰（原文为"猎兵"，疑似简称）、狩猎者级-载机巡洋舰（原文为"狩猎"，疑似简称）代替
- 战巡最推荐永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称），投射输出不可拦截且有效
- 无永恒风暴级-攻击战列巡洋舰时新君士坦丁大帝级-综合战列巡洋舰（原文为"大帝"，疑似简称）可上场，但易被拦截克制
- 卡利斯托-重型鱼雷袭击舰（原文为"重卡"，疑似简称）对战巡有额外增伤，无永恒风暴级-攻击战列巡洋舰时推荐，但易被拦截克制
- 护卫舰只推荐刺水母级-战术护卫舰（原文为"水母"，疑似简称）和锆石级-特种护卫舰（原文为"锆石特种"，疑似简称），两者可相互替换
