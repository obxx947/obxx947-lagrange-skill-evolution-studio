# A资料521 · 区域防空机制与舰船介绍

## 结论
- 区域防空能帮助更多我方单位进行防空打击
- 防空支援字条与不受击中的反击防空效果相同，不会因自身受击改变攻击目标
- 防空支援类武器比反击防空武器能更持久保护其他有护卫舰
- 大部分舰船防空无人机采用防空支援攻击方式，是补充舰船防空的首选
- 卫士-支援驱逐舰（原文为"卫士支援"，疑似简称）的无人机仍是反击防空机制，防空伤害几乎全由剑仔导弹打出
- 周期性大范围防空技能可锁定临近排对方战机或护航艇，通常附加命中率提高或冷却降低
- 周期性防空技能可通过调校获得更长持续时间，对战机和护航艇针对性更强
- 周期性防空技能命中率通常偏低，使用时应优先加点命中

## 配队与模块
- 枪骑兵级-区域防空驱逐舰（原文为"枪击兵"，疑似语音识别错误）可将自身武器防空范围扩展到我方阵型内所有舰船
- 光锥级-区域防空巡洋舰（原文为"防空圆锥综合"，疑似语音识别错误）可通过加点让同排船只防空武器扩大到临近排
