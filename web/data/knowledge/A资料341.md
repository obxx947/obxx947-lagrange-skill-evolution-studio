# A资料341

## 场景 / 对手
主星系全等级通用控制队，以飞机为伤害来源，用于控制点及三级城

## 舰队例子
- 飞机：15个800、10个蜂巢、5个星脉；舰船：10个BB、10个小米、8个以上066奶、10个拖鞋、5个诺玛；CB玩家带050A补充伤害，鱼玩家用前途盾（白板）挡刀；旗舰手册点满，连引10个血量和闪避点满（胜）【单刷S三级城及以下控制点100%无损】

## 实战结果
单队最高无损控制三级城，高级目标用相同配置拖队暴力控制

## 结论思路
- 以飞机为主要伤害来源，配置6+5的11级配件
- CB和鱼玩家在CG和舰船选择上有所不同，CB带050A补充伤害，鱼用前途盾挡刀
- 旗舰手册需点满，066奶数量至少8个，连引血量和闪避点满
- 工具船用拖鞋和诺玛，同一套配件可通用单刷S三级城及以下控制点

## 适用限制
- 适用于主星系控制点及三级城
- 需要高等级配件和旗舰手册
- 高级目标需拖队暴力控制，单队可能不足
