# A资料636 · 天枢内战直射对投射战报

> 场景：天枢级-支援航空母舰（原文为"天枢"，疑似简称）内战；死战7分钟；双方支援5天枢；右边小胜

## 结论
- 天枢内战中双方血量与维修量接近，主队受420人口限制，输出选择少，最终卷副队伤害。
- 左边走能扛能打：靠更高副队伤害更快打穿对面；右边走纯抗与投射分摊，思路较恶心。
- 右边小胜，双方基本全灭，右边天枢残存1个。
- 舰船数据接近时战况应平分秋色，难说谁更优秀。
- 左边能扛能打的总伤害优势很小，思路略有问题。
- 安东塔斯持剑者级-指挥舰（原文为"大剑"，疑似简称）在主队能扛能打，但在副队仅能扛；其输出多来自舰队中的维塔斯-B010-轰炸机（原文为"VB"，疑似简称）、星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）等，缺这些则输出下降。
- 建议左边把安东塔斯持剑者级-指挥舰换成乌拉诺斯之矛（原文为"大矛"，疑似简称）之类提升伤害；永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）可保留，当前能扛能打。
- 右边副队伤害少，主要靠5乌拉诺斯之矛。
- 总维修量右边更高；左边天枢维修分配均衡，因战巡吃奶量高且无中甲；右边维修集中天枢，战巡仅乌拉诺斯之矛与普鲁图斯之盾级-防护战列巡洋舰（原文为"大盾"，疑似简称）共6个且在中排吃不到奶，天枢附加低收益低；右边多玉衡级-支援巡洋舰（原文为"御寒"，疑似语音识别错误）维修。
- 天枢内战直射或投射都行，关键是单位人口伤害与数值够高；区别在战损方式：投射打战损更快，直射更慢。
- 死战无法避开对面直射，打灭对面无非先后顺序：投射先打超主力再打小船，直射先打小船再打超主力，最终考验数值。
- 混沌和风暴一起上打数值可行；新迈尽量放XT-11级-导弹驱逐舰（原文为"十一鱼"，疑似简称），别放猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误），猎兵的新迈伤害很低；谁数值高谁赢。
- 带米斯特拉-战斗攻击机（原文为"小米"，疑似简称）建议带信息链，否则别带或让它去绝育；带信息链可解放CV-T800型-脉冲炮艇（原文为"八百"，疑似简称）的伤害。
- 海氏追随者型-脉冲攻击机（原文为"海誓"，疑似语音识别错误）在天枢内战不建议超展，拿去对空可减少对面海尔波普-维修支援护航艇（原文为"海尔波普"，疑似简称）的奶量；海尔波普威胁大。
- 直射穿前排效率低，直射与反小火力拉满也花约3分半才打穿对面前排。
- 瑶光buff持续期间康纳马拉混沌级-轨道炮巡洋舰打109万，作为输出合格，但贯穿前排浪费时间。
- 左边直射思路：打穿对面前排后，再对中排造成伤害。
- 双方天枢模块都不齐。
