# A资料553

## 场景 / 对手
SP船评测，针对SP摇（可能为“瑶”或“摇”）的强度分析，涉及反小直射、轰炸、挡刀、护航等场景

## 舰队例子
- SP摇（基础面板1800，加点后2000，巅峰20可达4500-5000，反小直射武器，不可拦截，造价6380，修复时间最快，血量12000，8护甲，基础闪避高，强化5点一次）（胜（评价：综合能力强，适合多种场景））【作为反小输出、轰炸机、挡刀机，性价比高，适合低赛玩家和solo玩家】

## 实战结果
无具体实战记录，主要基于面板和机制分析，结论为SP摇值得获取，尤其对solo和护航第三阶段玩家

## 结论思路
- SP摇面板优秀，基础1800加点后2000，巅峰可达4500-5000，反小直射不可拦截，输出靠谱
- 造价低廉（6380），生产速度快，加满点10分钟内，适合消耗
- 修复时间全游戏最快，比例上零血也10分钟修复，适合轰炸
- 血量12000，8护甲，高闪避（基础闪避必定触发），比虚拟上位替代
- 强化便宜（5点一次），主武器5点，适合多数玩家调整
- 动力系统无伪装战机选项，但换来更好设备，在坦克和tamper存在下无需伪装
- 适用场景：低赛玩家（综合能力）、solo玩家（高速自动和高闪避）、护航第三阶段（空军防御）、红buff（吃载具加成）
- 价格合理（模块3200），建议趁早获取

## 适用限制
- 护航玩家可能作用有限，因为输出反小而非反大
- 依赖载具加成，需放在高加成载具上发挥
- 不适合需要反大的场景
- 对于非solo或非护航第三阶段玩家，可能优先级较低
