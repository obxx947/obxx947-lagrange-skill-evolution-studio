# A资料676

## 场景 / 对手
缺C1鱼、三千航母8级、南石10级，航母拼多多配置，打架环境

## 舰队例子
- 主队：3个六鱼+2个八鱼（增援位），三千航母（挺位18个，索木河9+青云脉冲9，机位25个，围臂+零五零+小米+凌霄补位），光防（信息链），狩猎（2个，放海市），泡泡龙，枪骑兵（6人口）（胜）【输出靠三千拉满，飞机配置优先围臂、零五零，小米和VA拉满】
- 副队：盾配矛（两盾三毛），大件（B3、C2电磁），官房，开洋（10个）+摇光（基础型号满），御衡（提供盘古巡洋buff）（胜）【毛需经验书调中排，副队以盾为主，六奶最多6个】

## 实战结果
无具体战报，配置分析：主队靠三千补位，副队盾矛组合，关键得失是航母拼多多导致输出依赖三千，泡泡龙需清理开洋才能启动

## 结论思路
- 鱼配置：B1不动，上3个六鱼+2个八鱼，其余用三千补位
- 三千挺位优先索木河和青云脉冲，机位优先围臂、零五零，小米和VA拉满
- 海市单宅放狩猎，泡泡龙点策略调教满
- 副队以盾为主，毛需经验书调中排，大件提供电磁
- 六奶不要上太多，最多6个，合理利用点子
- 海尔波普当前版本不适用，可洗点留用

## 适用限制
- 适用于点子不多、缺C1鱼、航母等级低的账号
- 打架时建议直接上5个盾，毛盾组合需经验书
- 泡泡龙需先清理敌方开洋才能启动
- 海尔波普仅适用于旧版本，当前地推版本以盘古为主
