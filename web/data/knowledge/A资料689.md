# A资料689

## 场景 / 对手
护航版本，空战与对舰体系，正面战斗，环境为护航队与solo对比

## 舰队例子
- 海狮追随者（动力系统索敌必点，武器系统按对舰加点，策略起手，载具绑定狩猎出超斩或五九）（胜）【对空或对舰均可，优先攻击护航艇，打完再对舰，适合针对奶猫队】
- 海狮追随者（极致对舰，超斩，攻击时间15秒*0.75）（胜）【火力分散或奶歪，提升输出效率】
- 海狮追随者（对空，不点策略，面板+命中）（胜）【solo中赢下空战，配合vb磨死对面，但怕聚焦空战】

## 实战结果
海狮追随者打奶猫队，几胜几负未明确；关键得失：对空可秒巡洋奶歪，对舰输出高，但被聚焦空战克制，生存依赖不被粘到

## 结论思路
- 海狮追随者是当前版本一哥二哥，除vb外最强，输出能力可弥补护航队坦度
- 必须剪掉索敌（动力系统必点），且绑定在有索敌的模块上，载具选狩猎出超斩或五九
- 三种用法：对空打巡洋、极致对舰、solo对空，均需操作
- 对空优先打护航艇，解放011去遇轰炸机，契合护航艇反哺流
- 玩海狮追随者要形成体系，量大带满（如配沙龙），避免被秒
- 加点：动力系统点目标选择时间下降，武器系统按对舰或对空调整，对空不点策略改面板+命中

## 适用限制
- 适用于护航版本，solo不带航母时效果受限
- 怕聚焦空战，对面点此技能则生存堪忧
- 对空时只打护航艇不打战机，需注意敌方战机配置
- 造价贵，生产慢，上场时间短，需谨慎使用
- 不推荐单独使用，需配合体系（如沙龙、拦截机）
