# A资料522 · 舰载机空战机制与加点

## 结论
- 舰载机分战斗机和护航艇两类，攻击模式分网络打击和独立作战两种
- 独立作战舰载机除开局在载机舰内首次锁敌外，其余时间可视为对方阵型内的护卫舰
- 独立作战武器遵循锁敌、攻击、冷却循环，直到被击毁
- 舰载机锁敌无视阵型阻挡，直接从攻击序列中选择目标
- 往复打击舰载机完成一次完整打击后返回载机舰补充弹药，再进行下一轮打击
- 舰队接敌后舰载机在载机舱内按武器锁敌速度初次锁敌，出舱飞向对方阵营后发起攻击
- 攻击结束后按返程时间返回载机舰，在机库内等待武器冷却并锁定新目标
- 舰载机在机库内不会被防空武器锁定，冷却和锁定目标同时进行
- 出舱后未完成攻击前丢失目标，会在对方阵营内重新锁敌，不返回载机舰
- 降低去程返程时间可增加往复打击频率
- 锁定目标时间需小于或等于武器冷却时间，否则会拖慢再次出击
- 打击间隔缩短相当于降低攻击持续时间，增加输出频率
- 聚焦空战让舰载机优先攻击对方战斗机和拦截机，可降低对方空军防空能力
- 聚焦空战缺点是不能第一时间攻击对方轰炸机，面对维塔斯-B010-轰炸机（原文为"vb"，疑似简称）时可能出现较大舰船损失
