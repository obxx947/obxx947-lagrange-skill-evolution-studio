# A资料522

## 场景 / 对手
舰载机空战机制，包括独立作战和往复打击，以及加点项作用

## 结论思路
- 独立作战的舰载机类似护卫舰，锁敌无视阵型阻挡，遵循攻击循环直至被击毁
- 往复打击的舰载机完成一次打击后返回机库补充弹药，再出库进行下一轮
- 舰载机在机库时不会被防空锁定，冷却和锁定目标同时进行
- 降低去程返程时间可增加往复打击频率
- 选择目标时间应小于等于武器冷却时间，以优化出击效率
- 打击间隔缩短可降低攻击持续时间，增加输出频率
- 聚焦空战优先攻击战斗机和拦截机，降低对方防空能力，但可能延误对轰炸机的打击

## 适用限制
- 往复打击机制适用于有载机舰的舰队
- 聚焦空战在面对VB轰炸机时可能导致舰船损失，需权衡使用
