# A资料658 · 护航协助防空抗伤队

> 场景：副队协助主队防空；应对轰炸

## 结论
- 护航协助防空仅针对直射防空武器。
- 当前较强防空型为斗牛级与亚达伯拉级-重型防空驱逐舰（原文为“鸭脖的防空型”，疑似简称），但亚达伯拉级防空子型号难找。
- 本方案采用双斗牛，获取门槛低。
- 斗牛级三型号中，仅斗牛级-脉冲炮驱逐舰与斗牛级-防御驱逐舰所有武器可防空。
- 斗牛级-突击攻击舰（原文为"突击型"，疑似简称）主武器不能防空，防空伤害偏低。
- 本配置中斗牛级-脉冲炮驱逐舰优于斗牛级-防御驱逐舰。
- 斗牛级-脉冲炮驱逐舰与斗牛级-防御驱逐舰抗伤不错，输出尚可。
- 斗牛级-防御驱逐舰是碰瓷队核心主力。
- 瑶光级-通用护卫舰提供能量抗性，可限制对方直射能量伤害，包括面对星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）。
- 谷神星级-支援驱逐舰用于前期续航并填剩余人口。
- 普鲁图斯之盾级-防护战列巡洋舰作旗舰扛伤，但必须带重甲，否则扛不住轰炸。
- 无重甲普鲁图斯之盾级-防护战列巡洋舰时可用ST59级-防御战列巡洋舰替代，并调整舰队人口。
- 开阳支援可加强抗线；不支援也可，按自己思路判断。
- 整套配置为护航防空抗伤队。

## 配队与模块
- 斗牛级-脉冲炮驱逐舰（原文为“基础型”，疑似简称）与斗牛级-防御驱逐舰（原文为“防护型”，疑似简称）组成双斗牛。
- 瑶光级-通用护卫舰（原文为“瑶光”，疑似简称）提供能量抗性。
- 谷神星级-支援驱逐舰（原文为“谷神”，疑似简称）用于前期续航并填剩余人口。
- 普鲁图斯之盾级-防护战列巡洋舰（原文为“大盾”，疑似简称）当旗舰扛伤，必须带重甲。
- 无重甲大盾时换ST59级-防御战列巡洋舰（原文为“59”，疑似简称），并调整舰队人口。
- 开阳级-机动驱逐舰/开阳级-鱼雷驱逐舰（原文为“开阳”，疑似简称，未指明型号）支援，加强抗线。
- 模块：普鲁图斯之盾级-防护战列巡洋舰需重甲（原文“重甲”，未列具体模块）。
