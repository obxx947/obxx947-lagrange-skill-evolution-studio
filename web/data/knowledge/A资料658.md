# A资料658

## 场景 / 对手
护航协助防空队，应对轰炸，正面抗伤

## 舰队例子
- 斗牛基础型+斗牛防护型（双斗牛）（胜）【基础型所有武器可防空，防护型为碰瓷核心，抗伤和输出均不错】
- 瑶光×6（胜）【提供能量抗性，限制星脉直射能量伤害】
- 谷神（数量未指定）（胜）【前期续航，补充剩余人口】
- 大盾（旗舰，需重甲模块）（胜）【扛伤核心，无重甲则换59并调整人口】
- 开阳×5（支援）（胜）【加强抗线能力，可选支援】

## 实战结果
未提供具体实战记录，但配置用于护航协助防空，应对轰炸，整体抗伤和防空能力较强

## 结论思路
- 护航协助防空只针对直射防空武器，目前强力的只有斗牛和鸭脖防空型，但鸭脖难找，故用双斗牛
- 斗牛基础型优于突击型，因为突击型主武器不能防空，防空伤害低
- 瑶光提供能量抗性，针对星脉轰炸限制直射能量伤害
- 大盾必须有重甲才能扛轰炸，否则换59并调整人口
- 开阳支援可加强抗线，但非必需

## 适用限制
- 适用于应对轰炸和直射能量伤害的场景
- 需要斗牛基础型和防护型，鸭脖防空型难获取
- 大盾必须带重甲，否则扛不住轰炸
- 舰队人口需根据旗舰选择调整
