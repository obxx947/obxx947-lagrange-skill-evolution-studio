# 巡洋舰站位（站位）

站位=该舰在舰队里的排位，取值：前排 / 中排 / 后排。
本表为用户核对后的最终版，与程序内 data/ship_database.json 的 position 字段完全一致；
配队、战斗模拟、任何站位判断一律以本表为准。
同族不同型号的站位可能不同（例如 奇美拉级-火炮巡洋舰=前排，奇美拉级-防御巡洋舰=中排），请按完整舰名查。
战机与护航艇不单独排位：随母舰出击（数据里记作 aircraft）。
