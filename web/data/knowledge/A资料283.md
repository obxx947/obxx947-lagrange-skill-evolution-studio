# A资料283

## 场景 / 对手
前期舰队配置，对比开阳级B型鱼雷驱逐舰与细重炮（C重炮）的优劣

## 舰队例子
- 开阳级B型鱼雷驱逐舰（鱼雷模块）（胜）【输出高于水母，存活率高，血量厚不易暴毙】
- 细重炮（C重炮）（负）【闪避低、血量薄，定位前排但抗伤能力差，不如特卡或开阳A】

## 实战结果
对比开阳B与细重炮，开阳B在前期输出和存活率上更优，细重炮因脆皮和定位问题被替代

## 结论思路
- 开阳B是细重炮的上位替代，前期性价比更高
- 前期应保证不掉虫，开阳B血量厚给奶船恢复时间
- 重炮闪避低血量薄，不如用特卡或开阳A前排
- 开阳B输出高于水母，存活率高，适合前期缺矿时使用

## 适用限制
- 适用于前期资源紧缺阶段
- 不适用于需要高闪避或特定前排定位的场景
- 若已有特卡或开阳A，可优先考虑其他输出舰船
