# A资料624

## 场景 / 对手
前期控制六级矿点，混合火力/纯防空/对舰，通用无损配置

## 舰队例子
- 卡特（前排，等效奶最高）+ 古神星载机（6个，搭载1组小米和2个A021）+ 诺马斯奶 + 瑶光（60能量盾）+ 女海脉冲 + 雷利亚特（胜）【混合火力控下无损满状态；古神星载机带小米优于海事，补地面输出和防空；A021牵制800伤害】
- 纯防空：卡特 + 古神星载机（小米处理基线）+ 水母防空（处理野火和800）+ A021（拖住800）（胜）【控防空会掉血，因清理飞机速度慢，血未回满】
- 对舰：类似混合火力配置（胜）【掉血少，仅一丝，可继续控一轮】

## 实战结果
混合火力控六级无损满状态；防空控后掉血；对舰控后掉血少。关键得失：古神星载机带A021牵制800，小米补输出；防空处理慢导致状态未满

## 结论思路
- 卡特等效奶最高，保证奶量跟上输出
- 古神星载机带小米比海事更优，补地面输出和防空
- 瑶光套盾反制离子炮和800输出
- 水母防空处理野火和800，小米处理050，A021拖住800
- 控制顺序：先控混合（无损满状态），再控防空（需满状态古神星），最后控对舰（半血不影响）
- 古神星武器要点满，不点防空协助策略，保持地面输出
- 小米不点优先打击主武器系统，避免结构伤害降低
- 诺马工程型不加点，A021加血量和闪避防止死亡
- 通用配置省军事港口，控完可拆古神星载机，返还资源不亏

## 适用限制
- 船必须与初始配置一致，私自更改不保证无损
- 古神星载机需满状态控防空，半血会炸
- A021必须加点血量和闪避，否则会死
- 适用于前期落地一天到5级，破盾两天内控制
- 不点防空协助和优先打击主武器系统策略
