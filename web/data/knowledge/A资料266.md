# A资料266

## 场景 / 对手
逆境盾玩法设置，针对大盾中排旗舰存活率问题，规避能量直射伤害

## 舰队例子
- 大盾（A系统至少两个模块，A1方案）（胜）【前凸吸收直射伤害】
- 大盾（A系统至少两个模块，A2方案）（胜）【中排旗舰盾用方案二】

## 结论思路
- 大盾多数处于中排，目的是提高旗舰大盾存活率，规避能量直射高额伤害
- 逆境盾玩法：当前排失去所有舰船时，中排仅保留旗舰大盾，剩余大盾前凸吸收直射伤害
- 要求大盾A系统至少有两个模块，否则无法玩逆境盾
- 设置两个不同A系统的生产方案，A1为方案一，A2为方案二，中排旗舰盾用方案二

## 适用限制
- 大盾A系统必须至少有两个模块
- 适用于需要规避能量直射伤害的场景
