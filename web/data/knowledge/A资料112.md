# A资料112

## 场景 / 对手
萌新护航队配置，未央势力舰船，六队配置

## 舰队例子
- 富贵（三种型号）全部造满，六队共45艘（胜）【基础护航队，输出和肉盾兼备】
- 零六六（领域横）全部上输出队，十一条KCC全部上满（胜）【巡洋策略，增强输出能力】
- 七二一六队，共46艘船（胜）【能抗能打，顶级配置】
- 输出队38艘船（胜）【反大反小，输出强化】

## 实战结果
萌新配置护航队，未央势力六队，富贵45艘、零六六+KCC、七二一六46艘、输出队38艘，整体胜率较高，关键在输出和肉盾平衡

## 结论思路
- 护航队核心是一个输出一个肉
- 萌新优先使用未央势力舰船，富贵三种型号造满
- 有领域横时，零六六全部上输出队，KCC上满
- 七二一六队作为顶级配置，能抗能打
- 输出队38艘船，反大反小

## 适用限制
- 适用于萌新阶段，未央势力舰船较多时
- 需要领域横模块支持零六六输出策略
- 不适用于高级玩家或非未央势力配置
