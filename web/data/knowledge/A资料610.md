# A资料610

## 场景 / 对手
反大测试，对手为电磁59大船，正面攻击，环境为测试环境

## 舰队例子
- 雷火M2模块+C1模块，搭配电磁59扛伤（胜）【M2对舰伤害约21万，投射武器可越过前排】
- 雷火M3模块+C1模块，搭配电磁59扛伤（胜）【M3对舰伤害约27万，直射武器优先打前排】
- 10艘VB，2分15秒（胜）【对舰伤害接近16万，用于对比】

## 实战结果
测试M2和M3模块对电磁59，M2伤害21万，M3伤害27万，M3对舰能力更高；但M2可越过前排，M3受前排限制

## 结论思路
- 反大时需合理选择模块搭配，M2为投射反大，M3为直射反大
- M2对舰伤害低于M3，但可越过前排打后排，且会被光防拦截
- M3对舰伤害高于M2，但优先打前排，不会被光防拦截
- 测试中只打大船，未发挥模块全部潜力，实战中伤害可能更高
- M2随累积伤害提升武器伤害，M3通过消灭目标降低冷却时间

## 适用限制
- 适用于反大场景，对手为闪避不高的大船
- M2适合对付有前排小船的敌方阵容，但需注意光防拦截
- M3适合对付无前排或前排较弱的敌方阵容，避免被小船阻挡
- 测试环境未包含其他舰船，实战中需结合其他武器模块触发M3效果
