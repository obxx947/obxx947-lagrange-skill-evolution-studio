# A资料275

## 场景 / 对手
SP实战视频，二阶段控对舰五六八八和四九五的对舰五，正面作战，环境为不吃奖励的守军清理

## 舰队例子
- 盾（白板，带拦截模块）+ 零六六 + 古神奶 + 鱼（未带赤瑶）（胜）【打四九五对舰五，盾血量健康，小船掉血较多，未带赤瑶导致小船损失】
- 盾（白板，带拦截模块）+ 零六六 + 古神奶 + 鱼 + 赤瑶（胜）【带赤瑶后基本不掉船，仅损失一个古神奶，治疗效果显著】
- 盾（白板，带拦截模块）+ 零六六 + 古神奶 + 鱼 + 星脉坦克蜂巢（或800）（胜）【打六八八对舰五，六八八反小多，古神奶易炸，建议带星脉坦克蜂巢提高稳定性】

## 实战结果
鲤鱼王打四九五和六八八对舰五，多场胜利，关键得失：不带赤瑶时小船掉血多，带赤瑶后损失极小；零六六有时不奶盾导致盾炸，需炮灰顶上；六八八反小多，古神奶易炸，需后打

## 结论思路
- 二阶段可以无伤控四九五和六八八的对舰五，四九五掉船少可连续控
- 不吃奖励时造停机坪，友军清差不多就撤退，避免浪费策略
- 炮灰等控到快百分之五十再点上去，减少掉血
- 打四九五对舰五，全直射，盾基本不掉血，但小船需带赤瑶治疗
- 零六六有时不奶盾，需准备炮灰顶替，盾炸后撤退
- 六八八反小多，古神奶易炸，建议后打，带星脉坦克蜂巢提高稳定性
- 盾白板即可，带拦截模块，多造几条盾和炮灰，炸了撤退让炮灰顶上
- 打完两队守军直接撤退，让吃奖励的继续控制

## 适用限制
- 适用于二阶段控对舰五，四九五和六八八
- 需准备炮灰应对零六六不奶盾的情况
- 打六八八需注意反小，古神奶易炸，建议带星脉坦克蜂巢
- 重卡城需等到三阶段结束再打
- 不吃奖励时适用，吃奖励的需另行处理
