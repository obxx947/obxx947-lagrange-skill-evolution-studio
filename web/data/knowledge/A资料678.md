# A资料678 · 红矿无拦截账号配队梳理

> 场景：红矿环境；对手常见小盘古/双瑶光；账号无拦截体系

## 结论
- CV3000级-快速航空母舰（原文为“3000”，疑似简称）仅50来点，模块比上个号略好
- 飞机点不够时，建议把CV3000级-快速航空母舰放副队当副航母，主队仍用11+13
- 11+13基本用完全部有加点的飞机，有CV3000也难再开新机位
- 普鲁图斯之盾级-防护战列巡洋舰（原文为“盾”，疑似简称）放中排；ST59级-防御战列巡洋舰（原文为“59”，疑似简称）模块不齐
- 永恒风暴级-攻击战列巡洋舰（原文为“风暴”，疑似简称）模块可用，可以上；八战巡未成型前放中排
- C3永恒风暴级增强后造价仍高，人口等只是功能性增强；大后期可放主队做输出，因有M2
- 后期不上CV3000级-快速航空母舰时，用S-列维9号-重型鱼雷艇（原文为“列兵”，疑似语音识别错误）补CV-T800型-脉冲炮艇（原文为“800”，疑似简称）艇位拉输出
- 没有光锥级-综合导弹巡洋舰（原文为“光锥”，疑似简称）就喂经验书，上光锥级-攻击导弹巡洋舰（原文为“突击锥”，疑似简称）即可
- 康纳马拉混沌级-高速等离子体巡洋舰（原文为“泡泡龙”，疑似简称）给65~70点够用，剩余吃经验书
- 艾奥级-高速离子炮巡洋舰（原文为“高速I”，疑似简称）正常用，主队旗舰给高速艾奥；其他艾奥可洗点
- 人人有小盘古组合（玉衡+开阳+瑶光，双瑶光）时，艾奥和泡泡龙难打伤害
- 需先清掉敌方开阳，泡泡龙才能反大船启动，因为攻击按前中后顺序
- 游骑兵级-重型离子炮巡洋舰（原文为“游骑兵离子炮”，疑似简称）没有就不上，点可洗给奇美拉/光锥级-区域防空巡洋舰（原文为“光防”，疑似简称）/突击锥
- 突击锥优点增命中、给飞机信息链；缺点投射，遇敌方实弹投射或三光防难受，不如奇美拉级-火炮巡洋舰（原文为“奇美拉重炮”，疑似简称）
- 没有拦截时CAS066级-支援巡洋舰（原文为“六六奶”，疑似简称）尽量少上，只上6个
- 无拦截时可造斗牛级-防御驱逐舰（原文为“防御牛”，疑似简称），但拦截量小效果低
- 红矿里卫士才能扩展到铜海；不买它，卫士防空攻击范围很小，只是区域防空
- 区域防空小于铜牌防空，没拦截账号要注意
- 海氏追随者型-脉冲攻击机（原文为“海式”，疑似语音识别错误）优先放狩猎者级-载机巡洋舰（原文为“狩猎”，疑似简称）
- 打架多优先造普鲁图斯之盾级-防护战列巡洋舰；有附加模块直接上附加，不要上反导
- 大盾反导拦截实际效果不好，附加大盾配永恒风暴级
- ST59级能用，但大盾有附加就不用ST59；ST59只作碰瓷队/防轰炸投射
- 主队可全拉永恒风暴级，分3个左右放副队；成型后五大盾三风暴，C28换C2，开阳前排加盾并配瑶光
- CV3000造出后主队下掉列兵，把CV-T800型-脉冲炮艇、蜂巢守卫者-重型鱼雷艇（原文为“蜂巢”，疑似简称）、CV-M011型-高速导弹艇（原文为“011的高速”，疑似简称）能丢就丢进CV3000
- 大后期造CV3000可白板丢雷火V022-轻型战斗机（原文为“雷火的基础型号”，疑似简称）、天璇A-轻型攻击机（原文为“天璇”，疑似简称）、平衡安德森SC020-侦察机（原文为“安德森”，疑似简称）
- ST59主副队均可，关键看C2/C3模块应用

## 配队与模块
- 主队：11+13；CV3000级-快速航空母舰放副队，主队列兵后期下掉
- 副队：开阳前排；瑶光级两个型号各5个互补，玉衡1个；副队200人口不能少
- 无拦截填线：CAS066级-支援巡洋舰6个，枪骑兵填线；点可洗给塔拉萨萤石级-信息驱逐舰（原文为“萤石”，疑似简称）做防空/奶量
- 防空/奶量：双皮奶苔原级-战术驱逐舰（原文为“台元”，疑似语音识别错误）或谷神星级-支援驱逐舰（原文为“股神”，疑似语音识别错误），优先苔原级赌防空
- 11鱼载机：优先米斯特拉-战斗攻击机（原文为“小米”，疑似简称）10个、维塔斯A021-重型攻击机（原文为“VA”，疑似简称）5个；维塔斯-B010-轰炸机（原文为“维b”，疑似简称）和BR050-标准轰炸机（原文为“050”，疑似简称）进两个13鱼；海氏追随者型进狩猎者级
- CV-T800型-脉冲炮艇：只上两锁；主武器系统锁敌不点，冷却/命中/策略伤害点满；动力系统点两个锁敌
- 主队大后期：附加大盾+永恒风暴；五大盾三风暴；开阳前排加盾+瑶光；C28换C2
- CV3000大后期：CV-T800型-脉冲炮艇、蜂巢守卫者-重型鱼雷艇、CV-M011型-高速导弹艇能丢就丢；雷火V022-轻型战斗机、天璇A-轻型攻击机、平衡安德森SC020-侦察机白板丢入
- 大盾模块：有附加直接上附加，不上反导
- 永恒风暴级：可上C3；大后期用M2；C28换C2
- 艾奥：主队旗舰给艾奥级-高速离子炮巡洋舰
- 光锥级：无则上光锥级-攻击导弹巡洋舰；点洗给奇美拉/光锥级-区域防空巡洋舰/突击锥
- 游骑兵级-重型离子炮巡洋舰没有就不上
- 泡泡龙：给65~70点，剩余经验书
- 九坦克九星脉；列兵造4个先塞主队，CV-T800待命
