# A资料3

## 场景 / 对手
对剑和奶量的测试，正面战斗，测试服环境

## 舰队例子
- 重卡（数量未提及）（胜）【输出65，受投射拦截影响，实际发挥有偏差】
- 康纳玛拉（数量未提及）（胜）【输出58，相对稳定，但怕前排巡洋分摊伤害，比正式服强一倍】
- 斗牛（12人口）（负）【输出不到8万，超模不再，但作为前排仍有作用】
- 战雷（3个，12人口）（胜）【输出高于斗牛，人口输出比优秀】
- 离子红宝石（3个，24人口）（负）【输出约8万，与斗牛同级】
- 赤水母（1个）（胜）【输出6点多，高于红宝石，低于战雷】
- 大地（数量未提及）（负）【输出巡洋居多、战巡居少，打混合舰队数量多时效果好，可造6个】
- 雷火（数量未提及）（胜）【输出战巡居多、巡洋少，对大船效果稳定，可造3个，价值大于大地】
- 大毛（数量未提及）（胜）【紫色舰船，只打前排】
- 五九（数量未提及）（负）【输出巡洋居多、战巡居少，与大地类似】
- 零六六（12个，18人口）（胜）【奶量约70-80，战损4个，换算5个奶量与古神相近】
- 古神（80人口）（胜）【奶量与零六六相差无几】
- 台仔（数量未提及）（负）【奶量50多，配合防空改动有崛起机会】

## 实战结果
测试服中测试对剑和奶量，重卡与康纳玛拉对比，康纳玛拉更优；斗牛、红宝石、赤水母、战雷对比，战雷最优，赤水母次之，斗牛与红宝石同级；战巡中雷火优于大地，但大地在混合舰队中数量多时输出更高；奶量上零六六与古神相近，台仔不足。

## 结论思路
- 康纳玛拉比正式服强一倍，但怕前排巡洋分摊伤害，需考虑对面前排是否巡洋
- 斗牛输出地位下降，但作为前排仍有作用，超模不再
- 战雷人口输出比最高，赤水母高于斗牛和红宝石
- 雷火对大船效果稳定，价值大于大地；大地在混合舰队中数量多时输出更高
- 零六六与古神奶量相近，可再测对比；台仔奶量不足但配合防空有崛起机会

## 适用限制
- 测试服环境，正式服可能有差异
- 未考虑火控加成，面板数据可能不全面
- 未使用防空舰船，防空改动可能影响结果
- 康纳玛拉怕巡洋分摊，需根据敌方阵容选择
