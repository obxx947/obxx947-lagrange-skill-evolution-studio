# A资料462 · 天权高达队内战战报解析

> 场景：天权高达队内战，双方满配加九

## 结论
- 大毛中排站位是为天枢级-支援航空母舰（原文为"天书"，疑似简称）承担伤害，思路可行
- 风暴负责给剑队套盾，抵抗能量伤害
- CV动力系统闪避被绝育后失效，抗伤能力受限
- 天旋通过降命中和绝育武器系统压制高达队输出
- 天机同样能绝育武器系统，针对高达队效果明显
- 舰载机带得多时海尔波普奶量非常可观
- 蓝十字带蜂巢和列维在高达队内战中伤害极低
- 蓝十字带挺难加成低，只有反馈，性价比不高
- 蓝十字思路是激活前排开阳，但牺牲了建队战斗力
- 大剑A2模块有残血斩杀机制，强度很高
- 大剑B1舰载机加成只有返回，不如B3降护甲降奶量实用
- 雷火M3粒子炮需要抢人头启动，伤害波动大
- 雷火打高达队伤害很高，打小船伤害低
- 武器协同不如命中，命中增强后可buff三个武器
- 大剑指挥坦克收益一般，指挥维B会更好
- 林鸮A100型-联合攻击机（原文为"凌霄"，疑似语音识别错误）未调校且未加暴击，导致伤害差距接近一倍
- 林鸮A100型-联合攻击机策略应选特种弹药，快速输出会左右横跳
- 风暴带得多能覆盖更多范围，压制对方能量伤害
- 右边输出队为反小而牺牲战建队战斗力，过于极端
- 右边风暴带少导致对方混沌和游骑兵伤害偏高

## 配队与模块
- 左边支援：五个满配A3天枢级-支援航空母舰，四个大毛中排，海尔兄弟，天机，二十九个炮艇
- 左边主队：两个奶毛，一个大盾旗舰，六个满配天权，三个满配CR风暴
- 右边支援：五个满配A3天枢级-支援航空母舰，四个护甲点满带B4模块的CV，兰捷CV，海尔兄弟，天机双型号，天旋双型号
- 右边主队：四个满配挺毛前排，一个大盾旗舰，六个满配天权，一个CR风暴
- 右边输出队：三个十一，两个十三，四个蓝十字带挺难，蓝十字带蜂巢和列维
- 右边主队：三个苍穹，一个大地，三个大剑，两个风暴，三个雷火，RB7突防型SP
- 大地带M2A2模块
- 大剑带短剑A2模块和B1模块
- 风暴带M2模块
- 雷火主武器选M3粒子炮，带投射器、中型反舰、打小船武器、武器协同
- 大剑指挥新麦和坦克
- 左边输出队：蓝十字带机蓝，主要输出为混沌和游骑兵
