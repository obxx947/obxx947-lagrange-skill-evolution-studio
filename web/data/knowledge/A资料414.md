# A资料414

## 场景 / 对手
护航艇能量伤害输出，针对小目标优先、后大目标，T0级别；分地推和轰炸两种玩法

## 舰队例子
- 星云脉冲 + 载具十一金（加成吃满），加点：伤害冷却、索敌暴击全拉满（胜）【地推玩法，最大化输出】
- 星云脉冲 + 载具C二苍穹，加点：锁敌换成命中（胜）【轰炸玩法，利用自带锁敌提升命中收益】

无具体实战数据，仅提供配置建议

## 结论思路
- 星云脉冲在护航艇中能量伤害输出第一，T0级别
- 地推玩法选十一金载具，加点全拉伤害冷却、索敌暴击
- 轰炸玩法选C二苍穹载具，加点将锁敌换成命中
- 一句话总结：一推十一金轰炸C二苍穹，加点差一个锁敌和命中的区别

## 适用限制
- 地推玩法适合地面推进场景，需载具十一金支持
- 轰炸玩法适合对舰轰炸，需C二苍穹载具
- 加点需根据玩法调整，不可混用
