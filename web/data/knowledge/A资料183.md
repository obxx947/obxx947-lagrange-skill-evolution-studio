# A资料183

## 场景 / 对手
星脉主武器加点及护航艇搭载舰船选择

## 舰队例子
- 星脉 + 十一鱼（载机加成：冷却、伤害、命中）（胜）【最适配，提供大幅冷却伤害和命中】
- 星脉 + CV3000大型机库（加成与鱼一致，无维修系统）（胜）【加成与鱼一致，但缺少维修系统加成】
- 星脉 + 猎兵（未点策略，提供锁敌速度）（负）【缺少伤害和冷却加成，锁敌提升不大，仅适合超斩】

## 实战结果
星脉最适配十一鱼，其次CV3000，猎兵仅用于超斩

## 结论思路
- 星脉加点不点命中，因基础命中高
- 提升伤害主要减少冷却时间
- 十一鱼提供冷却、伤害和命中，最适配星脉
- CV3000加成与鱼一致但无维修系统
- 猎兵未点策略时缺伤害和冷却，锁敌提升不大
- 其他护航艇也按此思路：先加好加点再找搭载舰船

## 适用限制
- 适用于星脉及其他护航艇的搭载选择
- 猎兵仅适合超斩场景
- 需考虑舰船维修系统加成
