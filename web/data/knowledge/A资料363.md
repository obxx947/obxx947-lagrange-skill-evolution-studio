# A资料363

## 场景 / 对手
乌拉诺斯之矛级重型战列巡洋舰现版本争议讨论，涉及副队配置与战场环境

## 舰队例子
- 乌拉诺斯之矛级（M1前排加点，中排A2/B2/B3加点，装甲加点，C2加点）（胜）【以066为主的副队中，中排附加损管毛更适合战场环境】
- 乌拉诺斯之矛级（前排附加挺锚，搭配C25风暴）（胜）【拥有航母等多超主的副队中表现不错，大毛超高的物理直射单发使其在高达内战中表现优异】

## 实战结果
主播讨论乌拉诺斯之矛级配置，未提供具体对战记录，但强调其在特定副队中的优势

## 结论思路
- 现版本中排附加损管毛更适合以066为主的副队战场环境
- 前排附加挺锚搭配C25风暴在航母多超主副队中有不错表现
- 大毛超高的物理直射单发使其在高达内战中表现优异
- 附加模块作用大于拦截模块，提供的物抗和维修量加成大于拦截作用

## 适用限制
- 适用于以066为主的副队配置
- 适用于拥有航母等多超主的副队
- 不适用于需要拦截模块的特定场景
