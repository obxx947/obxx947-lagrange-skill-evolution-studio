# A资料443

## 场景 / 对手
拉格朗日航母太阳鲸载机搭配选择，针对不同模块组合和玩家阶段

## 舰队例子
- 太阳鲸（M1+B1+C1），搭载6护航艇+5大型机，如星脉、坦克、VB、050（胜）【十一鱼，载机均衡，走地爆发强，适合2.0且有CE无M2的玩家】
- 太阳鲸（M2+B1+C1），搭载13大型机，M2放10维B+6个050，C1放4个050+6个VA（胜）【十三鱼，载机加成高，但载机不均衡，不能放护航艇，需建新方案，适合3.0且有M2和CE的玩家】
- 太阳鲸（M2+B2+C1），搭载13大型机+3护航艇（负）【十六鱼，载机不均衡，无B1冷却和伤害加成，不建议走地，只能轰炸】
- 工程鱼（M1+B1+C2）或（M2+B1+C2），搭配3个工程六鱼+2个工程霸宇（胜）【工程鱼，攻击指挥系统和绝育强，需双对结构伤害足够，若只有C2无M2也能玩但飞机需其他航母装】
- 太阳鲸（B2替换B1），如九鱼或十四鱼（负）【无B1载机加成，伤害大打折扣，不建议走地】

## 实战结果
分析不同太阳鲸搭配的优劣，十一鱼和十三鱼适合走地，十六鱼和九鱼/十四鱼不适合，工程鱼适合特殊战术

## 结论思路
- 十一鱼适合2.0且有CE无M2的玩家，载机均衡走地强
- 十三鱼适合3.0且有M2和CE的玩家，载机加成高但需新方案
- 十六鱼因无B1加成不建议走地，只能轰炸
- 工程鱼需C2模块，搭配工程六鱼和霸宇，攻击指挥系统强
- 九鱼和十四鱼因B2替换B1导致伤害降低，不建议走地
- 选择搭配需根据自身模块和对战需求

## 适用限制
- 十一鱼需CE模块，适合2.0阶段
- 十三鱼需M2和CE模块，适合3.0阶段
- 十六鱼仅适合轰炸，不适合走地
- 工程鱼需C2模块，且需结构伤害足够
- 九鱼和十四鱼因伤害不足不建议走地
