# A资料355

## 场景 / 对手
中后期320人口地推主战配置，含轰炸主队及护航队，用于推基地、打船等进攻性作战

## 舰队例子
- 轰炸队：苍穹（单苍穹轰炸，具体配置同之前推荐）（胜/负：强度较之前下降，单苍穹轰炸打战损困难）【优先拉出，需分基地和主基地人口800以上】
- 主队：投射配置，风暴（主要伤害）+重罚（补充输出）+支援航母（4CV，战机舰载机，可带控优或高速瞄腰增强防控）（胜/负：进攻性强，追求穿防效率）【人口不够时投射性价比最高】
- 副队：奶妈较少，无瑶光御魂，光锥（可换御衡，如打纯或野怪据点换3个玉衡）+支援（五九等）（胜/负：前期扛伤，优先保证大船生存）【人口受限，后期补瑶光和玉衡】

## 实战结果
三套配置构成全账号战斗力，主要攻坚；轰炸队强度两级分化，受克制影响；主队和副队需小船过渡

## 结论思路
- 三套配置需两个分基地和主基地人口800以上，资源消耗大，需过渡
- 轰炸队优先拉出，主队和副队用小船过渡
- 主队用投射配置，风暴和重罚输出，支援航母带战机
- 副队人口受限，优先保证大船生存，后期补瑶光和玉衡
- 配置主要地推主战，进攻性强，不针对反轰炸

## 适用限制
- 适用于中后期320人口，需足够人口和资源
- 不适用于开局硬憋，需过渡
- 轰炸队强度受克制影响，单苍穹轰炸可能战损困难
- 不适用于反轰炸或碰瓷队，后续会出专门配置
