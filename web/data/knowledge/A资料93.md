# A资料93

## 场景 / 对手
配船问题讨论，涉及11鱼和13鱼混搭、猎兵、泡泡龙对阵中排盾画旗舰和中排电磁舞者

## 舰队例子
- 11鱼和13鱼混搭、猎兵装铁、8个泡泡龙（负）【泡泡龙打前排小船，未有效打击关键目标，160人口浪费】
- 对面两个中排盾画旗舰、四个中排电磁舞者（胜）【盾只吃泡泡龙1万伤害，电磁舞者只吃5000多伤害】

## 实战结果
我方11鱼和13鱼混搭加猎兵和8个泡泡龙对阵对面两个中排盾画旗舰和四个中排电磁舞者，我方失败。关键得失：泡泡龙全部打前排小船，未触及关键目标，160人口浪费；对面盾和电磁舞者承受伤害极低

## 结论思路
- 不要舰队一部分超展，一部分打直射，导致斩不动也打不穿
- 泡泡龙打前排小船无实际用处，应避免浪费人口
- 如果不知道带什么，可带水母、锆石特种型、重卡等替代泡泡龙

## 适用限制
- 适用于配船时避免混合超展和直射体系
- 不适用于需要泡泡龙打前排小船的特定战术
