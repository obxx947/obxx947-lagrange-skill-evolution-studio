# A资料93 · 泡泡龙配队浪费人口

> 场景：11鱼与13鱼混搭+猎兵+8泡泡龙，对阵中排盾旗舰+中排电磁舞者

## 结论
- 舰队不要一部分打超斩、一部分打直射，斩不动且直射打不穿小船，浪费人口
- 泡泡龙基本打前排小船，没碰到对面高价值目标
- 泡泡龙对066的伤害是其他目标死完后才打出，实际用处不大
- 对面两个盾只吃到泡泡龙约1万伤害，电磁舞者只吃到约5000伤害
- 8个泡泡龙160人口基本全部浪费
- 不知道160人口带什么时，带水母、锆石特种型、重卡都比泡泡龙好

## 配队与模块
- 我方：11鱼与13鱼混搭，猎兵装铁，8个泡泡龙
- 对面：两个中排盾旗舰，四个中排电磁舞者

## 数值与数据
- 泡泡龙对盾造成约1万伤害
- 泡泡龙对电磁舞者造成约5000伤害
- 8个泡泡龙占160人口
