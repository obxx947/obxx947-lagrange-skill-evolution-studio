# A资料639

## 场景 / 对手
测试蓝十字轨道炮，靶船为盘古组合，测试时间3分钟，分大船组和小船组，对照组为蓝十字离子炮

## 舰队例子
- 蓝十字轨道炮（加点：命中、冷却、策略；B2模块加命中；A1载机模块加舰载机联动策略）（胜）【大船组伤害略低于离子炮，小船组伤害高，反小1分钟达10万】
- 蓝十字离子炮（对照组）（负）【大船组伤害略高，小船组被闪避克制，伤害不稳定】

## 实战结果
测试蓝十字轨道炮 vs 蓝十字离子炮，大船组轨道炮略逊，小船组轨道炮优势明显，关键得失：轨道炮反小能力强，反大受护甲影响大

## 结论思路
- 轨道炮加点优先命中和冷却，单发伤害不重要
- B2模块加命中，A1载机模块加舰载机联动策略
- 轨道炮反大能力不如离子炮，因单发伤害低且受护甲影响
- 轨道炮反小能力优秀，有舰载机协同后反小1分钟达10万
- 轨道炮作为航母附带输出优秀，但蓝十字靠其翻身困难

## 适用限制
- 适用于反小场景，对高护甲大船效果差
- 需要舰载机协同才能发挥最大反小能力
- 不适用于对抗高闪避目标，因轨道炮命中低需加点弥补
