# A资料446

## 场景 / 对手
奇美拉舰船评测，反小与扛伤定位分析

## 舰队例子
- 奇美拉F型号，实弹反小模块（负）【反小伤害不高，带少对穿箭牌帮助不大，带多打超主无力】
- 奇美拉C型号，扛伤模块（负）【中排无闪避，缺乏超主护甲，扛伤能力差】

## 实战结果
奇美拉三型号整体评价低，F和C型号均表现不佳，评分四分

## 结论思路
- 奇美拉F型号反小定位错误，实弹反小效率低
- 奇美拉C型号扛伤能力不足，无闪避和护甲优势
- 巡洋舰不适合作为摔炮使用

## 适用限制
- 不适用于反小任务，尤其面对穿箭牌或超主
- 不适用于扛伤前排，缺乏生存能力
- 不建议在需要高机动或高生存的场景使用
