# A资料499

## 场景 / 对手
针对天枢级盘古航母的两种玩法（副队抗伤与主队载机）及配合11鱼进行地推/轰炸的实战环境

## 舰队例子
- 天枢级盘古航母（副队抗伤）：A3 + C2 + D2（附加装甲）（胜）【代替066，取代高维修，增强副队抗伤】
- 天枢级盘古航母（主队载机）：B1/B2 + C1 + M2（胜）【配合11鱼，C1减少20%往返时间并加命中，追求伤害】
- 天枢级盘古航母（主队）：A1 + B1/B2 + C1 + M2（胜）【A1提供维修无人机，适合主队】
- 天枢级盘古航母（副队）：A3 + B1/B2 + C2 + D2（胜）【A3自主维修，C2分伤，适合副队】

## 实战结果
天枢级盘古航母在实战中表现优秀，作为副队抗伤或主队载机均有效，配合11鱼进行地推或轰炸时，能显著提升舰队生存与输出能力，关键得失在于模块选择需根据定位调整

## 结论思路
- 天枢级盘古航母出现即巅峰，分为副队抗伤和主队载机两种玩法
- 副队玩法：A3 + C2 + D2，代替066，增强抗伤
- 主队玩法：B1/B2 + C1 + M2，配合11鱼，C1减少往返时间并加命中
- M系统：M2（4艇）优于M1（4大型战机+4无人机），追求伤害选M2
- A系统：主队用A1（维修无人机），副队用A3（自主维修）
- C系统：主队用C1（飞行管控），副队用C2（分伤），C1收益高，甚至高于13余
- D系统：无脑上5附加装甲，D1没必要
- 地推推荐11鱼，若没有C2苍穹，可用13余配合其他机位
- 机位选择：小米依旧能用，021脉冲型（能量伤害）适合高课低课对抗，天机护航艇（鱼雷）配合轰炸或地推

## 适用限制
- 副队玩法适合有高维修需求的舰队，主队玩法适合追求伤害的配置
- B1/B2选择取决于艇位和机位，高课玩家可减少机位
- C1收益高但需配合主队，C2适合副队分伤
- 地推推荐11鱼，轰炸需苍穹配合
- 021脉冲型适合高课打低课，低课大量上光防时能量伤害更优
- 天机护航艇需配合鱼雷使用
