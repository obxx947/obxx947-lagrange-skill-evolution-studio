# A资料499 · 天枢级盘古航母模块与配队

> 场景：主队/副队、地推、轰炸、高课打低课

## 结论
- 盘古航母出现即巅峰，可放副队增援抗伤，代替066并取代一个高维修
- 副队玩法模块选A1、A3，往后加C2、D2
- 配合11鱼时作为载机，B系统选B1或B2，再配合C1飞行管控系统
- C1飞行管控系统减少20%时间并加命中，点两个冷却即可
- 追求伤害放主队时，M系统个人喜欢用M2
- 放主队建议A1，放副队抗伤配合天权及其他战损时用A3
- 放主队建议带C1，放副队带C2，因为要分伤
- D系统无脑上五个附加装甲，D1没必要上
- C系统提供75%往返减免，收益很高，甚至高于13鱼
- 打地推推荐11鱼，没有C2苍穹时只能上13鱼配合天枢打
- 有C2苍穹可挺线搞轰炸，配合天枢做副队增强抗伤
- 小米现在依旧能用，拦截效果非常好
- 盘古飞机轰炸时可当挡刀机
- 021脉冲型现在非常好用，能量伤害更好，高课打低课时光防多，能量伤害更优
- 天玑护航艇是鱼雷，搞轰炸和玩地推时都可配合用，能量伤害且有溶解弹

## 配队与模块
- 副队玩法：A1、A3，往后加C2、D2
- 配合11鱼：B1或B2，配合C1飞行管控系统
- M1：四个大型战机加四个无人机，协同反击防空
- M2：四个护航艇，配合无人艇协同
- A1：五个维修无人机，每30秒减冷却和持续时间
- A3：自主维修，自身一次性维修装甲
- B系统：一个护航艇位，四个护航艇；或四个大型战机机位
- C1：飞行管控系统，减少20%时间并加命中
- C2：分伤用
- D系统：五个附加装甲
- 地推：11鱼配合天枢级航母
- 轰炸：C2苍穹挺线搞轰炸，配合13鱼和天枢
- 021脉冲型可作能量伤害飞机使用
- 天玑护航艇可配合轰炸和地推

## 数值与数据
- C1飞行管控系统减少20%时间
- C系统提供75%往返减免
- A1五个维修无人机
- M1四个大型战机加四个无人机
- M2四个护航艇
- B系统四个护航艇或四个大型战机机位
