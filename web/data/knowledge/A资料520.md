# A资料520 · 主动防空机制与舰船推荐

> 场景：对抗飞机海/轰炸机

## 结论
- 主动防空单位无需被攻击即可自主锁定并攻击全场任意敌方空中单位
- 主动防空对舰载机锁敌优先级更高，优先打击轰炸机等高威胁目标
- 主动防空单位无论在前排、中排还是后排都能覆盖全场
- 主动防空适合正面接敌和夹击航母队，能有效打击敌方空军
- 被动防空需我方舰船被攻击后才能反击，存在反应延迟且需自身接敌
- 主动防空先手为强，尤其适合对抗轰炸机和飞机海
- 可通过加点聚焦空战来削弱对方防空能力
