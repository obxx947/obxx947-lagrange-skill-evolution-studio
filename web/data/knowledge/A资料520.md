# A资料520

## 场景 / 对手
空战核心机制，对抗飞机海轰炸

## 舰队例子
- 米斯特拉战机（胜）【最强主动防空战机，防空一哥】
- 沙龙大气层拦截机（胜）【主炮主动防空，需受击触发导弹，依赖敌方反击】
- CVT800脉冲炮艇（胜）【顶级主动防空护航体，优先锁定护航体】
- 郎西及防御护卫舰（胜）【血量越低伤害越高，限制撤退，兼具抗伤防空】
- 告十级突击护卫舰（胜）【搭载两架定制护航艇，吸收对空伤害】
- 伺水母防御护卫舰（胜）【专攻护航艇拦截，快速清理】

## 实战结果
主动防空单位无需被攻击即可自主锁定攻击全场空中单位，优先打击高威胁目标，对比被动防空（如林宵、包子）先手为强，有效瓦解轰炸机海攻势

## 结论思路
- 主动防空单位无需被攻击即可自主锁定攻击任意位置敌方空中单位
- 主动防空优先打击高威胁空中目标如轰炸机
- 可通过加点聚焦空战削弱敌方防空能力
- 主动防空单位部署位置不限，覆盖全场
- 主动防空适合对抗轰炸机和飞机海
- 被动防空需受击触发，存在延迟和限制

## 适用限制
- 适用于对抗轰炸机、飞机海等空中威胁
- 沙龙依赖敌方反击触发导弹，面对无反击防空目标时效果受限
- 主动防空单位需合理搭配以最大化防空效率
