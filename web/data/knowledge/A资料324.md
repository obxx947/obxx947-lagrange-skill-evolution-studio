# A资料324

## 场景 / 对手
大地A2/CE/AE/AR对比，反击盾体系，对抗太阳/摇光

## 舰队例子
- 大地A2（能量抗性，实弹脆弱）（负）【A2很弱，能量胆大、实弹胆小】
- 大地CE（增加能量伤害）（负）【CE也很弱，冷却时间天坑】
- 大地AE（带C3模块）（胜）【有命中加成，强大收割能力】
- 大地AR（需补网易）（负）【模块不全玩不了，模块全了玩A1C3】

## 实战结果
大地A2/CE/AR均弱，AE带C3为优；反击盾不怕拦截，打太阳不怕摇光，但冷却时间限制

## 结论思路
- 大地A2和CE均弱，不推荐单独使用
- CE增加能量伤害，但冷却时间是天坑
- AE带C3有命中加成和收割能力，优于A2/CE
- AR需补网易，模块不全无法使用，模块全了应选A1C3
- 反击盾体系不怕拦截，对太阳和摇光有优势

## 适用限制
- 适用于反击盾体系，对抗太阳/摇光
- 需模块齐全，否则无法发挥
- 冷却时间限制需注意，不适合高频率战斗
