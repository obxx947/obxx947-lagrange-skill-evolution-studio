# A资料382

## 场景 / 对手
航母强度评价，从弱到强，涉及各航母体系与实战环境

## 舰队例子
- CV3000（白板）（胜）【造价低、成型快，性价比之王】
- 南十字星（新版本）（胜）【略微加强，表现提升】
- 济南超展 + 十一鱼 + 蓝队（胜）【小效果突出，搭配灵活】
- 太阳鲸（单航母）（胜）【万金油，适用多种场景】
- 太阳鲸 + 11 + 13（双航母）（胜）【可搭配男石或苍穹，增强输出】
- 苍穹（轰炸）（胜）【轰炸代名词，真神，有C2即可毕业】
- 天书（奶船）（胜）【最强奶船，叹息之墙】
- 雷火之（指挥）（胜）【新船无弱者，指挥能力强】

## 实战结果
玩家对各航母进行从弱到强评价，未提及具体对战双方，但强调CV3000性价比、苍穹轰炸强势、天书奶船防御等关键点

## 结论思路
- CV3000适合低成本快速成型，性价比高
- 南十字星新版本加强，值得关注
- 济南超展搭配十一鱼和蓝队效果突出
- 太阳鲸作为万金油，单航母或双航母均可
- 苍穹是轰炸核心，有C2即可毕业
- 天书是最强奶船，提供强大防御
- 雷火之指挥能力强，新船无弱者

## 适用限制
- CV3000适合前期或资源有限时使用
- 苍穹依赖C2模块，否则效果受限
- 天书需搭配输出舰队才能发挥最大作用
- 雷火之作为新船，需适应版本环境
