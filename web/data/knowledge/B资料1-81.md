# B资料1-81 · 大剑盾白垩级模块讨论

> 场景：正面配队

## 结论
- 目标选择瞬间可能选天枢级-支援航空母舰（原文为“天枢级-支援航空母舰”，疑似语音识别错误），照理应锁护甲高/物理抵抗高的船，最终锁盾。
- 正常不推荐玩A3大剑（原文为“A三的键”，疑似语音识别错误）。
- 开阳级-机动驱逐舰（原文为“开阳光”，疑似语音识别错误）会影响大剑锁定。
- 永恒风暴级-攻击战列巡洋舰（原文为“风暴”，疑似简称）未带无人机时，血量点不点都无所谓，反正会死；点满血量可活下来。
- 白垩级-综合防空巡洋舰（原文为“白垩姬/白垩棋”，疑似语音识别错误）不宜带太多；没有防空模块时更不要太多。
- 普鲁图斯之盾级-防护战列巡洋舰（原文为“盾”，疑似简称）只有单模块时输出和防空都不强，带多还亏人口。
- 盾没伤害主要因没模块没点数；有模块有点数伤害才高。
- 低氪度盾按4.6玩法强度不会高，盾带越多越亏。
- 强的是策略盾，不是盾本身；应尽量让盾数量更少。
- 有模块的逆境盾伤害高于乌拉诺斯之矛（原文为“矛”，疑似简称）。

## 配队与模块
- 安东塔斯持剑者级-指挥舰（原文为“剑”，疑似简称）：可玩大剑，前提不遇太阳鲸-武装战略航空母舰（原文为“太阳”，疑似简称）和阳光；锁定目标锁盾。
- 普鲁图斯之盾级-防护战列巡洋舰：有模块才带逆境盾，无模块不带。
- 永恒风暴级-攻击战列巡洋舰：盾亏人口时多带风暴替代。
- 白垩级-综合防空巡洋舰：推荐M2+C2，M3+C3也可；M1和C不选；C1也能打很多防空。

## 数值与数据
- 乌拉诺斯之矛可打8万9，普鲁图斯之盾级-防护战列巡洋舰才打2万。
- 一个端口总面板44万。
- 白垩级-综合防空巡洋舰C3约16万，C2估计约16万；C3点数未加满。
- 战报中1艘换对面7艘。
- 推荐4.6的盾玩法（原文“四点六”）。
