# A资料476 · 新版本护航输出队搭配

> 场景：护航输出队/护航战斗

## 结论
- 巡洋舰输出可用但不推荐，直射武器易被开阳级-机动驱逐舰（原文为"开阳"，疑似简称）和瑶光级-通用护卫舰（原文为"瑶光"，疑似简称）克制
- 投射武器重卡易被防空锥子拦截，打不出伤害
- 游骑兵级-重型离子炮巡洋舰（原文为"游骑兵离子"，疑似简称）既直射又投射，更不推荐
- 护航输出队想打伤害，要么上战巡，要么拉飞机和护航艇
- 地面输出基本不带巡洋舰，唯一输出是永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）
- 永恒风暴级-攻击战列巡洋舰是投射武器，能越过前排打中后排大型舰船且无法被拦截
- 永恒风暴级-攻击战列巡洋舰能量输出，面对高物抗超主力舰有输出优势
- 永恒风暴级-攻击战列巡洋舰只要有M2输出模块就能玩，门槛很低
- 利用各种载具加成拉飞机和护航艇，舰载机输出非常夸张
- 支援+5时航母和舰载机不是越多越好，部分舰载机伤害主要打系统而非结构值
- 盲目堆航母和舰载机会导致对舰伤害水分大，打炸目标少
- 减少部分航母和飞机后伤害反而更高
- 版本要多带实弹伤害，如BR050-标准轰炸机（原文为"050"，疑似简称）、B192新大地-重型攻击机（原文为"新大地"，疑似简称）
- 实弹伤害用于应对敌方带C2风暴克制能量输出的情况

## 配队与模块
- 护航输出队：4艘永恒风暴级-攻击战列巡洋舰、3艘永恒苍穹级-无人机航空母舰（原文为"永恒苍穹"，疑似简称）、5艘太阳鲸-武装战略航空母舰（原文为"太阳鲸"，疑似简称）
- 补猎兵级-重型载机巡洋舰（原文为"猎兵"，疑似简称）和狩猎者级-载机巡洋舰（原文为"狩猎者"，疑似简称），拉大量飞机和护航艇
- 永恒风暴级-攻击战列巡洋舰带M2输出模块
- 舰载机配置：星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）、CV-T800型-脉冲炮艇（原文为"800"，疑似简称）、索姆河之影-装甲飞行坦克（原文为"索姆河"，疑似简称）
- 进阶版：三航母输出队
