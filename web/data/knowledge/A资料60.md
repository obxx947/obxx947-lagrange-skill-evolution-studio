# A资料60

## 场景 / 对手
针对轰炸/舰载机干扰的驱逐舰测试，对手为蜂巢、列维、维B、050等舰载机体系，正面测试

## 舰队例子
- 进攻方：维B、050、蜂巢（20战机+20炮艇）；防守方：奇美拉防御（胜/负/评价：测试干扰序列，干扰目标以炮艇为主，描述基本正确）【干扰目标优先炮艇其次战机，但索敌可能重复】
- 防守方：4奇美拉（无银石） vs 蜂巢+列维（生存时间2分27秒）【基准数据】
- 防守方：4奇美拉（无银石） vs 维B+050（生存时间2分25秒）【基准数据】
- 防守方：4奇美拉+10银石 vs 维B+050（生存时间2分31秒，提升6秒；干扰11层输出3.2万，8层输出3.7万）【干扰效果不明显】
- 防守方：4奇美拉+10银石 vs 蜂巢+列维（生存时间2分38秒，提升11秒）【对炮艇干扰略优于战机】
- 防守方：8奇美拉（无银石） vs 缝合蜂巢（生存时间2分33秒）【基准数据】
- 防守方：8奇美拉+10银石 vs 缝合蜂巢（生存时间2分46秒，提升13秒）【提升有限】

## 实战结果
测试者用银石对抗多种舰载机体系，银石对生存提升仅6-13秒，干扰效果微弱，整体评价为垃圾

## 结论思路
- 银石针对舰载机但克制能力几乎没有
- 闪避针对投射武器且为后排，生存优势难以发挥
- 干扰目标可叠加但索敌重复，实际效果打折
- 对生存提升极小，数据差距不显著

## 适用限制
- 仅适用于对抗舰载机体系
- 不适合放入主队或扛伤队
- 对投射武器为主的敌人效果有限
- 不建议作为核心辅助使用
