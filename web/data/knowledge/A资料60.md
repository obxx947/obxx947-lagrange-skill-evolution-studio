# A资料60 · 萤石级干扰舰载机实测

> 场景：舰载机/轰炸环境，防守方奇美拉防御

## 结论
- 萤石级定位尴尬，基本没用
- 降低舰载机命中率对轰炸克制能力几乎没有
- 后排站位导致无法扛伤，不如带赖船
- 投射武器闪避很抽象，带投射武器的人本来就不多
- 若改成通用闪避，这船会很强
- 放碰瓷队对空军无限制作用
- 放扛伤队因在后排扛不了伤
- 干扰目标优先炮艇其次战机，描述基本没问题
- 干扰命中可叠加到三层，即降低30%命中率
- 多个萤石对同一目标干扰时命中率会下降更多
- 索敌经常重复，运气差时干扰目标数会减少
- 一个萤石可同时干扰三个舰载机目标
- 带十个萤石运气好可同时干扰三十个舰载机
- 对战机命中率较高，但实际输出下降不明显
- 对炮艇生存提升略优于战机，但依然没用
- 面对缝合蜂巢时提升十三秒，数据差距太小

## 配队与模块
- 进攻方携带维塔斯-B010-轰炸机（原文为"维B"，疑似简称）、BR050系列轰炸机（原文为"050"，疑似简称）、列维、蜂巢，共20战机20炮艇
- 防守方使用奇美拉级-防御巡洋舰（原文为"奇美拉防御"，疑似简称）
- 测试靶船为4个奇美拉级-防御巡洋舰
- 加入10个萤石级进行干扰测试
- 缝合测试使用8个奇美拉级-防御巡洋舰，主要缝合蜂巢

## 数值与数据
- 萤石级为7人口驱逐舰
- 无萤石时4个奇美拉面对蜂巢和列维扛2分27秒
- 无萤石时4个奇美拉面对维塔斯-B010-轰炸机和BR050系列轰炸机扛2分25秒
- 加入10个萤石后奇美拉生存时间提升至2分31秒，提升6秒
- 战机被干扰11层时输出约3.2万
- 战机被干扰8层时输出接近3.7万，输出下降约5000
- 炮艇测试中奇美拉最后战损时间2分38秒，对比无萤石2分27秒提升11秒
- 缝合蜂巢测试无萤石时8个奇美拉生存2分33秒
- 加入萤石后奇美拉最后战损时间2分46秒，提升13秒
