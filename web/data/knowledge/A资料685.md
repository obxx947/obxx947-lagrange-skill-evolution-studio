# A资料685 · 林鸮A100加点与定位

> 场景：solo视角；当前护航版本

## 结论
- 林鸮A100型-联合攻击机（原文为"凌霄"，疑似语音识别错误）老少皆宜，任何赛季/阶段都能用，点数要求低。
- 定位为战机，主要打护航艇（原文为"护航体"，疑似语音识别错误）；当前护航版本空优机（原文为"空油机"，疑似语音识别错误）吃香，但支援防空夹击伤害低，上场空间不大。
- solo视角非常推荐；护航版本视角上场空间有限。
- 技术值不足时优先加动力系统；机动改良对战机的时间和伤害收益最高。
- 机动提升对维塔斯-B010-轰炸机（原文为"vb"，疑似简称）等轰炸机更明显。
- 空优机未死完前该船几乎不会第一个受伤，防御属性和闪避收益低。
- 主武器系统优先加点，该船不是第一优先被攻击目标。
- 主武器伤害和冷却提升很少，存在大量无效点数。
- 养成成本低，适合普通solo玩家；战机生存好，打护航艇，护航艇最容易被突破。
- 不吃载具加成，放到哪里都能用。
- 不同载具对林鸮A100型-联合攻击机的对空加成差距不大。
- 米斯特拉-战斗攻击机（原文为"小米"，疑似简称）/砂龙-大气层拦截机（原文为"沙龙"，疑似语音识别错误）放到南十字星元帅级模块上表现明显更差。
- 林鸮A100型-联合攻击机打武器系统，暴击很关键；爆系统越快越好。
- 加点仅个人视角，可按自己理解调整。

## 配队与模块
- 动力系统：机动改良、锁敌（原文为"锁地"，疑似语音识别错误）、命中；点数不足时只点这四个有效选项。
- 有锁敌必点；命中对护航艇无提升。
- 主武器系统：伤害、命中；点数充足补双伤害。
- 对战型：将命中或冷却之一改为双暴击。
- 策略系统不点。
- 可搭载于CV3000级-快速航空母舰（原文为"ce"，疑似语音识别错误）、ST59级-防御战列巡洋舰（原文为"五九"，疑似简称）、南十字星元帅级-武装航空母舰（原文为"男士制"，疑似语音识别错误）测试对空。

## 数值与数据
- 动力系统约40点 + 主武器系统约30点 = 70点够用。
- 抽到有50点加成时，点满动力后点主武器，两个伤害可不点，只点命中即可半毕业。
- CV3000级-快速航空母舰带林鸮A100型-联合攻击机对空约1万。
- ST59级-防御战列巡洋舰带林鸮A100型-联合攻击机对空约7000-8000。
- 南十字星元帅级-武装航空母舰载具虽弱，带林鸮A100型-联合攻击机对空仍6000多。
- 最强对空载具加成模块十一上也只有1万多，差距不大。
- 林鸮A100型-联合攻击机打武器系统进入25秒循环，一轮后继续爆第二轮。
