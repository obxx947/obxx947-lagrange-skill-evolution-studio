# B资料1-80 · 天枢配队与防空模块讨论

> 场景：团战/组队/顶着轰炸；副队防空与奶队

## 结论
- 天枢级-支援航空母舰（原文为“天枢级-支援航空母舰”，疑似语音识别错误）对舰/防空能力存疑：理论上无对舰能力，面板两百多却刮出一千八对舰伤害，放主队或组队可测。
- 天枢级-支援航空母舰A3一般优于A1，A1基础奶量太低，基本没有就业空间；A3强在飞机网/送光后。
- 天枢级-支援航空母舰A3时间拉长后把M模块送掉，M模块会转维修，相当于比A1多一个艇；基础奶量区别不大。
- 天枢级-支援航空母舰策略三十秒一触发，容易卡在三十秒点触发四轮；时间拉长差三十秒未触发，奶量反而可能更高。
- 天枢级-支援航空母舰有A3的玩家维修点上面也可，区别不大。
- 副队中天枢级-支援航空母舰A3有防空，天权级-重型防御战列巡洋舰（原文为"天拳"，疑似语音识别错误）不改；乌拉诺斯之矛用A3。
- 组队被轰炸时必须带白垩级-综合防空巡洋舰（原文为"白鳄"，疑似语音识别错误）防炸，不带被炸就得跑；主队带不带白垩差距也很大。
- 不带雷火之星-综合武库舰（原文为"雷火"，疑似简称）时，前排做FSV830-快速战术支援舰（原文为"八三"，疑似简称），中排两个普鲁图斯之盾级-防护战列巡洋舰（原文为"大盾"，疑似简称），或中排再加一个雷火之星-综合武库舰。
- 担心掩护按面板选择目标时，可能优先掩护大盾；看动画船突然不掉线可判断被掩护。
- 全中排再把雷火之星-综合武库舰调后排可行，雷火自身有拦截，天枢级-支援航空母舰也有自身拦截。
- 雷火之星-综合武库舰与天枢级-支援航空母舰自身拦截效率都一般，雷火两分钟才拦七颗子弹，约等于没有，能打点防空就算好。
- 这个队伍没必要反小，直接反大，把对方大船打完对方就会跑；若对方梭哈，自己会被夹到死。
- 普通玩家伤害越精准越好；大剑三条剑打同一目标会乘三倍计算，且目标大概率会死，有效率高。
- 主动防空主要是白垩级-综合防空巡洋舰A、棕熊级-防空巡洋舰（原文为"棕熊B"，疑似简称）B、安东塔斯持剑者级-指挥舰（原文为"大剑"，疑似简称）防空模块；其他多为支援防空。
- 支援防空打不到海尔波普；海尔波普无对舰也无对空，只有主动防空才打得到，所以海尔波普会一直活。
- 防空和拦截是独立系统，降命中不影响光锥级-综合导弹巡洋舰（原文为"光追"，疑似语音识别错误）的拦截；提升命中或频率也不会增加拦截率。
- 拦截率有独立词条，常见只有“获得/提升拦截率”和“拦截效果为中”两类，其他提升不改变拦截。
- 天璇-战斗攻击机-B（原文为"天选"，疑似语音识别错误）降命中需要溶解弹铺开，队伍里要带大量盘古家族船/矿艇；打高刻度用天璇，打低刻度可用SC002型-量子侦察机（原文为"零零二"，疑似简称）降敌方闪避，两者一般不共存。
- 新君士坦丁大帝级-综合战列巡洋舰（原文为"大帝"，疑似简称）用A1不用A2：A1按M1直射武器，策略靠A1激活；M2会重新锁人，容易锁后排。
- 新君士坦丁大帝级-综合战列巡洋舰优先攻击战神；C3策略要点，不点会加到航母、巡洋、战巡上；正常只带一到两台。
- 安东塔斯持剑者级-指挥舰可带防空模块，对舰伤害低；不追求剑伤害极致时可以带，配合新君士坦丁大帝级命中可吃百分之二十命中提升。
- 永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）C1/C2一般选C2；选C1会让CV-T800型-脉冲炮艇（原文为"t八百"，疑似简称）没位置，只能放组队；若带C1苍穹可带砂龙-大气层拦截机（原文为"沙龙"，疑似语音识别错误）。
- 天权级-重型防御战列巡洋舰改防空模块可保CV-T800型-脉冲炮艇，不改便宜但不能多队，打到第二天海尔波普会一直活。
- 南十字星元帅级-武装航空母舰（原文为"男生是"，疑似语音识别错误）六级给雷火之星-综合武库舰加命中，优先给伤害最高目标，但两分钟最多两三次，提升有限。
- 巅峰优先级：只有天枢级-支援航空母舰有必要巅峰十五；盾或矛巅峰五级给十蓝点即可，其他巅峰十不推荐，除非点数多到每个三百到四百点。
- 天枢级-支援航空母舰常规模块为M2、A3、B1、C2，D模块选第二或不选。
- 安东塔斯持剑者级-指挥舰不带融甲，龙甲伤害约百分之十到十七，集中在上面两个模块，调教性价比高。
- 星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）策略一分钟，战报只看四十五秒没有参考；应看五分钟让策略触发多轮，并考虑转火损失。
- 战报应看结构值伤害，扣除系统伤害后四分钟三百多万和六分钟七百万实际每分钟约七十到七十九万，舰船不变伤害不会大变。
- 护航队以奶为核心，激进战损让伤害和奶更集中是好处；但奶船少时照顾有限，多条船均匀掉血会奶不过来。
- 四分钟奶一百万约一分钟二十五万，若对方一分钟对舰一百万，这个奶量不算高；奶量若到五十万就能抵掉对方一半输出。
- 组队人口按联盟四百算，带白垩后用大盾凑人口。
- 安东塔斯持剑者级-指挥舰A3序列包含航母、巡洋、战巡，会打天枢级-支援航空母舰。
- 大剑可以指挥中排舰船、攻坚射船或空军，一般指挥三个自己起的战包。

## 配队与模块
- 天枢级-支援航空母舰：M2+A3+B1+C2，D模块选第二；加点按M2、A3、艇、维修常规点。
- 天枢级-支援航空母舰防御模块优先点抗性，不点血量也可以，最后点结构值。
- 天枢级-支援航空母舰强化备件可用，但与原方案差距不大；有A3时维修点上面也可。
- 天枢级-支援航空母舰若不放天枪护航艇，维修加点按常规；放天枪则按天枪加点。
- 副队：天枢级-支援航空母舰A3有防空，天权级-重型防御战列巡洋舰不改，乌拉诺斯之矛用A3，剩余位置给米斯特拉-战斗攻击机（原文为"小米"，疑似简称）和红宝石级（原文为"红箱子"，疑似语音识别错误）。
- 不带雷火之星-综合武库舰方案：前排FSV830-快速战术支援舰，中排两个普鲁图斯之盾级-防护战列巡洋舰，或中排再补雷火之星-综合武库舰。
- 组队方案：雷火之星-综合武库舰、永恒风暴级-攻击战列巡洋舰（原文为"风暴"，疑似简称）、安东塔斯持剑者级-指挥舰，艇位优先蜂巢守卫者-重型鱼雷艇（原文为"蜂巢"，疑似简称），RB7-13型-导弹艇（原文为"RB七"，疑似简称）就业空间小。
- 安东塔斯持剑者级-指挥舰可带九个RB7-13型-导弹艇；若不带融甲，可腾位置带RB7-13型-导弹艇。
- 新君士坦丁大帝级-综合战列巡洋舰带A1/M1，正常一到两台，C3策略要点。
- 组队防炸：带白垩级-综合防空巡洋舰A，剩余人口用两个白垩级或大盾凑，再补新君士坦丁大帝级加命中给安东塔斯持剑者级。
- 苍穹组队：永恒苍穹级-无人机航空母舰C2加CV-T800型-脉冲炮艇加新君士坦丁大帝级；若C1苍穹则带砂龙-大气层拦截机。
- CV-T800型-脉冲炮艇和星云追逐者-脉冲炮艇带不满会少两个，优先带满CV-T800型-脉冲炮艇，苍穹不用下，南十字星元帅级可下。
- 天权级-重型防御战列巡洋舰改防空模块，用来保CV-T800型-脉冲炮艇。
- 战机选择：打高刻度带天璇-战斗攻击机-B降命中，打低刻度带SC002型-量子侦察机降闪避；溶解弹需大量盘古家族船/矿艇铺开。
- 主动防空配置：白垩级-综合防空巡洋舰A、棕熊级-防空巡洋舰B、安东塔斯持剑者级-指挥舰防空模块；其他船多为支援防空。
- 南十字星元帅级-武装航空母舰六级命中优先给雷火之星-综合武库舰。
- 主队带白垩级-综合防空巡洋舰防轰炸，组队被轰炸也必须带白垩。
- 安东塔斯持剑者级-指挥舰防空模块可尝试，对舰伤害低但基础对舰约六千、基础命中约百分之五十以上，配合命中加成可提升防空。
- 新君士坦丁大帝级-综合战列巡洋舰命中加成可给安东塔斯持剑者级-指挥舰，组队只有两个战神时收益更明显。
- 雷火之星-综合武库舰、永恒风暴级-攻击战列巡洋舰、海尔波普多为支援防空；支援防空打不到海尔波普。
- 天枢级-支援航空母舰A3有防空，天权级-重型防御战列巡洋舰不改，乌拉诺斯之矛A3有防空。
- 大剑可指挥中排舰船、攻坚射船或空军，一般指挥三个自己起的战包。

## 数值与数据
- 天枢级-支援航空母舰基础奶约一万一千，加点后约两万，加一点约一万六；A1基础奶约八千三加一千二。
- 天枢级-支援航空母舰策略三十秒触发，四轮可触发完。
- 强化备件加五百；维修面板一万四到一万五加五百，两万也加五百多，三个约一千五，原方案约一千四，差距不大。
- 巅峰五级给十蓝点；巅峰十五只有天枢级-支援航空母舰有必要；其他巅峰十不推荐，除非点数多到每个号三百到四百点。
- 天枢级-支援航空母舰拦截效率一般，两分钟约拦七颗子弹。
- 安东塔斯持剑者级-指挥舰龙甲伤害约百分之十到十七；调教五个一调，加成百分之十五伤害。
- 大剑三条剑打同一目标乘三倍，有效率约百分之百；锁敌七秒，转火一秒，策略十五秒，转火一次损失十五分之一时间。
- 星云追逐者-脉冲炮艇策略一分钟；策略触发十五秒内输出可能高于前面一分钟；散热效率加八百等于百分之十五，百分之百乘六，八千乘六约四千八，面板近翻倍，原五千二到五千四，策略期间上万。
- 天璇-战斗攻击机-B溶解效果：百分之三十五几率施加六十秒，每层掉十结构值，最高三十层，命中率降低百分之十。
- 防空无人机全图拦截，导弹为半场/铜牌拦截，两者占比约五五开，防空无人机拦截多约一倍。
- 新君士坦丁大帝级-综合战列巡洋舰基础对舰约六千，基础命中约百分之五十以上，基础防空面板五十。
- 战报数据：四十五秒组队加副队打约一百万，总血量约三百万，最多两到三分钟；高刻度一分钟约两百万，低刻度一分钟约一百到一百二十万。
- 四分钟打三百多万，扣除系统伤害后约一分钟七十万；六分钟打七百万，扣除系统伤害约一百四十五万，剩五百五十五万，按七分钟约七十九万。
- 四分钟奶一百万，约一分钟二十五万；副队两分钟出伤一百万；没带天玑和天枢时两分钟约四十万。
- 联盟人口按四百算；带白垩级-综合防空巡洋舰后凑人口，大盾用于凑人口。
- 安东塔斯持剑者级-指挥舰带九个RB7-13型-导弹艇。
- 南十字星元帅级-武装航空母舰命中加成两分钟约两到三次。
- 盾被轰炸时战报约打三万五千伤害，约一半盾伤害。
- 防空模块数值对比：一个约一千三，另一个约七千，七千明显更高；战报有八九万、五万、三万五等防空伤害。
- 天枢级-支援航空母舰面板两百多却只刮出一千八对舰伤害，与六万防空/六万对舰说法矛盾。
