# A资料670

## 场景 / 对手
地推配置，针对开阳加瑶光组合，正面作战

## 舰队例子
- 鱼（3艘，11型）+ 坦克（3艘）+ 星脉 + 小米（3组）+ VA（5艘）（胜）【机位调整，手动添加小米优先，坦克三艘为一组】
- 苍穹（C1型）+ 凌霄 + VB（2艘，13鱼）+ VA（5艘）+ 刺遥（胜）【大型机库手动添加零五零基础，优先放凌霄】
- 海市 + 狩猎战术（胜）【腹肌库加成低（减数50% vs 70%），不推荐】
- 南石（加四型）+ 坦普尔 + 虚灵（胜）【优先放坦普尔，带干扰，用于增援副队】
- 八战群（2盾+3毛+3风暴）+ 风暴（中排）+ C2（胜）【成型后风暴放中排，上C2】
- 五战巡（矛盾组合：开阳+瑶光+御衡）+ 光防（3个）（胜）【中期打架放中排，节点调站位，模块附加挺毛】
- 八战巡成型 + 反战 + 损管毛 + 零幺幺/虚零/坦波尔（胜）【光防下，上反倒，分伤状态】
- 旬阳（棕熊无B型）+ 泡泡龙 + 奇美拉重炮（胜）【泡泡龙打大船，调教满，三冷却一策略两伤害】
- 巡洋（2盾+3毛+3风暴）+ 风暴（3艘）（胜）【风暴以盘古为主，断奶形式】
- 苍穹（C1满）+ 零五零 + 凌霄 + 零二幺/新大地/天旋/雷火（胜）【大型机库20机位优先零五零和凌霄，小型机库补位】
- 锆石特种 + 水母 + 双鱼海（B型）+ 开阳 + 吸神星重炮/雨海脉冲（胜）【鬼刀炮，人口少，受伤退中后排，针对开洋】
- 防空碰瓷队（股神星+台元+斗牛+七二幺+枪房5-8个）（胜）【双皮奶，点燃基地】
- 七二幺（导弹型）+ 五九 + 枪械兵 + 银时（4-6个）+ 白鳄（胜）【点策略命中，增援五九，吃轰炸】
- 开阳（双）+ 瑶光（胜）【前期扛伤用技术型，输出用子型号】
- 五战群（矛盾组合：御衡基础+开阳+瑶光）+ 大盾旗舰 + 3中排毛 + 光环 + 6奶（胜）【二百人口不省，增援位大盾】
- 第三队（光环+高速L）（胜）【人口提升后造，用于地推】

## 实战结果
针对开阳加瑶光组合，多舰队配置，胜多负少，关键在机位调整和模块选择

## 结论思路
- 鱼配十一和十三，机位调整，坦克三艘一组，小米优先
- 苍穹C1优先，大型机库手动添加零五零，凌霄优先
- 海市用狩猎战术，腹肌库加成低不推荐
- 南石需加四，优先坦普尔和虚灵，带干扰
- 八战群成型后风暴放中排，上C2
- 五战巡矛盾组合配小盘谷，中期放中牌，节点调站位
- 八战巡成型上反战，光防下，损管毛，分伤
- 泡泡龙打大船，调教满，三冷却一策略两伤害
- 风暴以盘古为主，断奶形式
- 苍穹C1造满，配合奇美拉重炮打地推
- 高速L反小还行，但开阳加瑶光组合难受，中卡易被拦截，重卡反拦截必点
- 小型机库用零二幺/新大地/天旋，天旋治盲瘤好
- 锆石配水母针对开洋，鬼刀炮，人口少
- 防空碰瓷队用股神星加台元，双皮奶，配合斗牛和七二幺
- 七二幺点策略命中，增援五九，配银时和白鳄
- 开阳前期扛伤用技术型，输出用子型号
- 五战群矛盾组合二百人口不省，增援大盾
- 列兵八百上两锁，自带70%减锁

## 适用限制
- 适用于地推场景，针对开阳加瑶光组合
- 需要特定模块和子型号（如加四、B型）
- 机位和人口需精确配置
- 不适用于无B型号的棕熊
- 高速L和中卡在特定组合下效果差
- 光防多时投射类武器难受
