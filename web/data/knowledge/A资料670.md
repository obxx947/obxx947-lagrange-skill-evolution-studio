# A资料670 · 三加三账号地推配队与模块

> 场景：地推；针对开阳+瑶光；防空碰瓷；敌方轰炸

## 结论
- 账号三点五加三/三加三，原石和模块全，全部走地推。
- 苍穹优先C1，C1人口不能省；可切C2但优先C1。
- 海氏优先狩猎者级-战术载机巡洋舰（原文为"狩猎战术"，疑似简称），苍穹附加载机机库（原文为"腹肌库"，疑似语音识别错误）加成较低。
- 南十字星元帅级需有加四再考虑。
- 带干扰的护航艇最适合地推。
- 八战巡成型后风暴放中排并上C2。
- 五战巡矛盾组合配开阳+瑶光+玉衡；中期高烈度放中排，节点调矛站位。
- 五战巡至少三个光防；八战巡成型后光防可下换反倒/反导。
- 艇位选011、虚灵、坦普尔做分伤，避免敌方集火前排中排。
- 棕熊无B型不建议上。
- 泡泡龙打大船；打开阳时不好用，敌方开阳被清后打大船好用。
- 泡泡龙加点调校满，三冷却一策略两伤害，以它为基础过渡到巡洋。
- 风暴地推以盘古为主；功能性增强后输出不变，放主队断奶。
- 组队时苍穹C1造满做增援，可切C2；泡泡龙+奇美拉重炮对敌方开阳火力输出。
- 光锥级-攻击导弹巡洋舰（原文为"光秃"，疑似语音识别错误）反小厉害但属投射；遇敌方三光防难受。
- 艾奥级-高速离子炮巡洋舰（原文为"高速l"，疑似语音识别错误）仍能用；开阳+瑶光让其打小船难受。
- 中卡能用但投射易被拦截；重卡反拦截必点，优先打大船，会被拦截，自己算机位。
- 锆石级-特种护卫舰（原文为"锆石的特种型号"，疑似简称）配刺水母级-战术护卫舰（原文为"水母"，疑似简称）不推荐上；配双鱼海可上B型。
- 锆石特种针对开阳用鬼刀炮，人口少、加点后输出高，受伤后退中排后排。
- 防空碰瓷队：巡洋继续搞熊二和白垩；开保底开到巡洋以上大船，巡洋及以下赶紧定白垩和熊二。
- 防空碰瓷需委派点敌方基地。
- 针对敌方轰炸：AC721后增，导弹型点策略命中，增援ST59，枪骑兵拉满，配4-6萤石，有白垩更好；省斗牛防御多上苔原。
- 开阳前期扛伤用基础型号，输出用子型号；子型号输出高于基础型号。可双开阳，省锆石上瑶光。
- 五战巡矛盾组合200人口不能省；玉衡基础+开阳+瑶光200人口不能省。
- 人口提升后用剩余光环和高速艾奥做第三队地推。
- 主队塞艇位时猎兵细节：T800上两锁够，猎兵自带70%减锁。

## 配队与模块
- 太阳鲸-武装战略航空母舰（原文为"鱼"，疑似简称）：十一配十三；三艘十一鱼手动添加三个为一组；两个十三鱼优先放维塔斯-B010轰炸机，后补5架维塔斯A021重型攻击机，刺鳐-鱼雷轰炸机（原文为"刺遥"，疑似错字）补位。
- 十一鱼艇位：索姆河之影-装甲飞行坦克（原文为"坦克"，疑似简称）+星云追逐者-脉冲炮艇（原文为"星脉"，疑似简称）；机位优先放米斯特拉-战斗攻击机（原文为"小米"，疑似简称）3个。
- 苍穹：C1，大型机库手动添加BR050-标准轰炸机（原文为"零五零"，疑似简称）基础；苍穹配林鸮A100型-联合攻击机；大型机库优先BR050+林鸮A100型-联合攻击机，小型机库补位。
- 小型机库：AT021-脉冲攻击机-A/新大地/天璇A/雷火V022；新大地做主输出，天璇走致盲流。
- 海氏：狩猎者级-战术载机巡洋舰或苍穹附加载机机库。
- 南十字：有加四上艇南，增援给副队；艇位坦普尔1号-信息护航艇（原文为"坦普尔"，疑似简称）、虚灵-隐身导弹艇（原文为"虚灵"，疑似简称）。
- 八战巡：普鲁图斯之盾级+乌拉诺斯之矛（原文为"三毛/毛"，疑似简称）+永恒风暴级（两盾三矛三风暴）；风暴中排，上C2。
- 五战巡：矛盾组合配开阳级+瑶光级+玉衡级；中期放中排；节点调矛站位；模块上附加矛。
- 八战巡：五战巡至少3光防；八战巡下光防上反倒；损管矛改损管；艇选CV-M011型-重型导弹艇（原文为"零幺幺/011"，疑似简称）、虚灵、坦普尔1号分伤。
- 巡洋两盾三矛三风暴成型，剩余3风暴放主队断奶。
- 组队：苍穹C1造满做增援，可切C2；上泡泡龙+奇美拉级-火炮巡洋舰（原文为"奇美拉重炮/齐美拉的重炮"，疑似简称）。
- 大型机库20机位优先BR050+林鸮A100型-联合攻击机；小型机库AT021/新大地/天璇/雷火；艇南有加四放雷火V022基础型号，还有4机位。
- 锆石级-特种护卫舰+刺水母级-战术护卫舰不上；配双鱼海可上B型；之后拉开阳级，剩余人口拉阋神星I级-重炮驱逐舰（原文为"吸神星的重炮"，疑似语音识别错误）或雨海级-脉冲炮护卫舰（原文为"雨海脉冲"，疑似简称）。
- 防空碰瓷委派：谷神星级-支援驱逐舰（原文为"股神星"，疑似语音识别错误）+苔原级-战术驱逐舰（原文为"台元"，疑似语音识别错误）（双皮奶）+斗牛级-防御驱逐舰（原文为"斗牛防御"，疑似简称）+AC721-重型导弹驱逐舰（原文为"七二幺"，疑似简称）+5到8个枪骑兵级-区域防空驱逐舰（原文为"枪房"，疑似简称）点基地。
- 针对轰炸：AC721-重型导弹驱逐舰后增，导弹型点策略命中；增援ST59级-防御战列巡洋舰（原文为"五九"，疑似简称）；枪骑兵拉满；配4到6个塔拉萨萤石级-信息驱逐舰（原文为"银时"，疑似语音识别错误）；有白垩更好；省斗牛防御多上苔原级。
- 开阳：前期扛伤用开阳级-机动驱逐舰（原文为"开洋"，疑似错字），输出用子型号；双开阳省锆石上瑶光级。
- 五战巡200人口：玉衡级基础+开阳+瑶光；吃大盾旗舰；增援位1大盾+3中排矛+1光环+6六奶。
- 人口提升：剩余光环+艾奥级-高速离子炮巡洋舰做第三队地推。
- 主队塞艇位：猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误）；CV-T800型-脉冲炮艇（原文为"八百"，疑似简称）上两锁。
