# A资料126

## 场景 / 对手
反轰炸航母碰瓷队，正面防空作战，环境为巅峰五满调

## 舰队例子
- 十三鱼航母，M2模块：10小米、10零消、8雷火A、8雷火B、4包子；CE模块：10沙龙、10新大地、5包子（胜）【纯防空配置，利用十三鱼高血量和能量抵抗，配合飞机回血，最大化防空火力】

## 实战结果
反轰炸航母碰瓷队使用十三鱼作为最优航母，凭借高血量和能量抵抗，以及飞机回血机制，成功抵御轰炸并发挥防空火力

## 结论思路
- 十三鱼拥有五十万九千五百六十九血量，具备百分之二十五能量抵抗，五条鱼总血量两百五十四万加，生存能力强
- 十三鱼上的飞机每次攻击结束回复百分之十血量，是飞机最佳母舰，提升飞机持续作战能力
- 航母和飞机生存双强，能发挥防空飞机最大火力，适合反轰炸碰瓷

## 适用限制
- 适用于巅峰五满调环境
- 纯防空场景，需携带指定飞机配置以发挥最大效果
- 不适用于需要其他功能（如对舰输出）的场合
