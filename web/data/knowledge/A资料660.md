# A资料660 · 永恒苍穹全模块解析

> 场景：主战航母/轰炸/空战；双航母抗商队

## 结论
- 永恒苍穹级-无人机航空母舰（原文为"苍穹"，疑似简称）定位战略打击，是当前最强副航母，也可当地推主战航母。
- M1为白板最实用机库，是绝育战机专属机库；最优秀搭配林鸮A100型-联合攻击机，狩猎者级-载机巡洋舰（原文为"狩猎"，疑似简称）带的林鸮A100型-联合攻击机弱，苍穹带的林鸮A100型-联合攻击机能与维比争锋。
- M1无人艇为能量伤害，对舰输出不错；带防空战机时也能打一点防空，适合多种作战场景。
- M1系统打击效率越高，系统殉爆伤害越高，直接提升所有绝育战机的对舰输出。
- M1分散作战扩大打击规模；短期绝育效率降低，长期打掉系统更多、绝育战机伤害更高。
- M1额外返回缩短舰载机往返效率，等同战机冷却，效率越快伤害越高；作用于全航母舰载机，不止该机库。
- 往返加点对独立作战舰载机不生效，如新麦类炮艇与无人艇；无人艇跟随战机出击，战机往返越快无人艇频率越高。
- M2无人艇为实弹伤害，基本没有对舰火力；主要防空，优先打护航艇，伤害可观，主动防空覆盖所有空域，可视为三个CV-T800型-脉冲炮艇（原文为"t八百"，疑似语音识别错误）。
- M2立体掩护在战机打击敌方载机时触发，空战很强；对战机不生效，规避不是闪避，可理解为无敌时间且无次数限制，但策略期间战机往返仍能被打到，实战效果可能不如预期。
- M2是空优机专属机库，加点完全服务空战。
- M3无人艇反击防空，优先战机，防空范围仅我方半场；不主动跟随战机打任意空中目标，类似砂龙-大气层拦截机（原文为"杀龙"，疑似语音识别错误）。
- M3诱导掩护条件苛刻、概率非100%，实战非常鸡肋，提升很小。
- M3定位携带炮灰在空战拖时间，无人艇强度低，机库加成差；适配轰炸带炮灰挡刀，主战航母最好别用，自带M1更强。
- M3在轰炸中战机只挡第一波伤害，不需要往返跑第二遍。
- M模块所有策略都能在轰炸中生效；无人艇无法在轰炸中发挥作用，不参与轰炸；轰炸玩法可不用在意M模块。
- C1抽到即可当主战航母带主流轰炸机；M模块20%返回也作用于C机库，实际加成比C位高。
- C2是当前轰炸核心模块，机库加成和猎兵级-重型载机巡洋舰（原文为"列兵"，疑似语音识别错误）基本一样；M模块返回对护航艇不生效。
- 轰炸旗舰额外弹药补给满后，对没有攻击食欲时间的单位加成直接伤害×3；增援给队友或自身旗舰，只要轰炸就生效，不做旗舰也生效。
- C3（原文为"ca三"，疑似语音识别错误）主要用途奶妈；天枢级-支援航空母舰（原文为"天书"，疑似语音识别错误）出来后上场率低，与苍穹当前定位冲突；仅小众双航母抗商队可用，奶量不错。
- A1直射实弹武器打伤害别指望，可有可无。
- A2离子炮是苍穹除无人艇外第二伤害来源；伤害频率低只有一次，基础命中率高，地推航母有上场价值。
- A2推荐伤害而非反大命中，因基础命中高、大船闪避不高、反大命中边际收益低。
- A3脉冲炮主要防空，航母上算添头，非核心模块。
- B模块整体不太有用，有没有都一样；B1别指望打伤害；B2大概率用不到；B3无特色。

## 配队与模块
- M1：白板自带；3中型战机+3无人艇；核心加点系统打击效率、分散作战、额外返回；主战带林鸮A100型-联合攻击机等绝育战机时剩余加点选冷却、伤害、返回；轰炸带海氏追随者型-脉冲攻击机（原文为"海誓"，疑似语音识别错误）时返回与策略无收益，换索敌、命中、伤害。
- M2：3战机+3无人艇；加点除双伤害和闪避不点，其余点满。
- M3：3无人艇+3战机；加点不点双返回；适合轰炸带炮灰挡刀。
- C1：大型战机模块，4个加点位；带轰炸机少点一个伤害。
- C2：轰炸核心模块；加点上面两个不点，下面四个点满。
- 旗舰：额外弹药补给点满。
- C3：奶妈模块；用于副对抗商和天枢级-支援航空母舰走双航母抗商队。
- A1：直射实弹武器，可有可无。
- A2：离子炮；优先保证小船命中，冷却点满，伤害与反大命中二选一，推荐伤害。
- A3：脉冲炮，主要防空，非核心。
- B1：投射导弹，优先打小船。
- B2：拦截模块，除非抗伤否则不调校。
- B3：防空导弹，面板一般、范围一般，常规加点。

## 数值与数据
- M1共6个加点位。
- M1额外返回：同级别CV3000级-快速航空母舰（原文为"cv航母"，疑似简称）返回点满40%，苍穹在原有基础上多20%。
- M2立体掩护：战机攻击持续时间内60%规避所有伤害。
- M3诱导掩护：舰载机血量低于15%时提供无敌状态，持续30秒，仅触发一次。
- C2点满需32点；旗舰额外弹药补给点满需20点。
- 旗舰额外弹药补给对没有攻击食欲时间的单位加成伤害×3。
- B2加点可提高15%拦截率，调校还能继续提高。
