# A资料288

## 场景 / 对手
低赛配队，针对新手，面对海盗砸矿车

## 舰队例子
- 卡特、鸭脖、开阳（抗伤驱护）（胜）【前期单队抗伤选择】
- 锆石、鱼海、斗牛、721、离子枪、骑综合（输出驱护）（胜）【前期单队输出选择】
- 诺玛奶、台源（奶船）（胜）【台源以防空为主，奶量不高】
- 浔阳（输出主力）（胜）【中后期护航双队，输出主力】
- 普通光锥、I L列兵（护航艇）（胜）【列兵数量取决于强力护航艇数量】
- 风潮、T八百（护航艇）（胜）【强力护航艇例子】
- 六十六奶（奶船）（胜）【廉价高奶量，可上满】
- 奇美拉（抗伤）（胜）【资源富裕时上】
- 白板五十九（驱护）（胜）【无奇美拉时增援，抗六队坚持三分钟】

## 实战结果
以该号为例，前期单队驱护配队，中后期护航双队，抗六队坚持三分钟

## 结论思路
- 前期单队以抗伤、输出、奶船组成
- 中后期配护航双队，输出放安全环境
- 航母战巡若无必要不上，以浔阳为输出主力
- 护航艇数量决定列兵数量
- 无奇美拉时用白板驱护增援

## 适用限制
- 仅针对新手
- 蓝图少时适用
- 配对需根据自身号调整，不可照搬
