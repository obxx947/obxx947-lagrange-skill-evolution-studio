# A资料632

## 场景 / 对手
碰瓷队核心思路讲解，涉及我方十苍穹缝合轰炸队与敌方碰瓷队对抗，以及我方碰瓷队对抗敌方十苍穹缝合轰炸队

## 舰队例子
- 我方轰炸队：10苍穹缝合（含10个零零三、20个星脉、16个八百、18个坦克、10个安德森、20个at零二幺）（胜）【战报1，敌方碰瓷队配置为10台元、10股神、10斗牛、10妖光，我方炮艇基本无损，敌方舰队几乎全灭】
- 我方碰瓷队：1中甲五九（带4个小米）、91个斗牛、10个七二一导弹、9个股神、10个瑶光（胜）【战报2，对抗敌方10苍穹缝合轰炸队，敌方4分钟仅打100多万伤害，我方战损极小】

## 实战结果
战报1：我方轰炸队胜，敌方碰瓷队败，敌方台元伤害低（打at零二幺），我方输出100多万；战报2：我方碰瓷队胜，敌方轰炸队败，敌方星脉4分钟仅43万伤害，我方五九满血，股神奶量39万

## 结论思路
- 碰瓷队防空火力必须优先集火炮艇，以降低对面轰炸火力，提高自身生存
- 碰瓷队需带入重甲战巡吸引坦克火力，实现伤害分流，为小船创造生存空间
- 碰瓷队小船必须足够肉，提高伤害稳定性，避免被一波带走
- 在满足上述条件的小船中，选择防空伤害最高的带入建队

## 适用限制
- 台元仅适合航母碰瓷队，因空优战机可快速清除干扰机，解放台元伤害
- 碰瓷队不宜携带护卫舰，因太脆易被轰炸清除
- 优先集火炮艇的武器（如枪炮、其而以导弹）对轰炸队更有效
