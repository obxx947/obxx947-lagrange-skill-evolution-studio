# A资料501

## 场景 / 对手
苍穹全模块讲解，涵盖走地（护航）和轰炸两种主要使用场景，对手体系包括护航盾、轰炸拦截、防空等

## 舰队例子
- 苍穹M1 + C2，搭载凌霄/维亚/新大地攻击机（胜）【走地护航，利用分散攻击稳定破除绝域盾，提升队伍护航阶段优势】
- 苍穹M2 + C2，搭载轰炸机（如星脉、坦克）（胜）【轰炸时提供生存增益和主动防空，为基线挡刀并清理对方空优】
- 苍穹M2 + C3，作为副队奶妈（胜）【高氪账号使用，提供坦度、奶量和分叉效果，适合肉队】

## 实战结果
苍穹凌霄在护航阶段对绝域盾有质变效果，有苍穹凌霄的队伍与无此配置的队伍相比有天然优势；苍穹C2轰炸可让星脉、坦克等获得三倍伤害，效果显著

## 结论思路
- M1模块适合走地，分散攻击和争议必点，冷却、索敌、往返（一格）和伤害按需取舍，最后一个往返不点
- M2模块适合轰炸，生存争议（60%规避）和主动防空无人艇强大，加点优先护甲、往返、冷却、索敌、伤害，闪避不点
- M3模块轰炸可用但不如M2，触发条件苛刻（载机低血量），加点类似M2
- A系统选择A2（反大直射），A1反小命中差，A3防空面板低
- B系统选择反舰投射，拦截和反击防空效果差
- C1机库加成接近十三鱼，但分散攻击会导致维B尿分叉，不推荐走地搭配
- C2模块封神，提供两次攻击次数，轰炸时三倍伤害
- C3模块在高氪账号中作为副队奶妈有价值，配合M2提供坦度和奶量

## 适用限制
- M1走地适合有凌霄等攻击机的队伍，需点分散攻击
- M2轰炸适合有轰炸机（星脉、坦克）和干扰机的队伍
- C3奶妈需要高航母点，仅适合高氪玩家
- C1不推荐走地，因分散攻击影响维B输出
- M2闪避加点无用，因防空优先攻击护航艇
