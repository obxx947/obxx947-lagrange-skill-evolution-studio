# A资料227

## 场景 / 对手
护航艇A/B型号对比，涉及进化协议、轰炸队、航母机库、列兵、苍穹C2机库等

## 舰队例子
- 星云追逐者A型号（弹炮型）+ 装甲系统 + 干扰系统 + 动力系统（闪避策略点满）（胜（作为轰炸挡刀艇，提升轰炸输出））【非进化协议下输出低，但生存能力强，适合挡刀】
- 星云追逐者A型号（进化协议专属新气限定武器技术）（胜（伤害超越B型号））【仅在进化协议中有效】
- 星脉（B型号脉冲型）+ 武器系统 + 动力系统（70蓝点）（胜（主队输出提升））【优先反小，伤害高，但被开阳和瑶光克制】
- 星脉 + 苍穹C2机库 + 苍穹策略（胜（伤害翻三倍））【轰炸主要输出，武器无持续时间】
- 星脉 + 列兵（打超战）（胜（适合超战））【根据队伍选择搭配】

## 实战结果
星云追逐者A型号在非进化协议下输出低，但可作挡刀艇；B型号星脉输出高且稳定，但受开阳和瑶光克制。星脉在苍穹C2机库中配合策略伤害翻三倍，是轰炸主要输出。

## 结论思路
- A型号非进化协议下输出低，但生存能力强，可作轰炸挡刀艇
- A型号在进化协议中装专属武器可超越B型号
- B型号星脉输出最高最稳定，优先反小，适合航母主机库或列兵打超战
- 星脉放苍穹C2机库配合策略伤害翻三倍
- 星脉武器加点：母舰无气势锁时命中换索敌
- 星脉生存有闪避加成，但无A型号的闪避策略
- 星脉获取难度高（自行号码），主队输出只需70蓝点点武器和动力系统，轰炸需点装甲和闪避
- 新手抽到星脉可放心带入主队提升输出

## 适用限制
- A型号非进化协议下不适合输出，仅适合挡刀
- 星脉被开阳和瑶光克制，但影响相对较小
- 星脉获取难度高，需自行号码
- 星脉轰炸需点装甲和闪避，主队输出只需武器和动力系统
