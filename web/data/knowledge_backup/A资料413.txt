每天练习一个拉格舰船只，玉衡级支援巡洋舰。玉衡级由盘古重工集团设计，驱言型为玉衡级的 c 型号，简称玉衡 c。现版本玉衡最强型号就是 c 型号，玉衡 c 针对快速维修区库而设计，主系统凝光应急装甲维修系统能快速维修舰队内受损的区库，配件加点能达到最好的维修效果。后台定位高抵抗自身维修策略，保证了自身的存活率极低的冷却和锁定时间，使得维修面板达到了惊人的36,000多。维修 驱护非常高效，并且武器系统能达到9000对舰面板提供了不错的反响火力。面对敌方驱护也能更快解决指挥系统自带的同公司加成，能让其他盘古之户打出更多伤害。但缺点是维修不够持久，白板携带的300克一次性维修装甲消耗完后不会再提供维修好，在调价版后固有450个实战中单搜能提供三十万左右的维修量，四个御衡 c 维修量就可以过百万。但御衡 c 是巡洋舰，如果你的副队依赖于零六六 g 原型带了库。 多的巡洋舰反而更容易被蛋奶。 所以玉恒心不是带越多越好的。 总结。 玉衡西能提供高效的区户维修。 和较为可观的反小火力。 但维修目标仅限于七户。 且维修总量有限。 这些秀森会吸引其他奶茶的奶量。 需要更加适合玉和C上场的舰队配置。
