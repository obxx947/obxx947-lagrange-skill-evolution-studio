## 3. 改动明细（6 组，均在 `simulator.html`，按"改前→改后"给出）

### 【1】修「折算归零」——米斯特拉 0 伤害的真因 ★核心
**位置**：`executeShot()` 的 APPLY DAMAGE 段落（锚文本：`打载机 / 打舰船的折算`）。
**现象**：米斯特拉（单发10）打战列舰：10% 保底算出 1 点 → ×`vsShipMul`(0.104) → `Math.round` → **0**，连打 81 发全 0。

```js
// 改前
if (target.position === 'aircraft') { if (weapon.vsAirMul > 0) dmg = Math.round(dmg * weapon.vsAirMul); }
else { if (weapon.vsShipMul > 0) dmg = Math.round(dmg * weapon.vsShipMul); }
// 改后（只要有伤害，折算后至少 1 点）
if (target.position === 'aircraft') { if (dmg > 0 && weapon.vsAirMul > 0) dmg = Math.max(1, Math.round(dmg * weapon.vsAirMul)); }
else { if (dmg > 0 && weapon.vsShipMul > 0) dmg = Math.max(1, Math.round(dmg * weapon.vsShipMul)); }
```
**实测**：对舰 0 → 4058（【9】分流模型后同场景为 **4134**）；验收 13/18 保持且 B 对空 −13.5%→−12.6%、敌方护航→我被护航对舰更准。

### 【2】系统伤害量级修正（去"双重归一化" + 吃暴击；⚠️ 此中间形态已被【9】取代 —— 直接按【9】做即可，本节保留供对照）
**位置**：`executeShot()` 的 SYSTEM DAMAGE 块（锚文本：`系统破坏原本按【每一发】判定`）。
**真因**：概率已 ÷发数（每轮期望=效率值），**伤害又 ÷发数** → 每次判定被压成 1 点；
知识库口径：系统伤害系数 1.5、**无护甲**、**会暴击**（「米斯特拉双伤双暴击=(20+4+4)×1.5×1.8=75.6 取整 75」）。

```js
// 改前
```

**实测**：【2】时代 15 → 241；【9】分流模型后重跑全舰验证（×6、双种子、靶止战级）：米斯特拉 **38952/40081**、刺鳐 **46242/51408**、天枪 **34668/35667**、太阳鲸 **102925/102626**。

### 【6】系统伤害两个真 bug：死键 + 已毁系统重复扣 5%
**位置**：`executeShot()` SYSTEM DAMAGE 块的匹配行 + 新增 `sysCatOf()`（插在 `executeShot` 函数前）。
**bug a（死键）**：游戏四类键「主武器系统/主机库系统」几乎匹配不到任何船的子系统名（子系统名从模块名提取）→ 挑到这类键的武器永远 0。
**bug b（重复计毁）**：只排除 `permanentDestroyed`，**待维修（25s 后复活）的已毁系统仍能被命中** → 每命中又计一次击毁、又扣一次 5% 船血（实测补射 1500 发多计 4 次、多扣 4×5%=57924）。

```js
// 新增 helper（放在 executeShot 之前）
function sysCatOf(s) {
    const nm = String((s && s.name) || '');
    if (s.type === 'command' || /指挥/.test(nm)) return '指挥系统';
    if (s.type === 'engine'  || /动力|引擎/.test(nm)) return '动力系统';
    if (s.type === 'hangar'  || /机库|机坞|搭载|舰载机|护航艇/.test(nm)) return '主机库系统';
    if (/武器|炮|导弹|鱼雷|无人机|武装|发射/.test(nm)) return '主武器系统';
    return null;
}
// 改前
const sys = target.subSystems.find(s=>s.name.includes(sysName) && !s.permanentDestroyed);
// 改后（名字匹配失败→按类别再匹配；跳过已毁）
const _sysMatch = (pred) => target.subSystems.find(s => pred(s) && !s.destroyed && !s.permanentDestroyed);
const sys = _sysMatch(s => s.name.includes(sysName)) || _sysMatch(s => sysCatOf(s) === sysName);
```
**实测**：死键武器（只有"主武器系统"键）从恒 0 → 有效系统伤害（同探针整场 17222）；补射已毁系统 → 不再重复计毁（killRepeated = 0）。

### 【8】系统「复活」要回血（真 bug 修复）
**位置**：`processBattleTick()` 的子系统维修段（锚文本：`Process subsystem repairs`）。

### 【9】系统伤害 = 「命中分流」模型（★按《战斗机制》原文重写，替代旧的"概率小口啃"）
**依据**（`知识库2/知识库/战斗机制.md` §195-203 / §363-378）：
「系统伤害效率高中低指的是**命中分流比率**，高中低比率分别是 **60%、40%、20%**」；
「打在系统上的伤害**全额生效**，打在装甲上的伤害会被抗性抵抗」；
「VA战机对动力系统效率高：**70%-90%** 的伤害打在目标系统上」（≈ 60% 分流 × 系统系数 1.25~1.5）；
「武器进行系统攻击**有伤害系数**（1.25/1.5/3）；可攻击系统的武器**打结构有系数**（不全是 0.8）」。

**实现（simulator.html 三处）**：
1) 伤害计算前（`energyArmor` 之后、`let dmg;` 之前）——常量 + 分流预计算：
```js
const SYS_SPLIT = { high: 0.6, medium: 0.4, low: 0.2 };   // 分流比率
const SYS_ATK_COEF = 1.5;   // 系统攻击伤害系数（逐武器 1.25/1.5/3，库里未逐门存 → 默认 1.5）
const STRUCT_COEF = 1.0;    // 结构侧系数（§371 逐门未知 → 不设；0.8/1.0 均实测 13/18，取 1.0）
let _sysSplit = null;
if (weapon.subSystemTargets && target.subSystems && target.subSystems.length > 0) {
    const _sysMatch0 = (pred) => target.subSystems.find(s => pred(s) && !s.destroyed && !s.permanentDestroyed);
    for (const [sysName, eff] of Object.entries(weapon.subSystemTargets)) {
        const sys = _sysMatch0(s => s.name.includes(sysName)) || _sysMatch0(s => sysCatOf(s) === sysName);
        if (sys) { _sysSplit = { sys, ratio: SYS_SPLIT[eff] || 0.2, eff }; break; }
    }
}
const _structMul = _sysSplit ? (1 - _sysSplit.ratio) * STRUCT_COEF : 1;
```
2) 物理/能量伤害分支：`baseVal` 换成 `baseVal * _structMul`（能量分支 `singleDmg * _structMul`），10% 保底同口径；
3) 原 SYSTEM DAMAGE 块整体换成「分流应用段」：
`systemDmg = Math.max(1, Math.round(baseVal * tuningCoeff * critMult * _sysSplit.ratio * SYS_ATK_COEF))`
（`sysDmgReduce` 削弱保留）→ 全额扣系统血 + 击毁/扣5%/记账（其余照旧）。

**`SYS_JUDGE_MUL`（概率倍率）已删除** —— 现在每发命中都分流，没有概率判定。
**实测**：10 林鸮+10 米斯特拉打战列舰 600s：**摧毁系统 0 → 4 个**（系统伤害 ~120k）；验收 **13/18**（回到最高档）。
**游戏真值对照**（《拉格朗日_战报1》158 张截图 OCR 全量，251 条「系统伤害（数量）」）：中位 **6468**、最高 **638845**；击毁数 **228/251 条为 0**，少数 1~10 → 新模型（验收两场 21万~91万 / 击毁 8~17）同水平、略高（旧模型 3456/0 个，差 2 个量级）。
