功能架构总览

一个会自我进化、可人工干预进化的《无尽的拉格朗日》AI 战术顾问 · 本地离线语音 · 知识库驱动

📱 安卓 App：点击下载安装（APK，含离线知识库） · 🌐 网页版：在线使用（GitHub Pages）
1️⃣ 核心对话引擎
🛰️
多 Agent 并行检索
舰队配置 / 舰船数据 / 战斗机制 / 讲解范例 4 个子代理并行检索知识库，主检索兜底，即问即答。
检索
🔧
7 个工具
知识库检索、舰船精确查询、战斗模拟、联网搜索、提问澄清、自主建工具、自主建Skill——AI 按需调用。
工具
🔬
FACT-AUDIT 质检
主张拆解→证据检索→多裁判辩论→五层审计→量化评分→链状修正；第2次仍不合格即强制放行，防死循环。
质检
🪄
计划模式 / 普通模式
普通模式直接回答；计划模式先出执行计划书、用户批准后才执行。顶栏一键切换。
模式
2️⃣ 自我进化（Agent 自主）
🧬
经验 Skill 沉淀（自动）
每轮对话结束后，AI 自动判断这段对话是否有可复用经验（配队思路/回答技巧/稳定偏好），有则沉淀为 Skill，无则静默。
自动
🧰
自主创建工具
AI 判断现有工具不够用时，自行写代码创建新工具，经「语法编译 + LLM 逻辑审查」自检通过即激活，不通过自动修复。
自动
🎯
Skill 按需注入
相关 Skill 命中关键词自动注入本对话；不相关不注入（防 token 膨胀）；画像只注入精简摘要。
自动
3️⃣ 用户干预进化（人工）
👍👎
点赞 / 点踩反思
对回答点赞/点踩可填理由，AI 反思整段对话，沉淀经验 Skill、更新用户画像。你越用，它越懂你。
人工
✍️
手写 Skill
在技能/工具页手动写一个 Skill（名称+摘要+关键词+全文），创建后相关对话自动注入。
人工
💬
对话直接创建
直接说「把这个保存成 Skill」，AI 就调用 create_skill 帮你创建。
人工
⚡
斜杠命令强制干预
/skill、/工具、/压缩、/回溯、/重启、/clear 等，强制注入、强制调用、强制操作。
人工
4️⃣ 对话管理
🌿
分叉对话
在任意消息处分叉，快照生成一个全新独立会话，原对话保留。
对话
↩️
回溯 / 重启
回溯=删除最新一轮问答；重启=回溯后原样重发那条提问。
对话
📎
@ 引用上下文
输入 @ 选中历史会话，其上下文注入本次提问供 AI 参考。
对话
🧹
/clear 清空会话

对话

6️⃣ 知识库
📚
双知识库检索引擎
第一知识库（47个md：舰船数据/战斗机制/实例/黑话）+ 第二知识库（备份精炼），TF-IDF 语义检索 + LRU缓存。
知识库
🗂️
开发中心
批量清洗→语义分块→实体抽取→冲突仲裁，产出清洗文档/父子块/知识图谱/勘误报告。
知识库
🔎 检索方式（混合检索管线）
📊
TF-IDF 稀疏检索
中文 bigram 分词 + 余弦相似度，关键词/词频召回。
稀疏
🧬
RAG 语义检索（bge）
前端 transformers.js 加载本地 bge-small-zh-v1.5 静态向量库（rag_index.json，512维×1125分块），离线免费；默认模型亦启用。
稠密
🗂️
分类检索
按资料类别（舰船数据/战斗机制/实例/黑话/人口…）定向检索。
分类
🚢
舰船名精确检索
SHIP_DB 精确匹配舰船，命中即给，未命中提示查黑话。
精确
🔀
RRF 倒数排名融合
融合稀疏 + 稠密两路结果，综合排序取Top。
融合
⚖️
元数据分层加权
音频口语稿降权、结构化舰船/配队数据升权，按来源质量调分。
加权
📑
相邻块上下文扩展
补同一来源前后 chunk，增强上下文连贯性。
扩展
🚧
数据文件夹 md 红线
仅允许知识库内来源进入结果（白名单，防外部/备份污染）。
红线
🧹
噪声过滤
去除碎片、重复、口语冗余、空白实例。
过滤
🎯
质量门控 CRAG
召回整体低分 → 触发改写二次检索，提升召回质量。
门控
⭐
A资料1-400 高优先
编号靠前的 A 资料优先参考，高于其后所有资料。
优先级

🔄 一次对话的完整流程
用户提问→4个子代理并行检索→主检索+联网搜索→组装【系统提示词+知识库资料+相关Skill+对话历史】→Agent主循环（可调7工具/可提问暂停）→FACT-AUDIT质检→最终回答+来源标注

自我进化路径：对话结束→自动反思→沉淀Skill/更新画像→下次相关对话自动注入
人工进化路径：👍👎 / 手写Skill / 对话直接创建 / 斜杠命令→Skill库→按需注入
💡 一句话理解：AI 对话用知识库+工具+质检保证准确；自进化与人工干预让 AI 越用越懂你；本地语音离线随时可用。
📌 入门：先到 ⚙️设置 确认模型，再到 🤖AI对话 提问；想沉淀经验就👍、想干预就✍️手写Skill或💬叫AI保存。
8️⃣ 所有智能体（Agent）定位
🧠
主 Agent（主对话/SYSTEM_PROMPT）
执行核心任务：按舰船知识库强制校验查数据、配队、查机制、出计划、五轮评测、输出附打分与理由；唯一读全量系统提示词的主体力。
🚪
需求理解/意图门（intentClarify）
结合最近5轮历史判断：明确需求、判断是否"日常闲聊"；闲聊→直接回答；任务→放行并注入明确需求。
🚢
检索舰队·检索总Agent
汇总≤3个检索子Agent的素材，去噪合并，按【核心思路/关键规则/原文事例/关键数据/争议点】5维提炼成【检索素材包】交主Agent。
🔍
检索舰队·检索子Agent（≤3）
两阶段：①输出检索意图(query/category/ship)→②代码多路检索(向量/关键词/分类/舰船名，≤50条)→解析标注(高/中/低/疑似沾边)并萃取原文，只产素材不答用户。
🕵️
质检 Agent-A（审计）
六步审计：关键词检测→战斗机制审计→逐句拆解→概括回答→具体建议→输出漏洞清单(found_issues)。查编造/数值/约束遗漏/来源/逻辑矛盾。
⚖️
质检 Agent-B（裁判）
三维度打分(数据来源/推演/思路，各1/3)，综合≥75 PASS、<75 FAIL。复核A的发现、检查漏判。
🛡️
监督 Agent（supervisoryCheck）
给全部Agent提示词重点，监督面向用户的输出/提问是否遵守硬性规则（军规校验/禁等级制/必附打分/知识库可溯源等），只做合规标记不重写答案。
💬
闲聊直答（chatDaily）
意图门判为日常闲聊时，主提示词单轮直接回答，不走检索/工具/质检。
📚
经验反思（REFLECT / AUTO）
点赞点踩/对话结束自动：提炼用户画像、沉淀Skill(查重/anti_patterns)；自动模式还要识别用户纠正/不满/反复需求/认可。
🧰
工具·元数据/安全审查/修复
create_tool 三件套：生成function-schema、LLM安全审查(强制检索知识库验证逻辑)、运行失败自动修复。
🗜️
对话摘要压缩（compress）
历史超阈值时把最旧轮次压成摘要(3500-7500字)，保留需求/结论/配置/禁忌/争议，保最近N轮全文。

🔢 全功能触发时的完整流程演示
场景：用户问「帮我配一个470+5的护航抗伤队，我没有CV3000」
① 需求理解(意图门)：读最近5轮历史，判定为任务(非闲聊)，提取意图=「470人口+5增援·护航抗伤队·无CV3000」→注入【需求理解·已明确用户需求】
② 检索：KB.load(kb_corpus) + TF-IDF稀疏top20 → RAG语义(bge)融合 → 过滤/加权 → A资料1-400优先；非默认模型再走检索舰队(子Agent出意图→多路检索≤50→解析→总Agent 5维【检索素材包】)
③ 联网：webSearch 补权威资料
④ 组装messages：主提示词+能力清单+用户画像+注入skill+【计划/普通模式】+【检索素材包】+【联网】+历史+【引用的历史对话】+明确需求+用户消息
⑤ 主Agent(agentLoop)：检索舰船数据核验→加入舰船先 ask_user 附数据经同意→对比候选→(可选 create_tool 自建DPM/人口计算工具并调用)→五轮评测打分→生成方案
⑥ 质检：Agent-A审计(查编造/数值/约束遗漏) → Agent-B裁判(数据/推演/思路,≥75PASS)→(非默认)监督Agent合规标记→输出配队必附打分+理由+来源标注
⑦ 沉淀/交互：👍点赞→反思沉淀Skill；对话结束自动反思更新画像→下次相关对话自动注入
⑧ UI：手机顶栏三栏(历史/AI状态/新建)+底部模式/模型一条+输入区；桌面窄边栏(菜单+历史+连接)+标题栏(实时AI状态)+底部工具条；顶栏状态实时显示→每条回答上方的「已思考/运行状态」折叠块→消息下方操作条(赞/踩/朗读/分叉/回溯)→历史面板可搜索/引用当前对话
💡 模型提示：内建默认模型(功能/性能已极大压缩)，为确保质量与稳定强烈建议配置自己的 API Key（⚙️设置→模型）；默认模型用共享Key、易被限流，界面有「⚠️共享Key易限流」提醒芯片可点去设置，遇限流会自动保留进度后台重试。
